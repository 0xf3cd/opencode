OpenCode Console udostępnia listę modeli przetestowanych i sprawdzonych przez zespół OpenCode. Zaloguj się, doładuj
środki i pobierz klucz API, aby korzystać z nich w OpenCode lub innym agencie AI do programowania.

Console działa w OpenCode jak każdy inny dostawca. Jest **całkowicie opcjonalna** – zamiast niej możesz używać
dowolnego innego dostawcy. Jeśli wolisz subskrypcję z wliczonym limitem użycia, zobacz [OpenCode Go](/console/go).

## Jak to działa

1. Zaloguj się do [Console](https://opencode.ai/console), dodaj dane rozliczeniowe i środki, a następnie skopiuj klucz API.
2. Uruchom `/connect` w TUI, wybierz dostawcę OpenCode z płatnością za użycie (pay-as-you-go) i wklej klucz API.

   ```text
   /connect
   ```

3. Uruchom `/models`, aby wyświetlić dostępne modele i wybrać jeden z nich.

   ```text
   /models
   ```

Opłaty są naliczane za każde żądanie, a środki na koncie możesz doładowywać.

### Jev

Jev to model typu System One od TypeSafe AI, przeznaczony do szybkiego podejmowania ustrukturyzowanych decyzji. Zamiast generować tekst, ocenia stan (`state`) pod kątem typowanych pytań i zwraca wartości oraz prawdopodobieństwa, których Twój kod może użyć bezpośrednio. Obsługuje pytania typu tak/nie (`noul`), pytania wielokrotnego wyboru (`choice`) i pytania oceniane według kryteriów (`score`).

Użyj klucza API OpenCode Console z endpointem `https://opencode.ai/inference/v1/systemone`. Ten przykład sprawdza, czy zgłoszenie do supportu jest pilne:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

W jednym żądaniu możesz zadać kilka pytań. Jev ocenia je równolegle i zwraca każdą odpowiedź pod identyfikatorem odpowiedniego pytania:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Aby skorzystać z modelu bezpłatnego przez ograniczony czas, użyj `jev-1.13-free` zamiast `jev-1.13`. Szczegóły dotyczące typów pytań i pól odpowiedzi znajdziesz w [dokumentacji TypeSafe AI](https://docs.typesafe.ai/).

## Cele

Stworzyliśmy Console, aby:

1. **Testować porównawczo** najlepsze modele i dostawców dla agentów AI do programowania.
2. Oferować opcje **najwyższej jakości** – bez obniżania wydajności i bez przekierowywania ruchu do tańszych dostawców.
3. Przekazywać Ci **obniżki cen** dzięki sprzedaży po kosztach, z marżą pokrywającą wyłącznie opłaty za obsługę płatności.
4. Nie wiązać Cię z jednym dostawcą (**no lock-in**): możesz używać Console z dowolnym agentem do programowania albo
   korzystać z OpenCode z innym dostawcą.
