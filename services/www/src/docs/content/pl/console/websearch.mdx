---
title: "Wyszukiwanie w sieci"
description: "Hostowane wyszukiwanie w sieci dla OpenCode przez Console."
---

Console udostępnia hostowane wyszukiwanie w sieci użytkownikom OpenCode v2 połączonym z obszarem roboczym. Właściciel lub administrator obszaru roboczego włącza je raz dla całego obszaru, a członkowie nie potrzebują osobnego klucza do dostawcy wyszukiwania.

Każde udane wyszukiwanie kosztuje **$0.01** i jest wliczane do salda obszaru roboczego oraz limitów wydatków członków.

## Włączanie

1. Zaloguj się do [Console](https://opencode.ai/console) jako właściciel lub administrator obszaru roboczego.
2. Otwórz **Settings** > **General**.
3. Włącz **Hosted web search**.

Następnie każdy członek łączy OpenCode z obszarem roboczym poleceniem `/connect`.

```text
/connect
```

OpenCode wczytuje **OpenCode Web Search** z zarządzanej konfiguracji obszaru roboczego. Członkowie nie muszą ustawiać `websearch.provider` ani dodawać klucza API dostawcy.

## Wyszukiwanie

Poproś OpenCode w prompcie o aktualne informacje. Wyszukiwania są uruchamiane z OpenCode, a nie z interaktywnej strony w Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

Hostowany dostawca przeszukuje publiczną sieć i zwraca do ośmiu wyników. OpenCode używa ich, aby odpowiedzieć na prompt i podać źródła.

Aby skonfigurować uprawnienia lub wyłączyć narzędzie, zobacz [przewodnik po wyszukiwaniu w sieci](/websearch).

## Rozliczenia

Console pobiera **$0.01**, gdy wyszukiwanie zwróci prawidłowy zestaw wyników. Nieudane wyszukiwania i wyszukiwania odrzucone z powodu limitu żądań nie są płatne.

Wyszukiwanie w sieci jest wykazywane oddzielnie od użycia modeli w **Usage**, **My Activity**, aktywności członków, fakturach i eksportach CSV. Miesięczne limity wydatków obszaru roboczego i członków obejmują opłaty za wyszukiwanie w sieci.

## Prywatność

Hostowane wyszukiwanie w sieci nie przechowuje żadnych danych (zero data retention). Console i jej dostawca wyszukiwania przetwarzają każde zapytanie i jego wyniki bez zapisywania ich treści.
