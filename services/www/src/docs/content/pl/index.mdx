OpenCode to agent AI do programowania o otwartym kodzie źródłowym. Jest dostępny jako interfejs terminalowy, aplikacja
desktopowa i aplikacja webowa.

Pakiet npm używa skryptu postinstall, który wybiera natywny plik binarny `opencode` odpowiedni dla Twojej platformy.
Polecenia dla Bun i pnpm jawnie zezwalają na uruchomienie tego skryptu; Vite+ nie wymaga żadnej dodatkowej flagi. Polecenie mise wymaga mise 2026.10.9 lub nowszej wersji; starsze wersje instalują OpenCode 1.

Menedżery pakietów dla Windows nie są obsługiwane.


Możesz też pobrać samodzielny plik binarny CLI dla swojej platformy.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)

## Web

Interfejs webowy OpenCode otworzysz poleceniem `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Obrazy Dockera mają tagi z numerem wersji, np. `ghcr.io/anomalyco/opencode:2.0.0`.

## Łączenie z dostawcami

OpenCode ma wbudowaną obsługę wielu dostawców LLM – możesz połączyć się z nimi bezpośrednio
[w TUI](/cli/providers) poleceniem `/connect`.

Aby skonfigurować własnych dostawców, zobacz [Dostawcy](/providers).

Jeśli chcesz w prosty sposób korzystać z najlepszych modeli do programowania, wypróbuj
[OpenCode Console](/console).

Możesz też wypróbować [OpenCode Go](/console/go) – subskrypcję za $10 miesięcznie, która daje dostęp do najlepszych
modeli open source.

## Dostosowywanie

Dopasuj OpenCode do siebie: edytuj [konfigurację OpenCode](/config), [wczytuj wtyczki](/plugins), [podłączaj serwery
MCP](/mcp-servers) lub [twórz polecenia](/commands). Motywy i skróty klawiszowe interfejsu terminalowego opisano w
sekcji [Ustawienia CLI](/cli/config).
