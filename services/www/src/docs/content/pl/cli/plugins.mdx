---
title: "Wtyczki"
---

Wtyczki skonfigurowane w `opencode.json(c)`, które udostępniają komponent TUI, są ładowane przez CLI automatycznie. Jak
tworzyć wtyczki, opisano w sekcji [Tworzenie wtyczek](/build/plugins). Nie musisz dodawać tego samego pakietu do
`cli.json`. CLI pobiera listę aktywnych wtyczek z połączonego serwera OpenCode, więc działa to także wtedy, gdy serwer
jest zdalny.

W `cli.json` umieszczaj wtyczki przeznaczone tylko dla CLI. Działają one lokalnie w terminalu i pozostają aktywne, gdy
CLI łączy się ze zdalnym serwerem:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Wpisy są przetwarzane po kolei. Poprzedź ID lub wzorzec wieloznaczny znakiem `-`, aby wyłączyć pasujące wtyczki:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Opcje wtyczki przekaż w postaci obiektu:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode wykrywa też wtyczki w globalnym katalogu konfiguracyjnym i w katalogach `.opencode` projektów. Każda wtyczka ma
taki sam układ jak opublikowany pakiet – punkty wejścia serwera i TUI znajdują się razem.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Wykryte wtyczki mogą bezpośrednio importować `@opencode/plugin/tui`; OpenCode rozwiązuje ten pakiet w czasie
działania. Przykłady znajdziesz w sekcji [Tworzenie wtyczek CLI](/build/plugins/cli).
