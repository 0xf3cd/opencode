---
title: "Skróty klawiszowe"
---

Skróty dostosujesz w `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Dla jednego klawisza użyj ciągu znaków:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Alternatywy rozdziel przecinkami:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Skrót wyłączysz wartością `"none"` lub `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Aby określić zachowanie zdarzenia, użyj obiektu:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

Domyślną wartością `leader` jest `ctrl+x`. `<leader>` w innym skrócie oznacza ten klawisz.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Nieznane ID poleceń są odrzucane.

## Mini

Polecenie `app.clear` działa tylko w [`opencode mini`](/cli). Naciśnij `ctrl+l`, aby wyczyścić widoczny ekran i ponownie narysować prompt. Terminal zachowuje historię przewijania.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Domyślnie | Opis                |
| ----------- | --------- | ------------------- |
| `app.clear` | `ctrl+l`  | Wyczyszczenie ekranu |

## Przeglądarka diffów

Naciśnij `d` (`diff.switch_source`), aby wybrać **All**, **Committed**, **Uncommitted** lub **Last turn** (w sesji), albo wybierz **Base**, aby zmienić gałąź do porównania. Wybory są zapamiętywane do zamknięcia TUI. Początkowy zakres ustawisz za pomocą [`diffs.source` w `cli.json`](/cli/config#diffs).

Skróty przewijania, przechodzenia o stronę oraz na początek i koniec zawsze sterują diffem. Nie ma przełączania fokusu klawiaturą: klikaj pliki, aby je otworzyć, klikaj foldery, aby je rozwinąć lub zwinąć, a drzewo plików przewijaj kółkiem myszy.

Między plikami przechodzisz klawiszami `n` / `p` lub `alt+down` / `alt+up` (Option w macOS). W przeglądarce diffów skróty z Alt przełączają pliki, a nie karty sesji.

Naciśnij `m`, aby oznaczyć plik jako przejrzany i zwinąć treść jego patcha. W widoku wszystkich plików naciśnij `m` ponownie, aby usunąć oznaczenie i ponownie rozwinąć patch. W widoku jednego pliku oznaczenie pliku jako przejrzanego automatycznie przenosi do następnego pliku, ale na ostatnim pliku widok się zatrzymuje, zamiast wracać na początek. Usunięcie oznaczenia nigdy nie przenosi do następnego pliku.

Kliknij plik w panelu bocznym lub nagłówek jego diffu prawym przyciskiem myszy, aby wybrać **Mark complete** (lub **Mark incomplete**). Zmienia to ten sam stan przejrzenia co `m`. Oznaczenie innego pliku z jego menu nie zaznacza go ani nie przenosi z aktualnie czytanego pliku.

Alternatywy `diff.help` z Shift obsługują terminale, które przy naciśnięciu `?` zgłaszają modyfikator Shift.
