OpenCode er en AI-kodeagent med åpen kildekode. Den er tilgjengelig som terminalgrensesnitt, skrivebordsapp og nettapp.

npm-pakken bruker et postinstall-skript for å velge riktig native `opencode`-binærfil for plattformen din. Bun- og
pnpm-kommandoene tillater skriptet eksplisitt; Vite+ trenger ikke noe ekstra flagg. mise-kommandoen krever mise 2026.10.9 eller nyere; eldre versjoner installerer OpenCode 1.

Pakkebehandlere for Windows støttes ikke.


Last ned en frittstående CLI-binærfil for plattformen din.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## Web

Åpne nettgrensesnittet til OpenCode med kommandoen `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker-images bruker versjonerte tagger, for eksempel `ghcr.io/anomalyco/opencode:2.0.0`.

## Koble til

OpenCode har innebygd støtte for mange LLM-leverandører. Du kan koble til dem direkte
[i TUI-en](/cli/providers) med `/connect`.

Se [Leverandører](/providers) for å konfigurere egendefinerte leverandører.

Vil du ha enkel tilgang til alle de beste kodemodellene, kan du prøve
[OpenCode Console](/console).

Du kan også prøve [OpenCode Go](/console/go), et abonnement til $10/måned som gir deg tilgang til de beste
modellene med åpen kildekode.

## Tilpass

Gjør OpenCode til ditt eget ved å redigere [OpenCode-konfigurasjonen](/config), [laste inn plugins](/plugins),
[koble til MCP-servere](/mcp-servers) eller [lage kommandoer](/commands). Se [CLI-innstillinger](/cli/config) for temaer og
hurtigtaster i terminalgrensesnittet.
