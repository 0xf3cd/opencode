title: "Hurtigtaster"
---

Tilpass hurtigtastene i `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Bruk en streng for én tast:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Skill alternativer med komma:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Deaktiver en hurtigtast med `"none"` eller `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Bruk et objekt for å styre hendelsesoppførselen:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` er `ctrl+x` som standard. `<leader>` i en annen hurtigtast viser til denne tasten.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Ukjente kommando-ID-er avvises.

## Mini

Kommandoen `app.clear` fungerer bare i [`opencode mini`](/cli). Trykk `ctrl+l` for å tømme den synlige skjermen og tegne prompten på nytt. Terminalen beholder rullehistorikken.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff-visning

Trykk `d` (`diff.switch_source`) for å velge **All**, **Committed**, **Uncommitted** eller **Last turn** (inne i en økt), eller velg **Base** for å endre sammenligningsgrenen. Valgene huskes til du avslutter TUI-en. Angi det innledende omfanget med [`diffs.source` i `cli.json`](/cli/config#diffs).

Snarveiene for rulling, bla side for side og start/slutt styrer alltid diffen. Det finnes ingen tastaturveksling av fokus: Klikk på filer for å åpne dem, klikk på mapper for å utvide eller skjule dem, og bruk musehjulet for å rulle i filtreet.

Bruk `n` / `p` eller `alt+down` / `alt+up` (Option på macOS) for å gå mellom filer. I diff-visningen navigerer Alt-snarveiene mellom filer i stedet for mellom øktfaner.

Trykk `m` for å merke en fil som gjennomgått og skjule patchinnholdet. I visningen med alle filer trykker du `m` igjen for å fjerne merket og åpne patchen på nytt. Visningen med én fil går automatisk videre til neste fil når du merker en fil som gjennomgått, men blir stående på den siste filen i stedet for å begynne forfra. Når du fjerner merket for en fil, går visningen aldri videre.

Høyreklikk på en fil i sidepanelet eller på diff-overskriften dens for å få **Mark complete** (eller **Mark incomplete**). Dette endrer den samme gjennomgått-tilstanden som `m`. Fullfører du en annen fil fra menyen dens, blir den ikke valgt, og filen du leser nå, blir ikke byttet ut.

Velg en kommando som kjører, i fanen **Shell** og trykk **Enter**, eller klikk på den, for å se innsamlet stdout og stderr.
Bruk **↑/↓**, **Page Up/Down** eller **Home** for å rulle, **End** for å følge nye utdata og **Esc** for å gå tilbake uten å stoppe kommandoen.
Visningen viser nylige utdata og forblir åpen etter at kommandoen har avsluttet. Utdata som er omdirigert til en fil, er ikke med.
