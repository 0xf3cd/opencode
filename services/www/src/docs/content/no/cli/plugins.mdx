---
title: "Plugins"
---

Plugins som er konfigurert i `opencode.json(c)` og tilbyr en TUI-komponent, lastes inn automatisk av CLI-en. Se
[Lage plugins](/build/plugins) for å lære hvordan du lager plugins. Du trenger ikke å legge til den samme pakken i
`cli.json`. CLI-en henter listen over aktive plugins fra den tilkoblede OpenCode-serveren, så dette fungerer også når
serveren kjører eksternt.

Bruk `cli.json` for plugins som bare gjelder CLI-en. Disse pluginene kjører lokalt i terminalen og er fortsatt aktive når
CLI-en kobler til en ekstern server:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Oppføringene behandles i rekkefølge. Sett `-` foran en ID eller et jokertegn for å deaktivere plugins som samsvarer:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Send alternativer til en plugin med objektformen:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode finner også plugins under den globale konfigurasjonskatalogen og i `.opencode`-katalogene i prosjekter. Hver
plugin bruker samme oppsett som en publisert pakke, med inngangspunktene for serveren og TUI-en samlet.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Plugins som blir funnet slik, kan importere `@opencode/plugin/tui` direkte. OpenCode løser opp pakken under kjøring. Se
[Lage CLI-plugins](/build/plugins/cli) for eksempler.
