`@opencode/sdk` kjører OpenCode direkte i applikasjonen din. I motsetning til
[nettverksklienten](/build/client) setter SDK-en sammen OpenCode-serveren og sender
API-kall gjennom HTTP-ruteren i minnet. Den åpner ingen HTTP-lytter og legger ikke
til noe nettverkshopp mellom klienten og serveren.

For Cloudflare Durable Objects, se [Cloudflare-veiledningen](/build/sdk/cloudflare).

Installer SDK-en:

```sh
bun add @opencode/sdk
```

## Opprett en vert

`OpenCode.create()` returnerer en vert med eksplisitt eierskap. Bruk `await using` for å
frigjøre ruteren, Location-tjenestene, fibrene og de scopede plugin-registreringene:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Kall `await opencode.close()` eksplisitt når eksplisitt ressursstyring ikke er
tilgjengelig.

Den innebygde verten bruker de samme Promise-verdiene, deklarerte feilene,
forespørselsalternativene og `AsyncIterable`-strømmene som `@opencode/client`. Den
eksponerer hele den genererte klienten og legger til snarveiene `sessions` og
`events` for økt- og hendelsesgruppene.

## Worktrees

Worktree-operasjoner krever en `projectID`. Create og refresh laster inn konfigurasjon og plugins fra prosjektets lagrede
kanoniske checkout. List leser bare den lagrede oversikten; remove aktiverer de kanoniske pluginene og bruker den
registrerte strategien, og feiler hvis strategien ikke er tilgjengelig.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

Refresh finner worktrees i alle kjente checkout-rotkataloger med alle tilgjengelige strategier. Registrer en egendefinert
strategi gjennom en [plugins worktree-transformasjon](/build/plugins#worktrees).

## Strøm hendelser

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Send inn et `AbortSignal` gjennom de genererte forespørselsalternativene, eller avslutt
en iterasjon for å avbryte svarteksten.

## Tilpass

Tilpass OpenCode-instansen din ved å registrere plugins. Send plugins til
`OpenCode.create()` for å tilpasse agenter, modeller, verktøy og annen oppførsel
når den innebygde verten starter:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Kall `await opencode.plugin(plugin)` for å registrere enda en plugin etter oppstart.

Se den [fullstendige plugin-dokumentasjonen](/build/plugins) for plugin-hooks,
transformasjoner, verktøy og hele plugin-konteksten.
