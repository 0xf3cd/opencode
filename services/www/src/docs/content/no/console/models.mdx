OpenCode Console tilbyr en liste over modeller som er testet og verifisert av OpenCode-teamet. Logg inn, fyll på kreditt
og hent en API-nøkkel for å bruke dem med OpenCode eller en annen kodeagent.

Console fungerer som alle andre leverandører i OpenCode. Den er **helt valgfri**, og du kan bruke en hvilken som helst
annen leverandør i stedet. Vil du ha et abonnement med inkludert bruk, kan du se [OpenCode Go](/console/go).

## Slik fungerer det

1. Logg inn på [Console](https://opencode.ai/console), legg inn faktureringsopplysninger og kreditt, og kopier
   API-nøkkelen din.
2. Kjør `/connect` i TUI-en, velg OpenCode-leverandøren med betaling etter bruk, og lim inn API-nøkkelen.

   ```text
   /connect
   ```

3. Kjør `/models` for å se de tilgjengelige modellene og velge én.

   ```text
   /models
   ```

Du belastes per forespørsel og kan fylle på kreditt på kontoen din.

### Jev

Jev er en System One-modell fra TypeSafe AI for raske, strukturerte beslutninger. I stedet for å generere tekst vurderer den en `state` opp mot typede spørsmål og returnerer verdier og sannsynligheter som koden din kan bruke direkte. Den støtter ja/nei-spørsmål (`noul`), flervalgsspørsmål (`choice`) og spørsmål basert på vurderingskriterier (`score`).

Bruk API-nøkkelen din fra OpenCode Console med endepunktet `https://opencode.ai/inference/v1/systemone`. Dette eksemplet sjekker om en supporthenvendelse haster:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Du kan stille flere spørsmål i én forespørsel. Jev vurderer dem parallelt og returnerer hvert svar under den tilsvarende spørsmåls-ID-en:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Bruk `jev-1.13-free` i stedet for `jev-1.13` for å bruke gratismodellen, som er tilgjengelig i en begrenset periode. Se [dokumentasjonen til TypeSafe AI](https://docs.typesafe.ai/) for detaljer om spørsmålstyper og svarfelt.

## Bakgrunn

Det finnes mange modeller, men bare noen få fungerer godt som kodeagenter. Leverandører varierer også i konfigurasjon,
ytelse og kvalitet, så en modell du bruker gjennom en gateway som OpenRouter, kan oppføre seg annerledes.

<Callout type="tip">Vi har testet et utvalg modeller og leverandører som fungerer godt med OpenCode.</Callout>

For å bygge denne katalogen har vi:

1. Testet et utvalg modeller og snakket med teamene bak dem om hvordan de best kjøres.
2. Samarbeidet med leverandører for å sikre at modellene leveres riktig.
3. Benchmarket hver kombinasjon av modell og leverandør for å lage en liste vi trygt kan anbefale.

Console er en AI-gateway som gir deg tilgang til disse modellene.

## Mål

Vi bygde Console for å:

1. **Benchmarke** de beste modellene og leverandørene for kodeagenter.
2. Tilby alternativer av **høyeste kvalitet** uten å svekke ytelsen eller rute til billigere leverandører.
3. Gi videre **prisfall** ved å selge til kostpris, med påslag bare for å dekke behandlingsgebyrer.
4. Unngå **innlåsing**: bruk Console med en hvilken som helst kodeagent, eller bruk en annen leverandør med OpenCode.
