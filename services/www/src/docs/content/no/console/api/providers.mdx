---
title: "Leverandør-API"
description: "Kall leverandørene som er koblet til arbeidsområdet, gjennom Console-gatewayen med en Console-nøkkel."
---

Hver [leverandør](/console/providers) som er koblet til arbeidsområdet, leveres gjennom Console-gatewayen på sin egen
URL. OpenCode bruker den automatisk etter `/connect`; kall den direkte for å bruke de samme leverandørene fra dine egne
verktøy. Console legger til legitimasjonen for leverandøren før forespørselen videresendes, så leverandørhemmeligheten
forlater aldri arbeidsområdet.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## Leverandør-URL

Kopier **Console API URL** fra siden til leverandøren under **Providers**.

```text
https://opencode.ai/inference/custom/<connection_id>
```

## Autentisering

Erstatt `<token>` med en [nøkkel for en tjenestekonto](/console/api#service-accounts) som er opprettet i Console. Console
bytter den ut med legitimasjonen for tilkoblingen før forespørselen videresendes.

```text
Authorization: Bearer <token>
```

Console leser også nøkkelen fra `x-api-key`, `api-key` eller `x-goog-api-key`, så leverandørenes SDK-er fungerer når de
pekes mot Console API URL.

## Endepunkter

Legg til API-stien til leverandøren etter Console API URL. Console videresender forespørselen til base-URL-en for
tilkoblingen og returnerer svaret fra leverandøren uendret.

| Format               | Sti                               |
| -------------------- | --------------------------------- |
| Chat Completions     | `/chat/completions`               |
| Responses API        | `/responses`                      |
| Anthropic Compatible | `/messages`                       |
| Google Generative AI | `/models/<model>:generateContent` |

Send modell-ID-en slik den vises på leverandørsiden. Når en modell har en annen API-ID hos leverandøren, skriver Console
den om. Forespørsler til modeller som ikke er aktivert på tilkoblingen, avvises.

### Chat Completions

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Responses API

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Say hi"
  }'
```

### Anthropic Compatible

`max_tokens` er påkrevd.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Google Generative AI

Modellen og metoden er en del av stien. Erstatt `:generateContent` med `:streamGenerateContent` for å strømme svaret.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```

## Bruk

Forespørsler teller mot [budsjetter](/console/budgets) ut fra prisene som er satt for hver modell. Leverandøren
fakturerer deg for tokenene.
