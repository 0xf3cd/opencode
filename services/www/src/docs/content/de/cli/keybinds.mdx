title: "Tastenkürzel"

Passe die Tastenbelegungen in der `cli.json` an:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Für eine einzelne Taste verwendest du einen String:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Alternativen trennst du mit Kommas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Mit `"none"` oder `false` deaktivierst du eine Belegung:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Für das Verhalten bei Tastenereignissen verwendest du ein Objekt:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` ist standardmäßig `ctrl+x`. `<leader>` in einer anderen Belegung verweist auf diese Taste.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Unbekannte Befehls-IDs werden abgelehnt.

## Mini

Der Befehl `app.clear` funktioniert nur in [`opencode mini`](/cli). Drücke `ctrl+l`, um den sichtbaren Bildschirm zu leeren und den Prompt neu zu zeichnen. Der Scrollback-Puffer des Terminals bleibt erhalten.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Standard | Beschreibung      |
| ----------- | -------- | ----------------- |
| `app.clear` | `ctrl+l` | Bildschirm leeren |

## Diff-Ansicht

Drücke `d` (`diff.switch_source`), um **All**, **Committed**, **Uncommitted** oder (innerhalb einer Sitzung) **Last turn** zu wählen, oder wähle **Base**, um den Vergleichs-Branch zu ändern. Die Auswahl bleibt erhalten, bis die TUI beendet wird. Den anfänglichen Umfang legst du mit [`diffs.source` in der `cli.json`](/cli/config#diffs) fest.

Tastenkürzel zum Scrollen, Blättern und Springen an Anfang oder Ende steuern immer den Diff. Einen Wechsel des Tastaturfokus gibt es nicht: Klicke auf Dateien, um sie zu öffnen, klicke auf Ordner, um sie auf- oder zuzuklappen, und scrolle den Dateibaum mit dem Mausrad.

Mit `n` / `p` oder `alt+down` / `alt+up` (Option unter macOS) wechselst du zwischen Dateien. In der Diff-Ansicht navigieren die Alt-Tastenkürzel zwischen Dateien statt zwischen Sitzungs-Tabs.

Drücke `m`, um eine Datei als geprüft zu markieren und ihren Patch einzuklappen. In der Ansicht aller Dateien hebst du die Markierung mit einem weiteren `m` auf und öffnest den Patch wieder. In der Einzeldateiansicht springt OpenCode beim Markieren automatisch zur nächsten Datei, bleibt aber bei der letzten Datei stehen, statt wieder von vorn zu beginnen. Beim Aufheben der Markierung wird nie weitergesprungen.

Klicke mit der rechten Maustaste auf eine Datei in der Seitenleiste oder auf ihre Diff-Überschrift, um **Mark complete** (bzw. **Mark incomplete**) zu wählen. Das ändert denselben Geprüft-Status wie `m`. Wenn du eine andere Datei über ihr Menü als erledigt markierst, wird sie weder ausgewählt, noch springt die gerade gelesene Datei weiter.

Die Shift-Varianten von `diff.help` unterstützen Terminals, die beim Drücken von `?` den Shift-Modifier mitmelden.

| `composer.shell.select`       | `return` | Shell-Ausgabe anzeigen  |

Wähle im Tab **Shell** einen laufenden Befehl aus und drücke **Enter** oder klicke ihn an, um die erfasste Ausgabe von stdout und stderr anzuzeigen.
Mit **↑/↓**, **Page Up/Down** oder **Home** scrollst du, mit **End** folgst du neuer Ausgabe, und mit **Esc** kehrst du zurück, ohne den Befehl zu beenden.
Die Ansicht zeigt die neueste Ausgabe und bleibt nach dem Beenden des Befehls geöffnet; in eine Datei umgeleitete Ausgabe ist nicht enthalten.
