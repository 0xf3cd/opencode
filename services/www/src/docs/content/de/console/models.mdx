Die OpenCode Console bietet eine Liste von Modellen, die das OpenCode-Team getestet und geprüft hat. Melde dich an,
lade Guthaben auf und hol dir einen API-Schlüssel, um sie mit OpenCode oder einem anderen Coding-Agent zu nutzen.

Die Console funktioniert in OpenCode wie jeder andere Anbieter. Sie ist **völlig optional**, und du kannst stattdessen
jeden anderen Anbieter verwenden. Ein Abonnement mit inkludierter Nutzung findest du unter [OpenCode Go](/console/go).

## So funktioniert es

1. Melde dich bei der [Console](https://opencode.ai/console) an, hinterlege deine Rechnungsdaten und Guthaben und kopiere deinen API-Schlüssel.
2. Führe in der TUI `/connect` aus, wähle den nutzungsbasierten OpenCode-Anbieter und füge deinen API-Schlüssel ein.

   ```text
   /connect
   ```

3. Führe `/models` aus, um die verfügbaren Modelle anzuzeigen, und wähle eines aus.

   ```text
   /models
   ```

Abgerechnet wird pro Anfrage; Guthaben kannst du deinem Konto selbst hinzufügen.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode/gpt-5.5",
}
```

Die vollständige Liste der verfügbaren Modelle samt Metadaten liefert der Endpunkt für Modelle:

```bash
curl https://opencode.ai/inference/v1/models
```

### Jev

Jev ist ein System-One-Modell von TypeSafe AI für schnelle, strukturierte Entscheidungen. Statt Text zu generieren, bewertet es einen `state` anhand typisierter Fragen und liefert Werte und Wahrscheinlichkeiten, die dein Code direkt verwenden kann. Es unterstützt Ja/Nein-Fragen (`noul`), Multiple-Choice-Fragen (`choice`) und Fragen mit Bewertungsraster (`score`).

Verwende deinen API-Schlüssel der OpenCode Console mit dem Endpunkt `https://opencode.ai/inference/v1/systemone`. Dieses Beispiel prüft, ob eine Supportanfrage dringend ist:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Du kannst mehrere Fragen in einer Anfrage stellen. Jev wertet sie parallel aus und liefert jede Antwort unter der passenden Frage-ID zurück:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Verwende `jev-1.13-free` statt `jev-1.13`, um das zeitlich begrenzt kostenlose Modell zu nutzen. Details zu Fragetypen und Antwortfeldern findest du in der [Dokumentation von TypeSafe AI](https://docs.typesafe.ai/).

## Hintergrund

Es gibt viele Modelle, aber nur wenige eignen sich gut als Coding-Agent. Anbieter unterscheiden sich zudem in
Konfiguration, Leistung und Qualität. Ein Modell, das du über ein Gateway wie OpenRouter nutzt, kann sich daher anders
verhalten.

<Callout type="tip">Wir haben eine ausgewählte Gruppe von Modellen und Anbietern getestet, die gut mit OpenCode funktionieren.</Callout>

Für diesen Katalog haben wir:

1. Eine ausgewählte Gruppe von Modellen getestet und mit ihren Teams besprochen, wie man sie am besten betreibt.
2. Mit Anbietern zusammengearbeitet, um sicherzustellen, dass die Modelle korrekt bereitgestellt werden.
3. Jede Kombination aus Modell und Anbieter einem Benchmark unterzogen, um eine Liste zu erstellen, die wir guten Gewissens empfehlen können.

Die Console ist ein KI-Gateway, das dir Zugriff auf diese Modelle gibt.

## Ziele

Wir haben die Console entwickelt, um:

1. Die besten Modelle und Anbieter für Coding-Agenten per **Benchmark** zu ermitteln.
2. Optionen in **höchster Qualität** anzubieten, ohne die Leistung zu drosseln oder an günstigere Anbieter weiterzuleiten.
3. **Preissenkungen** weiterzugeben, indem wir zum Selbstkostenpreis verkaufen – mit einem Aufschlag nur zur Deckung der Bearbeitungsgebühren.
4. **Keinen Lock-in** zu erzeugen: Nutze die Console mit jedem Coding-Agent oder einen anderen Anbieter mit OpenCode.
