---
title: "Websuche"
description: "Gehostete Websuche für OpenCode über die Console."
---

Die Console stellt verbundenen Nutzern von OpenCode v2 eine gehostete Websuche bereit. Ein Owner oder Admin des Workspace aktiviert sie einmalig für den gesamten Workspace, ohne dass Mitglieder einen eigenen Schlüssel für einen Suchanbieter brauchen.

Jede erfolgreiche Suche kostet **$0.01** und wird auf das Guthaben des Workspace sowie auf die Ausgabenlimits der Mitglieder angerechnet.

## Aktivieren

1. Melde dich als Owner oder Admin des Workspace bei der [Console](https://opencode.ai/console) an.
2. Öffne **Settings** > **General**.
3. Aktiviere **Hosted web search**.

Anschließend verbindet jedes Mitglied OpenCode mit `/connect` mit dem Workspace.

```text
/connect
```

OpenCode lädt **OpenCode Web Search** aus der verwalteten Konfiguration des Workspace. Mitglieder müssen weder `websearch.provider` setzen noch einen API-Schlüssel für einen Anbieter hinterlegen.

## Suchen

Frag OpenCode in einem Prompt nach aktuellen Informationen. Die Suche läuft in OpenCode, nicht auf einer interaktiven Seite in der Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

Der gehostete Anbieter durchsucht das öffentliche Web und liefert bis zu acht Ergebnisse. OpenCode beantwortet den Prompt anhand dieser Ergebnisse und nennt die Quellen.

Wie du Berechtigungen konfigurierst oder das Tool deaktivierst, erfährst du in der [Anleitung zur Websuche](/websearch).

## Abrechnung

Die Console berechnet **$0.01**, sobald eine Suche einen gültigen Ergebnissatz liefert. Fehlgeschlagene und durch ein Rate-Limit abgewiesene Suchen werden nicht berechnet.

Die Websuche wird in **Usage**, **My Activity**, der Mitgliederaktivität, in Rechnungen und CSV-Exporten getrennt von der Modellnutzung ausgewiesen. Die monatlichen Ausgabenlimits für Workspace und Mitglieder schließen die Kosten der Websuche ein.

## Datenschutz

Die gehostete Websuche speichert keinerlei Daten. Die Console und ihr gehosteter Suchanbieter verarbeiten jede Anfrage und deren Ergebnisse, ohne die Inhalte zu speichern.
