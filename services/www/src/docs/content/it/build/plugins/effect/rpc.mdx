---
title: "RPC"
---

I plugin Effect possono esporre metodi ed eventi che restituiscono Effect e Stream tipizzati.

## Definizione

Usa `Rpc.define` con Effect Schema per definire l'RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Validazione

Effect Schema convalida i valori e ne deduce i tipi TypeScript.

```ts
input: Schema.Struct({ query: Schema.String })
```

Sono supportati anche JSON Schema e Standard Schema.

### Input e output

Usa `input` per l'argomento del metodo e `output` per il valore restituito. Puoi ometterli singolarmente quando non c'è alcun valore.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Errori

Aggiungi gli errori previsti in `errors`. Ogni chiave diventa il `type` dell'errore.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Eventi

Aggiungi gli eventi alla mappa `events` di primo livello. I dati di un evento devono essere un oggetto.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Implementazione

Registra l'implementazione dall'Effect del plugin:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

La mappa degli errori diventa il tipo di errore dell'Effect di ciascun metodo. Usa `context.error(...)` per creare un
errore dichiarato.

## Chiamata

Una volta registrato, l'RPC può essere chiamato tramite HTTP o da un altro plugin.

### HTTP

Crea il client Effect, quindi crea il subclient RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Plugin

Un altro plugin Effect può creare un subclient locale dal proprio contesto:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Sottoscrizione

Gli eventi RPC sono Stream. Sottoscriviti tramite il nome dell'evento ed esegui lo Stream in un fiber con scope:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Le sottoscrizioni ricevono solo eventi in tempo reale e si chiudono quando termina il consumo dello Stream.
