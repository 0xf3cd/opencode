`@opencode/sdk` ospita OpenCode direttamente all'interno della tua applicazione. A differenza del
[client di rete](/build/client), assembla il server OpenCode e instrada le chiamate API attraverso il suo router HTTP in
memoria. Non apre alcun listener HTTP e non aggiunge passaggi di rete tra client e server.

Per i Durable Object di Cloudflare, consulta la [guida per Cloudflare](/build/sdk/cloudflare).

Installa l'SDK:

```sh
bun add @opencode/sdk
```

## Creare un host

`OpenCode.create()` restituisce un host di cui sei esplicitamente proprietario. Usa `await using` per rilasciarne il
router, i servizi Location, i fiber e le registrazioni con scope dei plugin:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Se la gestione esplicita delle risorse non è disponibile, chiama direttamente `await opencode.close()`.

L'host integrato usa gli stessi valori Promise, errori dichiarati, opzioni delle richieste e stream `AsyncIterable` di
`@opencode/client`. Espone il client generato completo e aggiunge gli alias di comodo `sessions` ed `events` per i gruppi
delle sessioni e degli eventi.

## Worktree

Le operazioni sui worktree richiedono un `projectID`. La creazione e l'aggiornamento caricano configurazione e plugin dal
checkout canonico salvato del progetto. L'elenco legge solo l'inventario salvato; la rimozione attiva i plugin canonici e
usa la strategia registrata, fallendo se quella strategia non è disponibile.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

L'aggiornamento rileva i worktree in tutte le radici di checkout note usando tutte le strategie disponibili. Registra una
strategia personalizzata tramite la [trasformazione dei worktree di un plugin](/build/plugins#worktrees).

## Stream di eventi

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Passa un `AbortSignal` tramite le opzioni della richiesta generate, oppure esci dall'iterazione per annullarne il body
della risposta.

## Personalizzazione

Personalizza la tua istanza di OpenCode registrando plugin. Passa i plugin a `OpenCode.create()` per personalizzare
agenti, modelli, strumenti e altri comportamenti all'avvio dell'host integrato:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Chiama `await opencode.plugin(plugin)` per registrare un altro plugin dopo l'avvio.

Consulta la [documentazione completa sui plugin](/build/plugins) per hook, trasformazioni, strumenti e contesto completo
dei plugin.
