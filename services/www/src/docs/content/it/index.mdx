OpenCode è un agente di programmazione AI open source, disponibile come interfaccia da terminale, app desktop o app web.

Il pacchetto npm usa uno script postinstall per selezionare il binario nativo `opencode` adatto alla tua piattaforma. I
comandi per Bun e pnpm consentono esplicitamente lo script necessario; con Vite+ non serve alcun flag aggiuntivo. Il comando mise richiede mise 2026.10.9 o successivo; le versioni precedenti installano OpenCode 1.

I gestori di pacchetti per Windows non sono supportati.


Scarica il binario standalone della CLI per la tua piattaforma.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

Accedi all'interfaccia web di OpenCode con il comando `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Le immagini Docker usano tag con versione, ad esempio `ghcr.io/anomalyco/opencode:2.0.0`.

## Connessione

OpenCode supporta in modo nativo molti provider LLM: puoi collegarti direttamente
[dalla TUI](/cli/providers) con `/connect`.

Per configurare provider personalizzati, consulta [Provider](/providers).

Se vuoi accedere facilmente ai migliori modelli per la programmazione, prova
[OpenCode Console](/console).

Puoi anche provare [OpenCode Go](/console/go), un abbonamento da $10/mese che ti dà
accesso ai migliori modelli open source.

---

## Personalizzazione

Adatta OpenCode alle tue esigenze modificando la [configurazione di OpenCode](/config), [caricando plugin](/plugins),
[collegando server MCP](/mcp-servers) o [creando comandi](/commands). Per i temi e le scorciatoie da tastiera
dell'interfaccia da terminale, consulta [Impostazioni della CLI](/cli/config).
