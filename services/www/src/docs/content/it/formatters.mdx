---
title: "Formatter"
---

OpenCode può formattare i file dopo che gli strumenti `write`, `edit` o `patch` li hanno
modificati. I formatter sono disabilitati per impostazione predefinita, quindi abilitali nella
configurazione:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

## Abilitazione

Imposta `formatter` su `true` per abilitare tutti i formatter integrati. OpenCode esegue un
formatter integrato solo se il relativo eseguibile e gli eventuali requisiti specifici del
progetto sono disponibili.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

Anche un oggetto abilita i formatter integrati e ti permette di sovrascriverli o di aggiungere
formatter personalizzati. Un oggetto vuoto conserva le impostazioni dei formatter ereditate,
mentre `true` le reimposta sui formatter integrati.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {},
}
```

## Formatter integrati

indicato sia disponibile; le definizioni con regole di rilevamento aggiuntive le riportano qui sotto.

Ad esempio, abilitando i formatter integrati OpenCode può individuare ed eseguire la dipendenza
Prettier locale del progetto per i file corrispondenti:

```jsonc title="opencode.jsonc"
{
  "formatter": true,
}
```

## Personalizzazione

Aggiungi una voce con nome per modificare un formatter integrato o definirne uno personalizzato.
Per essere eseguito, un formatter personalizzato richiede sia `command` sia `extensions`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "environment": {
        "NODE_ENV": "development",
      },
      "extensions": [".js", ".ts"],
    },
    "deno-markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

| Campo | Tipo | Comportamento |
| --- | --- | --- |
| `disabled` | `boolean` | Se `true`, rimuove il formatter indicato. |
| `command` | `string[]` | Sostituisce il comando integrato o definisce un comando personalizzato. |
| `environment` | `Record<string, string>` | Aggiunge variabili d'ambiente mantenendo l'ambiente del processo padre. |
| `extensions` | `string[]` | Sostituisce l'elenco di estensioni integrato o definisce quello personalizzato. Includi il punto iniziale. |

Tutti i campi sono facoltativi. Una voce integrata eredita i valori omessi, mentre una nuova voce
senza comando o senza estensioni non può essere eseguita.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "extensions": [".md", ".mdx"],
    },
  },
}
```

## Comandi

`command` è un array di argomenti, non una stringa di comando della shell. OpenCode sostituisce
`$FILE` con il percorso assoluto del file ed esegue il comando dalla directory del progetto attivo.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "custom": {
      "command": ["custom-fmt", "--write", "$FILE"],
      "extensions": [".custom"],
    },
  },
}
```

## Corrispondenza

OpenCode confronta l'estensione finale del file con `extensions`. Il confronto distingue tra
maiuscole e minuscole, e le voci composte come `.part.md` non corrispondono a `notes.part.md`,
perché la sua estensione finale è `.md`.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

Quando più formatter corrispondono, OpenCode li prova nell'ordine di registrazione e si ferma al
primo comando eseguito con successo. I formatter integrati mantengono il proprio ordine; le voci
personalizzate seguono nell'ordine dell'oggetto. Se un formatter termina con un errore, OpenCode
registra l'errore nei log e prova la corrispondenza successiva.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "preferred": {
      "command": ["preferred-fmt", "$FILE"],
      "extensions": [".foo"],
    },
    "fallback": {
      "command": ["fallback-fmt", "$FILE"],
      "extensions": [".foo"],
    },
  },
}
```

## Disattivazione

La formattazione è disabilitata quando nessun file di configurazione imposta `formatter`. Per
disabilitare la formattazione abilitata da un file con priorità inferiore, impostalo su `false`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false,
}
```

Per disabilitare un singolo formatter integrato lasciando abilitati gli altri, contrassegna come
disabilitata la relativa voce.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "disabled": true,
    },
  },
}
```
