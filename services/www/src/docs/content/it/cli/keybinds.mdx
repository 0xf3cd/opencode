---
title: "Scorciatoie"
---

Personalizza le scorciatoie in `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Usa una stringa per un singolo tasto:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separa le alternative con le virgole:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Disabilita una scorciatoia con `"none"` o `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Usa un oggetto per controllare il comportamento dell'evento:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

Il valore predefinito di `leader` è `ctrl+x`. `<leader>` in un'altra scorciatoia fa riferimento a quel tasto.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Gli ID di comando sconosciuti vengono rifiutati.

## Mini

Il comando `app.clear` funziona solo in [`opencode mini`](/cli). Premi `ctrl+l` per pulire lo schermo visibile e ridisegnare il prompt. Il terminale conserva la cronologia di scorrimento (scrollback).

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID | Predefinito | Descrizione |
| --- | --- | --- |

## Visualizzatore dei diff

Premi `d` (`diff.switch_source`) per scegliere **All**, **Committed**, **Uncommitted** o **Last turn** (all'interno di una sessione), oppure seleziona **Base** per cambiare il branch di confronto. Le scelte vengono ricordate fino alla chiusura della TUI. Imposta l'ambito iniziale con [`diffs.source` in `cli.json`](/cli/config#diffs).

Lo scorrimento, lo scorrimento per pagine e le scorciatoie per inizio e fine controllano sempre il diff. Non esiste un cambio di focus da tastiera: fai clic sui file per aprirli, sulle cartelle per espanderle o comprimerle e usa la rotellina del mouse per scorrere l'albero dei file.

Usa `n` / `p` oppure `alt+down` / `alt+up` (Option su macOS) per spostarti tra i file. All'interno del visualizzatore dei diff, le scorciatoie con Alt navigano tra i file anziché tra le schede delle sessioni.

Premi `m` per contrassegnare un file come revisionato e comprimere il corpo della sua patch. Nella vista con tutti i file, premi di nuovo `m` per rimuovere il contrassegno e riaprire la patch. Nella vista a file singolo, quando contrassegni un file come revisionato si passa automaticamente al file successivo, ma sull'ultimo file la vista resta ferma invece di ricominciare dall'inizio. Rimuovere il contrassegno non fa mai avanzare.

Fai clic con il pulsante destro su un file nella barra laterale o sull'intestazione del suo diff per scegliere **Mark complete** (o **Mark incomplete**). L'opzione modifica lo stesso stato di revisione di `m`. Completare un altro file dal suo menu non lo seleziona e non fa avanzare il file che stai leggendo.

Le alternative con Shift di `diff.help` servono per i terminali che segnalano il modificatore Shift quando premi `?`.
