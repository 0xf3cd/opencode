title: "TUI"
description: "Avvia una sessione e usa i flussi di lavoro quotidiani nell'interfaccia da terminale."
---

Esegui OpenCode dal tuo progetto, scrivi una richiesta e premi **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Premi **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** o **Ctrl+J** per andare a capo. Mentre OpenCode è al lavoro, **Enter** invia il prompt alla sessione attiva per orientarne il lavoro in corso; premi **Ctrl+X** e poi **Enter** per mettere il prompt in coda e inviarlo più tardi.

## Contesto

Digita `@` per cercare un file, poi selezionalo per allegarlo al prompt. Continua a digitare dopo `@` per restringere i risultati.

```text
Review @src/auth.ts for error handling problems
```

Dopo il percorso puoi indicare una riga o un intervallo di righe.

```text
Explain @src/auth.ts#20-45
```

## Shell

Digita `!` all'inizio di un prompt vuoto per entrare nella modalità shell. Inserisci un comando e premi **Enter**; premi **Esc** per uscire dalla modalità shell senza eseguire nulla.

```text
!git status
```

I comandi della shell vengono eseguiti nella directory di lavoro della sessione e il loro output resta nella sessione.

## Comandi

Digita `/` per elencare i comandi slash. Continua a digitare per filtrare l'elenco, poi premi **Enter** per eseguire il comando selezionato.

```text
/models
```

Tra i comandi più comuni ci sono `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` ed `/editor`. Premi **Ctrl+P** per aprire la palette dei comandi con tutte le azioni disponibili nella vista corrente.

Dopo un aggiornamento, OpenCode mostra una sola volta, nella schermata iniziale, le novità della release. Esegui `/highlights` per rivederle oppure imposta `"highlights": false` in [`cli.json`](/cli/config#alerts) per evitare che si aprano automaticamente.

## Domande a margine

Esegui `/btw <question>` per fare una domanda veloce sulla conversazione fin qui. La risposta usa il contesto della sessione e il modello corrente, ma non viene aggiunta alla conversazione, quindi non influisce sui prompt successivi. Durante l'esecuzione, nel piè di pagina del prompt compare l'indicatore `/btw`, e la risposta si apre in una finestra di dialogo; premi **C** per copiarla.

```text
/btw why did the test in step 2 fail?
```

## Modelli

Premi **Ctrl+X** e poi **M** per scegliere un modello, oppure esegui `/models`. Premi **F2** per scorrere i modelli usati di recente.

Premi **Ctrl+X** e poi **A** per scegliere un agente, oppure esegui `/agents`. Premi **Shift+Tab** per scorrere gli agenti.

## Sessioni

Premi **Ctrl+X** e poi **N** per iniziare una nuova sessione. Premi **Ctrl+X** e poi **L**, oppure esegui `/sessions`, per tornare a una sessione esistente; **Ctrl+O** apre insieme le sessioni e i progetti recenti.

Le schede sono abilitate per impostazione predefinita. Usa **Ctrl+Tab** e **Ctrl+Shift+Tab** per spostarti tra le schede, **Ctrl+X** e poi **W** per chiuderne una e **Ctrl+Shift+T** per riaprire l'ultima scheda chiusa.

## Cronologia

Premi **Ctrl+X** e poi **U**, oppure esegui `/undo`, per annullare l'ultimo messaggio dell'utente e il lavoro che ne è seguito. Il prompt annullato torna nel compositore, così puoi modificarlo.

Premi **Ctrl+X** e poi **R**, oppure esegui `/redo`, per ripristinare il lavoro annullato. Se invece invii un nuovo prompt, l'annullamento diventa definitivo e la sessione prosegue da quel punto.

## Editor

Imposta `VISUAL` o `EDITOR`, poi premi **Ctrl+X** e quindi **E**, oppure esegui `/editor`, per modificare il prompt corrente in quell'editor. Salva ed esci per riportare il testo nel compositore, poi premi **Enter** per inviarlo.

```bash
export EDITOR="nvim"
opencode
```

Il tasto leader predefinito è **Ctrl+X**. Consulta [Scorciatoie](/cli/keybinds) per modificare queste scorciatoie.
