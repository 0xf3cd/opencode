title: "Web"
description: "Esegui OpenCode nel browser."
---

OpenCode include un'interfaccia web servita dallo stesso server che alimenta la
TUI. È disponibile per impostazione predefinita ed è protetta da password.

## Accesso

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

  █▀▀▀▀▀█ ...
```

Aprendo un link nel browser, l'accesso avviene tramite un cookie di sessione e si carica l'interfaccia web. Allo stesso
modo puoi collegare l'app OpenCode scansionando il codice QR dall'app oppure incollando il link nel suo campo per
l'indirizzo del server. Le sessioni durano 30 giorni; cambiare la password del server disconnette tutte le sessioni.

### Tramite SSH

Se il server è in ascolto solo su localhost, inoltra la sua porta dalla tua macchina e apri localmente il link
stampato:

```bash
$ ssh -L 49374:127.0.0.1:49374 my-server
```

Per impostazione predefinita il server usa la porta 49374 ed è in ascolto solo su localhost. Puoi modificare questa
configurazione con il comando `opencode service`.

### Accesso remoto

Per collegarti da qualsiasi luogo, esegui l'abbinamento tramite un indirizzo remoto
[OpenTunnel](https://github.com/anomalyco/opentunnel):

```bash
$ opencode pair --remote
```

La prima volta che attiva l'accesso remoto, il comando chiede conferma prima di procedere:

```text
▲  This will expose your OpenCode server to the internet.
│  Traffic is end-to-end encrypted, and access requires your server password.
│  To pair locally instead, run `opencode pair` without the --remote flag.
│
◆  Expose your server to the internet?
│  ● Yes / ○ No
```

Senza un terminale interattivo il comando non riesce, a meno che tu non passi `--yes` per accettare. Una volta
accettato, le esecuzioni successive saltano la domanda, anche se nel frattempo l'accesso remoto è stato disattivato con
`opencode service set remote false`.

## Configurazione

Imposta qualsiasi opzione con `opencode service set`:

```bash
# Listen on every network interface
$ opencode service set hostname 0.0.0.0

# Use a fixed port instead of the channel default
$ opencode service set port 49374

# Replace the generated password
$ opencode service set password "a-long-secret"

# Allow a web client served from another origin
$ opencode service set cors https://app.example.com,https://other.example.com

# Pass an environment variable to the server process
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

La modifica di un'impostazione arresta il server in background. Per applicare la nuova configurazione, esegui:

```bash
$ opencode service start
```

## Standalone

`opencode serve` esegue lo stesso server in primo piano anziché tramite il servizio in background condiviso.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
server listening on http://0.0.0.0:4096
server password <password>
```

Usalo quando vuoi:

- Eseguire OpenCode su un host condiviso, sempre attivo o remoto, e poi collegare i client con
  `opencode --server <url>`.
- Controllare hostname, porta e origini CORS di un singolo processo.
- Eseguirlo sotto un supervisore come systemd, Docker o un altro ambiente che si aspetta un processo in primo piano.
- Mantenere un server dedicato al posto del servizio in background condiviso.

Collega un client con `--server`:

```bash
$ opencode --server http://127.0.0.1:4096
```
