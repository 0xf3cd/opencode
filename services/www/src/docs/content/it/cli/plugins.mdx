---
title: "Plugin"
---

I plugin configurati in `opencode.json(c)` che espongono un componente TUI vengono caricati automaticamente dalla CLI.
Per sapere come creare plugin, consulta [Creare plugin](/build/plugins). Non è necessario aggiungere lo stesso pacchetto
a `cli.json`. La CLI ottiene l'elenco dei plugin attivi dal server OpenCode a cui è collegata, quindi funziona anche
quando il server è remoto.

Usa `cli.json` per i plugin esclusivi della CLI. Questi plugin vengono eseguiti localmente nel terminale e restano attivi
quando la CLI si collega a un server remoto:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Le voci vengono elaborate in ordine. Anteponi `-` a un ID o a un carattere jolly per disabilitare i plugin
corrispondenti:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Passa le opzioni del plugin usando la forma a oggetto:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode rileva i plugin anche nella directory di configurazione globale e nelle directory `.opencode` dei progetti.
Ogni plugin segue la stessa struttura di un pacchetto pubblicato, con gli entrypoint del server e della TUI tenuti
insieme.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

I plugin rilevati possono importare direttamente `@opencode/plugin/tui`; OpenCode risolve il pacchetto a runtime. Per
alcuni esempi, consulta [Creare plugin per la CLI](/build/plugins/cli).
