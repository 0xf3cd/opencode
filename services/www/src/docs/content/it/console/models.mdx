OpenCode Console offre un elenco di modelli testati e verificati dal team di OpenCode. Accedi, aggiungi credito e ottieni
una chiave API per usarli con OpenCode o con un altro agente di programmazione.

In OpenCode la Console funziona come qualsiasi altro provider. È **del tutto facoltativa** e puoi usare qualsiasi altro
provider al suo posto. Se preferisci un abbonamento con utilizzo incluso, consulta [OpenCode Go](/console/go).

## Come funziona

1. Accedi alla [Console](https://opencode.ai/console), aggiungi i dati di fatturazione e del credito, quindi copia la
   tua chiave API.
2. Esegui `/connect` nella TUI, scegli il provider a consumo di OpenCode e incolla la chiave API.

   ```text
   /connect
   ```

3. Esegui `/models` per vedere i modelli disponibili e selezionarne uno.

   ```text
   /models
   ```

Paghi per ogni richiesta e puoi aggiungere credito al tuo account.

### Jev

Jev è un modello System One di TypeSafe AI pensato per decisioni rapide e strutturate. Invece di generare testo, valuta uno `state` rispetto a domande tipizzate e restituisce valori e probabilità che il tuo codice può usare direttamente. Supporta domande sì/no (`noul`), a scelta multipla (`choice`) e basate su una griglia di valutazione (`score`).

Usa la chiave API di OpenCode Console con l'endpoint `https://opencode.ai/inference/v1/systemone`. Questo esempio verifica se una richiesta di assistenza è urgente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Puoi porre più domande in una sola richiesta. Jev le valuta in parallelo e restituisce ogni risposta sotto l'ID della domanda corrispondente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Usa `jev-1.13-free` al posto di `jev-1.13` per il modello gratuito disponibile per un periodo limitato. Per i dettagli sui tipi di domanda e sui campi della risposta, consulta la [documentazione di TypeSafe AI](https://docs.typesafe.ai/).

## Contesto

Esistono molti modelli, ma solo pochi funzionano bene come agenti di programmazione. Inoltre i provider differiscono per
configurazione, prestazioni e qualità, quindi un modello raggiunto tramite un gateway come OpenRouter può comportarsi in
modo diverso.

<Callout type="tip">Abbiamo testato un gruppo selezionato di modelli e provider che funzionano bene con OpenCode.</Callout>

Per costruire questo catalogo abbiamo:

1. Testato un gruppo selezionato di modelli e parlato con i rispettivi team del modo migliore per eseguirli.
2. Collaborato con i provider per assicurarci che i modelli venissero serviti correttamente.
3. Eseguito benchmark su ogni combinazione modello/provider per ottenere un elenco che ci sentiamo di consigliare.

La Console è un gateway AI che ti dà accesso a questi modelli.

## Obiettivi

Abbiamo creato la Console per:

1. Eseguire **benchmark** sui migliori modelli e provider per gli agenti di programmazione.
2. Offrire le opzioni di **massima qualità**, senza ridurre le prestazioni né instradare le richieste verso provider più
   economici.
3. Trasferire i **ribassi di prezzo** vendendo a prezzo di costo, con un ricarico che copre solo le commissioni di
   elaborazione.
4. Evitare qualsiasi **lock-in**: usa la Console con qualsiasi agente di programmazione, oppure un altro provider con
   OpenCode.
