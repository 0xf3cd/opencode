---
title: "Ricerca web"
description: "Ricerca web ospitata per OpenCode tramite la Console."
---

La Console offre una ricerca web ospitata agli utenti di OpenCode v2 collegati. Un proprietario o un amministratore del workspace la abilita una sola volta per l'intero workspace, senza dover fornire ai membri una chiave separata per un provider di ricerca.

Ogni ricerca riuscita costa **$0.01** e viene conteggiata nel saldo del workspace e nei limiti di spesa dei membri.

## Abilitazione

1. Accedi alla [Console](https://opencode.ai/console) come proprietario o amministratore del workspace.
2. Apri **Settings** > **General**.
3. Attiva **Hosted web search**.

Ogni membro collega poi OpenCode al workspace con `/connect`.

```text
/connect
```

OpenCode carica **OpenCode Web Search** dalla configurazione gestita del workspace. I membri non devono impostare `websearch.provider` né aggiungere la chiave API di un provider.

## Ricerca

Chiedi a OpenCode informazioni aggiornate in un prompt. Le ricerche vengono eseguite da OpenCode e non da una pagina interattiva della Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

Il provider ospitato effettua la ricerca sul web pubblico e restituisce fino a otto risultati. OpenCode li usa per rispondere al prompt e citare le fonti.

Consulta la [guida alla ricerca web](/websearch) per configurare i permessi o disabilitare lo strumento.

## Fatturazione

La Console addebita **$0.01** dopo che una ricerca ha restituito un insieme di risultati valido. Le ricerche non riuscite o bloccate dai limiti di frequenza non vengono addebitate.

La ricerca web compare separatamente dall'utilizzo dei modelli in **Usage**, **My Activity**, nell'attività dei membri, nelle fatture e nelle esportazioni CSV. I limiti di spesa mensili del workspace e dei membri includono gli addebiti per la ricerca web.

## Privacy

La ricerca web ospitata non conserva alcun dato (zero data retention). La Console e il provider di ricerca ospitato elaborano ogni query e i relativi risultati senza memorizzarne il contenuto.
