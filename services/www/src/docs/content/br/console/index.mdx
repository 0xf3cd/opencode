O [OpenCode Console](https://opencode.ai/console) é um serviço opcional que traz benefícios adicionais para quem usa o
OpenCode, sozinho ou em equipe.

- [Workspaces](/console/workspaces) para compartilhar o acesso com a sua [equipe](/console/members)
- [Inferência](/console/models) para modelos proprietários e de código aberto
- [Provedores](/console/providers) para conectar as suas próprias contas de provedores pelo gateway do Console
- Acompanhamento de uso e controle de [orçamento](/console/budgets)
- Políticas para toda a equipe que controlam o comportamento do OpenCode
- [Pesquisa na web](/console/websearch)
- [OpenCode Go e Go Plus](/console/go), assinaturas de $10 e $40 por mês com acesso a modelos de código aberto

## Primeiros passos

Você não precisa de uma equipe para usar o Console. Toda conta começa com um workspace **Personal**, do qual você é o
único membro.

1. Entre no [Console](https://opencode.ai/console).
2. Assine o [Go](/console/go), adicione [créditos](/console/billing#add-credits) ou conecte um [provedor](/console/providers).
3. Execute `/connect` no OpenCode e escolha o workspace.
4. Se quiser, [convide](/console/members#invite-members) a sua equipe.

```text
/connect
```

## Políticas

As regras de Providers e Tools da página Policies valem para todos os clientes do OpenCode V2 conectados ao workspace.
Elas são entregues como declarações de [política](/policies#console), com autoridade final sobre a configuração do
próprio membro, e entram em vigor em cerca de um minuto.
