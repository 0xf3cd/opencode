---
title: "Pesquisa na web"
description: "Pesquisa na web hospedada para o OpenCode pelo Console."
---

O Console oferece pesquisa na web hospedada para usuários do OpenCode v2 conectados. Um proprietário ou administrador do
workspace a ativa uma única vez para o workspace inteiro, sem precisar dar aos membros uma chave separada de um provedor
de pesquisa.

Cada pesquisa bem-sucedida custa **$0.01** e conta para o saldo do workspace e para os limites de gastos dos membros.

## Ativar

1. Entre no [Console](https://opencode.ai/console) como proprietário ou administrador do workspace.
2. Abra **Settings** > **General**.
3. Ative **Hosted web search**.

Depois, cada membro conecta o OpenCode ao workspace com `/connect`.

```text
/connect
```

O OpenCode carrega o **OpenCode Web Search** a partir da configuração gerenciada do workspace. Os membros não precisam
definir `websearch.provider` nem adicionar uma chave de API de provedor.

## Pesquisar

Peça informações atuais ao OpenCode em um prompt. As pesquisas são feitas pelo OpenCode, e não por uma página interativa
no Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

O provedor hospedado pesquisa na web pública e retorna até oito resultados. O OpenCode usa esses resultados para
responder ao prompt e citar as fontes.

Consulte o [guia de pesquisa na web](/websearch) para configurar permissões ou desativar a ferramenta.

## Faturamento

O Console cobra **$0.01** depois que uma pesquisa retorna um conjunto de resultados válido. Pesquisas que falham ou que
atingem o limite de taxa não são cobradas.

A pesquisa na web aparece separada do uso de modelos em **Usage**, **My Activity**, na atividade dos membros, nas faturas
e nas exportações CSV. Os limites mensais de gastos do workspace e dos membros incluem as cobranças de pesquisa na web.

## Privacidade

A pesquisa na web hospedada tem retenção zero de dados. O Console e o provedor de pesquisa hospedado processam cada
consulta e os seus resultados sem armazenar o conteúdo.
