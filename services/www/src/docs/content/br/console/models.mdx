O OpenCode Console oferece uma lista de modelos testados e verificados pela equipe do OpenCode. Entre, adicione créditos e
obtenha uma chave de API para usá-los no OpenCode ou em outro agente de programação.

O Console funciona como qualquer outro provedor no OpenCode. Ele é **totalmente opcional**, e você pode usar qualquer
outro provedor no lugar dele. Para uma assinatura com uso incluído, consulte o [OpenCode Go](/console/go).

## Como funciona

1. Entre no [console](https://opencode.ai/console), adicione seus dados de cobrança e créditos e copie a sua chave de API.
2. Execute `/connect` na TUI, escolha o provedor pré-pago do OpenCode e cole a sua chave de API.

   ```text
   /connect
   ```

3. Execute `/models` para ver os modelos disponíveis e selecionar um.

   ```text
   /models
   ```

A cobrança é feita por requisição, e você pode adicionar créditos à sua conta.

### Jev

O Jev é um modelo System One da TypeSafe AI para decisões rápidas e estruturadas. Em vez de gerar texto, ele avalia um
`state` com base em perguntas tipadas e retorna valores e probabilidades que o seu código pode usar diretamente. Ele
aceita perguntas de sim/não (`noul`), de múltipla escolha (`choice`) e baseadas em rubrica (`score`).

Use a chave de API do OpenCode Console com o endpoint `https://opencode.ai/inference/v1/systemone`. Este exemplo
verifica se uma solicitação de suporte é urgente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Você pode fazer várias perguntas em uma única requisição. O Jev as avalia em paralelo e retorna cada resposta sob o ID
da pergunta correspondente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Use `jev-1.13-free` em vez de `jev-1.13` para usar o modelo gratuito por tempo limitado. Consulte a
[documentação da TypeSafe AI](https://docs.typesafe.ai/) para mais detalhes sobre os tipos de pergunta e os campos da
resposta.

## Contexto

Existem muitos modelos disponíveis, mas só alguns funcionam bem como agentes de programação. Os provedores também variam
em configuração, desempenho e qualidade, então um modelo acessado por um gateway como o OpenRouter pode ter um desempenho
diferente.

<Callout type="tip">Testamos um grupo seleto de modelos e provedores que funcionam bem com o OpenCode.</Callout>

Para montar este catálogo, nós:

1. Testamos um grupo seleto de modelos e conversamos com as equipes deles sobre a melhor forma de executá-los.
2. Trabalhamos com os provedores para garantir que os modelos fossem servidos corretamente.
3. Fizemos benchmarks de cada combinação de modelo e provedor para chegar a uma lista que recomendamos com confiança.

O Console é um gateway de IA que dá acesso a esses modelos.

## Objetivos

Criamos o Console para:

1. Fazer **benchmarks** dos melhores modelos e provedores para agentes de programação.
2. Oferecer as opções de **mais alta qualidade**, sem degradar o desempenho nem rotear para provedores mais baratos.
3. Repassar **reduções de preço** vendendo a preço de custo, com margem apenas para cobrir as taxas de processamento.
4. Não ter **lock-in**: use o Console com qualquer agente de programação ou use outro provedor com o OpenCode.
