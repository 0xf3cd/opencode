title: "Temas"
---

Escolha um tema na interface de terminal pressionando `Ctrl+P`, selecionando **Open settings** e abrindo **Theme**.
Você também pode defini-lo diretamente na configuração global da CLI:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Os temas pertencem ao cliente de terminal. Coloque a seleção de tema no `cli.json`, não no `opencode.json`. Consulte as
[configurações da CLI](/cli/config) para ver o local da configuração e as demais configurações do terminal.

## Modos

Use `system` para acompanhar a aparência do terminal ou fixe o tema em um único modo:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Valor    | Comportamento                                    |
| -------- | ------------------------------------------------ |
| `system` | Acompanha o modo claro ou escuro do terminal.    |
| `dark`   | Sempre usa o tema escuro.                        |
| `light`  | Sempre usa o tema claro.                         |

Se um tema personalizado oferece apenas um modo, o OpenCode usa esse modo quando o outro é solicitado.

## Temas integrados

Selecione um tema integrado pelo nome:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Os temas disponíveis incluem:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

O tema `system` fica disponível quando o OpenCode consegue ler a paleta do terminal.

## Arquivos

Para criar um tema global chamado `ocean`, use a ferramenta de temas para gerar um arquivo completo no diretório global
de temas. A estrutura relevante fica assim:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Depois, selecione `ocean` nas configurações ou defina `theme.name` como `ocean` no `cli.json`. O nome do arquivo, sem
`.json`, é o nome do tema.

| Escopo  | Diretório                                    |
| ------- | -------------------------------------------- |
| Global  | `~/.config/opencode/themes/`                 |
| Projeto | `.opencode/themes/` na árvore do projeto     |

O OpenCode lê apenas arquivos `.json`. Um tema mais próximo do diretório atual substitui um tema global ou de um
diretório pai com o mesmo nome.

## Formato

Todo tema da V2 declara uma árvore de tokens `base` completa e pelo menos uma paleta de matizes `light` ou `dark`. Os
modos herdam apenas do `base` do próprio arquivo; eles não herdam do tema integrado do OpenCode nem um do outro. Use a
ferramenta de temas para gerar um `base` completo antes de personalizá-lo.

Os exemplos abaixo mostram apenas as seções relevantes para cada conceito; eles não são arquivos de tema completos.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Cores

Use uma cor hexadecimal, `transparent` ou uma referência a outra cor do tema:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Valores hexadecimais podem ter 3, 4, 6 ou 8 dígitos. Referências começam com `$`; referências a matizes usam o formato
`$hue.<name>.<step>`.

## Matizes

Sobrescreva um alias de matiz para mudar de uma vez uma família de cores relacionadas:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Tipo    | Valores                                                              |
| ------- | -------------------------------------------------------------------- |
| Base    | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Alias   | `accent`, `interactive`, `neutral`                                   |
| Nível   | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Os níveis de matiz seguem a direção de contraste do modo: nos temas claros, vão do escuro em `100` ao claro em `900`;
nos temas escuros, vão do claro em `100` ao escuro em `900`.

`categorical` define a sequência de matizes usada para distinguir agentes e outros itens repetidos. Ela precisa conter
pelo menos um matiz base ou alias.

## Estados

Use chaves de estado para mudar as cores interativas. Estados não especificados usam o valor base mais próximo:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Grupo     | Valores                                                      |
| --------- | ------------------------------------------------------------ |
| Ações     | `primary`, `secondary`, `destructive`                        |
| Estados   | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Campos de formulário usam as mesmas chaves de estado diretamente em `text.formfield` ou `background.formfield`.

## Tokens

O `base` completo contém todos os grupos de tokens. Um modo pode sobrescrever qualquer parte dele depois de fornecer a
própria paleta de matizes completa:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Grupo        | Finalidade                                                              |
| ------------ | ----------------------------------------------------------------------- |
| `text`       | Texto base, atenuado, de ações, de campos de formulário e de feedback   |
| `background` | Fundo base, superfícies, ações, campos de formulário e feedback         |
| `border`     | Bordas                                                                  |
| `scrollbar`  | Barras de rolagem                                                       |
| `diff`       | Cores de adições, remoções, contexto, destaque e números de linha       |
| `syntax`     | Realce de código-fonte                                                  |
| `markdown`   | Elementos de Markdown                                                   |

As chaves de sintaxe são `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` e
`punctuation`. As chaves de Markdown são `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`,
`strong`, `horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` e `codeBlock`.

## Superfícies elevadas

Painéis, diálogos, menus e notificações (toasts) escolhem a profundidade a partir de `background.raised`. Os diálogos
também aceitam uma superfície contextual `@dialog`. A TUI resolve a paleta de novo depois de aplicar `@dialog`, então
tokens que referenciam `$background.base` acompanham o fundo do diálogo:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` aceita os mesmos grupos de tokens do modo base. O `base` contextual de uma ação também vira o fallback dos
estados não especificados dela; uma sobrescrita explícita de estado continua prevalecendo.
