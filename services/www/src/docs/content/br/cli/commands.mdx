---
title: "Comandos"
description: "Referência da linha de comando do opencode."
---

Todo comando aceita `--help` para exibir a lista completa de flags, por exemplo `opencode run --help`. Alguns comandos
que dependem do servidor aceitam `--standalone` para executar um servidor privado ou `--server <url>` para usar um
servidor específico; consulte a ajuda do comando para ver as flags que ele aceita.

## run

Envia uma mensagem e exibe a resposta sem abrir a interface interativa.

```bash
$ opencode run "Explain this repository"
```

### CI

Em CI, passe a chave de API de um provedor como segredo e use o modo standalone para que o servidor privado a receba.
Por exemplo, este job do GitHub Actions revisa o repositório obtido com o checkout:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Escolha um modelo.

```bash
$ opencode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue a última sessão.

```bash
$ opencode run --continue "Now handle the expired case"
```

Gere JSON delimitado por quebra de linha para scripts.

```bash
$ opencode run --format json "List the TODO comments"
```

Anexe arquivos à mensagem.

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Execute com um agente específico.

```bash
$ opencode run --agent build "Fix the failing test"
```

Veja todos os subcomandos e flags.

```bash
$ opencode run --help
```

## mini

Inicia a interface interativa mínima em vez da TUI em tela cheia.

```bash
$ opencode mini
```

Continue a última sessão.

```bash
$ opencode mini --continue
```

Comece com um modelo e um prompt inicial.

```bash
$ opencode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

Veja todos os subcomandos e flags.

```bash
$ opencode mini --help
```

## session

Gerencia sessões.

```bash
$ opencode session list
```

Limite a lista e exiba em JSON.

```bash
$ opencode session list --max-count 20 --format json
```

Exclua uma sessão e as sessões filhas dela.

```bash
$ opencode session delete ses_9c1b08
```

Exporte os dados da sessão em JSON.

```bash
$ opencode session export ses_4f2a1c
```

Oculte dados sensíveis da transcrição e dos arquivos ao exportar.

```bash
$ opencode session export ses_4f2a1c --sanitize
```

Importe dados de sessão de um arquivo JSON ou de uma URL.

```bash
$ opencode session import session.json
```

Importe para um diretório específico.

```bash
$ opencode session import session.json --directory ~/code/project
```

Veja todos os subcomandos e flags.

```bash
$ opencode session --help
```

## auth

Gerencia provedores de IA e credenciais.

```bash
$ opencode auth list
```

Liste em JSON.

```bash
$ opencode auth list --format json
```

Faça login em um provedor.

```bash
$ opencode auth login anthropic
```

Faça login com um método de autenticação específico.

```bash
$ opencode auth login anthropic --method key
```

Saia de uma conta salva.

```bash
$ opencode auth logout anthropic work
```

Troque a conta ativa de uma integração.

```bash
$ opencode auth switch anthropic work
```

Veja todos os subcomandos e flags.

```bash
$ opencode auth --help
```

## mcp

Gerencia servidores MCP (Model Context Protocol).

```bash
$ opencode mcp list
```

Adicione um servidor remoto.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Adicione um servidor local à configuração global.

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Adicione um servidor local com uma variável de ambiente.

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Adicione um servidor remoto com um cabeçalho.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Autentique-se em um servidor remoto compatível com OAuth.

```bash
$ opencode mcp auth sentry
```

Remova as credenciais OAuth armazenadas de um servidor.

```bash
$ opencode mcp logout sentry
```

Veja todos os subcomandos e flags.

```bash
$ opencode mcp --help
```

## plugin

Gerencia plugins.

```bash
$ opencode plugin list
```

Inclua os plugins de servidor integrados.

```bash
$ opencode plugin list --builtin
```

Instale um plugin e adicione-o à configuração global.

```bash
$ opencode plugin add @example/opencode-tui
```

Verifique se há atualizações para os plugins de pacote.

```bash
$ opencode plugin check
```

Atualize os plugins de pacote.

```bash
$ opencode plugin update
```

Remova um plugin da configuração global.

```bash
$ opencode plugin remove @example/opencode-tui
```

Veja todos os subcomandos e flags.

```bash
$ opencode plugin --help
```

```

```

```bash
$ opencode stats --models
```

Mostre detalhes de custo e de tokens.

```bash
$ opencode stats --cost
```

Exiba JSON em vez de um relatório.

```bash
$ opencode stats --json
```

Veja todos os subcomandos e flags.

```bash
$ opencode stats --help
```

## serve

Inicia o servidor da API e da interface web. Consulte [Web](/cli/web).

```bash
$ opencode serve
```

Escute em todas as interfaces em uma porta fixa.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
```

Permita um cliente de navegador de outra origem.

```bash
$ opencode serve --cors https://app.example.com
```

Veja todos os subcomandos e flags.

```bash
$ opencode serve --help
```

## pair

Exibe links de uso único, junto com um QR code do primeiro deles, que fazem login de um navegador ou app no servidor.
Os links expiram depois de 5 minutos e funcionam uma única vez.

```bash
$ opencode pair
```

Use uma URL externa nos links.

```bash
$ opencode pair --url https://dev.example.com
```

Faça o pareamento de qualquer lugar por um endereço remoto do OpenTunnel. Isso expõe o servidor à internet, então, na
primeira vez que ativa o acesso remoto, o comando explica isso e pede que você aceite. Consulte
[Acesso remoto](/cli/web#remote-access).

```bash
$ opencode pair --remote
```

Aceite sem confirmação, por exemplo em um script sem terminal.

```bash
$ opencode pair --remote --yes
```

Veja todos os subcomandos e flags.

```bash
$ opencode pair --help
```

## service

Gerencia o servidor em segundo plano. Consulte [Web](/cli/web).

```bash
$ opencode service start
```

Reinicie-o.

```bash
$ opencode service restart
```

Mostre o status dele.

```bash
$ opencode service status
```

Pare-o.

```bash
$ opencode service stop
```

Leia uma configuração.

```bash
$ opencode service get hostname
```

Defina uma configuração.

```bash
$ opencode service set hostname 0.0.0.0
```

Permita uma origem CORS adicional.

```bash
$ opencode service set cors https://app.example.com
```

Passe uma variável de ambiente para o processo do servidor.

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Restaure o valor padrão de uma configuração.

```bash
$ opencode service unset hostname
```

Veja todos os subcomandos e flags.

```bash
$ opencode service --help
```

## reload

Recarrega a configuração sem reiniciar o servidor. As sessões em execução continuam com serviços renovados a partir da
próxima etapa.

```bash
$ opencode reload
```

## api

Faz uma requisição ao servidor em execução.

```bash
$ opencode api GET /api/session
```

Chame um ID de operação com um parâmetro de query.

```bash
$ opencode api session.list --param limit=10
```

Envie um corpo JSON.

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

Adicione um cabeçalho à requisição.

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

Veja todos os subcomandos e flags.

```bash
$ opencode api --help
```

## upgrade

Atualiza o OpenCode para a versão mais recente ou para uma versão específica. Alias: `update`.

```bash
$ opencode upgrade
```

Atualize para uma versão específica com um gerenciador de pacotes específico.

```bash
$ opencode upgrade 2.0.21 --method bun
```

Veja todos os subcomandos e flags.

```bash
$ opencode upgrade --help
```

## uninstall

Remove o OpenCode e todos os arquivos relacionados.

```bash
$ opencode uninstall
```

Veja uma prévia do que seria removido.

```bash
$ opencode uninstall --dry-run
```

Veja todos os subcomandos e flags.

```bash
$ opencode uninstall --help
```
