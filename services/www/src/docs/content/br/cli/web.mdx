---
title: "Web"
description: "Execute o OpenCode no navegador."
---

O OpenCode inclui uma interface web servida pelo mesmo servidor que alimenta a TUI. Ela fica disponível por padrão e é
protegida por senha.

## Acesso

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

  █▀▀▀▀▀█ ...
```

Ao abrir um link no navegador, ele faz login com um cookie de sessão e carrega a interface web. Ler o QR code com o app
do OpenCode, ou colar o link no campo de endereço do servidor do app, conecta o app da mesma forma. As sessões duram 30
dias; alterar a senha do servidor desconecta todas as sessões.

### Via SSH

Quando o servidor escuta apenas em localhost, encaminhe a porta dele a partir da sua máquina e abra localmente o link
exibido:

```bash
$ ssh -L 49374:127.0.0.1:49374 my-server
```

Por padrão, o servidor usa a porta 49374 e escuta apenas em localhost. Você pode alterar essa configuração com o comando
`opencode service`.

### Acesso remoto

Para se conectar de qualquer lugar, faça o pareamento por um endereço remoto do
[OpenTunnel](https://github.com/anomalyco/opentunnel):

```bash
$ opencode pair --remote
```

Na primeira vez que ativa o acesso remoto, o comando pede confirmação antes de continuar:

```text
▲  This will expose your OpenCode server to the internet.
│  Traffic is end-to-end encrypted, and access requires your server password.
│  To pair locally instead, run `opencode pair` without the --remote flag.
│
◆  Expose your server to the internet?
│  ● Yes / ○ No
```

Sem um terminal interativo, o comando falha, a menos que você passe `--yes` para aceitar. Depois de aceito, as execuções
seguintes pulam a confirmação, mesmo que o acesso remoto tenha sido desativado com
`opencode service set remote false`.

## Configurar

Defina qualquer opção com `opencode service set`:

```bash
# Listen on every network interface
$ opencode service set hostname 0.0.0.0

# Use a fixed port instead of the channel default
$ opencode service set port 49374

# Replace the generated password
$ opencode service set password "a-long-secret"

# Allow a web client served from another origin
$ opencode service set cors https://app.example.com,https://other.example.com

# Pass an environment variable to the server process
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Alterar uma configuração interrompe o servidor em segundo plano. Para aplicar a nova configuração, execute:

```bash
$ opencode service start
```

## Standalone

`opencode serve` executa o mesmo servidor em primeiro plano, em vez de usar o serviço compartilhado em segundo plano.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
server listening on http://0.0.0.0:4096
server password <password>
```

Use-o quando quiser:

- Executar o OpenCode em um host compartilhado, sempre ligado ou remoto e conectar clientes com
  `opencode --server <url>`.
- Controlar o hostname, a porta e as origens de CORS de um único processo.
- Executar sob um supervisor como systemd, Docker ou outro ambiente que espera um processo em primeiro plano.
- Manter um servidor dedicado em vez do serviço compartilhado em segundo plano.

Conecte um cliente a ele com `--server`:

```bash
$ opencode --server http://127.0.0.1:4096
```
