---
title: "Plugins"
---

Plugins configurados no `opencode.json(c)` que expõem um componente de TUI são carregados automaticamente pela CLI. Para
saber como criar plugins, consulte [Criar plugins](/build/plugins). Não é preciso adicionar o mesmo pacote ao
`cli.json`. A CLI obtém a lista de plugins ativos do servidor OpenCode conectado, então isso também funciona quando o
servidor é remoto.

Use o `cli.json` para plugins exclusivos da CLI. Esses plugins são executados localmente no terminal e continuam ativos
quando a CLI se conecta a um servidor remoto:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

As entradas são processadas em ordem. Coloque `-` antes de um ID ou curinga para desativar os plugins correspondentes:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Passe opções para o plugin usando a forma de objeto:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

O OpenCode também descobre plugins no diretório de configuração global e nos diretórios `.opencode` do projeto. Cada
plugin usa a mesma estrutura de um pacote publicado, com os pontos de entrada do servidor e da TUI lado a lado.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Plugins descobertos podem importar `@opencode/plugin/tui` diretamente; o OpenCode resolve o pacote em tempo de execução.
Consulte [Criar plugins para a CLI](/build/plugins/cli) para ver exemplos.
