---
title: "Atalhos de teclado"
---

Personalize os atalhos no `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Use uma string para uma única tecla:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separe alternativas com vírgulas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Desative um atalho com `"none"` ou `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Use um objeto para controlar o comportamento do evento:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

O valor padrão de `leader` é `ctrl+x`. `<leader>` em outro atalho se refere a essa tecla.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

IDs de comando desconhecidos são rejeitados.

## Mini

O comando `app.clear` funciona apenas no [`opencode mini`](/cli). Pressione `ctrl+l` para limpar a tela visível e
desenhar o prompt de novo. O terminal mantém o histórico de rolagem.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Visualizador de diff

Pressione `d` (`diff.switch_source`) para escolher **All**, **Committed**, **Uncommitted** ou **Last turn** (dentro de
uma sessão), ou selecione **Base** para mudar o branch de comparação. As escolhas são lembradas até a TUI ser
encerrada. Defina o escopo inicial com [`diffs.source` no `cli.json`](/cli/config#diffs).

Os atalhos de rolagem, de paginação e de início/fim sempre controlam o diff. Não há troca de foco pelo teclado: clique
nos arquivos para abri-los, clique nas pastas para expandi-las ou recolhê-las e use a roda do mouse para rolar a árvore
de arquivos.

Use `n` / `p` ou `alt+down` / `alt+up` (Option no macOS) para navegar entre os arquivos. Dentro do visualizador de diff,
os atalhos com Alt navegam entre arquivos, e não entre as abas de sessão.

Pressione `m` para marcar um arquivo como revisado e recolher o corpo do patch. Na visualização de todos os arquivos,
pressione `m` de novo para desmarcá-lo e reabrir o patch. Na visualização de arquivo único, marcar como revisado avança
automaticamente para o próximo arquivo, mas permanece no último arquivo em vez de voltar ao início. Desmarcar um arquivo
nunca avança.

Clique com o botão direito em um arquivo na barra lateral ou no cabeçalho do diff dele para acessar **Mark complete**
(ou **Mark incomplete**). Isso altera o mesmo estado de revisão que `m`. Concluir outro arquivo pelo menu dele não o
seleciona nem avança o arquivo que está sendo lido.

As alternativas de `diff.help` com Shift atendem terminais que informam o modificador Shift quando você pressiona `?`.
