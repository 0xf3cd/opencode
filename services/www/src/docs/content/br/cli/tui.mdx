title: "TUI"
description: "Inicie uma sessão e use os fluxos do dia a dia na interface de terminal."
---

Execute o OpenCode no seu projeto, digite uma solicitação e pressione **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Pressione **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** ou **Ctrl+J** para inserir uma nova linha. Enquanto o OpenCode
está trabalhando, **Enter** envia o prompt para redirecionar a sessão ativa; pressione **Ctrl+X** e depois **Enter** para enfileirar o prompt
para mais tarde.

## Contexto

Digite `@` para pesquisar um arquivo e selecione-o para anexá-lo ao prompt. Continue digitando depois do `@` para
refinar os resultados.

```text
Review @src/auth.ts for error handling problems
```

Você pode incluir uma linha ou um intervalo depois do caminho.

```text
Explain @src/auth.ts#20-45
```

## Shell

Digite `!` no início de um prompt vazio para entrar no modo shell. Digite um comando e pressione **Enter**; pressione
**Esc** para sair do modo shell sem executar nada.

```text
!git status
```

Os comandos de shell são executados no diretório de trabalho da sessão, e a saída deles fica na sessão.

## Comandos

Digite `/` para listar os comandos de barra. Continue digitando para filtrar a lista e pressione **Enter** para executar
o comando selecionado.

```text
/models
```

Entre os comandos mais comuns estão `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` e `/editor`. Pressione
**Ctrl+P** para abrir a paleta de comandos com todas as ações disponíveis na visualização atual.

Depois de uma atualização, o OpenCode mostra uma única vez, na tela inicial, as novidades da versão. Execute
`/highlights` para vê-las de novo ou defina `"highlights": false` no [`cli.json`](/cli/config#alerts) para que elas não
abram automaticamente.

## Perguntas paralelas

Execute `/btw <question>` para fazer uma pergunta rápida sobre a conversa até o momento. A resposta usa o contexto e o
modelo atual da sessão, mas não é adicionada à conversa, então não afeta os prompts seguintes. Um indicador `/btw`
aparece no rodapé do prompt enquanto a pergunta é processada, e a resposta abre em uma caixa de diálogo; pressione **C**
para copiá-la.

```text
/btw why did the test in step 2 fail?
```

## Modelos

Pressione **Ctrl+X** e depois **M** para escolher um modelo, ou execute `/models`. Pressione **F2** para alternar entre
os modelos usados recentemente.

Pressione **Ctrl+X** e depois **A** para escolher um agente, ou execute `/agents`. Pressione **Shift+Tab** para alternar
entre os agentes.

## Sessões

Pressione **Ctrl+X** e depois **N** para iniciar uma nova sessão. Pressione **Ctrl+X** e depois **L**, ou execute
`/sessions`, para voltar a uma sessão existente; **Ctrl+O** abre as sessões e os projetos recentes juntos.

As abas vêm ativadas por padrão. Use **Ctrl+Tab** e **Ctrl+Shift+Tab** para navegar entre elas, **Ctrl+X** e depois
**W** para fechar uma aba e **Ctrl+Shift+T** para reabrir a última aba fechada.

## Histórico

Pressione **Ctrl+X** e depois **U**, ou execute `/undo`, para reverter a última mensagem do usuário e o trabalho feito
depois dela. O prompt revertido volta para o editor de mensagens para que você possa editá-lo.

Pressione **Ctrl+X** e depois **R**, ou execute `/redo`, para restaurar o trabalho revertido. Se, em vez disso, você
enviar um novo prompt, a reversão é confirmada e a conversa continua a partir desse ponto.

## Editor

Defina `VISUAL` ou `EDITOR` e pressione **Ctrl+X** e depois **E**, ou execute `/editor`, para editar o prompt atual
nesse editor. Salve e saia para devolver o texto ao editor de mensagens e pressione **Enter** para enviá-lo.

```bash
export EDITOR="nvim"
opencode
```

A tecla líder é **Ctrl+X** por padrão. Consulte [Atalhos de teclado](/cli/keybinds) para alterar esses atalhos.
