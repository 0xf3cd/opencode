O OpenCode é um agente de programação com IA de código aberto. Ele está disponível como interface de terminal, app
desktop ou app web.

O pacote npm usa um script de postinstall para selecionar o binário nativo do `opencode` para a sua plataforma. Os
comandos do Bun e do pnpm liberam explicitamente esse script; o Vite+ não precisa de nenhuma flag adicional. O comando do mise exige o mise 2026.10.9 ou mais recente; versões anteriores instalam o OpenCode 1.

Gerenciadores de pacotes do Windows não são suportados.


Baixe um binário independente da CLI para a sua plataforma.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

Acesse a interface web do OpenCode com o comando `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

As imagens Docker usam tags versionadas, por exemplo `ghcr.io/anomalyco/opencode:2.0.0`.

---

## Conectar

O OpenCode tem suporte nativo a vários provedores de LLM. Você pode se conectar a eles diretamente
[na TUI](/cli/providers) com `/connect`.

Para configurar provedores personalizados, consulte [Provedores](/providers).

Se você quer acesso fácil aos melhores modelos de programação, experimente o [OpenCode Console](/console).

Você também pode experimentar o [OpenCode Go](/console/go), um plano de assinatura de $10/mês que dá acesso aos melhores
modelos de código aberto.

---

## Personalizar

Deixe o OpenCode do seu jeito editando a [configuração do OpenCode](/config), [carregando plugins](/plugins),
[conectando servidores MCP](/mcp-servers) ou [criando comandos](/commands). Para temas e atalhos de teclado da interface
de terminal, consulte as [configurações da CLI](/cli/config).
