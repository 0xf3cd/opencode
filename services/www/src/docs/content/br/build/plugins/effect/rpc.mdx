---
title: "RPC"
---

Plugins Effect podem expor métodos e eventos que retornam Effects e Streams
tipados.

## Definir

Use `Rpc.define` com o Effect Schema para definir a RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Validação

O Effect Schema valida os valores e infere os tipos TypeScript deles.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema e Standard Schema também são suportados.

### Entrada e saída

Use `input` para o argumento do método e `output` para o valor de retorno.
Omita qualquer um dos dois quando não houver valor.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Erros

Adicione as falhas esperadas em `errors`. Cada chave vira o `type` do erro.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Eventos

Adicione eventos ao mapa `events` de nível superior. Os dados do evento precisam
ser um objeto.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Implementar

Registre a implementação a partir do Effect do plugin:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

O mapa de erros vira o tipo de erro do Effect de cada método. Use
`context.error(...)` para criar um erro declarado.

## Chamar

Depois de registrada, a RPC pode ser chamada por HTTP ou a partir de outro plugin.

### HTTP

Crie o cliente Effect e, em seguida, o subcliente da RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Plugin

Outro plugin Effect pode criar um subcliente local a partir do próprio contexto:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Assinar

Eventos de RPC são Streams. Assine pelo nome do evento e execute o Stream em uma
fiber com escopo:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

As assinaturas recebem apenas eventos ao vivo e são encerradas quando o consumo do
Stream para.
