title: "CLI"

Plugins da CLI estendem o terminal com comandos, rotas, slots, renderizadores de Markdown, notificações e estado local.

```ts title="src/tui.ts"
import { Plugin } from "@opencode/plugin/tui"

export default Plugin.define({
  id: "acme.cli",
  setup(context) {
    context.ui.toast.show({ message: "CLI plugin loaded", variant: "success" })
  },
})
```

Importe `@opencode/plugin/tui` diretamente. O OpenCode resolve essa importação em tempo de execução, então plugins
locais da CLI não precisam de um caminho absoluto para um checkout do OpenCode.

## Contexto

`setup` recebe a configuração, os metadados do app, a localização atual, o cliente do OpenCode, dados em cache, tokens
de tema, o renderizador do OpenTUI e as APIs de UI documentadas abaixo.

```ts
setup(context) {
  const compact = context.options.compact === true
  const location = context.location ?? context.data.location.default()
  const version = context.app.version
  const channel = context.app.channel
  const client = context.client
  const renderer = context.renderer
  const theme = context.theme
}
```

Retorne uma função de limpeza para os recursos que pertencem ao plugin.

```ts
setup(context) {
  const stop = context.data.on("session.execution.succeeded", () => {})
  return () => stop()
}
```

## Cliente

`context.client` é o cliente gerado do OpenCode e pode chamar o servidor conectado, inclusive um servidor remoto.

```ts
const response = await context.client.plugin.list({
  location: context.location ?? context.data.location.default(),
})
const plugins = response.data
```

## Eventos

Use `data.on` para um evento tipado ou `data.listen` para todos os eventos do servidor; os dois retornam uma função
para cancelar a assinatura.

```ts
const stopPermission = context.data.on("permission.asked", (event) => {
  context.ui.toast.show({ message: `Permission ${event.data.id}` })
})
const stopAll = context.data.listen(({ details }) => console.log(details.type))

return () => {
  stopPermission()
  stopAll()
}
```

## Sessões

Os dados de sessão oferecem listagem, consulta, hierarquia, custo, status, sincronização e invalidação.

```ts
const sessions = context.data.session.list()
const session = context.data.session.get(sessionID)
const rootID = context.data.session.root(sessionID)
const familyIDs = context.data.session.family(sessionID)
const cost = context.data.session.cost(sessionID)
const status = context.data.session.status(sessionID)
await context.data.session.sync(sessionID)
context.data.session.invalidate(sessionID)
```

Itens pendentes da caixa de entrada e mensagens têm APIs de listagem, consulta, sincronização e invalidação.

```ts
await context.data.session.pending.sync(sessionID)
const pending = context.data.session.pending.list(sessionID)
context.data.session.pending.invalidate(sessionID)

await context.data.session.message.sync(sessionID)
const messages = context.data.session.message.list(sessionID)
const message = context.data.session.message.get(sessionID, messageID)
context.data.session.message.invalidate(sessionID)
```

As requisições de permissão de uma sessão podem ser lidas e atualizadas.

```ts
await context.data.session.permission.sync(sessionID)
const requests = context.data.session.permission.list(sessionID) ?? []
context.data.session.permission.invalidate(sessionID)
```

Formulários podem ser listados, atualizados, respondidos ou cancelados em uma localização.

```ts
import type { FormCancelInput, FormReplyInput } from "@opencode/client"

async function handleForm(reply: FormReplyInput, cancel: FormCancelInput) {
  const location = context.location
  await context.data.session.form.sync(sessionID, location)
  const forms = context.data.session.form.list(sessionID, location) ?? []
  await context.data.session.form.reply(reply, location)
  await context.data.session.form.cancel(cancel, location)
  context.data.session.form.invalidate(sessionID, location)
}
```

## Projetos e shells

Projetos e permissões salvas oferecem operações de listagem, consulta, sincronização e invalidação.

```ts
await context.data.project.sync()
const projects = context.data.project.list()
const project = context.data.project.get(projectID)
context.data.project.invalidate()

await context.data.project.permission.sync(projectID)
const saved = context.data.project.permission.list(projectID) ?? []
context.data.project.permission.invalidate(projectID)
```

Os dados de shell oferecem operações de listagem, consulta, sincronização e invalidação com escopo de localização.

```ts
await context.data.shell.sync(context.location)
const shells = context.data.shell.list(context.location)
const shell = context.data.shell.get(shellID)
context.data.shell.invalidate(context.location)
```

## Dados de localização

O estado de localização expõe a localização padrão e controles de atualização.

```ts
const location = context.data.location.default()
await context.data.location.sync(location)
context.data.location.invalidate(location)
```

O estado de controle de versão expõe informações do repositório em uma localização.

```ts
await context.data.location.vcs.sync(context.location)
const vcs = context.data.location.vcs.info(context.location)
const branch = vcs?.branch.current
context.data.location.vcs.invalidate(context.location)
```

Os dados de agentes, comandos, integrações, modelos, provedores, referências, skills e MCP compartilham os métodos
`list`, `sync` e `invalidate`.

```ts
const location = context.location
await Promise.all([
  context.data.location.agent.sync(location),
  context.data.location.command.sync(location),
  context.data.location.integration.sync(location),
  context.data.location.model.sync(location),
  context.data.location.provider.sync(location),
  context.data.location.reference.sync(location),
  context.data.location.skill.sync(location),
  context.data.location.mcp.server.sync(location),
  context.data.location.mcp.resource.sync(location),
])

const agents = context.data.location.agent.list(location) ?? []
const commands = context.data.location.command.list(location) ?? []
const integrations = context.data.location.integration.list(location) ?? []
const models = context.data.location.model.list(location) ?? []
const providers = context.data.location.provider.list(location) ?? []
const references = context.data.location.reference.list(location) ?? []
const skills = context.data.location.skill.list(location) ?? []
const servers = context.data.location.mcp.server.list(location) ?? []
const resources = context.data.location.mcp.resource.list(location) ?? []

context.data.location.model.invalidate(location)
```

## Atenção

Solicitações de atenção podem exibir uma notificação do sistema, tocar um som configurado ou fazer as duas coisas,
conforme o foco do terminal.

```ts
const result = await context.attention.notify({
  title: "OpenCode",
  message: "Session done",
  notification: { when: "blurred" },
  sound: { name: "done", volume: 0.5, when: "always" },
})
console.log(result.ok, result.notification, result.sound, result.skipped)
```

## Tema e renderizador

Use tokens semânticos de tema com elementos do OpenTUI e passe `context.renderer` para helpers específicos do
renderizador.

```tsx
const Status = () => <text fg={context.theme.text.base}>Ready</text>
const renderer = context.renderer
```

## Componentes Solid

Use `usePlugin` para acessar o contexto atual dentro do JSX renderizado por uma rota, um diálogo ou um slot.

```tsx
import { usePlugin } from "@opencode/plugin/tui"

function Status() {
  const context = usePlugin()
  return <text fg={context.theme.text.base}>{context.app.version}</text>
}
```

## Markdown

Registre um renderizador de blocos de código cercados por linguagem; a função retornada cancela o registro.

```ts
const unregister = context.markdown.registerCodeBlockRenderer("acme", (_token, render) => render.defaultRender())
return unregister
```

## Comandos e keymaps

Registre comandos da paleta, comandos de barra e comandos de teclado em uma camada reativa de keymap.

```ts
context.keymap.layer(() => ({
  mode: "global",
  priority: 10,
  commands: [
    {
      id: "acme.status",
      title: "Show Acme status",
      group: "Acme",
      bind: "ctrl+g",
      palette: true,
      slash: { name: "acme", aliases: ["status"], arguments: true },
      enabled: () => true,
      suggested: true,
      run: async (input) => context.ui.toast.show({ message: input ?? "Ready" }),
    },
  ],
  bindings: ["acme.status"],
}))
```

Chame `layer` a partir de `setup`, inclusive depois de um `await`, ou de um componente. Cada camada é removida no
primeiro destes eventos:

- O plugin é desativado, recarregado ou falha no setup.
- O componente ou a computação reativa que a criou, como um slot, uma rota ou um diálogo, é descartado.

A factory da camada precisa ser pura. O OpenCode a avalia uma vez sem rastreamento de dependências para validar o
formato inicial dos comandos e, depois, de forma reativa. Erros no formato inicial dos comandos, como um comando da
paleta sem ID, são lançados por `layer()`. O OpenTUI trata erros de parsing dos atalhos. Erros de atualizações reativas
posteriores seguem o tratamento de erros do Solid.

```ts
async setup(context) {
  const settings = await loadSettings()
  context.keymap.layer(() => ({
    mode: "global",
    commands: [{ id: "acme.sync", title: "Sync Acme", palette: true, run: () => sync(settings) }],
  }))
}
```

Uma camada pode ter como alvo um renderable do OpenTUI, e um comando pode retornar `false` para continuar o
despacho do teclado.

```ts
context.keymap.layer(() => ({
  target: () => panel,
  commands: [{ bind: "escape", run: (_input, event) => (event ? false : undefined) }],
}))
```

Despache comandos, inspecione atalhos e o estado dos comandos ou empilhe um modo de entrada temporário.

```ts
context.keymap.dispatch("acme.status", "verbose")
const shortcuts = context.keymap.shortcuts("acme.status")
const commands = context.keymap.commands()
const pending = context.keymap.pending()
const active = context.keymap.active()
const currentMode = context.keymap.mode.current()
const popMode = context.keymap.mode.push("acme-search")
popMode()
```

## Armazenamento

O armazenamento durável persiste JSON entre reinicializações e é sincronizado entre instâncias da TUI.

```ts
const [settings, updateSettings] = context.storage.store("settings", {
  initial: { compact: false },
})
await updateSettings((draft) => {
  draft.compact = true
})
```

O armazenamento em memória sobrevive a recarregamentos do plugin, mas é descartado quando a TUI é encerrada.

```ts
const [state, updateState] = context.storage.memory("state", {
  initial: { count: 0 },
})
updateState((draft) => {
  draft.count++
})
```

## Diálogos e notificações

Use diálogos baseados em promises para alertas, confirmações, entrada de texto e seleção.

```ts
await context.ui.dialog.alert({ title: "Acme", message: "Ready" })
const confirmed = await context.ui.dialog.confirm({
  title: "Continue?",
  message: "Run the Acme action?",
  label: { confirm: "Run", cancel: "Cancel" },
})
const name = await context.ui.dialog.prompt({ title: "Name", placeholder: "release" })
const mode = await context.ui.dialog.select({
  title: "Mode",
  current: "safe",
  options: [
    { title: "Safe", value: "safe", description: "Ask before changes" },
    { title: "Fast", value: "fast", disabled: false, category: "Advanced" },
  ],
})
```

### Pesquisa na seleção

Passe `search` para controlar a correspondência e a ordem dos resultados. Ela é executada para cada consulta, inclusive
a vazia, e recebe apenas as opções habilitadas. Os resultados são listados na ordem retornada, com a categoria de cada
um exibida na mesma linha.

```ts
const project = await context.ui.dialog.select({
  title: "Projects",
  options: [
    { title: "Alpha", value: "alpha", category: "Recent" },
    { title: "Beta", value: "beta", category: "Pinned" },
  ],
  search: (query, options) =>
    options
      .filter((option) => option.title.toLowerCase().includes(query.toLowerCase()))
      .toSorted((left, right) => right.title.localeCompare(left.title)),
})
```

### Ações da seleção

As ações aparecem no rodapé e são executadas pelo atalho de teclado, por um clique ou com foco via Tab seguido de
Enter. Por padrão, elas recebem o valor selecionado e ficam indisponíveis sem uma seleção. Use `selection: "none"` para
ações que não precisam de seleção.

```ts
await context.ui.dialog.select({
  title: "Projects",
  options: [{ title: "Alpha", value: "alpha" }],
  actions: [
    { bind: "ctrl+o", title: "Inspect", onTrigger: (value) => context.ui.toast.show({ message: value }) },
    { bind: "ctrl+a", title: "Close", side: "right", selection: "none", onTrigger: () => context.ui.dialog.clear() },
  ],
})
```

- Uma ação não fecha o diálogo nem resolve a promise.
- Enter ou um clique em uma opção resolve com o valor selecionado.
- Escape, `clear()` ou a exibição de outro diálogo resolve com `undefined`.
- Não vincule `ctrl+n` nem `ctrl+p`. O diálogo os reserva para navegação, e os atalhos dele têm precedência.

Diálogos JSX personalizados podem definir o próprio tamanho e se fechar sozinhos.

```tsx
context.ui.dialog.set({ size: "large", centered: true })
context.ui.dialog.show(
  () => (
    <box>
      <text>Acme</text>
    </box>
  ),
  () => console.log("closed"),
)
context.ui.dialog.clear()
```

As notificações (toasts) aceitam título, mensagem, variante e duração.

```ts
context.ui.toast.show({
  title: "Acme",
  message: "Saved",
  variant: "success",
  duration: 3000,
})
```

## Rotas e abas

Registre uma rota JSX, inspecione a rota atual e navegue para a tela inicial, uma sessão ou a página do plugin.

```tsx
const unregister = context.ui.router.register({
  name: "dashboard",
  render: ({ data }) => <text>{String(data?.title ?? "Acme")}</text>,
})
const current = context.ui.router.current()
context.ui.router.navigate({ type: "plugin", name: "dashboard", data: { title: "Status" } })
context.ui.router.navigate({ type: "session", sessionID })
context.ui.router.navigate({ type: "home" })
return unregister
```

Quando as abas de sessão estão habilitadas, é possível listar, abrir, focar, mover e fechar abas. `open` não altera o
foco; `focus` abre a aba quando necessário.

```ts
if (context.ui.tabs.enabled()) {
  context.ui.tabs.open(backgroundSessionID)
  context.ui.tabs.focus(sessionID)
  const tabs = context.ui.tabs.list()
  context.ui.tabs.move(backgroundSessionID, tabs.length - 1)
  context.ui.tabs.close(sessionID)
  context.ui.tabs.close()
}
```

## Modelo

Leia o modelo selecionado no prompt e altere a variante dele. `current()` e `variant.list()` são reativos quando lidos
dentro de uma computação do Solid. Uma `variant` igual a `undefined` corresponde ao padrão do modelo.

```ts
const selected = context.ui.model.current()
const variants = context.ui.model.variant.list()
context.ui.model.variant.set("high")
context.ui.model.variant.set(undefined)
```

`variant.set` retorna `false` quando nenhum modelo está selecionado ou o modelo não tem essa variante. Vincule-o a um
comando para substituir o ciclo de variantes nativo, por exemplo para pular o padrão do modelo:

```ts
context.keymap.layer(() => ({
  commands: [
    {
      id: "acme.variant.cycle",
      title: "Cycle variants",
      bind: "tab",
      run() {
        const variants = context.ui.model.variant.list()
        if (variants.length === 0) return
        const index = variants.indexOf(context.ui.model.current()?.variant ?? "")
        context.ui.model.variant.set(variants[(index + 1) % variants.length])
      },
    },
  ],
}))
```

## Slots

Slots inserem ou substituem JSX em `app`, `home.footer`, `home.footer.status`, `prompt.footer`, `prompt.footer.status`,
`prompt.footer.file`, `session.composer.top`, `sidebar.content` ou `sidebar.footer`.

```tsx
return context.ui.slot({
  append: "sidebar.content",
  render: ({ sessionID }) => <text>{context.data.session.get(sessionID)?.title}</text>,
})
```

Use `prepend`, `append`, `before`, `after` ou `replace` para definir o posicionamento.

```tsx
context.ui.slot({ prepend: "home.footer", render: () => <text>Before footer content</text> })
context.ui.slot({ append: "home.footer", render: () => <text>After footer content</text> })
context.ui.slot({ before: "home.footer", render: () => <text>Before footer slot</text> })
context.ui.slot({ after: "home.footer", render: () => <text>After footer slot</text> })
context.ui.slot({ replace: "home.footer", render: () => <text>New footer</text> })
```

Use `home.footer.status` para adicionar conteúdo à linha de rodapé nativa sem substituí-la. Essas contribuições aparecem
depois dos indicadores de saúde do OpenCode e antes da versão.

```tsx
context.ui.slot({ append: "home.footer.status", render: () => <text>SYNCED</text> })
```

### Painéis de sessão

Registre uma contribuição em `session.panel` e abra o painel a partir de um comando. O host controla o tamanho, o foco
e a exibição em tela cheia; o plugin controla o conteúdo. O nome selecionado é passado a todas as contribuições como
`panel.name`, e cada contribuição decide se deve renderizar.

```tsx
import { Show } from "solid-js"

context.ui.slot({
  append: "session.panel",
  render: (panel) => (
    <Show when={panel.name === "acme.review"}>
      <ReviewPanel panel={panel} />
    </Show>
  ),
})

context.ui.slot({
  append: "app",
  render: () => {
    context.keymap.layer(() => ({
      mode: "global",
      commands: [
        {
          id: "acme.review",
          title: "Open review",
          slash: { name: "review" },
          run: () => {
            context.ui.panel.open("acme.review")
          },
        },
      ],
    }))
    return null
  },
})
```

- Abrir o painel fora de uma sessão retorna `false`.
- É um slot comum: os cinco posicionamentos e as regras de ordenação de substituição existentes se aplicam.
- Use `append` para contribuições selecionáveis de forma independente, para que possam coexistir. `replace` continua
  assumindo o slot.
- Os nomes são valores de seleção compartilhados, não reivindicações registradas. Use um nome com prefixo do plugin,
  como `acme.review`, para evitar colisões. Abrir um nome sem renderizador correspondente deixa o slot vazio.
- Mudar a forma de exibição preserva as contribuições montadas. Fechar o painel as descarta; desativar um plugin remove
  as contribuições dele pela limpeza normal de slots.
- As camadas de teclado e os modos de entrada do painel só ficam ativos enquanto o painel controla a entrada.

O slot recebe as propriedades reativas `name`, `sessionID`, `width`, `presentation` e `focused`, além das ações `focus`,
`close` e `toggleFullscreen`. O host mantém terminais estreitos em tela cheia; `toggleFullscreen` não tem efeito até
haver espaço suficiente para um painel lateral.

```tsx
import type { PanelInput } from "@opencode/plugin/tui/context"
import { usePlugin } from "@opencode/plugin/tui"

function ReviewPanel(props: { panel: PanelInput }) {
  const context = usePlugin()
  context.keymap.layer(() => ({
    commands: [
      {
        id: "acme.review.fullscreen",
        bind: "f",
        run: props.panel.toggleFullscreen,
      },
    ],
  }))
  return <text>Reviewing {props.panel.sessionID}</text>
}
```

Você pode pedir a exibição em tela cheia desde o início, inspecionar o seu painel ativo ou fechá-lo sem afetar o painel
de outro plugin.

```ts
context.ui.panel.open("acme.review", { presentation: "fullscreen" })
const current = context.ui.panel.current()
context.ui.panel.close()
```

## Publicar e carregar

Exponha o plugin da CLI por `./tui`; adicione as peer dependencies do OpenTUI quando o plugin renderizar JSX.

```json title="package.json"
{
  "name": "opencode-acme-plugin",
  "type": "module",
  "exports": {
    ".": "./src/index.ts",
    "./tui": "./src/tui.tsx"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "@opentui/core": ">=0.5.8",
    "@opentui/solid": ">=0.5.8",
    "solid-js": ">=1.9.0"
  }
}
```

Exporte `./tui` junto ao [plugin principal](/build/plugins) para que ele seja carregado automaticamente.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin"

export default Plugin.define({
  id: "acme.server",
  setup() {},
})
```

Configure um pacote exclusivo da CLI em [`cli.json`](/cli/plugins) para que ele continue ativo com servidores remotos.

```json title="cli.json"
{
  "plugins": ["opencode-acme-plugin"]
}
```
