OpenCode 是一个开源的 AI 编程代理，提供终端界面、桌面应用和 Web 应用。

npm 包通过 postinstall 脚本为你的平台选择对应的原生 `opencode` 二进制文件。上面的 Bun 和 pnpm 命令显式允许了该脚本；Vite+ 无需额外参数。mise 命令需要 mise 2026.10.9 或更高版本；更早的版本会安装 OpenCode 1。

不支持 Windows 包管理器。


下载适用于你平台的独立 CLI 二进制文件。

- **macOS：** [Apple 芯片](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel（baseline）](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)

## Web

使用 `opencode pair` 命令访问 OpenCode Web 界面。

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker 镜像使用带版本号的标签，例如 `ghcr.io/anomalyco/opencode:2.0.0`。

## 连接

OpenCode 内置支持众多 LLM 提供商，你可以直接[在 TUI 中](/cli/providers)使用 `/connect` 连接它们。

如需配置自定义提供商，请参阅[提供商](/providers)。

如果你想轻松使用所有最好的编码模型，可以试试 [OpenCode Console](/console)。

你也可以试试 [OpenCode Go](/console/go)，这是一个每月 10 美元的订阅计划，可以使用最好的开源模型。

---

## 自定义

你可以通过编辑 [OpenCode 配置](/config)、[加载插件](/plugins)、[连接 MCP 服务器](/mcp-servers)或[创建命令](/commands)，打造属于你自己的 OpenCode。终端界面的主题和快捷键请参阅 [CLI 设置](/cli/config)。
