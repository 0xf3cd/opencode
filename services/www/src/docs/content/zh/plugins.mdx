title: 插件
---

你可以在 `opencode.json(c)` 中添加已发布的包、指定版本的包、带作用域的包或本地插件目录。

## 配置

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-plugin",
    "opencode-acme-plugin@1.2.0",
    "@acme/opencode-plugin",
    "./plugins/local",
    "../shared/plugin.ts",
    "/absolute/path/plugin.ts",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/opencode-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

相对路径相对于包含该条目的配置文件进行解析。各个适用配置文件中的插件数组会按优先级从低到高依次应用，而不是相互替换。

```text
~/.config/opencode/opencode.jsonc
./opencode.jsonc
./.opencode/opencode.jsonc
```

## 自动发现

OpenCode 还会从每个被发现的 `.opencode/plugins/` 目录中加载直接位于其中的 `.ts` 和 `.js` 文件，以及第一层的插件包目录。

```text
.opencode/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

全局插件在 OpenCode 配置目录下使用相同的发现结构。

```text
~/.config/opencode/plugins/
```

与项目根目录的 `opencode.json(c)` 同级的 `plugins/` 目录不会被自动发现；请显式配置其中的文件，或将它移到 `.opencode/` 下。

```jsonc title="opencode.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## 启用与禁用

插件条目按顺序处理。在 ID 或通配符前加 `-` 可以禁用对应插件，`*` 匹配所有插件，`.*` 匹配 ID 前缀。后面再出现的 ID 会重新启用该插件。

```jsonc title="opencode.jsonc"
{
  "plugins": ["*", "-opencode.provider.*", "opencode.provider.openai", "-acme.reviewer"]
}
```

有两个内置插件会忽略移除操作，以防仓库关闭[策略](/policies)的强制执行：`opencode.config.policy`，以及负责下发组织策略的 Console 连接 `opencode.provider.opencode`。

## 管理

使用 CLI 安装、列出、检查、更新或移除全局包插件。

```sh
opencode plugin add opencode-acme-plugin@1.2.0
opencode plugin list
opencode plugin list --builtin
opencode plugin check
opencode plugin update
opencode plugin update opencode-acme-plugin
opencode plugin remove opencode-acme-plugin@1.2.0
```

`plugin check` 会检查服务器插件包和仅限 TUI 的插件包是否有更新。`plugin update` 会更新所有过期的包；传入一个已配置的包作为目标，则只检查或更新该包。本地插件和锁定到确切版本的包会被跳过。

安装包时，可以使用带版本、标签或版本范围的 npm 包名，也可以使用兼容 npm 的 Git 包描述。Git 仓库可以使用托管平台简写、HTTPS 或 SSH，也包括可通过你现有 Git 凭据访问的私有仓库。

```sh
opencode plugin add @acme/opencode-plugin@latest
opencode plugin add github:acme/opencode-plugin
opencode plugin add git+ssh://git@github.com/acme/opencode-plugin.git#main
opencode plugin add 'github:acme/plugins#main::path:packages/opencode-plugin'
```

支持分支、标签、完整的提交哈希，以及 npm 用于选择仓库子目录的 `::path:` 语法。本地路径请直接写在配置中；`plugin add` 不接受 tarball 和 npm 别名目标。

## 重新加载

受监听的配置目录中发生变更时会自动重新加载。服务器启动时会立即加载已缓存的插件包，在后台安装缺失的包，并检查未锁定版本的 npm 和 Git 插件是否有更新，但不会改动已安装的包。确切的 npm 版本和完整的 Git 提交哈希会保持锁定。未受监听的本地依赖发生变更时，可能仍需重启 OpenCode。

```sh
touch .opencode/plugins/concise/index.ts
opencode service restart
```

## 终端插件

仅限 CLI 的插件需要单独配置，连接到远程服务器时也会保持启用。

```json title="cli.json"
{
  "plugins": ["opencode-acme-cli"]
}
```
