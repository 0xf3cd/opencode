title: "快捷键"
---

在 `cli.json` 中自定义快捷键：

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

单个按键使用字符串：

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

多个备选按键用逗号分隔：

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

使用 `"none"` 或 `false` 禁用某个快捷键：

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

如需控制事件行为，请使用对象形式：

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` 默认为 `ctrl+x`。其他快捷键中的 `<leader>` 指代该按键。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

未知的命令 ID 会被拒绝。

## Diff 查看器

按 `d`（`diff.switch_source`）可以选择 **All**、**Committed**、**Uncommitted** 或 **Last turn**（仅在会话中可用），也可以选择 **Base** 来更改对比分支。所选项会一直保留到 TUI 退出。初始范围可通过 [`cli.json` 中的 `diffs.source`](/cli/config#diffs) 设置。

滚动、翻页以及跳到开头/结尾的快捷键始终作用于 diff。查看器没有键盘焦点切换：点击文件即可打开，点击文件夹可展开或折叠，使用鼠标滚轮滚动文件树。

使用 `n` / `p` 或 `alt+down` / `alt+up`（macOS 上为 Option 键）在文件之间切换。在 diff 查看器中，这些 Alt 快捷键用于切换文件，而不是切换会话标签页。

按 `m` 可将文件标记为已审阅，并折叠其补丁内容。在全部文件视图中，再次按 `m` 可取消标记并重新展开补丁。在单文件视图中，标记为已审阅后会自动跳到下一个文件，但到达最后一个文件时会停留，不会回到开头。取消标记永远不会跳转。

在侧边栏中右键点击某个文件或其 diff 标题，可以选择 **Mark complete**（或 **Mark incomplete**）。这与 `m` 修改的是同一个已审阅状态。通过菜单将另一个文件标记为完成时，不会选中该文件，也不会让当前正在阅读的文件跳转。

`diff.help` 中带 Shift 的备选按键，是为按下 `?` 时会报告 Shift 修饰键的终端准备的。
