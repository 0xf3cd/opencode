在项目中运行 CLI，即可打开全屏终端界面：

```bash
opencode
```

传入一个目录，可以在其他项目中工作：

```bash
opencode ~/code/my-project
```

推荐使用以下终端：

- [Ghostty](https://ghostty.org)
- [WezTerm](https://wezterm.org)
- [Alacritty](https://alacritty.org)
- [Kitty](https://sw.kovidgoyal.net/kitty/)

终端支持真彩色（Truecolor）时，主题颜色最为准确；不支持的终端会使用可用调色板中的近似颜色。

## 自动化

使用 `opencode run` 可以直接提交提示词，而不打开交互界面。它专为脚本、CI 任务以及其他需要在终端中直接获取模型输出的工作流设计。

```bash
opencode run "Explain this repository"
```

## Mini

使用 `opencode mini` 启动 OpenCode 的精简交互界面，代替全屏 TUI。

```bash
opencode mini
```

运行 `opencode mini --help` 查看会话、模型、代理、提示词和回放相关选项。

## 后台服务

默认情况下，OpenCode 会为你的用户账户发现或启动一个共享的后台服务器。所有本地 OpenCode 客户端都连接到这个服务器，由它负责管理会话、配置、集成、权限和工具执行。

使用 `--standalone` 运行私有服务器，或使用 `--server` 连接到指定的服务器 URL：

```bash
opencode --standalone
opencode --server http://localhost:4096
```

如果希望 CLI 命令默认使用私有服务器，而不是启动共享服务，可以禁用共享服务：

```bash
opencode service set disabled true
opencode
```

这会停止正在运行的后台服务。`--server` 仍然可以连接到显式指定的服务器，`opencode service start` 也仍然可以显式启动共享服务。要恢复自动使用服务，运行 `opencode service unset disabled`。配对功能依赖共享服务，禁用期间无法使用。

共享服务的诊断方法请参阅[故障排除](/troubleshooting)，服务器端点请参阅 [API 参考](/api)。

## 路径

打印某个本地路径，以便在其他工具中使用：

```bash
opencode debug paths db
sqlite3 "$(opencode debug paths db)"
```

可选的选择器支持 `db`、`home`、`data`、`config`、`cache`、`state`、`tmp`、`bin`、`log` 或 `repos`，只会输出路径和一个换行符。数据库路径会遵循发布渠道和 `OPENCODE_DB` 设置；相对路径的数据库覆盖值会基于数据目录解析，`:memory:` 则原样输出。该命令不会启动服务器，也不会打开数据库。

省略选择器时，会显示所有路径及其标签：

```bash
opencode debug paths
```

## 卸载

预览将要删除的文件和安装：

```bash
opencode uninstall --dry-run
```

运行 `opencode uninstall` 确认删除。OpenCode 会先停止已注册的后台服务和持久终端，然后删除全局缓存目录；该目录由所有 OpenCode 版本和渠道共享。会话数据、配置和状态永远不会被删除。

- `--force`（`-f`）跳过确认，适用于非交互式删除。
- 通过包管理器安装的，会使用检测到的包管理器卸载。通过 curl 安装的，会打印最后一条命令，供你手动删除可执行文件。
