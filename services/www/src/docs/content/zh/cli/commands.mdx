每个命令都支持 `--help`，用于查看完整的参数列表，例如 `opencode run --help`。部分依赖服务器的命令支持 `--standalone`（运行私有服务器）或 `--server <url>`（连接到指定服务器）；具体支持哪些参数，请查看该命令的帮助信息。

## run

发送一条消息并打印回复，不打开交互界面。

```bash
$ opencode run "Explain this repository"
```

### CI

在 CI 中，请以 secret 的形式传入提供商 API 密钥，并使用独立模式，让私有服务器能够读取它。例如，下面这个 GitHub Actions 任务会审查检出的仓库：

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

选择模型。

```bash
$ opencode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

继续上一个会话。

```bash
$ opencode run --continue "Now handle the expired case"
```

为脚本输出以换行分隔的 JSON。

```bash
$ opencode run --format json "List the TODO comments"
```

为消息附加文件。

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

使用指定代理运行。

```bash
$ opencode run --agent build "Fix the failing test"
```

查看所有子命令和参数。

```bash
$ opencode run --help
```

```bash
$ opencode mini
```

```bash
$ opencode mini --continue
```

```bash
$ opencode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

```bash
$ opencode mini --help
```

## session

管理会话。

```bash
$ opencode session list
```

限制列表数量并输出 JSON。

```bash
$ opencode session list --max-count 20 --format json
```

删除一个会话及其子会话。

```bash
$ opencode session delete ses_9c1b08
```

将会话数据导出为 JSON。

```bash
$ opencode session export ses_4f2a1c
```

导出时隐去对话记录和文件中的敏感数据。

```bash
$ opencode session export ses_4f2a1c --sanitize
```

从 JSON 文件或 URL 导入会话数据。

```bash
$ opencode session import session.json
```

导入到指定目录。

```bash
$ opencode session import session.json --directory ~/code/project
```

查看所有子命令和参数。

```bash
$ opencode session --help
```

## auth

管理 AI 提供商和凭据。

```bash
$ opencode auth list
```

以 JSON 格式列出。

```bash
$ opencode auth list --format json
```

登录提供商。

```bash
$ opencode auth login anthropic
```

使用指定的身份验证方式登录。

```bash
$ opencode auth login anthropic --method key
```

登出已保存的账户。

```bash
$ opencode auth logout anthropic work
```

切换某个集成的当前账户。

```bash
$ opencode auth switch anthropic work
```

查看所有子命令和参数。

```bash
$ opencode auth --help
```

## mcp

管理 MCP（Model Context Protocol）服务器。

```bash
$ opencode mcp list
```

添加远程服务器。

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

将本地服务器添加到全局配置。

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

添加带环境变量的本地服务器。

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

添加带请求头的远程服务器。

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

向支持 OAuth 的远程服务器进行身份验证。

```bash
$ opencode mcp auth sentry
```

删除为某个服务器保存的 OAuth 凭据。

```bash
$ opencode mcp logout sentry
```

查看所有子命令和参数。

```bash
$ opencode mcp --help
```

## plugin

管理插件。

```bash
$ opencode plugin list
```

包含内置的服务器插件。

```bash
$ opencode plugin list --builtin
```

安装插件并将其添加到全局配置。

```bash
$ opencode plugin add @example/opencode-tui
```

检查包插件是否有更新。

```bash
$ opencode plugin check
```

更新包插件。

```bash
$ opencode plugin update
```

从全局配置中移除插件。

```bash
$ opencode plugin remove @example/opencode-tui
```

查看所有子命令和参数。

```bash
$ opencode plugin --help
```

## serve

启动 API 和 Web 服务器。请参阅 [Web](/cli/web)。

```bash
$ opencode serve
```

在固定端口上绑定所有网络接口。

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
```

允许来自其他来源的浏览器客户端。

```bash
$ opencode serve --cors https://app.example.com
```

查看所有子命令和参数。

```bash
$ opencode serve --help
```

## pair

打印一次性链接，并显示第一个链接的二维码，用于让浏览器或应用登录到服务器。链接 5 分钟后过期，且只能使用一次。

```bash
$ opencode pair
```

在链接中使用外部 URL。

```bash
$ opencode pair --url https://dev.example.com
```

通过 OpenTunnel 远程地址，从任何地方进行配对。这会将服务器暴露到互联网，因此首次开启远程访问时，命令会说明这一点并请你确认。请参阅[远程访问](/cli/web#remote-access)。

```bash
$ opencode pair --remote
```

跳过确认提示直接同意，例如在没有终端的脚本中。

```bash
$ opencode pair --remote --yes
```

查看所有子命令和参数。

```bash
$ opencode pair --help
```

## service

管理后台服务器。请参阅 [Web](/cli/web)。

```bash
$ opencode service start
```

重启服务。

```bash
$ opencode service restart
```

查看服务状态。

```bash
$ opencode service status
```

停止服务。

```bash
$ opencode service stop
```

读取某项设置。

```bash
$ opencode service get hostname
```

修改某项设置。

```bash
$ opencode service set hostname 0.0.0.0
```

允许额外的 CORS 来源。

```bash
$ opencode service set cors https://app.example.com
```

向服务器进程传递环境变量。

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

将某项设置重置为默认值。

```bash
$ opencode service unset hostname
```

查看所有子命令和参数。

```bash
$ opencode service --help
```

## reload

在不重启服务器的情况下重新加载配置。正在运行的会话会在下一个步骤边界切换到新的服务继续运行。

```bash
$ opencode reload
```

## api

向正在运行的服务器发送请求。

```bash
$ opencode api GET /api/session
```

调用某个操作 ID，并带上查询参数。

```bash
$ opencode api session.list --param limit=10
```

发送 JSON 请求体。

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

添加请求头。

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

查看所有子命令和参数。

```bash
$ opencode api --help
```

## upgrade

将 OpenCode 升级到最新版本或指定版本。别名：`update`。

```bash
$ opencode upgrade
```

使用指定的包管理器升级到指定版本。

```bash
$ opencode upgrade 2.0.21 --method bun
```

查看所有子命令和参数。

```bash
$ opencode upgrade --help
```

## uninstall

```bash
$ opencode uninstall
```

预览将被移除的内容。

```bash
$ opencode uninstall --dry-run
```

查看所有子命令和参数。

```bash
$ opencode uninstall --help
```
