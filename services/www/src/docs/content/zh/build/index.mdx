每天有数百万人在使用 OpenCode。你可以基于它构建自己的应用、集成和代理体验，无需从零开始。

我们还为[插件](/build/plugins/effect)、[客户端](/build/client/effect)和[嵌入式应用](/build/sdk/effect)提供了 Effect API。

  <Card title="扩展 OpenCode" href="/build/plugins">

  </Card>
  <Card title="作为服务器运行" href="/build/client">

  </Card>
  <Card title="嵌入使用" href="/build/sdk">

  </Card>
