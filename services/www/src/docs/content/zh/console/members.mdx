所有者和管理员在 **Members** 页面中管理人员。每一行都会显示成员的角色、加入日期、本月用量和预算上限。

## 邀请成员

1. 打开 **Members**，点击 **Invite Members**。
2. 添加一个或多个电子邮件地址。地址之间用空格、逗号或分号分隔，也可以直接粘贴一个列表。
3. 点击 **Send invitations**。

每位受邀者都会收到一封标题为 **Join Acme Inc. on OpenCode** 的邮件，其中包含 **Join workspace** 按钮。

邀请在 7 天后过期。所有人加入时的角色都是 **Member**，加入后可以再[修改角色](#change-a-role)。

<Callout>
  订阅了 [OpenCode Go](/console/go) 的工作区无法邀请成员。请为你的团队另外创建一个工作区。
</Callout>

成员也可以自动加入：

- [SSO](/console/sso#automatic-membership)：已验证邮箱域名下的用户首次登录时会被自动添加。
- [目录同步](/console/scim)：根据你在身份提供商中的分配情况添加或移除成员。

## 接受邀请

受邀者必须使用接收邀请的电子邮件地址登录。接受邀请有两种方式：

- 点击邀请邮件中的 **Join workspace**，然后登录或创建账号。
- 登录 Console，打开工作区菜单，在 **Pending invitations** 下点击 **Join**。

如果受邀者当前登录的是其他账号，Console 会提示他们 **Sign out and continue**，改用受邀的邮箱登录。

## 管理待处理的邀请

待处理的邀请会显示在 Members 表格中，状态为 **Pending · Expires** 加上日期，或者 **Expired**。

| 操作     | 方法                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 重新发送 | **⋯ › Resend invitation**。发送一个有效期 7 天的新链接，旧链接随即失效。 |
| 撤销     | **⋯ › Remove...**。链接立即失效。                                       |

## 修改角色

打开成员所在行的角色菜单，选择 **Member**、**Admin** 或 **Owner**。

你只能授予不高于自己的角色，并且工作区始终至少保留一个所有者。请参阅[角色](/console/workspaces#roles)。

## 移除成员

1. 在成员所在行中点击 **⋯ › Remove...**。
2. 点击 **Remove member** 确认。

访问权限会立即撤销，之后你仍可以再次邀请对方。对方过去的用量会保留在工作区的报告中。

服务账号及其 API 密钥属于工作区，因此移除创建它们的成员不会撤销这些密钥。如有需要，请在 **Keys** 中撤销密钥。请参阅[服务账号](/console/api#service-accounts)。

## 成员详情

点击某个成员，可以查看其每月预算、使用的模型和客户端、用量图表以及请求日志。你还可以在这里设置该成员的[预算](/console/budgets#member-budgets)，并将其用量导出为 CSV。
