[OpenCode Console](https://opencode.ai/console) 是一项可选服务，无论你是独自使用 OpenCode 还是团队协作，它都能带来更多便利。

- 通过[工作区](/console/workspaces)与你的[团队](/console/members)共享访问权限
- 提供专有模型和开源模型的[推理](/console/models)服务
- 通过 Console 网关接入你自己的[提供商](/console/providers)账号
- 用量跟踪和[预算](/console/budgets)控制
- 部署团队范围的策略，统一控制 OpenCode 的行为
- [网页搜索](/console/websearch)
- [OpenCode Go 和 Go Plus](/console/go)：每月 10 美元和 40 美元的订阅，用于访问开源模型

## 快速开始

使用 Console 不需要组建团队。每个账号都自带一个 **Personal** 工作区，其中只有你一个成员。

1. 登录 [Console](https://opencode.ai/console)。
2. 订阅 [Go](/console/go)、充值[额度](/console/billing#add-credits)，或接入一个[提供商](/console/providers)。
3. 在 OpenCode 中运行 `/connect` 并选择该工作区。
4. （可选）[邀请](/console/members#invite-members)你的团队成员。

```text
/connect
```

## 策略

**Policies** 页面中的 Providers 和 Tools 规则会作用于连接到该工作区的所有 OpenCode V2 客户端。这些规则以[策略](/policies#console)语句的形式下发，优先级高于成员自己的配置，并在大约一分钟内生效。
