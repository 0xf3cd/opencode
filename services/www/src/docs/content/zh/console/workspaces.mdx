工作区承载着 [Console](https://opencode.ai/console) 中的一切：成员、额度、预算、提供商、策略和服务账号。用量和计费都按工作区统计。

工作区可以只有一名成员。你可以独自使用额度、[自己的提供商](/console/providers)、预算和 [Go](/console/go)，等到需要时再[邀请成员](/console/members)。

## 你的第一个工作区

注册时，Console 会创建一个名为 **Personal** 的工作区，你是它的所有者，也是唯一的成员。如果你是通过邀请注册的，则会直接加入发出邀请的工作区，不会创建 Personal 工作区。

## 创建工作区

1. 打开顶部栏中的工作区菜单。
2. 点击 **Create Workspace**。
3. 输入 **Workspace name**，然后点击 **Create**。

你会成为新工作区的所有者。

## 切换工作区

在工作区菜单中选择另一个工作区即可。Console 会让你停留在同一个页面，因此在 `/acme/members` 上切换时，会打开另一个工作区的 Members 页面。

待处理的邀请显示在同一菜单的顶部。请参阅[成员](/console/members#accept-an-invitation)。

## 重命名工作区

所有者和管理员可以在 **Settings › General** 中重命名工作区。修改 **Workspace name** 后，离开输入框时会自动保存。该名称仅用于显示。

## 连接 OpenCode

在 OpenCode 中运行 `/connect`，然后在浏览器中选择工作区。之后 OpenCode 就会使用该工作区的模型、策略和预算。

```text
/connect
```

再次运行 `/connect` 可以将 OpenCode 切换到另一个工作区。工作区[策略](/policies#console)会替换为新工作区的策略，断开连接时则会被清除。

## 角色

每个成员都有一个角色。新成员加入时的角色始终是 **Member**。

| 角色   | 权限                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| Member | 使用 OpenCode，查看自己的用量、日志和预算。                                            |
| Admin  | 拥有 Member 的所有权限，还可以管理成员、计费、预算、提供商、策略、服务账号和设置。     |
| Owner  | 拥有 Admin 的所有权限，还可以授予 Owner 角色和删除工作区。                             |

Member 只能看到 **Overview**、**Logs**、**Leaderboard**（仅当其对成员可见时）以及 **Settings › Account**。

### 角色规则

- 一个工作区可以有多个所有者，并且始终至少保留一个。
- 你不能分配高于自己的角色，因此只有所有者才能将他人设为所有者。
- 你不能修改自己的角色。

### 转移所有权

1. 以所有者身份打开 **Members**，将新所有者的角色设为 **Owner**。
2. 请新所有者将你的角色改为 **Admin** 或 **Member**。

## 删除工作区

只有所有者才能删除工作区，并且前提是他们至少还属于另一个工作区。

1. 打开 **Settings › General**，点击 **Delete workspace**。
2. 勾选所有确认项。
3. 点击 **Delete workspace** 确认删除。

删除会立即生效，且无法撤销：

- 成员会立即失去访问权限。
- 所有服务账号 API 密钥和待处理的邀请都会被撤销。
- 自动充值停止。
- 生效中的 Go 订阅终止。
- 剩余的额度余额作废。

<Callout type="warning">付款处理期间无法删除工作区，请几分钟后再试。</Callout>

## 离开工作区

成员不能自行退出。请联系所有者或管理员[将你移除](/console/members#remove-a-member)。
