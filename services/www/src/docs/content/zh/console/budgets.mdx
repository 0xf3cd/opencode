---
title: "预算"
description: "为工作区、成员和服务账号设置每月支出上限。"
---

预算用于限制工作区每月的支出。所有者和管理员可以在 **Members** 和 **Keys** 页面的 **Budget limits** 面板中进行设置。

## 预算层级

| 预算             | 适用范围                       | 设置位置                                           |
| ---------------- | ------------------------------ | -------------------------------------------------- |
| 工作区           | 工作区内所有人的总支出         | **Members** 或 **Keys › Monthly workspace budget** |
| 默认用户         | 未设置自定义上限的每位成员     | **Members › Monthly default user budget**          |
| 自定义用户       | 单个成员                       | **Members** 表格或成员页面                         |
| 默认服务账号     | 未设置自定义上限的每个服务账号 | **Keys › Monthly default service account budget**  |
| 自定义服务账号   | 单个服务账号                   | 服务账号页面                                       |

请求必须同时满足工作区预算和个人预算的限制。如果没有设置任何预算，支出不受限制。

## 工作区预算

工作区支出达到工作区预算后，所有人的请求都会被拦截。

1. 打开 **Members** 或 **Keys**。
2. 在 **Budget limits** 中点击 **Monthly workspace budget**。
3. 以美元为单位输入 **Workspace limit**，然后点击 **Save**。

## 成员预算

默认用户预算适用于所有未设置自定义上限的成员。你可以在 **Monthly default user budget** 中设置。

可以通过以下任一方式为某个成员设置自定义上限：

- 点击该成员在 **Members** 表格中的 **Limit** 单元格，然后输入金额。
- 打开该成员的页面，在 **Monthly Budget** 下点击 **Set User Budget**。

自定义上限会在 Members 表格中高亮显示。清除自定义上限后，该成员会恢复使用默认预算，成员页面上会显示 **Using Default**。

## 服务账号预算

服务账号的预算设置方式相同。你可以在 **Keys** 页面设置 **Monthly default service account budget**，也可以打开某个服务账号，点击 **Set Service Account Budget**。

## 金额与重置

- 金额以美元为单位，最多保留两位小数。
- 预算在每月 1 日 00:00 UTC 重置。
- 设为 `$0` 的预算会拦截所有计入预算的支出。

## 计入范围

| 支出                                                           | 是否计入预算         |
| -------------------------------------------------------------- | -------------------- |
| 付费 Console 模型                                              | 是                   |
| 已设置价格的[自有提供商](/console/providers)模型               | 是，按配置的价格计算 |
| [网页搜索](/console/websearch)                                 | 是                   |
| 免费模型                                                       | 否                   |
| 套餐范围内的 [Go](/console/go) 用量                            | 否                   |
| 使用额度支付的 Go 额外用量                                     | 是                   |

## 达到预算后

在预算重置或管理员提高预算之前，新请求都会以 HTTP `429` 失败。响应中不会说明达到的是哪一项预算。

```text
Upstream request failed: Account budget exceeded
```

预算在请求开始时检查。正在进行中的请求会继续完成，因此最终支出可能会略微超出上限。

## 跟踪支出

每位成员都可以在 **Overview** 中查看自己的预算：剩余金额、已用金额和重置日期。

对于成员数多于一人的工作区，所有者和管理员还可以看到 **Usage**。它按天、模型和人员细分成本，点击 **Export usage** 按钮可以将最近 7 天、30 天或 90 天的每日汇总下载为 CSV。

## 自动化管理预算

使用 [Budgets API](/console/api/budgets)，可以在你自己的工具中读取每位成员的预算并设置自定义上限。
