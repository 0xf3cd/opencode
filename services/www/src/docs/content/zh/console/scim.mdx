---
title: "目录同步"
description: "从 Okta、Microsoft Entra ID 或任何 SCIM 2.0 身份提供商自动添加和移除工作区成员。"
---

目录同步（SCIM 2.0）会在你于身份提供商中分配用户时将其添加到工作区，并在取消分配时撤销其访问权限。角色仍在 Console 中管理。

```text
https://opencode.ai/console/scim/v2
```

## 开始之前

- 为工作区设置 [SSO](/console/sso)。
- [验证](/console/sso#verify-email-domains)成员登录时使用的所有邮箱域名。目录同步只会添加已验证域名下的用户；其他人请通过 [Members](/console/members) 邀请。

## 创建令牌

1. 打开 **Settings › Security**，在 **Directory sync** 下点击 **Set up**。
2. 复制 **SCIM base URL** 和令牌。令牌只会显示一次，请将其保存在密钥管理工具中。

身份提供商会在每个请求中发送该令牌。

```text
Authorization: Bearer <token>
```

## 连接身份提供商

### Okta

1. 添加 **SCIM 2.0 Test App (Header Auth)** 应用。
2. 设置 base URL，并在 **API Token** 中输入 `Bearer ` 加上令牌。
3. 启用 **Create Users**、**Update User Attributes** 和 **Deactivate Users**。保持 **Import Groups** 和密码同步处于关闭状态。

### Microsoft Entra ID

1. 在你的企业应用中打开 **Provisioning**，将模式设为 **Automatic**。
2. 将 base URL 填入 **Tenant URL**，将令牌填入 **Secret Token**。
3. 分配用户和组，然后开始预配。

### 其他提供商

使用支持请求头令牌认证的 SCIM 2.0 应用，并将其指向 base URL。Console 支持 `/Users` 和 `/Groups` 端点。

建议先分配一名测试用户。收到第一个请求后，**Directory sync** 会显示 **Connected to your identity provider**。

## 同步内容

| 在身份提供商中      | 在 Console 中                                                     |
| ------------------- | ----------------------------------------------------------------- |
| 分配用户            | 以 **Member** 身份添加。已有成员保留原有角色。                    |
| 更新姓名            | 更新个人资料。                                                    |
| 取消分配或停用      | 暂停访问权限，并显示为 **Deactivated**。其创建的 API 密钥会被撤销。 |
| 重新分配            | 恢复访问权限。已撤销的密钥仍保持撤销状态。                        |
| 删除                | 从工作区中移除。其账号和其他工作区不受影响。                      |

- 目录同步不会更改角色和电子邮件地址。
- 最后一个所有者无法被停用或删除。
- 订阅了 [Go](/console/go) 的工作区无法通过目录同步添加成员。

## 组

推送组可以为组内成员打上标签，例如使用 Okta 的 **Push Groups** 或 Entra 的组分配。请先分配用户，再推送他们所在的组。

```text
Platform Admins  →  platform-admins
```

每个组都会为其成员打上一个以该组命名的标签。在 **Settings › Security › Group tags** 中，你可以重命名标签、将多个组指向同一个标签，或者停止为某个组打标签。成员离开组后，对应的标签会被移除。

## 轮换令牌

1. 点击 **New token**，并在身份提供商中配置新令牌。
2. 等待新令牌显示最近使用时间。
3. 撤销旧令牌。

撤销令牌会停止后续更新，但不会改变现有成员。删除 SSO 连接会撤销所有令牌。

## SSO 与目录同步

工作区一旦签发过令牌，SSO 就不再[自动添加成员](/console/sso#automatic-membership)。即使之后撤销了令牌，成员资格仍由目录决定。
