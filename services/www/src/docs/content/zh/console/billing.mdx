description: "在 OpenCode Console 中充值额度、设置自动充值、管理付款方式和下载账单。"
---

无论团队规模大小，Console 都免费使用，不收取席位费。你只需为用量付费，费用从覆盖整个工作区的预付额度中扣除。所有者和管理员在 **Settings › Billing** 中管理计费。

通过[自有提供商](/console/providers)产生的用量由提供商计费，而不是由 Console 计费。

## 添加付款方式

1. 打开 **Settings › Billing**。
2. 在 **Payment methods** 下点击 **Add**。
3. 选择一种付款方式，并完成 Stripe 设置。

支持的付款方式：

- 银行卡
- Link
- Alipay（支付宝）
- UPI
- WeChat Pay（微信支付）

使用 **⋯ › Make default** 选择用于自动扣款的付款方式。移除某种付款方式后，使用该方式的自动充值和 Go 续费可能会停止。

## 充值额度

1. 在 **Credits** 下点击 **Add credits**。
2. 选择 $10、$50 或 $100，或者选择 **Other** 并输入金额。
3. 选择付款方式，然后点击 **Confirm and pay**。

另外会加收 4.6% + $0.31 的手续费，因此购买 $50 实际支付 $52.61，余额会完整增加 $50。

## 自动充值

自动充值会在余额不足时自动购买额度。

1. 在 **Auto-recharge** 下点击 **Add rule**。
2. 设置触发扣款的余额阈值和充值金额。
3. 点击 **Save**。

自动充值会从默认付款方式扣款，并包含手续费。如果扣款失败，自动充值会关闭，直到你重新设置。

## 查看余额

所有者和管理员可以在 **Overview** 的 **Credits** 卡片中查看余额。

## 额度用完后

余额归零后，付费请求会以 HTTP `402` 失败。余额永远不会变为负数。

```text
Upstream request failed: Insufficient account funds
```

## 账单记录

每笔付款都会显示在 **Invoices** 中，包含其状态以及 **Download invoice** 或 **View receipt** 链接。

| 条目             | 产生原因           |
| ---------------- | ------------------ |
| Balance top-up   | 充值额度           |
| Automatic top-up | 自动充值           |
| Go subscription  | 订阅 Go            |
| Go renewal       | Go 每月续费        |
| Monthly Usage    | 按账单结算         |

## 按账单结算

签订了信用协议的工作区可以按月开具账单结算，无需预先购买额度。如需开通，请联系支持团队。

- 用量从信用额度中扣除，而不是从预付余额中扣除。
- 每月的账单在 1 日（UTC）开具，14 天后到期。
- 未付账单上会显示 **Pay now** 按钮。
- 达到信用额度上限或账单逾期时，请求会以 HTTP `402` 失败。

## Go

[OpenCode Go](/console/go) 订阅使用相同的付款方式，并显示在同一个账单列表中。在 **Overview** 的额度卡片上打开 **Extra usage**，即可在达到 Go 限额后改用额度付费。
