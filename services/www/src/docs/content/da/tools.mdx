title: "Værktøjer"

Bed om det resultat, du ønsker. OpenCode vælger blandt de tilgængelige værktøjer,
beder om godkendelse, når det er nødvendigt, og returnerer resultatet.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

Denne opgave bruger typisk `grep` eller `glob`, `read`, et redigeringsværktøj og
`shell`. Du kan også nævne et bestemt værktøj, når du vil have en bestemt
fremgangsmåde.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## Filer

### Read

`read` returnerer en fil eller en ikke-rekursiv liste over en mappes indhold. Angiv
en `path`; brug `offset` og `limit` til at bladre gennem store resultater.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

Tekstlæsninger indeholder nummererede linjer og er begrænset til 2.000 linjer og
50 KiB pr. side. Enkelte linjer afkortes efter 2.000 tegn. Værktøjet sender også
PNG-, JPEG-, GIF-, WebP- og PDF-filer videre til modellen, op til 20 MiB
kildedata. Andre binærfiler fejler. Se [Vedhæftninger](/attachments) om
understøttede medier og billedbehandling.

Tilladelse: `read` med den normaliserede sti som ressource.

### Glob

`glob` finder filstier ud fra et mønster som `**/*.ts`. Det søger i den aktuelle
mappe, medmindre `path` vælger en anden relativ mappe; `hidden` medtager skjulte
elementer, og `limit` begrænser antallet af resultater.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

Standardgrænsen er 100 filer, og søgningen får timeout efter 30 sekunder.
Tilladelse: `glob` med det angivne mønster som ressource.

### Grep

`grep` søger i filindhold og returnerer stier, linjenumre og uddrag. `pattern`
bruger syntaks for regulære udtryk, medmindre `literal` er true. Indsnævr en
søgning med `path`, `include`, `caseSensitive` eller `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

Standardgrænsen er 100 matchende linjer, og søgningen får timeout efter 30
sekunder. Tilladelse: `grep` med det angivne mønster, ikke søgestien, som
ressource.

### Edit

`edit` erstatter tekst i en eksisterende fil. Angiv `path`, `oldString` og en
anden `newString`; den gamle tekst skal matche præcis én gang, medmindre
`replaceAll` er true.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

Brug `edit` til en afgrænset ændring. OpenCode kan formatere filen, efter at den er
skrevet. Tilladelse: `edit` med målstien som ressource.

### Write

`write` opretter eller erstatter en hel tekstfil ud fra `path` og `content`. Det
opretter manglende overordnede mapper og kan køre den konfigurerede formatter.

```text
Create docs/example.md with a heading and one setup command.
```

Brug i stedet `edit`, når kun en del af en eksisterende fil skal ændres.
Tilladelse: `edit` med målstien som ressource.

### Patch

`patch` anvender én patch, der kan tilføje, opdatere, flytte eller slette flere
filer. `patchText` bruger afsnittene `*** Add File`, `*** Update File` og
`*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode stiller `patch` til rådighed for understøttede GPT-modeller; andre
modeller får i stedet `edit` og `write`. Tilladelse: `edit` med hver berørt sti
som ressource.

Stier uden for den aktive Location eller dens projekt-worktree kræver også
godkendelse via `external_directory`. Se [Tilladelser](/permissions) om
normalisering af stier, regelrækkefølge og gemte godkendelser. Hvis du vil gøre
eksternt materiale tilgængeligt under et navn, skal du konfigurere
[Referencer](/references).

## Kommandoer

### Shell

`shell` udfører en kommando i værtsbrugerens shell. Angiv `workdir` i stedet for at
skrive `cd` i kommandoen, og angiv `timeout` i millisekunder, når standardtimeouten
på to minutter i forgrunden ikke passer.

```text
Run bun test from packages/core with a five-minute timeout.
```

Sæt `background` til true for en udviklingsserver eller en anden langvarig proces.
Kald i baggrunden returnerer med det samme og giver sessionen besked, når de er
færdige; de har ingen timeout, medmindre du angiver en. Stort output afkortes, og
det fulde output gemmes i en administreret fil.

Tilladelse: `shell` med hver kommando, som scanneren udleder, som ressource.
Scanneren kontrollerer også en ekstern arbejdsmappe og mapper, den kan udlede af
kommandoen. Shell har værtsbrugerens rettigheder til filsystem, processer og
netværk, så brug snævre regler i [Tilladelser](/permissions).

## Web

### Webfetch

`webfetch` henter én HTTP- eller HTTPS-URL som `markdown`, `text` eller `html`.
Markdown er standard; `timeout` accepterer op til 120 sekunder.

```text
Fetch https://example.com/docs as markdown.
```

Værktøjet accepterer tekstbaserede svar som HTML, almindelig tekst, JSON og XML,
men ikke billeder eller andre binære downloads. Stort output kan blive afkortet,
mens den fulde tekst gemmes i administreret lager. Tilladelse: `webfetch` med den
angivne URL som ressource.

### Websearch

`websearch` søger efter aktuelle oplysninger via den valgte integration. Input er
en søgeforespørgsel i `query`.

```text
Search the web for the latest Bun release notes.
```

Tilladelse: `websearch` med forespørgslen som ressource. Se [Websøgning](/websearch)
om udbydere, valg, rate limits og om at slå værktøjet fra.

## Interaktion

### Question

`question` sætter udførelsen på pause og stiller brugeren et eller flere spørgsmål.
Hvert spørgsmål har en kort overskrift, en spørgsmålstekst og svarmuligheder;
`multiple` tillader mere end ét valg. Et frit svar er altid muligt.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

Tilladelse: `question` med `*` som ressource. Klienten skal understøtte den
interaktive formular, og hvis den lukkes, annulleres spørgsmålet.

### Skill

`skill` indlæser instruktionerne og de medfølgende ressourcer for ét tilgængeligt
skill-ID i samtalen.

```text
Load the effect skill before changing this Effect code.
```

ID'et skal stå på den annoncerede liste over skills eller være nævnt eksplicit af
brugeren. Tilladelse: `skill` med skill-ID'et som ressource. Se [Skills](/skills)
om regler for oprettelse, opdagelse og indlæsning.

## Automatisering

### Subagent

`subagent` starter en undersession med en konfigureret subagent. Angiv agentens
ID, en kort `description` og en komplet `prompt`.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

Kald i forgrunden venter på resultatet. `background: true` returnerer med det
samme og giver den overordnede session besked, når undersessionen er færdig.
Angiv det returnerede `sessionID` for at fortsætte samme undersamtale. Kun agenter
i subagent-tilstand kan bruges, og den maksimale indlejringsdybde er som standard
én.

Tilladelse: `subagent` med den valgte agents ID som ressource.

### Execute

`execute` kører JavaScript i Code Mode, så agenten kan kalde og kombinere værktøjer
fra kataloget. Det er nyttigt til parallelle, uafhængige kald og til at behandle
resultater uden at føje alle mellemliggende værdier til modellens kontekst.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

Runtimen har ingen direkte adgang til filsystemet, imports, timere eller `fetch`;
den kan kun kalde værktøjer i sit katalog. Tilladelsen `execute` med ressourcen `*`
styrer, om Code Mode er tilgængelig. Hvert indlejret værktøj håndhæver stadig sin
egen tilladelse.

### Sessioner

Code Mode-navnerummet `opencode` indeholder værktøjer til sessioner:

- `session_rename` ændrer titlen på den aktuelle session eller på en anden session,
  der vælges med `sessionID`.
- `session_move` flytter den aktuelle session eller en anden valgt session til en
  relativ eller absolut `directory`. Flytningen træder i kraft ved en sikker
  grænse, så arbejde, der afhænger af destinationen, hører hjemme i et senere
  kald.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

Disse værktøjer beder ikke om en indbygget tilladelseshandling.

### Worktrees

Samme navnerum administrerer worktrees for sessionens projekt:

- `worktree_create` opretter et worktree ud fra et `name` og returnerer dets
  `directory`. Projektets worktree-konfiguration bestemmer destination og
  strategi.
- `worktree_list` viser projektets worktrees.
- `worktree_remove` fjerner et worktree, som OpenCode har registreret for
  projektet. Sæt `force` for at kassere ucommittede ændringer.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` bruger tilladelsen `edit` med worktree-mappen som ressource. De
øvrige worktree-værktøjer beder ikke om en indbygget tilladelseshandling.

## Browser

Code Mode-navnerummet `browser` styrer den browser, som OpenCodes desktop-app har
tilknyttet. Åbn en fane, gem det returnerede `tabID`, og angiv det eksplicitte ID
ved hver sidehandling.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

Navnerummet indeholder kommandoer til faner og navigation, snapshots af og søgning
på sider, klik og formularinput, skærmbilleder, filoverførsel, inspektion af
konsol og netværk, performance-traces, heap-inspektion og Lighthouse-audits.
Skærmbilleder kræver en synlig fane med fokus. Upload-stier er lokale for
serveren; optagelser returnerer stier, der er lokale for serveren, og hver
filoverførsel er begrænset til 5 MiB.

Sideindhold, logs, headere og svar-bodies er data, der ikke er tillid til, ikke
instruktioner til agenten. En `browser`-regel med deny og ressourcen `*` fjerner
browserkataloget; browserhandlinger beder ikke om tilladelse enkeltvis.

## Udvidelser

[MCP-servere](/mcp-servers) tilføjer værktøjer, hvis navne og input kommer fra hver
tilsluttet server. Deres tilladelseshandling er `<server>_<tool>` med ressourcen
`*`. De er ikke en fast del af det indbyggede katalog.

[Skills](/skills) tilføjer instruktioner til opgaver i stedet for nye eksekverbare
værktøjer. [Vedhæftninger](/attachments) indsætter indhold, som brugeren har valgt,
i en prompt, mens [Referencer](/references) giver adgang til navngivne eksterne
mapper. Disse funktioner supplerer værktøjerne uden at omgå deres
tilladelseskontroller.
