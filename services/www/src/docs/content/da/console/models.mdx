OpenCode Console tilbyder en liste over modeller, der er testet og verificeret af OpenCode-teamet. Log ind, tilføj
kredit, og hent en API-nøgle for at bruge dem med OpenCode eller en anden kodningsagent.

Console fungerer som enhver anden udbyder i OpenCode. Den er **helt valgfri**, og du kan bruge en hvilken som helst
anden udbyder i stedet. Hvis du vil have et abonnement med inkluderet forbrug, kan du se [OpenCode Go](/console/go).

## Sådan fungerer det

1. Log ind i [Console](https://opencode.ai/console), tilføj dine faktureringsoplysninger og kredit, og kopier din API-nøgle.
2. Kør `/connect` i TUI'en, vælg OpenCode-udbyderen med betaling efter forbrug, og indsæt din API-nøgle.

   ```text
   /connect
   ```

3. Kør `/models` for at se de tilgængelige modeller og vælge en.

   ```text
   /models
   ```

Du betaler pr. anmodning og kan tilføje kredit til din konto.

### Jev

Jev er en System One-model fra TypeSafe AI til hurtige, strukturerede beslutninger. I stedet for at generere tekst evaluerer den en `state` ud fra typede spørgsmål og returnerer værdier og sandsynligheder, som din kode kan bruge direkte. Den understøtter ja/nej-spørgsmål (`noul`), multiple choice-spørgsmål (`choice`) og spørgsmål baseret på en bedømmelsesskala (`score`).

Brug din API-nøgle fra OpenCode Console med endpointet `https://opencode.ai/inference/v1/systemone`. Dette eksempel kontrollerer, om en supportanmodning haster:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Du kan stille flere spørgsmål i én anmodning. Jev evaluerer dem parallelt og returnerer hvert svar under det tilsvarende spørgsmåls-ID:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Brug `jev-1.13-free` i stedet for `jev-1.13` for at bruge den gratis model, der er tilgængelig i en begrænset periode. Se [dokumentationen fra TypeSafe AI](https://docs.typesafe.ai/) for detaljer om spørgsmålstyper og felter i svaret.

## Baggrund

Der findes mange modeller, men kun få fungerer godt som kodningsagenter. Udbydere varierer også i konfiguration,
ydeevne og kvalitet, så en model, du tilgår via en gateway som OpenRouter, kan opføre sig anderledes.

<Callout type="tip">Vi har testet en udvalgt gruppe af modeller og udbydere, der fungerer godt med OpenCode.</Callout>

For at opbygge dette katalog har vi:

1. Testet en udvalgt gruppe af modeller og talt med teamene bag dem om, hvordan de bedst køres.
2. Samarbejdet med udbydere for at sikre, at modellerne blev leveret korrekt.
3. Benchmarket hver kombination af model og udbyder for at nå frem til en liste, vi trygt kan anbefale.

Console er en AI-gateway, der giver dig adgang til disse modeller.

## Mål

Vi byggede Console for at:

1. **Benchmarke** de bedste modeller og udbydere til kodningsagenter.
2. Tilbyde muligheder af **højeste kvalitet** uden at forringe ydeevnen eller route til billigere udbydere.
3. Give **prisfald** videre ved at sælge til kostpris, kun med et tillæg, der dækker betalingsgebyrer.
4. Undgå **lock-in**: Brug Console med en hvilken som helst kodningsagent, eller brug en anden udbyder med OpenCode.
