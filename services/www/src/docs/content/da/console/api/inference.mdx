---

Inferens i Console leverer OpenAI-, Anthropic- og Gemini-kompatible API'er fra `https://opencode.ai/inference`. Send en
JSON-`POST`-anmodning til det endpoint, der matcher modellens API-familie.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.6",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## Godkendelse

Erstat `<token>` med en [nøgle til en tjenestekonto](/console/api#service-accounts), der er oprettet i
[Console](https://opencode.ai/console). Betalte modeller kræver headeren; gratis chatmodeller kan kaldes uden den.

```text
Authorization: Bearer <token>
```

## Endpoints

| API                     | Sti                                                       |
| ----------------------- | --------------------------------------------------------- |
| OpenAI Chat Completions | `/inference/openai/v1/chat/completions`                   |
| OpenAI Responses        | `/inference/openai/v1/responses`                          |
| Anthropic Messages      | `/inference/anthropic/v1/messages`                        |
| Gemini                  | `/inference/google/v1beta/models/<model>:generateContent` |

Hver model leveres af én API-familie. Se tabellen over [model-endpoints](/console/models#endpoints), eller hent den
aktuelle liste:

```bash
curl https://opencode.ai/inference/v1/models
```

### OpenAI Chat Completions

Åbne modeller som `kimi-k2.6`, `glm-5.1`, `minimax-m2.7` og de gratis modeller bruger Chat Completions API.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.1",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### OpenAI Responses

GPT-modeller bruger Responses API.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hi"
  }'
```

### Anthropic Messages

Claude- og Qwen-modeller bruger Messages API. `max_tokens` er påkrævet.

```bash
curl -X POST "https://opencode.ai/inference/anthropic/v1/messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Gemini

Gemini-modeller angiver modellen og metoden i stien. Erstat `:generateContent` med `:streamGenerateContent` for at
streame svaret.

```bash
curl -X POST "https://opencode.ai/inference/google/v1beta/models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```
