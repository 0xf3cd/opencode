Opret `.opencode/commands/review.md` for at gøre en prompt til `/review`:

```md title=".opencode/commands/review.md"
Review $ARGUMENTS for bugs and missing tests.
```

Kør den fra TUI'en med et mål:

```text
/review src/auth.ts
```

OpenCode sender `Review src/auth.ts for bugs and missing tests.` som en brugerprompt.

## Markdown

Læg globale kommandoer i `~/.config/opencode/commands/` og projektkommandoer i `.opencode/commands/`.

```text
~/.config/opencode/commands/review.md
.opencode/commands/review.md
```

Kun `.md`-filer findes. Indlejrede stier bliver til kommandonavne med `/` som skilletegn:

```md title=".opencode/commands/team/review.md"
Review $ARGUMENTS using the team's checklist.
```

Kør den indlejrede kommando som `/team/review src/auth.ts`. Den ældre mappe i ental, `command/`, findes også, men brug
`commands/` til nye filer.

Tilføj YAML-frontmatter, når kommandoen har brug for metadata. Den trimmede Markdown-brødtekst er altid promptskabelonen.

```md title=".opencode/commands/review.md"
---
description: Review code for correctness
agent: plan
model: anthropic/claude-sonnet-4-5#high
---

Review $ARGUMENTS. Report bugs first.
```

## JSON

Definer kommandoer under `commands` i en hvilken som helst JSON- eller JSONC-[konfigurationsfil](/config) til OpenCode.
Hver kommando kræver en `template`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "commands": {
    "review": {
      "description": "Review code for correctness",
      "template": "Review $ARGUMENTS. Report bugs first.",
    },
  },
}
```

## Felter

Markdown-frontmatter og JSON-poster accepterer de samme felter, bortset fra at Markdown får `template` fra filens
brødtekst.

| Felt | Påkrævet | Adfærd |
| --- | --- | --- |
| `template` | Kun JSON | Promptskabelon. |
| `description` | Nej | Tekst, der vises i kommandolister og ved søgning. |
| `agent` | Nej | Agent, der vælges, når kommandoen kører. |
| `model` | Nej | Tilsidesættelse af modellen i formatet `provider/model` eller `provider/model#variant`. |
| `subagent` | Nej | `true` kører i en undersession i baggrunden; `false` gennemtvinger den aktuelle session. |
| `subtask` | Nej | Forældet alias for `subagent`. |

Denne JSON-kommando angiver for eksempel alle de nuværende valgfrie felter:

```jsonc title="opencode.jsonc"
{
  "commands": {
    "audit": {
      "template": "Audit $ARGUMENTS.",
      "description": "Audit a package",
      "agent": "general",
      "model": "anthropic/claude-sonnet-4-5#high",
      "subagent": true,
    },
  },
}
```

Angiv ikke `template` i Markdown-frontmatter; brødteksten leverer den.

## Argumenter

Brug `$ARGUMENTS` til hele argumentstrengen, præcis som den blev indtastet.

```md title=".opencode/commands/component.md"
Create a typed React component named $ARGUMENTS.
```

For `/component Account Settings` bliver pladsholderen til `Account Settings`.

## Positioner

Brug `$1`, `$2` og højere tal til fortolkede positionelle argumenter. Enkelte eller dobbelte anførselstegn grupperer ord
og fjernes.

```md title=".opencode/commands/check.md"
Check $1. Focus on $2.
```

For `/check src/auth.ts "error handling"` bliver `$1` til `src/auth.ts`, og `$2` bliver til `error handling`.

Pladsholderen med det højeste tal opbruger sit argument og alt, hvad der kommer efter. Manglende positioner bliver til
tomme strenge.

```md title=".opencode/commands/compare.md"
Compare $1 with $2.
```

For `/compare api stable branch` sender OpenCode `Compare api with stable branch.`

## Fallback

Når en skabelon ikke har `$ARGUMENTS` eller en positionel pladsholder, tilføjer OpenCode argumenter, der ikke er tomme,
efter en tom linje.

```md title=".opencode/commands/explain.md"
Explain this code clearly.
```

For `/explain src/cache.ts` bliver prompten til:

```text
Explain this code clearly.

src/cache.ts
```

## Shell

Omslut en shell-kommando med `!` efterfulgt af backticks for at indsætte dens output, før prompten sendes.

```md title=".opencode/commands/review-diff.md"
Review this diff:

!`git diff --stat && git diff`
```

OpenCode kører hver blok med den konfigurerede shell på det aktive projekts placering og indsætter det samlede output.
Argumentpladsholdere udvides først:

```md title=".opencode/commands/history.md"
Summarize these commits:

!`git log --oneline -$1`
```

For `/history 5` modtager shellen `git log --oneline -5`. Placer ikke argumenter, du ikke har tillid til, i
shell-blokke.

<Callout type="warning">
  Shell-blokke kører, når OpenCode evaluerer kommandoen, uden for agentens tilladelsesflow for værktøjer. Brug kun
  kommandoer fra kilder, du har tillid til.
</Callout>

## Vedhæftninger

Gemte skabeloner udvider ikke `@path`; det forbliver almindelig prompttekst.

```md title=".opencode/commands/readme.md"
Review @README.md.
```

Hvis du vil vedhæfte en fil, så tilføj den via inputfeltet, når du kalder kommandoen. OpenCode bevarer disse
vedhæftninger, når den udvidede prompt sendes.

## Udførelse

Kommandoer udvider argumenter og shell-blokke, før de sender en varig brugerprompt. Som standard kører de i den aktuelle
session.

```md title=".opencode/commands/plan.md"
---
agent: plan
---

Plan $ARGUMENTS.
```

Når du kører `/plan migration`, skifter den aktuelle session til `plan`, før prompten sendes.

Valget af model følger disse regler:

1. En kommandos `model` tilsidesætter alle andre modeller.
2. Ellers tilsidesætter den konfigurerede model for kommandoens valgte agent den model, der er aktiv, når kommandoen
   kaldes.
3. Ellers forbliver sessionens aktuelle model aktiv.

Denne kommando vælger for eksempel både sin agent og en eksplicit model:

```md title=".opencode/commands/design.md"
---
agent: plan
model: openai/gpt-5#high
---

Design $ARGUMENTS.
```

## Baggrund

Sæt `subagent: true` for at køre en kommando i en undersession i baggrunden.

```md title=".opencode/commands/audit.md"
---
description: Audit changes
agent: general
subagent: true
---

Audit $ARGUMENTS for bugs and missing tests.
```

Den overordnede session forbliver tilgængelig og beholder sin agent og model. OpenCode sender undersessionens resultat
eller fejl tilbage til den overordnede session, når undersessionen er færdig.

| Værdi | Adfærd |
| --- | --- |
| `true` | Brug altid en undersession, også når den valgte agent har `mode: primary`. |
| `false` | Brug altid den aktuelle session, også når den valgte agent har `mode: subagent`. |
| Udeladt | Brug kun en undersession, når den valgte agent har `mode: subagent`. |

Undersessionen bruger kommandoens model, derefter den valgte agents model og derefter den overordnede sessions model.
Det ældre `subtask` accepteres stadig; hvis begge felter er angivet, vinder `subagent`.

```yaml
subagent: false
subtask: true
```

Dette eksempel kører i den aktuelle session, fordi `subagent` har forrang.

## Indlæsning

Markdown- og JSON-kommandoer deler ét register. Senere kilder erstatter tidligere kommandoer med samme navn.

```text
~/.config/opencode/commands/review.md   # Lower priority
.opencode/commands/review.md           # Replaces the global command
```

Projektkilder har forrang for globale kilder, og nærmere projektkilder har forrang for kilder i overordnede mapper. En
brugerdefineret definition kan også erstatte en tidligere indbygget kommando. OpenCode genindlæser kommandofiler og
ændringer i konfigurationen automatisk.

```md title=".opencode/commands/review.md"
Review only the staged changes: !`git diff --cached`
```

Når du gemmer filen, opdateres `/review` uden at genstarte OpenCode.
