---
title: "Tastaturgenveje"
---

Tilpas genveje i `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Brug en streng til én tast:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Adskil alternativer med kommaer:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Slå en genvej fra med `"none"` eller `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Brug et objekt til at styre hændelsesadfærd:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` er som standard `ctrl+x`. `<leader>` i en anden genvej henviser til den tast.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Ukendte kommando-ID'er afvises.

## Mini

Kommandoen `app.clear` virker kun i [`opencode mini`](/cli). Tryk på `ctrl+l` for at rydde den synlige skærm og tegne prompten igen. Terminalen beholder scrollback-historikken.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff-visning

Tryk på `d` (`diff.switch_source`) for at vælge **All**, **Committed**, **Uncommitted** eller **Last turn** (i en session), eller vælg **Base** for at ændre sammenligningsbranchen. Valgene huskes, indtil TUI'en afsluttes. Angiv det indledende omfang med [`diffs.source` i `cli.json`](/cli/config#diffs).

Genveje til rulning, sideskift og start/slut styrer altid diffet. Der er ingen tastaturgenvej til at skifte fokus: Klik på filer for at åbne dem, klik på mapper for at folde dem ud eller sammen, og brug musehjulet til at rulle i filtræet.

Brug `n` / `p` eller `alt+down` / `alt+up` (Option på macOS) til at skifte mellem filer. I diff-visningen navigerer Alt-genvejene mellem filer i stedet for sessionsfaner.

Tryk på `m` for at markere en fil som gennemgået og folde dens patch sammen. I visningen med alle filer kan du trykke på `m` igen for at fjerne markeringen og åbne patchen igen. Visningen med én fil går automatisk videre til næste fil, når du markerer en fil som gennemgået, men bliver på den sidste fil i stedet for at starte forfra. Fjernelse af markeringen går aldrig videre.

Højreklik på en fil i sidepanelet eller på dens diff-overskrift for at vælge **Mark complete** (eller **Mark incomplete**). Det ændrer den samme gennemgået-status som `m`. Markerer du en anden fil som færdig via dens menu, bliver den ikke valgt, og den fil, du er i gang med at læse, skifter ikke.

De alternative `diff.help`-genveje med Shift understøtter terminaler, der rapporterer Shift-tasten, når du trykker på `?`.

Vælg en kørende kommando under fanen **Shell**, og tryk på **Enter**, eller klik på den, for at se det opsamlede stdout og stderr.
Brug **↑/↓**, **Page Up/Down** eller **Home** til at rulle, **End** til at følge nyt output og **Esc** til at vende tilbage uden at stoppe kommandoen.
Visningen viser det seneste output og forbliver åben, når kommandoen er afsluttet. Output, der er omdirigeret til en fil, medtages ikke.
