title: "Web"
description: "Kør OpenCode i browseren."
---

OpenCode leveres med en webbrugerflade, som serveres af den samme server, der driver TUI'en. Den er tilgængelig som
standard og beskyttet med adgangskode.

## Adgang

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

  █▀▀▀▀▀█ ...
```

Når du åbner et link i en browser, logges browseren ind med en sessionscookie, og webbrugerfladen indlæses. Scanner du
QR-koden fra OpenCode-appen eller indsætter linket i appens felt til serveradresse, forbindes appen på samme måde.
Sessioner varer 30 dage. Hvis du ændrer serverens adgangskode, logges alle sessioner ud.

### Via SSH

Når serveren kun lytter på localhost, kan du videresende dens port fra din maskine og åbne det udskrevne link lokalt:

```bash
$ ssh -L 49374:127.0.0.1:49374 my-server
```

Som standard kører serveren på port 49374 og lytter kun på localhost. Du kan ændre denne konfiguration med kommandoen
`opencode service`.

### Fjernadgang

Hvis du vil forbinde hvor som helst fra, kan du parre via en fjernadresse fra
[OpenTunnel](https://github.com/anomalyco/opentunnel):

```bash
$ opencode pair --remote
```

Første gang kommandoen slår fjernadgang til, spørger den, før den fortsætter:

```text
▲  This will expose your OpenCode server to the internet.
│  Traffic is end-to-end encrypted, and access requires your server password.
│  To pair locally instead, run `opencode pair` without the --remote flag.
│
◆  Expose your server to the internet?
│  ● Yes / ○ No
```

Uden en interaktiv terminal fejler kommandoen, medmindre du angiver `--yes` for at acceptere. Når du har accepteret,
springer senere kørsler spørgsmålet over, også efter at fjernadgang er slået fra med `opencode service set remote false`.

## Konfiguration

Angiv en hvilken som helst indstilling med `opencode service set`:

```bash
# Listen on every network interface
$ opencode service set hostname 0.0.0.0

# Use a fixed port instead of the channel default
$ opencode service set port 49374

# Replace the generated password
$ opencode service set password "a-long-secret"

# Allow a web client served from another origin
$ opencode service set cors https://app.example.com,https://other.example.com

# Pass an environment variable to the server process
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Når du ændrer en indstilling, stoppes baggrundsserveren. Anvend den nye konfiguration med:

```bash
$ opencode service start
```

## Selvstændig

`opencode serve` kører den samme server i forgrunden i stedet for via den delte baggrundstjeneste.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
server listening on http://0.0.0.0:4096
server password <password>
```

Brug den når du vil:

- Køre OpenCode på en delt, altid tændt eller fjern vært og derefter forbinde klienter med `opencode --server <url>`.
- Styre værtsnavn, port og CORS-origins for en enkelt proces.
- Køre under en supervisor som systemd, Docker eller et andet miljø, der forventer en forgrundsproces.
- Have en dedikeret server i stedet for den delte baggrundstjeneste.

Forbind en klient til den med `--server`:

```bash
$ opencode --server http://127.0.0.1:4096
```
