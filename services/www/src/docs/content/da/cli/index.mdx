Kør CLI'en i et projekt for at åbne den terminalbaserede brugerflade i fuld skærm:

```bash
opencode
```

Angiv en mappe for at arbejde i et andet projekt:

```bash
opencode ~/code/my-project
```

Anbefalede terminaler:

- [Ghostty](https://ghostty.org)
- [WezTerm](https://wezterm.org)
- [Alacritty](https://alacritty.org)
- [Kitty](https://sw.kovidgoyal.net/kitty/)

Med truecolor-understøttelse vises temaer med de mest præcise farver. Terminaler uden truecolor bruger en tilnærmelse
ud fra den tilgængelige palet.

## Automatisering

Brug `opencode run` til at sende en prompt uden at åbne den interaktive brugerflade. Kommandoen er beregnet til scripts,
CI-jobs og andre workflows, der skal have modellens output direkte i terminalen.

```bash
opencode run "Explain this repository"
```

## Mini

Brug `opencode mini` til at starte OpenCodes minimale interaktive brugerflade i stedet for TUI'en i fuld skærm.

```bash
opencode mini
```

Kør `opencode mini --help` for at se indstillingerne for session, model, agent, prompt og genafspilning.

## Baggrundstjeneste

Som standard finder eller starter OpenCode én delt baggrundsserver til din brugerkonto. Alle lokale OpenCode-klienter
forbinder til den server, som ejer sessioner, konfiguration, integrationer, tilladelser og udførelse af værktøjer.

Brug `--standalone` for at køre med en privat server, eller `--server` for at forbinde til en bestemt server-URL:

```bash
opencode --standalone
opencode --server http://localhost:4096
```

Hvis CLI-kommandoer som standard skal bruge private servere i stedet for at starte den delte tjeneste, kan du slå
tjenesten fra:

```bash
opencode service set disabled true
opencode
```

Det stopper den kørende baggrundstjeneste. `--server` forbinder stadig til en eksplicit valgt server, og
`opencode service start` kan stadig starte den delte tjeneste eksplicit. Kør `opencode service unset disabled` for at
vende tilbage til automatisk brug af tjenesten. Parring kræver den delte tjeneste og er ikke tilgængelig, mens den er
slået fra.

Se [Fejlfinding](/troubleshooting) for diagnosticering af den delte tjeneste og [API-referencen](/api) for serverens
endpoints.

## Stier

Udskriv en bestemt lokal sti til brug i andre værktøjer:

```bash
opencode debug paths db
sqlite3 "$(opencode debug paths db)"
```

Den valgfri vælger accepterer `db`, `home`, `data`, `config`, `cache`, `state`, `tmp`, `bin`, `log` eller `repos` og
udskriver kun stien efterfulgt af et linjeskift. Databasestien tager højde for udgivelseskanalen og `OPENCODE_DB`.
Relative databasetilsidesættelser opløses i forhold til datamappen, og `:memory:` udskrives uændret. Kommandoen starter
ikke en server og åbner ikke databasen.

Udelad vælgeren for at vise alle stier med etiketter:

```bash
opencode debug paths
```

## Afinstallation

Se en forhåndsvisning af de filer og den installation, der bliver fjernet:

```bash
opencode uninstall --dry-run
```

Kør `opencode uninstall` for at bekræfte fjernelsen. OpenCode stopper registrerede baggrundstjenester og vedvarende
terminaler, før den globale cachemappe fjernes. Den deles af alle OpenCode-versioner og -kanaler. Sessionsdata,
konfiguration og tilstand fjernes aldrig.

- `--force` (`-f`) springer bekræftelsen over. Brug det til ikke-interaktiv fjernelse.
- Installationer via pakkehåndtering bruger den registrerede pakkehåndtering. Installationer via curl udskriver den sidste
  kommando, så du selv kan fjerne den eksekverbare fil.
