---
title: "Plugins"
---

Plugins, der er konfigureret i `opencode.json(c)` og har en TUI-komponent, indlæses automatisk af CLI'en. Se
[Byg plugins](/build/plugins) for at lære, hvordan du bygger plugins. Du behøver ikke at føje den samme pakke til
`cli.json`. CLI'en henter listen over aktive plugins fra den forbundne OpenCode-server, så det virker også, når serveren
kører eksternt.

Brug `cli.json` til plugins, der kun gælder CLI'en. De kører lokalt i terminalen og forbliver aktive, når CLI'en
forbinder til en fjernserver:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Posterne behandles i rækkefølge. Sæt `-` foran et ID eller jokertegn for at slå de matchende plugins fra:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Angiv plugin-indstillinger med objektformen:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode finder også plugins i den globale konfigurationsmappe og i projekters `.opencode`-mapper. Hvert plugin bruger
samme struktur som en publiceret pakke, med server- og TUI-indgangspunkter samlet.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Fundne plugins kan importere `@opencode/plugin/tui` direkte. OpenCode opløser pakken under kørslen. Se
[Byg CLI-plugins](/build/plugins/cli) for eksempler.
