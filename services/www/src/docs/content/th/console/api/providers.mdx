---

[ผู้ให้บริการ](/console/providers)ทุกรายที่เชื่อมต่อกับ Workspace จะให้บริการผ่าน gateway ของ Console ที่ URL ของตัวเอง OpenCode ใช้ URL นี้โดยอัตโนมัติหลังจาก `/connect` คุณเรียกใช้โดยตรงได้เพื่อใช้ผู้ให้บริการเดียวกันจากเครื่องมือของคุณเอง Console จะเพิ่มข้อมูลรับรองของผู้ให้บริการก่อนส่งต่อคำขอ secret ของผู้ให้บริการจึงไม่เคยออกไปนอก Workspace

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## URL ของผู้ให้บริการ

คัดลอก **Console API URL** จากหน้าของผู้ให้บริการใน **Providers**

```text
https://opencode.ai/inference/custom/<connection_id>
```

## การยืนยันตัวตน

แทนที่ `<token>` ด้วย[คีย์ของบัญชีบริการ](/console/api#service-accounts)ที่สร้างใน Console ซึ่ง Console จะสลับเป็นข้อมูลรับรองของการเชื่อมต่อก่อนส่งต่อคำขอ

```text
Authorization: Bearer <token>
```

Console ยังอ่านคีย์จาก `x-api-key`, `api-key` หรือ `x-goog-api-key` ได้ด้วย SDK ของผู้ให้บริการจึงใช้งานได้เมื่อชี้ไปที่ Console API URL

## Endpoint

ต่อท้าย Console API URL ด้วยพาธ API ของผู้ให้บริการ Console จะส่งต่อคำขอไปยัง base URL ของการเชื่อมต่อ และส่งการตอบกลับของผู้ให้บริการกลับมาโดยไม่เปลี่ยนแปลง

| รูปแบบ               | พาธ                               |
| -------------------- | --------------------------------- |
| Chat Completions     | `/chat/completions`               |
| Responses API        | `/responses`                      |
| Anthropic Compatible | `/messages`                       |
| Google Generative AI | `/models/<model>:generateContent` |

ส่ง ID โมเดลตามที่แสดงในหน้าผู้ให้บริการ หากโมเดลมี API ID ฝั่งต้นทาง (upstream) ที่ต่างออกไป Console จะเขียนใหม่ให้ คำขอสำหรับโมเดลที่ไม่ได้เปิดใช้งานในการเชื่อมต่อจะถูกปฏิเสธ

### Chat Completions

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Responses API

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Say hi"
  }'
```

### Anthropic Compatible

ต้องระบุ `max_tokens`

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Google Generative AI

โมเดลและเมธอดเป็นส่วนหนึ่งของพาธ แทนที่ `:generateContent` ด้วย `:streamGenerateContent` เพื่อสตรีมการตอบกลับ

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```

## การใช้งาน

คำขอจะนับรวมใน[งบประมาณ](/console/budgets)ตามราคาที่ตั้งไว้ในแต่ละโมเดล ส่วนค่าโทเค็นผู้ให้บริการจะเรียกเก็บจากคุณโดยตรง
