title: "งบประมาณ"

---

งบประมาณใช้จำกัดยอดใช้จ่ายของ Workspace ในแต่ละเดือน เจ้าของและผู้ดูแลระบบตั้งค่าได้จากแผง **Budget limits** ในหน้า **Members** และ **Keys**

## ระดับของงบประมาณ

| งบประมาณ                | มีผลกับ                                      | ตั้งค่าได้ที่                                         |
| ----------------------- | ------------------------------------------- | -------------------------------------------------- |
| Workspace               | ยอดใช้จ่ายรวมของทุกคนใน Workspace              | **Members** หรือ **Keys › Monthly workspace budget** |
| ผู้ใช้ (ค่าเริ่มต้น)          | สมาชิกแต่ละคนที่ไม่มีวงเงินกำหนดเอง                | **Members › Monthly default user budget**          |
| ผู้ใช้ (กำหนดเอง)          | สมาชิกหนึ่งคน                                   | ตาราง **Members** หรือหน้าสมาชิก                     |
| บัญชีบริการ (ค่าเริ่มต้น)     | บัญชีบริการแต่ละบัญชีที่ไม่มีวงเงินกำหนดเอง          | **Keys › Monthly default service account budget**  |
| บัญชีบริการ (กำหนดเอง)     | บัญชีบริการหนึ่งบัญชี                             | หน้าบัญชีบริการ                                     |

คำขอต้องอยู่ภายในทั้งงบประมาณของ Workspace และงบประมาณของผู้ใช้คนนั้นเอง หากไม่ได้ตั้งงบประมาณใดไว้ ยอดใช้จ่ายจะไม่จำกัด

## งบประมาณของ Workspace

เมื่อ Workspace ใช้จ่ายถึงงบประมาณแล้ว คำขอของทุกคนจะถูกบล็อก

1. เปิด **Members** หรือ **Keys**
2. ใน **Budget limits** คลิก **Monthly workspace budget**
3. ป้อน **Workspace limit** เป็น USD แล้วคลิก **Save**

## งบประมาณของสมาชิก

งบประมาณผู้ใช้เริ่มต้นมีผลกับสมาชิกทุกคนที่ไม่มีวงเงินกำหนดเอง ตั้งค่าได้ใน **Monthly default user budget**

กำหนดวงเงินเฉพาะให้สมาชิกคนหนึ่งได้จากที่ใดที่หนึ่งต่อไปนี้:

- คลิกเซลล์ **Limit** ในแถวของสมาชิกในหน้า **Members** แล้วป้อนจำนวนเงิน
- เปิดหน้าสมาชิกแล้วคลิก **Set User Budget** ใต้ **Monthly Budget**

วงเงินกำหนดเองจะถูกไฮไลต์ในตาราง Members ล้างวงเงินกำหนดเองเพื่อให้สมาชิกกลับไปใช้ค่าเริ่มต้น จากนั้นหน้าสมาชิกจะแสดง **Using Default**

## งบประมาณของบัญชีบริการ

บัญชีบริการทำงานแบบเดียวกัน ตั้งค่า **Monthly default service account budget** ในหน้า **Keys** หรือเปิดบัญชีบริการแล้วคลิก **Set Service Account Budget**

## จำนวนเงินและการรีเซ็ต

- จำนวนเงินเป็นดอลลาร์สหรัฐ มีทศนิยมได้ไม่เกินสองตำแหน่ง
- งบประมาณจะรีเซ็ตในวันที่ 1 ของทุกเดือน เวลา 00:00 UTC
- งบประมาณ `$0` จะบล็อกยอดใช้จ่ายทั้งหมดที่นับรวมในงบประมาณ

## สิ่งที่นับรวม

| ยอดใช้จ่าย                                                            | นับรวมในงบประมาณ             |
| ------------------------------------------------------------------- | ---------------------------- |
| โมเดลแบบชำระเงินของ Console                                          | ใช่                          |
| โมเดลจาก[ผู้ให้บริการของคุณเอง](/console/providers)ที่ตั้งราคาไว้          | ใช่ ตามราคาที่กำหนดค่าไว้        |
| [การค้นหาเว็บ](/console/websearch)                                     | ใช่                          |
| โมเดลฟรี                                                             | ไม่                          |
| การใช้งาน [Go](/console/go) ภายในแผน                                  | ไม่                          |
| การใช้งาน Go ส่วนเกินที่ชำระจากเครดิต                                   | ใช่                          |

## เมื่อใช้ถึงงบประมาณ

คำขอใหม่จะล้มเหลวด้วย HTTP `429` จนกว่างบประมาณจะรีเซ็ตหรือผู้ดูแลระบบเพิ่มงบประมาณ การตอบกลับจะไม่ระบุว่าใช้ถึงงบประมาณใด

```text
Upstream request failed: Account budget exceeded
```

ระบบตรวจสอบงบประมาณเมื่อคำขอเริ่มต้น คำขอที่กำลังดำเนินการอยู่จะทำงานจนเสร็จ ยอดใช้จ่ายจึงอาจเกินวงเงินไปเล็กน้อย

## ติดตามยอดใช้จ่าย

สมาชิกแต่ละคนจะเห็นงบประมาณของตนเองใน **Overview** ได้แก่ ยอดคงเหลือ ยอดที่ใช้ไป และวันที่รีเซ็ต

เจ้าของและผู้ดูแลระบบของ Workspace ที่มีสมาชิกมากกว่าหนึ่งคนจะเห็น **Usage** ด้วย ซึ่งแจกแจงค่าใช้จ่ายตามวัน โมเดล และผู้ใช้ ส่วนปุ่ม **Export usage** จะดาวน์โหลดยอดรวมรายวันของ 7, 30 หรือ 90 วันล่าสุดเป็น CSV

## จัดการงบประมาณอัตโนมัติ

ใช้ [Budgets API](/console/api/budgets) เพื่ออ่านงบประมาณของสมาชิกทุกคนและตั้งวงเงินกำหนดเองจากเครื่องมือของคุณเอง
