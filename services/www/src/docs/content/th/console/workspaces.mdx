Workspace เก็บทุกอย่างใน [Console](https://opencode.ai/console) ไว้ ได้แก่ สมาชิก เครดิต งบประมาณ ผู้ให้บริการ นโยบาย และบัญชีบริการ (service account) การใช้งานและการเรียกเก็บเงินติดตามแยกตาม Workspace

Workspace มีสมาชิกเพียงคนเดียวก็ได้ คุณใช้เครดิต [ผู้ให้บริการของคุณเอง](/console/providers) งบประมาณ และ [Go](/console/go) ได้ด้วยตัวเอง แล้วค่อย[เชิญสมาชิก](/console/members)เมื่อจำเป็น

## Workspace แรกของคุณ

Console จะสร้าง Workspace ชื่อ **Personal** เมื่อคุณสมัครใช้งาน โดยมีคุณเป็นเจ้าของและสมาชิกเพียงคนเดียว หากคุณสมัครจากคำเชิญ คุณจะเข้าร่วม Workspace ที่เชิญมาแทน และจะไม่มีการสร้าง Workspace Personal

## สร้าง Workspace

1. เปิดเมนู Workspace ในแถบด้านบน
2. คลิก **Create Workspace**
3. ป้อน **Workspace name** แล้วคลิก **Create**

คุณจะเป็นเจ้าของ Workspace ใหม่นั้น

## สลับ Workspace

เลือก Workspace อื่นจากเมนู Workspace Console จะพาคุณไปยังหน้าเดิม ดังนั้นการสลับจาก `/acme/members` จะเปิดหน้า Members ของ Workspace อีกแห่ง

คำเชิญที่รอดำเนินการจะแสดงที่ด้านบนของเมนูเดียวกัน ดู[สมาชิก](/console/members#accept-an-invitation)

## เปลี่ยนชื่อ Workspace

เจ้าของและผู้ดูแลระบบเปลี่ยนชื่อ Workspace ได้ใน **Settings › General** แก้ไข **Workspace name** แล้วการเปลี่ยนแปลงจะบันทึกเมื่อคุณออกจากฟิลด์ ชื่อนี้ใช้สำหรับแสดงผลเท่านั้น

## เชื่อมต่อ OpenCode

รัน `/connect` ใน OpenCode แล้วเลือก Workspace ในเบราว์เซอร์ จากนั้น OpenCode จะใช้โมเดล นโยบาย และงบประมาณของ Workspace นั้น

```text
/connect
```

รัน `/connect` อีกครั้งเพื่อสลับ OpenCode ไปยัง Workspace อื่น [นโยบาย](/policies#console)ของ Workspace จะถูกแทนที่ด้วยนโยบายของ Workspace ใหม่ และจะถูกล้างเมื่อคุณยกเลิกการเชื่อมต่อ

## บทบาท

สมาชิกแต่ละคนมีบทบาทเดียว สมาชิกใหม่จะเข้าร่วมในบทบาท **Member** เสมอ

| บทบาท  | สิ่งที่ทำได้                                                                                                          |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | ใช้ OpenCode ดูการใช้งาน ล็อก และงบประมาณของตนเอง                                                                    |
| Admin  | ทุกอย่างที่ Member ทำได้ รวมถึงจัดการสมาชิก การเรียกเก็บเงิน งบประมาณ ผู้ให้บริการ นโยบาย บัญชีบริการ และการตั้งค่า          |
| Owner  | ทุกอย่างที่ Admin ทำได้ รวมถึงมอบบทบาท Owner และลบ Workspace                                                         |

สมาชิกจะเห็นเฉพาะ **Overview**, **Logs**, **Leaderboard** (เมื่อตั้งให้สมาชิกมองเห็น) และ **Settings › Account**

### กฎของบทบาท

- Workspace มีเจ้าของได้หลายคน และจะต้องมีเจ้าของอย่างน้อยหนึ่งคนเสมอ
- คุณมอบบทบาทที่สูงกว่าบทบาทของตนเองไม่ได้ ดังนั้นมีเพียงเจ้าของเท่านั้นที่แต่งตั้งผู้อื่นเป็นเจ้าของได้
- คุณเปลี่ยนบทบาทของตนเองไม่ได้

### โอนความเป็นเจ้าของ

1. ในฐานะเจ้าของ ให้เปิด **Members** แล้วตั้งบทบาทของเจ้าของคนใหม่เป็น **Owner**
2. ขอให้เจ้าของคนใหม่เปลี่ยนบทบาทของคุณเป็น **Admin** หรือ **Member**

## ลบ Workspace

เฉพาะเจ้าของเท่านั้นที่ลบ Workspace ได้ และต้องเป็นสมาชิกของ Workspace อื่นอย่างน้อยหนึ่งแห่งด้วย

1. เปิด **Settings › General** แล้วคลิก **Delete workspace**
2. ทำเครื่องหมายยอมรับทุกข้อ
3. คลิก **Delete workspace** เพื่อยืนยัน

การลบจะมีผลทันทีและย้อนกลับไม่ได้:

- สมาชิกจะเสียสิทธิ์เข้าถึงทันที
- คีย์ API ของบัญชีบริการทั้งหมดและคำเชิญที่รอดำเนินการจะถูกเพิกถอน
- การเติมเงินอัตโนมัติจะหยุด
- การสมัครสมาชิก Go ที่ใช้งานอยู่จะสิ้นสุดลง
- ยอดเครดิตคงเหลือทั้งหมดจะถูกริบ

<Callout type="warning">ไม่สามารถลบได้ระหว่างที่มีการชำระเงินกำลังดำเนินการ โปรดลองอีกครั้งในอีกไม่กี่นาที</Callout>

## ออกจาก Workspace

สมาชิกนำตนเองออกจาก Workspace ไม่ได้ ให้ขอเจ้าของหรือผู้ดูแลระบบ[นำคุณออก](/console/members#remove-a-member)
