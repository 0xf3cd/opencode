OpenCode Console มีรายการโมเดลที่ทีม OpenCode ทดสอบและตรวจสอบแล้ว ลงชื่อเข้าใช้ เติมเครดิต แล้วรับคีย์ API เพื่อใช้โมเดลเหล่านี้กับ OpenCode หรือเอเจนต์เขียนโค้ดอื่น

Console ทำงานเหมือนผู้ให้บริการอื่น ๆ ใน OpenCode และเป็น**ตัวเลือกเสริมทั้งหมด** คุณจะใช้ผู้ให้บริการรายอื่นแทนก็ได้ หากต้องการการสมัครสมาชิกที่รวมโควตาการใช้งานไว้แล้ว ดู [OpenCode Go](/console/go)

## วิธีการทำงาน

1. ลงชื่อเข้าใช้ [Console](https://opencode.ai/console) เพิ่มข้อมูลการเรียกเก็บเงินและเครดิต แล้วคัดลอกคีย์ API
2. รัน `/connect` ใน TUI เลือกผู้ให้บริการ OpenCode แบบจ่ายตามการใช้งาน แล้ววางคีย์ API

   ```text
   /connect
   ```

3. รัน `/models` เพื่อดูโมเดลที่ใช้ได้และเลือกโมเดล

   ```text
   /models
   ```

ระบบจะเรียกเก็บเงินเป็นรายคำขอ และคุณเติมเครดิตเข้าบัญชีได้

แพ็กเกจ AI SDK เหล่านี้มีไว้สำหรับแอปพลิเคชันที่เรียก endpoint โดยตรง หากต้องการเลือก[โมเดล](/models)ใน OpenCode ให้ใช้รูปแบบ `opencode/<model-id>`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode/gpt-5.5",
}
```

### รายการโมเดล

ดึงรายการโมเดลที่ใช้ได้ทั้งหมดพร้อมเมทาดาทาจาก endpoint ของโมเดล:

```bash
curl https://opencode.ai/inference/v1/models
```

### Jev

Jev เป็นโมเดล System One จาก TypeSafe AI สำหรับการตัดสินใจที่รวดเร็วและมีโครงสร้าง แทนที่จะสร้างข้อความ Jev จะประเมิน `state` เทียบกับคำถามที่กำหนดชนิดไว้ แล้วส่งค่าและความน่าจะเป็นที่โค้ดของคุณนำไปใช้ได้ทันที รองรับคำถามแบบใช่/ไม่ใช่ (`noul`) แบบหลายตัวเลือก (`choice`) และแบบให้คะแนนตามเกณฑ์ (`score`)

ใช้คีย์ API ของ OpenCode Console กับ endpoint `https://opencode.ai/inference/v1/systemone` ตัวอย่างนี้ตรวจสอบว่าคำขอความช่วยเหลือเป็นเรื่องเร่งด่วนหรือไม่:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

ถามหลายคำถามในคำขอเดียวได้ Jev จะประเมินคำถามเหล่านั้นแบบขนาน และส่งคำตอบแต่ละข้อกลับมาภายใต้ ID ของคำถามที่ตรงกัน:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

ใช้ `jev-1.13-free` แทน `jev-1.13` เพื่อใช้โมเดลฟรีที่เปิดให้ใช้ในระยะเวลาจำกัด ดูรายละเอียดเกี่ยวกับชนิดคำถามและฟิลด์ในการตอบกลับได้ที่[เอกสารของ TypeSafe AI](https://docs.typesafe.ai/)

## สำหรับทีม

แชร์โมเดลของ Console กับทีมได้จาก[Workspace](/console/workspaces) เจ้าของและผู้ดูแลระบบสามารถ[เชิญสมาชิก](/console/members) เลือกโมเดลที่จะเปิดใช้จากแท็บ **Models** ตั้ง[งบประมาณ](/console/budgets) และเชื่อมต่อ[ผู้ให้บริการของตนเอง](/console/providers)ได้

## ที่มา

มีโมเดลให้เลือกมากมาย แต่มีเพียงไม่กี่โมเดลที่ทำงานได้ดีในฐานะเอเจนต์เขียนโค้ด ผู้ให้บริการแต่ละรายยังแตกต่างกันทั้งด้านการกำหนดค่า ประสิทธิภาพ และคุณภาพ ดังนั้นโมเดลเดียวกันที่เข้าถึงผ่าน gateway อย่าง OpenRouter อาจให้ผลลัพธ์ต่างออกไป

<Callout type="tip">เราได้ทดสอบโมเดลและผู้ให้บริการกลุ่มหนึ่งที่คัดเลือกมาแล้วว่าทำงานได้ดีกับ OpenCode</Callout>

ในการสร้างแคตตาล็อกนี้ เราได้:

1. ทดสอบโมเดลกลุ่มหนึ่งที่คัดเลือกมา และพูดคุยกับทีมผู้พัฒนาถึงวิธีรันโมเดลให้ได้ผลดีที่สุด
2. ทำงานร่วมกับผู้ให้บริการเพื่อให้แน่ใจว่าโมเดลให้บริการได้อย่างถูกต้อง
3. ทำ benchmark ทุกคู่โมเดล/ผู้ให้บริการ เพื่อได้รายการที่เรามั่นใจที่จะแนะนำ

Console เป็น AI gateway ที่ให้คุณเข้าถึงโมเดลเหล่านี้

## เป้าหมาย

เราสร้าง Console เพื่อ:

1. **Benchmark** โมเดลและผู้ให้บริการที่ดีที่สุดสำหรับเอเจนต์เขียนโค้ด
2. มอบตัวเลือกที่มี**คุณภาพสูงสุด** โดยไม่ลดประสิทธิภาพหรือส่งต่อไปยังผู้ให้บริการที่ราคาถูกกว่า
3. ส่งต่อ**ราคาที่ลดลง**ให้ผู้ใช้ด้วยการขายในราคาต้นทุน โดยบวกเพิ่มเฉพาะค่าธรรมเนียมการชำระเงินเท่านั้น
4. **ไม่ผูกมัด**: ใช้ Console กับเอเจนต์เขียนโค้ดตัวใดก็ได้ หรือใช้ผู้ให้บริการรายอื่นกับ OpenCode ก็ได้
