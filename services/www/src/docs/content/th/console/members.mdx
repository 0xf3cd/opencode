เจ้าของและผู้ดูแลระบบจัดการผู้ใช้ได้จากหน้า **Members** แต่ละแถวแสดงบทบาท วันที่เข้าร่วม การใช้งานรายเดือน และวงเงินงบประมาณของสมาชิก

## เชิญสมาชิก

1. เปิด **Members** แล้วคลิก **Invite Members**
2. เพิ่มอีเมลหนึ่งรายการหรือมากกว่า โดยคั่นด้วยช่องว่าง เครื่องหมายจุลภาค หรือเครื่องหมายอัฒภาค หรือวางเป็นรายการก็ได้
3. คลิก **Send invitations**

ผู้รับแต่ละคนจะได้รับอีเมลหัวเรื่อง **Join Acme Inc. on OpenCode** ที่มีปุ่ม **Join workspace**

คำเชิญจะหมดอายุหลังจาก 7 วัน ทุกคนจะเข้าร่วมในบทบาท **Member** แล้วคุณค่อย[เปลี่ยนบทบาท](#change-a-role)หลังจากเข้าร่วมแล้ว

<Callout>
  Workspace ที่สมัครสมาชิก [OpenCode Go](/console/go) ไว้จะเชิญสมาชิกไม่ได้ ให้สร้าง Workspace แยกสำหรับทีมของคุณ
</Callout>

สมาชิกยังเข้าร่วมได้โดยอัตโนมัติ:

- [SSO](/console/sso#automatic-membership) จะเพิ่มผู้ใช้ที่ใช้อีเมลในโดเมนที่ยืนยันแล้วเมื่อลงชื่อเข้าใช้ครั้งแรก
- [การซิงค์ไดเรกทอรี](/console/scim)จะเพิ่มและนำผู้ใช้ออกตามที่คุณกำหนดในผู้ให้บริการข้อมูลประจำตัว (identity provider)

## ตอบรับคำเชิญ

ผู้ได้รับเชิญต้องลงชื่อเข้าใช้ด้วยอีเมลที่ได้รับคำเชิญ ตอบรับได้สองวิธี:

- คลิก **Join workspace** ในอีเมลคำเชิญ แล้วลงชื่อเข้าใช้หรือสร้างบัญชี
- ลงชื่อเข้าใช้ Console เปิดเมนู Workspace แล้วคลิก **Join** ใต้ **Pending invitations**

หากลงชื่อเข้าใช้ด้วยบัญชีอื่นอยู่ Console จะขอให้ **Sign out and continue** ด้วยอีเมลที่ได้รับเชิญ

## จัดการคำเชิญที่รอดำเนินการ

คำเชิญที่รอดำเนินการจะแสดงในตาราง Members เป็น **Pending · Expires** ตามด้วยวันที่ หรือ **Expired**

| การดำเนินการ | วิธี                                                                                       |
| ------------ | ----------------------------------------------------------------------------------------- |
| ส่งอีกครั้ง   | **⋯ › Resend invitation** ส่งลิงก์ใหม่ที่ใช้ได้ 7 วัน และลิงก์เดิมจะใช้ไม่ได้อีก                  |
| เพิกถอน      | **⋯ › Remove...** ลิงก์จะใช้ไม่ได้ทันที                                                       |

## เปลี่ยนบทบาท

เปิดเมนูบทบาทในแถวของสมาชิก แล้วเลือก **Member**, **Admin** หรือ **Owner**

คุณมอบบทบาทได้ไม่เกินบทบาทของตนเอง และ Workspace จะต้องมีเจ้าของอย่างน้อยหนึ่งคนเสมอ ดู[บทบาท](/console/workspaces#roles)

## นำสมาชิกออก

1. คลิก **⋯ › Remove...** ในแถวของสมาชิก
2. ยืนยันด้วย **Remove member**

สิทธิ์เข้าถึงจะถูกเพิกถอนทันที และคุณเชิญสมาชิกคนนั้นกลับมาได้ในภายหลัง การใช้งานที่ผ่านมาของสมาชิกยังคงอยู่ในรายงานของ Workspace

บัญชีบริการและคีย์ API ของบัญชีเหล่านั้นเป็นของ Workspace ดังนั้นการนำสมาชิกที่สร้างบัญชีเหล่านั้นออกจะไม่เพิกถอนคีย์ หากจำเป็นให้เพิกถอนคีย์จาก **Keys** ดู[บัญชีบริการ](/console/api#service-accounts)

## รายละเอียดสมาชิก

คลิกสมาชิกเพื่อดูงบประมาณรายเดือน โมเดลและไคลเอนต์ที่ใช้ แผนภูมิการใช้งาน และล็อกคำขอ จากหน้านี้คุณตั้ง[งบประมาณ](/console/budgets#member-budgets)ของสมาชิกและส่งออกการใช้งานเป็น CSV ได้
