[OpenCode Console](https://opencode.ai/console) เป็นบริการเสริมที่ช่วยเพิ่มประโยชน์ในการใช้ OpenCode ไม่ว่าจะใช้งานคนเดียวหรือเป็นทีม

- [Workspace](/console/workspaces) สำหรับแชร์สิทธิ์เข้าถึงกับ[ทีม](/console/members)ของคุณ
- [Inference](/console/models) สำหรับทั้งโมเดลแบบปิด (proprietary) และโมเดลโอเพนซอร์ส
- [ผู้ให้บริการ](/console/providers)สำหรับเชื่อมต่อบัญชีผู้ให้บริการของคุณเองผ่าน gateway ของ Console
- การติดตามการใช้งานและการควบคุม[งบประมาณ](/console/budgets)
- ปรับใช้นโยบายระดับทีมเพื่อควบคุมการทำงานของ OpenCode
- [การค้นหาเว็บ](/console/websearch)
- [OpenCode Go และ Go Plus](/console/go) การสมัครสมาชิกรายเดือนราคา $10 และ $40 สำหรับเข้าถึงโมเดลโอเพนซอร์ส

## เริ่มต้นใช้งาน

ไม่จำเป็นต้องมีทีมก็ใช้ Console ได้ ทุกบัญชีจะเริ่มต้นด้วย Workspace **Personal** ที่มีคุณเป็นสมาชิกเพียงคนเดียว

1. ลงชื่อเข้าใช้ [Console](https://opencode.ai/console)
2. สมัครสมาชิก [Go](/console/go) เติม[เครดิต](/console/billing#add-credits) หรือเชื่อมต่อ[ผู้ให้บริการ](/console/providers)
3. รัน `/connect` ใน OpenCode แล้วเลือก Workspace
4. [เชิญ](/console/members#invite-members)ทีมของคุณเข้าร่วม (ไม่บังคับ)

```text
/connect
```

## นโยบาย

กฎ Providers และ Tools จากหน้า Policies มีผลกับไคลเอนต์ OpenCode V2 ทุกตัวที่เชื่อมต่อกับ Workspace กฎเหล่านี้ส่งไปในรูปแบบคำสั่ง[นโยบาย](/policies#console)ที่มีอำนาจเหนือการกำหนดค่าของสมาชิกเอง และจะมีผลภายในประมาณหนึ่งนาที
