---
title: "ค้นหาเว็บ"
description: "การค้นหาเว็บแบบโฮสต์สำหรับ OpenCode ผ่าน Console"
---

Console ให้บริการการค้นหาเว็บแบบโฮสต์แก่ผู้ใช้ OpenCode v2 ที่เชื่อมต่ออยู่ เจ้าของหรือผู้ดูแลระบบของ Workspace เปิดใช้งานเพียงครั้งเดียวสำหรับทั้ง Workspace โดยไม่ต้องแจกคีย์ผู้ให้บริการค้นหาแยกให้สมาชิกแต่ละคน

การค้นหาที่สำเร็จแต่ละครั้งมีค่าใช้จ่าย **$0.01** และนับรวมในยอดคงเหลือของ Workspace และวงเงินใช้จ่ายของสมาชิก

## เปิดใช้งาน

1. ลงชื่อเข้าใช้ [Console](https://opencode.ai/console) ในฐานะเจ้าของหรือผู้ดูแลระบบของ Workspace
2. เปิด **Settings** > **General**
3. เปิด **Hosted web search**

จากนั้นสมาชิกแต่ละคนเชื่อมต่อ OpenCode กับ Workspace ด้วย `/connect`

```text
/connect
```

OpenCode จะโหลด **OpenCode Web Search** จากการกำหนดค่าที่ Workspace จัดการ สมาชิกไม่ต้องตั้งค่า `websearch.provider` หรือเพิ่มคีย์ API ของผู้ให้บริการ

## ค้นหา

ขอข้อมูลล่าสุดจาก OpenCode ในพรอมต์ได้เลย การค้นหาจะรันจาก OpenCode ไม่ใช่จากหน้าแบบอินเทอร์แอกทีฟใน Console

```text
Find the latest Bun release and summarize the changes with source links.
```

ผู้ให้บริการแบบโฮสต์จะค้นหาบนเว็บสาธารณะและส่งผลลัพธ์กลับมาไม่เกินแปดรายการ OpenCode ใช้ผลลัพธ์เหล่านี้ตอบพรอมต์และอ้างอิงแหล่งที่มา

ดู[คู่มือการค้นหาเว็บ](/websearch)เพื่อกำหนดค่าสิทธิ์หรือปิดเครื่องมือนี้

## การเรียกเก็บเงิน

Console จะเรียกเก็บ **$0.01** หลังจากการค้นหาส่งชุดผลลัพธ์ที่ถูกต้องกลับมา การค้นหาที่ล้มเหลวหรือถูกจำกัดอัตรา (rate limit) จะไม่ถูกเรียกเก็บเงิน

การค้นหาเว็บจะแสดงแยกจากการใช้งานโมเดลใน **Usage**, **My Activity** กิจกรรมของสมาชิก ใบแจ้งหนี้ และไฟล์ส่งออก CSV วงเงินใช้จ่ายรายเดือนของ Workspace และของสมาชิกรวมค่าใช้จ่ายการค้นหาเว็บด้วย

## ความเป็นส่วนตัว

การค้นหาเว็บแบบโฮสต์ไม่เก็บข้อมูลใด ๆ (zero data retention) Console และผู้ให้บริการค้นหาแบบโฮสต์จะประมวลผลแต่ละคำค้นและผลลัพธ์โดยไม่จัดเก็บเนื้อหาเหล่านั้น
