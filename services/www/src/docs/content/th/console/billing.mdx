Console ใช้ได้ฟรีกับทีมทุกขนาดโดยไม่มีค่าที่นั่ง (seat fee) คุณจ่ายเฉพาะการใช้งานจริงจากเครดิตแบบเติมเงินล่วงหน้าที่ใช้ร่วมกันทั้ง Workspace เจ้าของและผู้ดูแลระบบจัดการการเรียกเก็บเงินได้ใน **Settings › Billing**

การใช้งานผ่าน[ผู้ให้บริการของคุณเอง](/console/providers)จะเรียกเก็บเงินโดยผู้ให้บริการนั้น ไม่ใช่โดย Console

## เพิ่มวิธีการชำระเงิน

1. เปิด **Settings › Billing**
2. ใต้ **Payment methods** คลิก **Add**
3. เลือกวิธีการชำระเงินแล้วตั้งค่าใน Stripe ให้เสร็จ

วิธีการชำระเงินที่รองรับ:

- บัตร
- Link
- Alipay
- UPI
- WeChat Pay

ใช้ **⋯ › Make default** เพื่อเลือกวิธีการชำระเงินสำหรับการเรียกเก็บเงินอัตโนมัติ การนำวิธีการชำระเงินออกอาจทำให้การเติมเงินอัตโนมัติและการต่ออายุ Go ที่ใช้วิธีนั้นหยุดทำงาน

## เติมเครดิต

1. ใต้ **Credits** คลิก **Add credits**
2. เลือก $10, $50 หรือ $100 หรือเลือก **Other** แล้วป้อนจำนวนเงิน
3. เลือกวิธีการชำระเงินแล้วคลิก **Confirm and pay**

ระบบจะบวกค่าธรรมเนียม 4.6% + $0.31 เพิ่มเข้าไป ดังนั้นการซื้อ $50 จะมีค่าใช้จ่าย $52.61 และยอดคงเหลือจะเพิ่มขึ้นเต็ม $50

## เติมเงินอัตโนมัติ

การเติมเงินอัตโนมัติจะซื้อเครดิตเมื่อยอดคงเหลือเหลือน้อย

1. ใต้ **Auto-recharge** คลิก **Add rule**
2. ตั้งยอดคงเหลือที่จะทริกเกอร์การเรียกเก็บเงิน และจำนวนเงินที่จะเติม
3. คลิก **Save**

การเติมเงินอัตโนมัติจะเรียกเก็บเงินจากวิธีการชำระเงินเริ่มต้น รวมค่าธรรมเนียมด้วย หากการเรียกเก็บเงินล้มเหลว การเติมเงินอัตโนมัติจะปิดลงจนกว่าคุณจะตั้งค่าใหม่

## ตรวจสอบยอดคงเหลือ

การ์ด **Credits** ในหน้า **Overview** จะแสดงยอดคงเหลือให้เจ้าของและผู้ดูแลระบบ

## เมื่อเครดิตหมด

คำขอแบบชำระเงินจะล้มเหลวด้วย HTTP `402` เมื่อยอดคงเหลือเป็นศูนย์ ยอดคงเหลือจะไม่ติดลบ

```text
Upstream request failed: Insufficient account funds
```

## ใบแจ้งหนี้

การชำระเงินทุกรายการจะแสดงใน **Invoices** พร้อมสถานะและลิงก์ **Download invoice** หรือ **View receipt**

| รายการ           | เกิดจาก             |
| ---------------- | ------------------ |
| Balance top-up   | การเติมเครดิต         |
| Automatic top-up | การเติมเงินอัตโนมัติ     |
| Go subscription  | การสมัครสมาชิก Go    |
| Go renewal       | การต่ออายุ Go รายเดือน |
| Monthly Usage    | การเรียกเก็บเงินแบบใบแจ้งหนี้ |

## การเรียกเก็บเงินแบบใบแจ้งหนี้

Workspace ที่มีข้อตกลงสินเชื่อ (credit agreement) สามารถรับใบแจ้งหนี้รายเดือนแทนการซื้อเครดิตได้ ติดต่อฝ่ายสนับสนุนเพื่อตั้งค่า

- การใช้งานจะหักจากวงเงินสินเชื่อแทนยอดคงเหลือแบบเติมเงินล่วงหน้า
- ใบแจ้งหนี้ของแต่ละเดือนจะออกในวันที่ 1 (UTC) และครบกำหนดชำระใน 14 วันถัดมา
- ใบแจ้งหนี้ที่ยังไม่ชำระจะมีปุ่ม **Pay now**
- คำขอจะล้มเหลวด้วย HTTP `402` เมื่อใช้ถึงวงเงินสินเชื่อหรือมีใบแจ้งหนี้ค้างชำระ

## Go

การสมัครสมาชิก [OpenCode Go](/console/go) ใช้วิธีการชำระเงินเดียวกันและแสดงในรายการใบแจ้งหนี้เดียวกัน เปิด **Extra usage** ในการ์ดเครดิตของหน้า **Overview** เพื่อชำระจากเครดิตเมื่อใช้ถึงวงเงินของ Go
