---

เชื่อมต่อบัญชีผู้ให้บริการที่คุณชำระเงินอยู่แล้ว เช่น Anthropic, OpenAI หรือ AWS Bedrock แล้วแชร์โมเดลของผู้ให้บริการเหล่านั้นให้ทุกคนใน Workspace Console จะจัดเก็บข้อมูลรับรองและให้บริการผู้ให้บริการแต่ละรายผ่าน gateway ของ Console สมาชิกจึงใช้โมเดลได้โดยไม่เคยเห็นคีย์ของผู้ให้บริการ เครื่องมือของคุณเองก็ใช้ gateway เดียวกันนี้ได้ผ่าน [Providers API](/console/api/providers)

เจ้าของและผู้ดูแลระบบจัดการผู้ให้บริการได้จากแท็บ **Providers** ส่วนสมาชิกจะได้รับโมเดลที่เปิดใช้งานใน OpenCode หลังจากรัน `/connect`

## เชื่อมต่อผู้ให้บริการ

1. เปิด **Providers** แล้วคลิก **Connect Provider**
2. เลือกผู้ให้บริการจากแคตตาล็อกแล้วป้อนคีย์ API
3. คลิก **Test connection** หากต้องการ จากนั้นคลิก **Save**

แคตตาล็อกมีทั้ง Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter และอีกมากมาย ผู้ให้บริการในแคตตาล็อกมาพร้อมโมเดลที่กำหนดค่าไว้ล่วงหน้าแล้ว

### ผู้ให้บริการคลาวด์

ผู้ให้บริการคลาวด์ต้องการรายละเอียดเพิ่มเติมเล็กน้อย

| ผู้ให้บริการ          | รายละเอียด                            |
| --------------------- | ------------------------------------- |
| Azure                 | ชื่อทรัพยากร (resource name) และคีย์ API |
| AWS Bedrock           | ภูมิภาคและคีย์ API                     |
| Google Vertex AI      | ภูมิภาคและ JSON ของบัญชีบริการ (service account) |
| Cloudflare AI Gateway | Account ID, Gateway ID และ API token  |
| Databricks            | URL ของ Workspace และโทเค็น            |

### ผู้ให้บริการแบบกำหนดเอง

คลิก **Add Custom Provider** เพื่อเชื่อมต่อ endpoint อื่นใดก็ได้ แล้วเพิ่มโมเดลด้วย **Add Model**

| ฟิลด์      | คำอธิบาย                                                                        |
| ---------- | ------------------------------------------------------------------------------- |
| Base URL   | ปลายทางที่ Console ส่งต่อคำขอไป เช่น `https://api.deepseek.com/v1`            |
| Format     | Chat Completions, Responses API, Anthropic Compatible หรือ Google Generative AI |
| Auth mode  | Bearer, API key header หรือ Custom header                                       |
| Credential | คีย์ที่ Console ส่งไปยังผู้ให้บริการ                                              |

## เลือกโมเดล

เปิดผู้ให้บริการเพื่อดูโมเดลของผู้ให้บริการนั้น สมาชิกจะใช้ได้เฉพาะโมเดลที่เปิดใช้งานเท่านั้น

- ใช้สวิตช์ **Enabled** เพื่อเปิดหรือปิดโมเดล
- เปิด **New models** เพื่อเปิดใช้งานโมเดลที่ผู้ให้บริการเพิ่มในอนาคตโดยอัตโนมัติ

## แก้ไขโมเดล

คลิกโมเดลเพื่อแก้ไข การเปลี่ยนแปลงจะบันทึกเมื่อคุณปิดแผง

| ส่วน          | สิ่งที่เปลี่ยนได้                                                  |
| ------------- | --------------------------------------------------------------- |
| General       | ชื่อที่แสดง API ID การรองรับเครื่องมือ และชนิดอินพุตและเอาต์พุต      |
| Variants      | รูปแบบย่อย (variant) ที่มี header หรือ body ของตัวเอง               |
| Configuration | variant เริ่มต้น header และ body ของคำขอ และขีดจำกัดโทเค็น          |
| Cost Tiers    | ราคาอินพุต เอาต์พุต การอ่านแคช และการเขียนแคชต่อ 1M โทเค็น          |

### ราคาแบบกำหนดเอง

โมเดลในแคตตาล็อกเริ่มต้นด้วยราคาตามรายการ (list price) ของผู้ให้บริการ หากคุณมีราคาที่เจรจาไว้ เช่น ส่วนลดในสัญญากับ OpenAI ให้แทนที่ราคาใน **Cost Tiers** เพื่อให้รายงานการใช้งานและ[งบประมาณ](/console/budgets)ตรงกับที่คุณจ่ายจริง

| ฟิลด์            | ราคาตามรายการ | ราคาของคุณ |
| ---------------- | ------------- | ---------- |
| Input price      | $2.50         | $2.00      |
| Output price     | $15.00        | $12.00     |
| Cache read price | $0.25         | $0.20      |

ราคาที่คุณเปลี่ยนจะถูกไฮไลต์ในหน้าผู้ให้บริการ ใช้ **Restore default value** ที่ฟิลด์ หรือ **⋯ › Restore...** ที่โมเดล เพื่อกลับไปใช้ราคาตามรายการ

เพิ่มระดับ **Context** เมื่อโมเดลคิดราคาสูงขึ้นเมื่อบริบทเกินขนาดที่กำหนด เช่น สำหรับพรอมต์ที่ยาวเกิน 200K โทเค็น

### โมเดลแบบกำหนดเอง

คลิก **Add Model** เพื่อเพิ่มโมเดลที่ไม่มีในแคตตาล็อก โดยระบุ **Display name** และ **Model ID** ใช้ **⋯ › Duplicate...** กับโมเดลที่มีอยู่เพื่อเริ่มจากการตั้งค่าของโมเดลนั้น

## โมเดลของ OpenCode

แท็บ **Models** ใช้จัดการ[โมเดล](/console/models)ที่ Console มีให้ ซึ่งชำระเงินจากเครดิตของ Workspace แท็บนี้ทำงานเหมือนหน้าผู้ให้บริการ:

- เปิดหรือปิดโมเดลทีละตัว
- ปิด **Free models** เพื่อบล็อกโมเดลฟรีสำหรับ Workspace
- เปิด **New models** เพื่อเปิดใช้งานโมเดลใหม่ของ Console โดยอัตโนมัติ

ปิดผู้ให้บริการนี้ทั้งหมดได้จาก **⋯ › Disable** เพื่อใช้เฉพาะผู้ให้บริการของคุณเอง

## ใช้ใน OpenCode

สมาชิกรัน `/connect` แล้วเลือก Workspace ผู้ให้บริการแต่ละรายที่เปิดใช้งานจะแสดงเป็นชื่อ Workspace ตามด้วยชื่อผู้ให้บริการ และ `/models` จะแสดงโมเดลที่เปิดใช้งานของผู้ให้บริการนั้น

```text
Acme Inc. / Anthropic
```

เปิด **Managed providers only** ใน **Settings › General** เพื่อจำกัดให้ทุกคนใช้ OpenCode กับผู้ให้บริการของ Workspace เท่านั้น

## ปิดใช้งานหรือนำออก

เปิดเมนู **⋯** ของผู้ให้บริการ:

- **Disable** ซ่อนผู้ให้บริการและโมเดลของผู้ให้บริการนั้นจากสมาชิก แต่ยังเก็บการตั้งค่าไว้
- **Remove...** ลบผู้ให้บริการและโมเดลของผู้ให้บริการนั้น กล่องโต้ตอบจะแสดงว่าใครใช้งานไปเมื่อเร็ว ๆ นี้ และมีตัวเลือก **Disable instead**

หากต้องการหมุนเวียนคีย์ (rotate) ให้คลิกข้อมูลรับรองในหน้าผู้ให้บริการแล้วป้อนคีย์ใหม่

## การเรียกเก็บเงิน

ผู้ให้บริการจะเรียกเก็บค่าโทเค็นจากคุณโดยตรง Console ไม่หักเครดิตสำหรับโทเค็นเหล่านี้ แต่ Console ยังบันทึกทุกคำขอและค่าใช้จ่ายตามราคาของโมเดล รายงานการใช้งานและ[งบประมาณ](/console/budgets)จึงรวมการใช้งานนี้ด้วย

หากต้องการเรียกผู้ให้บริการจากเครื่องมือของคุณเองแทน OpenCode ให้ใช้ [Providers API](/console/api/providers)
