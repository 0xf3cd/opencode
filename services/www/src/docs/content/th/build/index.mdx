title: "บทนำ"
---

OpenCode มีผู้ใช้หลายล้านคนทุกวัน คุณสามารถต่อยอดจาก OpenCode เพื่อสร้างแอปพลิเคชัน การผสานรวม และประสบการณ์ใช้งานเอเจนต์ของคุณเองได้โดยไม่ต้องเริ่มจากศูนย์

นอกจากนี้ยังมี Effect API สำหรับ[ปลั๊กอิน](/build/plugins/effect) [ไคลเอนต์](/build/client/effect) และ[แอปแบบฝัง](/build/sdk/effect)

<CardGroup cols={1}>
  <Card title="ขยายความสามารถของ OpenCode" href="/build/plugins">
    สร้างปลั๊กอินที่เพิ่มเครื่องมือ การผสานรวม คำสั่ง เอเจนต์ และพฤติกรรมแบบกำหนดเอง โดยส่วนอื่นของ OpenCode ยังทำงานเหมือนเดิม
  </Card>
  <Card title="รันเป็นเซิร์ฟเวอร์" href="/build/client">
    เชื่อมต่อกับ OpenCode ด้วยไคลเอนต์ตัวเดียวกับที่ TUI และแอปเดสก์ท็อปใช้ แล้วสร้างอินเทอร์เฟซ เวิร์กโฟลว์ หรือประสบการณ์ใช้งานเอเจนต์แบบใดก็ได้บนไคลเอนต์นั้น
  </Card>
  <Card title="ฝังลงในแอป" href="/build/sdk">
    ฝัง OpenCode ลงในแอปพลิเคชันของคุณโดยตรง แล้วสร้างเอเจนต์ อินเทอร์เฟซ หรือผลิตภัณฑ์สำหรับนักพัฒนาที่กำหนดเองได้ทั้งหมด
  </Card>
</CardGroup>
