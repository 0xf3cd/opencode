title: "Effect"
---

`@opencode/plugin/effect` คือ API ปลั๊กอินของ OpenCode เวอร์ชันที่ออกแบบมาสำหรับ Effect โดยเฉพาะ การดำเนินการผ่านบริบทคืนค่าเป็น Effect หรือ Stream ส่วน callback คืนค่าเป็น Effect และอายุการทำงานของปลั๊กอินแทนด้วย `Scope`

OpenCode จัดเตรียม `effect` (รวมถึง subpath `effect/*` ที่ export ไว้) และ `@opencode/plugin` ให้ในรันไทม์เมื่อโหลดปลั๊กอินและ dependency ใน `node_modules` ของปลั๊กอิน ให้ติดตั้งแพ็กเกจเหล่านี้เป็น peer/dev dependency สำหรับตรวจสอบชนิดข้อมูลและทดสอบภายในเครื่อง แทนการ bundle รวมไว้ในปลั๊กอิน

```sh
bun add --peer @opencode/plugin effect
```

ให้ export ปลั๊กอิน Effect จาก `.opencode/plugins/` เพื่อให้โหลดโดยอัตโนมัติ

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

แพ็กเกจที่เผยแพร่แล้วและไดเรกทอรีปลั๊กอินที่อยู่นอก `.opencode/plugins/` ใช้การกำหนดค่า `plugins` แบบเดียวกับปลั๊กอินเซิร์ฟเวอร์อื่น ๆ

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

ดูการเปิดใช้งาน การ resolve แพ็กเกจ และลำดับความสำคัญของการกำหนดค่าได้ที่[กำหนดค่าปลั๊กอิน](/plugins)

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## วงจรชีวิต

`effect` จะรันเมื่อโหลดปลั๊กอิน และ scope ของมันจะปิดลงเมื่อปลั๊กอินรีโหลดหรือถูกยกเลิกการโหลด การลงทะเบียน ไฟเบอร์ที่ผูกกับ scope และ finalizer จึงถูกปล่อยพร้อมกันทั้งหมด

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

ใช้ไฟเบอร์ที่ผูกกับ scope สำหรับงานเบื้องหลัง scope ของปลั๊กอินจะ interrupt ไฟเบอร์นั้นระหว่าง cleanup

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### บริบท

บริบทเปิดให้ใช้ไคลเอนต์ Effect สำหรับเซิร์ฟเวอร์ OpenCode ที่เชื่อมต่ออยู่ รวมถึง transform, hook, พื้นที่จัดเก็บ การรีโหลด และตัวเลือกที่มีเฉพาะสำหรับปลั๊กอิน แต่ไม่เปิดให้เข้าถึงบริการ Core ภายในของ OpenCode

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

นิยามปลั๊กอินและบริบททั้งหมดประกาศไว้ดังนี้

```ts

```

ส่งตัวเลือกด้วยรูปแบบออบเจกต์ใน `opencode.json(c)`

```jsonc title="opencode.jsonc"

  "plugins": [
    {
      "package": "./plugins/company-effect",

```

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"

export default Plugin.define({

      const strict = ctx.options.strict === true

    }),
})
```

## Transform

Transform แก้ไขสถานะแบบ synchronous ผ่าน editor OpenCode ใช้ transform ตามลำดับการลงทะเบียนภายในแต่ละโดเมน แหล่งข้อมูล (source) จะเพิ่มผู้ให้บริการและนิยามโมเดลแบบ immutable ก่อน จากนั้น transform ของโมเดลจึงแก้ไขโมเดลที่เป็นตัวเลือก (candidate) ของผู้ให้บริการที่ใช้งานอยู่ การ yield การลงทะเบียนจะผูกการลงทะเบียนนั้นไว้กับ scope ของปลั๊กอิน

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

transform ของโมเดลบังคับใช้นโยบายกับชุดโมเดล candidate ทั้งหมดของผู้ให้บริการที่ใช้งานอยู่ได้

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

เรียก `reload` เมื่อสถานะภายนอกที่ transform ใช้อยู่เปลี่ยนไป ในตัวอย่างนี้ `loadFromSource()` คืนค่ารายการแบบ `{ info: Provider.Info, models: readonly Model.Info[] }` การรีโหลดผู้ให้บริการจะทำให้ผลลัพธ์ของโมเดลทั้งหมดใช้ไม่ได้และต้องคำนวณใหม่ด้วย

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### เอเจนต์

อ่านเอเจนต์ทั้งหมดหรือดึงเอเจนต์เดียวด้วย ID การตอบกลับจากไคลเอนต์มี location ที่ resolve แล้วและข้อมูล schema

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

Transform หรือรีโหลดเอเจนต์

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Schema: [`Agent.Info`](/api#schema-Agent.Info)

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### ผู้ให้บริการ

อ่านผู้ให้บริการที่มีอยู่ หรือดูข้อมูลเมตาของผู้ให้บริการรายเดียวด้วย ID

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

transform ของผู้ให้บริการแก้ไขการตั้งค่าผู้ให้บริการและนิยามจากแหล่งข้อมูล การอ่านผ่าน editor จะรวมผู้ให้บริการที่ไม่ได้ใช้งานด้วยและให้นิยามแบบ immutable ส่วน `models.update` แก้ไขสำเนาของโมเดลจากแหล่งข้อมูลที่ปลั๊กอินเป็นเจ้าของ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

แทนที่รายการโมเดลทั้งหมดของแหล่งข้อมูลด้วย `models.set` แล้วรีโหลดเมื่อนิยามที่บันทึกไว้เปลี่ยนไป

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

สำหรับการค้นหาโมเดลเฉพาะบัญชี ให้ส่งการเชื่อมต่อที่ใช้โหลดรายการโมเดลเป็น `sourceConnection` OpenCode จะไม่รวมผู้ให้บริการนั้นขณะที่มีการเลือกการเชื่อมต่ออื่นอยู่ จนกว่าปลั๊กอินของคุณจะเผยแพร่รายการโมเดลที่รีเฟรชแล้ว

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

Schema: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info)

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### โมเดล

อ่านโมเดลที่มีอยู่และโมเดลที่เลือกเป็นค่าเริ่มต้น

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

transform ของโมเดลแก้ไขชุดโมเดล candidate ทั้งหมดของผู้ให้บริการที่ใช้งานอยู่ candidate ที่ถูกปิดใช้งานยังแก้ไขได้จนกว่า transform ทั้งหมดจะทำงานเสร็จ และ `update` เพิ่มโมเดลได้เฉพาะภายใต้ผู้ให้บริการที่มีอยู่เท่านั้น

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

callback แก้ไขค่าแทนที่ (override) ของโมเดลแบบดิบ ค่าเริ่มต้นของผู้ให้บริการจะ merge เพียงครั้งเดียวเมื่อ OpenCode commit ผลลัพธ์ และการอ่านที่ไม่มีการเปลี่ยนแปลงจะใช้ผลลัพธ์นั้นซ้ำ `editor.provider` อ่านนิยามแบบ immutable จากแหล่งข้อมูล รวมถึงเทมเพลตที่ไม่ได้ใช้งาน ไม่ใช่เอาต์พุตของ transform โมเดล

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Schema: [`Model.Info`](/api#schema-Model.Info)

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>

}
```

### คำสั่ง

อ่านคำสั่งที่ใช้ได้ใน location ปัจจุบัน

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

transform ของคำสั่งในปัจจุบันรองรับเฉพาะการเพิ่ม executor จะได้รับเซสชัน ไฟล์แนบของพรอมต์ และโหมดการส่ง (delivery mode)

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Schema: [`Command.Info`](/api#schema-Command.Info), [`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery)

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID
  readonly prompt: PromptInput.Prompt
  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### การผสานรวม

อ่านการผสานรวม (integration) และ resolve ข้อมูลรับรองที่ใช้งานอยู่หากมี

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

เชื่อมต่อด้วยคีย์ หรือดำเนินขั้นตอน OAuth ผ่าน API ที่เชื่อมต่ออยู่

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

Transform การผสานรวมและวิธีการยืนยันตัวตน callback ของวิธี OAuth เป็น Effect และอาจจองทรัพยากรที่ผูกกับ scope ได้

### เครื่องมือ

ลงทะเบียนเครื่องมือที่มีชนิดข้อมูลกำกับด้วย Effect `Schema` executor จะได้รับอินพุตที่ decode แล้ว และคืนค่า Effect ที่มีเอาต์พุตแบบมีชนิดข้อมูล เนื้อหาสำหรับแสดงผล หรือข้อมูลเมตา

editor รองรับ `add`, `update` และ `remove` callback ของ transform ทำงานแบบ synchronous จึงต้องไม่คืนค่า Effect หรือ Promise ให้โหลดข้อมูลภายนอกก่อนลงทะเบียนหรือรีโหลด OpenCode จะเล่น transform ที่ใช้งานอยู่ซ้ำตามลำดับการลงทะเบียนบน editor ใหม่ทุกครั้ง หากชื่อเครื่องมือที่มีผลจริงซ้ำกัน การลงทะเบียนที่ถูกต้องซึ่งมาทีหลังจะแทนที่รายการก่อนหน้า

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

เรียก `yield* ctx.tool.reload()` หลังจากเปลี่ยนข้อมูลต้นทางที่ callback ใช้อยู่ การรีโหลดจะเล่น transform ที่ใช้งานอยู่ซ้ำโดยไม่เปลี่ยนลำดับ และไม่รัน effect ของปลั๊กอินใหม่

เครื่องมือมี `id` ซึ่งเป็นชื่อที่มีผลจริง และ `get()` คืนค่า `undefined` หากไม่มี ID นั้น ใช้ `update` และ `remove` กับชื่อเครื่องมือที่มีผลจริงซึ่งรวม namespace ไว้ด้วย (`acme_greeting` ในตัวอย่างด้านบน) จุดใน namespace และอักขระที่ไม่รองรับในชื่อเครื่องมือจะกลายเป็น `_` ชื่อที่ไม่มีอยู่จะถูกข้าม การสร้างเครื่องมือต้องใช้ `add` พร้อมนิยามที่ครบถ้วน การอัปเดตจะคงชื่อและ namespace เดิมไว้ ให้กำหนด schema หรือตัวเลือกใหม่ทั้งก้อนเพื่อแทนที่ แทนการแก้ไขค่าที่ซ้อนอยู่ภายใน การอัปเดตที่ไม่ถูกต้องจะถูกบันทึก log และคงนิยามเดิมไว้

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

การอัปเดตและการลบจะเล่นซ้ำตามลำดับร่วมกับการเพิ่ม รวมถึงหลังจากแคตตาล็อก MCP รีเฟรชด้วย

`transform` คืนค่าการลงทะเบียนที่ผูกกับ scope รัน `yield* registration.dispose` เพื่อลบ transform นั้นและสร้างผลลัพธ์ใหม่จาก transform ที่เหลือ ซึ่งจะทำให้นิยามก่อนหน้าที่เคยถูกแทนที่กลับมามีผล การ dispose เรียกซ้ำได้อย่างปลอดภัย (idempotent) และการปิด scope ของปลั๊กอินก็จะ dispose การลงทะเบียนทั้งหมดของปลั๊กอินด้วย

คำขอโมเดลแต่ละครั้งจะเก็บสแนปช็อตของเครื่องมือไว้ การรีโหลดและการ dispose มีผลกับสแนปช็อตในอนาคตเท่านั้น ไม่กระทบนิยามหรือ executor ที่คำขอที่มีอยู่เก็บไว้แล้ว executor ที่อ้างถึงข้อมูลปลั๊กอินที่เปลี่ยนแปลงได้ยังคงเห็นการเปลี่ยนแปลงของข้อมูลนั้น หากค่าต้องผูกอยู่กับนิยามนั้นตลอด ให้เก็บค่าไว้ภายใน transform

```ts
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",
        info: () => Effect.succeed({ branch: { current: "feature", default: "main" } }),
        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

callback ของผู้ให้บริการจะได้รับ location ปัจจุบัน root ของ working copy root ของโปรเจกต์หลัก (canonical) และ repository store (ถ้ามี) callback ของ diff ยังได้รับโหมดที่เลือก บริบทที่ขอ และงบประมาณขนาดเอาต์พุตเป็นไบต์ด้วย การค้นหา repository ยังคงใช้ตัวตรวจจับ Git และ Mercurial ในตัวของ OpenCode

ผู้ให้บริการจะ implement `init(scope)` เพื่อสร้าง repository ใน `scope.worktree` ก็ได้ (ไม่บังคับ) การเริ่มต้น repository จะเลือกผู้ให้บริการตาม ID (ค่าเริ่มต้นคือ Git) ไม่ใช่ตามชนิด repository ที่ตรวจพบ ให้ลงทะเบียนผู้ให้บริการที่มี `init` แม้ location นั้นจะยังไม่มี repository ก็ตาม OpenCode จะตรวจสอบว่าไดเรกทอรีมีอยู่และยังไม่มี repository ก่อนเรียกใช้ แล้วจึงค้นหาโปรเจกต์ใหม่ รูปแบบ repository ใหม่ยังต้องมีการรองรับการค้นหาเพิ่มเติมนอกเหนือจาก callback นี้

### การค้นหาเว็บ

แสดงรายการผู้ให้บริการ หรือรันคำค้นผ่านผู้ให้บริการที่เลือก

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const websearch = ctx.websearch
    const providers = yield* websearch.providers().pipe(Effect.orDie)
    const results = yield* websearch
      .query({ query: "OpenCode plugins", providerID: WebSearch.ID.make("internal") })
```

```ts
effect: (ctx) =>
```

### อีเวนต์

การ subscribe อีเวนต์สาธารณะของเซิร์ฟเวอร์เป็น Effect `Stream` ให้ fork ตัวรับข้อมูลไว้ใน scope ของปลั๊กอินเพื่อให้ถูก interrupt โดยอัตโนมัติ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.tap((item) => Effect.logDebug("OpenCode event", { type: item.type })),
      Stream.runDrain,
      Effect.forkScoped,
    )
  }),
```

ใช้ operator ของ Stream เพื่อเลือกและประมวลผลชนิดอีเวนต์

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.filter((item) => item.type === "config.updated"),
      Stream.runForEach(() => Effect.logInfo("configuration changed")),
      Effect.forkScoped,
    )
  }),
```

## Hook

Hook ดักจับการดำเนินการที่กำลังเกิดขึ้น ปลั๊กอินหลายตัวลงทะเบียน hook เดียวกันได้ OpenCode จะรัน hook ตามลำดับปลั๊กอิน hook ที่มาทีหลังจึงเห็นการเปลี่ยนแปลงจาก hook ก่อนหน้า การลงทะเบียนจะมีผลตลอดอายุ scope ของปลั๊กอิน

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", () => Effect.void)
  }),
```

### เซสชัน

แก้ไขคำแนะนำระบบ (system instructions) ข้อความ หรือเครื่องมือที่ประกอบแล้วก่อนส่งไปยังโมเดล `context` ทำงานสำหรับลูปของเอเจนต์ ส่วน `compaction`, `generate` และ `title` ทำงานสำหรับคำขอเสริมตามชื่อ `compaction` และ `title` รับ `result` เพื่อข้ามการเรียกโมเดลได้

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

แก้ไขการตั้งค่าคำขอโมเดล และจำกัด hook ให้ใช้กับผู้ให้บริการรายเดียวได้ (ไม่บังคับ) อีเวนต์มี `kind` แบบเดียวกับ hook HTTP ด้านล่าง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

แก้ไขคำขอหรือการตอบกลับเนทีฟของผู้ให้บริการ body ของทั้งสองอย่างเป็นสตรีมที่อ่านได้ครั้งเดียว จึงต้อง clone หรือแทนที่ body ก่อนอ่าน hook ทั้งสองทำงานกับทุกคำขอที่เซสชันส่งออกไป `event.kind` มีค่าเป็น `"primary"`, `"compaction"`, `"title"` หรือ `"generate"` ขึ้นอยู่กับว่าโฟลว์ใดเป็นผู้ส่งคำขอ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

ผู้ให้บริการที่สตรีมผ่าน WebSocket จะใช้การเชื่อมต่อเดียวซ้ำต่อเซสชัน hook HTTP จึงไม่เห็นทราฟฟิกนั้นเลย hook ทดลอง `experimental.ws.handshake` ทำงานหนึ่งครั้งต่อการเรียกโมเดลก่อนเลือกการเชื่อมต่อ และเปิดให้เข้าถึง `url` และ `headers` ของการเชื่อมต่อ การเปลี่ยนค่าใดค่าหนึ่งจะเปิด socket ใหม่ hook HTTP ยังคงทำงานกับคำขอที่ route แบบ WebSocket สลับไปใช้ HTTP เป็นทางสำรอง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` และ `experimental.ws.receive` เปิดให้เข้าถึงเฟรมโดยตรง `send` ทำงานหลังจาก driver ของผู้ให้บริการสร้างเฟรมขาออก ส่วน `receive` ทำงานกับเฟรมขาเข้าแต่ละเฟรมก่อนที่ driver จะเห็น ค่าใดก็ตามที่อยู่ใน `frame` เมื่อ hook คืนค่าคือสิ่งที่จะถูกส่งออกไปหรือส่งถึง driver โดย OpenCode ไม่ตรวจสอบความถูกต้อง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

แทนที่การตัดสินใจลองใหม่ (retry) สำหรับความล้มเหลวของผู้ให้บริการ หรือแทนที่ระยะหน่วงเป็นมิลลิวินาที hook ทำงานหลังจาก OpenCode จำแนกความล้มเหลวและเสนอนโยบายแล้ว แต่ก่อนจะกำหนดเวลาการลองใหม่ใด ๆ โดยไม่เปิดเผยว่า OpenCode ดำเนินการครั้งถัดไปภายในอย่างไร

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

`decision` เริ่มต้นคือนโยบายของ OpenCode ดังนั้น hook อาจทำให้ความล้มเหลวของผู้ให้บริการที่ปกติถือเป็นจุดสิ้นสุดกลับลองใหม่ได้ หรือปฏิเสธการลองใหม่ที่เสนอมา hook หลายตัวทำงานตามลำดับการลงทะเบียน และ hook ที่มาทีหลังจะเห็นการตัดสินใจปัจจุบัน จำนวนครั้งสูงสุดในตัวยังคงเป็นขีดจำกัดตายตัว `attempt` คือครั้งที่กำลังจะส่งจริง โดยคำขอแรกคือครั้งที่ `1` การลองใหม่ครั้งแรกจึงเป็นครั้งที่ `2` ระยะหน่วงที่ไม่ถูกต้อง (`NaN`, อนันต์ หรือค่าติดลบ) จะใช้ระยะหน่วงที่คำนวณไว้แทน การกู้คืนเมื่อบริบทล้นยังแยกเป็นอีกกลไก เพราะจะบีบอัดบริบทของบทสนทนาแทนการส่งคำขอเดิมซ้ำ

### เครื่องมือ

hook ก่อนรัน (before) แทนที่อินพุตหรือล้มเหลวด้วย `Tool.Error` ได้

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

hook หลังรัน (after) ตรวจสอบหรือแทนที่ผลลัพธ์ที่สำเร็จและความล้มเหลวได้

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

#### ข้อมูลอ้างอิง

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
}

interface ToolFailures extends Record<keyof ToolHooks, unknown> {
  readonly "execute.before": Tool.Error
  readonly "execute.after": never
}

interface ToolHookDomain {
  readonly hook: Hooks<ToolHooks, ToolFailures>
}
```

ชนิดการลงทะเบียนที่ใช้ร่วมกันแสดงให้เห็นว่าการดำเนินการใดต้องใช้ scope ของปลั๊กอิน

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## เผยแพร่

ปลั๊กอินแบบแพ็กเกจใช้ default export แบบเดียวกับปลั๊กอิน Effect ภายในเครื่อง ให้ export implementation แบบ Effect จาก entrypoint หลัก และประกาศ `effect` เป็น `peerDependency`

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

OpenCode จะเปลี่ยนเส้นทางการ import `effect`, subpath `effect/*` ที่ export ไว้ และ `@opencode/plugin` (รวมถึงการ import จาก dependency ใน `node_modules` ของปลั๊กอิน) ไปยังอินสแตนซ์รันไทม์ของโฮสต์ เพื่อให้ไฟเบอร์ logger และตัว parse `Schema` ใช้รันไทม์ชุดเดียวกัน

- โปรดอย่า bundle `effect` ไว้ในอาร์ติแฟกต์ของปลั๊กอินที่เผยแพร่ หากใช้ bundler ให้กำหนด `effect` และ `effect/*` เป็น external
- ปลั๊กอินและ dependency ใน `node_modules` ของปลั๊กอินจะทำงานกับอินสแตนซ์ `effect` ของ OpenCode รุ่นที่เป็นโฮสต์เสมอ ให้ใช้ API และพาธโมดูลของ `effect` ที่เข้ากันได้กับ OpenCode รุ่นที่คุณรองรับ dependency ที่สร้างบน `effect` major อื่น (เช่น Effect 3) ก็จะได้รับ `effect` ของโฮสต์เช่นกันและไม่รองรับ
- มีให้เฉพาะ subpath สาธารณะของ `effect` เท่านั้น ปลั๊กอินที่ import โมดูล `internal` ส่วนตัวของ Effect จะโหลดไม่สำเร็จ พร้อมข้อผิดพลาดที่ระบุพาธนั้น
- ไบนารี OpenCode ที่คอมไพล์แล้วไม่มีไฟล์ Scalar และ Swagger UI ที่หน้าเอกสาร HTTP API ของ Effect ใช้ หากให้บริการหน้าเหล่านั้นจากปลั๊กอิน จะแสดงข้อความแจ้งแทน

entrypoint ของแพ็กเกจ export `Plugin.define` พร้อมฟังก์ชัน `effect`

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

ใช้เวอร์ชันที่เข้ากันได้กับ OpenCode รุ่นที่คุณรองรับ และทดสอบแพ็กเกจที่ติดตั้งจริง ไม่ใช่เพียงสำเนาที่ลิงก์ผ่าน workspace

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
