แพ็กเกจ npm ใช้สคริปต์ postinstall เพื่อเลือกไบนารี `opencode` แบบเนทีฟที่ตรงกับแพลตฟอร์มของคุณ คำสั่งของ Bun และ pnpm ด้านบนอนุญาตให้รันสคริปต์นี้ไว้อย่างชัดเจนแล้ว ส่วน Vite+ ไม่ต้องใช้แฟล็กเพิ่มเติม คำสั่ง mise ต้องใช้ mise 2026.10.9 ขึ้นไป เวอร์ชันที่เก่ากว่าจะติดตั้ง OpenCode 1

ไม่รองรับตัวจัดการแพ็กเกจบน Windows

## เชื่อมต่อ

OpenCode รองรับผู้ให้บริการ LLM จำนวนมากในตัว คุณเชื่อมต่อได้โดยตรง[ใน TUI](/cli/providers) ด้วยคำสั่ง `/connect`

หากต้องการกำหนดค่าผู้ให้บริการแบบกำหนดเอง ดูรายละเอียดได้ที่[ผู้ให้บริการ](/providers)

หากต้องการเข้าถึงโมเดลเขียนโค้ดที่ดีที่สุดทั้งหมดได้อย่างง่ายดาย ลองใช้ [OpenCode Console](/console)

นอกจากนี้ คุณยังลองใช้ [OpenCode Go](/console/go) ได้ด้วย ซึ่งเป็นแผนสมาชิกราคา $10/เดือนที่ให้คุณเข้าถึงโมเดลโอเพนซอร์สที่ดีที่สุด
