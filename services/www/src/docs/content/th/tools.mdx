---
title: "เครื่องมือ"
---

บอกผลลัพธ์ที่ต้องการ แล้ว OpenCode จะเลือกเครื่องมือที่มีอยู่ ขอการอนุมัติเมื่อจำเป็น และส่งผลลัพธ์กลับมา

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

งานนี้มักใช้ `grep` หรือ `glob`, `read`, เครื่องมือแก้ไขไฟล์ และ `shell` คุณยังระบุชื่อเครื่องมือได้เมื่อต้องการให้ใช้วิธีการเฉพาะ

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## ไฟล์

### Read

`read` ส่งคืนเนื้อหาไฟล์หรือรายการในไดเรกทอรีแบบไม่ recursive ระบุ `path` และใช้ `offset` กับ `limit` เพื่ออ่านผลลัพธ์ขนาดใหญ่ทีละหน้า

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

การอ่านข้อความจะมีหมายเลขบรรทัดกำกับ และจำกัดไว้ที่ 2,000 บรรทัดและ 50 KiB ต่อหน้า บรรทัดที่ยาวเกิน 2,000 อักขระจะถูกตัดให้สั้นลง เครื่องมือนี้ยังส่งไฟล์ PNG, JPEG, GIF, WebP และ PDF ไปยังโมเดลได้ โดยข้อมูลต้นฉบับต้องไม่เกิน 20 MiB ไฟล์ไบนารีอื่นจะล้มเหลว ดูสื่อที่รองรับและการประมวลผลรูปภาพได้ที่[ไฟล์แนบ](/attachments)

สิทธิ์: `read` โดยใช้พาธที่ normalize แล้วเป็น resource

### Glob

`glob` ค้นหาพาธไฟล์จากรูปแบบอย่าง `**/*.ts` โดยค้นในไดเรกทอรีปัจจุบัน เว้นแต่ `path` จะเลือกไดเรกทอรีสัมพัทธ์อื่น `hidden` จะรวมรายการที่ซ่อนอยู่ และ `limit` จำกัดจำนวนผลลัพธ์

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

ขีดจำกัดเริ่มต้นคือ 100 ไฟล์ และหมดเวลาค้นหาที่ 30 วินาที สิทธิ์: `glob` โดยใช้รูปแบบที่ร้องขอเป็น resource

### Grep

`grep` ค้นหาในเนื้อหาไฟล์และส่งคืนพาธ หมายเลขบรรทัด และตัวอย่างข้อความ `pattern` ใช้ไวยากรณ์ regular expression เว้นแต่ `literal` เป็น true จำกัดขอบเขตการค้นหาได้ด้วย `path`, `include`, `caseSensitive` หรือ `limit`

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

ขีดจำกัดเริ่มต้นคือ 100 บรรทัดที่ตรงกัน และหมดเวลาค้นหาที่ 30 วินาที สิทธิ์: `grep` โดยใช้รูปแบบที่ร้องขอเป็น resource ไม่ใช่พาธที่ค้นหา

### Edit

`edit` แทนที่ข้อความในไฟล์ที่มีอยู่ ระบุ `path`, `oldString` และ `newString` ที่ต่างออกไป ข้อความเดิมต้องตรงกันเพียงตำแหน่งเดียว เว้นแต่ `replaceAll` เป็น true

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

ใช้ `edit` สำหรับการเปลี่ยนแปลงเฉพาะจุด OpenCode อาจจัดรูปแบบไฟล์หลังเขียนเสร็จ สิทธิ์: `edit` โดยใช้พาธเป้าหมายเป็น resource

### Write

`write` สร้างหรือแทนที่ไฟล์ข้อความทั้งไฟล์จาก `path` และ `content` โดยจะสร้างไดเรกทอรีแม่ที่ยังไม่มีให้ และอาจรันตัวจัดรูปแบบโค้ดที่กำหนดไว้

```text
Create docs/example.md with a heading and one setup command.
```

หากต้องการเปลี่ยนเพียงบางส่วนของไฟล์ที่มีอยู่ ให้ใช้ `edit` แทน สิทธิ์: `edit` โดยใช้พาธเป้าหมายเป็น resource

### Patch

`patch` ใช้แพตช์หนึ่งชุดที่เพิ่ม อัปเดต ย้าย หรือลบได้หลายไฟล์ `patchText` ใช้ส่วน `*** Add File`, `*** Update File` และ `*** Delete File`

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode เปิดให้ใช้ `patch` กับโมเดล GPT ที่รองรับ ส่วนโมเดลอื่นจะได้ `edit` และ `write` แทน สิทธิ์: `edit` โดยใช้ทุกพาธที่ได้รับผลกระทบเป็น resource

พาธที่อยู่นอก Location ที่ใช้งานอยู่หรือนอก worktree ของโปรเจกต์ต้องได้รับการอนุมัติ `external_directory` ด้วย ดูการ normalize พาธ ลำดับกฎ และการอนุมัติที่บันทึกไว้ได้ที่[สิทธิ์](/permissions) หากต้องการให้เข้าถึงเนื้อหาภายนอกด้วยชื่อ ให้กำหนดค่า[ไดเรกทอรีอ้างอิง](/references)

## คำสั่ง

### Shell

`shell` รันคำสั่งใน shell ของผู้ใช้บนเครื่องโฮสต์ ให้ตั้งค่า `workdir` แทนการใส่ `cd` ในคำสั่ง และตั้งค่า `timeout` เป็นมิลลิวินาทีเมื่อเวลาหมดเริ่มต้นสองนาทีสำหรับการรันแบบเบื้องหน้าไม่เหมาะสม

```text
Run bun test from packages/core with a five-minute timeout.
```

ตั้งค่า `background` เป็น true สำหรับ dev server หรือโปรเซสอื่นที่ทำงานเป็นเวลานาน การเรียกแบบเบื้องหลังจะส่งคืนทันทีและแจ้งเซสชันเมื่อทำงานเสร็จ โดยไม่มีเวลาหมดเว้นแต่จะระบุไว้ เอาต์พุตขนาดใหญ่จะถูกย่อให้สั้นลง และเอาต์พุตฉบับเต็มจะเก็บไว้ในไฟล์ที่ OpenCode จัดการ

สิทธิ์: `shell` โดยใช้แต่ละคำสั่งที่ตัวสแกนแยกออกมาเป็น resource ตัวสแกนยังตรวจสอบไดเรกทอรีทำงานภายนอกและไดเรกทอรีที่อนุมานได้จากคำสั่งด้วย Shell มีสิทธิ์ด้านระบบไฟล์ โปรเซส และเครือข่ายเท่ากับผู้ใช้บนเครื่องโฮสต์ จึงควรใช้กฎที่แคบใน[สิทธิ์](/permissions)

## เว็บ

### Webfetch

`webfetch` ดึง URL แบบ HTTP หรือ HTTPS หนึ่งรายการในรูปแบบ `markdown`, `text` หรือ `html` โดยค่าเริ่มต้นคือ Markdown และ `timeout` รับค่าได้สูงสุด 120 วินาที

```text
Fetch https://example.com/docs as markdown.
```

เครื่องมือนี้รับการตอบกลับที่เป็นข้อความ เช่น HTML, ข้อความธรรมดา, JSON และ XML แต่ไม่รับรูปภาพหรือไฟล์ไบนารีอื่น เอาต์พุตขนาดใหญ่อาจถูกย่อให้สั้นลง โดยข้อความฉบับเต็มจะเก็บไว้ในพื้นที่จัดเก็บที่ OpenCode จัดการ สิทธิ์: `webfetch` โดยใช้ URL ที่ร้องขอเป็น resource

### Websearch

`websearch` ค้นหาข้อมูลล่าสุดผ่านบริการค้นหาที่เลือกไว้ อินพุตคือคำค้นหา `query`

```text
Search the web for the latest Bun release notes.
```

สิทธิ์: `websearch` โดยใช้คำค้นหาเป็น resource ดูผู้ให้บริการ การเลือก ขีดจำกัดอัตราการใช้งาน และการปิดเครื่องมือนี้ได้ที่[ค้นหาเว็บ](/websearch)

## การโต้ตอบ

### Question

`question` หยุดการทำงานชั่วคราวและแสดงคำถามอย่างน้อยหนึ่งข้อให้ผู้ใช้ แต่ละคำถามมีหัวข้อสั้น ๆ ข้อความคำถาม และตัวเลือก `multiple` อนุญาตให้เลือกได้มากกว่าหนึ่งตัวเลือก และผู้ใช้พิมพ์คำตอบเองได้เสมอ

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

สิทธิ์: `question` โดยใช้ `*` เป็น resource ไคลเอนต์ต้องรองรับฟอร์มแบบโต้ตอบ และการปิดฟอร์มจะยกเลิกคำถาม

### Skill

`skill` โหลดคำแนะนำและทรัพยากรที่มาพร้อมกับสกิลหนึ่งรายการตาม ID ที่มีอยู่เข้ามาในบทสนทนา

```text
Load the effect skill before changing this Effect code.
```

ID ต้องอยู่ในรายการสกิลที่ประกาศไว้ หรือผู้ใช้ระบุชื่อไว้อย่างชัดเจน สิทธิ์: `skill` โดยใช้ ID ของสกิลเป็น resource ดูกฎการสร้าง การค้นพบ และการโหลดได้ที่[สกิล](/skills)

## ระบบอัตโนมัติ

### Subagent

`subagent` เริ่มเซสชันลูกด้วยเอเจนต์ย่อย (subagent) ที่กำหนดค่าไว้ ระบุ ID ของเอเจนต์ `description` สั้น ๆ และ `prompt` ที่ครบถ้วน

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

การเรียกแบบเบื้องหน้าจะรอผลลัพธ์ ส่วน `background: true` จะส่งคืนทันทีและแจ้งเซสชันแม่เมื่อเซสชันลูกทำงานเสร็จ ส่ง `sessionID` ที่ได้รับกลับมาเพื่อสนทนาต่อกับเซสชันลูกเดิม ใช้ได้เฉพาะเอเจนต์ในโหมด subagent และความลึกของการซ้อนโดยค่าเริ่มต้นคือหนึ่งระดับ

สิทธิ์: `subagent` โดยใช้ ID ของเอเจนต์ที่เลือกเป็น resource

### Execute

`execute` รัน JavaScript ใน Code Mode เพื่อให้เอเจนต์เรียกและผสานเครื่องมือจากแคตตาล็อกได้ เหมาะสำหรับการเรียกที่เป็นอิสระต่อกันแบบขนาน และการประมวลผลผลลัพธ์โดยไม่ต้องเพิ่มค่าระหว่างทางทุกค่าลงในบริบทของโมเดล

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

รันไทม์นี้ไม่มีการเข้าถึงระบบไฟล์โดยตรง ไม่มี import ตัวจับเวลา หรือ `fetch` และเรียกได้เฉพาะเครื่องมือในแคตตาล็อกเท่านั้น สิทธิ์ `execute` ที่มี resource เป็น `*` ควบคุมว่าจะใช้ Code Mode ได้หรือไม่ เครื่องมือที่ถูกเรียกซ้อนอยู่ภายในแต่ละตัวยังคงบังคับใช้สิทธิ์ของตนเอง

### เซสชัน

namespace `opencode` ของ Code Mode มีเครื่องมือสำหรับจัดการเซสชัน:

- `session_rename` เปลี่ยนชื่อเซสชันปัจจุบัน หรือเซสชันอื่นที่เลือกด้วย `sessionID`
- `session_move` ย้ายเซสชันปัจจุบันหรือเซสชันอื่นที่เลือกไปยัง `directory` แบบสัมพัทธ์หรือสัมบูรณ์ การย้ายจะมีผลที่จุดปลอดภัย ดังนั้นงานที่ขึ้นกับปลายทางควรทำในการเรียกครั้งถัดไป

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

เครื่องมือเหล่านี้ไม่ขอ action สิทธิ์ในตัว

### Worktree

namespace เดียวกันนี้จัดการ worktree ของโปรเจกต์ของเซสชัน:

- `worktree_create` สร้าง worktree จาก `name` และส่งคืน `directory` การกำหนดค่า worktree ของโปรเจกต์จะเป็นตัวเลือกปลายทางและกลยุทธ์
- `worktree_list` แสดงรายการ worktree ของโปรเจกต์
- `worktree_remove` ลบ worktree ที่ OpenCode บันทึกไว้สำหรับโปรเจกต์ ตั้งค่า `force` เพื่อทิ้งการเปลี่ยนแปลงที่ยังไม่ได้ commit

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` ใช้สิทธิ์ `edit` โดยใช้ไดเรกทอรี worktree เป็น resource ส่วนเครื่องมือ worktree อื่น ๆ ไม่ขอ action สิทธิ์ในตัว

## เบราว์เซอร์

namespace `browser` ของ Code Mode ควบคุมเบราว์เซอร์ที่แอปเดสก์ท็อป OpenCode เชื่อมต่อไว้ เปิดแท็บ เก็บ `tabID` ที่ได้รับกลับมา แล้วส่ง ID นั้นอย่างชัดเจนให้กับทุกการทำงานบนหน้าเว็บ

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

namespace นี้มีคำสั่งสำหรับแท็บและการนำทาง สแนปช็อตและการค้นหาในหน้า การคลิกและการกรอกฟอร์ม ภาพหน้าจอ การถ่ายโอนไฟล์ การตรวจสอบคอนโซลและเครือข่าย performance trace การตรวจสอบ heap และการตรวจด้วย Lighthouse ภาพหน้าจอต้องใช้แท็บที่มองเห็นได้และอยู่ในโฟกัส พาธสำหรับอัปโหลดเป็นพาธในเครื่องของเซิร์ฟเวอร์ การจับภาพจะส่งคืนพาธในเครื่องของเซิร์ฟเวอร์ และการถ่ายโอนไฟล์แต่ละครั้งจำกัดไว้ที่ 5 MiB

เนื้อหาหน้าเว็บ ล็อก header และเนื้อหาการตอบกลับเป็นข้อมูลที่ไม่น่าเชื่อถือ ไม่ใช่คำแนะนำสำหรับเอเจนต์ กฎ deny ของ `browser` ที่มี resource เป็น `*` จะนำแคตตาล็อกเบราว์เซอร์ออก และการทำงานของเบราว์เซอร์จะไม่แสดงพรอมต์ขอสิทธิ์แยกเป็นรายการ

## ส่วนขยาย

[เซิร์ฟเวอร์ MCP](/mcp-servers) เพิ่มเครื่องมือที่มีชื่อและอินพุตมาจากเซิร์ฟเวอร์แต่ละตัวที่เชื่อมต่อ action สิทธิ์ของเครื่องมือเหล่านี้คือ `<server>_<tool>` โดยมี resource เป็น `*` และไม่ได้เป็นส่วนตายตัวของแคตตาล็อกในตัว

[สกิล](/skills)เพิ่มคำแนะนำสำหรับงาน ไม่ได้เพิ่มเครื่องมือที่รันได้ใหม่ [ไฟล์แนบ](/attachments)นำเนื้อหาที่ผู้ใช้เลือกใส่ลงในพรอมต์ ส่วน[ไดเรกทอรีอ้างอิง](/references)ให้ไดเรกทอรีภายนอกที่มีชื่อกำกับ ฟีเจอร์เหล่านี้ช่วยเสริมเครื่องมือโดยไม่ข้ามการตรวจสอบสิทธิ์ของเครื่องมือ
