---
title: "เซิร์ฟเวอร์ MCP"
---

OpenCode เชื่อมต่อกับเซิร์ฟเวอร์ [Model Context Protocol](https://modelcontextprotocol.io/) และเปิดให้ใช้ความสามารถต่าง ๆ เช่น เครื่องมือ พรอมต์ resource และคำแนะนำ เครื่องมือ MCP ใช้พื้นที่บริบทของโมเดล จึงควรเพิ่มเฉพาะเซิร์ฟเวอร์ที่จำเป็นเท่านั้น

## การตั้งค่า

เพิ่มเซิร์ฟเวอร์ระยะไกลจากโปรเจกต์ที่จะใช้งาน แล้วตรวจสอบการเชื่อมต่อ:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
opencode mcp list
```

คำสั่งนี้จะเขียนเซิร์ฟเวอร์ลงใน[การกำหนดค่า](/config)ของโปรเจกต์ เพิ่ม `--global` เพื่อให้ใช้งานได้ในทุกโปรเจกต์:

```sh
opencode mcp add context7 --global --url https://mcp.context7.com/mcp
```

เซิร์ฟเวอร์ระยะไกลใช้ OAuth โดยค่าเริ่มต้น หากรายการแสดง `needs authentication` ให้เปิด OpenCode รัน `/mcps` เลือกเซิร์ฟเวอร์ แล้วลงชื่อเข้าใช้ เมื่อเซิร์ฟเวอร์เชื่อมต่อแล้ว เอเจนต์ก็พร้อมใช้งานได้ทันที:

```text
✓ context7  connected
```

## การกำหนดค่า

หากต้องการกำหนดค่าเซิร์ฟเวอร์ด้วยตนเอง ให้ตั้งชื่อที่ไม่ซ้ำกันไว้ใต้ `mcp.servers` ใน V2 จะไม่วางชื่อเซิร์ฟเวอร์ไว้ใต้ `mcp` โดยตรง

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
      },
    },
  },
}
```

เซิร์ฟเวอร์จะเชื่อมต่อโดยอัตโนมัติ หากต้องการเก็บการกำหนดค่าไว้โดยไม่เชื่อมต่อ ให้ใช้ `disabled` ไม่ใช่ฟิลด์ `enabled`:

```jsonc
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
        "disabled": true,
      },
    },
  },
}
```

การกำหนดค่าโปรเจกต์ที่มีลำดับความสำคัญสูงกว่าจะแทนที่ออบเจกต์เซิร์ฟเวอร์ที่มีชื่อเดียวกันทั้งออบเจกต์ ให้ใช้ชื่อต่างกันสำหรับการเชื่อมต่อหรือบัญชีที่แยกกัน มิฉะนั้นต้องระบุทุกฟิลด์ที่จำเป็นซ้ำในการแทนที่ (override):

```jsonc title="opencode.jsonc"
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
      },
    },
  },
}
```

## ในเครื่อง

เซิร์ฟเวอร์ในเครื่องคือคำสั่งที่ OpenCode เริ่มทำงานผ่าน MCP stdio transport เพิ่มเซิร์ฟเวอร์โดยระบุคำสั่งต่อจาก `--`:

```sh
opencode mcp add everything -- npx -y @modelcontextprotocol/server-everything
```

ใช้การกำหนดค่าสำหรับตัวเลือกของโปรเซส เช่น ไดเรกทอรีทำงานหรือตัวแปรสภาพแวดล้อม:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "everything": {
        "type": "local",
        "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
        "cwd": ".",
        "environment": {
          "LOG_LEVEL": "info",
          "MCP_API_KEY": "{env:MCP_API_KEY}",
        },
      },
    },
  },
}
```

| ฟิลด์ | จำเป็น | คำอธิบาย |
| --- | --- | --- |
| `type` | ใช่ | ต้องเป็น `"local"` |
| `command` | ใช่ | ไฟล์ executable ตามด้วยอาร์กิวเมนต์ |
| `cwd` | ไม่ | ไดเรกทอรีของโปรเซส พาธสัมพัทธ์จะ resolve จาก workspace ซึ่งเป็นค่าเริ่มต้นด้วย |
| `environment` | ไม่ | ตัวแปรแบบสตริงที่เพิ่มเข้าไปในสภาพแวดล้อมของโปรเซสที่สืบทอดมาจาก OpenCode |
| `disabled` | ไม่ | ป้องกันการเชื่อมต่อเมื่อเป็น `true` ค่าเริ่มต้นคือ `false` |
| `codemode` | ไม่ | ตั้งค่าเป็น `false` เพื่อเปิดให้ใช้เครื่องมือโดยตรงแทนการใช้ผ่าน Code Mode ค่าเริ่มต้นคือ `true` |
| `timeout` | ไม่ | ค่าเวลาหมดที่แทนที่ค่าเริ่มต้นสำหรับเซิร์ฟเวอร์นี้ |
| `protocol` | ไม่ | `legacy` (ค่าเริ่มต้น), `auto` หรือ `2026-07-28` ดู[เวอร์ชันโปรโตคอล](#protocol-version) |

ใช้ `{env:NAME}` เพื่อแทนค่าตัวแปรสภาพแวดล้อม นิพจน์ shell อย่าง `$NAME` จะไม่ถูกขยายในสตริง JSON:

```jsonc
{
  "environment": {
    "MCP_API_KEY": "{env:MCP_API_KEY}",
  },
}
```

## ระยะไกล

เซิร์ฟเวอร์ระยะไกลใช้ MCP Streamable HTTP transport และต้องใช้ URL แบบสัมบูรณ์:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
```

ใช้การกำหนดค่าเมื่อเซิร์ฟเวอร์ต้องการ header หรือตัวเลือกอื่น ๆ เก็บข้อมูลลับไว้ในตัวแปรสภาพแวดล้อมแทนการเขียนลงในไฟล์:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "oauth": false,
        "headers": {
          "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}",
        },
      },
    },
  },
}
```

| ฟิลด์ | จำเป็น | คำอธิบาย |
| --- | --- | --- |
| `type` | ใช่ | ต้องเป็น `"remote"` |
| `url` | ใช่ | endpoint แบบ Streamable HTTP ที่เป็น URL สัมบูรณ์ |
| `headers` | ไม่ | HTTP header แบบสตริงที่ส่งไปยัง endpoint |
| `oauth` | ไม่ | การตั้งค่า OAuth หรือ `false` เพื่อปิด OAuth |
| `disabled` | ไม่ | ป้องกันการเชื่อมต่อเมื่อเป็น `true` ค่าเริ่มต้นคือ `false` |
| `codemode` | ไม่ | ตั้งค่าเป็น `false` เพื่อเปิดให้ใช้เครื่องมือโดยตรงแทนการใช้ผ่าน Code Mode ค่าเริ่มต้นคือ `true` |
| `timeout` | ไม่ | ค่าเวลาหมดที่แทนที่ค่าเริ่มต้นสำหรับเซิร์ฟเวอร์นี้ |
| `protocol` | ไม่ | `legacy` (ค่าเริ่มต้น), `auto` หรือ `2026-07-28` ดู[เวอร์ชันโปรโตคอล](#protocol-version) |

ใช้ `oauth: false` เฉพาะเมื่อเซิร์ฟเวอร์ใช้คีย์ API หรือข้อมูลรับรองผ่าน header อื่นเท่านั้น:

```jsonc
{
  "type": "remote",
  "url": "https://mcp.example.com/mcp",
  "oauth": false,
  "headers": { "Authorization": "Bearer {env:MCP_API_KEY}" },
}
```

## OAuth

OAuth เปิดใช้งานสำหรับเซิร์ฟเวอร์ระยะไกล เว้นแต่ `oauth` จะเป็น `false` OpenCode จะค้นหา authorization server ใช้ PKCE รีเฟรชโทเค็น และพยายามลงทะเบียนไคลเอนต์แบบไดนามิก (dynamic client registration) เมื่อรองรับ โดยข้อมูลรับรองจะเก็บไว้นอกการกำหนดค่าของโปรเจกต์

สำหรับการลงทะเบียนแบบไดนามิก ให้กำหนดค่าเฉพาะ URL ของเซิร์ฟเวอร์:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
      },
    },
  },
}
```

หากเซิร์ฟเวอร์ต้องยืนยันตัวตน ให้รัน `/mcps` เลือกเซิร์ฟเวอร์ แล้วอนุญาตสิทธิ์ให้เสร็จในเบราว์เซอร์ CLI ก็เริ่มขั้นตอนเดียวกันนี้ได้:

```sh
opencode mcp auth sentry
```

เมื่อผู้ให้บริการให้ client credential มา ให้ใช้ฟิลด์ OAuth แบบ snake_case ของ V2:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "company-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "oauth": {
          "client_id": "{env:MCP_CLIENT_ID}",
          "client_secret": "{env:MCP_CLIENT_SECRET}",
          "scope": "tools:read tools:execute",
          "callback_port": 19876,
          "redirect_uri": "http://127.0.0.1:19876/callback",
        },
      },
    },
  },
}
```

| ฟิลด์ | คำอธิบาย |
| --- | --- |
| `client_id` | client ID ที่ลงทะเบียนไว้ล่วงหน้า หากไม่ระบุจะพยายามลงทะเบียนแบบไดนามิก |
| `client_secret` | secret ของไคลเอนต์ที่ลงทะเบียนไว้ล่วงหน้า |
| `scope` | scope ที่จะร้องขอ คั่นด้วยช่องว่าง |
| `callback_port` | พอร์ต callback ในเครื่อง ตั้งแต่ `1` ถึง `65535` ค่าเริ่มต้นคือพอร์ตชั่วคราว (ephemeral) ที่ว่างอยู่ |
| `redirect_uri` | URI แบบ loopback ที่ลงทะเบียนไว้ล่วงหน้า ซึ่งพาธและพอร์ตชี้ไปยังตัวรับ callback ในเครื่อง |
| `auth_server_metadata_url` | URL ของเอกสารเมตาดาตา OAuth หรือ OpenID Connect ของ authorization server ตั้งค่านี้เมื่อเซิร์ฟเวอร์ MCP ไม่ได้เผยแพร่เมตาดาตา protected resource ที่ระบุ authorization server ของตน |

ลบข้อมูลรับรอง OAuth ที่บันทึกไว้เมื่อต้องการลงชื่อเข้าใช้ใหม่หรือสลับบัญชี:

```sh
opencode mcp logout sentry
```

## เวลาหมด

เวลาหมด (timeout) เป็นจำนวนเต็มบวกในหน่วยมิลลิวินาที ตั้งค่าเริ่มต้นไว้ใต้ `mcp.timeout` และออบเจกต์ `timeout` ของแต่ละเซิร์ฟเวอร์จะแทนที่ค่าเริ่มต้นที่ตรงกัน

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "timeout": {
      "startup": 45000,
      "catalog": 30000,
      "execution": 600000,
    },
    "servers": {
      "slow-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "timeout": {
          "catalog": 60000,
        },
      },
    },
  },
}
```

| เวลาหมด | ค่าเริ่มต้น | ใช้กับ |
| --- | --- | --- |
| `startup` | 30 วินาที | การเชื่อมต่อ transport และการเริ่มต้นเซิร์ฟเวอร์ |
| `catalog` | 30 วินาที | การแสดงรายการเครื่องมือ พรอมต์ resource และ resource template |
| `execution` | 12 ชั่วโมง | การเรียกใช้เครื่องมือ การดึงพรอมต์ และการอ่าน resource |

## เวอร์ชันโปรโตคอล

โดยค่าเริ่มต้น OpenCode จะเปิดการเชื่อมต่อกับทุกเซิร์ฟเวอร์ด้วย handshake `initialize` แบบดั้งเดิมของ MCP ตั้งค่า `protocol` ของเซิร์ฟเวอร์เพื่อสื่อสารกับเซิร์ฟเวอร์ที่สร้างบนรุ่นแก้ไข 2026-07-28:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "modern": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "protocol": "auto",
      },
    },
  },
}
```

| ค่า | พฤติกรรม |
| --- | --- |
| `legacy` | ค่าเริ่มต้น ส่ง `initialize` และใช้โปรโตคอลรุ่นแก้ไขได้ถึง 2025-11-25 |
| `auto` | ตรวจหารุ่นแก้ไข 2026-07-28 ด้วย `server/discover` และกลับไปใช้ `legacy` เมื่อเซิร์ฟเวอร์ไม่รองรับ |
| `2026-07-28` | ต้องใช้รุ่นแก้ไข 2026-07-28 การเชื่อมต่อกับเซิร์ฟเวอร์รุ่นเก่ากว่าจะล้มเหลว |

การตรวจหากับเซิร์ฟเวอร์ `legacy` ในเครื่องจะเพิ่มโปรเซสชั่วคราวอีกหนึ่งตัว และอาจต้องรอจนถึงเวลาหมดของการเริ่มต้นเมื่อเซิร์ฟเวอร์เพิกเฉยต่อคำขอที่ไม่รู้จัก จึงควรใช้ `auto` เฉพาะกับเซิร์ฟเวอร์ที่จำเป็นเท่านั้น

## ชื่อ

OpenCode ตั้งชื่อเครื่องมือเป็น `<server>_<tool>` โดยแทนที่อักขระที่ไม่ใช่ตัวอักษร ตัวเลข `_` และ `-` ด้วย `_`:

```text
server: context 7
tool:   resolve.library/id
name:   context_7_resolve_library_id
```

พรอมต์ MCP จะกลายเป็นคำสั่งชื่อ `<server>:<prompt>` โดย normalize แบบเดียวกัน ตัวอย่างเช่น:

```text
/context_7:find_docs
```

เลือกชื่อเซิร์ฟเวอร์สั้น ๆ ที่ยังไม่ซ้ำกันหลัง normalize แล้ว ภายใต้ Code Mode ซึ่งเป็นค่าเริ่มต้น เครื่องมือจะถูกจัดกลุ่มตามชื่อเซิร์ฟเวอร์ที่ normalize แล้ว:

```text
tools.context_7.resolve_library_id(...)
```

## สิทธิ์

Code Mode เป็นค่าเริ่มต้น ตั้งค่า `codemode` เป็น `false` เมื่อต้องการให้เครื่องมือของเซิร์ฟเวอร์อยู่ในรายการเครื่องมือเนทีฟของผู้ให้บริการ:

```jsonc
{
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "codemode": false,
      },
    },
  },
}
```

ใช้ action สิทธิ์เพื่อซ่อนหรือปฏิเสธเครื่องมือโดยไม่ต้องตัดการเชื่อมต่อเซิร์ฟเวอร์ ให้จับคู่กับชื่อ `<server>_<tool>` ที่ normalize แล้ว:

```jsonc
{
  "permissions": [
    {
      "action": "context7_*",
      "resource": "*",
      "effect": "deny",
    },
  ],
}
```

## บริบท

สำหรับการเรียกที่ทำในนามของเซสชัน OpenCode จะส่ง ID ของเซสชันไปใน `CallToolRequest.params._meta["ai.opencode/sessionID"]` ซึ่งใช้กับทั้งเครื่องมือโดยตรงและ Code Mode ผ่าน stdio และ Streamable HTTP:

```json
{
  "method": "tools/call",
  "params": {
    "name": "lookup",
    "arguments": { "query": "example" },
    "_meta": { "ai.opencode/sessionID": "ses_..." }
  }
}
```

ID นี้เป็นเมตาดาตาของคำขอ ไม่ใช่อาร์กิวเมนต์ของเครื่องมือ จึงไม่ปรากฏใน schema ที่โมเดลมองเห็น ให้ถือว่าเป็นค่าสำหรับเชื่อมโยง (correlation) ที่ไม่ควรตีความเนื้อหา:

| กฎ | พฤติกรรม |
| --- | --- |
| ตัวตน | ระบุเซสชัน OpenCode ที่เรียกใช้ ไม่ใช่เซสชันของ MCP transport |
| การมีอยู่ | อาจไม่มีสำหรับการเรียกที่ไม่มีบริบทของเซสชัน |
| ความปลอดภัย | อย่าใช้ค่านี้เพียงอย่างเดียวในการยืนยันตัวตนหรือการอนุญาตสิทธิ์ |
| ความเป็นส่วนตัว | เซิร์ฟเวอร์ระยะไกลจะได้รับ ID ดิบ และอาจบันทึกลงล็อกหรือเก็บไว้ |

## การจัดการ

แสดงรายการเซิร์ฟเวอร์และสถานะการเชื่อมต่อปัจจุบันได้จากทุกโปรเจกต์:

```sh
opencode mcp list
```

ใช้ `/mcps` ใน OpenCode เพื่อดู เชื่อมต่อ ตัดการเชื่อมต่อ หรือยืนยันตัวตนกับเซิร์ฟเวอร์ ใช้ CLI เพื่อเพิ่มเซิร์ฟเวอร์และจัดการข้อมูลรับรอง OAuth:

```sh
opencode mcp add sentry --url https://mcp.sentry.dev/mcp
opencode mcp auth sentry
opencode mcp logout sentry
```

หากต้องการนำเซิร์ฟเวอร์ออก ให้ลบรายการของเซิร์ฟเวอร์นั้นออกจากการกำหนดค่าของโปรเจกต์หรือระดับ global ที่เพิ่มไว้:

```jsonc
{
  "mcp": {
    "servers": {},
  },
}
```

แก้ไขการกำหนดค่าโดยตรงสำหรับการตั้งค่าไคลเอนต์ OAuth เวลาหมด ไดเรกทอรีทำงาน หรือการเปิด/ปิดใช้งานแบบถาวร:

```jsonc
{
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
        "disabled": true,
      },
    },
  },
}
```
