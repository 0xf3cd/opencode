---
title: "การอุ่นเครื่องเซสชัน"
---

การอุ่นเครื่องเซสชัน (warming) จะส่งคำขอไปยังโมเดลเป็นระยะ เพื่อรักษาแคชพรอมต์ฝั่งผู้ให้บริการหรือสถานะอื่นที่มีอายุสั้นไว้ระหว่างที่คุณหยุดพักระหว่างพรอมต์ ฟีเจอร์นี้ปิดใช้งานโดยค่าเริ่มต้น

เปิดใช้งานการอุ่นเครื่องใน[ไฟล์กำหนดค่า OpenCode](/config) ไฟล์ใดก็ได้:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

ด้วยการกำหนดค่านี้ OpenCode จะอุ่นเครื่องเซสชันที่เพิ่งใช้งานเมื่อไม่มีคำขอไปยังโมเดลเป็นเวลาสี่นาที และจะทำต่อทุกสี่นาทีจนครบ 30 นาทีนับจากคำขอล่าสุดที่ไม่ใช่การอุ่นเครื่อง

## ตัวเลือก

ใช้รูปแบบออบเจกต์เพื่อเปลี่ยนพรอมต์สำหรับอุ่นเครื่อง ช่วงเวลาว่าง หรือช่วงเวลาที่ทำงาน:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| ฟิลด์ | ค่าเริ่มต้น | วัตถุประสงค์ |
| --- | --- | --- |
| `prompt` | คำแนะนำสำหรับ keep-alive | ต่อท้ายเป็นข้อความผู้ใช้ชั่วคราวในทุกคำขออุ่นเครื่อง ค่าเริ่มต้นจะขอให้โมเดลไม่ทำงานใด ๆ ไม่ใช้เครื่องมือ และตอบกลับด้วย `OK` |
| `interval` | `"4 minutes"` | ระยะเวลาว่างก่อนส่งคำขออุ่นเครื่องครั้งถัดไป |
| `duration` | `"30 minutes"` | ช่วงเวลาอุ่นเครื่อง นับจากคำขอล่าสุดไปยังโมเดลที่ไม่ใช่การอุ่นเครื่อง |

ฟิลด์ที่ไม่ได้ระบุในออบเจกต์จะใช้ค่าเริ่มต้น ตัวอย่างนี้เปลี่ยนเฉพาะ `interval`:

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## ระยะเวลา

`interval` และ `duration` รับสตริงระยะเวลา ทั้งสองค่าต้องได้ค่าที่จำกัดและมากกว่าศูนย์ มิฉะนั้น OpenCode จะข้ามการอุ่นเครื่องและบันทึกคำเตือนลงในล็อก

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## จังหวะเวลา

การอุ่นเครื่องจะเริ่มหลังคำขอไปยังโมเดลที่ไม่ใช่การอุ่นเครื่อง หลังคำขออุ่นเครื่องเสร็จสิ้น ช่วงเวลาว่างรอบถัดไปจะเริ่มนับ แต่ช่วงเวลาที่ทำงานจะไม่ถูกขยายออกไป

```text
00:00  normal model request
00:04  warming request
00:08  warming request
00:30  warming stops
```

กิจกรรมใหม่ของโมเดลที่ไม่ใช่การอุ่นเครื่องจะรีเซ็ตตัวจับเวลาทั้งสอง หาก `interval` ยาวเท่ากับหรือยาวกว่า `duration` ช่วงเวลาที่ทำงานจะหมดลงก่อนที่จะมีการส่งคำขออุ่นเครื่อง

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

## คำขอ

คำขออุ่นเครื่องใช้โมเดล เอเจนต์ คำแนะนำ และบริบทบทสนทนาปัจจุบันของเซสชัน OpenCode จะต่อท้ายพรอมต์ที่กำหนดไว้แบบชั่วคราว เรียกโมเดลหนึ่งครั้ง แล้วทิ้งการตอบกลับ

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

คำขอนี้ไม่รับอินพุตเข้าเซสชัน ไม่เพิ่มข้อความลงในประวัติ และไม่เปลี่ยนสถานะเซสชันที่บันทึกถาวร OpenCode ไม่เรียกใช้เครื่องมือในเครื่องหรือทำลูปเครื่องมือต่อ และพรอมต์เริ่มต้นก็บอกโมเดลไม่ให้ใช้เครื่องมือด้วย

## ความล้มเหลว

ความล้มเหลวของการอุ่นเครื่องจะถูกบันทึกลงในล็อกโดยไม่ทำให้เซสชันล้มเหลวหรือเปลี่ยนแปลง OpenCode จะรอจนครบช่วงเวลาว่างรอบถัดไปก่อนลองใหม่ ขณะที่ช่วงเวลาที่ทำงานเดิมยังคงนับถอยหลังต่อไป

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

## ค่าใช้จ่าย

คำขออุ่นเครื่องเป็นคำขอจริงไปยังผู้ให้บริการ จึงอาจใช้โทเค็น มีค่าใช้จ่าย นับรวมในขีดจำกัดอัตราการใช้งาน และล้มเหลวได้เหมือนคำขออื่นไปยังโมเดล

- `interval` ที่สั้นลงจะเพิ่มจำนวนคำขอ
- `duration` ที่ยาวขึ้นจะทำให้มีคำขออุ่นเครื่องได้มากขึ้น
- เปิดใช้งานการอุ่นเครื่องเฉพาะเมื่อประโยชน์ที่ได้ฝั่งผู้ให้บริการคุ้มกับการใช้งานที่เพิ่มขึ้น

ตัวอย่างเช่น ค่าเริ่มต้นอนุญาตให้อุ่นเครื่องได้สูงสุดเจ็ดครั้งในช่วงเวลา 30 นาทีที่ไม่ถูกขัดจังหวะ คือที่นาทีที่ 4, 8, 12, 16, 20, 24 และ 28

## การปิดใช้งาน

ตั้งค่า `warming` เป็น `false` เพื่อปิดใช้งานอย่างชัดเจน การไม่ระบุฟิลด์นี้ก็ทำให้การอุ่นเครื่องยังคงปิดอยู่เช่นกัน

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
