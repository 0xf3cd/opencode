title: "ปุ่มลัด"
---

ปรับแต่งการผูกปุ่มได้ใน `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

ใช้สตริงสำหรับปุ่มเดียว:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

คั่นปุ่มทางเลือกด้วยเครื่องหมายจุลภาค:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

ปิดการผูกปุ่มด้วย `"none"` หรือ `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

ใช้อ็อบเจกต์เพื่อกำหนดการทำงานของอีเวนต์:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

ค่าเริ่มต้นของ `leader` คือ `ctrl+x` และ `<leader>` ในการผูกปุ่มอื่นจะหมายถึงปุ่มนั้น

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

ID คำสั่งที่ไม่รู้จักจะถูกปฏิเสธ

## ตัวแสดง Diff

กด `d` (`diff.switch_source`) เพื่อเลือก **All**, **Committed**, **Uncommitted** หรือ **Last turn** (ภายในเซสชัน) หรือเลือก **Base** เพื่อเปลี่ยนบรานช์ที่ใช้เปรียบเทียบ ตัวเลือกจะถูกจดจำไว้จนกว่าจะออกจาก TUI กำหนดขอบเขตเริ่มต้นได้ด้วย [`diffs.source` ใน `cli.json`](/cli/config#diffs)

ปุ่มลัดสำหรับการเลื่อน การเลื่อนทีละหน้า และการไปยังจุดเริ่มต้น/จุดสิ้นสุดจะควบคุม diff เสมอ ไม่มีการสลับโฟกัสด้วยแป้นพิมพ์ ให้คลิกไฟล์เพื่อเปิด คลิกโฟลเดอร์เพื่อขยายหรือยุบ และใช้ล้อเมาส์เพื่อเลื่อนแผนผังไฟล์

ใช้ `n` / `p` หรือ `alt+down` / `alt+up` (ปุ่ม Option บน macOS) เพื่อย้ายไปมาระหว่างไฟล์ ภายในตัวแสดง diff ปุ่มลัด Alt จะใช้นำทางระหว่างไฟล์แทนแท็บเซสชัน

กด `m` เพื่อทำเครื่องหมายว่ารีวิวไฟล์แล้วและยุบเนื้อหา patch ในมุมมองทุกไฟล์ กด `m` อีกครั้งเพื่อยกเลิกเครื่องหมายและเปิด patch อีกครั้ง มุมมองไฟล์เดียวจะเลื่อนไปยังไฟล์ถัดไปโดยอัตโนมัติเมื่อทำเครื่องหมายว่ารีวิวแล้ว แต่จะหยุดอยู่ที่ไฟล์สุดท้ายโดยไม่วนกลับไปไฟล์แรก การยกเลิกเครื่องหมายจะไม่เลื่อนไปไฟล์ถัดไป

คลิกขวาที่ไฟล์ในแถบด้านข้างหรือที่หัวข้อ diff ของไฟล์เพื่อเลือก **Mark complete** (หรือ **Mark incomplete**) ซึ่งเปลี่ยนสถานะการรีวิวเดียวกับ `m` การทำเครื่องหมายว่าเสร็จให้ไฟล์อื่นจากเมนูจะไม่เลือกไฟล์นั้นและไม่เลื่อนไฟล์ที่กำลังอ่านอยู่

ปุ่มทางเลือกแบบมี Shift ของ `diff.help` มีไว้รองรับเทอร์มินัลที่รายงานปุ่ม Shift เมื่อกด `?`
