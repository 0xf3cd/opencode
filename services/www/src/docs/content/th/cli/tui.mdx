รัน OpenCode จากโปรเจกต์ของคุณ พิมพ์คำขอ แล้วกด **Enter**

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

กด **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** หรือ **Ctrl+J** เพื่อขึ้นบรรทัดใหม่ ขณะที่ OpenCode กำลังทำงาน **Enter** จะส่งพรอมต์เข้าไปกำกับเซสชันที่ทำงานอยู่ (steer) หากต้องการเข้าคิวพรอมต์ไว้ทีหลัง ให้กด **Ctrl+X** แล้วกด **Enter**

## บริบท

พิมพ์ `@` เพื่อค้นหาไฟล์ แล้วเลือกไฟล์เพื่อแนบเข้ากับพรอมต์ พิมพ์ต่อหลัง `@` เพื่อกรองผลลัพธ์ให้แคบลง

```text
Review @src/auth.ts for error handling problems
```

ระบุบรรทัดหรือช่วงบรรทัดต่อท้ายพาธได้

```text
Explain @src/auth.ts#20-45
```

## Shell

พิมพ์ `!` ที่ต้นพรอมต์ที่ว่างอยู่เพื่อเข้าสู่โหมด shell ป้อนคำสั่งแล้วกด **Enter** หรือกด **Esc** เพื่อออกจากโหมด shell โดยไม่รันคำสั่ง

```text
!git status
```

คำสั่ง shell จะรันในไดเรกทอรีทำงานของเซสชัน และเอาต์พุตจะอยู่ในเซสชัน

## คำสั่ง

พิมพ์ `/` เพื่อแสดงรายการคำสั่งสแลช (slash command) พิมพ์ต่อเพื่อกรองรายการ แล้วกด **Enter** เพื่อรันคำสั่งที่เลือก

```text
/models
```

คำสั่งที่ใช้บ่อยได้แก่ `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` และ `/editor` กด **Ctrl+P** เพื่อเปิดชุดคำสั่ง (command palette) ที่รวมทุกการกระทำที่ใช้ได้ในมุมมองปัจจุบัน

หลังอัปเดต OpenCode จะแสดงสิ่งใหม่ในรีลีสนั้นหนึ่งครั้งที่หน้าจอหลัก รัน `/highlights` เพื่อดูอีกครั้ง หรือตั้งค่า `"highlights": false` ใน [`cli.json`](/cli/config#alerts) เพื่อไม่ให้เปิดขึ้นมาโดยอัตโนมัติ

## คำถามแทรก

รัน `/btw <question>` เพื่อถามคำถามสั้น ๆ เกี่ยวกับบทสนทนาที่ผ่านมา คำตอบจะใช้บริบทและโมเดลปัจจุบันของเซสชัน แต่จะไม่ถูกเพิ่มลงในบทสนทนา จึงไม่มีผลกับพรอมต์ถัด ๆ ไป ขณะทำงานจะมีตัวบ่งชี้ `/btw` แสดงที่ส่วนท้ายของพรอมต์ และคำตอบจะเปิดในกล่องโต้ตอบ กด **C** เพื่อคัดลอก

```text
/btw why did the test in step 2 fail?
```

## โมเดล

กด **Ctrl+X** แล้วกด **M** เพื่อเลือกโมเดล หรือรัน `/models` กด **F2** เพื่อสลับไปยังโมเดลที่ใช้ล่าสุดทีละตัว

กด **Ctrl+X** แล้วกด **A** เพื่อเลือกเอเจนต์ หรือรัน `/agents` กด **Shift+Tab** เพื่อสลับเอเจนต์ทีละตัว

## เซสชัน

กด **Ctrl+X** แล้วกด **N** เพื่อเริ่มเซสชันใหม่ กด **Ctrl+X** แล้วกด **L** หรือรัน `/sessions` เพื่อกลับไปยังเซสชันที่มีอยู่ ส่วน **Ctrl+O** จะเปิดเซสชันและโปรเจกต์ล่าสุดพร้อมกัน

แท็บเปิดใช้งานอยู่โดยค่าเริ่มต้น ใช้ **Ctrl+Tab** และ **Ctrl+Shift+Tab** เพื่อสลับระหว่างแท็บ กด **Ctrl+X** แล้วกด **W** เพื่อปิดแท็บ และกด **Ctrl+Shift+T** เพื่อเปิดแท็บที่ปิดล่าสุดอีกครั้ง

## ประวัติ

กด **Ctrl+X** แล้วกด **U** หรือรัน `/undo` เพื่อย้อนข้อความล่าสุดของผู้ใช้และงานที่ตามมาหลังจากนั้น พรอมต์ที่ถูกย้อนจะกลับไปอยู่ในช่องเขียนพรอมต์เพื่อให้แก้ไขได้

กด **Ctrl+X** แล้วกด **R** หรือรัน `/redo` เพื่อกู้คืนงานที่ถูกย้อน หากส่งพรอมต์ใหม่แทน จะถือว่ายอมรับการย้อนนั้นและทำงานต่อจากจุดดังกล่าว

## ตัวแก้ไข

ตั้งค่า `VISUAL` หรือ `EDITOR` แล้วกด **Ctrl+X** ตามด้วย **E** หรือรัน `/editor` เพื่อแก้ไขพรอมต์ปัจจุบันในตัวแก้ไขนั้น บันทึกและออกเพื่อนำข้อความกลับมายังช่องเขียนพรอมต์ แล้วกด **Enter** เพื่อส่ง

```bash
export EDITOR="nvim"
opencode
```

ปุ่ม leader โดยค่าเริ่มต้นคือ **Ctrl+X** ดูวิธีเปลี่ยนปุ่มลัดเหล่านี้ได้ที่[ปุ่มลัด](/cli/keybinds)
