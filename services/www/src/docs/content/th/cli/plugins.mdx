---
title: "ปลั๊กอิน"
---

CLI จะโหลดปลั๊กอินที่กำหนดค่าไว้ใน `opencode.json(c)` และมีคอมโพเนนต์ TUI ให้โดยอัตโนมัติ ดูวิธีสร้างปลั๊กอินได้ที่[การสร้างปลั๊กอิน](/build/plugins) ไม่จำเป็นต้องเพิ่มแพ็กเกจเดียวกันลงใน `cli.json` เนื่องจาก CLI ดึงรายการปลั๊กอินที่ใช้งานอยู่จากเซิร์ฟเวอร์ OpenCode ที่เชื่อมต่อ วิธีนี้จึงใช้ได้แม้เซิร์ฟเวอร์จะอยู่ระยะไกล

ใช้ `cli.json` สำหรับปลั๊กอินเฉพาะ CLI ปลั๊กอินเหล่านี้รันในเทอร์มินัลบนเครื่อง และยังคงทำงานอยู่เมื่อ CLI เชื่อมต่อกับเซิร์ฟเวอร์ระยะไกล:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

รายการจะได้รับการประมวลผลตามลำดับ ใส่ `-` นำหน้า ID หรือ wildcard เพื่อปิดใช้งานปลั๊กอินที่ตรงกัน:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

ส่งตัวเลือกให้ปลั๊กอินด้วยรูปแบบอ็อบเจกต์:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode ยังค้นหาปลั๊กอินในไดเรกทอรีกำหนดค่าส่วนกลางและไดเรกทอรี `.opencode` ของโปรเจกต์ด้วย ปลั๊กอินแต่ละตัวใช้โครงสร้างเดียวกับแพ็กเกจที่เผยแพร่ โดยเก็บ entrypoint ของเซิร์ฟเวอร์และ TUI ไว้ด้วยกัน

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

ปลั๊กอินที่ค้นพบสามารถ import `@opencode/plugin/tui` ได้โดยตรง เพราะ OpenCode จะ resolve แพ็กเกจนี้ขณะรันไทม์ ดูตัวอย่างได้ที่[การสร้างปลั๊กอิน CLI](/build/plugins/cli)
