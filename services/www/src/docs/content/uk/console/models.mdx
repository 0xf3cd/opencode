OpenCode Console надає список моделей, протестованих і перевірених командою OpenCode. Увійдіть, додайте кредити та
отримайте ключ API, щоб користуватися ними в OpenCode або іншому агенті для програмування.

Console працює так само, як будь-який інший провайдер в OpenCode. Вона **повністю необов'язкова**: натомість можна
використовувати будь-якого іншого провайдера. Якщо вам потрібна підписка з включеним обсягом використання,
перегляньте [OpenCode Go](/console/go).

## Як це працює

1. Увійдіть в [OpenCode Console](https://opencode.ai/console), додайте платіжні дані та кредити й скопіюйте свій
   ключ API.
2. Виконайте `/connect` в інтерфейсі TUI, виберіть провайдера OpenCode з оплатою за використання та вставте свій ключ
   API.

   ```text
   /connect
   ```

3. Виконайте `/models`, щоб переглянути доступні моделі та вибрати одну з них.

   ```text
   /models
   ```

Оплата стягується за кожен запит, а кредити можна поповнювати у своєму обліковому записі.

### Jev

Jev — це модель System One від TypeSafe AI для швидких структурованих рішень. Замість генерування тексту вона оцінює `state` за типізованими запитаннями та повертає значення й імовірності, які ваш код може використовувати безпосередньо. Підтримуються запитання типу «так/ні» (`noul`), з вибором варіанта (`choice`) і з оцінюванням за критеріями (`score`).

Використовуйте свій ключ API OpenCode Console з ендпоінтом `https://opencode.ai/inference/v1/systemone`. Цей приклад перевіряє, чи є звернення до служби підтримки терміновим:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

В одному запиті можна поставити кілька запитань. Jev оцінює їх паралельно й повертає кожну відповідь під ID відповідного запитання:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Щоб скористатися безкоштовною моделлю, доступною обмежений час, вкажіть `jev-1.13-free` замість `jev-1.13`. Докладніше про типи запитань і поля відповіді читайте в [документації TypeSafe AI](https://docs.typesafe.ai/).

## Передісторія

Моделей існує багато, але лише деякі добре працюють як агенти для програмування. До того ж провайдери відрізняються
конфігурацією, продуктивністю та якістю, тож модель, доступна через шлюз на кшталт OpenRouter, може працювати інакше.

<Callout type="tip">Ми протестували добірку моделей і провайдерів, які добре працюють з OpenCode.</Callout>

Щоб сформувати цей каталог, ми:

1. Протестували добірку моделей і поспілкувалися з їхніми командами про те, як найкраще їх запускати.
2. Працювали з провайдерами, щоб переконатися, що моделі обслуговуються правильно.
3. Провели бенчмарки кожної комбінації моделі й провайдера, щоб скласти список, який ми можемо впевнено рекомендувати.

Console — це AI-шлюз, що надає доступ до цих моделей.

## Цілі

Ми створили Console, щоб:

1. **Порівнювати в бенчмарках** найкращі моделі та провайдерів для агентів для програмування.
2. Надавати варіанти **найвищої якості** без зниження продуктивності чи перенаправлення до дешевших провайдерів.
3. Передавати вам **зниження цін**, продаючи за собівартістю з націнкою лише на покриття комісій за обробку платежів.
4. **Не прив'язувати** вас: використовуйте Console з будь-яким агентом для програмування або іншого провайдера з OpenCode.
