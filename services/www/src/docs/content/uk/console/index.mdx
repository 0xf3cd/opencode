[OpenCode Console](https://opencode.ai/console) — це необов'язковий сервіс, який розширює можливості OpenCode як для
індивідуальної роботи, так і для команд.

- [Робочі простори](/console/workspaces) для спільного доступу вашої [команди](/console/members)
- [Інференс](/console/models) для пропрієтарних моделей і моделей з відкритим кодом
- [Провайдери](/console/providers) для підключення власних облікових записів провайдерів через шлюз Console
- Відстеження використання та контроль [бюджету](/console/budgets)
- Політики для всієї команди, що керують поведінкою OpenCode
- [Вебпошук](/console/websearch)
- [OpenCode Go і Go Plus](/console/go) — підписки за $10 і $40 на місяць із доступом до моделей з відкритим кодом

## Початок роботи

Щоб користуватися Console, команда не потрібна. Кожен обліковий запис отримує робочий простір **Personal**, у якому ви
єдиний учасник.

1. Увійдіть в [OpenCode Console](https://opencode.ai/console).
2. Оформіть підписку [Go](/console/go), додайте [кредити](/console/billing#add-credits) або підключіть
   [провайдера](/console/providers).
3. Виконайте `/connect` в OpenCode і виберіть робочий простір.
4. За бажанням [запросіть](/console/members#invite-members) свою команду.

```text
/connect
```

## Політики

Правила Providers і Tools зі сторінки Policies застосовуються до кожного клієнта OpenCode V2, підключеного до робочого
простору. Вони надходять як інструкції [політики](/policies#console), що мають остаточний пріоритет над власною
конфігурацією учасника, і набувають чинності приблизно протягом хвилини.
