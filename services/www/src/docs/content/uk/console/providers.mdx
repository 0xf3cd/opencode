Підключіть облікові записи провайдерів, за які ви вже платите, наприклад Anthropic, OpenAI або AWS Bedrock, і відкрийте
їхні моделі для всіх у робочому просторі. Console зберігає облікові дані й обслуговує кожного провайдера через свій
шлюз, тож учасники користуються моделями, жодного разу не бачачи ключа провайдера. Той самий шлюз доступний і для
ваших власних інструментів через [Providers API](/console/api/providers).

Власники та адміністратори керують провайдерами на вкладці **Providers**. Учасники отримують увімкнені моделі
в OpenCode після виконання `/connect`.

## Підключення провайдера

1. Відкрийте **Providers** і натисніть **Connect Provider**.
2. Виберіть провайдера з каталогу та введіть його ключ API.
3. За бажанням натисніть **Test connection**, а потім **Save**.

Каталог містить Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter та багато інших. Моделі
провайдерів із каталогу вже попередньо налаштовано.

### Хмарні провайдери

Хмарним провайдерам потрібно кілька додаткових параметрів.

| Провайдер             | Параметри                                 |
| --------------------- | ----------------------------------------- |
| Azure                 | Назва ресурсу та ключ API                 |
| AWS Bedrock           | Регіон і ключ API                         |
| Google Vertex AI      | Регіон і JSON сервісного облікового запису |
| Cloudflare AI Gateway | Account ID, Gateway ID і токен API        |
| Databricks            | URL-адреса робочого простору та токен     |

### Власні провайдери

Натисніть **Add Custom Provider**, щоб підключити будь-який інший ендпоінт, а потім додайте його моделі кнопкою
**Add Model**.

| Поле       | Опис                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| Base URL   | Куди Console пересилає запити, наприклад `https://api.deepseek.com/v1`.               |
| Format     | Chat Completions, Responses API, Anthropic Compatible або Google Generative AI.      |
| Auth mode  | Bearer, заголовок ключа API або власний заголовок.                                   |
| Credential | Ключ, який Console надсилає провайдеру.                                              |

## Вибір моделей

Відкрийте провайдера, щоб побачити його моделі. Учасникам доступні лише увімкнені моделі.

- Перемикач **Enabled** вмикає або вимикає модель.
- Увімкніть **New models**, щоб автоматично вмикати моделі, які провайдер додасть у майбутньому.

## Редагування моделей

Натисніть модель, щоб її відредагувати. Зміни зберігаються, коли ви закриваєте панель.

| Розділ        | Що можна змінити                                                                 |
| ------------- | -------------------------------------------------------------------------------- |
| General       | Відображувана назва, API ID, підтримка інструментів, типи вхідних і вихідних даних |
| Variants      | Варіанти з власними заголовками або тілом запиту                                 |
| Configuration | Варіант за замовчуванням, заголовки й тіло запиту, ліміти токенів                |
| Cost Tiers    | Ціни на вхідні та вихідні токени, читання й запис кешу за 1M токенів             |

### Власні ціни

Моделі з каталогу спочатку мають прайсову ціну провайдера. Якщо у вас є узгоджені ціни, наприклад знижка за договором
з OpenAI, перевизначте ціни в розділі **Cost Tiers**, щоб звіти про використання та [бюджети](/console/budgets)
відповідали тому, що ви фактично платите.

| Поле             | Прайсова ціна | Ваша ціна |
| ---------------- | ------------- | --------- |
| Input price      | $2.50         | $2.00     |
| Output price     | $15.00        | $12.00    |
| Cache read price | $0.25         | $0.20     |

Змінені ціни виділяються на сторінці провайдера. Щоб повернути прайсову ціну, скористайтеся **Restore default value**
для окремого поля або **⋯ › Restore...** для моделі.

Додайте рівень **Context**, якщо модель тарифікується дорожче понад певний розмір контексту, наприклад для промптів
понад 200K токенів.

### Власні моделі

Натисніть **Add Model**, щоб додати модель, якої немає в каталозі, вказавши **Display name** і **Model ID**.
Щоб узяти за основу налаштування наявної моделі, виберіть для неї **⋯ › Duplicate...**.

## Моделі OpenCode

Вкладка **Models** керує [моделями](/console/models), які надає Console і які оплачуються з кредитів робочого простору.
Вона працює так само, як сторінка провайдера:

- Вмикайте або вимикайте окремі моделі.
- Вимкніть **Free models**, щоб заблокувати безкоштовні моделі для робочого простору.
- Увімкніть **New models**, щоб нові моделі Console вмикалися автоматично.

Щоб користуватися лише власними провайдерами, вимкніть цього провайдера повністю через **⋯ › Disable**.

## Використання в OpenCode

Учасники виконують `/connect` і вибирають робочий простір. Кожен увімкнений провайдер відображається як назва робочого
простору, за якою йде назва провайдера, а `/models` показує його увімкнені моделі.

```text
Acme Inc. / Anthropic
```

Увімкніть **Managed providers only** у **Settings › General**, щоб обмежити OpenCode для всіх лише провайдерами
робочого простору.

## Вимкнення або видалення

Відкрийте меню **⋯** провайдера:

- **Disable** приховує провайдера та його моделі від учасників, але зберігає налаштування.
- **Remove...** видаляє провайдера та його моделі. Діалогове вікно показує, хто нещодавно ним користувався, і пропонує
  **Disable instead** (вимкнути замість видалення).

Щоб замінити ключ, натисніть облікові дані на сторінці провайдера та введіть новий ключ.

## Оплата

За токени вам виставляє рахунок провайдер; Console не списує за них кредити. Проте Console усе одно записує кожен запит
і його вартість за цінами моделі, тому вони враховуються у звітах про використання та [бюджетах](/console/budgets).

Щоб викликати провайдера з власних інструментів, а не з OpenCode, використовуйте [Providers API](/console/api/providers).
