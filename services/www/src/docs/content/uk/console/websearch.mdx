---
title: "Вебпошук"
description: "Хостований вебпошук для OpenCode через Console."
---

Console надає хостований вебпошук підключеним користувачам OpenCode v2. Власник або адміністратор робочого простору вмикає його один раз для всього робочого простору, і учасникам не потрібен окремий ключ пошукового провайдера.

Кожен успішний пошук коштує **$0.01** і списується з балансу робочого простору та враховується в лімітах витрат учасників.

## Увімкнення

1. Увійдіть в [OpenCode Console](https://opencode.ai/console) як власник або адміністратор робочого простору.
2. Відкрийте **Settings** > **General**.
3. Увімкніть **Hosted web search**.

Після цього кожен учасник підключає OpenCode до робочого простору командою `/connect`.

```text
/connect
```

OpenCode завантажує **OpenCode Web Search** з керованої конфігурації робочого простору. Учасникам не потрібно задавати `websearch.provider` або додавати ключ API провайдера.

## Пошук

Попросіть OpenCode в промпті знайти актуальну інформацію. Пошук виконується з OpenCode, а не з інтерактивної сторінки в Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

Хостований провайдер шукає у відкритому інтернеті й повертає до восьми результатів. OpenCode використовує їх, щоб відповісти на промпт і послатися на джерела.

Щоб налаштувати дозволи або вимкнути інструмент, перегляньте [посібник із вебпошуку](/websearch).

## Оплата

Console списує **$0.01**, коли пошук повертає коректний набір результатів. За невдалі пошуки та пошуки, обмежені лімітом запитів, плата не стягується.

Вебпошук відображається окремо від використання моделей у **Usage**, **My Activity**, активності учасників, рахунках та експортах CSV. Місячні ліміти витрат робочого простору й учасників включають витрати на вебпошук.

## Конфіденційність

Хостований вебпошук не зберігає жодних даних. Console і її провайдер хостованого пошуку обробляють кожен запит і його результати, не зберігаючи їхнього вмісту.
