Зчитуйте з інтеграції чинні місячні бюджети всіх учасників робочого простору та керуйте власним бюджетом кожного
учасника.

## Швидкий старт

Створіть в [OpenCode Console](https://opencode.ai/console) ключ API [сервісного облікового запису](/console/api#service-accounts)
з дозволами **All**. Ключі лише для інференсу не мають доступу до даних бюджетів і не можуть змінювати ліміти.

```bash
export CONSOLE_URL="https://opencode.ai/console"
export SERVICE_API_KEY="oc_sk_..."
```

Отримайте список бюджетів учасників:

```bash
curl --fail-with-body \
  "${CONSOLE_URL}/api/v1/budgets/members" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Accept: application/json"
```

## Список бюджетів учасників

```text
GET /api/v1/budgets/members
```

Відповідь містить усіх поточних учасників, упорядкованих за електронною адресою. Ліміт із джерелом `custom` — це
перевизначення для учасника; джерело `default` означає, що ліміт успадковано від значення за замовчуванням робочого
простору. Якщо ліміт і джерело мають значення null, витрати учасника необмежені.

```json
[
  {
    "user_id": "user_...",
    "email": "alice@example.com",
    "limit_micro_cents": "7525000000",
    "spent_micro_cents": "1250000000",
    "exceeded": false,
    "resets_at": "2026-10-01T00:00:00.000Z",
    "source": "custom",
    "updated_at": "2026-09-03T12:00:00.000Z"
  }
]
```

Грошові поля відповіді — це десяткові рядки в мікроцентах, щоб інтеграції не втрачали точності. В одному доларі США
100,000,000 мікроцентів. Витрати та час скидання стосуються поточного календарного місяця за UTC. `updated_at` має
значення null, якщо для учасника немає власного перевизначення.

## Встановлення власного бюджету

```text
PUT /api/v1/budgets/members/:user_id
```

Встановіть для одного учасника місячний бюджет $75.25:

```bash
curl --fail-with-body --request PUT \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"budget_dollars":75.25}'
```

`budget_dollars` приймає невід'ємну суму в доларах США з не більше ніж двома знаками після коми. Запит PUT
ідемпотентний і повертає HTTP 204. Використовуйте ID учасника, повернутий операцією отримання списку.

## Повернення до значення за замовчуванням

```text
DELETE /api/v1/budgets/members/:user_id
```

Видаліть власне перевизначення:

```bash
curl --fail-with-body --request DELETE \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

Видалення перевизначення не видаляє учасника. Після цього учасник успадковує бюджет за замовчуванням робочого
простору або отримує необмежені витрати, якщо значення за замовчуванням не задано. Запит можна безпечно повторювати;
він повертає HTTP 204.

## Помилки

| Статус | Значення                                                              |
| ------ | --------------------------------------------------------------------- |
| `400`  | Недійсний ID учасника або сума бюджету.                               |
| `401`  | Сервісний ключ API відсутній, недійсний, прострочений або відкликаний. |
| `403`  | Ключ API не має дозволу на керування бюджетами.                       |
| `404`  | Учасника немає в робочому просторі, до якого прив'язано ключ API.     |
