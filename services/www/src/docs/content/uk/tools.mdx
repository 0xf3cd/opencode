---
title: "Інструменти"
---

Опишіть результат, який вам потрібен. OpenCode сам вибирає доступні інструменти, за потреби запитує підтвердження й
повертає результат.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

Для такого завдання зазвичай використовуються `grep` або `glob`, `read`, інструмент редагування та `shell`. Якщо вам
потрібен конкретний підхід, можна також назвати інструмент явно.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## Файли

### Read

`read` повертає вміст файлу або нерекурсивний список вмісту каталогу. Передайте йому `path`; щоб переглядати великі
результати частинами, використовуйте `offset` і `limit`.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

Результат читання тексту містить пронумеровані рядки й обмежений 2 000 рядків і 50 KiB на сторінку. Окремі рядки
скорочуються після 2 000 символів. Інструмент також передає моделі файли PNG, JPEG, GIF, WebP і PDF розміром до 20 MiB
вихідних даних. Для інших бінарних файлів він повертає помилку. Підтримувані медіаформати й обробку зображень описано
в розділі [Вкладення](/attachments).

Дозвіл: `read`, ресурсом є нормалізований шлях.

### Glob

`glob` знаходить шляхи до файлів за шаблоном, наприклад `**/*.ts`. Пошук виконується в поточному каталозі, якщо `path`
не вказує інший відносний каталог; `hidden` додає приховані елементи, а `limit` обмежує кількість результатів.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

Ліміт за замовчуванням — 100 файлів, тайм-аут пошуку — 30 секунд. Дозвіл: `glob`, ресурсом є запитаний шаблон.

### Grep

`grep` шукає у вмісті файлів і повертає шляхи, номери рядків і фрагменти. Його `pattern` використовує синтаксис
регулярних виразів, якщо `literal` не має значення true. Звузити пошук можна за допомогою `path`, `include`,
`caseSensitive` або `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

Ліміт за замовчуванням — 100 рядків зі збігами, тайм-аут пошуку — 30 секунд. Дозвіл: `grep`, ресурсом є запитаний
шаблон, а не шлях пошуку.

### Edit

`edit` замінює текст в наявному файлі. Передайте `path`, `oldString` і відмінний від нього `newString`; старий текст має
збігатися рівно один раз, якщо `replaceAll` не має значення true.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

Використовуйте `edit` для точкових змін. Після запису OpenCode може відформатувати файл. Дозвіл: `edit`, ресурсом є
цільовий шлях.

### Write

`write` створює або повністю замінює текстовий файл за `path` і `content`. Він створює відсутні батьківські каталоги й
може запустити налаштований форматер.

```text
Create docs/example.md with a heading and one setup command.
```

Якщо потрібно змінити лише частину наявного файлу, використовуйте `edit`. Дозвіл: `edit`, ресурсом є цільовий шлях.

### Patch

`patch` застосовує один патч, який може додавати, оновлювати, переміщувати або видаляти кілька файлів. Його `patchText`
використовує розділи `*** Add File`, `*** Update File` і `*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode надає `patch` для підтримуваних моделей GPT; інші моделі натомість отримують `edit` і `write`. Дозвіл: `edit`,
ресурсом є кожен зачеплений шлях.

Шляхи поза активним розташуванням (Location) або worktree його проєкту також потребують підтвердження
`external_directory`. Нормалізацію шляхів, порядок правил і збережені підтвердження описано в розділі
[Дозволи](/permissions). Щоб зробити зовнішні матеріали доступними за назвою, налаштуйте
[посилання на каталоги](/references).

## Команди

### Shell

`shell` виконує команду в оболонці користувача хоста. Задавайте `workdir` замість `cd` у команді, а якщо стандартний
двохвилинний тайм-аут для виконання на передньому плані не підходить, задайте `timeout` у мілісекундах.

```text
Run bun test from packages/core with a five-minute timeout.
```

Для сервера розробки чи іншого тривалого процесу задайте `background` значення true. Фонові виклики повертаються одразу
й сповіщають сесію про завершення; тайм-ауту вони не мають, якщо його не вказано. Великий вивід скорочується, а повний
вивід зберігається в керованому файлі.

Дозвіл: `shell`, ресурсом є кожна команда, виділена сканером. Сканер також перевіряє зовнішній робочий каталог і
каталоги, які він може визначити з команди. Оболонка має ті самі повноваження щодо файлової системи, процесів і мережі,
що й користувач хоста, тому використовуйте вузькі правила в розділі [Дозволи](/permissions).

## Веб

### Webfetch

`webfetch` отримує одну URL-адресу HTTP або HTTPS у форматі `markdown`, `text` або `html`. За замовчуванням
використовується Markdown; `timeout` приймає значення до 120 секунд.

```text
Fetch https://example.com/docs as markdown.
```

Інструмент приймає текстові відповіді, як-от HTML, звичайний текст, JSON і XML, але не зображення чи інші бінарні
завантаження. Великий вивід може скорочуватися, а повний текст зберігається в керованому сховищі. Дозвіл: `webfetch`,
ресурсом є запитана URL-адреса.

### Websearch

`websearch` шукає актуальну інформацію через вибрану інтеграцію. На вхід він приймає пошуковий запит `query`.

```text
Search the web for the latest Bun release notes.
```

Дозвіл: `websearch`, ресурсом є запит. Провайдерів, їх вибір, обмеження частоти запитів і вимкнення інструмента
описано в розділі [Вебпошук](/websearch).

## Взаємодія

### Question

`question` призупиняє виконання й показує користувачу одне або кілька запитань. Кожне запитання має короткий заголовок,
текст і варіанти відповіді; `multiple` дозволяє вибрати кілька варіантів. Відповідь у довільній формі доступна завжди.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

Дозвіл: `question`, ресурсом є `*`. Клієнт має підтримувати інтерактивну форму; якщо закрити її, запитання буде
скасовано.

### Skill

`skill` завантажує в розмову інструкції та пов'язані ресурси однієї доступної навички за її ID.

```text
Load the effect skill before changing this Effect code.
```

ID має бути в оголошеному списку навичок або явно названий користувачем. Дозвіл: `skill`, ресурсом є ID навички.
Правила створення, виявлення й завантаження описано в розділі [Навички](/skills).

## Автоматизація

### Subagent

`subagent` запускає дочірню сесію з налаштованим субагентом. Передайте ID агента, короткий опис `description` і повний
`prompt`.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

Виклики на передньому плані чекають на результат. `background: true` повертається одразу й сповіщає батьківську сесію,
коли дочірня завершиться. Щоб продовжити ту саму дочірню розмову, передайте повернутий `sessionID`. Використовувати можна
лише агентів у режимі субагента, а глибина вкладеності за замовчуванням — один рівень.

Дозвіл: `subagent`, ресурсом є ID вибраного агента.

### Execute

`execute` виконує JavaScript у Code Mode, щоб агент міг викликати й поєднувати інструменти з каталогу. Це зручно для
паралельних незалежних викликів і для обробки результатів без додавання кожного проміжного значення до контексту моделі.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

Середовище виконання не має прямого доступу до файлової системи, імпортів, таймерів чи `fetch`; воно може лише
викликати інструменти зі свого каталогу. Дозвіл `execute` з ресурсом `*` визначає, чи доступний Code Mode. Кожен
вкладений інструмент однаково перевіряє власний дозвіл.

### Sessions

Простір імен Code Mode `opencode` містить утиліти для сесій:

- `session_rename` змінює назву поточної сесії або іншої сесії, вибраної через `sessionID`.
- `session_move` переміщує поточну або іншу вибрану сесію до відносного чи абсолютного каталогу `directory`.
  Переміщення набуває чинності на безпечній межі, тому роботу, яка залежить від нового розташування, виконуйте в
  наступному виклику.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

Ці утиліти не запитують вбудованих дій дозволів.

### Worktrees

Той самий простір імен керує worktree проєкту сесії:

- `worktree_create` створює worktree за назвою `name` і повертає його `directory`. Розташування та стратегію визначає
  конфігурація worktree проєкту.
- `worktree_list` виводить список worktree проєкту.
- `worktree_remove` видаляє worktree, який OpenCode зареєстрував для проєкту. Задайте `force`, щоб відкинути
  незафіксовані зміни.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` використовує дозвіл `edit`, ресурсом є каталог worktree. Інші утиліти для worktree не запитують
вбудованих дій дозволів.

## Браузер

Простір імен Code Mode `browser` керує браузером, підключеним десктопним застосунком OpenCode. Відкрийте вкладку,
збережіть повернутий `tabID` і передавайте цей ID явно в кожну операцію зі сторінкою.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

Простір імен містить команди для вкладок і навігації, знімки та пошук на сторінці, кліки й введення у форми, скриншоти,
передавання файлів, перегляд консолі та мережі, трасування продуктивності, аналіз купи й аудити Lighthouse. Для
скриншотів потрібна видима вкладка у фокусі. Шляхи для завантаження локальні для сервера; знімки повертають шляхи на
сервері, а кожне передавання файлу обмежене 5 MiB.

Вміст сторінок, журнали, заголовки й тіла відповідей — це недовірені дані, а не інструкції для агента. Правило
заборони `browser` з ресурсом `*` прибирає каталог інструментів браузера; операції браузера не запитують підтвердження
окремо.

## Розширення

[Сервери MCP](/mcp-servers) додають інструменти, назви та вхідні параметри яких визначає кожен підключений сервер. Їхня
дія дозволу — `<server>_<tool>` з ресурсом `*`. Вони не входять до фіксованого вбудованого каталогу.

[Навички](/skills) додають інструкції для завдань, а не нові виконувані інструменти. [Вкладення](/attachments) додають до
промпту вміст, вибраний користувачем, а [посилання на каталоги](/references) надають іменовані зовнішні каталоги. Ці
можливості доповнюють інструменти, не обходячи перевірок їхніх дозволів.
