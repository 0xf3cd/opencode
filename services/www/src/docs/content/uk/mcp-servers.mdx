---
title: "Сервери MCP"
---

OpenCode підключається до серверів [Model Context Protocol](https://modelcontextprotocol.io/) і надає доступ до їхніх
можливостей: інструментів, промптів, ресурсів та інструкцій. Інструменти MCP займають контекст моделі, тому додавайте
лише ті сервери, які вам справді потрібні.

## Налаштування

Додайте віддалений сервер із проєкту, у якому він має використовуватися, а потім перевірте підключення:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
opencode mcp list
```

Команда записує сервер у [конфігурацію](/config) проєкту. Додайте `--global`, щоб сервер був доступний у всіх проєктах:

```sh
opencode mcp add context7 --global --url https://mcp.context7.com/mcp
```

Віддалені сервери за замовчуванням використовують OAuth. Якщо у списку відображається `needs authentication`, відкрийте
OpenCode, виконайте `/mcps`, виберіть сервер і увійдіть. Підключений сервер готовий до використання агентом:

```text
✓ context7  connected
```

## Конфігурація

Щоб налаштувати сервер вручну, задайте йому унікальну назву в `mcp.servers`. У V2 назви серверів не розміщуються
безпосередньо в `mcp`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
      },
    },
  },
}
```

Сервери підключаються автоматично. Щоб зберегти сервер у конфігурації, але не підключати його, використовуйте
`disabled`, а не поле `enabled`:

```jsonc
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
        "disabled": true,
      },
    },
  },
}
```

Конфігурація проєкту з вищим пріоритетом повністю замінює об'єкт сервера з тією самою назвою. Для окремих підключень
або облікових записів використовуйте різні назви; інакше повторіть у перевизначенні всі обов'язкові поля:

```jsonc title="opencode.jsonc"
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
      },
    },
  },
}
```

## Локальні сервери

Локальний сервер — це команда, яку OpenCode запускає через транспорт MCP stdio. Додайте його, указавши команду після
`--`:

```sh
opencode mcp add everything -- npx -y @modelcontextprotocol/server-everything
```

Для параметрів процесу, як-от робочого каталогу чи змінних середовища, використовуйте конфігурацію:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "everything": {
        "type": "local",
        "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
        "cwd": ".",
        "environment": {
          "LOG_LEVEL": "info",
          "MCP_API_KEY": "{env:MCP_API_KEY}",
        },
      },
    },
  },
}
```

| Поле | Обов'язкове | Опис |
| --- | --- | --- |
| `type` | Так | Має бути `"local"`. |
| `command` | Так | Виконуваний файл і його аргументи. |
| `cwd` | Ні | Каталог процесу. Відносні шляхи обчислюються від робочого простору, який також використовується за замовчуванням. |
| `environment` | Ні | Рядкові змінні, що додаються до успадкованого середовища процесу OpenCode. |
| `disabled` | Ні | Якщо `true`, сервер не підключається. За замовчуванням `false`. |
| `codemode` | Ні | Задайте `false`, щоб надавати інструменти напряму, а не через Code Mode. За замовчуванням `true`. |
| `timeout` | Ні | Перевизначення тайм-аутів для цього сервера. |
| `protocol` | Ні | `legacy` (за замовчуванням), `auto` або `2026-07-28`. Див. [Версія протоколу](#protocol-version). |

Для підстановки змінних середовища використовуйте `{env:NAME}`. Вирази оболонки на кшталт `$NAME` у рядках JSON не
розгортаються:

```jsonc
{
  "environment": {
    "MCP_API_KEY": "{env:MCP_API_KEY}",
  },
}
```

## Віддалені сервери

Віддалений сервер використовує транспорт MCP Streamable HTTP і потребує абсолютної URL-адреси:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Якщо серверу потрібні заголовки чи інші параметри, використовуйте конфігурацію. Секрети зберігайте в змінних
середовища, а не у файлі:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "oauth": false,
        "headers": {
          "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}",
        },
      },
    },
  },
}
```

| Поле | Обов'язкове | Опис |
| --- | --- | --- |
| `type` | Так | Має бути `"remote"`. |
| `url` | Так | Абсолютна адреса ендпоінта Streamable HTTP. |
| `headers` | Ні | Рядкові HTTP-заголовки, що надсилаються на ендпоінт. |
| `oauth` | Ні | Налаштування OAuth або `false`, щоб вимкнути OAuth. |
| `disabled` | Ні | Якщо `true`, сервер не підключається. За замовчуванням `false`. |
| `codemode` | Ні | Задайте `false`, щоб надавати інструменти напряму, а не через Code Mode. За замовчуванням `true`. |
| `timeout` | Ні | Перевизначення тайм-аутів для цього сервера. |
| `protocol` | Ні | `legacy` (за замовчуванням), `auto` або `2026-07-28`. Див. [Версія протоколу](#protocol-version). |

Використовуйте `oauth: false`, лише якщо сервер приймає виключно ключ API або інші облікові дані в
заголовку:

```jsonc
{
  "type": "remote",
  "url": "https://mcp.example.com/mcp",
  "oauth": false,
  "headers": { "Authorization": "Bearer {env:MCP_API_KEY}" },
}
```

## OAuth

Для віддалених серверів OAuth увімкнено, якщо `oauth` не має значення `false`. OpenCode знаходить сервер авторизації,
використовує PKCE, оновлює токени й, якщо це підтримується, намагається виконати динамічну реєстрацію клієнта; облікові
дані зберігаються поза конфігурацією проєкту.

Для динамічної реєстрації вкажіть лише URL-адресу сервера:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
      },
    },
  },
}
```

Якщо сервер потребує автентифікації, виконайте `/mcps`, виберіть його й завершіть авторизацію в браузері. Той самий
процес можна запустити з CLI:

```sh
opencode mcp auth sentry
```

Якщо провайдер видав вам облікові дані клієнта, використовуйте поля OAuth у V2 у форматі snake_case:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "company-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "oauth": {
          "client_id": "{env:MCP_CLIENT_ID}",
          "client_secret": "{env:MCP_CLIENT_SECRET}",
          "scope": "tools:read tools:execute",
          "callback_port": 19876,
          "redirect_uri": "http://127.0.0.1:19876/callback",
        },
      },
    },
  },
}
```

| Поле | Опис |
| --- | --- |
| `client_id` | Попередньо зареєстрований ID клієнта. Не вказуйте його, щоб спробувати динамічну реєстрацію. |
| `client_secret` | Секрет попередньо зареєстрованого клієнта. |
| `scope` | Області доступу (scopes), що запитуються, через пробіл. |
| `callback_port` | Локальний порт зворотного виклику від `1` до `65535`. За замовчуванням — доступний тимчасовий порт. |
| `redirect_uri` | Попередньо зареєстрована loopback-адреса URI, шлях і порт якої ведуть до локального обробника зворотного виклику. |
| `auth_server_metadata_url` | URL-адреса документа метаданих OAuth або OpenID Connect сервера авторизації. Задайте її, якщо сервер MCP не публікує метадані захищеного ресурсу із зазначенням свого сервера авторизації. |

Щоб увійти повторно або змінити обліковий запис, видаліть збережені облікові дані OAuth:

```sh
opencode mcp logout sentry
```

## Тайм-аути

Тайм-аути задаються додатними цілими числами в мілісекундах. Значення за замовчуванням задайте в `mcp.timeout`; об'єкт
`timeout` сервера перевизначає відповідні значення за замовчуванням.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "timeout": {
      "startup": 45000,
      "catalog": 30000,
      "execution": 600000,
    },
    "servers": {
      "slow-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "timeout": {
          "catalog": 60000,
        },
      },
    },
  },
}
```

| Тайм-аут | За замовчуванням | Застосовується до |
| --- | --- | --- |
| `startup` | 30 секунд | Підключення транспорту та ініціалізації сервера. |
| `catalog` | 30 секунд | Отримання списків інструментів, промптів, ресурсів і шаблонів ресурсів. |
| `execution` | 12 годин | Викликів інструментів, отримання промптів і читання ресурсів. |

## Версія протоколу

За замовчуванням OpenCode відкриває з'єднання з кожним сервером за допомогою класичного рукостискання MCP `initialize`.
Щоб працювати із сервером на основі ревізії 2026-07-28, задайте його поле `protocol`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "modern": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "protocol": "auto",
      },
    },
  },
}
```

| Значення | Поведінка |
| --- | --- |
| `legacy` | За замовчуванням. Надсилає `initialize` і підтримує ревізії протоколу до 2025-11-25. |
| `auto` | Перевіряє підтримку ревізії 2026-07-28 запитом `server/discover` і повертається до `legacy`, якщо сервер її не підтримує. |
| `2026-07-28` | Вимагає ревізії 2026-07-28. Підключення до старіших серверів завершується помилкою. |

Перевірка локального сервера `legacy` запускає короткочасний додатковий процес і може тривати до завершення тайм-ауту
запуску, якщо сервер ігнорує невідомі запити, тому використовуйте `auto` лише для серверів, яким це потрібно.

## Назви

OpenCode називає інструмент `<server>_<tool>`. Усі символи, крім літер, цифр, `_` і `-`, замінюються на `_`:

```text
server: context 7
tool:   resolve.library/id
name:   context_7_resolve_library_id
```

Промпти MCP стають командами з назвами `<server>:<prompt>` з такою самою нормалізацією. Наприклад:

```text
/context_7:find_docs
```

Вибирайте короткі назви серверів, які залишаються унікальними після нормалізації. У режимі Code Mode, що діє за
замовчуванням, інструменти групуються за нормалізованою назвою сервера:

```text
tools.context_7.resolve_library_id(...)
```

## Дозволи

Code Mode використовується за замовчуванням. Задайте `codemode` значення `false`, якщо інструменти сервера мають
залишатися в нативному списку інструментів провайдера:

```jsonc
{
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "codemode": false,
      },
    },
  },
}
```

Щоб приховати або заборонити інструменти, не відключаючи їхній сервер, використовуйте дії дозволів. Зіставляйте з
нормалізованою назвою `<server>_<tool>`:

```jsonc
{
  "permissions": [
    {
      "action": "context7_*",
      "resource": "*",
      "effect": "deny",
    },
  ],
}
```

## Контекст

Для викликів від імені сесії OpenCode надсилає ID сесії в `CallToolRequest.params._meta["ai.opencode/sessionID"]`. Це
стосується як прямих інструментів, так і Code Mode через stdio і Streamable HTTP:

```json
{
  "method": "tools/call",
  "params": {
    "name": "lookup",
    "arguments": { "query": "example" },
    "_meta": { "ai.opencode/sessionID": "ses_..." }
  }
}
```

ID — це метадані запиту, а не аргумент інструмента, тому його немає у схемі, видимій моделі. Вважайте його непрозорим
значенням для кореляції:

| Правило | Поведінка |
| --- | --- |
| Ідентифікація | Він ідентифікує сесію OpenCode, що здійснює виклик, а не транспортну сесію MCP. |
| Наявність | Він може бути відсутній у викликах без контексту сесії. |
| Безпека | Не використовуйте його сам по собі для автентифікації чи авторизації. |
| Приватність | Віддалені сервери отримують необроблений ID і можуть записувати його в журнали або зберігати. |

## Керування

Переглянути список серверів і їхній поточний стан підключення можна з будь-якого проєкту:

```sh
opencode mcp list
```

У OpenCode використовуйте `/mcps`, щоб переглядати, підключати, відключати сервери або проходити автентифікацію. Для
додавання серверів і керування обліковими даними OAuth використовуйте CLI:

```sh
opencode mcp add sentry --url https://mcp.sentry.dev/mcp
opencode mcp auth sentry
opencode mcp logout sentry
```

Щоб видалити сервер, видаліть його запис із конфігурації проєкту або глобальної конфігурації, куди його було додано:

```jsonc
{
  "mcp": {
    "servers": {},
  },
}
```

Налаштування клієнта OAuth, тайм-аути, робочі каталоги чи постійне ввімкнення та вимкнення змінюйте безпосередньо в
конфігурації:

```jsonc
{
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
        "disabled": true,
      },
    },
  },
}
```
