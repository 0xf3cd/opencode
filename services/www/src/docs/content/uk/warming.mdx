---
title: "Прогрівання сесій"
---

Прогрівання сесії періодично надсилає запити до моделі, щоб зберегти кеш промптів або інший короткочасний стан на боці
провайдера, поки ви робите паузу між промптами. За замовчуванням прогрівання вимкнено.

Увімкніть прогрівання в будь-якому [файлі конфігурації OpenCode](/config):

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

З такою конфігурацією OpenCode прогріває нещодавно активну сесію після чотирьох хвилин без запитів до моделі. Прогрівання
повторюється кожні чотири хвилини, доки не мине 30 хвилин від останнього звичайного запиту (не запиту прогрівання).

## Параметри

Щоб змінити промпт прогрівання, інтервал простою або активне вікно, використайте об'єктну форму:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| Поле | За замовчуванням | Призначення |
| --- | --- | --- |
| `prompt` | Інструкція підтримання активності | Додається як тимчасове повідомлення користувача до кожного запиту прогрівання. Промпт за замовчуванням просить модель нічого не робити, не використовувати інструменти й відповісти `OK`. |
| `interval` | `"4 minutes"` | Час простою перед наступним запитом прогрівання. |
| `duration` | `"30 minutes"` | Вікно прогрівання, що відраховується від останнього звичайного запиту до моделі. |

Пропущені поля об'єкта зберігають значення за замовчуванням. Наприклад, така конфігурація змінює лише інтервал:

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## Тривалості

`interval` і `duration` приймають рядки тривалості. Обидва значення мають бути скінченними й більшими за нуль; інакше
OpenCode пропускає прогрівання й записує попередження в журнал.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## Розклад

Прогрівання починається після звичайного запиту до моделі. Після завершення запиту прогрівання починається наступний
інтервал простою, але активне вікно не подовжується.

```text
00:00  normal model request
00:04  warming request
00:08  warming request
00:30  warming stops
```

Будь-яка нова звичайна активність моделі скидає обидва таймери. Якщо інтервал дорівнює тривалості або перевищує її,
активне вікно спливає раніше, ніж буде надіслано запит прогрівання.

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

## Запити

Запит прогрівання використовує поточну модель, агента, інструкції та контекст розмови сесії. OpenCode тимчасово додає
налаштований промпт, виконує один виклик моделі й відкидає відповідь.

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

Запит не приймає введення, не додає повідомлень до історії й не змінює постійний стан сесії. OpenCode не виконує
локальні виклики інструментів і не продовжує цикл інструментів; промпт за замовчуванням також забороняє моделі
використовувати інструменти.

## Збої

Збої прогрівання записуються в журнал, але не спричиняють помилки сесії й не змінюють її. OpenCode чекає до наступного
інтервалу, перш ніж спробувати знову, а початкове активне вікно тим часом продовжує спливати.

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

## Вартість

Запити прогрівання — це справжні запити до провайдера. Вони можуть витрачати токени, коштувати грошей, враховуватися
в обмеженнях частоти запитів і завершуватися помилками, як і інші запити до моделі.

- Коротші інтервали збільшують кількість запитів.
- Довша тривалість дає змогу надіслати більше запитів прогрівання.
- Вмикайте прогрівання лише тоді, коли його користь на боці провайдера виправдовує додаткові витрати.

Наприклад, значення за замовчуванням дають до семи спроб прогрівання за одне безперервне 30-хвилинне вікно: на 4, 8, 12,
16, 20, 24 і 28 хвилинах.

## Вимкнення

Щоб явно вимкнути прогрівання, задайте `warming` значення `false`. Якщо поле не вказано, прогрівання теж залишається
вимкненим.

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
