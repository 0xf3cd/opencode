title: "Гарячі клавіші"
---

Налаштуйте сполучення клавіш у `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Для однієї клавіші використовуйте рядок:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Альтернативні варіанти розділяйте комами:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Щоб вимкнути сполучення, використайте `"none"` або `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Щоб налаштувати поведінку подій, використайте об'єкт:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

За замовчуванням `leader` — це `ctrl+x`. `<leader>` в іншому сполученні посилається на цю клавішу.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Невідомі ID команд відхиляються.

## Mini

Команда `app.clear` працює лише в [`opencode mini`](/cli). Натисніть `ctrl+l`, щоб очистити видиму частину екрана й
знову показати промпт. Історія прокручування в терміналі зберігається.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | За замовчуванням | Опис           |
| ----------- | ---------------- | -------------- |
| `app.clear` | `ctrl+l`         | Очистити екран |

## Перегляд змін

Натисніть `d` (`diff.switch_source`), щоб вибрати **All**, **Committed**, **Uncommitted** або **Last turn** (у сесії),
або виберіть **Base**, щоб змінити гілку для порівняння. Вибір запам'ятовується, доки ви не вийдете з TUI. Початковий
обсяг задається через [`diffs.source` у `cli.json`](/cli/config#diffs).

Сполучення для прокручування, гортання сторінками та переходу на початок чи кінець завжди керують переглядом змін.
Перемикання фокуса клавіатурою немає: клацніть файл, щоб відкрити його, клацніть папку, щоб розгорнути або згорнути її,
і прокручуйте дерево файлів коліщатком миші.

Щоб переходити між файлами, використовуйте `n` / `p` або `alt+down` / `alt+up` (Option у macOS). У перегляді змін
сполучення з Alt перемикають файли, а не вкладки сесій.

Натисніть `m`, щоб позначити файл як переглянутий і згорнути вміст його патча. У поданні всіх файлів знову натисніть
`m`, щоб зняти позначку й знову розгорнути патч. У поданні одного файлу після позначення автоматично відкривається
наступний файл, але на останньому файлі перегляд зупиняється, а не повертається на початок. Зняття позначки ніколи не
переходить до наступного файлу.

Клацніть правою кнопкою миші файл на бічній панелі або його заголовок у diff, щоб вибрати **Mark complete** (або
**Mark incomplete**). Це змінює той самий стан «переглянуто», що й `m`. Якщо позначити через меню інший файл, він не
вибирається, і поточний файл, який ви читаєте, не змінюється.

Варіанти `diff.help` із Shift призначені для терміналів, які передають модифікатор Shift під час натискання `?`.
