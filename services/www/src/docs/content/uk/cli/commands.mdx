---
title: "Команди"
description: "Довідник із командного рядка opencode."
---

Кожна команда приймає `--help`, який показує повний список її прапорців, наприклад `opencode run --help`. Деякі команди,
що працюють через сервер, приймають `--standalone`, щоб запустити приватний сервер, або `--server <url>`, щоб звернутися
до конкретного сервера; підтримувані прапорці дивіться в довідці відповідної команди.

## run

Надсилає повідомлення й виводить відповідь без відкриття інтерактивного інтерфейсу.

```bash
$ opencode run "Explain this repository"
```

### CI

У CI передайте ключ API провайдера як секрет і використовуйте автономний режим, щоб його отримав приватний сервер.
Наприклад, це завдання GitHub Actions перевіряє отриманий репозиторій:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Виберіть модель.

```bash
$ opencode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Продовжте останню сесію.

```bash
$ opencode run --continue "Now handle the expired case"
```

Виводьте JSON, розділений символами нового рядка, для скриптів.

```bash
$ opencode run --format json "List the TODO comments"
```

Вкладіть файли в повідомлення.

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Запустіть із конкретним агентом.

```bash
$ opencode run --agent build "Fix the failing test"
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode run --help
```

## session

Керує сесіями.

```bash
$ opencode session list
```

Обмежте список і виведіть його у форматі JSON.

```bash
$ opencode session list --max-count 20 --format json
```

Видаліть сесію та її дочірні сесії.

```bash
$ opencode session delete ses_9c1b08
```

Експортуйте дані сесії у форматі JSON.

```bash
$ opencode session export ses_4f2a1c
```

Приховайте конфіденційні дані стрічки розмови та файлів під час експорту.

```bash
$ opencode session export ses_4f2a1c --sanitize
```

Імпортуйте дані сесії з JSON-файлу або URL-адреси.

```bash
$ opencode session import session.json
```

Імпортуйте в конкретний каталог.

```bash
$ opencode session import session.json --directory ~/code/project
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode session --help
```

## auth

Керує AI-провайдерами та обліковими даними.

```bash
$ opencode auth list
```

Виведіть список у форматі JSON.

```bash
$ opencode auth list --format json
```

Увійдіть у провайдера.

```bash
$ opencode auth login anthropic
```

Увійдіть конкретним способом автентифікації.

```bash
$ opencode auth login anthropic --method key
```

Вийдіть зі збереженого облікового запису.

```bash
$ opencode auth logout anthropic work
```

Перемкніть активний обліковий запис для інтеграції.

```bash
$ opencode auth switch anthropic work
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode auth --help
```

## mcp

Керує серверами MCP (Model Context Protocol).

```bash
$ opencode mcp list
```

Додайте віддалений сервер.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Додайте локальний сервер до глобальної конфігурації.

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Додайте локальний сервер зі змінною середовища.

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Додайте віддалений сервер із заголовком.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Пройдіть автентифікацію на віддаленому сервері з підтримкою OAuth.

```bash
$ opencode mcp auth sentry
```

Видаліть збережені облікові дані OAuth для сервера.

```bash
$ opencode mcp logout sentry
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode mcp --help
```

## plugin


```bash
$ opencode plugin list --builtin
```

Установіть плагін і додайте його до глобальної конфігурації.

```bash
$ opencode plugin add @example/opencode-tui
```

```bash

```

Оновіть плагіни-пакети.

```bash
$ opencode plugin update
```

```bash
$ opencode plugin remove @example/opencode-tui
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode plugin --help
```

## pair

Виводить одноразові посилання та QR-код першого з них, за якими браузер або застосунок входить на сервер. Посилання
діють 5 хвилин і працюють лише один раз.

```bash
$ opencode pair
```

Використайте в посиланнях зовнішню URL-адресу.

```bash
$ opencode pair --url https://dev.example.com
```

Створіть пару звідусіль через віддалену адресу OpenTunnel. Це відкриває доступ до сервера з інтернету, тому під час
першого ввімкнення віддаленого доступу команда пояснює це й просить підтвердження. Див. розділ
[Віддалений доступ](/cli/web#remote-access).

```bash
$ opencode pair --remote
```

Підтвердьте без запиту, наприклад у скрипті без термінала.

```bash
$ opencode pair --remote --yes
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode pair --help
```

## service

Керує фоновим сервером. Див. розділ [Web](/cli/web).

```bash
$ opencode service start
```

Перезапустіть його.

```bash
$ opencode service restart
```

Покажіть його стан.

```bash
$ opencode service status
```

Зупиніть його.

```bash
$ opencode service stop
```

Прочитайте значення параметра.

```bash
$ opencode service get hostname
```

Задайте значення параметра.

```bash
$ opencode service set hostname 0.0.0.0
```

Дозвольте додаткове джерело CORS.

```bash
$ opencode service set cors https://app.example.com
```

Передайте змінну середовища процесу сервера.

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Скиньте параметр до значення за замовчуванням.

```bash
$ opencode service unset hostname
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode service --help
```

## reload

Перезавантажує конфігурацію без перезапуску сервера. Активні сесії продовжують роботу з оновленими сервісами на межі
наступного кроку.

```bash
$ opencode reload
```

## api

Надсилає запит до запущеного сервера.

```bash
$ opencode api GET /api/session
```

Викличте операцію за її ID з параметром запиту.

```bash
$ opencode api session.list --param limit=10
```

Надішліть тіло запиту в JSON.

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

Додайте заголовок запиту.

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode api --help
```

закриє з'єднання.

```bash
$ opencode acp
```

```bash
$ opencode acp --help
```

## upgrade

Оновлює OpenCode до останньої або конкретної версії. Псевдонім: `update`.

```bash
$ opencode upgrade
```

Оновіть до конкретної версії за допомогою конкретного менеджера пакетів.

```bash
$ opencode upgrade 2.0.21 --method bun
```

Перегляньте всі підкоманди та прапорці.

```bash
$ opencode upgrade --help
```
