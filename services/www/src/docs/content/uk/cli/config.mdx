Налаштування CLI стосуються лише термінальних клієнтів. Вони відокремлені від налаштувань сервера та проєкту в
`opencode.json(c)`.

Щоб змінити основні налаштування з TUI, натисніть `Ctrl+P` і виберіть **Open settings**.

<img src={`${import.meta.env.BASE_URL}assets/docs/cli/settings.png`} alt="Діалогове вікно налаштувань OpenCode TUI" />

## Файл конфігурації

OpenCode зберігає налаштування CLI в одному глобальному файлі:

```text
~/.config/opencode/cli.json
```

Якщо задано `$XDG_CONFIG_HOME`, OpenCode використовує:

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

Файлу налаштувань CLI на рівні проєкту немає. Додайте опубліковану JSON Schema для валідації та автодоповнення:

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode додає `$schema`, коли створює або мігрує цей файл. Невідомі налаштування відхиляються, а коректні зміни
застосовуються без перезапуску, поки TUI працює.

## Вбудована конфігурація

Задайте `OPENCODE_CLI_CONFIG_CONTENT`, щоб застосувати налаштування CLI з вбудованого JSON:

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode накладає вбудовані налаштування поверх глобального `cli.json`. Вкладені об'єкти
об'єднуються, а масиви та скалярні значення зі змінної середовища замінюють глобальні значення. Поки змінну задано,
вбудовані налаштування мають вирішальне значення.

## Вигляд
Виберіть тему, налаштуйте анімацію інтерфейсу та перевизначте курсор термінала:

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування вигляду" tabIndex={0}>

| Параметр          | Значення                                | Опис                                                                     |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `theme.name`      | рядок                                   | Вибирає вбудовану, власну або згенеровану з кольорів термінала тему.     |
| `theme.mode`      | `system`, `dark` або `light`            | Відповідає вигляду термінала або фіксує тему в одному колірному режимі.  |
| `animations`      | boolean                                 | Вмикає анімації інтерфейсу.                                              |
| `cursor.style`    | `block`, `underline`, `line`, `default` | Задає форму курсора. `default` зберігає форму курсора термінала.         |
| `cursor.blinking` | boolean                                 | Керує блиманням курсора. Не діє, якщо вибрано стиль `default`.           |

</div>

Про вибір і створення тем див. розділ [Тема](/cli/theme).

## Введення

Налаштуйте захоплення миші, прокручування, контекст редактора, вставлення та попередній перегляд зображень у промпті:

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування введення" tabIndex={0}>

| Параметр                   | Значення                        | Опис                                                                        |
| -------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| `mouse`                    | boolean                         | Вмикає захоплення миші в терміналі.                                         |
| `scroll.speed`             | число, не менше `0.001`         | Задає фіксовану відстань прокручування за один крок.                        |
| `scroll.acceleration`      | boolean                         | Прискорює повторне прокручування. Якщо ввімкнено, має пріоритет над швидкістю. |
| `prompt.editor`            | boolean                         | Додає активний файл або виділення в редакторі як контекст промпту.          |
| `prompt.paste`             | `compact` або `full`            | Показує великі вставлені фрагменти як компактні заповнювачі або повним текстом. |
| `prompt.image_preview`     | boolean                         | Показує попередній перегляд вкладених зображень над полем введення промпту. |

</div>

## Сесії

Налаштуйте, як відображаються сесії в повноекранному TUI і де починаються нові сесії:

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування сесій" tabIndex={0}>

| Параметр                | Значення                    | Опис                                                                         |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `session.sidebar`       | `auto` або `hide`           | Показує бічну панель, коли дозволяє місце, або завжди приховує її.           |
| `session.scrollbar`     | boolean                     | Показує смугу прокручування стрічки розмови.                                 |
| `session.thinking`      | `show` або `hide`           | Показує або приховує міркування моделі за замовчуванням.                     |
| `session.grouping`      | `auto` або `none`           | Групує пов'язані елементи стрічки розмови або показує кожен елемент окремо.  |
| `session.image_preview` | boolean                     | Показує в стрічці розмови вкладені користувачем зображення та зображення з результатів інструментів. |
| `session.tps`           | boolean                     | Показує кількість вихідних токенів за секунду в нижній панелі відповідей асистента. |
| `session.markdown`      | `source` або `rendered`     | Показує синтаксичні позначки Markdown або приховує їх у відформатованому вмісті. |
| `session.new_location`  | `launch` або `inherit`      | Починає в каталозі, з якого запущено TUI, або успадковує розташування активної сесії. |
| `session.permissions`   | `prompt` або `autoaccept`   | Запитує підтвердження для запитів на дозвіл або автоматично приймає кожен запит. |

</div>

## Вкладки

Налаштуйте постійну панель вкладок сесій:

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

Застарілий логічний параметр `tabs.enabled` і далі підтримується: `true` відповідає `on`, а `false` — `off`. OpenCode
читає його, не переписуючи файл конфігурації.

<div class="docs-table-scroll" role="region" aria-label="Налаштування вкладок" tabIndex={0}>

| Параметр          | Значення                    | Опис                                                                          |
| ----------------- | --------------------------- | ----------------------------------------------------------------------------- |
| `tabs.mode`       | `auto`, `on` або `off`      | Використовує вкладки автоматично, завжди або ніколи. У режимі auto вкладки приховано всередині Herdr. |
| `tabs.scope`      | `cwd` або `global`          | Зберігає окремі вкладки для кожного робочого каталогу або спільні для всіх.   |
| `tabs.layout`     | `horizontal` або `vertical` | Розміщує вкладки в горизонтальній смузі або у вертикальній бічній панелі.     |
| `tabs.indicators` | `status` або `numbers`      | Показує значки стану або завжди показує номери вкладок.                       |

</div>

Числові індикатори зберігають кольори стану та фонові анімації. Сполучення Ctrl+цифра перемикають вкладки в будь-якому
режимі індикаторів.

## Зміни

Налаштуйте початковий обсяг і подання змін (diff):

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування змін" tabIndex={0}>

| Параметр       | Значення                                    | Опис                                                      |
| -------------- | ------------------------------------------- | --------------------------------------------------------- |
| `diffs.source` | `branch`, `committed`, `working` або `turn` | Задає початковий обсяг перегляду.                         |
| `diffs.wrap`   | `word` або `none`                           | Переносить довгі рядки за словами або не переносить їх.   |
| `diffs.tree`   | boolean                                     | Показує дерево файлів зі змінами.                         |
| `diffs.single` | boolean                                     | Показує лише патч вибраного файлу.                        |
| `diffs.view`   | `auto`, `split` або `unified`               | Задає компонування. `auto` вибирає його залежно від доступної ширини. |

</div>

`branch` показує **All** — зміни гілки та локальні зміни, `committed` показує лише коміти гілки, а `working` показує
проіндексовані, непроіндексовані та невідстежувані зміни. `turn` показує **Last turn** — файли, які сесія змінила за
останній хід; цей режим оновлюється, коли сесія завершує хід, і повертається до `branch`, якщо `/diff` відкрито не з
сесії.

У `/diff` натисніть `d`, щоб змінити обсяг, або виберіть гілку для порівняння в **Base**. Цей вибір діє, доки ви не
вийдете з TUI, і не змінює `cli.json`.

## Сповіщення

Системні сповіщення та звукові сигнали вмикаються незалежно:

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування сповіщень" tabIndex={0}>

| Параметр                 | Значення               | Опис                                                                                                     |
| ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `attention.notifications` | boolean               | Показує системні сповіщення, зазвичай коли термінал не у фокусі.                                         |
| `attention.sound`        | boolean                | Відтворює звукові сигнали.                                                                               |
| `attention.volume`       | число від `0` до `1`   | Задає гучність звуку.                                                                                    |
| `attention.sound_pack`   | рядок                  | Вибирає ID активного набору звуків.                                                                      |
| `attention.sounds`       | об'єкт                 | Перевизначає звукові файли для `default`, `question`, `permission`, `error`, `done` або `subagent_done`. |

</div>

Якщо перевизначений файл недійсний або його не вдається прочитати, для цієї події використовується вбудований звук.

Після оновлення TUI один раз показує на головному екрані основні нововведення випуску. Виконайте `/highlights`, щоб
переглянути їх знову, або вимкніть це вікно:

```json title="cli.json"
{
  "highlights": false
}
```

## Термінал

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування термінала" tabIndex={0}>

| Параметр         | Значення             | Опис                                                                                                     |
| ---------------- | -------------------- | -------------------------------------------------------------------------------------------------------- |
| `terminal.title` | boolean              | Оновлює заголовок вікна термінала.                                                                       |
| `terminal.copy`  | `manual` або `select` | Копіює вручну або одразу після виділення. Значення за замовчуванням залежить від платформи: `manual` у Windows і `select` на інших платформах. |

</div>

## Mini

Група `mini` керує [`opencode mini`](/cli#mini) — мінімальним інтерактивним інтерфейсом:

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування Mini" tabIndex={0}>

| Параметр            | Значення                       | Опис                                                                               |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| `mini.thinking`     | `show` або `hide`              | Показує або приховує міркування моделі.                                            |
| `mini.tools`        | `show` або `hide`              | Показує або приховує виклики інструментів і текст асистента перед ними.            |
| `mini.shell_output` | `show` або `hide`              | Показує або приховує необроблений вивід інструмента оболонки.                      |
| `mini.turn_summary` | `show` або `hide`              | Показує або приховує в історії прокручування підсумок з агентом, моделлю та тривалістю. |
| `mini.footer`       | `show` або `hide`              | Показує або приховує постійні відомості про активність, модель, використання та контекст. |
| `mini.splash`       | `show` або `hide`              | Показує або приховує заставки під час входу та виходу.                             |
| `mini.work_spinner` | ID індикатора                  | Вибирає анімацію роботи в нижній панелі.                                           |
| `mini.mono`         | boolean                        | Використовує монохромний вивід ASCII.                                              |
| `mini.replay`       | boolean                        | Відновлює історію сесії під час відновлення роботи та зміни розміру термінала.     |
| `mini.replay_limit` | додатне ціле число             | Обмежує відтворення найновішими повідомленнями. Ліміт за замовчуванням — `200`.    |

</div>

Доступні ID індикаторів:

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

Прапорці відтворення в командному рядку `mini` перевизначають ці налаштування для конкретного запуску.

## Гарячі клавіші

Перевизначте сполучення клавіш для команди та тайм-аут клавіші leader:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування гарячих клавіш" tabIndex={0}>

| Параметр                | Значення                                         | Опис                                                                 |
| ----------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| `keybinds.leader`       | значення сполучення                              | Задає клавішу, на яку посилається `<leader>` в інших сполученнях.    |
| `keybinds.<command>`    | значення сполучення                              | Перевизначає сполучення для одного ID команди.                       |
| `keybinds.*.key`        | рядок клавіші або дескриптор                     | Вибирає клавішу для сполучення, заданого об'єктом.                   |
| `keybinds.*.event`      | `press` або `release`                            | Обмежує сполучення, задане об'єктом, однією подією клавіші.          |
| `keybinds.*.preventDefault` | boolean                                      | Визначає, чи блокувати стандартну поведінку клавіші в терміналі.     |
| `keybinds.*.fallthrough` | boolean                                         | Дозволяє обробникам із нижчим пріоритетом отримувати ту саму подію.  |
| `leader.timeout`        | додатне ціле число                               | Задає, скільки мілісекунд чекати після натискання клавіші leader.    |

</div>

Значенням сполучення може бути рядок, масив альтернатив або об'єкт. Щоб вимкнути сполучення, використайте `"none"` або
`false`. Підтримуваний синтаксис клавіш, усі ID команд і всі сполучення за замовчуванням описано в розділі
[Гарячі клавіші](/cli/keybinds).

## Плагіни

Завантажуйте плагіни лише для термінала в заданому порядку:

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування плагінів" tabIndex={0}>

| Параметр             | Значення        | Опис                                                            |
| -------------------- | --------------- | --------------------------------------------------------------- |
| `plugins`            | масив           | Оголошує впорядковані директиви ввімкнення та зовнішні плагіни. |
| `plugins[].package`  | рядок           | Задає назву пакета, локальний шлях або файлову URL-адресу.      |
| `plugins[].options`  | об'єкт          | Передає плагіну його специфічні параметри.                      |

</div>

Форми запису пакетів, локальне виявлення, шаблони з підстановкою та директиви вимкнення описано в розділі
[Плагіни](/cli/plugins).

## Налагодження та експериментальні функції

Увімкніть діагностику або експериментальну функцію, доступну наразі:

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Налаштування налагодження та експериментальних функцій" tabIndex={0}>

| Параметр            | Значення                        | Опис                                                                                |
| ------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `debug.devtools`    | boolean                         | Показує панель налагодження DevTools.                                               |
| `debug.timing`      | boolean                         | Показує на панелі налагодження діагностику часу до першого відображення.            |
| `debug.turn_tokens` | boolean або `verbose`           | Показує використання токенів за кожен хід; `verbose` також додає вхідні дані викликів інструментів. |
| `experimental`      | об'єкт з ID функцій і значеннями boolean | Вмикає або вимикає експериментальні функції, які можуть змінитися або зникнути без попередження. |

</div>

Використовуйте лише ID функцій, які зараз перелічені в діалоговому вікні **Experiments** у TUI. Невідомі ID не діють.
