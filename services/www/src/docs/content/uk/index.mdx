OpenCode — це AI-агент для програмування з відкритим кодом. Він доступний як термінальний інтерфейс, десктопний застосунок
і вебзастосунок.

Пакет npm за допомогою скрипту postinstall вибирає нативний бінарний файл `opencode` для вашої платформи. Команди Bun і
pnpm явно дозволяють запуск цього скрипту; для Vite+ додаткові прапорці не потрібні. Для команди mise потрібна mise 2026.10.9 або новіша; старіші версії встановлюють OpenCode 1.

Менеджери пакетів Windows не підтримуються.


Завантажте окремий бінарний файл CLI для вашої платформи.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Веб

Відкрийте вебінтерфейс OpenCode за допомогою команди `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Образи Docker мають теги з номером версії, наприклад `ghcr.io/anomalyco/opencode:2.0.0`.

## Підключення

OpenCode має вбудовану підтримку багатьох LLM-провайдерів: підключитися до них можна безпосередньо
[у TUI](/cli/providers) командою `/connect`.

Щоб налаштувати власних провайдерів, перегляньте розділ [Провайдери](/providers).

Якщо вам потрібен простий доступ до всіх найкращих моделей для програмування, спробуйте
[OpenCode Console](/console).

Також можна спробувати [OpenCode Go](/console/go) — підписку за $10 на місяць, яка дає доступ до найкращих моделей
з відкритим кодом.

## Налаштування під себе

Налаштуйте OpenCode під себе: відредагуйте [конфігурацію OpenCode](/config), [завантажте плагіни](/plugins),
[підключіть сервери MCP](/mcp-servers) або [створіть команди](/commands). Теми та сполучення клавіш термінального
інтерфейсу описано в розділі [Налаштування CLI](/cli/config).
