---
title: "RPC"
---

Effect-плагіни можуть надавати методи й події, які повертають типізовані Effect і
Stream.

## Визначення

Визначте RPC за допомогою `Rpc.define` і Effect Schema.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Валідація

Effect Schema перевіряє значення та виводить їхні типи TypeScript.

```ts
input: Schema.Struct({ query: Schema.String })
```

Також підтримуються JSON Schema і Standard Schema.

### Вхідні та вихідні дані

`input` описує аргумент методу, а `output` — значення, яке він повертає. Якщо
значення немає, відповідне поле можна пропустити.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Помилки

Додайте очікувані помилки в `errors`. Кожен ключ стає значенням `type` помилки.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Події

Додайте події до мапи `events` верхнього рівня. Дані події мають бути об'єктом.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Реалізація

Зареєструйте реалізацію в Effect плагіна:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Мапа помилок стає типом помилки Effect кожного методу. Щоб створити оголошену
помилку, використайте `context.error(...)`.

## Виклик

Після реєстрації RPC можна викликати через HTTP або з іншого плагіна.

### HTTP

Створіть Effect-клієнт, а потім — RPC-підклієнт:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Плагін

Інший Effect-плагін може створити локальний підклієнт зі свого контексту:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Підписка

Події RPC — це Stream. Підпишіться за назвою події та запустіть Stream у fiber,
прив'язаному до області дії (scope):

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Підписки працюють лише в реальному часі й закриваються, коли споживання Stream
припиняється.
