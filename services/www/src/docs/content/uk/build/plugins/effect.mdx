---
title: "Effect"
---

`@opencode/plugin/effect` — це Effect-нативна версія API плагінів OpenCode. Операції контексту повертають Effect або
Stream, колбеки повертають Effect, а час життя плагіна представлено через `Scope`.

Під час завантаження плагінів і їхніх залежностей із `node_modules` OpenCode сам надає в середовищі виконання `effect`
(разом з експортованими підшляхами `effect/*`) і `@opencode/plugin`. Установіть їх як peer- або dev-залежності для
локальної перевірки типів і тестування, але не включайте їх у збірку плагіна.

```sh
bun add --peer @opencode/plugin effect
```

Експортуйте Effect-плагін із `.opencode/plugins/`, щоб він завантажувався автоматично.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

Опубліковані пакети та каталоги плагінів поза `.opencode/plugins/` підключаються через ту саму конфігурацію `plugins`,
що й інші серверні плагіни.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

Про ввімкнення, розв'язання пакетів і пріоритет конфігурації читайте в розділі [Налаштування плагінів](/plugins).

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## Життєвий цикл

`effect` запускається під час завантаження плагіна. Його область дії (scope) закривається, коли плагін перезавантажується
або вивантажується, тож реєстрації, fiber в області дії та фіналізатори звільняються разом.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

Для фонової роботи використовуйте fiber в області дії. Під час очищення область дії плагіна перериває такий fiber.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### Контекст

Контекст надає Effect-клієнт для підключеного сервера OpenCode, а також доступні лише плагінам перетворення, хуки,
сховище, перезавантаження та параметри. Приватних сервісів Core OpenCode контекст не відкриває.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

Визначення плагіна та повний контекст оголошено так.

```ts
interface Context {

  readonly location: Location.Info
  readonly options: PluginOptions
  readonly agent: AgentDomain
  readonly aisdk: AISDKDomain
  readonly command: CommandDomain
  readonly event: EventDomain
  readonly experimental: {
    readonly terminal: Pick<ExperimentalApi<unknown>["persistentPty"], "read">
  }
  readonly integration: IntegrationDomain
  readonly mcp: MCPDomain
  readonly model: ModelDomain
  readonly generate: GenerateApi<unknown>
  readonly permission: PermissionDomain
  readonly plugin: Pick<PluginApi<unknown>, "list">
  readonly provider: ProviderDomain
  readonly reference: ReferenceDomain
  readonly rpc: RpcDomain
  readonly session: SessionDomain
  readonly shell: ShellDomain
  readonly skill: SkillDomain
  readonly storage: StorageDomain
  readonly tool: ToolDomain
  readonly vcs: VcsDomain
  readonly websearch: WebSearchDomain
  readonly worktree: WorktreeDomain
}

interface Plugin<R = Scope.Scope> {
  readonly id: string
  readonly effect: (context: Context) => Effect.Effect<void, never, R>
}
```

### Параметри

Передавайте параметри в об'єктній формі в `opencode.json(c)`.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

Читайте параметри з `ctx.options`. Перш ніж використовувати значення невідомого типу, звузьте його тип.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## Перетворення

Перетворення синхронно змінюють стан через редактор. У межах кожного домену OpenCode застосовує перетворення в порядку
реєстрації. Спочатку джерела додають провайдерів і незмінні визначення моделей; потім перетворення моделей редагують
кандидатів активних провайдерів. Якщо виконати `yield*` для реєстрації, вона залишається в області дії плагіна.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

Перетворення моделей може застосовувати політику до всієї колекції кандидатів активних провайдерів.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

Викликайте `reload`, коли змінюється зовнішній стан, який використовує перетворення. Тут `loadFromSource()` повертає
записи `{ info: Provider.Info, models: readonly Model.Info[] }`; перезавантаження провайдерів також робить недійсним
весь результат моделей.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### Агент

Отримайте всіх агентів або одного агента за ID. Відповіді клієнта містять розв'язане розташування та дані схеми.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

Перетворюйте або перезавантажуйте агентів.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Схема: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Провайдери

Отримайте доступних провайдерів або перегляньте метадані одного провайдера за ID.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

Перетворення провайдерів редагують налаштування провайдерів і визначення джерел. Читання через редактор охоплює й
неактивних провайдерів і повертає незмінні визначення; `models.update` редагує власну копію моделі з джерела.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

Замініть перелік моделей джерела через `models.set`, а після зміни захоплених визначень виконайте перезавантаження.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

Для виявлення моделей, специфічних для облікового запису, передайте як `sourceConnection` підключення, через яке
завантажено перелік. Поки вибрано інше підключення, OpenCode виключає цього провайдера — доки ваш плагін не опублікує
оновлений перелік.

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

Схеми: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Моделі

Отримайте доступні моделі та вибір за замовчуванням.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

Перетворення моделей редагують усю колекцію кандидатів активних провайдерів. Вимкнені кандидати можна редагувати, доки
не завершаться всі перетворення; `update` може додати модель лише до доступного провайдера.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

Колбеки редагують сирі перевизначення моделей. Значення провайдера за замовчуванням об'єднуються один раз, коли OpenCode
фіксує результат; повторні читання без змін використовують цей результат. `editor.provider` читає незмінні визначення
джерел, зокрема неактивні шаблони, а не результат перетворень моделей.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Схема: [`Model.Info`](/api#schema-Model.Info).

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Команди

Отримайте команди, доступні в поточному розташуванні.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

Наразі перетворення команд дозволяє лише додавати команди. Виконавець отримує сесію, вкладення промпту та режим доставки.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Схеми: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID
  readonly prompt: PromptInput.Prompt
  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Інтеграції

Отримайте інтеграції та розв'яжіть активні облікові дані, якщо вони є.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

Підключіться за допомогою ключа або проведіть спробу OAuth через підключений API.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

Перетворюйте інтеграції та методи автентифікації. Колбеки методів OAuth є Effect і можуть отримувати ресурси в області
дії.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

Схеми: [`Integration.Info`](/api#schema-Integration.Info), [`Integration.Method`](/api#schema-Integration.Method),
[`Connection.Info`](/api#schema-Connection.Info), [`Form.Answer`](/api#schema-Form.Answer).

```ts
type IntegrationOAuthAuthorization = {
  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number
} & (
  | { readonly mode: "auto"; readonly callback: Effect.Effect<Credential.OAuth, unknown> }
  | { readonly mode: "code"; readonly callback: (code: string) => Effect.Effect<Credential.OAuth, unknown> }
)

type IntegrationOAuthMethodRegistration = {
  readonly integrationID: string
  readonly method: IntegrationOAuthMethod
  readonly authorize: (answer: Form.Answer) => Effect.Effect<IntegrationOAuthAuthorization, unknown, Scope.Scope>
  readonly refresh?: (credential: Credential.OAuth) => Effect.Effect<Credential.OAuth, unknown>
  readonly label?: (credential: Credential.OAuth) => string | undefined
}

interface IntegrationEditor {
  list(): readonly IntegrationRef[]
  get(id: string): IntegrationRef | undefined
  update(id: string, update: (integration: IntegrationRef) => void): void
  remove(id: string): void
  readonly method: {
    list(integrationID: string): readonly IntegrationMethod[]
    update(input: IntegrationMethodRegistration): void
    remove(integrationID: string, method: IntegrationMethod): void
  }
}

interface IntegrationDomain extends Omit<IntegrationApi<unknown>, "wellknown"> {
  readonly transform: Transform<IntegrationEditor>
  readonly reload: () => Effect.Effect<void>
  readonly connection: {
    readonly active: (integrationID: string) => Effect.Effect<ConnectionInfo | undefined>
    readonly resolve: (connection: ConnectionInfo) => Effect.Effect<Credential.Value | undefined, unknown>
  }
}
```

### MCP

Отримайте список серверів MCP і їхній поточний стан підключення.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

Плагіни керують серверами MCP лише через перетворення. Щоб додати або замінити сервер, використайте `editor.set`; щоб
змінити його конфігурацію — `editor.update`; щоб видалити — `editor.remove`. Переглянути конфігурацію можна через
`editor.list` і `editor.get`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
      editor.set("docs", { type: "remote", url: "https://mcp.example.com" })
      editor.update("docs", (server) => (server.disabled = false))
      editor.remove("legacy")
    })
  }),
```

Задайте в перетворенні `disabled: true`, щоб вимкнути сервер і від'єднати його, або `disabled: false`, щоб увімкнути

### Інструменти

Реєструйте типізовані інструменти за допомогою Effect `Schema`. Виконавець отримує декодовані вхідні дані й повертає
Effect із типізованим результатом, вмістом для відображення або метаданими.

Редактор підтримує `add`, `update` і `remove`. Колбек перетворення синхронний: він не повинен повертати Effect або
Promise. Завантажуйте зовнішні дані до реєстрації чи перезавантаження. OpenCode повторно застосовує активні перетворення
в порядку реєстрації до нового редактора; для однакової ефективної назви інструмента пізніша коректна реєстрація
перевизначає попередню.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

Після зміни вихідних даних, захоплених колбеком, викличте `yield* ctx.tool.reload()`. Перезавантаження повторно
застосовує активні перетворення, не змінюючи їхнього порядку; ефект плагіна повторно не запускається.

Інструменти мають `id` з їхньою ефективною назвою, а `get()` повертає `undefined`, якщо такого ID немає. Передавайте в
`update` і `remove` ефективну назву інструмента разом із простором імен (у прикладі вище — `acme_greeting`). Крапки в
просторах імен і непідтримувані символи в назвах інструментів замінюються на `_`. Відсутні назви ігноруються; щоб
створити інструмент, потрібен `add` з повним визначенням. Оновлення зберігають назву та простір імен. Щоб замінити схеми
чи параметри, присвойте нові значення, а не змінюйте вкладені. Некоректні оновлення записуються в журнал, а попереднє
визначення залишається без змін.

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

Оновлення та видалення повторно застосовуються в порядку разом із додаваннями, зокрема після оновлення каталогу MCP.

`transform` повертає реєстрацію, прив'язану до області дії. Виконайте `yield* registration.dispose`, щоб видалити її
перетворення й перебудувати стан з решти перетворень; тоді знову стане видимим будь-яке раніше визначення, яке воно
перевизначало. Звільнення ідемпотентне, а закриття області дії плагіна також звільняє його реєстрації.

Кожен запит до моделі захоплює знімок інструментів. Перезавантаження та звільнення впливають на майбутні знімки, а не
на визначення чи виконавців, уже захоплених наявним запитом. Виконавці, що замикають змінні дані плагіна, і далі бачать
ці дані; якщо значення має залишатися прив'язаним до конкретного визначення, захопіть його всередині перетворення.

Схеми: [`Tool.Content`](/api#schema-Tool.Content), [`Tool.TextContent`](/api#schema-Tool.TextContent),
[`Tool.FileContent`](/api#schema-Tool.FileContent).

```ts
interface ToolEditor {
  list(): readonly (Tool.Info & { readonly id: string })[]
  get(id: string): (Tool.Info & { readonly id: string }) | undefined
  namespace(namespace: { name: string; description: string }): void
  add<Input extends Tool.ValueSchema<any>, Output extends Tool.ValueSchema<any> | undefined>(
    tool: Tool.Info<Input, Output>,
  ): void
  update(id: string, update: (tool: Types.Mutable<Tool.Info>) => void): void
  remove(id: string): void
}

interface ToolDomain {
  readonly list: () => Effect.Effect<readonly (Tool.Info & { readonly id: string })[]>

```

Зареєструйте провайдера для розташування через перетворення в області дії. Провайдери, що відповідають виявленому типу
репозиторію, вибираються автоматично; щоб вибрати іншого провайдера, використайте `editor.default.set`.

Колбеки провайдера отримують поточне розташування, корінь робочої копії, канонічний корінь проєкту та необов'язкове

Для виявлення репозиторіїв і далі використовуються вбудовані детектори Git і Mercurial в OpenCode.

Провайдери можуть додатково реалізувати `init(scope)`, щоб створювати репозиторій у `scope.worktree`. Під час

провайдера з `init`, навіть якщо в розташуванні ще немає репозиторію: перед викликом OpenCode перевіряє, що каталог

виявлення, яку цей колбек не забезпечує.

### Сесії

Змінюйте зібрані системні інструкції, повідомлення або інструменти безпосередньо перед надсиланням запиту до моделі.
`context` запускається для циклу агента; `compaction`, `generate` і `title` — для відповідних допоміжних запитів.
`compaction` і `title` приймають `result`, який дає змогу пропустити виклик моделі.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

Змінюйте налаштування запиту до моделі й за потреби обмежуйте хук одним провайдером. Подія містить той самий `kind`, що
й описані нижче HTTP-хуки.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

Змінюйте нативні запити до провайдера або його відповіді. Їхні тіла є одноразовими потоками: перш ніж читати тіло,
клонуйте або замініть його. Обидва хуки запускаються для кожного запиту, який надсилає сесія; `event.kind` має значення
`"primary"`, `"compaction"`, `"title"` або `"generate"` залежно від того, який процес надіслав запит.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

Провайдери, що передають потік через WebSocket, повторно використовують одне з'єднання на сесію, тому HTTP-хуки цього
трафіку не бачать. Експериментальний хук `experimental.ws.handshake` запускається один раз на виклик моделі до вибору
з'єднання й надає `url` і `headers` з'єднання; зміна будь-якого з них повторно відкриває сокет. HTTP-хуки, як і раніше,
запускаються для всіх запитів, на які маршрут WebSocket переходить як на резервний варіант.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` і `experimental.ws.receive` надають доступ до самих фреймів: `send` запускається після того, як
драйвер провайдера сформує вихідний фрейм, а `receive` — для кожного вхідного фрейму, перш ніж його побачить драйвер.
Те, що міститься у `frame` на момент повернення з хука, і буде передано мережею або драйверу; OpenCode це значення не
перевіряє.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

Перевизначте рішення про повторну спробу після збою провайдера або замініть затримку в мілісекундах. Хук запускається
після того, як OpenCode класифікує збій і запропонує свою політику, але до планування будь-якої повторної спроби. Він не
розкриває, як OpenCode внутрішньо виконує наступну спробу.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

Початкове значення `decision` — це політика OpenCode, тож хуки можуть зробити повторюваним збій провайдера, який
зазвичай є остаточним, або скасувати запропоновану повторну спробу. Кілька хуків запускаються в порядку реєстрації, і
пізніші бачать поточне рішення. Вбудована максимальна кількість спроб залишається жорстким обмеженням. `attempt` — це
номер фактичної спроби, що пропонується; початковий запит — це спроба `1`, тож перша повторна спроба — це спроба `2`.
Некоректні затримки (`NaN`, нескінченність або від'ємні значення) замінюються обчисленою затримкою. Відновлення після
переповнення контексту працює окремо, оскільки воно стискає розмову, а не повторює той самий запит.

### Оболонка

Змінюйте команди оболонки, робочі каталоги, тайм-аути, виконувані файли або змінні середовища перед виконанням.

effect: (ctx) =>

### Інструменти

Хуки «before» можуть замінити вхідні дані або завершитися помилкою `Tool.Error`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

Хуки «after» можуть переглядати або замінювати успішні результати й помилки.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

#### Довідка

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
}

interface ToolFailures extends Record<keyof ToolHooks, unknown> {
  readonly "execute.before": Tool.Error
  readonly "execute.after": never
}

interface ToolHookDomain {
  readonly hook: Hooks<ToolHooks, ToolFailures>
}
```

Спільні типи реєстрації показують, яким операціям потрібна область дії плагіна.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## Публікація

Плагін-пакет використовує той самий експорт за замовчуванням, що й локальний Effect-плагін. Експортуйте Effect-реалізацію
з головної точки входу та оголосіть `effect` як `peerDependency`.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

OpenCode перенаправляє імпорти `effect`, експортованих підшляхів `effect/*` і `@opencode/plugin` (зокрема імпорти із
залежностей у `node_modules` плагіна) на екземпляри середовища виконання хоста, щоб fiber, логери та парсери `Schema`
спільно використовували одну копію середовища виконання.

- Не включайте `effect` у збірку опублікованого плагіна. Якщо використовуєте бандлер, позначте `effect` і `effect/*` як
  зовнішні (external).
- Плагіни та їхні залежності з `node_modules` завжди виконуються з екземпляром `effect` того релізу OpenCode, що є
  хостом. Використовуйте API та шляхи модулів `effect`, сумісні з цільовим релізом OpenCode; залежності, зібрані під іншу
  мажорну версію `effect` (наприклад, Effect 3), також отримують `effect` хоста й не підтримуються.
- Доступні лише публічні підшляхи `effect`. Плагін, який імпортує один із приватних модулів `internal` Effect, не
  завантажиться, а помилка міститиме шлях до модуля.
- Скомпільований бінарний файл OpenCode не містить ресурсів Scalar і Swagger UI, які використовують сторінки
  документації HTTP API в Effect; якщо плагін віддає ці сторінки, замість них відображається повідомлення.

Точка входу пакета експортує `Plugin.define` з функцією `effect`.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

Використовуйте версії, сумісні з цільовим релізом OpenCode, і тестуйте встановлений пакет, а не лише копію, підключену як
workspace-залежність.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
