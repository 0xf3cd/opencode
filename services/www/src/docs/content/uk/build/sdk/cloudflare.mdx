Використовуйте `@opencode/sdk/workerd` усередині Cloudflare Durable Object. Цей профіль використовує сховище SQLite
об'єкта, зберігає постійні події для відновлення після витіснення та замінює недоступні сервіси локальної файлової
системи й процесів.

```sh
bun add @opencode/sdk
```

Тримайте один хост протягом усього життя екземпляра Durable Object, а не створюйте новий для кожного запиту.

```ts
import { OpenCodeWorkerd } from "@opencode/sdk/workerd"
import myPlugin from "./my-plugin"

export class OpenCodeDO {
  private readonly opencode: Promise<OpenCodeWorkerd.Interface>

  constructor(state: DurableObjectState) {
    this.opencode = state.blockConcurrencyWhile(() =>
      OpenCodeWorkerd.create({
        storage: state.storage,
        config: { default_agent: "build" },
        plugins: [myPlugin],
      }),
    )
  }

  async fetch() {
    const opencode = await this.opencode
    return Response.json(await opencode.server.info())
  }
}
```

`blockConcurrencyWhile` не пропускає жодних подій Durable Object, доки хост не буде готовий, і скидає об'єкт, якщо
ініціалізація завершилася помилкою. Збережений Promise дає обробникам запитів прямий доступ до того самого хоста після
запуску.

```ts
constructor(state: DurableObjectState) {
  this.opencode = state.blockConcurrencyWhile(() =>
    OpenCodeWorkerd.create({ storage: state.storage }),
  )
}
```

Wrangler вибирає безпечні для Workerd реалізації OpenCode через умову пакета `workerd`. Cloudflare може витіснити
Durable Object без виконання очищення, тому коректність роботи не залежить від виклику `close()`.

```jsonc title="wrangler.jsonc"
{
  "compatibility_flags": ["nodejs_compat"]
}
```

## Налаштування

Налаштовуйте свій екземпляр OpenCode, реєструючи плагіни, що входять до збірки
вашого Worker. Передайте плагіни в `OpenCodeWorkerd.create()`, щоб налаштувати
агентів, моделі, інструменти та іншу поведінку:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCodeWorkerd } from "@opencode/sdk/workerd"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await OpenCodeWorkerd.create({
  storage: state.storage,
  config: { default_agent: "build" },
  plugins: [plugin],
})
```

Хуки, перетворення, інструменти та повний контекст плагіна описано в
[повній документації з плагінів](/build/plugins).
