---
title: "Вступ"
---

OpenCode щодня користуються мільйони людей. Створюйте на його основі власні застосунки, інтеграції та агентні сценарії,
не починаючи з нуля.

Також доступні Effect API для [плагінів](/build/plugins/effect), [клієнтів](/build/client/effect) і
[вбудованих застосунків](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Розширте OpenCode" href="/build/plugins">
    Створюйте плагіни, які додають інструменти, інтеграції, команди, агентів і власну поведінку, не змінюючи решту
    OpenCode.
  </Card>
  <Card title="Запустіть як сервер" href="/build/client">
    Підключайтеся до OpenCode тим самим клієнтом, що й TUI та десктопний застосунок, і будуйте навколо нього будь-який
    інтерфейс, робочий процес чи агентний сценарій.
  </Card>
  <Card title="Вбудуйте у свій застосунок" href="/build/sdk">
    Вбудуйте OpenCode безпосередньо у свій застосунок і створіть на його основі повністю власного агента, інтерфейс або
    продукт для розробників.
  </Card>
</CardGroup>
