Щоб вибрати тему в термінальному інтерфейсі, натисніть `Ctrl+P`, виберіть **Open settings** і відкрийте **Theme**. Також
її можна задати безпосередньо в глобальній конфігурації CLI:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Теми належать термінальному клієнту. Вибір теми задавайте в `cli.json`, а не в `opencode.json`. Розташування
конфігурації та інші налаштування термінала описано в розділі [Налаштування CLI](/cli/config).

## Режими

Використовуйте `system`, щоб тема відповідала оформленню термінала, або зафіксуйте один режим:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Значення | Поведінка                                        |
| -------- | ------------------------------------------------ |
| `system` | Відповідає світлому або темному режиму термінала. |
| `dark`   | Завжди використовує темну тему.                  |
| `light`  | Завжди використовує світлу тему.                 |

Якщо власна тема має лише один режим, OpenCode використовує його й тоді, коли запитано інший.

## Вбудовані теми

Виберіть вбудовану тему за назвою:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Доступні теми:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

Тема `system` доступна, якщо OpenCode може прочитати палітру вашого термінала.

## Файли

Щоб створити глобальну тему з назвою `ocean`, згенеруйте за допомогою інструмента тем повний файл у глобальному каталозі
тем. Його основна структура виглядає так:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Потім виберіть `ocean` у налаштуваннях або задайте `theme.name` значення `ocean` у `cli.json`. Назва файлу без `.json`
є назвою теми.

| Область   | Каталог                                    |
| --------- | ------------------------------------------ |
| Глобальна | `~/.config/opencode/themes/`               |
| Проєкт    | `.opencode/themes/` у дереві проєкту       |

OpenCode читає лише файли `.json`. Тема, розташована ближче до поточного каталогу, замінює глобальну або батьківську
тему з тією самою назвою.

## Формат

Кожна тема V2 оголошує одне повне дерево токенів `base` і щонайменше одну палітру відтінків `light` або `dark`. Режими
успадковують лише від `base` цього файлу; вони не успадковують ні від вбудованої теми OpenCode, ні один від одного.
Перш ніж налаштовувати тему, згенеруйте повну основу за допомогою інструмента тем.

Наведені нижче приклади показують лише розділи, що стосуються відповідного поняття; це не повні файли тем.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Кольори

Використовуйте шістнадцятковий колір, `transparent` або посилання на інший колір теми:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Шістнадцяткові значення можуть мати 3, 4, 6 або 8 цифр. Посилання починаються з `$`; посилання на відтінки мають форму
`$hue.<name>.<step>`.

## Відтінки

Перевизначте псевдонім відтінку, щоб одразу змінити цілу групу пов'язаних кольорів:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Тип       | Значення                                                             |
| --------- | -------------------------------------------------------------------- |
| Базовий   | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Псевдонім | `accent`, `interactive`, `neutral`                                   |
| Крок      | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Кроки відтінків ідуть у напрямку контрасту режиму: у світлих темах від темного на `100` до світлого на `900`, а в темних
темах — від світлого на `100` до темного на `900`.

`categorical` задає впорядковані відтінки, якими розрізняються агенти та інші повторювані елементи. Він має містити
щонайменше один базовий відтінок або псевдонім.

## Стани

Ключі станів змінюють кольори інтерактивних елементів. Для незаданих станів використовується найближче базове значення:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Група  | Значення                                                     |
| ------ | ------------------------------------------------------------ |
| Дії    | `primary`, `secondary`, `destructive`                        |
| Стани  | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Поля форм використовують ті самі ключі станів безпосередньо в `text.formfield` або `background.formfield`.

## Токени

Повна `base` містить усі групи токенів. Режим може перевизначити будь-яку її частину, якщо надає повну палітру
відтінків:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Група        | Призначення                                                         |
| ------------ | ------------------------------------------------------------------- |
| `text`       | Базовий і приглушений текст, текст дій, полів форм і зворотного зв'язку |
| `background` | Базовий фон, поверхні, дії, поля форм і заливки зворотного зв'язку  |
| `border`     | Рамки                                                               |
| `scrollbar`  | Смуги прокручування                                                 |
| `diff`       | Кольори доданих і видалених рядків, контексту, виділення та номерів рядків |
| `syntax`     | Підсвічування вихідного коду                                        |
| `markdown`   | Елементи Markdown                                                   |

Ключі синтаксису: `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` і
`punctuation`. Ключі Markdown: `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`,
`horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` і `codeBlock`.

## Підняті поверхні

Панелі, діалоги, меню та спливні сповіщення вибирають глибину з `background.raised`. Діалоги додатково підтримують
контекстну поверхню `@dialog`. Після застосування `@dialog` інтерфейс TUI повторно обчислює палітру, тому токени, що
посилаються на `$background.base`, відповідають фону діалогу:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` приймає ті самі групи токенів, що й базовий режим. Контекстне значення `base` дії також стає резервним для її
незаданих станів; явне перевизначення стану однаково має пріоритет.
