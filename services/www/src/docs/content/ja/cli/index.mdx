プロジェクト内で CLI を実行すると、フルスクリーンのターミナルインターフェイスが開きます。

```bash
opencode
```

別のプロジェクトで作業するには、ディレクトリを指定します。

```bash
opencode ~/code/my-project
```

推奨ターミナル：

- [Ghostty](https://ghostty.org)
- [WezTerm](https://wezterm.org)
- [Alacritty](https://alacritty.org)
- [Kitty](https://sw.kovidgoyal.net/kitty/)

Truecolor に対応したターミナルでは、テーマの色が最も正確に表示されます。対応していないターミナルでは、利用可能なパレットで近似した色が使われます。

## 自動化

`opencode run` を使うと、対話型インターフェイスを開かずにプロンプトを送信できます。スクリプトや CI ジョブなど、モデルの出力をターミナルで直接受け取りたいワークフロー向けのコマンドです。

```bash
opencode run "Explain this repository"
```

## Mini

フルスクリーンの TUI の代わりに、`opencode mini` で OpenCode の最小構成の対話型インターフェイスを起動できます。

```bash
opencode mini
```

`opencode mini --help` を実行すると、セッション、モデル、エージェント、プロンプト、リプレイに関するオプションを確認できます。

## バックグラウンドサービス

デフォルトでは、OpenCode はユーザーアカウントごとに 1 つの共有バックグラウンドサーバーを検出するか、起動します。ローカルのすべての OpenCode クライアントはこのサーバーに接続し、セッション、設定、連携機能、権限、ツールの実行はこのサーバーが管理します。

専用のサーバーで実行するには `--standalone` を、特定のサーバー URL に接続するには `--server` を使用します。

```bash
opencode --standalone
opencode --server http://localhost:4096
```

共有サービスを起動する代わりに、専用サーバーを CLI コマンドのデフォルトにするには、共有サービスを無効にします。

```bash
opencode service set disabled true
opencode
```

これにより、実行中のバックグラウンドサービスは停止します。無効にした後も、`--server` で明示的に指定したサーバーには接続でき、`opencode service start` で共有サービスを明示的に起動することもできます。サービスの自動利用に戻すには、`opencode service unset disabled` を実行します。ペアリングには共有サービスが必要なため、無効にしている間は利用できません。

共有サービスの診断については[トラブルシューティング](/troubleshooting)を、サーバーのエンドポイントについては [API リファレンス](/api)を参照してください。

## パス

他のツールで使うために、特定のローカルパスを出力します。

```bash
opencode debug paths db
sqlite3 "$(opencode debug paths db)"
```

省略可能なセレクターには `db`、`home`、`data`、`config`、`cache`、`state`、`tmp`、`bin`、`log`、`repos` のいずれかを指定でき、パスと改行のみを出力します。データベースのパスはリリースチャンネルと `OPENCODE_DB` に従います。データベースのパスを相対パスで上書きした場合はデータディレクトリを基準に解決され、`:memory:` はそのまま出力されます。このコマンドはサーバーを起動せず、データベースも開きません。

セレクターを省略すると、すべてのパスがラベル付きで表示されます。

```bash
opencode debug paths
```

## アンインストール

削除されるファイルとインストールを事前に確認します。

```bash
opencode uninstall --dry-run
```

`opencode uninstall` を実行し、確認すると削除されます。OpenCode は、登録済みのバックグラウンドサービスと永続ターミナルを停止してから、グローバルキャッシュディレクトリを削除します。このディレクトリは OpenCode のバージョンやチャンネル間で共有されています。セッションデータ、設定、状態が削除されることはありません。

- `--force` (`-f`) を指定すると確認をスキップします。非対話的に削除する場合に使用します。
- パッケージマネージャーでインストールした場合は、検出されたパッケージマネージャーを使って削除します。curl でインストールした場合は、最後に、実行ファイルを手動で削除するためのコマンドが出力されます。
