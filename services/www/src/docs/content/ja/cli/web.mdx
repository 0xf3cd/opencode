title: "Web"
description: "ブラウザーで OpenCode を実行します。"
---

OpenCode には Web UI が付属しており、TUI を動かしているのと同じサーバーから配信されます。デフォルトで利用でき、パスワードで保護されています。

## アクセス

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

  █▀▀▀▀▀█ ...
```

ブラウザーでリンクを開くと、セッション Cookie でサインインし、Web UI が読み込まれます。OpenCode アプリから QR コードをスキャンするか、アプリのサーバーアドレス欄にリンクを貼り付けても、同じようにアプリが接続されます。セッションの有効期間は 30 日です。サーバーのパスワードを変更すると、すべてのセッションがサインアウトされます。

### SSH 経由のアクセス

サーバーが localhost でのみ待ち受けている場合は、手元のマシンからそのポートをフォワードし、表示されたリンクをローカルで開きます。

```bash
$ ssh -L 49374:127.0.0.1:49374 my-server
```

デフォルトでは、サーバーはポート 49374 で動作し、localhost でのみ待ち受けます。この設定は `opencode service` コマンドで変更できます。

### リモートアクセス

どこからでも接続するには、[OpenTunnel](https://github.com/anomalyco/opentunnel) のリモートアドレスを使ってペアリングします。

```bash
$ opencode pair --remote
```

初めてリモートアクセスを有効にするときは、続行する前に確認を求められます。

```text
▲  This will expose your OpenCode server to the internet.
│  Traffic is end-to-end encrypted, and access requires your server password.
│  To pair locally instead, run `opencode pair` without the --remote flag.
│
◆  Expose your server to the internet?
│  ● Yes / ○ No
```

対話型ターミナルがない場合は、承認のために `--yes` を指定しないとコマンドは失敗します。一度承認すると、以降の実行では確認が省略されます。これは、`opencode service set remote false` でリモートアクセスを無効にした後も同様です。

## 設定

各オプションは `opencode service set` で設定します。

```bash
# Listen on every network interface
$ opencode service set hostname 0.0.0.0

# Use a fixed port instead of the channel default
$ opencode service set port 49374

# Replace the generated password
$ opencode service set password "a-long-secret"

# Allow a web client served from another origin
$ opencode service set cors https://app.example.com,https://other.example.com

# Pass an environment variable to the server process
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

設定を変更すると、バックグラウンドサーバーは停止します。新しい設定を適用するには、次のコマンドを実行します。

```bash
$ opencode service start
```

## スタンドアロン

`opencode serve` は、共有バックグラウンドサービスを経由せず、同じサーバーをフォアグラウンドで実行します。

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
server listening on http://0.0.0.0:4096
server password <password>
```

次のような場合に使用します。

- 共有のホスト、常時稼働しているホスト、またはリモートホストで OpenCode を実行し、`opencode --server <url>` でクライアントを接続する場合。
- 単一のプロセスについて、ホスト名、ポート、CORS のオリジンを制御する場合。
- systemd や Docker など、フォアグラウンドプロセスを前提とするスーパーバイザーや環境で実行する場合。
- 共有バックグラウンドサービスではなく、専用のサーバーを維持する場合。

`--server` を使ってクライアントを接続します。

```bash
$ opencode --server http://127.0.0.1:4096
```
