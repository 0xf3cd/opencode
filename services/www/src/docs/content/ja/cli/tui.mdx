---

プロジェクトで OpenCode を実行し、リクエストを入力して **Enter** を押します。

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

改行するには **Shift+Enter**、**Ctrl+Enter**、**Alt+Enter**、**Ctrl+J** のいずれかを押します。OpenCode の作業中に **Enter** を押すと、実行中のセッションに指示を割り込ませます。プロンプトを後で実行するようキューに入れるには、**Ctrl+X** を押してから **Enter** を押します。

## コンテキスト

`@` を入力してファイルを検索し、選択するとそのファイルがプロンプトに添付されます。`@` の後に続けて入力すると、結果を絞り込めます。

```text
Review @src/auth.ts for error handling problems
```

パスの後に行番号や行範囲を指定することもできます。

```text
Explain @src/auth.ts#20-45
```

## シェル

空のプロンプトの先頭で `!` を入力すると、シェルモードに入ります。コマンドを入力して **Enter** を押します。コマンドを実行せずにシェルモードを終了するには **Esc** を押します。

```text
!git status
```

シェルコマンドはセッションの作業ディレクトリで実行され、その出力はセッション内に残ります。

## コマンド

`/` を入力すると、スラッシュコマンドの一覧が表示されます。続けて入力して一覧を絞り込み、**Enter** を押すと選択したコマンドが実行されます。

```text
/models
```

よく使うコマンドには `/new`、`/sessions`、`/models`、`/agents`、`/undo`、`/redo`、`/editor` などがあります。**Ctrl+P** を押すと、現在のビューで利用できるすべての操作を含むコマンドパレットが開きます。

アップデート後、OpenCode はホーム画面にリリースの新機能を一度だけ表示します。もう一度見るには `/highlights` を実行します。自動的に表示されないようにするには、[`cli.json`](/cli/config#alerts) で `"highlights": false` を設定します。

## 補足の質問

`/btw <question>` を実行すると、ここまでの会話について簡単な質問ができます。回答にはセッションのコンテキストと現在のモデルが使われますが、会話には追加されないため、以降のプロンプトには影響しません。実行中はプロンプトのフッターに `/btw` インジケーターが表示され、回答はダイアログで開きます。**C** を押すと回答をコピーできます。

```text
/btw why did the test in step 2 fail?
```

## モデル

モデルを選択するには、**Ctrl+X** を押してから **M** を押すか、`/models` を実行します。**F2** を押すと、最近使ったモデルを順に切り替えられます。

エージェントを選択するには、**Ctrl+X** を押してから **A** を押すか、`/agents` を実行します。**Shift+Tab** を押すと、エージェントを順に切り替えられます。

## セッション

新しいセッションを開始するには、**Ctrl+X** を押してから **N** を押します。既存のセッションに戻るには、**Ctrl+X** を押してから **L** を押すか、`/sessions` を実行します。**Ctrl+O** を押すと、最近のセッションとプロジェクトがまとめて表示されます。

タブはデフォルトで有効です。**Ctrl+Tab** と **Ctrl+Shift+Tab** でタブ間を移動し、**Ctrl+X** の後に **W** でタブを閉じ、**Ctrl+Shift+T** で最後に閉じたタブを開き直します。

## 履歴

**Ctrl+X** を押してから **U** を押すか、`/undo` を実行すると、最新のユーザーメッセージとその後の作業が元に戻ります。元に戻したプロンプトは入力欄に戻るので、編集できます。

**Ctrl+X** を押してから **R** を押すか、`/redo` を実行すると、元に戻した作業が復元されます。代わりに新しいプロンプトを送信すると、元に戻した状態が確定し、その時点から作業が続行されます。

## エディター

`VISUAL` または `EDITOR` を設定してから、**Ctrl+X** を押して **E** を押すか、`/editor` を実行すると、現在のプロンプトをそのエディターで編集できます。保存して終了するとテキストが入力欄に戻るので、**Enter** を押して送信します。

```bash
export EDITOR="nvim"
opencode
```

リーダーキーはデフォルトで **Ctrl+X** です。これらのショートカットを変更するには、[キーバインド](/cli/keybinds)を参照してください。
