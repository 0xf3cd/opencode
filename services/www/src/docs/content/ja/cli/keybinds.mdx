---
title: "キーバインド"
---

キーバインドは `cli.json` でカスタマイズします。

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

1 つのキーを割り当てるには、文字列を使用します。

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

複数の代替キーはカンマで区切ります。

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

バインドを無効にするには、`"none"` または `false` を指定します。

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

イベントの動作を指定するには、オブジェクトを使用します。

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` のデフォルトは `ctrl+x` です。他のバインドで `<leader>` と書くと、このキーを参照します。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

不明なコマンド ID は拒否されます。

## Mini

`app.clear` コマンドは [`opencode mini`](/cli) でのみ動作します。`ctrl+l` を押すと、表示中の画面をクリアしてプロンプトを再描画します。ターミナルのスクロールバックは保持されます。

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | デフォルト  | 説明      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | 画面をクリア |

## 差分ビューアー

`d` (`diff.switch_source`) を押すと、**All**、**Committed**、**Uncommitted**、**Last turn**（セッション内のみ）のいずれかを選択できます。**Base** を選択すると、比較対象のブランチを変更できます。選択内容は TUI を終了するまで保持されます。初期スコープは [`cli.json` の `diffs.source`](/cli/config#diffs) で設定します。

スクロール、ページ送り、先頭／末尾への移動のショートカットは、常に差分に対して働きます。キーボードフォーカスの切り替えはありません。ファイルをクリックすると開き、フォルダーをクリックすると展開または折りたたみます。ファイルツリーのスクロールにはマウスホイールを使用します。

ファイル間を移動するには、`n` / `p` または `alt+down` / `alt+up`（macOS では Option）を使用します。差分ビューアー内では、Alt のショートカットはセッションタブではなくファイル間の移動に使われます。

`m` を押すと、ファイルをレビュー済みにして、パッチの本文を折りたたみます。全ファイル表示では、もう一度 `m` を押すとレビュー済みが解除され、パッチが再び開きます。単一ファイル表示では、レビュー済みにすると自動的に次のファイルに進みますが、最後のファイルでは先頭に戻らずにそのまま留まります。レビュー済みを解除しても、次のファイルには進みません。

サイドバーのファイルまたはその差分の見出しを右クリックすると、**Mark complete**（または **Mark incomplete**）を選択できます。これは `m` と同じレビュー済みの状態を変更します。メニューから別のファイルを完了にしても、そのファイルは選択されず、現在読んでいるファイルからも進みません。

`diff.help` の Shift 付きの代替キーは、`?` を押したときに Shift 修飾キーを報告するターミナル向けです。

**Shell** タブで実行中のコマンドを選択して **Enter** を押すか、クリックすると、取得された stdout と stderr を表示できます。スクロールには **↑/↓**、**Page Up/Down**、**Home** を使用し、新しい出力を追従するには **End** を、コマンドを停止せずに戻るには **Esc** を押します。ビューアーには最近の出力が表示され、コマンドの終了後も開いたままになります。ファイルにリダイレクトされた出力は含まれません。
