---
title: "はじめに"
---

OpenCode は毎日数百万人に使われています。OpenCode を基盤にすれば、独自のアプリケーション、インテグレーション、エージェント体験をゼロから作らずに構築できます。

[プラグイン](/build/plugins/effect)、[クライアント](/build/client/effect)、[組み込みアプリ](/build/sdk/effect)向けの Effect API も提供しています。

<CardGroup cols={1}>
  <Card title="OpenCode を拡張する" href="/build/plugins">
    ツール、インテグレーション、コマンド、エージェント、独自の動作を追加するプラグインを構築できます。OpenCode のほかの部分はそのまま維持されます。
  </Card>
  <Card title="サーバーとして実行する" href="/build/client">
    TUI やデスクトップアプリと同じクライアントで OpenCode に接続し、それを中心にあらゆるインターフェイス、ワークフロー、エージェント体験を構築できます。
  </Card>
  <Card title="組み込む" href="/build/sdk">
    OpenCode をアプリケーションに直接組み込み、完全に独自のエージェント、インターフェイス、開発者向け製品を構築できます。
  </Card>
</CardGroup>
