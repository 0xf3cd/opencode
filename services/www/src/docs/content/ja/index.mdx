OpenCode はオープンソースの AI コーディングエージェントです。ターミナルベースのインターフェイス、デスクトップアプリ、Web アプリとして利用できます。


## CLI

npm パッケージは postinstall スクリプトを使って、お使いのプラットフォームに対応するネイティブの `opencode` バイナリを選択します。上記の Bun と pnpm のコマンドでは、必要なスクリプトの実行を明示的に許可しています。Vite+ では追加のフラグは不要です。mise のコマンドには mise 2026.10.9 以降が必要です。それより古いバージョンでは OpenCode 1 がインストールされます。

Windows のパッケージマネージャーには対応していません。


お使いのプラットフォーム向けのスタンドアロン CLI バイナリは、以下からダウンロードできます。

- **macOS：** [Apple シリコン](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows：** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc)：** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl)：** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

`opencode pair` コマンドを使うと、OpenCode の Web インターフェイスにアクセスできます。

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker イメージには、`ghcr.io/anomalyco/opencode:2.0.0` のようにバージョン付きのタグが付いています。

## 接続

OpenCode は多くの LLM プロバイダーに標準で対応しており、[TUI から](/cli/providers) `/connect` を使って直接接続できます。

カスタムプロバイダーの設定については、[プロバイダー](/providers)を参照してください。

優れたコーディングモデルをまとめて手軽に使いたい場合は、[OpenCode Console](/console) をお試しください。

[OpenCode Go](/console/go) もお試しいただけます。月額 $10 のサブスクリプションプランで、最高水準のオープンソースモデルを利用できます。
