title: "請求"
description: "OpenCode Console でクレジットの追加、自動チャージの設定、支払い方法の管理、請求書のダウンロードを行います。"
---

Console はチームの規模にかかわらず無料で、シート料金はかかりません。料金は使用量に対してのみ発生し、ワークスペース全体で共有するプリペイドのクレジットから支払われます。オーナーと管理者は **Settings › Billing** で請求を管理します。

[自分のプロバイダー](/console/providers)を通じた使用量は、Console ではなくプロバイダーから請求されます。

## 支払い方法の追加

1. **Settings › Billing** を開きます。
2. **Payment methods** の下にある **Add** をクリックします。
3. 支払い方法を選択し、Stripe での設定を完了します。

対応している支払い方法：

- カード
- Link
- Alipay
- UPI
- WeChat Pay

自動での請求に使う支払い方法は、**⋯ › Make default** で選択します。支払い方法を削除すると、その方法を使う自動チャージや Go の更新が停止することがあります。

## クレジットの追加

1. **Credits** の下にある **Add credits** をクリックします。
2. $10、$50、$100 のいずれかを選ぶか、**Other** を選んで金額を入力します。
3. 支払い方法を選択し、**Confirm and pay** をクリックします。

4.6% + $0.31 の処理手数料が上乗せされます。たとえば $50 を購入すると支払額は $52.61 となり、残高には $50 全額が追加されます。

## 自動チャージ

自動チャージは、残高が少なくなったときにクレジットを購入します。

1. **Auto-recharge** の下にある **Add rule** をクリックします。
2. 請求のきっかけとなる残高と、追加する金額を設定します。
3. **Save** をクリックします。

自動チャージでは、処理手数料を含めてデフォルトの支払い方法に請求されます。請求に失敗すると、もう一度設定するまで自動チャージはオフになります。

## 残高の確認

オーナーと管理者は、**Overview** の **Credits** カードで残高を確認できます。

## クレジットがなくなった場合

残高がゼロになると、有料のリクエストは HTTP `402` で失敗します。残高がマイナスになることはありません。

```text
Upstream request failed: Insufficient account funds
```

## 請求書

すべての支払いは、ステータスと **Download invoice** または **View receipt** へのリンクとともに **Invoices** に表示されます。

| エントリ | 作成されるタイミング |
| ---------------- | ------------------ |
| Balance top-up   | クレジットの追加 |
| Automatic top-up | 自動チャージ |
| Go subscription  | Go の購読 |
| Go renewal       | Go の毎月の更新 |
| Monthly Usage    | 請求書払い |

## 請求書払い

与信契約を結んでいるワークスペースでは、クレジットを購入する代わりに月ごとの請求書払いを利用できます。設定するにはサポートにお問い合わせください。

- 使用量は、プリペイドの残高ではなく与信枠から差し引かれます。
- 各月の請求書は 1 日（UTC）に発行され、支払期限は 14 日後です。
- 未払いの請求書には **Pay now** ボタンが表示されます。
- 与信枠に達した場合や請求書の支払期限を過ぎた場合、リクエストは HTTP `402` で失敗します。

## Go

[OpenCode Go](/console/go) のサブスクリプションでは、同じ支払い方法を使い、同じ請求書の一覧に表示されます。Go の上限に達した後にクレジットから支払うには、**Overview** の **Credits** カードで **Extra usage** をオンにします。
