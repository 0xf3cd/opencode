[OpenCode Console](https://opencode.ai/console) は、個人でもチームでも OpenCode をより便利に使うためのオプションのサービスです。

- [ワークスペース](/console/workspaces)：[チーム](/console/members)とアクセスを共有
- [推論](/console/models)：プロプライエタリモデルとオープンソースモデルの両方を利用
- [プロバイダー](/console/providers)：Console ゲートウェイを通じて、自分のプロバイダーアカウントを接続
- 使用量のトラッキングと[予算](/console/budgets)の管理
- チーム全体にポリシーを展開して OpenCode の動作を制御
- [Web 検索](/console/websearch)
- [OpenCode Go と Go Plus](/console/go)：オープンソースモデルを利用できる月額 $10 と $40 のサブスクリプション

## 利用開始

Console はチームがなくても利用できます。どのアカウントにも、自分だけがメンバーの **Personal** ワークスペースが最初から用意されています。

1. [Console](https://opencode.ai/console) にサインインします。
2. [Go](/console/go) を購読するか、[クレジット](/console/billing#add-credits)を追加するか、[プロバイダー](/console/providers)を接続します。
3. OpenCode で `/connect` を実行し、ワークスペースを選択します。
4. 必要に応じて、チームを[招待](/console/members#invite-members)します。

```text
/connect
```

## ポリシー

Policies ページの Providers と Tools のルールは、ワークスペースに接続しているすべての OpenCode V2 クライアントに適用されます。これらのルールは[ポリシー](/policies#console)ステートメントとして配信され、メンバー自身の設定よりも常に優先されます。反映までの時間は 1 分ほどです。
