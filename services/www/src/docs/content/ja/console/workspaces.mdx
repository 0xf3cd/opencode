ワークスペースには、[Console](https://opencode.ai/console) のメンバー、クレジット、予算、プロバイダー、ポリシー、サービスアカウントといったすべてが含まれます。使用量と請求はワークスペースごとに管理されます。

ワークスペースのメンバーは 1 人だけでもかまいません。クレジット、[自分のプロバイダー](/console/providers)、予算、[Go](/console/go) を個人で利用し、必要になったときだけ[メンバーを招待](/console/members)できます。

## 最初のワークスペース

サインアップすると、Console は **Personal** という名前のワークスペースを作成します。オーナーであり唯一のメンバーは自分自身です。招待からサインアップした場合は、招待元のワークスペースに参加し、Personal ワークスペースは作成されません。

## ワークスペースの作成

1. 上部バーのワークスペースメニューを開きます。
2. **Create Workspace** をクリックします。
3. **Workspace name** を入力し、**Create** をクリックします。

作成した新しいワークスペースのオーナーになります。

## ワークスペースの切り替え

ワークスペースメニューから別のワークスペースを選択します。Console は同じページを表示したまま切り替えるため、`/acme/members` から切り替えると、切り替え先のワークスペースの Members ページが開きます。

保留中の招待は、同じメニューの上部に表示されます。[メンバー](/console/members#accept-an-invitation)を参照してください。

## ワークスペース名の変更

オーナーと管理者は、**Settings › General** でワークスペース名を変更できます。**Workspace name** を編集すると、フィールドから離れたときに変更が保存されます。名前は表示にのみ使われます。

## OpenCode の接続

OpenCode で `/connect` を実行し、ブラウザーでワークスペースを選択します。以降、OpenCode はそのワークスペースのモデル、ポリシー、予算を使用します。

```text
/connect
```

OpenCode の接続先を別のワークスペースに切り替えるには、もう一度 `/connect` を実行します。ワークスペースの[ポリシー](/policies#console)は新しいワークスペースのものに置き換えられ、接続を解除するとクリアされます。

## ロール

各メンバーには 1 つのロールがあります。新しいメンバーは常に **Member** として参加します。

| ロール | できること |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | OpenCode の利用、自分の使用量、ログ、予算の確認。 |
| Admin  | Member ができるすべての操作に加え、メンバー、請求、予算、プロバイダー、ポリシー、サービスアカウント、設定の管理。 |
| Owner  | Admin ができるすべての操作に加え、Owner ロールの付与とワークスペースの削除。 |

Member に表示されるのは、**Overview**、**Logs**、**Settings › Account** と、メンバーへの表示が許可されている場合の **Leaderboard** だけです。

### ロールのルール

- ワークスペースには複数のオーナーを置くことができ、常に 1 人以上のオーナーが必要です。
- 自分より上位のロールは割り当てられないため、オーナーを任命できるのはオーナーだけです。
- 自分自身のロールは変更できません。

### オーナー権限の移譲

1. オーナーとして **Members** を開き、新しいオーナーのロールを **Owner** に設定します。
2. 新しいオーナーに、自分のロールを **Admin** または **Member** に変更してもらいます。

## ワークスペースの削除

ワークスペースを削除できるのはオーナーだけで、ほかに 1 つ以上のワークスペースに所属している場合に限られます。

1. **Settings › General** を開き、**Delete workspace** をクリックします。
2. すべての確認事項にチェックを入れます。
3. **Delete workspace** をクリックして確定します。

削除はすぐに実行され、元に戻せません。

- メンバーはただちにアクセスできなくなります。
- サービスアカウントのすべての API キーと保留中の招待が取り消されます。
- 自動チャージが停止します。
- 有効な Go サブスクリプションは終了します。
- 残っているクレジット残高は失われます。

<Callout type="warning">支払いの処理中は削除できません。数分後にもう一度お試しください。</Callout>

## ワークスペースからの退出

メンバーは自分自身を削除できません。オーナーまたは管理者に[削除](/console/members#remove-a-member)を依頼してください。
