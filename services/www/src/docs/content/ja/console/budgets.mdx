---
title: "予算"
description: "ワークスペース、メンバー、サービスアカウントの月間支出に上限を設定します。"
---

予算は、ワークスペースが毎月支出できる金額に上限を設けます。オーナーと管理者は、**Members** ページと **Keys** ページの **Budget limits** パネルで予算を設定します。

## 予算のレベル

| 予算 | 適用対象 | 設定場所 |
| ----------------------- | ------------------------------------------- | -------------------------------------------------- |
| ワークスペース | ワークスペースの全員の支出の合計 | **Members** または **Keys › Monthly workspace budget** |
| ユーザーのデフォルト | 個別の上限がない各メンバー | **Members › Monthly default user budget** |
| ユーザーごとのカスタム | 1 人のメンバー | **Members** テーブルまたはメンバーのページ |
| サービスアカウントのデフォルト | 個別の上限がない各サービスアカウント | **Keys › Monthly default service account budget** |
| サービスアカウントごとのカスタム | 1 つのサービスアカウント | サービスアカウントのページ |

リクエストは、ワークスペースの予算とそのユーザー自身の予算の両方に収まる必要があります。予算をまったく設定しない場合、支出は無制限です。

## ワークスペースの予算

ワークスペースの予算に達すると、全員のリクエストがブロックされます。

1. **Members** または **Keys** を開きます。
2. **Budget limits** で **Monthly workspace budget** をクリックします。
3. **Workspace limit** に米ドルで金額を入力し、**Save** をクリックします。

## メンバーの予算

ユーザーのデフォルト予算は、個別の上限がないすべてのメンバーに適用されます。**Monthly default user budget** で設定します。

特定のメンバーに個別の上限を設定するには、次のいずれかの方法を使います。

- **Members** のそのメンバーの行で **Limit** セルをクリックし、金額を入力します。
- メンバーを開き、**Monthly Budget** の下にある **Set User Budget** をクリックします。

個別の上限は Members テーブルで強調表示されます。個別の上限をクリアするとメンバーはデフォルトに戻り、メンバーのページに **Using Default** と表示されます。

## サービスアカウントの予算

サービスアカウントも同じ仕組みです。**Keys** ページで **Monthly default service account budget** を設定するか、サービスアカウントを開いて **Set Service Account Budget** をクリックします。

## 金額とリセット

- 金額は米ドルで、小数点以下 2 桁まで指定できます。
- 予算は毎月 1 日の 00:00 UTC にリセットされます。
- `$0` の予算は、予算に計上されるすべての支出をブロックします。

## 計上される支出

| 支出 | 予算への計上 |
| ------------------------------------------------------------------- | ---------------------------- |
| Console の有料モデル | あり |
| 料金を設定した[自分のプロバイダー](/console/providers)のモデル | あり（設定した料金で計上） |
| [Web 検索](/console/websearch) | あり |
| 無料モデル | なし |
| プランの範囲内の [Go](/console/go) の使用量 | なし |
| クレジットから支払う Go の追加使用量 | あり |

## 予算に達した場合

予算がリセットされるか管理者が予算を引き上げるまで、新しいリクエストは HTTP `429` で失敗します。レスポンスには、どの予算に達したかは示されません。

```text
Upstream request failed: Account budget exceeded
```

予算はリクエストの開始時にチェックされます。すでに処理中のリクエストは最後まで実行されるため、支出が上限をわずかに超えることがあります。

## 支出の確認

各メンバーは、**Overview** で自分の予算（残額、支出額、リセット日）を確認できます。

メンバーが 2 人以上いるワークスペースのオーナーと管理者には、**Usage** も表示されます。日別、モデル別、ユーザー別のコストの内訳を確認でき、**Export usage** ボタンで過去 7 日、30 日、90 日間の日別合計を CSV としてダウンロードできます。

## 予算の自動化

[予算 API](/console/api/budgets) を使うと、独自のツールから全メンバーの予算を取得したり、個別の上限を設定したりできます。
