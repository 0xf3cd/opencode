---
title: "Web 検索"
description: "Console を通じて OpenCode にホスト型の Web 検索を提供します。"
---

Console は、接続している OpenCode v2 ユーザーにホスト型の Web 検索を提供します。ワークスペースのオーナーまたは管理者がワークスペースで一度有効にするだけで、メンバーに個別の検索プロバイダーのキーを配布する必要はありません。

検索が 1 回成功するごとに **$0.01** かかり、ワークスペースの残高とメンバーの支出上限に計上されます。

## 有効化

1. ワークスペースのオーナーまたは管理者として [Console](https://opencode.ai/console) にサインインします。
2. **Settings** > **General** を開きます。
3. **Hosted web search** をオンにします。

その後、各メンバーが `/connect` で OpenCode をワークスペースに接続します。

```text
/connect
```

OpenCode は、ワークスペースの管理対象の設定から **OpenCode Web Search** を読み込みます。メンバーが `websearch.provider` を設定したり、プロバイダーの API キーを追加したりする必要はありません。

## 検索

プロンプトで OpenCode に最新の情報を尋ねます。検索は Console の対話的なページからではなく、OpenCode から実行されます。

```text
Find the latest Bun release and summarize the changes with source links.
```

ホスト型プロバイダーは公開 Web を検索し、最大 8 件の結果を返します。OpenCode はその結果を使ってプロンプトに回答し、出典を示します。

権限の設定やツールの無効化については、[Web 検索ガイド](/websearch)を参照してください。

## 請求

Console は、検索が有効な結果セットを返した時点で **$0.01** を請求します。失敗した検索やレート制限を受けた検索は請求されません。

Web 検索は、**Usage**、**My Activity**、メンバーのアクティビティ、請求書、CSV エクスポートで、モデルの使用量とは別に表示されます。ワークスペースとメンバーの月間支出上限には、Web 検索の料金も含まれます。

## プライバシー

ホスト型の Web 検索はデータを一切保持しません（ゼロデータリテンション）。Console とそのホスト型検索プロバイダーは、各クエリと結果を処理しますが、その内容は保存しません。
