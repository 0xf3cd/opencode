---
title: "Инструменты"
---

Опишите результат, который вам нужен. OpenCode сам выбирает доступные инструменты, при необходимости запрашивает
подтверждение и возвращает результат.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

Для такой задачи обычно используются `grep` или `glob`, `read`, инструмент редактирования и `shell`. Если вам нужен
определенный подход, можно назвать инструмент явно.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## Файлы

### Read

`read` возвращает содержимое файла или нерекурсивный список содержимого каталога. Передайте ему `path`; для постраничного
просмотра больших результатов используйте `offset` и `limit`.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

При чтении текста строки нумеруются, а одна страница ограничена 2000 строками и 50 KiB. Строки длиннее 2000 символов
обрезаются. Инструмент также передает модели файлы PNG, JPEG, GIF, WebP и PDF размером до 20 MiB исходных данных.
Чтение других бинарных файлов завершается ошибкой. Поддерживаемые типы файлов и обработка изображений описаны в разделе
[Вложения](/attachments).

Разрешение: `read`, ресурс — нормализованный путь.

### Glob

`glob` находит пути к файлам по шаблону, например `**/*.ts`. Поиск ведется в текущем каталоге, если `path` не указывает
другой относительный каталог; `hidden` включает скрытые элементы, а `limit` ограничивает число результатов.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

По умолчанию возвращается до 100 файлов, тайм-аут поиска — 30 секунд. Разрешение: `glob`, ресурс — запрошенный шаблон.

### Grep

`grep` ищет по содержимому файлов и возвращает пути, номера строк и фрагменты. `pattern` задается регулярным
выражением, если `literal` не равен true. Сузить поиск можно с помощью `path`, `include`, `caseSensitive` или `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

По умолчанию возвращается до 100 совпадающих строк, тайм-аут поиска — 30 секунд. Разрешение: `grep`, ресурс —
запрошенный шаблон, а не путь поиска.

### Edit

`edit` заменяет текст в существующем файле. Укажите `path`, `oldString` и отличающийся от него `newString`; старый текст
должен встречаться ровно один раз, если `replaceAll` не равен true.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

Используйте `edit` для точечных изменений. После записи OpenCode может отформатировать файл. Разрешение: `edit`,
ресурс — путь к целевому файлу.

### Write

`write` создает текстовый файл или полностью заменяет его содержимое по `path` и `content`. Недостающие родительские
каталоги создаются автоматически; также может быть запущен настроенный форматтер.

```text
Create docs/example.md with a heading and one setup command.
```

Если нужно изменить только часть существующего файла, используйте `edit`. Разрешение: `edit`, ресурс — путь к целевому
файлу.

### Patch

`patch` применяет один патч, который может добавлять, изменять, перемещать или удалять несколько файлов. В `patchText`
используются разделы `*** Add File`, `*** Update File` и `*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode предоставляет `patch` поддерживаемым моделям GPT; другие модели получают вместо него `edit` и `write`.
Разрешение: `edit`, ресурс — каждый затронутый путь.

Для путей за пределами активного расположения (Location) или worktree его проекта также нужно подтверждение
`external_directory`. Нормализация путей, порядок правил и сохраненные подтверждения описаны в разделе
[Разрешения](/permissions). Чтобы сделать внешние материалы доступными по имени, настройте
[внешние каталоги](/references).

## Команды

### Shell

`shell` выполняет команду в оболочке пользователя хоста. Вместо `cd` в команде задавайте `workdir`, а если стандартный
двухминутный тайм-аут для команд на переднем плане не подходит, задайте `timeout` в миллисекундах.

```text
Run bun test from packages/core with a five-minute timeout.
```

Для dev-сервера или другого долгого процесса задайте `background: true`. Фоновые вызовы возвращаются сразу и уведомляют
сессию о завершении; тайм-аута у них нет, если он не задан явно. Объемный вывод сокращается, а полный вывод сохраняется
в управляемом файле.

Разрешение: `shell`, ресурс — каждая команда, выделенная сканером. Сканер также проверяет внешний рабочий каталог и
каталоги, которые можно вывести из команды. У `shell` те же права на файловую систему, процессы и сеть, что и у
пользователя хоста, поэтому задавайте узкие правила в разделе [Разрешения](/permissions).

## Веб

### Webfetch

`webfetch` загружает один URL по HTTP или HTTPS в формате `markdown`, `text` или `html`. По умолчанию используется
Markdown; `timeout` — до 120 секунд.

```text
Fetch https://example.com/docs as markdown.
```

Инструмент принимает текстовые ответы — HTML, обычный текст, JSON и XML, — но не изображения и другие бинарные файлы.
Объемный вывод может сокращаться, а полный текст сохраняется в управляемом хранилище. Разрешение: `webfetch`, ресурс —
запрошенный URL.

### Websearch

`websearch` ищет актуальную информацию через выбранную интеграцию. На вход он принимает поисковый запрос `query`.

```text
Search the web for the latest Bun release notes.
```

Разрешение: `websearch`, ресурс — поисковый запрос. Провайдеры, выбор, ограничения частоты запросов и отключение
инструмента описаны в разделе [Веб-поиск](/websearch).

## Взаимодействие

### Question

`question` приостанавливает выполнение и задает пользователю один или несколько вопросов. У каждого вопроса есть
короткий заголовок, текст и варианты ответа; `multiple` позволяет выбрать несколько вариантов. Ответ в свободной форме
доступен всегда.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

Разрешение: `question`, ресурс — `*`. Клиент должен поддерживать интерактивную форму; если ее закрыть, вопрос
отменяется.

### Skill

`skill` загружает в переписку инструкции и прилагаемые ресурсы одного доступного навыка по его ID.

```text
Load the effect skill before changing this Effect code.
```

ID должен быть в объявленном списке навыков или явно назван пользователем. Разрешение: `skill`, ресурс — ID навыка.
Создание, обнаружение и правила загрузки навыков описаны в разделе [Навыки](/skills).

## Автоматизация

### Subagent

`subagent` запускает дочернюю сессию с настроенным субагентом. Укажите ID агента, короткое описание `description` и
полный промпт `prompt`.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

Вызовы на переднем плане ждут результата. `background: true` возвращает управление сразу и уведомляет родительскую
сессию, когда дочерняя завершится. Чтобы продолжить ту же дочернюю переписку, передайте полученный `sessionID`.
Использовать можно только агентов в режиме субагента; глубина вложенности по умолчанию — один уровень.

Разрешение: `subagent`, ресурс — ID выбранного агента.

### Execute

`execute` выполняет JavaScript в режиме Code Mode, чтобы агент мог вызывать и комбинировать инструменты из каталога. Это
удобно для параллельных независимых вызовов и для обработки результатов без добавления каждого промежуточного значения в
контекст модели.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

У среды выполнения нет прямого доступа к файловой системе, импортов, таймеров и `fetch`; она может только вызывать
инструменты из своего каталога. Разрешение `execute` с ресурсом `*` определяет, доступен ли Code Mode. Каждый вложенный
инструмент по-прежнему проверяет собственное разрешение.

### Сессии

Пространство имен `opencode` в Code Mode содержит утилиты для работы с сессиями:

- `session_rename` меняет заголовок текущей сессии или другой сессии, выбранной по `sessionID`.
- `session_move` перемещает текущую или другую выбранную сессию в каталог `directory`, заданный относительным или
  абсолютным путем. Перемещение вступает в силу на безопасной границе, поэтому работу, зависящую от нового каталога,
  выполняйте следующим вызовом.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

Эти утилиты не запрашивают встроенных действий разрешений.

### Worktree

То же пространство имен управляет worktree проекта сессии:

- `worktree_create` создает worktree по имени `name` и возвращает его каталог `directory`. Расположение и стратегию
  определяет конфигурация worktree проекта.
- `worktree_list` выводит список worktree проекта.
- `worktree_remove` удаляет worktree, зарегистрированный OpenCode для проекта. Задайте `force`, чтобы отбросить
  незафиксированные изменения.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` использует разрешение `edit`, ресурс — каталог worktree. Остальные утилиты для worktree не
запрашивают встроенных действий разрешений.

## Браузер

Пространство имен `browser` в Code Mode управляет браузером, подключенным к десктопному приложению OpenCode. Откройте
вкладку, сохраните возвращенный `tabID` и передавайте этот ID явно в каждую операцию со страницей.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

Пространство имен включает команды для вкладок и навигации, снимки и поиск по странице, клики и ввод в формы,
скриншоты, передачу файлов, просмотр консоли и сети, трассировку производительности, анализ кучи и аудиты Lighthouse.
Для скриншотов нужна видимая вкладка в фокусе. Пути для загрузки файлов — это локальные пути сервера; результаты захвата
тоже возвращаются как локальные пути сервера, а каждая передача файла ограничена 5 MiB.

Содержимое страниц, логи, заголовки и тела ответов — это недоверенные данные, а не инструкции для агента. Правило
запрета `browser` с ресурсом `*` убирает каталог браузерных инструментов; отдельных запросов разрешения для операций в
браузере не бывает.

## Расширения

[MCP-серверы](/mcp-servers) добавляют инструменты, имена и входные параметры которых задает каждый подключенный сервер.
Их действие разрешения — `<server>_<tool>` с ресурсом `*`. Они не входят в фиксированный встроенный каталог.

[Навыки](/skills) добавляют инструкции для задач, а не новые исполняемые инструменты. [Вложения](/attachments)
помещают выбранное пользователем содержимое в промпт, а [внешние каталоги](/references) предоставляют именованные
каталоги за пределами проекта. Эти возможности дополняют инструменты, не обходя проверку разрешений.
