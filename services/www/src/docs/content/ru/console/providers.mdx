Подключите аккаунты у провайдеров, за которые вы уже платите, например Anthropic, OpenAI или AWS Bedrock, и откройте
их модели всем участникам рабочего пространства. Console хранит учетные данные и обслуживает каждого провайдера через
свой шлюз, поэтому участники пользуются моделями, никогда не видя ключа провайдера. Тот же шлюз доступен вашим
собственным инструментам через [Providers API](/console/api/providers).

Владельцы и администраторы управляют провайдерами на вкладке **Providers**. Участники получают включенные модели в
OpenCode после выполнения `/connect`.

## Подключение провайдера

1. Откройте **Providers** и нажмите **Connect Provider**.
2. Выберите провайдера в каталоге и введите его API-ключ.
3. При желании нажмите **Test connection**, затем нажмите **Save**.

В каталоге есть Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter и многие другие. Модели провайдеров
из каталога уже преднастроены.

### Облачные провайдеры

Облачным провайдерам нужно несколько дополнительных параметров.

| Провайдер             | Параметры                                  |
| --------------------- | ------------------------------------------ |
| Azure                 | Имя ресурса и API-ключ                     |
| AWS Bedrock           | Регион и API-ключ                          |
| Google Vertex AI      | Регион и JSON сервисного аккаунта          |
| Cloudflare AI Gateway | Account ID, Gateway ID и API-токен         |
| Databricks            | URL рабочего пространства и токен          |

### Собственные провайдеры

Чтобы подключить любой другой эндпоинт, нажмите **Add Custom Provider**, затем добавьте его модели с помощью
**Add Model**.

| Поле       | Описание                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------- |
| Base URL   | Куда Console перенаправляет запросы, например `https://api.deepseek.com/v1`.                |
| Format     | Chat Completions, Responses API, Anthropic Compatible или Google Generative AI.             |
| Auth mode  | Bearer, заголовок с API-ключом (API key header) или произвольный заголовок (Custom header). |
| Credential | Ключ, который Console отправляет провайдеру.                                                |

## Выбор моделей

Откройте провайдера, чтобы увидеть его модели. Участникам доступны только включенные модели.

- Переключатель **Enabled** включает или выключает модель.
- Включите **New models**, чтобы автоматически включать модели, которые провайдер добавит в будущем.

## Редактирование моделей

Нажмите на модель, чтобы отредактировать ее. Изменения сохраняются при закрытии панели.

| Раздел        | Что можно изменить                                                              |
| ------------- | ------------------------------------------------------------------------------- |
| General       | Отображаемое имя, API ID, поддержку инструментов, типы входных и выходных данных |
| Variants      | Варианты с собственными заголовками или телом запроса                           |
| Configuration | Вариант по умолчанию, заголовки и тело запроса, лимиты токенов                  |
| Cost Tiers    | Цены за 1M токенов на вход, выход, чтение и запись кеша                         |

### Собственные цены

Для моделей из каталога изначально заданы прайс-листовые цены провайдера. Если у вас договорные цены, например скидка
по контракту с OpenAI, переопределите цены в разделе **Cost Tiers**, чтобы отчеты об использовании и
[бюджеты](/console/budgets) соответствовали тому, что вы платите на самом деле.

| Поле             | Цена по прайс-листу | Ваша цена |
| ---------------- | ------------------- | --------- |
| Input price      | $2.50               | $2.00     |
| Output price     | $15.00              | $12.00    |
| Cache read price | $0.25               | $0.20     |

Измененные цены выделяются на странице провайдера. Чтобы вернуться к цене по прайс-листу, используйте
**Restore default value** у поля или **⋯ › Restore...** у модели.

Добавьте уровень **Context**, если модель берет больше за превышение определенного размера контекста, например за
промпты длиннее 200K токенов.

### Собственные модели

Чтобы добавить модель, которой нет в каталоге, нажмите **Add Model** и укажите **Display name** и **Model ID**. Чтобы
взять за основу настройки существующей модели, используйте **⋯ › Duplicate...**.

## Модели OpenCode

На вкладке **Models** настраиваются [модели](/console/models), которые предоставляет Console и которые оплачиваются из
кредитов рабочего пространства. Она работает так же, как страница провайдера:

- Включайте и выключайте отдельные модели.
- Выключите **Free models**, чтобы запретить бесплатные модели в рабочем пространстве.
- Включите **New models**, чтобы новые модели Console включались автоматически.

Чтобы использовать только собственных провайдеров, отключите этого провайдера целиком через **⋯ › Disable**.

## Использование в OpenCode

Участники выполняют `/connect` и выбирают рабочее пространство. Каждый включенный провайдер отображается как название
рабочего пространства и имя провайдера, а `/models` показывает его включенные модели.

```text
Acme Inc. / Anthropic
```

Включите **Managed providers only** в **Settings › General**, чтобы ограничить OpenCode провайдерами рабочего
пространства для всех участников.

## Отключение и удаление

Откройте меню **⋯** провайдера:

- **Disable** скрывает провайдера и его модели от участников, но сохраняет настройки.
- **Remove...** удаляет провайдера и его модели. В диалоге показано, кто недавно им пользовался, и есть вариант
  **Disable instead** («Отключить вместо удаления»).

Чтобы сменить ключ, нажмите на учетные данные на странице провайдера и введите новый ключ.

## Оплата

Токены оплачиваются у провайдера; Console не списывает за них кредиты. При этом Console все равно записывает каждый
запрос и его стоимость по ценам модели, поэтому он учитывается в отчетах об использовании и
[бюджетах](/console/budgets).

Чтобы обращаться к провайдеру из собственных инструментов, а не из OpenCode, используйте
[Providers API](/console/api/providers).
