Console бесплатен для команд любого размера, без платы за места. Вы платите только за использование — из предоплаченных
кредитов, общих для всего рабочего пространства. Владельцы и администраторы управляют оплатой в разделе
**Settings › Billing**.

Использование [собственных провайдеров](/console/providers) оплачивается у провайдера, а не через Console.

## Добавление способа оплаты

1. Откройте **Settings › Billing**.
2. В разделе **Payment methods** нажмите **Add**.
3. Выберите способ и завершите настройку в Stripe.

Поддерживаемые способы оплаты:

- Card
- Link
- Alipay
- UPI
- WeChat Pay

Чтобы выбрать способ для автоматических списаний, используйте **⋯ › Make default**. Удаление способа оплаты может
остановить автопополнение и продление Go, которые его используют.

## Пополнение кредитов

1. В разделе **Credits** нажмите **Add credits**.
2. Выберите $10, $50 или $100 либо нажмите **Other** и введите сумму.
3. Выберите способ оплаты и нажмите **Confirm and pay**.

Сверху добавляется комиссия за обработку платежа 4.6% + $0.31: покупка на $50 стоит $52.61, а на баланс зачисляются
все $50.

## Автопополнение

Автопополнение покупает кредиты, когда баланс становится низким.

1. В разделе **Auto-recharge** нажмите **Add rule**.
2. Укажите баланс, при котором происходит списание, и сумму пополнения.
3. Нажмите **Save**.

Автопополнение списывает средства со способа оплаты по умолчанию, включая комиссию за обработку. Если списание не
удалось, автопополнение отключается, пока вы не настроите его заново.

## Проверка баланса

Карточка **Credits** на странице **Overview** показывает баланс владельцам и администраторам.

## Когда кредиты заканчиваются

Когда баланс достигает нуля, платные запросы завершаются ошибкой HTTP `402`. Баланс никогда не уходит в минус.

```text
Upstream request failed: Insufficient account funds
```

## Счета

Каждый платеж отображается в разделе **Invoices** со статусом и ссылкой **Download invoice** или **View receipt**.

| Запись           | Когда создается         |
| ---------------- | ----------------------- |
| Balance top-up   | Пополнение кредитов     |
| Automatic top-up | Автопополнение          |
| Go subscription  | Оформление подписки Go  |
| Go renewal       | Ежемесячное продление Go |
| Monthly Usage    | Оплата по счетам        |

## Оплата по счетам

Рабочим пространствам с кредитным соглашением можно выставлять счета ежемесячно вместо покупки кредитов. Чтобы
подключить эту возможность, обратитесь в поддержку.

- Использование списывается из кредитного лимита, а не с предоплаченного баланса.
- Счет за каждый месяц выставляется 1-го числа (UTC) и подлежит оплате в течение 14 дней.
- У неоплаченных счетов есть кнопка **Pay now**.
- Запросы завершаются ошибкой HTTP `402`, когда кредитный лимит исчерпан или счет просрочен.

## Go

Подписки [OpenCode Go](/console/go) используют те же способы оплаты и отображаются в том же списке счетов. Включите
**Extra usage** в карточке кредитов на странице **Overview**, чтобы после достижения лимита Go оплачивать использование
из кредитов.
