OpenCode Go дает надежный доступ к популярным открытым моделям для программирования. Доступны два месячных плана:

| План        | Цена          | Включенное использование                    |
| ----------- | ------------- | ------------------------------------------- |
| **Go**      | **$10 в месяц** | Доступ к моделям ниже по более низкой цене |
| **Go Plus** | **$40 в месяц** | Более высокие лимиты использования для моделей ниже |

В OpenCode Go работает как любой другой провайдер: вы оформляете подписку на OpenCode Go и получаете API-ключ. Подписка **совершенно необязательна** — OpenCode можно использовать и без нее.

Сервис ориентирован прежде всего на международных пользователей и обеспечивает стабильный доступ по всему миру.

## Как это работает

1. Войдите в [OpenCode Console](https://opencode.ai/console), оформите подписку Go или Go Plus, добавьте платежные данные и скопируйте API-ключ.
2. Выполните `/connect` в TUI, выберите **OpenCode Go** и вставьте API-ключ.

   ```text
   /connect
   ```

3. Выполните `/models`, чтобы выбрать модель, доступную в Go.

   ```text
   /models
   ```

<Callout>
  Go и Go Plus предназначены для рабочих пространств с одним участником, например для рабочего пространства
  **Personal**, которое создается при регистрации. В рабочее пространство с подпиской Go нельзя приглашать участников.
</Callout>

## Где можно использовать Go?

OpenCode Go предназначен для [OpenCode](https://opencode.ai) и других агентов для программирования, которые отправляют
похожие запросы. Трафик отслеживается на предмет злоупотреблений, ухудшающих работу других пользователей.

Ваш клиент должен:

1. Отправлять трафик, типичный для агента для программирования.
2. Представляться собственным user agent, например `my-coding-agent/1.0`, а не общим именем SDK или
   HTTP-библиотеки.
3. Передавать стабильный ID сессии в `x-opencode-session` для каждого диалога, чтобы мы могли оптимизировать
   маршрутизацию и кеширование промптов.

### Проверенные клиенты

Помимо OpenCode, корректная работа с OpenCode Go проверена для следующих клиентов. Однако мы не гарантируем, что они
продолжат работать в будущем.

| Клиент            | Поддержка сессий                                                                                                                                                                                                                            |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hermes**        | Сборки, включающие [PR #101864](https://github.com/NousResearch/hermes-agent/pull/101864), отправляют заголовок в основных и вспомогательных запросах к OpenCode. Исправление влито после v0.21.0; сам этот релиз его не содержит.                 |
| **Claude Code**   | Go распознает собственный заголовок сессии этого клиента. Обертка с пользовательским заголовком не нужна.                                                                                                                                                                |
| **Codex**         | Go распознает собственный заголовок сессии этого клиента. Некоторые версии и конфигурации прокси все еще его не передают; сохраняйте заголовок сессии при перенаправлении запросов.                                                                                                |
| **ZCode**         | Go распознает собственный заголовок сессии этого клиента. Наш [запрос на поддержку `x-opencode-session`](https://github.com/zai-org/feedback/issues/492) остается открытым, но отправлять именно этот заголовок больше не нужно.                                   |
| **Pi**            | Текущие сборки передают OpenCode информацию о сессии. Обновите старые установки.                                                                                                                                                           |
| **jcode**         | Обновитесь до **v0.81.6 или новее** — в этой версии есть [исправление заголовка сессии](https://github.com/1jehuang/jcode/issues/1167).                                                                                                                     |
| **Kilo Code CLI** | Сборки, включающие [PR #13752](https://github.com/Kilo-Org/kilocode/pull/13752), восстанавливают заголовки сессии OpenCode. Исправление касается CLI, но не расширения для VS Code. См. [issue #13723](https://github.com/Kilo-Org/kilocode/issues/13723). |

| **GitHub Copilot Chat** | Автоматическая поддержка заголовка сессии запрошена в [VS Code issue #334186](https://github.com/microsoft/vscode/issues/334186).                                                                                                                           |

### Использование сверх лимитов

Если на балансе Console есть кредиты, можно включить в Console параметр **Use balance**. Тогда после достижения
лимитов Go не будет блокировать запросы, а начнет списывать средства с [баланса с оплатой по мере использования](/console/models#pricing).

### Почему у некоторых моделей меньше лимит

Включенный в Go месячный объем использования зависит от модели.

Для большинства моделей это возможно благодаря оптовым скидкам и зарезервированным мощностям GPU. Эту экономию мы
передаем вам в виде более высокого месячного лимита.

Для некоторых моделей у нас пока не было возможности договориться о скидке или разместить их дешевле — либо потому, что
модель новая, либо потому, что ее публичная цена уже снижена.

По этим моделям вы все равно получаете немного больше, чем при прямой оплате провайдерам, поэтому их месячный лимит
ниже.

## Предыстория

Открытые модели стали действительно хорошими: в задачах программирования они почти не уступают проприетарным. А
поскольку их могут обслуживать многие провайдеры, конкурируя между собой, обычно они намного дешевле.

Однако получить к ним надежный доступ с низкой задержкой бывает непросто: провайдеры различаются по качеству и
доступности.

<Callout type="tip">Мы протестировали отобранную группу моделей и провайдеров, которые хорошо работают с OpenCode.</Callout>

Чтобы решить эту проблему, мы:

1. Протестировали отобранную группу открытых моделей и обсудили с их командами, как лучше их запускать.
2. Вместе с несколькими провайдерами убедились, что модели обслуживаются правильно.
3. Провели бенчмарки пар «модель — провайдер» и составили список, который можем уверенно рекомендовать.

Go и Go Plus дают доступ к этим моделям; выберите план в зависимости от того, насколько активно вы ими пользуетесь.

## Цели

Мы создали OpenCode Go, чтобы:

1. Сделать программирование с AI **доступным** для большего числа людей благодаря недорогой подписке.
2. Обеспечить **надежный** доступ к лучшим открытым моделям для программирования.
3. Отбирать модели, **протестированные и проверенные бенчмарками** для работы в агентах для программирования.
4. **Не привязывать** вас: с OpenCode можно использовать и любого другого провайдера.
