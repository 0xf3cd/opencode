Получайте действующие месячные бюджеты всех участников рабочего пространства и управляйте собственным бюджетом каждого
участника из интеграции.

## Быстрый старт

Создайте в [Console](https://opencode.ai/console) API-ключ [сервисного аккаунта](/console/api#service-accounts) с
разрешением **All**. Ключи с разрешением только на инференс не имеют доступа к данным бюджетов и не могут менять
лимиты.

```bash
export CONSOLE_URL="https://opencode.ai/console"
export SERVICE_API_KEY="oc_sk_..."
```

Получите список бюджетов участников:

```bash
curl --fail-with-body \
  "${CONSOLE_URL}/api/v1/budgets/members" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Accept: application/json"
```

## Список бюджетов участников

```text
GET /api/v1/budgets/members
```

Ответ содержит всех текущих участников, упорядоченных по адресу электронной почты. Лимит с источником `custom` — это
переопределение для участника; источник `default` означает, что лимит унаследован от значения по умолчанию рабочего
пространства. Если лимит и источник равны null, расходы участника не ограничены.

```json
[
  {
    "user_id": "user_...",
    "email": "alice@example.com",
    "limit_micro_cents": "7525000000",
    "spent_micro_cents": "1250000000",
    "exceeded": false,
    "resets_at": "2026-10-01T00:00:00.000Z",
    "source": "custom",
    "updated_at": "2026-09-03T12:00:00.000Z"
  }
]
```

Денежные поля ответа — это десятичные строки в микроцентах, чтобы интеграции не теряли точность. В одном долларе США
100,000,000 микроцентов. Расходы и время сброса относятся к текущему календарному месяцу по UTC. Если собственного
переопределения для участника нет, `updated_at` равно null.

## Задание собственного бюджета

```text
PUT /api/v1/budgets/members/:user_id
```

Задайте одному участнику месячный бюджет $75.25:

```bash
curl --fail-with-body --request PUT \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"budget_dollars":75.25}'
```

`budget_dollars` принимает неотрицательную сумму в долларах США, не более двух знаков после запятой. Запрос PUT
идемпотентен и возвращает HTTP 204. Используйте ID участника из ответа на запрос списка.

## Возврат к значению по умолчанию

```text
DELETE /api/v1/budgets/members/:user_id
```

Удалите собственное переопределение:

```bash
curl --fail-with-body --request DELETE \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

Удаление переопределения не удаляет участника. После этого участник наследует бюджет по умолчанию рабочего
пространства, а если его нет — расходы участника не ограничены. Повторный запрос безопасен и возвращает HTTP 204.

## Ошибки

| Статус | Значение                                                          |
| ------ | ----------------------------------------------------------------- |
| `400`  | Недопустимый ID участника или сумма бюджета.                      |
| `401`  | API-ключ сервисного аккаунта отсутствует, недействителен, просрочен или отозван. |
| `403`  | У API-ключа нет разрешения на управление бюджетами.               |
| `404`  | Участника нет в рабочем пространстве, к которому привязан API-ключ. |
