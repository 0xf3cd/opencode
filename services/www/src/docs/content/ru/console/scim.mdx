Синхронизация каталога пользователей (SCIM 2.0) добавляет пользователей в рабочее пространство, когда вы назначаете их
в провайдере удостоверений, и отзывает доступ, когда назначение снимается. Роли по-прежнему управляются в Console.

```text
https://opencode.ai/console/scim/v2
```

## Подготовка

- Настройте [SSO](/console/sso) для рабочего пространства.
- [Подтвердите](/console/sso#verify-email-domains) все почтовые домены, с которых входят ваши пользователи.
  Синхронизация каталога добавляет только пользователей с подтвержденных доменов; всех остальных приглашайте на
  странице [Участники](/console/members).

## Создание токена

1. Откройте **Settings › Security** и нажмите **Set up** в разделе **Directory sync**.
2. Скопируйте **SCIM base URL** и токен. Токен показывается только один раз, поэтому сохраните его в менеджере
   секретов.

Провайдер удостоверений передает токен в каждом запросе.

```text
Authorization: Bearer <token>
```

## Подключение провайдера удостоверений

### Okta

1. Добавьте приложение **SCIM 2.0 Test App (Header Auth)**.
2. Укажите базовый URL, а в поле **API Token** введите `Bearer ` и затем токен.
3. Включите **Create Users**, **Update User Attributes** и **Deactivate Users**. **Import Groups** и синхронизацию
   паролей оставьте выключенными.

### Microsoft Entra ID

1. В корпоративном приложении откройте **Provisioning** и выберите режим **Automatic**.
2. Введите базовый URL в поле **Tenant URL**, а токен — в поле **Secret Token**.
3. Назначьте пользователей и группы, затем запустите провизионинг.

### Другие провайдеры

Используйте приложение SCIM 2.0 с аутентификацией по токену в заголовке, указав базовый URL. Console поддерживает
эндпоинты `/Users` и `/Groups`.

Сначала назначьте одного тестового пользователя. После первого запроса в разделе **Directory sync** появится
**Connected to your identity provider**.

## Что синхронизируется

| В провайдере удостоверений     | В Console                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| Назначение пользователя        | Добавляется с ролью **Member**. Существующие участники сохраняют свою роль.                 |
| Изменение имени                | Профиль обновляется.                                                                        |
| Снятие назначения или деактивация | Доступ приостанавливается, отображается статус **Deactivated**. Созданные пользователем API-ключи отзываются. |
| Повторное назначение           | Доступ восстанавливается. Отозванные ключи остаются отозванными.                            |
| Удаление                       | Удаляется из рабочего пространства. Аккаунт и другие рабочие пространства не затрагиваются. |

- Синхронизация каталога не меняет роли и адреса электронной почты.
- Последнего владельца нельзя деактивировать или удалить.
- Рабочие пространства с подпиской [Go](/console/go) не могут добавлять участников через синхронизацию каталога.

## Группы

Передавайте группы, чтобы помечать их участников тегами, например с помощью **Push Groups** в Okta или назначения групп
в Entra. Назначьте пользователей до передачи их групп.

```text
Platform Admins  →  platform-admins
```

Каждая группа помечает своих участников тегом с именем группы. В разделе **Settings › Security › Group tags** можно
переименовать тег, связать несколько групп с одним тегом или перестать помечать участников группы. При выходе из
группы ее тег снимается.

## Ротация токена

1. Нажмите **New token** и установите новый токен в провайдере удостоверений.
2. Дождитесь, пока у нового токена появится время последнего использования.
3. Отзовите старый токен.

Отзыв токена останавливает дальнейшие обновления, но не меняет текущих участников. При удалении SSO-подключения
отзываются все токены.

## SSO и синхронизация каталога

После того как в рабочем пространстве выпущен токен, SSO больше не
[добавляет участников автоматически](/console/sso#automatic-membership). Состав участников определяет каталог, даже
если токен позже отозван.
