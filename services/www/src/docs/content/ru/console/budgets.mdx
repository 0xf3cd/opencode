---
title: "Бюджеты"
description: "Ограничение месячных расходов рабочего пространства, его участников и сервисных аккаунтов."
---

Бюджеты ограничивают, сколько рабочее пространство тратит за месяц. Владельцы и администраторы задают их на панели
**Budget limits** на страницах **Members** и **Keys**.

## Уровни бюджетов

| Бюджет                                       | Применяется к                                   | Где задается                                       |
| -------------------------------------------- | ----------------------------------------------- | -------------------------------------------------- |
| Рабочего пространства                        | Общим расходам всех участников                  | **Members** или **Keys › Monthly workspace budget** |
| Пользовательский по умолчанию                | Каждому участнику без собственного лимита       | **Members › Monthly default user budget**          |
| Собственный для пользователя                 | Одному участнику                                | Таблица **Members** или страница участника         |
| Для сервисных аккаунтов по умолчанию         | Каждому сервисному аккаунту без собственного лимита | **Keys › Monthly default service account budget**  |
| Собственный для сервисного аккаунта          | Одному сервисному аккаунту                      | Страница сервисного аккаунта                       |

Запрос должен укладываться и в бюджет рабочего пространства, и в личный бюджет пользователя. Если бюджеты не заданы,
расходы не ограничены.

## Бюджет рабочего пространства

Когда рабочее пространство исчерпывает свой бюджет, запросы блокируются для всех.

1. Откройте **Members** или **Keys**.
2. На панели **Budget limits** нажмите **Monthly workspace budget**.
3. Введите **Workspace limit** в долларах США и нажмите **Save**.

## Бюджеты участников

Пользовательский бюджет по умолчанию применяется ко всем участникам без собственного лимита. Он задается в
**Monthly default user budget**.

Собственный лимит для участника можно задать двумя способами:

- Нажмите ячейку **Limit** в его строке на странице **Members** и введите сумму.
- Откройте страницу участника и нажмите **Set User Budget** в разделе **Monthly Budget**.

Собственные лимиты выделены в таблице Members. Если удалить собственный лимит, участнику снова назначается бюджет по
умолчанию, а на его странице отображается **Using Default**.

## Бюджеты сервисных аккаунтов

Для сервисных аккаунтов все работает так же. Задайте **Monthly default service account budget** на странице **Keys**
или откройте сервисный аккаунт и нажмите **Set Service Account Budget**.

## Суммы и сброс

- Суммы указываются в долларах США, не более двух знаков после запятой.
- Бюджеты сбрасываются 1-го числа каждого месяца в 00:00 UTC.
- Бюджет `$0` блокирует все расходы, которые учитываются в бюджетах.

## Что учитывается

| Расходы                                                                   | Учитываются в бюджетах        |
| ------------------------------------------------------------------------- | ----------------------------- |
| Платные модели Console                                                    | Да                            |
| Модели [собственных провайдеров](/console/providers) с заданной ценой     | Да, по заданной цене          |
| [Веб-поиск](/console/websearch)                                           | Да                            |
| Бесплатные модели                                                         | Нет                           |
| Использование [Go](/console/go) в пределах плана                          | Нет                           |
| Дополнительное использование Go, оплаченное из кредитов                   | Да                            |

## Когда бюджет исчерпан

Новые запросы завершаются ошибкой HTTP `429`, пока бюджет не сбросится или администратор его не увеличит. В ответе не
указано, какой именно бюджет исчерпан.

```text
Upstream request failed: Account budget exceeded
```

Бюджеты проверяются в момент начала запроса. Уже выполняющиеся запросы завершаются, поэтому итоговые расходы могут
немного превысить лимит.

## Отслеживание расходов

Каждый участник видит свой бюджет на странице **Overview**: остаток, потраченную сумму и дату сброса.

Владельцы и администраторы рабочих пространств, где больше одного участника, также видят раздел **Usage**. В нем
расходы разбиты по дням, моделям и пользователям, а кнопка **Export usage** выгружает дневные итоги за последние 7, 30
или 90 дней в формате CSV.

## Автоматизация бюджетов

С помощью [Budgets API](/console/api/budgets) можно получать бюджеты всех участников и задавать собственные лимиты из
своих инструментов.
