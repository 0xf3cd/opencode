OpenCode Console предоставляет список моделей, протестированных и проверенных командой OpenCode. Войдите, пополните
кредиты и получите API-ключ, чтобы использовать их в OpenCode или другом агенте для программирования.

В OpenCode Console работает как любой другой провайдер. Он **совершенно необязателен**, и вместо него можно
использовать любого другого провайдера. Если вам нужна подписка с включенным объемом использования, см.
[OpenCode Go](/console/go).

## Как это работает

1. Войдите в [Console](https://opencode.ai/console), добавьте платежные данные и кредиты и скопируйте API-ключ.
2. Выполните `/connect` в TUI, выберите провайдера OpenCode с оплатой по мере использования и вставьте API-ключ.

   ```text
   /connect
   ```

3. Выполните `/models`, чтобы увидеть доступные модели, и выберите одну из них.

   ```text
   /models
   ```

Оплата списывается за каждый запрос, а кредиты можно пополнять в аккаунте.

```jsonc title="opencode.jsonc"
  "model": "opencode/gpt-5.5",
}
```

### Jev

Jev — модель класса System One от TypeSafe AI для быстрых структурированных решений. Вместо генерации текста она оценивает состояние `state` по типизированным вопросам и возвращает значения и вероятности, которые ваш код может использовать напрямую. Поддерживаются вопросы «да/нет» (`noul`), с выбором из нескольких вариантов (`choice`) и с оценкой по шкале критериев (`score`).

Используйте API-ключ OpenCode Console с эндпоинтом `https://opencode.ai/inference/v1/systemone`. В этом примере проверяется, срочный ли запрос в поддержку:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

В одном запросе можно задать несколько вопросов. Jev оценивает их параллельно и возвращает каждый ответ под ID соответствующего вопроса:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Чтобы воспользоваться бесплатной моделью, доступной ограниченное время, укажите `jev-1.13-free` вместо `jev-1.13`. Подробнее о типах вопросов и полях ответа читайте в [документации TypeSafe AI](https://docs.typesafe.ai/).

## Предыстория

Моделей много, но лишь немногие хорошо работают в роли агентов для программирования. Кроме того, провайдеры
различаются по конфигурации, производительности и качеству, поэтому модель, доступная через шлюз вроде OpenRouter,
может работать иначе.

<Callout type="tip">Мы протестировали отобранную группу моделей и провайдеров, которые хорошо работают с OpenCode.</Callout>

Чтобы составить этот каталог, мы:

1. Протестировали отобранную группу моделей и обсудили с их командами, как лучше их запускать.
2. Вместе с провайдерами убедились, что модели обслуживаются правильно.
3. Провели бенчмарки каждой пары «модель — провайдер» и составили список, который можем уверенно рекомендовать.

Console — это AI-шлюз, который дает доступ к этим моделям.

## Цели

Мы создали Console, чтобы:

1. **Тестировать** лучшие модели и провайдеров для агентов для программирования.
2. Предлагать варианты **высочайшего качества** без снижения производительности и без перенаправления к более дешевым
   провайдерам.
3. Передавать вам **снижение цен**, продавая по себестоимости с наценкой только на покрытие комиссий за обработку
   платежей.
4. **Не привязывать** вас: используйте Console с любым агентом для программирования, а с OpenCode — любого другого
   провайдера.
