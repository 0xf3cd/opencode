Чтобы выбрать тему в терминальном интерфейсе, нажмите `Ctrl+P`, выберите **Open settings** и откройте **Theme**. Тему
также можно задать напрямую в глобальной конфигурации CLI:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Темы относятся к терминальному клиенту. Указывайте тему в `cli.json`, а не в `opencode.json`. Расположение файла
конфигурации и другие настройки терминала описаны в разделе [Настройки CLI](/cli/config).

## Режимы

Значение `system` следует оформлению терминала; также можно закрепить за темой один режим:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Значение | Поведение                                        |
| -------- | ------------------------------------------------ |
| `system` | Следует светлому или темному режиму терминала.   |
| `dark`   | Всегда использует темную тему.                   |
| `light`  | Всегда использует светлую тему.                  |

Если собственная тема поддерживает только один режим, OpenCode использует его и тогда, когда запрошен другой.

## Встроенные темы

Встроенная тема выбирается по имени:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Доступные темы:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

Тема `system` доступна, если OpenCode может прочитать палитру вашего терминала.

## Файлы

Чтобы создать глобальную тему `ocean`, сгенерируйте с помощью инструмента тем полный файл в глобальном каталоге тем.
Основная часть его структуры выглядит так:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Затем выберите `ocean` в настройках или задайте `theme.name` значение `ocean` в `cli.json`. Имя файла без `.json` —
это имя темы.

| Область | Каталог                                     |
| ------- | ------------------------------------------- |
| Глобальные | `~/.config/opencode/themes/`             |
| Проект  | `.opencode/themes/` в дереве проекта        |

OpenCode читает только файлы `.json`. Тема, расположенная ближе к текущему каталогу, заменяет глобальную или
родительскую тему с тем же именем.

## Формат

Каждая тема V2 объявляет одно полное дерево токенов `base` и хотя бы одну палитру оттенков `light` или `dark`. Режимы
наследуют только от `base` этого файла: они не наследуют ни от встроенной темы OpenCode, ни друг от друга. Прежде чем
настраивать тему, сгенерируйте полный `base` с помощью инструмента тем.

В примерах ниже показаны только разделы, относящиеся к каждому понятию; это не полные файлы тем.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Цвета

Указывайте цвет в шестнадцатеричном формате, `transparent` или ссылку на другой цвет темы:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Шестнадцатеричные значения могут содержать 3, 4, 6 или 8 цифр. Ссылки начинаются с `$`; ссылки на оттенки имеют вид
`$hue.<name>.<step>`.

## Оттенки

Переопределите псевдоним оттенка, чтобы сразу изменить целое семейство связанных цветов:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Вид       | Значения                                                             |
| --------- | -------------------------------------------------------------------- |
| Базовые   | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Псевдонимы | `accent`, `interactive`, `neutral`                                  |
| Ступени   | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Ступени оттенков следуют направлению контраста режима: в светлых темах они идут от темного на `100` к светлому на
`900`, а в темных — от светлого на `100` к темному на `900`.

`categorical` задает упорядоченный набор оттенков, которыми различаются агенты и другие повторяющиеся элементы. Он
должен содержать хотя бы один базовый оттенок или псевдоним.

## Состояния

Ключи состояний меняют цвета интерактивных элементов. Для незаданных состояний используется ближайшее базовое значение:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Группа    | Значения                                                     |
| --------- | ------------------------------------------------------------ |
| Действия  | `primary`, `secondary`, `destructive`                        |
| Состояния | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Поля форм используют те же ключи состояний непосредственно в `text.formfield` или `background.formfield`.

## Токены

Полный `base` содержит все группы токенов. Режим может переопределить любую его часть, если задает полную палитру
оттенков:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Группа       | Назначение                                                              |
| ------------ | ----------------------------------------------------------------------- |
| `text`       | Основной и приглушенный текст, текст действий, полей форм и обратной связи |
| `background` | Основной фон, поверхности, действия, поля форм и заливки обратной связи |
| `border`     | Границы                                                                 |
| `scrollbar`  | Полосы прокрутки                                                        |
| `diff`       | Цвета добавленных и удаленных строк, контекста, выделения и номеров строк |
| `syntax`     | Подсветка исходного кода                                                |
| `markdown`   | Элементы Markdown                                                       |

Ключи синтаксиса: `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` и
`punctuation`. Ключи Markdown: `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`,
`horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` и `codeBlock`.

## Приподнятые поверхности

Панели, диалоги, меню и всплывающие уведомления выбирают уровень глубины из `background.raised`. Диалоги дополнительно
поддерживают контекстную поверхность `@dialog`. После применения `@dialog` TUI заново разрешает палитру, поэтому
токены, ссылающиеся на `$background.base`, следуют фону диалога:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` принимает те же группы токенов, что и базовый режим. Контекстный `base` действия также становится резервным
значением для его незаданных состояний; явно заданное состояние по-прежнему имеет приоритет.
