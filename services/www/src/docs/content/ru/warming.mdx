---
title: "Прогрев сессий"
---

Прогрев сессии — это периодическая отправка запросов к модели, которая сохраняет кэш промптов на стороне провайдера или
другое кратковременное состояние, пока вы делаете паузу между промптами. По умолчанию прогрев отключен.

Включите прогрев в любом [файле конфигурации OpenCode](/config):

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

С такой конфигурацией OpenCode прогревает недавно активную сессию, если в течение четырех минут не было запросов к
модели. Прогрев повторяется каждые четыре минуты, пока с последнего обычного (не прогревочного) запроса не пройдет 30
минут.

## Параметры

Чтобы изменить промпт прогрева, интервал простоя или окно активности, используйте объектную форму:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `prompt` | Инструкция для поддержания активности | Добавляется как временное сообщение пользователя к каждому запросу прогрева. По умолчанию модель просят ничего не делать, не использовать инструменты и ответить `OK`. |
| `interval` | `"4 minutes"` | Время простоя перед следующим запросом прогрева. |
| `duration` | `"30 minutes"` | Окно прогрева, отсчитываемое от последнего обычного запроса к модели. |

Пропущенные поля объекта сохраняют значения по умолчанию. Например, эта настройка меняет только интервал:

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## Длительность

`interval` и `duration` принимают строки с длительностью. Оба значения должны быть конечными и больше нуля; иначе
OpenCode пропускает прогрев и записывает предупреждение в журнал.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## Расписание

Прогрев начинается после обычного запроса к модели. Когда запрос прогрева завершается, начинается следующий интервал
простоя, но окно активности не продлевается.

```text
00:00  normal model request
00:04  warming request
00:08  warming request
00:30  warming stops
```

Любой новый обычный запрос к модели сбрасывает оба таймера. Если интервал не короче длительности окна, окно истекает
раньше, чем будет отправлен запрос прогрева.

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

## Запросы

Запрос прогрева использует текущую модель, агента, инструкции и контекст переписки сессии. OpenCode временно добавляет
заданный промпт, выполняет один вызов модели и отбрасывает ответ.

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

Запрос не принимает ввод, не добавляет сообщения в историю и не меняет сохраненное состояние сессии. OpenCode не
выполняет локальные вызовы инструментов и не продолжает цикл инструментов; промпт по умолчанию к тому же запрещает
модели использовать инструменты.

## Сбои

Сбои прогрева записываются в журнал, но не приводят к ошибке сессии и не меняют ее. OpenCode ждет следующего интервала,
прежде чем повторить попытку, а исходное окно активности продолжает отсчитываться.

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

## Стоимость

Запросы прогрева — это настоящие запросы к провайдеру. Они могут расходовать токены, стоить денег, учитываться в
ограничениях частоты запросов и завершаться ошибками, как и другие запросы к модели.

- Чем короче интервал, тем больше запросов.
- Чем длиннее окно, тем больше запросов прогрева возможно.
- Включайте прогрев, только если выгода на стороне провайдера оправдывает дополнительный расход.

Например, со значениями по умолчанию за одно непрерывное 30-минутное окно возможно до семи попыток прогрева: на 4, 8,
12, 16, 20, 24 и 28 минутах.

## Отключение

Чтобы явно отключить прогрев, задайте `warming: false`. Если поле не указано, прогрев тоже отключен.

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
