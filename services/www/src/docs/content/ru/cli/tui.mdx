Запустите OpenCode в каталоге проекта, введите запрос и нажмите **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Новая строка — **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** или **Ctrl+J**. Пока OpenCode работает, **Enter** корректирует ход активной сессии; чтобы поставить промпт в очередь, нажмите **Ctrl+X**, затем **Enter**.

## Контекст

Введите `@`, чтобы найти файл, и выберите его — файл будет прикреплен к промпту. Продолжайте вводить текст после `@`, чтобы сузить результаты.

```text
Review @src/auth.ts for error handling problems
```

После пути можно указать строку или диапазон строк.

```text
Explain @src/auth.ts#20-45
```

## Оболочка

Введите `!` в начале пустого промпта, чтобы перейти в режим оболочки. Введите команду и нажмите **Enter**; чтобы выйти из режима оболочки, ничего не выполняя, нажмите **Esc**.

```text
!git status
```

Команды оболочки выполняются в рабочем каталоге сессии, а их вывод остается в сессии.

## Команды

Введите `/`, чтобы увидеть список slash-команд. Продолжайте вводить текст, чтобы отфильтровать список, затем нажмите **Enter**, чтобы выполнить выбранную команду.

```text
/models
```

Часто используются команды `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` и `/editor`. **Ctrl+P** открывает палитру команд со всеми действиями, доступными в текущем представлении.

После обновления OpenCode один раз показывает на главном экране, что нового в релизе. Чтобы посмотреть это снова, выполните `/highlights`; чтобы обзор не открывался автоматически, задайте `"highlights": false` в [`cli.json`](/cli/config#alerts).

## Вопросы по ходу

Команда `/btw <question>` позволяет быстро задать вопрос о текущем разговоре. Ответ использует контекст сессии и текущую модель, но не добавляется в разговор, поэтому не влияет на следующие промпты. Пока вопрос обрабатывается, в нижней части промпта отображается индикатор `/btw`, а ответ открывается в диалоговом окне; нажмите **C**, чтобы скопировать его.

```text
/btw why did the test in step 2 fail?
```

## Модели

Чтобы выбрать модель, нажмите **Ctrl+X**, затем **M**, или выполните `/models`. **F2** переключает недавно использованные модели по кругу.

Чтобы выбрать агента, нажмите **Ctrl+X**, затем **A**, или выполните `/agents`. **Shift+Tab** переключает агентов по кругу.

## Сессии

Чтобы начать новую сессию, нажмите **Ctrl+X**, затем **N**. Чтобы вернуться к существующей сессии, нажмите **Ctrl+X**, затем **L**, или выполните `/sessions`; **Ctrl+O** открывает недавние сессии и проекты в одном списке.

Вкладки включены по умолчанию. Переключайтесь между ними с помощью **Ctrl+Tab** и **Ctrl+Shift+Tab**, закрывайте вкладку сочетанием **Ctrl+X**, затем **W**, а последнюю закрытую вкладку открывайте снова сочетанием **Ctrl+Shift+T**.

## История

Нажмите **Ctrl+X**, затем **U**, или выполните `/undo`, чтобы откатить последнее сообщение пользователя и всю работу после него. Откаченный промпт возвращается в поле ввода, и его можно отредактировать.

Нажмите **Ctrl+X**, затем **R**, или выполните `/redo`, чтобы восстановить откаченную работу. Если вместо этого отправить новый промпт, откат будет принят и работа продолжится с этого места.

## Редактор

Задайте `VISUAL` или `EDITOR`, затем нажмите **Ctrl+X**, затем **E**, или выполните `/editor`, чтобы отредактировать текущий промпт в этом редакторе. Сохраните файл и выйдите из редактора — текст вернется в поле ввода; затем нажмите **Enter**, чтобы отправить его.

```bash
export EDITOR="nvim"
opencode
```

По умолчанию клавиша leader — **Ctrl+X**. Как изменить эти сочетания, описано в разделе [Сочетания клавиш](/cli/keybinds).
