title: "Сочетания клавиш"
---

Сочетания клавиш настраиваются в `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Для одной клавиши используйте строку:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Альтернативные варианты разделяйте запятыми:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Чтобы отключить сочетание, укажите `"none"` или `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Чтобы настроить обработку события, используйте объект:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

По умолчанию `leader` — это `ctrl+x`. `<leader>` в других сочетаниях ссылается на эту клавишу.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Неизвестные ID команд отклоняются.

## Mini

Команда `app.clear` работает только в [`opencode mini`](/cli). Нажмите `ctrl+l`, чтобы очистить видимую часть экрана и
заново отрисовать промпт. История прокрутки терминала сохраняется.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| --- | --- | --- |
| `app.clear` | `ctrl+l` | Очистить экран |

## Просмотр diff

Нажмите `d` (`diff.switch_source`), чтобы выбрать **All**, **Committed**, **Uncommitted** или **Last turn** (внутри
сессии), либо выберите **Base**, чтобы сменить ветку для сравнения. Выбор сохраняется до выхода из TUI. Начальную
область можно задать в [`diffs.source` в `cli.json`](/cli/config#diffs).

Сочетания для прокрутки, постраничного перехода и перехода в начало или конец всегда управляют diff. Переключения фокуса
с клавиатуры нет: щелкните файл, чтобы открыть его, щелкните папку, чтобы развернуть или свернуть ее, а дерево файлов
прокручивайте колесом мыши.

Для перехода между файлами используйте `n` / `p` или `alt+down` / `alt+up` (Option в macOS). В режиме просмотра diff
сочетания с Alt переключают файлы, а не вкладки сессий.

Нажмите `m`, чтобы отметить файл как просмотренный и свернуть тело его патча. В режиме всех файлов повторное нажатие
`m` снимает отметку и снова раскрывает патч. В режиме одного файла после отметки автоматически открывается следующий
файл, но на последнем файле переход останавливается, а не начинается сначала. Снятие отметки никогда не переключает
файл.

Щелкните правой кнопкой мыши файл на боковой панели или его заголовок в diff и выберите **Mark complete** (или
**Mark incomplete**). Это меняет то же состояние «просмотрено», что и `m`. Если отметить через меню другой файл, он не
выбирается, а текущий читаемый файл не переключается.

Альтернативы `diff.help` с Shift нужны для терминалов, которые при нажатии `?` сообщают о модификаторе Shift.

щелкните по ней. Для прокрутки используйте **↑/↓**, **Page Up/Down** или **Home**, **End** — чтобы следить за новым
выводом, а **Esc** — чтобы вернуться, не останавливая команду. Окно просмотра показывает последний вывод и остается
открытым после завершения команды; вывод, перенаправленный в файл, не отображается.
