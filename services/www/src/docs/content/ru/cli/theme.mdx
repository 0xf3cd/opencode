title: "Тема"
---

В OpenCode есть множество встроенных тем для светлого и темного режимов. Выберите тему в настройках или задайте собственные цвета.

## Выбор темы

Нажмите `Ctrl+P`, выберите **Open settings**, затем откройте **Theme**. Тема по умолчанию — `opencode`.

Тему также можно задать в глобальных [настройках CLI](/cli/config):

```json title="~/.config/opencode/cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json",
  "theme": {
    "name": "tokyonight",
    "mode": "dark"
  }
}
```

Чтобы сменить тему, не открывая настройки, выполните `/themes`.

## Системные цвета

Если OpenCode может прочитать палитру терминала, в списке тем появляется тема `system`. Ее цвета берутся из цвета текста, цвета фона и ANSI-палитры терминала.

Имя темы `system` выбирает цвета терминала. Режим `system` следует светлому или темному оформлению терминала.

## Режим

Используйте `system`, чтобы следовать оформлению терминала, или закрепите светлый либо темный режим:

| Режим | Поведение |
| --- | --- |
| `system` | Следует определенному светлому или темному оформлению терминала. |
| `dark` | Всегда использует темные цвета темы. |
| `light` | Всегда использует светлые цвета темы. |

Этому соответствует поле `mode` внутри `theme` в конфигурации CLI. Если пользовательская тема поддерживает только один режим, OpenCode использует его, даже когда запрошен другой.

## Добавление темы

Чтобы добавить тему, которую вы скачали или получили от кого-то, скопируйте ее JSON-файл в глобальный каталог тем:

```bash
cp theme.json ~/.config/opencode/themes/
```

Тему также можно положить в каталог `.opencode/themes` проекта — тогда она будет доступна только в этом проекте.

Имя файла становится именем темы. Например, `my-theme.json` отображается как `my-theme`. После добавления файла перезапустите OpenCode и выберите тему командой `/themes`.

OpenCode читает только файлы `.json`. Тема, расположенная ближе к текущему каталогу, заменяет глобальную тему или тему из родительского каталога с тем же именем.

## Темы в плагинах

[Плагины для CLI](/build/plugins/cli) получают итоговые цвета через `context.theme`, а активный режим — через `context.themeMode`. Используйте семантические токены, чтобы плагин следовал выбранной теме:

```tsx title="Inside a CLI plugin component"
import { usePlugin } from "@opencode/plugin/tui"

function Status() {
  const context = usePlugin()
  return <text fg={context.theme.text.base}>Ready</text>
}
```

Публичный API плагинов для CLI не регистрирует темы. Добавляйте собственные темы JSON-файлами в каталоги, указанные выше.

## Создание темы

Создавать и редактировать темы удобно в нашем [редакторе тем](https://opencode.ai/theme/). Он помогает разобраться в структуре темы, изменить ее и задать собственные цвета. Описание ниже приведено для справки.

Тема разделяет общие семантические токены и палитры для конкретных режимов:

| Раздел | Назначение |
| --- | --- |
| `base` | Полное дерево токенов, общее для всех режимов. |
| `light`, `dark` | Полная палитра оттенков и необязательные переопределения токенов для этого режима. |

Каждая тема содержит полный раздел `base` и определяет хотя бы один из режимов — `light` или `dark`. Режимы наследуют значения из `base` того же файла; они не наследуют ничего ни от встроенной темы OpenCode, ни друг от друга.

В примерах ниже показаны только разделы, относящиеся к рассматриваемому понятию. Прежде чем настраивать тему, сгенерируйте полный файл в редакторе тем.

### Структура

Цвета, общие для обоих режимов, задайте в `base`, а при необходимости переопределите их внутри `light` или `dark`:

```json title="theme.json (excerpt)"
{
  "$schema": "https://opencode.ai/theme.json",
  "base": {
    "text": {
      "base": "$hue.neutral.200",
      "muted": "$hue.neutral.400"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": {
      "muted": "$hue.neutral.300"
    }
  }
}
```

Полный раздел `base` задает все семантические токены. Каждый режим задает все обязательные оттенки и может переопределить любую часть базового дерева токенов.

### Цвета и ссылки

Цвет может быть шестнадцатеричным значением, `"transparent"` или ссылкой на другой цвет темы:

```json title="Inside base or a mode"
{
  "text": {
    "base": "#eeeeee",
    "muted": "$hue.neutral.400"
  },
  "border": {
    "base": "$text.muted"
  }
}
```

### Оттенки

Оттенки — это цветовые шкалы из девяти ступеней. Каждый режим определяет восемь базовых оттенков и три псевдонима:

| Вид | Значения |
| --- | --- |
| Базовые | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Псевдонимы | `accent`, `interactive`, `neutral` |
| Ступени | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900` |

Задайте все девять ступеней базового оттенка или сделайте один оттенок псевдонимом другого:

```json title="Inside light or dark"
{
  "hue": {
    "purple": {
      "100": "#b38ff4",
      "200": "#9d7cd8",
      "300": "#8869bd",
      "400": "#7357a2",
      "500": "#5f4688",
      "600": "#4b356f",
      "700": "#392557",
      "800": "#271640",
      "900": "#17072b"
    },
    "accent": "$hue.purple"
  }
}
```

Ступени оттенков следуют направлению контраста режима. В светлых темах они идут от темного на `100` к светлому на `900`, в темных — от светлого на `100` к темному на `900`.

Массив `categorical` в `base` задает упорядоченный список оттенков, которыми различаются агенты и другие повторяющиеся элементы:

```json title="Inside base"
{
  "categorical": ["accent", "purple", "green", "blue"]
}
```

### Семантические токены

Семантические токены назначают цвета ролям в интерфейсе. Компоненты используют эти роли, а не выбирают цвета напрямую.

| Группа | Назначение |
| --- | --- |
| `text` | Основной и приглушенный текст, текст действий, полей форм, статусов и обратной связи. |
| `background` | Основной фон, приподнятые поверхности, действия, поля форм и заливки обратной связи. |
| `border`, `scrollbar` | Цвета границ и полос прокрутки. |
| `diff` | Цвета добавленных и удаленных строк, контекста, выделения и номеров строк. |
| `syntax` | Подсветка исходного кода. |
| `markdown` | Элементы Markdown. |

Например, `text.muted` управляет второстепенным текстом, а `background.raised` задает поверхности с возрастающим уровнем приподнятости:

```json title="Inside base"
{
  "text": {
    "base": "$hue.neutral.200",
    "muted": "$hue.neutral.400"
  },
  "background": {
    "base": "$hue.neutral.800",
    "raised": {
      "base": "$hue.neutral.700",
      "high": "$hue.neutral.600",
      "max": "$hue.neutral.500"
    }
  }
}
```

Ключи подсветки синтаксиса: `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` и `punctuation`.

Ключи Markdown: `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`, `horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` и `codeBlock`.

### Действия и состояния

У действий есть варианты `primary`, `secondary` и `destructive`. Действия и поля форм используют `base` и необязательные состояния взаимодействия:

```json title="Inside base or a mode"
{
  "text": {
    "action": {
      "primary": {
        "base": "$hue.interactive.400",
        "$hovered": "$hue.interactive.300",
        "$disabled": "$hue.neutral.600"
      }
    }
  }
}
```

Ключи состояний: `$hovered`, `$focused`, `$pressed`, `$selected` и `$disabled`. Для незаданного состояния используется цвет `base` соответствующего действия или поля формы.

### Поверхность диалогов

Панели, диалоговые окна, меню и всплывающие уведомления выбирают уровень приподнятости из `background.raised`. Диалоговые окна могут дополнительно переопределять семантические токены через `@dialog`:

```json title="Inside base or a mode"
{
  "@dialog": {
    "background": {
      "base": "$background.raised.base",
      "action": {
        "primary": {
          "$hovered": "$background.raised.high"
        }
      }
    }
  }
}
```

После применения `@dialog` TUI заново разрешает ссылки, поэтому токены, ссылающиеся на `$background.base`, следуют фону диалогового окна. Значение `base` контекстного действия становится резервным для его незаданных состояний; явно заданные состояния по-прежнему имеют приоритет.
