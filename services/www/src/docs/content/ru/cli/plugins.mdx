---
title: "Плагины"
---

Плагины, настроенные в `opencode.json(c)` и предоставляющие TUI-компонент, CLI загружает автоматически. О создании
плагинов читайте в разделе [Разработка плагинов](/build/plugins). Добавлять тот же пакет в `cli.json` не нужно: CLI
получает список активных плагинов от подключенного сервера OpenCode, поэтому это работает и с удаленным сервером.

Для плагинов, которые нужны только CLI, используйте `cli.json`. Такие плагины работают локально в терминале и остаются
активными, когда CLI подключен к удаленному серверу:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Записи обрабатываются по порядку. Чтобы отключить подходящие плагины, добавьте `-` перед ID или шаблоном:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Параметры плагина передаются в форме объекта:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode также находит плагины в глобальном каталоге конфигурации и в каталогах `.opencode` проекта. Структура каждого
плагина такая же, как у опубликованного пакета: точки входа для сервера и TUI лежат рядом.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Найденные плагины могут напрямую импортировать `@opencode/plugin/tui` — OpenCode разрешает этот пакет во время
выполнения. Примеры приведены в разделе [Разработка плагинов для CLI](/build/plugins/cli).
