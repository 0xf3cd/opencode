Настройки CLI относятся только к терминальным клиентам. Они хранятся отдельно от настроек сервера и проекта в
`opencode.json(c)`.

Чтобы изменить основные настройки из TUI, нажмите `Ctrl+P` и выберите **Open settings**.

<img src={`${import.meta.env.BASE_URL}assets/docs/cli/settings.png`} alt="Диалог настроек в TUI OpenCode" />

## Файл конфигурации

OpenCode хранит настройки CLI в одном глобальном файле:

```text
~/.config/opencode/cli.json
```

Если задана переменная `$XDG_CONFIG_HOME`, OpenCode использует файл:

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

Локального файла настроек CLI для проекта нет. Для проверки и автодополнения подключите опубликованную JSON Schema:

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode добавляет `$schema`, когда создает или мигрирует этот файл. Неизвестные настройки отклоняются, а корректные
изменения применяются без перезапуска TUI.

## Встроенная конфигурация

Чтобы применить настройки CLI из встроенного JSON, задайте `OPENCODE_CLI_CONFIG_CONTENT`:

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode накладывает встроенные настройки поверх глобального `cli.json`. Вложенные объекты объединяются, а массивы и
скалярные значения из переменной окружения заменяют глобальные. Пока переменная задана, встроенные настройки имеют
приоритет.

## Внешний вид
Выберите тему, настройте анимацию интерфейса и переопределите курсор терминала:

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки внешнего вида" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `theme.name` | строка | Выбирает встроенную, пользовательскую тему или тему на основе цветов терминала. |
| `theme.mode` | `system`, `dark` или `light` | Следует оформлению терминала или закрепляет один цветовой режим темы. |
| `animations` | логическое значение | Включает анимацию интерфейса. |
| `cursor.style` | `block`, `underline`, `line`, `default` | Задает форму курсора. `default` сохраняет форму курсора терминала. |
| `cursor.blinking` | логическое значение | Управляет миганием курсора. Не действует, если выбран стиль `default`. |

</div>

Выбор и создание тем описаны в разделе [Тема](/cli/theme).

## Ввод

Настройте захват мыши, прокрутку, контекст редактора, вставку текста и предпросмотр изображений в промпте:

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки ввода" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `mouse` | логическое значение | Включает захват мыши в терминале. |
| `scroll.speed` | число, не меньше `0.001` | Задает фиксированное расстояние прокрутки за один шаг ввода. |
| `scroll.acceleration` | логическое значение | Ускоряет повторную прокрутку. Если включено, имеет приоритет над скоростью. |
| `prompt.editor` | логическое значение | Добавляет в контекст промпта активный файл или выделение в редакторе. |
| `prompt.paste` | `compact` или `full` | Показывает большие вставки компактными заполнителями или полным текстом. |
| `prompt.image_preview` | логическое значение | Показывает предпросмотр прикрепленных изображений над полем ввода промпта. |

</div>

## Сессии

Настройте отображение сессий в полноэкранном TUI и каталог, в котором начинаются новые сессии:

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки сессий" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `session.sidebar` | `auto` или `hide` | Показывает боковую панель, если хватает места, или всегда скрывает ее. |
| `session.scrollbar` | логическое значение | Показывает полосу прокрутки ленты сессии. |
| `session.thinking` | `show` или `hide` | Показывает или скрывает рассуждения модели по умолчанию. |
| `session.grouping` | `auto` или `none` | Группирует связанные элементы ленты или показывает каждый элемент отдельно. |
| `session.image_preview` | логическое значение | Показывает в ленте изображения из вложений пользователя и результатов инструментов. |
| `session.tps` | логическое значение | Показывает число выходных токенов в секунду в нижней строке ответов ассистента. |
| `session.markdown` | `source` или `rendered` | Показывает символы разметки Markdown или скрывает их в отрендеренном содержимом. |
| `session.new_location` | `launch` или `inherit` | Начинает сессию в каталоге запуска TUI или наследует расположение активной сессии. |
| `session.permissions` | `prompt` или `autoaccept` | Запрашивает подтверждение для запросов разрешений или автоматически принимает все запросы. |

</div>

## Вкладки

Настройте постоянную панель вкладок сессий:

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

Устаревшая логическая настройка `tabs.enabled` по-прежнему поддерживается: `true` соответствует `on`, а `false` —
`off`. OpenCode читает ее, не перезаписывая файл конфигурации.

<div class="docs-table-scroll" role="region" aria-label="Настройки вкладок" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `tabs.mode` | `auto`, `on` или `off` | Включает вкладки автоматически, всегда или никогда. В режиме auto вкладки скрываются внутри Herdr. |
| `tabs.scope` | `cwd` или `global` | Хранит отдельные вкладки для каждого рабочего каталога или общий набор для всех. |
| `tabs.layout` | `horizontal` или `vertical` | Размещает вкладки в горизонтальной полосе или в вертикальной боковой панели. |
| `tabs.indicators` | `status` или `numbers` | Показывает значки статуса или всегда показывает номера вкладок. |

</div>

Номера вкладок сохраняют цвета статуса и фоновую анимацию. Сочетания Ctrl+цифра переключают вкладки в любом режиме
индикаторов.

## Diff

Настройте начальную область и отображение diff:

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки diff" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `diffs.source` | `branch`, `committed`, `working` или `turn` | Задает начальную область просмотра. |
| `diffs.wrap` | `word` или `none` | Переносит длинные строки по словам или не переносит их. |
| `diffs.tree` | логическое значение | Показывает дерево файлов diff. |
| `diffs.single` | логическое значение | Показывает патч только для выбранного файла. |
| `diffs.view` | `auto`, `split` или `unified` | Задает макет. `auto` выбирает его по доступной ширине. |

</div>

`branch` показывает **All** — изменения в ветке и локальные изменения, `committed` — только коммиты ветки, а
`working` — проиндексированные, непроиндексированные и неотслеживаемые изменения. `turn` показывает **Last turn** —
файлы, которые сессия изменила за последний ход; область обновляется, когда сессия завершает ход, а если `/diff` открыт
не из сессии, используется `branch`.

В `/diff` нажмите `d`, чтобы сменить область, или выберите ветку для сравнения в **Base**. Этот выбор действует до
выхода из TUI и не изменяет `cli.json`.

## Оповещения

Системные уведомления и звуковые сигналы включаются независимо друг от друга:

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки оповещений" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `attention.notifications` | логическое значение | Показывает системные уведомления, обычно когда терминал не в фокусе. |
| `attention.sound` | логическое значение | Воспроизводит звуковые сигналы. |
| `attention.volume` | число от `0` до `1` | Задает громкость звука. |
| `attention.sound_pack` | строка | Выбирает ID активного набора звуков. |
| `attention.sounds` | объект | Переопределяет звуковые файлы для `default`, `question`, `permission`, `error`, `done` или `subagent_done`. |

</div>

Если файл из переопределения некорректен или не читается, для этого события используется встроенный звук.

После обновления TUI один раз показывает на главном экране основные новинки релиза. Чтобы посмотреть их снова,
выполните `/highlights`. Это окно также можно отключить:

```json title="cli.json"
{
  "highlights": false
}
```

## Терминал

Настройте интеграцию с терминалом:

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки терминала" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `terminal.title` | логическое значение | Обновляет заголовок окна терминала. |
| `terminal.copy` | `manual` или `select` | Копирует вручную или сразу после выделения. По умолчанию — `manual` в Windows и `select` на остальных платформах. |

</div>

## Mini

Группа `mini` управляет минималистичным интерактивным интерфейсом [`opencode mini`](/cli#mini):

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки Mini" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `mini.thinking` | `show` или `hide` | Показывает или скрывает рассуждения модели. |
| `mini.tools` | `show` или `hide` | Показывает или скрывает вызовы инструментов и предшествующий им текст ассистента. |
| `mini.shell_output` | `show` или `hide` | Показывает или скрывает необработанный вывод инструмента оболочки. |
| `mini.turn_summary` | `show` или `hide` | Показывает или скрывает в истории прокрутки сводку: агент, модель и длительность. |
| `mini.footer` | `show` или `hide` | Показывает или скрывает постоянную строку с активностью, моделью, расходом и контекстом. |
| `mini.splash` | `show` или `hide` | Показывает или скрывает заставки при входе и выходе. |
| `mini.work_spinner` | ID спиннера | Выбирает анимацию работы в нижней строке. |
| `mini.mono` | логическое значение | Включает монохромный ASCII-вывод. |
| `mini.replay` | логическое значение | Восстанавливает историю сессии при возобновлении и изменении размера терминала. |
| `mini.replay_limit` | положительное целое число | Ограничивает воспроизведение последними сообщениями. По умолчанию — `200`. |

</div>

Доступные ID спиннеров:

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

Флаги воспроизведения `mini` в командной строке переопределяют эти настройки для конкретного запуска.

## Сочетания клавиш

Переопределите сочетание для команды и тайм-аут клавиши leader:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки сочетаний клавиш" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `keybinds.leader` | значение сочетания | Задает клавишу, на которую ссылается `<leader>` в других сочетаниях. |
| `keybinds.<command>` | значение сочетания | Переопределяет сочетание для одного ID команды. |
| `keybinds.*.key` | строка или дескриптор клавиши | Выбирает клавишу для сочетания в форме объекта. |
| `keybinds.*.event` | `press` или `release` | Ограничивает сочетание в форме объекта одним событием клавиши. |
| `keybinds.*.preventDefault` | логическое значение | Определяет, отменяется ли стандартное поведение клавиши в терминале. |
| `keybinds.*.fallthrough` | логическое значение | Позволяет обработчикам с более низким приоритетом получить то же событие. |
| `leader.timeout` | положительное целое число | Задает, сколько миллисекунд ждать после нажатия клавиши leader. |

</div>

Значением сочетания может быть строка, массив альтернатив или объект. Чтобы отключить сочетание, укажите `"none"` или
`false`. Синтаксис клавиш, все ID команд и все сочетания по умолчанию описаны в разделе
[Сочетания клавиш](/cli/keybinds).

## Плагины

Загрузите плагины, работающие только в терминале, в нужном порядке:

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки плагинов" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `plugins` | массив | Задает упорядоченные директивы включения и внешние плагины. |
| `plugins[].package` | строка | Задает имя пакета, локальный путь или file URL. |
| `plugins[].options` | объект | Передает плагину его собственные параметры. |

</div>

Формы записи пакетов, локальный поиск, шаблоны и директивы отключения описаны в разделе [Плагины](/cli/plugins).

## Отладка и экспериментальные функции

Включите диагностику или подключите один из доступных сейчас экспериментов:

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Настройки отладки и экспериментальных функций" tabIndex={0}>

| Настройка | Значения | Описание |
| --- | --- | --- |
| `debug.devtools` | логическое значение | Показывает отладочную панель DevTools. |
| `debug.timing` | логическое значение | Показывает в отладочной панели время до первой отрисовки. |
| `debug.turn_tokens` | логическое значение или `verbose` | Показывает расход токенов за каждый ход; `verbose` также включает входные данные вызовов инструментов. |
| `experimental` | объект: ID функций → логические значения | Включает или отключает эксперименты, которые могут измениться или быть удалены без предупреждения. |

</div>

Используйте только ID функций, которые сейчас перечислены в диалоге **Experiments** в TUI. Неизвестные ID ни на что не
влияют.
