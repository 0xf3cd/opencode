---
title: "Инструкции"
---

Добавьте файл `AGENTS.md`, чтобы дать OpenCode постоянные инструкции для проекта: команды сборки, заметки об архитектуре, соглашения по коду и требования к проверке.

```md title="AGENTS.md"
# Project instructions

- Run `bun typecheck` after changing TypeScript.
- Keep database queries in `src/database`.
- Do not edit generated files directly.
```

Добавляйте файлы инструкций проекта в репозиторий, чтобы все, кто работает с ним, получали одинаковые инструкции.

## Область действия

Поместите `AGENTS.md` в каталог, к которому относятся инструкции. OpenCode загружает глобальный файл, а затем все файлы `AGENTS.md` от текущего каталога рабочего пространства вверх до домашнего каталога. Если рабочее пространство находится вне домашнего каталога, поиск останавливается на корне проекта.

```text
~/.config/opencode/AGENTS.md
~/code/my-project/AGENTS.md
~/code/my-project/packages/AGENTS.md
~/code/my-project/packages/web/AGENTS.md  ← current workspace
```

В этом примере загружаются все четыре файла. Они объединяются в таком порядке:

```text
~/.config/opencode/AGENTS.md
packages/web/AGENTS.md
packages/AGENTS.md
AGENTS.md
```

Инструкции, которые действуют везде, храните в глобальном файле. Инструкции для всего репозитория помещайте в корень проекта, а более конкретные — ближе к коду, к которому они относятся. OpenCode объединяет файлы и не разрешает противоречия между ними.

Если рабочее пространство находится вне корня проекта, загружается только глобальный файл. Задайте `OPENCODE_DISABLE_PROJECT_CONFIG=1`, чтобы отключить поиск `AGENTS.md` в проекте, сохранив глобальный файл.

<Callout type="note">
  OpenCode V2 распознает только `AGENTS.md`. `CLAUDE.md` не используется в качестве резервного варианта.
</Callout>

## Обнаружение

Файлы инструкций ниже рабочего пространства обнаруживаются по мере того, как агент изучает проект. При чтении файла или просмотре каталога загружаются все файлы `AGENTS.md`, расположенные между этим объектом и рабочим пространством.

```text
my-project/                         ← current workspace
├── AGENTS.md                       loaded initially
└── packages/
    └── web/
        ├── AGENTS.md               loaded when this area is read
        └── src/
            └── app.ts              read target
```

Вложенные файлы загружаются начиная с ближайшего и не дублируются, пока их запись с инструкциями остается в истории, видимой модели. Повторное чтение той же области обычно не добавляет их снова. Если эта запись удалена в результате сжатия контекста или отката, при следующем чтении файл может загрузиться снова.

Изменения во вложенном файле после его загрузки автоматически не отслеживаются. Если обновленный текст должен применяться сразу, начните новую сессию.

## Порядок

Первым отправляется системный промпт выбранного агента или провайдера. Затем OpenCode собирает начальные инструкции в таком порядке:

```text
1. Agent or provider system prompt
2. Built-in environment and date context
3. Code Mode tool guidance, when enabled
4. Global and project AGENTS.md files
5. Available skill, reference, and MCP guidance
6. Session-specific instruction entries supplied through the API
```

Эти источники объединяются, а не переопределяют друг друга. Вложенные файлы `AGENTS.md`, обнаруженные позже, добавляются в историю сессии в порядке обнаружения.

## Обновления

Чтобы обновить инструкции во время работы сессии, отредактируйте глобальный файл `AGENTS.md` или один из файлов, найденных при поиске вверх по каталогам.

```bash
$ printf '\n- Run the integration suite before committing.\n' >> AGENTS.md
```

Перед следующим запросом к модели OpenCode обнаруживает изменение и, прежде чем доставить ожидающий ввод, добавляет обновление инструкций:

```text
AGENTS.md changes
→ instruction update
→ next prompt
```

- Если удалить все файлы `AGENTS.md`, загружаемые автоматически, сессия получит сообщение, что прежние инструкции больше не действуют.
- При временной ошибке чтения сохраняются последние известные инструкции, а не считаются удаленными.
- При перемещении сессии ее состояние инструкций сохраняется, поэтому инструкции в новом каталоге добавляются как обновление.
- Фиксация отката сессии сбрасывает ее состояние инструкций и перезагружает инструкции перед следующим промптом.

Содержимое инструкций остается привилегированным. Клиенты видят, какие источники изменились, но не их содержимое.

## Конфигурация

Схема конфигурации V2 принимает массив `instructions`, но сейчас V2 не обрабатывает указанные в нем файлы, glob-шаблоны и URL. Такая конфигурация пока не добавляет инструкции для модели:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "instructions": ["CONTRIBUTING.md", "docs/guidelines/*.md", "https://example.com/instructions.md"],
}
```

Для действующих инструкций в V2 используйте `AGENTS.md`. Расположение файлов конфигурации и их приоритет описаны в разделе [Конфигурация](/config).
