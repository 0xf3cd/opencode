OpenCode — это AI-агент для программирования с открытым исходным кодом. Он доступен в виде терминального интерфейса,
десктопного приложения и веб-приложения.

Пакет npm с помощью postinstall-скрипта выбирает нативный бинарный файл `opencode` для вашей платформы. Команды для Bun
и pnpm явно разрешают запуск этого скрипта; для Vite+ дополнительные флаги не нужны. Для команды mise нужна mise 2026.10.9 или новее; более старые версии устанавливают OpenCode 1.

Пакетные менеджеры Windows не поддерживаются.


Вы также можете скачать отдельный бинарный файл CLI для своей платформы.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## Веб-интерфейс

Чтобы открыть веб-интерфейс OpenCode, выполните команду `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker-образы публикуются с тегами версий, например `ghcr.io/anomalyco/opencode:2.0.0`.

## Подключение

OpenCode из коробки поддерживает множество LLM-провайдеров: подключиться к ним можно прямо
[в TUI](/cli/providers) командой `/connect`.

О настройке собственных провайдеров читайте в разделе [Провайдеры](/providers).

Если вам нужен простой доступ ко всем лучшим моделям для программирования, попробуйте
[OpenCode Console](/console).

Также можно попробовать [OpenCode Go](/console/go) — подписку за $10 в месяц с доступом к лучшим моделям с открытым
исходным кодом.

## Персонализация

Настройте OpenCode под себя: отредактируйте [конфигурацию OpenCode](/config), [подключите плагины](/plugins) и
[MCP-серверы](/mcp-servers) или [создайте свои команды](/commands). Темы и сочетания клавиш терминального интерфейса
описаны в разделе [Настройки CLI](/cli/config).
