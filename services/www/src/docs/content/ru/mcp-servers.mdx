---
title: "MCP-серверы"
---

OpenCode подключается к серверам [Model Context Protocol](https://modelcontextprotocol.io/) и предоставляет их возможности: инструменты, промпты, ресурсы и инструкции. MCP-инструменты расходуют контекст модели, поэтому добавляйте только нужные серверы.

## Настройка

Добавьте удаленный сервер из проекта, в котором он нужен, и проверьте подключение:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
opencode mcp list
```

Команда записывает сервер в [конфигурацию](/config) проекта. Чтобы сервер был доступен во всех проектах, добавьте `--global`:

```sh
opencode mcp add context7 --global --url https://mcp.context7.com/mcp
```

Удаленные серверы по умолчанию используют OAuth. Если в списке указано `needs authentication`, откройте OpenCode, выполните `/mcps`, выберите сервер и войдите. Подключенный сервер готов к использованию агентом:

```text
✓ context7  connected
```

## Конфигурация

Чтобы настроить сервер вручную, задайте ему уникальное имя в `mcp.servers`. В V2 имена серверов не размещаются прямо в `mcp`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
      },
    },
  },
}
```

Серверы подключаются автоматически. Чтобы сервер оставался в конфигурации, но не подключался, используйте `disabled`, а не поле `enabled`:

```jsonc
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
        "disabled": true,
      },
    },
  },
}
```

Конфигурация проекта с более высоким приоритетом полностью заменяет объект сервера с тем же именем. Для разных подключений или аккаунтов используйте разные имена; иначе повторите в переопределении все обязательные поля:

```jsonc title="opencode.jsonc"
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
      },
    },
  },
}
```

## Локальные серверы

Локальный сервер — это команда, которую OpenCode запускает с транспортом MCP через stdio. Чтобы добавить его, укажите команду после `--`:

```sh
opencode mcp add everything -- npx -y @modelcontextprotocol/server-everything
```

Параметры процесса, например рабочий каталог или переменные окружения, задаются в конфигурации:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "everything": {
        "type": "local",
        "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
        "cwd": ".",
        "environment": {
          "LOG_LEVEL": "info",
          "MCP_API_KEY": "{env:MCP_API_KEY}",
        },
      },
    },
  },
}
```

| Поле | Обязательное | Описание |
| --- | --- | --- |
| `type` | Да | Должно быть `"local"`. |
| `command` | Да | Исполняемый файл и его аргументы. |
| `cwd` | Нет | Каталог процесса. Относительные пути отсчитываются от рабочего пространства, оно же используется по умолчанию. |
| `environment` | Нет | Строковые переменные, добавляемые к окружению, унаследованному от процесса OpenCode. |
| `disabled` | Нет | Если `true`, сервер не подключается. По умолчанию `false`. |
| `codemode` | Нет | `false` предоставляет инструменты напрямую, а не через Code Mode. По умолчанию `true`. |
| `timeout` | Нет | Переопределения тайм-аутов для этого сервера. |
| `protocol` | Нет | `legacy` (по умолчанию), `auto` или `2026-07-28`. См. [Версия протокола](#protocol-version). |

Для подстановки переменных окружения используйте `{env:NAME}`. Выражения оболочки вроде `$NAME` в строках JSON не раскрываются:

```jsonc
{
  "environment": {
    "MCP_API_KEY": "{env:MCP_API_KEY}",
  },
}
```

## Удаленные серверы

Удаленный сервер использует транспорт MCP Streamable HTTP и требует абсолютного URL:

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Если серверу нужны заголовки или другие параметры, используйте конфигурацию. Секреты храните в переменных окружения, а не в файле:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "oauth": false,
        "headers": {
          "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}",
        },
      },
    },
  },
}
```

| Поле | Обязательное | Описание |
| --- | --- | --- |
| `type` | Да | Должно быть `"remote"`. |
| `url` | Да | Абсолютный адрес эндпоинта Streamable HTTP. |
| `headers` | Нет | Строковые HTTP-заголовки, отправляемые эндпоинту. |
| `oauth` | Нет | Настройки OAuth или `false`, чтобы отключить OAuth. |
| `disabled` | Нет | Если `true`, сервер не подключается. По умолчанию `false`. |
| `codemode` | Нет | `false` предоставляет инструменты напрямую, а не через Code Mode. По умолчанию `true`. |
| `timeout` | Нет | Переопределения тайм-аутов для этого сервера. |
| `protocol` | Нет | `legacy` (по умолчанию), `auto` или `2026-07-28`. См. [Версия протокола](#protocol-version). |

Используйте `oauth: false`, только если сервер работает исключительно с API-ключом или другими учетными данными в заголовке:

```jsonc
{
  "type": "remote",
  "url": "https://mcp.example.com/mcp",
  "oauth": false,
  "headers": { "Authorization": "Bearer {env:MCP_API_KEY}" },
}
```

## OAuth

Для удаленных серверов OAuth включен, если `oauth` не равен `false`. OpenCode находит сервер авторизации, использует PKCE, обновляет токены и, если это поддерживается, пытается выполнить динамическую регистрацию клиента; учетные данные хранятся вне конфигурации проекта.

Для динамической регистрации достаточно указать URL сервера:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
      },
    },
  },
}
```

Если серверу нужна аутентификация, выполните `/mcps`, выберите его и завершите авторизацию в браузере. Тот же процесс можно запустить из CLI:

```sh
opencode mcp auth sentry
```

Если провайдер выдал вам учетные данные клиента, используйте поля OAuth V2 в формате snake_case:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "company-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "oauth": {
          "client_id": "{env:MCP_CLIENT_ID}",
          "client_secret": "{env:MCP_CLIENT_SECRET}",
          "scope": "tools:read tools:execute",
          "callback_port": 19876,
          "redirect_uri": "http://127.0.0.1:19876/callback",
        },
      },
    },
  },
}
```

| Поле | Описание |
| --- | --- |
| `client_id` | ID заранее зарегистрированного клиента. Если не указан, OpenCode попытается выполнить динамическую регистрацию. |
| `client_secret` | Секрет заранее зарегистрированного клиента. |
| `scope` | Запрашиваемые области доступа (scopes) через пробел. |
| `callback_port` | Локальный порт для обратного вызова от `1` до `65535`. По умолчанию используется свободный эфемерный порт. |
| `redirect_uri` | Заранее зарегистрированный loopback-URI, путь и порт которого ведут к локальному обработчику обратного вызова. |
| `auth_server_metadata_url` | URL документа метаданных OAuth или OpenID Connect сервера авторизации. Задайте его, если MCP-сервер не публикует метаданные защищенного ресурса с указанием своего сервера авторизации. |

Если нужно войти заново или сменить аккаунт, удалите сохраненные учетные данные OAuth:

```sh
opencode mcp logout sentry
```

## Тайм-ауты

Тайм-ауты задаются положительными целыми числами в миллисекундах. Значения по умолчанию задаются в `mcp.timeout`; объект `timeout` сервера переопределяет соответствующие значения по умолчанию.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "timeout": {
      "startup": 45000,
      "catalog": 30000,
      "execution": 600000,
    },
    "servers": {
      "slow-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "timeout": {
          "catalog": 60000,
        },
      },
    },
  },
}
```

| Тайм-аут | По умолчанию | К чему применяется |
| --- | --- | --- |
| `startup` | 30 секунд | Подключение транспорта и инициализация сервера. |
| `catalog` | 30 секунд | Получение списков инструментов, промптов, ресурсов и шаблонов ресурсов. |
| `execution` | 12 часов | Вызовы инструментов, получение промптов и чтение ресурсов. |

## Версия протокола

По умолчанию OpenCode подключается к каждому серверу с классическим рукопожатием MCP `initialize`. Чтобы работать с сервером на ревизии 2026-07-28, задайте для него `protocol`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "modern": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "protocol": "auto",
      },
    },
  },
}
```

| Значение | Поведение |
| --- | --- |
| `legacy` | По умолчанию. Отправляет `initialize` и поддерживает ревизии протокола до 2025-11-25. |
| `auto` | Проверяет поддержку ревизии 2026-07-28 запросом `server/discover` и переходит на `legacy`, если сервер ее не поддерживает. |
| `2026-07-28` | Требует ревизию 2026-07-28. Подключение к более старым серверам завершается ошибкой. |

Проверка локального сервера с `legacy` запускает дополнительный кратковременный процесс и, если сервер игнорирует неизвестные запросы, может ждать до истечения тайм-аута запуска. Поэтому включайте `auto` только для серверов, которым это нужно.

## Имена

OpenCode называет инструменты `<server>_<tool>`. Все символы, кроме букв, цифр, `_` и `-`, заменяются на `_`:

```text
server: context 7
tool:   resolve.library/id
name:   context_7_resolve_library_id
```

MCP-промпты становятся командами с именами `<server>:<prompt>` с той же нормализацией. Например:

```text
/context_7:find_docs
```

Выбирайте короткие имена серверов, которые остаются уникальными после нормализации. В режиме Code Mode, используемом по умолчанию, инструменты группируются по нормализованному имени сервера:

```text
tools.context_7.resolve_library_id(...)
```

## Разрешения

По умолчанию используется Code Mode. Задайте `codemode: false`, если инструменты сервера должны оставаться в нативном списке инструментов провайдера:

```jsonc
{
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "codemode": false,
      },
    },
  },
}
```

Чтобы скрыть или запретить инструменты, не отключая сервер, используйте действия разрешений. Указывайте нормализованное имя `<server>_<tool>`:

```jsonc
{
  "permissions": [
    {
      "action": "context7_*",
      "resource": "*",
      "effect": "deny",
    },
  ],
}
```

## Контекст

Для вызовов от имени сессии OpenCode передает ID сессии в `CallToolRequest.params._meta["ai.opencode/sessionID"]`. Это относится к прямым инструментам и к Code Mode как через stdio, так и через Streamable HTTP:

```json
{
  "method": "tools/call",
  "params": {
    "name": "lookup",
    "arguments": { "query": "example" },
    "_meta": { "ai.opencode/sessionID": "ses_..." }
  }
}
```

ID передается в метаданных запроса, а не как аргумент инструмента, поэтому его нет в схеме, которую видит модель. Считайте его непрозрачным значением для корреляции:

| Правило | Поведение |
| --- | --- |
| Идентичность | Обозначает вызывающую сессию OpenCode, а не сессию транспорта MCP. |
| Наличие | Может отсутствовать у вызовов без контекста сессии. |
| Безопасность | Не используйте только его для аутентификации или авторизации. |
| Конфиденциальность | Удаленные серверы получают ID как есть и могут записывать его в журналы или хранить. |

## Управление

Список серверов и их текущее состояние подключения можно вывести из любого проекта:

```sh
opencode mcp list
```

В OpenCode команда `/mcps` позволяет просматривать серверы, подключать и отключать их, а также проходить аутентификацию. Добавлять серверы и управлять учетными данными OAuth можно через CLI:

```sh
opencode mcp add sentry --url https://mcp.sentry.dev/mcp
opencode mcp auth sentry
opencode mcp logout sentry
```

Чтобы удалить сервер, удалите его запись из конфигурации проекта или глобальной конфигурации, куда он был добавлен:

```jsonc
{
  "mcp": {
    "servers": {},
  },
}
```

Настройки OAuth-клиента, тайм-ауты, рабочие каталоги и постоянное включение или отключение задаются напрямую в конфигурации:

```jsonc
{
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
        "disabled": true,
      },
    },
  },
}
```
