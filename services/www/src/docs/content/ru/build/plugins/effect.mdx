---
title: "Effect"
---

`@opencode/plugin/effect` — версия API плагинов OpenCode, построенная на Effect. Операции контекста возвращают Effect
или Stream, колбэки возвращают Effect, а время жизни плагина представлено через `Scope`.

При загрузке плагинов и их зависимостей из `node_modules` OpenCode сам предоставляет в среде выполнения `effect`
(включая экспортируемые подпути `effect/*`) и `@opencode/plugin`. Для локальной проверки типов и тестирования
установите их как peer- или dev-зависимости, а не включайте в сборку плагина.

```sh
bun add --peer @opencode/plugin effect
```

Чтобы Effect-плагин загружался автоматически, экспортируйте его из `.opencode/plugins/`.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

Опубликованные пакеты и каталоги плагинов за пределами `.opencode/plugins/` подключаются через ту же настройку
`plugins`, что и другие серверные плагины.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

О включении плагинов, разрешении пакетов и приоритете конфигурации читайте в разделе [Настройка плагинов](/plugins).

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## Жизненный цикл

`effect` выполняется при загрузке плагина. Его Scope закрывается, когда плагин перезагружается или выгружается, поэтому
регистрации, привязанные к Scope файберы и финализаторы освобождаются вместе.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

Для фоновой работы используйте файберы, привязанные к Scope. При очистке Scope плагина прерывает такой файбер.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### Контекст

Контекст предоставляет Effect-клиент для подключенного сервера OpenCode, а также доступные только плагинам
преобразования, хуки, хранилище, перезагрузку и параметры. Внутренние сервисы Core OpenCode через него недоступны.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

Определение плагина и полный контекст объявлены так:

```ts
interface Context {
  readonly app: App
  readonly location: Location.Info
  readonly options: PluginOptions
  readonly agent: AgentDomain
  readonly aisdk: AISDKDomain
  readonly command: CommandDomain
  readonly event: EventDomain
  readonly experimental: {
    readonly terminal: Pick<ExperimentalApi<unknown>["persistentPty"], "read">
  }
  readonly integration: IntegrationDomain
  readonly mcp: MCPDomain
  readonly model: ModelDomain
  readonly generate: GenerateApi<unknown>
  readonly permission: PermissionDomain
  readonly plugin: Pick<PluginApi<unknown>, "list">
  readonly provider: ProviderDomain
  readonly reference: ReferenceDomain
  readonly rpc: RpcDomain
  readonly session: SessionDomain
  readonly shell: ShellDomain
  readonly skill: SkillDomain
  readonly storage: StorageDomain
  readonly tool: ToolDomain
  readonly vcs: VcsDomain
  readonly websearch: WebSearchDomain
  readonly worktree: WorktreeDomain
}

interface Plugin<R = Scope.Scope> {
  readonly id: string
  readonly effect: (context: Context) => Effect.Effect<void, never, R>
}
```

### Параметры

Передайте параметры, используя объектную форму записи в `opencode.json(c)`.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

Параметры читаются из `ctx.options`. Прежде чем использовать значения неизвестного типа, сузьте их тип.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## Преобразования

Преобразования синхронно изменяют состояние через редактор. В пределах каждого домена OpenCode применяет преобразования
в порядке регистрации. Сначала источники добавляют провайдеров и неизменяемые определения моделей, затем преобразования
моделей изменяют кандидатов активных провайдеров. Если выполнить `yield*` для регистрации, она остается привязанной к
Scope плагина.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

Преобразование моделей может применять политику ко всему набору кандидатов активных провайдеров.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

Если внешнее состояние, которое использует преобразование, изменилось, вызовите `reload`. В этом примере
`loadFromSource()` возвращает записи вида `{ info: Provider.Info, models: readonly Model.Info[] }`; перезагрузка
провайдеров также делает недействительным весь результат для моделей.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### Агенты

Получите всех агентов или одного по ID. Ответы клиента содержат разрешенное расположение и данные схемы.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

Преобразование и перезагрузка агентов.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Схема: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Провайдеры

Получите список доступных провайдеров или метаданные одного провайдера по ID.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

Преобразования провайдеров изменяют настройки провайдеров и определения источников. При чтении через редактор видны и
неактивные провайдеры, а определения доступны только для чтения; `models.update` изменяет собственную копию модели из
источника.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

Замените набор моделей источника с помощью `models.set`, а после изменения захваченных им определений выполните
перезагрузку.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

Если набор моделей зависит от аккаунта, передайте подключение, через которое он загружен, в `sourceConnection`. Пока
выбрано другое подключение, OpenCode исключает этого провайдера — до тех пор, пока ваш плагин не опубликует
обновленный набор моделей.

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

Схемы: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Модели

Получите доступные модели и выбор по умолчанию.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

Преобразования моделей изменяют весь набор кандидатов активных провайдеров. Отключенные кандидаты остаются доступными
для изменения, пока не завершатся все преобразования; `update` может добавить модель только к доступному провайдеру.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

Колбэки изменяют необработанные переопределения моделей. Значения по умолчанию провайдера объединяются с ними один раз,
когда OpenCode фиксирует результат; повторные чтения без изменений используют этот результат. `editor.provider` читает
неизменяемые определения источников, включая неактивные шаблоны, а не результат преобразований моделей.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Схема: [`Model.Info`](/api#schema-Model.Info).

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Команды

Получите команды, доступные в текущем расположении.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

Сейчас преобразование команд позволяет только добавлять их. Исполнитель получает сессию, вложения промпта и режим
доставки.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Схемы: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID
  readonly prompt: PromptInput.Prompt
  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Интеграции

Получите интеграции и активные учетные данные, если они есть.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

Подключитесь с помощью ключа или проведите авторизацию OAuth через подключенный API.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

Преобразование интеграций и методов аутентификации. Колбэки методов OAuth — это Effect, и они могут захватывать
ресурсы, привязанные к Scope.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

Схемы: [`Integration.Info`](/api#schema-Integration.Info), [`Integration.Method`](/api#schema-Integration.Method),
[`Connection.Info`](/api#schema-Connection.Info), [`Form.Answer`](/api#schema-Form.Answer).

```ts
type IntegrationOAuthAuthorization = {
  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number
} & (
  | { readonly mode: "auto"; readonly callback: Effect.Effect<Credential.OAuth, unknown> }
  | { readonly mode: "code"; readonly callback: (code: string) => Effect.Effect<Credential.OAuth, unknown> }
)

type IntegrationOAuthMethodRegistration = {
  readonly integrationID: string
  readonly method: IntegrationOAuthMethod
  readonly authorize: (answer: Form.Answer) => Effect.Effect<IntegrationOAuthAuthorization, unknown, Scope.Scope>
  readonly refresh?: (credential: Credential.OAuth) => Effect.Effect<Credential.OAuth, unknown>
  readonly label?: (credential: Credential.OAuth) => string | undefined
}

interface IntegrationEditor {
  list(): readonly IntegrationRef[]
  get(id: string): IntegrationRef | undefined
  update(id: string, update: (integration: IntegrationRef) => void): void
  remove(id: string): void
  readonly method: {
    list(integrationID: string): readonly IntegrationMethod[]
    update(input: IntegrationMethodRegistration): void
    remove(integrationID: string, method: IntegrationMethod): void
  }
}

interface IntegrationDomain extends Omit<IntegrationApi<unknown>, "wellknown"> {
  readonly transform: Transform<IntegrationEditor>
  readonly reload: () => Effect.Effect<void>
  readonly connection: {
    readonly active: (integrationID: string) => Effect.Effect<ConnectionInfo | undefined>
    readonly resolve: (connection: ConnectionInfo) => Effect.Effect<Credential.Value | undefined, unknown>
  }
}
```

### MCP

Получите список MCP-серверов и их текущее состояние подключения.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

Плагины управляют MCP-серверами только через преобразования. `editor.set` добавляет или заменяет сервер,
`editor.update` изменяет его конфигурацию, а `editor.remove` удаляет его. Посмотреть конфигурацию можно через
`editor.list` и `editor.get`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
      editor.set("docs", { type: "remote", url: "https://mcp.example.com" })
      editor.update("docs", (server) => (server.disabled = false))
      editor.remove("legacy")
    })
  }),
```

Задайте в преобразовании `disabled: true`, чтобы отключить сервер и разорвать соединение с ним, или `disabled: false`,
чтобы включить его и разрешить OpenCode подключиться. OpenCode приводит жизненный цикл серверов в соответствие с
преобразованной конфигурацией.

Если внешнее состояние, которое использует преобразование, изменилось, вызовите `reload()`: преобразования будут
применены заново, а состояние серверов — синхронизировано.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.reload()
  }),
```

Схемы: [`Mcp.Server`](/api#schema-Mcp.Server), [`Mcp.LocalConfigEncoded`](/api#schema-Mcp.LocalConfigEncoded),
[`Mcp.RemoteConfigEncoded`](/api#schema-Mcp.RemoteConfigEncoded).

```ts

  list(): readonly [string, Types.DeepMutable<Mcp.ServerConfig>][]
```

### Инструменты

Регистрируйте типизированные инструменты с помощью Effect `Schema`. Исполнитель получает декодированные входные данные
и возвращает Effect с типизированным результатом, отображаемым содержимым или метаданными.

Редактор поддерживает `add`, `update` и `remove`. Колбэк преобразования синхронный: он не должен возвращать Effect или
Promise. Загружайте внешние данные до регистрации или перезагрузки. OpenCode повторно применяет активные преобразования
к новому редактору в порядке регистрации; если итоговое имя инструмента совпадает, более поздняя корректная регистрация
переопределяет более раннюю.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

После изменения исходных данных, захваченных колбэком, вызовите `yield* ctx.tool.reload()`. Перезагрузка повторно
применяет активные преобразования, не меняя их порядок, но не перезапускает Effect плагина.

У инструментов есть поле `id` с итоговым именем, а `get()` возвращает `undefined`, если такого ID нет. В `update` и
`remove` указывайте итоговое имя инструмента вместе с пространством имен (`acme_greeting` в примере выше). Точки в
пространствах имен и недопустимые символы в именах инструментов заменяются на `_`. Отсутствующие имена игнорируются;
чтобы создать инструмент, вызовите `add` с полным определением. Обновления сохраняют имя и пространство имен. Чтобы
заменить схемы или параметры, присваивайте новые значения, а не изменяйте вложенные. Некорректные обновления
записываются в лог, а предыдущее определение остается без изменений.

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

Обновления и удаления воспроизводятся по порядку вместе с добавлениями, в том числе после обновления каталога MCP.

`transform` возвращает регистрацию, привязанную к Scope. Выполните `yield* registration.dispose`, чтобы удалить ее
преобразование и пересобрать состояние из оставшихся преобразований; при этом снова станет видно определение, которое
оно переопределяло. Повторное освобождение безопасно, а закрытие Scope плагина тоже освобождает его регистрации.

Каждый запрос к модели захватывает снимок инструментов. Перезагрузка и освобождение влияют на будущие снимки, но не на
определения и исполнителей, уже захваченных текущим запросом. Исполнители, замыкающие изменяемые данные плагина, по-прежнему
видят эти данные; если значение должно оставаться связанным с конкретным определением, захватите его внутри
преобразования.

Схемы: [`Tool.Content`](/api#schema-Tool.Content), [`Tool.TextContent`](/api#schema-Tool.TextContent),
[`Tool.FileContent`](/api#schema-Tool.FileContent).

```ts

  list(): readonly (Tool.Info & { readonly id: string })[]
  get(id: string): (Tool.Info & { readonly id: string }) | undefined
  namespace(namespace: { name: string; description: string }): void
  add<Input extends Tool.ValueSchema<any>, Output extends Tool.ValueSchema<any> | undefined>(
    tool: Tool.Info<Input, Output>,
  ): void
  update(id: string, update: (tool: Types.Mutable<Tool.Info>) => void): void
```

Получите сведения о репозитории, состояние рабочей копии или diff файлов.

```ts
    yield* Effect.logInfo("vcs", { branch: info.data.branch.current, files: changes.data.length })
  }),
```

Зарегистрируйте провайдера, привязанного к расположению, через преобразование, привязанное к Scope. Провайдеры,
соответствующие обнаруженному типу репозитория, выбираются автоматически; чтобы выбрать другого провайдера,
используйте `editor.default.set`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",

        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

Колбэки провайдера получают текущее расположение, корень рабочей копии, канонический корень проекта и, если есть,
хранилище репозитория. Колбэки diff также получают выбранный режим, запрошенный контекст и лимит размера вывода в
байтах. Для обнаружения репозиториев по-прежнему используются встроенные детекторы Git и Mercurial в OpenCode.

Провайдеры могут дополнительно реализовать `init(scope)`, чтобы создать репозиторий в `scope.worktree`. При
инициализации провайдер выбирается по ID (по умолчанию Git), а не по обнаруженному типу репозитория. Регистрируйте
провайдера с `init`, даже если в расположении еще нет репозитория: перед вызовом OpenCode проверяет, что каталог
существует и репозитория в нем нет, а затем заново обнаруживает проект. Для новых форматов репозиториев одного этого
колбэка недостаточно — им по-прежнему нужна поддержка обнаружения.

## Хуки

Хуки перехватывают операции во время их выполнения. Один и тот же хук могут зарегистрировать несколько плагинов;
OpenCode запускает их в порядке плагинов, поэтому более поздние хуки видят изменения, внесенные ранними. Регистрации
действуют, пока открыт Scope плагина.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", () => Effect.void)
  }),
```

### Сессии

Изменяйте собранные системные инструкции, сообщения или инструменты непосредственно перед отправкой модели. `context`
выполняется для цикла агента, а `compaction`, `generate` и `title` — для соответствующих вспомогательных запросов.
`compaction` и `title` принимают `result`, при наличии которого вызов модели пропускается.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

Изменяйте настройки запроса к модели и при необходимости ограничивайте хук одним провайдером. Событие содержит тот же
`kind`, что и описанные ниже HTTP-хуки.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

Изменяйте нативные запросы к провайдеру или его ответы. Их тела — одноразовые потоки, поэтому перед чтением тело нужно
клонировать или заменить. Оба хука выполняются для каждого запроса сессии; `event.kind` принимает значение
`"primary"`, `"compaction"`, `"title"` или `"generate"` в зависимости от того, какой процесс отправил запрос.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

Провайдеры, которые передают поток через WebSocket, используют одно соединение на сессию, поэтому HTTP-хуки этот
трафик не видят. Экспериментальный хук `experimental.ws.handshake` выполняется один раз на каждый вызов модели до выбора
соединения и предоставляет `url` и `headers` соединения; изменение любого из них переоткрывает сокет. HTTP-хуки
по-прежнему выполняются для всех запросов, на которые маршрут WebSocket переключается в качестве резервного варианта.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` и `experimental.ws.receive` дают доступ к самим фреймам: `send` выполняется после того, как
драйвер провайдера сформировал исходящий фрейм, а `receive` — для каждого входящего фрейма до того, как его увидит
драйвер. Именно то, что находится в `frame` в момент возврата из хука, уходит в сеть или передается драйверу; OpenCode
это значение не проверяет.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

Переопределите решение о повторной попытке после сбоя провайдера или замените задержку в миллисекундах. Хук
выполняется после того, как OpenCode классифицировал сбой и предложил политику, но до планирования повторной попытки.
Как именно OpenCode выполняет следующую попытку внутри, хук не раскрывает.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

Начальное значение `decision` — это политика OpenCode, поэтому хуки могут сделать повторяемым сбой провайдера, который
обычно считается окончательным, или запретить предложенную повторную попытку. Несколько хуков выполняются в порядке
регистрации, и более поздние видят текущее решение. Встроенное максимальное число попыток остается жестким
ограничением. `attempt` — номер предлагаемой физической попытки: исходный запрос — это попытка `1`, значит, первая
повторная попытка — `2`. При некорректной задержке (`NaN`, бесконечность или отрицательное значение) используется
вычисленная задержка. Восстановление после переполнения контекста работает отдельно, потому что оно сжимает диалог, а
не повторяет тот же запрос.

### Оболочка

Изменяйте команды оболочки, рабочие каталоги, тайм-ауты, исполняемые файлы или переменные окружения перед выполнением.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const shell = ctx.shell
    yield* shell.hook("create.before", (event) =>
      Effect.sync(() => {
        if (event.command === "npm") event.command = "bun"
        event.timeout = Math.min(event.timeout, 60_000)
        event.env.COMPANY_ENV = "development"
      }),
    )
  }),
```

### Инструменты

Хуки `execute.before` могут заменить входные данные или завершиться ошибкой `Tool.Error`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

Хуки `execute.after` могут проверить или заменить как успешные результаты, так и сбои.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

#### Справочник

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
}

interface ToolFailures extends Record<keyof ToolHooks, unknown> {
  readonly "execute.before": Tool.Error
  readonly "execute.after": never
}

interface ToolHookDomain {
  readonly hook: Hooks<ToolHooks, ToolFailures>

```

Общие типы регистраций показывают, каким операциям нужен Scope плагина.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## Публикация

Плагин в виде пакета использует тот же экспорт по умолчанию, что и локальный Effect-плагин. Экспортируйте реализацию
на Effect из основной точки входа и объявите `effect` в `peerDependency`.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

OpenCode перенаправляет импорты `effect`, экспортируемых подпутей `effect/*` и `@opencode/plugin` (включая импорты из
зависимостей в `node_modules` плагина) на экземпляры среды выполнения хоста, чтобы файберы, логгеры и парсеры `Schema`
использовали одну копию среды выполнения.

- Не включайте `effect` в сборку публикуемого плагина. Если вы используете сборщик, пометьте `effect` и `effect/*` как
  external.
- Плагины и их зависимости из `node_modules` всегда выполняются с экземпляром `effect` из той версии OpenCode, в которой
  они запущены. Используйте API и пути модулей `effect`, совместимые с целевой версией OpenCode; зависимости, собранные
  под другую мажорную версию `effect` (например, Effect 3), тоже получат `effect` хоста и не поддерживаются.
- Доступны только публичные подпути `effect`. Плагин, импортирующий один из внутренних модулей `internal` Effect, не
  загрузится, а в ошибке будет указан путь.
- Скомпилированный бинарный файл OpenCode не содержит ресурсов Scalar и Swagger UI, которые используются страницами
  документации HTTP API в Effect; если отдавать такие страницы из плагина, вместо них отображается уведомление.

Точка входа пакета экспортирует `Plugin.define` с функцией `effect`.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

Используйте версии, совместимые с целевой версией OpenCode, и тестируйте установленный пакет, а не только копию,
связанную через рабочее пространство.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
