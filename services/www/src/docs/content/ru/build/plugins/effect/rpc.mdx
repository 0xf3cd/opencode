title: "RPC"
---

Effect-плагины могут предоставлять методы и события, которые возвращают типизированные Effect и Stream.

## Определение

Определите RPC с помощью `Rpc.define` и Effect Schema.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Валидация

Effect Schema проверяет значения и выводит их типы TypeScript.

```ts
input: Schema.Struct({ query: Schema.String })
```

Поддерживаются также JSON Schema и Standard Schema.

### Входные и выходные данные

`input` описывает аргумент метода, а `output` — возвращаемое значение. Если значения нет, соответствующее поле можно
не указывать.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Ошибки

Перечислите ожидаемые сбои в `errors`. Каждый ключ становится значением `type` ошибки.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### События

Добавьте события в карту `events` верхнего уровня. Данные события должны быть объектом.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Реализация

Зарегистрируйте реализацию в Effect плагина:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Карта ошибок становится типом ошибки Effect каждого метода. Чтобы создать объявленную ошибку, используйте
`context.error(...)`.

## Вызов

После регистрации RPC можно вызывать по HTTP или из другого плагина.

### HTTP

Создайте Effect-клиент, а затем подклиент RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Плагин

Другой Effect-плагин может создать локальный подклиент из своего контекста:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Подписка

События RPC — это Stream. Подпишитесь по имени события и запустите Stream в файбере, привязанном к Scope:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Подписки работают только в реальном времени и закрываются, когда чтение Stream прекращается.
