OpenCode 是開源的 AI 程式設計代理，提供終端機介面、桌面應用程式和網頁應用程式三種使用方式。

npm 套件會透過 postinstall 指令碼，為你的平台選擇對應的原生 `opencode` 執行檔。上方的 Bun 和 pnpm 指令已明確允許執行這個必要的指令碼；Vite+ 則不需要額外的旗標。mise 指令需要 mise 2026.10.9 或更新版本；較舊的版本會安裝 OpenCode 1。

不支援 Windows 套件管理員。


下載適用於你平台的獨立 CLI 執行檔。

- **macOS：** [Apple 晶片](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)

- **Linux (glibc)：** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## 網頁版

使用 `opencode pair` 指令開啟 OpenCode 網頁介面。

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker 映像檔使用帶有版本號的標籤，例如 `ghcr.io/anomalyco/opencode:2.0.0`。

## 連線

OpenCode 內建支援許多 LLM 供應商，你可以直接[在 TUI 中](/cli/providers)使用 `/connect` 連線。

若要設定自訂供應商，請參閱[供應商](/providers)。

如果想輕鬆使用各家最好的程式設計模型，可以試試 [OpenCode Console](/console)。

你也可以試試 [OpenCode Go](/console/go)：這是每月 $10 的訂閱方案，讓你使用最優秀的開源模型。

## 自訂

你可以編輯 [OpenCode 設定](/config)、[載入外掛](/plugins)、[連接 MCP 伺服器](/mcp-servers)或[建立指令](/commands)，打造專屬於你的 OpenCode。終端機介面的主題和快速鍵，請參閱 [CLI 偏好設定](/cli/config)。
