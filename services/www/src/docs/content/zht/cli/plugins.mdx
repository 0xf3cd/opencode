---
title: "外掛"
---

在 `opencode.json(c)` 中設定、且提供 TUI 元件的外掛，會由 CLI 自動載入。若要了解如何開發外掛，請參閱[開發外掛](/build/plugins)。你不需要再將同一個套件加入 `cli.json`。CLI 會從所連線的 OpenCode 伺服器取得啟用中的外掛清單，因此即使伺服器在遠端也能正常運作。

僅供 CLI 使用的外掛請寫在 `cli.json` 中。這些外掛會在終端機本機執行，即使 CLI 連線到遠端伺服器，也會保持啟用：

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

項目會依序處理。在 ID 或萬用字元前面加上 `-`，即可停用符合的外掛：

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

使用物件形式傳入外掛選項：

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode 也會在全域設定目錄和專案的 `.opencode` 目錄中尋找外掛。每個外掛都使用與已發布套件相同的結構，伺服器和 TUI 的進入點放在一起。

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

找到的外掛可以直接匯入 `@opencode/plugin/tui`；OpenCode 會在執行時解析這個套件。範例請參閱[開發 CLI 外掛](/build/plugins/cli)。
