title: "快速鍵"
---

在 `cli.json` 中自訂快速鍵綁定：

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

單一按鍵使用字串：

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

多個替代按鍵以逗號分隔：

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

使用 `"none"` 或 `false` 停用綁定：

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

需要設定事件行為時使用物件：

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` 預設為 `ctrl+x`。其他綁定中的 `<leader>` 就是指這個按鍵。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

未知的指令 ID 會被拒絕。

## Mini

`app.clear` 指令只能在 [`opencode mini`](/cli) 中使用。按 `ctrl+l` 會清除目前可見的畫面，並重新繪製提示詞。終端機會保留捲動緩衝區。

{
  "keybinds": {
    "app.clear": "ctrl+l"
  }

## 差異檢視器

按 `d`（`diff.switch_source`）可以選擇 **All**、**Committed**、**Uncommitted** 或 **Last turn**（僅限工作階段中），或選擇 **Base** 變更要比較的分支。這些選擇會保留到 TUI 結束為止。若要設定初始範圍，請使用 [`cli.json` 中的 `diffs.source`](/cli/config#diffs)。

捲動、翻頁和跳至開頭／結尾的快速鍵一律控制差異內容。沒有切換鍵盤焦點的按鍵：按一下檔案即可開啟，按一下資料夾即可展開或收合，並使用滑鼠滾輪捲動檔案樹。

使用 `n` / `p` 或 `alt+down` / `alt+up`（macOS 上為 Option 鍵）在檔案之間移動。在差異檢視器中，Alt 快速鍵會切換檔案，而不是工作階段分頁。

按 `m` 可以將檔案標記為已審查，並收合它的修補內容。在所有檔案檢視中，再按一次 `m` 會取消標記並重新展開修補內容。在單一檔案檢視中，標記為已審查後會自動前往下一個檔案，但到了最後一個檔案就會停留，不會繞回開頭。取消標記則永遠不會前往下一個檔案。

在側邊欄的檔案或其差異標題上按一下滑鼠右鍵，即可選擇 **Mark complete**（或 **Mark incomplete**）。這和 `m` 變更的是同一個已審查狀態。從選單將其他檔案標記為完成時，不會選取該檔案，也不會讓目前正在閱讀的檔案前進。

`diff.help` 中加上 Shift 的替代按鍵，是為了支援按下 `?` 時會回報 Shift 修飾鍵的終端機。

在 **Shell** 分頁中選取正在執行的指令並按 **Enter**，或直接按一下該指令，即可檢視擷取到的 stdout 和 stderr。使用 **↑/↓**、**Page Up/Down** 或 **Home** 捲動，按 **End** 跟隨新的輸出，按 **Esc** 返回，且不會停止指令。檢視器會顯示最近的輸出，指令結束後仍會保持開啟；重新導向到檔案的輸出不會包含在內。
