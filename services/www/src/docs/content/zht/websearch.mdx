---
title: "網頁搜尋"
---

向 OpenCode 詢問最新資訊時，它可以搜尋網路、閱讀搜尋結果，並在回應中附上來源連結。

```text
Find the latest Bun release and summarize the changes.
```

第一次搜尋時，OpenCode 會請你允許網頁搜尋並選擇供應商。之後的工作階段會沿用你的選擇。

## 供應商

OpenCode 內建五個搜尋供應商：

| 供應商 | ID | 環境變數 |
| --- | --- | --- |
| Exa | `exa` | `EXA_API_KEY` |
| Firecrawl | `firecrawl` | `FIRECRAWL_API_KEY` |
| Parallel | `parallel` | `PARALLEL_API_KEY` |
| Tavily | `tavily` | `TAVILY_API_KEY` |
| TinyFish | `tinyfish` | `TINYFISH_API_KEY`（選用） |

在 TUI 中使用 `/connect` 連結帳號，或在啟動 OpenCode 前設定該供應商的環境變數。

```bash
$ TAVILY_API_KEY=your-key opencode
```

## 選擇供應商

在 `opencode.jsonc` 中指定供應商，就不會再出現選擇提示。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "tavily",
  },
}
```

使用 `"random"` 可自動選擇一個可用的供應商。每個工作階段會持續使用所選的供應商，直到該供應商觸發速率限制為止。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "random",
  },
}
```

## 限制

當供應商回傳 HTTP 429 時，隨機選擇模式會改用另一個可用的供應商重試搜尋。觸發速率限制的供應商會等待其 `Retry-After` 指定的時間；如果回應中沒有有效的時間，則等待 60 秒。

```text
Exa returns HTTP 429
→ Exa enters cooldown
→ OpenCode retries with another provider
```

如果所有供應商都在冷卻中，搜尋會立即失敗。移動工作階段或重新啟動其伺服器，會清除該工作階段記住的供應商；冷卻狀態則由同一個工作區中的所有工作階段共用。

## 權限

網頁搜尋使用 `websearch` 權限動作，並以搜尋查詢作為資源。下列設定會在執行未明確允許的搜尋前先詢問你。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "permissions": [
    {
      "action": "websearch",
      "resource": "*",
      "effect": "ask",
    },
  ],
}
```

規則順序與比對方式請參閱[權限](/permissions)。

## 停用

將 `websearch` 設為 `false`，即可從模型請求中移除網頁搜尋工具。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": false,
}
```
