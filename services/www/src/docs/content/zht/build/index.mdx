---
title: "簡介"
---

每天都有數百萬人在使用 OpenCode。你可以在它的基礎上打造自己的應用程式、整合功能和代理體驗，不必從零開始。

我們也為[外掛](/build/plugins/effect)、[用戶端](/build/client/effect)和[內嵌應用程式](/build/sdk/effect)提供 Effect API。

<CardGroup cols={1}>
  <Card title="擴充 OpenCode" href="/build/plugins">
    開發外掛來新增工具、整合功能、指令、代理和自訂行為，同時讓 OpenCode 的其他部分維持原樣。
  </Card>
  <Card title="以伺服器形式執行" href="/build/client">
    使用和 TUI 及桌面應用程式相同的用戶端連線到 OpenCode，再以它為基礎打造任何介面、工作流程或代理體驗。
  </Card>
  <Card title="內嵌使用" href="/build/sdk">
    將 OpenCode 直接內嵌到你的應用程式中，以它為基礎打造完全自訂的代理、介面或開發者產品。
  </Card>
</CardGroup>
