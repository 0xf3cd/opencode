`@opencode/sdk` 讓你直接在應用程式內部託管 OpenCode。與[網路用戶端](/build/client)不同，它會組裝 OpenCode 伺服器，並在記憶體中透過伺服器的 HTTP 路由器處理 API 呼叫。它不會開啟 HTTP 監聽器，用戶端與伺服器之間也不會多出網路跳轉。

如需搭配 Cloudflare Durable Objects 使用，請參閱 [Cloudflare 指南](/build/sdk/cloudflare)。

安裝 SDK：

```sh
bun add @opencode/sdk
```

## 建立主機

`OpenCode.create()` 會回傳一個由你明確擁有的主機。使用 `await using` 來釋放它的路由器、Location 服務、fiber 和具範圍的外掛註冊：

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

如果環境不支援明確資源管理，請自行呼叫 `await opencode.close()`。

內嵌主機使用與 `@opencode/client` 相同的 Promise 值、宣告的錯誤、請求選項和 `AsyncIterable` 串流。它公開完整的產生用戶端，並為工作階段與事件群組額外提供 `sessions` 和 `events` 兩個便利別名。

## Worktree

Worktree 操作需要 `projectID`。建立（create）與重新整理（refresh）會從專案已儲存的標準 checkout 載入設定和外掛。列出（list）只讀取已儲存的清單；移除（remove）會啟用標準 checkout 的外掛並使用記錄的策略，如果該策略無法使用就會失敗。

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

重新整理會使用所有可用的策略，在已知的 checkout 根目錄中探索 worktree。如需自訂策略，請透過[外掛的 worktree 轉換](/build/plugins#worktrees)註冊。

## 串流事件

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

透過產生的請求選項傳入 `AbortSignal`，或跳出迭代來取消其回應主體。

## 自訂

註冊外掛即可自訂你的 OpenCode 執行個體。將外掛傳給 `OpenCode.create()`，就能在內嵌主機啟動時自訂代理、模型、工具和其他行為：

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

啟動後如需再註冊其他外掛，請呼叫 `await opencode.plugin(plugin)`。

外掛 hook、轉換、工具和完整的外掛上下文，請參閱[完整的外掛文件](/build/plugins)。
