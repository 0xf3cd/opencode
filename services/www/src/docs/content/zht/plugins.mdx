---
title: "外掛"
---

將已發布的套件、指定版本的套件、具範圍的套件或本機外掛目錄加入 `opencode.json(c)`。

## 設定

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-plugin",
    "opencode-acme-plugin@1.2.0",
    "@acme/opencode-plugin",
    "./plugins/local",
    "../shared/plugin.ts",
    "/absolute/path/plugin.ts",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/opencode-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

相對路徑會以包含該項目的設定檔為基準解析。各個適用設定檔中的外掛陣列，會依照優先順序由低到高套用，而不是互相取代。

```text
~/.config/opencode/opencode.jsonc
./opencode.jsonc
./.opencode/opencode.jsonc
```

## 探索

OpenCode 也會從每個找到的 `.opencode/plugins/` 目錄中，載入直接放在其中的 `.ts` 和 `.js` 檔案，以及第一層的外掛套件目錄。

```text
.opencode/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

全域外掛在 OpenCode 設定目錄底下使用相同的探索結構。

```text
~/.config/opencode/plugins/
```

位於專案根目錄 `opencode.json(c)` 旁邊的 `plugins/` 目錄不會被自動探索；請明確設定其中的檔案，或將它移到 `.opencode/` 底下。

```jsonc title="opencode.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## 控制

外掛項目會依序處理。在 ID 或萬用字元前面加上 `-` 即可停用，使用 `*` 代表所有外掛，使用 `.*` 比對 ID 前綴。之後再列出的 ID 會重新啟用該外掛。

```jsonc title="opencode.jsonc"
{
  "plugins": ["*", "-opencode.provider.*", "opencode.provider.openai", "-acme.reviewer"]
}
```

有兩個內建外掛會忽略移除設定，讓儲存庫無法關閉[原則](/policies)的強制執行：`opencode.config.policy`，以及負責傳遞組織原則的 Console 連線 `opencode.provider.opencode`。

## 管理

使用 CLI 安裝、列出、檢查、更新或移除全域套件外掛。

```sh
opencode plugin add opencode-acme-plugin@1.2.0
opencode plugin list
opencode plugin list --builtin
opencode plugin check
opencode plugin update
opencode plugin update opencode-acme-plugin
opencode plugin remove opencode-acme-plugin@1.2.0
```

`plugin check` 會檢查伺服器外掛和僅限 TUI 的套件外掛是否有更新。`plugin update` 會更新所有過期的套件；傳入已設定的套件目標，即可只檢查或更新該套件。本機外掛和指定確切版本的套件會被略過。

安裝套件時，可以使用附帶版本、標籤或版本範圍的 npm 名稱，也可以使用與 npm 相容的 Git 套件規格。Git 儲存庫可以使用代管服務的簡寫、HTTPS 或 SSH，包括可透過你現有的 Git 認證資訊存取的私有儲存庫。

```sh
opencode plugin add @acme/opencode-plugin@latest
opencode plugin add github:acme/opencode-plugin
opencode plugin add git+ssh://git@github.com/acme/opencode-plugin.git#main
opencode plugin add 'github:acme/plugins#main::path:packages/opencode-plugin'
```

支援分支、標籤、完整的 commit 雜湊值，以及 npm 用來選擇儲存庫子目錄的 `::path:` 選擇器。本機路徑請直接寫在設定中；`plugin add` 不接受 tarball 和 npm 別名目標。

## 重新載入

受監看的設定目錄中有變更時，會自動重新載入。伺服器啟動時會立即載入已快取的套件外掛、在背景安裝缺少的套件，並檢查未固定版本的 npm 和 Git 外掛是否有更新，但不會變更已安裝的套件。確切的 npm 版本和完整的 Git commit 雜湊值會保持固定。未受監看的本機相依套件發生變更時，可能仍需要重新啟動 OpenCode。

```sh
touch .opencode/plugins/concise/index.ts
opencode service restart
```

## 終端機

僅限 CLI 的外掛需要另外設定，連線到遠端伺服器時仍會保持作用。

```json title="cli.json"
{
  "plugins": ["opencode-acme-cli"]
}
```
