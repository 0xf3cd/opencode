[OpenCode Console](https://opencode.ai/console) 是一項選用服務，無論你是獨自使用還是團隊協作，都能讓 OpenCode 用起來更順手。

- [工作區](/console/workspaces)：與你的[團隊](/console/members)共用存取權
- [推論](/console/models)：同時提供專有模型與開源模型
- [供應商](/console/providers)：透過 Console 閘道連接你自己的供應商帳號
- 用量追蹤與[預算](/console/budgets)控管
- 部署全團隊適用的原則，控管 OpenCode 的行為
- [網頁搜尋](/console/websearch)
- [OpenCode Go 與 Go Plus](/console/go)：每月 $10 和 $40 的訂閱方案，可使用開源模型

## 開始使用

使用 Console 不一定要有團隊。每個帳號一開始都有一個 **Personal** 工作區，而你是其中唯一的成員。

1. 登入 [Console](https://opencode.ai/console)。
2. 訂閱 [Go](/console/go)、加值[額度](/console/billing#add-credits)，或連接[供應商](/console/providers)。
3. 在 OpenCode 中執行 `/connect`，然後選擇工作區。
4. 視需要[邀請](/console/members#invite-members)你的團隊。

```text
/connect
```

## 原則

**Policies** 頁面中的 Providers 與 Tools 規則，會套用到所有連接到該工作區的 OpenCode V2 用戶端。這些規則會以[原則](/policies#console)陳述式的形式下發，對成員自己的設定擁有最終決定權，並在大約一分鐘內生效。
