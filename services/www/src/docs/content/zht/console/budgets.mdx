---
title: "預算"
description: "為工作區、成員和服務帳戶設定每月支出上限。"
---

預算用來限制工作區每個月的支出。擁有者和管理員可以在 **Members** 和 **Keys** 頁面的 **Budget limits** 面板中設定。

## 預算層級

| 預算 | 適用對象 | 設定位置 |
| ----------------------- | ------------------------------------------- | -------------------------------------------------- |
| 工作區 | 工作區內所有人的支出總和 | **Members** 或 **Keys › Monthly workspace budget** |
| 預設使用者 | 每位沒有自訂上限的成員 | **Members › Monthly default user budget** |
| 自訂使用者 | 單一成員 | **Members** 表格或成員頁面 |
| 預設服務帳戶 | 每個沒有自訂上限的服務帳戶 | **Keys › Monthly default service account budget** |
| 自訂服務帳戶 | 單一服務帳戶 | 服務帳戶頁面 |

請求必須同時在工作區預算和個人預算的範圍內。沒有設定任何預算時，支出不受限制。

## 工作區預算

工作區達到工作區預算後，所有人的請求都會被封鎖。

1. 開啟 **Members** 或 **Keys**。
2. 在 **Budget limits** 中按一下 **Monthly workspace budget**。
3. 以美元輸入 **Workspace limit**，然後按一下 **Save**。

## 成員預算

預設使用者預算適用於每位沒有自訂上限的成員。請在 **Monthly default user budget** 中設定。

你可以從下列任一處為單一成員設定自訂上限：

- 按一下該成員在 **Members** 中那一列的 **Limit** 儲存格，然後輸入金額。
- 開啟該成員，在 **Monthly Budget** 底下按一下 **Set User Budget**。

自訂上限會在 Members 表格中醒目標示。清除自訂上限即可讓成員恢復使用預設值，成員頁面隨即會顯示 **Using Default**。

## 服務帳戶預算

服務帳戶的運作方式相同。在 **Keys** 頁面設定 **Monthly default service account budget**，或開啟服務帳戶後按一下 **Set Service Account Budget**。

## 金額與重設

- 金額以美元計算，最多兩位小數。
- 預算會在每月 1 日 00:00 UTC 重設。
- `$0` 的預算會封鎖所有計入預算的支出。

## 計入的支出

| 支出 | 是否計入預算 |
| ------------------------------------------------------------------- | ---------------------------- |
| 付費的 Console 模型 | 是 |
| [你自己的供應商](/console/providers)中已設定價格的模型 | 是，依設定的價格計算 |
| [網頁搜尋](/console/websearch) | 是 |
| 免費模型 | 否 |
| 方案內的 [Go](/console/go) 用量 | 否 |
| 從額度支付的 Go 額外用量 | 是 |

## 達到預算時

在預算重設或管理員調高預算之前，新的請求都會以 HTTP `429` 失敗。回應中不會說明達到的是哪一個預算。

```text
Upstream request failed: Account budget exceeded
```

預算會在請求開始時檢查。已在進行中的請求仍會完成，因此支出最後可能會略高於上限。

## 追蹤支出

每位成員都可以在 **Overview** 中查看自己的預算：剩餘金額、已支出金額和重設日期。

成員超過一位的工作區，其擁有者和管理員還能看到 **Usage**。它會依日期、模型和人員細分費用，**Export usage** 按鈕則可將過去 7、30 或 90 天的每日總計下載為 CSV。

## 自動化預算

使用 [Budgets API](/console/api/budgets)，即可從你自己的工具讀取每位成員的預算並設定自訂上限。
