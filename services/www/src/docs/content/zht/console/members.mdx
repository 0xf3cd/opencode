title: "成員"

擁有者和管理員在 **Members** 頁面管理人員。每一列會顯示成員的角色、加入日期、每月用量和預算上限。

## 邀請成員

1. 開啟 **Members**，然後按一下 **Invite Members**。
2. 加入一或多個電子郵件地址。可以用空格、逗號或分號分隔，也可以直接貼上清單。
3. 按一下 **Send invitations**。

每個人都會收到一封標題為 **Join Acme Inc. on OpenCode** 的電子郵件，裡面有 **Join workspace** 按鈕。

邀請會在 7 天後到期。所有人都以 **Member** 身分加入；他們加入後，你可以再[變更角色](#change-a-role)。

<Callout>
  已訂閱 [OpenCode Go](/console/go) 的工作區無法邀請成員。請為你的團隊另外建立一個工作區。
</Callout>

成員也可以自動加入：

- [SSO](/console/sso#automatic-membership) 會在使用你已驗證電子郵件網域的人首次登入時，將他們加入工作區。
- [目錄同步](/console/scim)會依照你在身分識別提供者中的指派，新增或移除成員。

## 接受邀請

受邀者必須使用收到邀請的電子郵件地址登入。接受邀請的方式有兩種：

- 按一下邀請郵件中的 **Join workspace**，然後登入或建立帳號。
- 登入 Console，開啟工作區選單，然後在 **Pending invitations** 底下按一下 **Join**。

如果受邀者目前登入的是其他帳號，Console 會要求他們 **Sign out and continue**，改用受邀的電子郵件繼續。

## 管理待處理的邀請

待處理的邀請會出現在 Members 表格中，顯示為 **Pending · Expires** 加上日期，或顯示為 **Expired**。

| 動作 | 方式 |
| ------ | ----------------------------------------------------------------------------------------- |
| 重新傳送 | **⋯ › Resend invitation**。傳送一個 7 天內有效的新連結，舊連結隨即失效。 |
| 撤銷 | **⋯ › Remove...**。連結會立即失效。 |

## 變更角色

開啟成員那一列的角色選單，然後選擇 **Member**、**Admin** 或 **Owner**。

你只能授予不高於自己的角色，而且工作區一律至少保留一位擁有者。請參閱[角色](/console/workspaces#roles)。

## 移除成員

1. 在成員那一列按一下 **⋯ › Remove...**。
2. 按一下 **Remove member** 確認。

存取權會立即撤銷，之後你仍可以再次邀請對方。對方過去的用量會保留在工作區的報告中。

服務帳戶及其 API 金鑰屬於工作區，因此移除建立它們的成員並不會撤銷它們。如有需要，請在 **Keys** 中撤銷金鑰。請參閱[服務帳戶](/console/api#service-accounts)。

## 成員詳細資料

按一下成員即可查看他們的每月預算、使用的模型和用戶端、用量圖表以及請求紀錄。你可以在這裡設定他們的[預算](/console/budgets#member-budgets)，並將他們的用量匯出為 CSV。
