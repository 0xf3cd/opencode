description: "在 OpenCode Console 中加值額度、設定自動加值、管理付款方式及下載發票。"

無論團隊規模大小，Console 都是免費的，也不收席位費。你只需要為用量付費，費用從涵蓋整個工作區的預付額度中扣除。擁有者和管理員在 **Settings › Billing** 中管理計費。

透過[你自己的供應商](/console/providers)產生的用量，由供應商計費，而不是由 Console 計費。

## 新增付款方式

1. 開啟 **Settings › Billing**。
2. 在 **Payment methods** 底下按一下 **Add**。
3. 選擇付款方式，並完成 Stripe 設定。

支援的付款方式：

- 信用卡
- Link
- 支付寶（Alipay）
- UPI
- 微信支付（WeChat Pay）

使用 **⋯ › Make default** 選擇用於自動扣款的付款方式。移除付款方式可能會停止使用該方式的自動加值和 Go 續訂。

## 加值額度

1. 在 **Credits** 底下按一下 **Add credits**。
2. 選擇 $10、$50 或 $100，或選擇 **Other** 並輸入金額。
3. 選擇付款方式，然後按一下 **Confirm and pay**。

另外會加收 4.6% + $0.31 的手續費，因此購買 $50 的費用為 $52.61，而完整的 $50 都會加入餘額。

## 自動加值

自動加值會在餘額不足時購買額度。

1. 在 **Auto-recharge** 底下按一下 **Add rule**。
2. 設定觸發扣款的餘額，以及要加值的金額。
3. 按一下 **Save**。

自動加值會從預設付款方式扣款，並包含手續費。如果扣款失敗，自動加值會關閉，直到你重新設定為止。

## 查看餘額

擁有者和管理員可以在 **Overview** 的 **Credits** 卡片中查看餘額。

## 額度用完時

餘額歸零後，付費請求會以 HTTP `402` 失敗。餘額永遠不會變成負數。

```text
Upstream request failed: Insufficient account funds
```

## 發票

每筆付款都會出現在 **Invoices** 底下，並顯示狀態，以及 **Download invoice** 或 **View receipt** 連結。

| 項目 | 產生來源 |
| ---------------- | ------------------ |
| Balance top-up | 加值額度 |
| Automatic top-up | 自動加值 |
| Go subscription | 訂閱 Go |
| Go renewal | 每月 Go 續訂 |
| Monthly Usage | 發票計費 |

## 發票計費

已簽訂信用協議的工作區可以改為按月開立發票，不必預先購買額度。如需設定，請聯絡支援團隊。

- 用量會從信用額度中扣除，而不是從預付餘額中扣除。
- 每個月的發票會在 1 日（UTC）開立，並於 14 天後到期。
- 未付款的發票會有 **Pay now** 按鈕。
- 達到信用額度或發票逾期時，請求會以 HTTP `402` 失敗。

## Go

[OpenCode Go](/console/go) 訂閱使用相同的付款方式，並會出現在同一份發票清單中。在 **Overview** 的額度卡片上開啟 **Extra usage**，即可在達到 Go 上限後改從額度支付。
