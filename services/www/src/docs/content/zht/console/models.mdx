OpenCode Console 提供一份經過 OpenCode 團隊測試與驗證的模型清單。登入、加值額度並取得 API 金鑰後，就能在 OpenCode 或其他程式設計代理中使用這些模型。

Console 在 OpenCode 中的運作方式和其他供應商一樣。它**完全是選用的**，你也可以改用其他任何供應商。如果想要內含用量的訂閱方案，請參閱 [OpenCode Go](/console/go)。

## 運作方式

1. 登入 [Console](https://opencode.ai/console)，加入帳單資訊和額度，然後複製你的 API 金鑰。
2. 在 TUI 中執行 `/connect`，選擇 OpenCode 按用量計費的供應商，然後貼上你的 API 金鑰。

   ```text
   /connect
   ```

3. 執行 `/models` 查看可用的模型並選擇一個。

   ```text
   /models
   ```

費用按請求計算，你可以為帳號加值額度。

### Jev

Jev 是 TypeSafe AI 推出的 System One 模型，專門用來快速做出結構化的判斷。它不會產生文字，而是根據具型別的問題評估 `state`，並回傳程式可以直接使用的值與機率。它支援是非題（`noul`）、選擇題（`choice`）和依評分標準評分（`score`）的問題。

搭配 `https://opencode.ai/inference/v1/systemone` 端點使用你的 OpenCode Console API 金鑰。下面的範例會判斷一則客服請求是否緊急：

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

你可以在一個請求中提出多個問題。Jev 會平行評估這些問題，並將每個答案放在對應的問題 ID 底下回傳：

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

將 `jev-1.13` 換成 `jev-1.13-free`，即可使用限時免費的模型。問題類型和回應欄位的詳細資訊，請參閱 [TypeSafe AI 文件](https://docs.typesafe.ai/)。

## 背景

可用的模型很多，但真正適合當作程式設計代理的只有少數幾個。各家供應商的設定、效能和品質也不盡相同，因此透過 OpenRouter 這類閘道存取的模型，表現可能會有所不同。

<Callout type="tip">我們測試了一批與 OpenCode 搭配良好的精選模型和供應商。</Callout>

為了建立這份清單，我們：

1. 測試了一批精選模型，並與各模型團隊討論如何以最佳方式執行。
2. 與供應商合作，確保模型以正確的方式提供服務。
3. 對每一組模型與供應商的組合進行基準測試，整理出一份我們有信心推薦的清單。

Console 是一個 AI 閘道，讓你能夠存取這些模型。

## 目標

我們打造 Console 的目的是：

1. 為程式設計代理**基準測試**最好的模型和供應商。
2. 提供**最高品質**的選項，不降低效能，也不會轉送到更便宜的供應商。
3. 以成本價販售，只加收足以支付手續費的費用，把**降價**直接回饋給你。
4. **沒有綁定**：你可以在任何程式設計代理中使用 Console，也可以在 OpenCode 中使用其他供應商。
