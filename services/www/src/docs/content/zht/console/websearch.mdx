---
title: "網頁搜尋"
description: "透過 Console 為 OpenCode 提供代管的網頁搜尋。"
---

Console 為已連線的 OpenCode v2 使用者提供代管的網頁搜尋。工作區擁有者或管理員只要為工作區啟用一次即可，不必另外發給成員搜尋供應商的金鑰。

每次成功的搜尋費用為 **$0.01**，會從工作區餘額扣除，並計入成員的支出上限。

## 啟用

1. 以工作區擁有者或管理員身分登入 [Console](https://opencode.ai/console)。
2. 開啟 **Settings** > **General**。
3. 開啟 **Hosted web search**。

接著，每位成員使用 `/connect` 將 OpenCode 連接到工作區。

```text
/connect
```

OpenCode 會從工作區的受管理設定載入 **OpenCode Web Search**。成員不需要設定 `websearch.provider`，也不需要加入供應商 API 金鑰。

## 搜尋

在提示詞中請 OpenCode 查詢最新資訊即可。搜尋是由 OpenCode 執行，而不是在 Console 的互動頁面中進行。

```text
Find the latest Bun release and summarize the changes with source links.
```

代管的供應商會搜尋公開網路，最多回傳八筆結果。OpenCode 會根據這些結果回答提示詞並引用來源。

若要設定權限或停用這個工具，請參閱[網頁搜尋指南](/websearch)。

## 計費

搜尋回傳有效的結果集之後，Console 才會收取 **$0.01**。失敗或受到速率限制的搜尋不收費。

在 **Usage**、**My Activity**、成員活動、發票和 CSV 匯出中，網頁搜尋都會和模型用量分開列出。工作區與成員的每月支出上限都包含網頁搜尋費用。

## 隱私

代管的網頁搜尋不保留任何資料。Console 及其代管搜尋供應商處理每次查詢和結果時，都不會儲存其內容。
