---
title: "推論 API"
description: "只需一個驗證標頭，即可透過 Console 推論呼叫與 OpenAI、Anthropic 和 Gemini 相容的模型。"
---

Console 推論從 `https://opencode.ai/inference` 提供與 OpenAI、Anthropic 和 Gemini 相容的 API。請向符合模型 API 系列的端點傳送 JSON `POST` 請求。

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.6",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## 身分驗證

將 `<token>` 換成在 [Console](https://opencode.ai/console) 中建立的[服務帳戶金鑰](/console/api#service-accounts)。付費模型必須提供此標頭；免費的聊天模型則可以不帶標頭呼叫。

```text
Authorization: Bearer <token>
```

## 端點

| API | 路徑 |
| ----------------------- | --------------------------------------------------------- |
| OpenAI Chat Completions | `/inference/openai/v1/chat/completions` |
| OpenAI Responses | `/inference/openai/v1/responses` |
| Anthropic Messages | `/inference/anthropic/v1/messages` |
| Gemini | `/inference/google/v1beta/models/<model>:generateContent` |

每個模型都只由一個 API 系列提供。請參閱[模型端點](/console/models#endpoints)表格，或取得即時清單：

```bash
curl https://opencode.ai/inference/v1/models
```

### OpenAI Chat Completions

`kimi-k2.6`、`glm-5.1`、`minimax-m2.7` 等開放式模型以及免費模型，都使用 Chat Completions API。

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.1",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### OpenAI Responses

GPT 模型使用 Responses API。

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hi"
  }'
```

### Anthropic Messages

Claude 和 Qwen 模型使用 Messages API。`max_tokens` 為必填欄位。

```bash
curl -X POST "https://opencode.ai/inference/anthropic/v1/messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Gemini

Gemini 模型會在路徑中指定模型和方法。將 `:generateContent` 換成 `:streamGenerateContent`，即可以串流方式接收回應。

```bash
curl -X POST "https://opencode.ai/inference/google/v1beta/models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```
