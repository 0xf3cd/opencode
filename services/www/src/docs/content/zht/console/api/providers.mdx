---
title: "供應商 API"
description: "使用 Console 金鑰，透過 Console 閘道呼叫已連接到工作區的供應商。"
---

連接到工作區的每個[供應商](/console/providers)，都會透過 Console 閘道以各自的 URL 提供服務。OpenCode 會在 `/connect` 後自動使用它；你也可以直接呼叫，從自己的工具使用相同的供應商。Console 會在轉送前加上供應商的認證資訊，因此供應商的密鑰永遠不會離開工作區。

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## 供應商 URL

在 **Providers** 底下的供應商頁面中，複製 **Console API URL**。

```text
https://opencode.ai/inference/custom/<connection_id>
```

## 身分驗證

將 `<token>` 換成在 Console 中建立的[服務帳戶金鑰](/console/api#service-accounts)。Console 會在轉送前將它換成該連線的認證資訊。

```text
Authorization: Bearer <token>
```

Console 也會從 `x-api-key`、`api-key` 或 `x-goog-api-key` 讀取金鑰，因此將供應商 SDK 指向 Console API URL 時也能正常運作。

## 端點

在 Console API URL 後面加上供應商的 API 路徑。Console 會將請求轉送到該連線的 base URL，並原封不動地回傳供應商的回應。

| 格式 | 路徑 |
| -------------------- | --------------------------------- |
| Chat Completions | `/chat/completions` |
| Responses API | `/responses` |
| Anthropic Compatible | `/messages` |
| Google Generative AI | `/models/<model>:generateContent` |

請傳送供應商頁面上顯示的模型 ID。如果模型在上游使用不同的 API ID，Console 會自動改寫。對連線中未啟用的模型發出的請求會被拒絕。

### Chat Completions

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Responses API

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Say hi"
  }'
```

### Anthropic Compatible

`max_tokens` 為必填欄位。

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Google Generative AI

模型和方法是路徑的一部分。將 `:generateContent` 換成 `:streamGenerateContent`，即可以串流方式接收回應。

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```

## 用量

請求會依照各模型設定的價格計入[預算](/console/budgets)。token 費用則由供應商向你收取。
