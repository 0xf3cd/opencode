[Console](https://opencode.ai/console) 中的一切都屬於某個工作區：成員、額度、預算、供應商、原則和服務帳戶。用量和計費都以工作區為單位追蹤。

工作區可以只有一位成員。你可以獨自使用額度、[自己的供應商](/console/providers)、預算和 [Go](/console/go)，等到需要時再[邀請成員](/console/members)。

## 你的第一個工作區

註冊時，Console 會建立一個名為 **Personal** 的工作區，你是它的擁有者，也是唯一的成員。如果你是透過邀請註冊，則會直接加入邀請你的工作區，不會建立 Personal 工作區。

## 建立工作區

1. 開啟頂端列中的工作區選單。
2. 按一下 **Create Workspace**。
3. 輸入 **Workspace name**，然後按一下 **Create**。

你會成為新工作區的擁有者。

## 切換工作區

從工作區選單中選擇其他工作區。Console 會讓你停留在同一個頁面，因此從 `/acme/members` 切換後，會開啟另一個工作區的 Members 頁面。

待處理的邀請會顯示在同一個選單的頂端。請參閱[成員](/console/members#accept-an-invitation)。

## 重新命名工作區

擁有者和管理員可以在 **Settings › General** 中重新命名工作區。編輯 **Workspace name**，離開欄位時就會儲存變更。這個名稱僅用於顯示。

## 連接 OpenCode

在 OpenCode 中執行 `/connect`，然後在瀏覽器中選擇工作區。之後 OpenCode 就會使用該工作區的模型、原則和預算。

```text
/connect
```

再次執行 `/connect` 即可將 OpenCode 切換到其他工作區。工作區[原則](/policies#console)會換成新工作區的原則，中斷連線時則會清除。

## 角色

每位成員都有一個角色。新成員一律以 **Member** 身分加入。

| 角色 | 權限 |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | 使用 OpenCode，查看自己的用量、紀錄和預算。 |
| Admin | 具備 Member 的所有權限，還能管理成員、計費、預算、供應商、原則、服務帳戶和設定。 |
| Owner | 具備 Admin 的所有權限，還能授予 Owner 角色及刪除工作區。 |

Member 只能看到 **Overview**、**Logs**、**Settings › Account**，以及設為對成員顯示時的 **Leaderboard**。

### 角色規則

- 一個工作區可以有多位擁有者，而且一律至少保留一位。
- 你無法指派比自己更高的角色，因此只有擁有者能將他人設為擁有者。
- 你無法變更自己的角色。

### 轉移擁有權

1. 以擁有者身分開啟 **Members**，將新擁有者的角色設為 **Owner**。
2. 請新擁有者將你的角色變更為 **Admin** 或 **Member**。

## 刪除工作區

只有擁有者可以刪除工作區，而且前提是他們至少還屬於另一個工作區。

1. 開啟 **Settings › General**，然後按一下 **Delete workspace**。
2. 勾選所有確認事項。
3. 按一下 **Delete workspace** 確認。

刪除會立即生效，而且無法復原：

- 成員會立即失去存取權。
- 所有服務帳戶的 API 金鑰和待處理的邀請都會被撤銷。
- 自動加值會停止。
- 有效的 Go 訂閱會終止。
- 剩餘的額度餘額將會作廢。

<Callout type="warning">付款處理期間無法刪除工作區。請過幾分鐘後再試一次。</Callout>

## 離開工作區

成員無法自行退出。請擁有者或管理員[將你移除](/console/members#remove-a-member)。
