title: "Temalar"
---

Terminal arayüzünden tema seçmek için `Ctrl+P` tuşlarına basın, **Open settings** öğesini seçin ve **Theme** bölümünü
açın. Temayı doğrudan global CLI yapılandırmanızda da ayarlayabilirsiniz:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Temalar terminal istemcisine aittir. Tema seçimini `opencode.json` dosyasına değil, `cli.json` dosyasına yazın.
Yapılandırma konumu ve diğer terminal ayarları için [CLI ayarları](/cli/config) sayfasına bakın.

## Modlar

Terminalinizin görünümünü izlemek için `system` değerini kullanın veya temayı tek bir moda sabitleyin:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Değer    | Davranış                                         |
| -------- | ------------------------------------------------ |
| `system` | Terminalin açık veya koyu modunu izler.          |
| `dark`   | Her zaman koyu temayı kullanır.                  |
| `light`  | Her zaman açık temayı kullanır.                  |

Özel bir tema yalnızca bir mod sağlıyorsa, diğer mod istendiğinde OpenCode bu modu kullanır.

## Yerleşik temalar

Yerleşik bir temayı adıyla seçin:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Kullanılabilir temalar şunlardır:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

`system` teması, OpenCode terminal paletinizi okuyabildiğinde kullanılabilir.

## Dosyalar

`ocean` adlı global bir tema oluşturmak için tema aracını kullanarak global tema dizininde eksiksiz bir dosya oluşturun.
Dosyanın ilgili yapısı şuna benzer:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Ardından ayarlarda `ocean` temasını seçin veya `cli.json` dosyasında `theme.name` değerini `ocean` olarak ayarlayın.
`.json` uzantısı olmadan dosya adı, temanın adıdır.

| Kapsam  | Dizin                                      |
| ------- | ------------------------------------------ |
| Global  | `~/.config/opencode/themes/`               |
| Proje   | Proje ağacındaki `.opencode/themes/`       |

OpenCode yalnızca `.json` dosyalarını okur. Geçerli dizine daha yakın olan bir tema, aynı adlı global veya üst dizindeki
temanın yerini alır.

## Biçim

Her V2 teması eksiksiz bir `base` token ağacı ve en az bir `light` veya `dark` ton paleti tanımlar. Modlar yalnızca o
dosyanın tabanından devralır; yerleşik OpenCode temasından veya birbirlerinden devralmazlar. Özelleştirmeye başlamadan
önce eksiksiz bir taban oluşturmak için tema aracını kullanın.

Aşağıdaki örnekler yalnızca her kavramla ilgili bölümleri gösterir; eksiksiz tema dosyaları değildir.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Renkler

Bir hex renk, `transparent` veya başka bir tema rengine referans kullanın:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Hex değerleri 3, 4, 6 veya 8 haneli olabilir. Referanslar `$` ile başlar; ton referansları `$hue.<name>.<step>` biçimini
kullanır.

## Tonlar

Birbiriyle ilişkili bir renk ailesini tek seferde değiştirmek için bir ton takma adını geçersiz kılın:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Tür       | Değerler                                                             |
| --------- | -------------------------------------------------------------------- |
| Temel     | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Takma ad  | `accent`, `interactive`, `neutral`                                   |
| Adım      | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Ton adımları modun kontrast yönünü izler: açık temalarda `100` koyu, `900` açıktır; koyu temalarda ise `100` açık, `900`
koyudur.

`categorical`, ajanları ve diğer tekrarlanan öğeleri birbirinden ayırt etmek için kullanılan sıralı tonları belirler. En
az bir temel ton veya takma ad içermelidir.

## Durumlar

Etkileşimli renkleri değiştirmek için durum anahtarlarını kullanın. Belirtilmeyen durumlar en yakın temel değeri
kullanır:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Grup      | Değerler                                                     |
| --------- | ------------------------------------------------------------ |
| Eylemler  | `primary`, `secondary`, `destructive`                        |
| Durumlar  | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Form alanları aynı durum anahtarlarını doğrudan `text.formfield` veya `background.formfield` altında kullanır.

## Token'lar

Eksiksiz `base`, tüm token gruplarını içerir. Bir mod, eksiksiz ton paletini sağladıktan sonra bunun herhangi bir
bölümünü geçersiz kılabilir:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Grup         | Amaç                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| `text`       | Temel, soluk, eylem, form alanı ve geri bildirim metni                 |
| `background` | Temel, yüzeyler, eylemler, form alanları ve geri bildirim dolguları    |
| `border`     | Kenarlıklar                                                            |
| `scrollbar`  | Kaydırma çubukları                                                     |
| `diff`       | Eklenen, kaldırılan, bağlam, vurgu ve satır numarası renkleri          |
| `syntax`     | Kaynak kodu vurgulama                                                  |
| `markdown`   | Markdown öğeleri                                                       |

Sözdizimi anahtarları `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` ve
`punctuation` şeklindedir. Markdown anahtarları ise `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`,
`emphasis`, `strong`, `horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` ve `codeBlock` şeklindedir.

## Yükseltilmiş yüzeyler

Paneller, iletişim kutuları, menüler ve bildirimler (toast) derinliklerini `background.raised` üzerinden seçer. İletişim
kutuları ayrıca bağlama özgü bir `@dialog` yüzeyini de destekler. TUI, `@dialog` uygulandıktan sonra paleti yeniden
çözümler; böylece `$background.base` değerine referans veren token'lar iletişim kutusunun arka planını izler:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog`, temel modla aynı token gruplarını kabul eder. Bir eylemin bağlama özgü `base` değeri, belirtilmemiş durumları
için de yedek değer olur; açıkça belirtilmiş bir durum geçersiz kılması yine önceliklidir.
