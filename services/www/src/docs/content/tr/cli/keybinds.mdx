title: "Tuş atamaları"
---

Tuş atamalarını `cli.json` dosyasında özelleştirin:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Tek bir tuş için dize kullanın:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Alternatifleri virgülle ayırın:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Bir atamayı `"none"` veya `false` ile devre dışı bırakın:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Olay davranışı için nesne kullanın:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` varsayılan olarak `ctrl+x` değerini alır. Başka bir atamadaki `<leader>` bu tuşu ifade eder.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Bilinmeyen komut ID'leri reddedilir.

## Diff görüntüleyici

**All**, **Committed**, **Uncommitted** veya (bir oturum içindeyken) **Last turn** kapsamlarından birini seçmek için `d` (`diff.switch_source`) tuşuna basın ya da karşılaştırma dalını değiştirmek için **Base** seçeneğini seçin. Seçimler TUI kapanana kadar hatırlanır. Başlangıç kapsamını [`cli.json` dosyasındaki `diffs.source`](/cli/config#diffs) ayarıyla belirleyin.

Kaydırma, sayfalama ve başa/sona gitme kısayolları her zaman diff'i denetler. Klavye odağını değiştiren bir kısayol yoktur: dosyaları açmak için tıklayın, klasörleri genişletmek veya daraltmak için tıklayın, dosya ağacını kaydırmak için fare tekerleğini kullanın.

Dosyalar arasında geçiş yapmak için `n` / `p` veya `alt+down` / `alt+up` (macOS'te Option) tuşlarını kullanın. Diff görüntüleyicinin içinde Alt kısayolları oturum sekmeleri yerine dosyalar arasında gezinir.

Bir dosyayı incelendi olarak işaretleyip yama gövdesini daraltmak için `m` tuşuna basın. Tüm dosyalar görünümünde işareti kaldırmak ve yamayı yeniden açmak için `m` tuşuna yeniden basın. Tek dosya görünümü, incelendi olarak işaretlediğinizde otomatik olarak sonraki dosyaya geçer; ancak son dosyada başa dönmek yerine orada kalır. Bir dosyanın işaretini kaldırmak hiçbir zaman sonraki dosyaya geçirmez.

**Mark complete** (veya **Mark incomplete**) için kenar çubuğundaki bir dosyaya ya da dosyanın diff başlığına sağ tıklayın. Bu, `m` ile aynı incelendi durumunu değiştirir. Başka bir dosyayı menüsünden tamamlandı olarak işaretlemek o dosyayı seçmez; okumakta olduğunuz dosyadan da sonrakine geçilmez.

Shift'li `diff.help` alternatifleri, `?` tuşuna bastığınızda Shift değiştiricisini bildiren terminaller içindir.

Yakalanan stdout ve stderr çıktısını görüntülemek için **Shell** sekmesinde çalışan bir komutu seçip **Enter** tuşuna basın veya komuta tıklayın.
Kaydırmak için **↑/↓**, **Page Up/Down** veya **Home**, yeni çıktıyı izlemek için **End**, komutu durdurmadan geri dönmek için **Esc** tuşunu kullanın.
Görüntüleyici son çıktıyı gösterir ve komut sonlandıktan sonra da açık kalır; bir dosyaya yönlendirilen çıktı dahil edilmez.
