title: "RPC"
---

Effect eklentileri, türlü Effect ve Stream döndüren yöntemler ve olaylar sunabilir.

## Tanımlama

RPC'yi tanımlamak için Effect Schema ile birlikte `Rpc.define` kullanın.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Doğrulama

Effect Schema değerleri doğrular ve TypeScript türlerini çıkarır.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema ve Standard Schema da desteklenir.

### Girdi ve çıktı

Yöntemin argümanı için `input`, dönüş değeri için `output` kullanın. Değer yoksa ilgili alanı belirtmeyin.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Hatalar

Beklenen hataları `errors` alanına ekleyin. Her anahtar, hatanın `type` değeri olur.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Olaylar

Olayları üst düzeydeki `events` eşlemesine ekleyin. Olay verisi bir nesne olmalıdır.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Uygulama

Uygulamayı eklentinin Effect'i içinden kaydedin:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Hata eşlemesi, her yöntemin döndürdüğü Effect'in hata türü olur. Bildirilmiş bir hata oluşturmak için
`context.error(...)` kullanın.

## Çağırma

RPC kaydedildikten sonra HTTP üzerinden veya başka bir eklentiden çağrılabilir.

### HTTP

Effect istemcisini, ardından RPC alt istemcisini oluşturun:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Eklenti

Başka bir Effect eklentisi, kendi bağlamından yerel bir alt istemci oluşturabilir:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Abone olma

RPC olayları birer Stream'dir. Olay adıyla abone olun ve Stream'i kapsamlı bir fiber'da çalıştırın:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Abonelikler yalnızca canlıdır ve Stream tüketimi durduğunda kapanır.
