`@opencode/sdk`, OpenCode'u doğrudan uygulamanızın içinde barındırır. [Ağ istemcisinden](/build/client) farklı olarak
OpenCode sunucusunu bir araya getirir ve API çağrılarını onun HTTP yönlendiricisi üzerinden bellek içinde iletir. Hiçbir
HTTP dinleyicisi açmaz ve istemci ile sunucu arasına ek bir ağ adımı eklemez.

Cloudflare Durable Objects için [Cloudflare kılavuzuna](/build/sdk/cloudflare) bakın.

SDK'yı yükleyin:

```sh
bun add @opencode/sdk
```

## Host oluşturma

`OpenCode.create()`, sahipliği açıkça size ait bir host döndürür. Yönlendiricisini, Location hizmetlerini, fiber'larını ve
kapsamlı eklenti kayıtlarını serbest bırakmak için `await using` kullanın:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Açık kaynak yönetimi (explicit resource management) kullanılamıyorsa `await opencode.close()` çağrısını kendiniz yapın.

Gömülü host, `@opencode/client` ile aynı Promise değerlerini, bildirilmiş hataları, istek seçeneklerini ve
`AsyncIterable` akışlarını kullanır. Üretilmiş istemcinin tamamını sunar ve oturum ile olay grupları için `sessions` ve
`events` kolaylık takma adlarını ekler.

## Worktree'ler

Worktree işlemleri bir `projectID` gerektirir. Oluşturma (create) ve yenileme (refresh), yapılandırmayı ve eklentileri
projenin kaydedilmiş kanonik checkout'undan yükler. Listeleme (list) yalnızca kayıtlı envanteri okur. Kaldırma (remove)
kanonik eklentileri etkinleştirir ve kaydedilmiş stratejiyi kullanır; bu strateji kullanılamıyorsa başarısız olur.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

Yenileme, bilinen checkout köklerindeki worktree'leri mevcut tüm stratejileri kullanarak keşfeder. Özel bir strateji
kaydetmek için [eklentinin worktree dönüşümünü](/build/plugins#worktrees) kullanın.

## Olay akışı

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Üretilmiş istek seçenekleri aracılığıyla bir `AbortSignal` iletin veya yanıt gövdesini iptal etmek için yinelemeden çıkın.

## Özelleştirme

OpenCode örneğinizi eklentiler kaydederek özelleştirin. Gömülü host başlarken ajanları, modelleri, araçları ve diğer
davranışları özelleştirmek için eklentileri `OpenCode.create()` fonksiyonuna iletin:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Başlangıçtan sonra başka bir eklenti kaydetmek için `await opencode.plugin(plugin)` çağırın.

Eklenti hook'ları, dönüşümler, araçlar ve eklenti bağlamının tamamı için
[eklenti dokümantasyonunun tamamına](/build/plugins) bakın.
