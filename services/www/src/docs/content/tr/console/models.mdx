OpenCode Console, OpenCode ekibi tarafından test edilip doğrulanmış modellerden oluşan bir liste sunar. Bu modelleri
OpenCode'da veya başka bir kodlama ajanında kullanmak için oturum açın, kredi ekleyin ve bir API anahtarı alın.

Console, OpenCode'daki diğer sağlayıcılar gibi çalışır. Kullanımı **tamamen isteğe bağlıdır**; bunun yerine başka
herhangi bir sağlayıcıyı kullanabilirsiniz. Kullanım hakkı içeren bir abonelik için [OpenCode Go](/console/go) sayfasına
bakın.

## Nasıl çalışır

1. [Console'da](https://opencode.ai/console) oturum açın, fatura bilgilerinizi ve kredinizi ekleyin, ardından API
   anahtarınızı kopyalayın.
2. TUI'de `/connect` komutunu çalıştırın, OpenCode kullandıkça öde sağlayıcısını seçin ve API anahtarınızı yapıştırın.

   ```text
   /connect
   ```

3. Kullanılabilir modelleri görmek ve birini seçmek için `/models` komutunu çalıştırın.

   ```text
   /models
   ```

Ücret istek başına alınır ve hesabınıza kredi ekleyebilirsiniz.

`opencode/<model-id>` biçimini kullanın:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode/gpt-5.5",
}
```

### Model listesi

Kullanılabilir modellerin tam listesini ve meta verilerini models uç noktasından alın:

```bash
curl https://opencode.ai/inference/v1/models
```

### Jev

Jev, TypeSafe AI'ın hızlı ve yapılandırılmış kararlar için geliştirdiği bir System One modelidir. Metin üretmek yerine bir `state` değerini tipli sorulara göre değerlendirir ve kodunuzun doğrudan kullanabileceği değerler ile olasılıklar döndürür. Evet/hayır (`noul`), çoktan seçmeli (`choice`) ve değerlendirme ölçütüne dayalı (`score`) soruları destekler.

OpenCode Console API anahtarınızı `https://opencode.ai/inference/v1/systemone` uç noktasıyla kullanın. Bu örnek, bir destek talebinin acil olup olmadığını kontrol eder:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Tek bir istekte birden fazla soru sorabilirsiniz. Jev soruları paralel olarak değerlendirir ve her yanıtı ilgili soru ID'sinin altında döndürür:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Sınırlı süre için ücretsiz olan modeli kullanmak için `jev-1.13` yerine `jev-1.13-free` kullanın. Soru türleri ve yanıt alanları hakkında ayrıntılar için [TypeSafe AI dokümantasyonuna](https://docs.typesafe.ai/) bakın.

## Arka plan

Pek çok model mevcut olsa da yalnızca birkaçı kodlama ajanı olarak iyi çalışır. Sağlayıcılar da yapılandırma, performans
ve kalite açısından farklılık gösterir; bu nedenle OpenRouter gibi bir ağ geçidi üzerinden erişilen bir model farklı
performans gösterebilir.

<Callout type="tip">OpenCode ile iyi çalışan, seçilmiş bir grup model ve sağlayıcıyı test ettik.</Callout>

Bu kataloğu oluşturmak için:

1. Seçilmiş bir grup modeli test ettik ve en iyi nasıl çalıştırılacakları konusunda ekipleriyle görüştük.
2. Modellerin doğru şekilde sunulduğundan emin olmak için sağlayıcılarla birlikte çalıştık.
3. Gönül rahatlığıyla önerebileceğimiz bir liste oluşturmak için her model/sağlayıcı kombinasyonunu karşılaştırmalı
   olarak test ettik.

Console, bu modellere erişmenizi sağlayan bir AI ağ geçididir.

## Hedefler

Console'u şu amaçlarla geliştirdik:

1. Kodlama ajanları için en iyi modelleri ve sağlayıcıları **karşılaştırmalı olarak test etmek**.
2. Performansı düşürmeden veya daha ucuz sağlayıcılara yönlendirmeden **en yüksek kaliteli** seçenekleri sunmak.
3. Maliyetine satış yaparak ve yalnızca işlem ücretlerini karşılayacak kadar fiyat ekleyerek **fiyat düşüşlerini**
   kullanıcılara yansıtmak.
4. **Bağımlılık yaratmamak**: Console'u herhangi bir kodlama ajanıyla kullanabilir veya OpenCode ile başka bir sağlayıcı
   kullanabilirsiniz.
