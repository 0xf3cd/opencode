---
title: "모델"
---

`/models`로 현재 세션에서 사용할 모델을 선택하세요.

```text
/models
```

OpenCode는 [models.dev](https://models.dev), 제공자 통합, 사용자 구성에서 모델 목록을 가져옵니다. 선택기에는 현재
프로젝트에서 제공자를 사용할 수 있는, 활성화된 모델만 표시됩니다. 제공자 연결은 [제공자](/providers)를 참고하세요.

## 선택

제공자나 모델 ID를 추측하지 말고 `/models`에서 항목을 고르세요. 선택한 모델은 현재 세션에만 적용되며 구성은 바뀌지
않습니다.

```text
anthropic/claude-sonnet-4-5
```

사용 가능 여부는 프로젝트마다 다릅니다.

- 모델이 활성화되어 있어야 합니다.
- 현재 프로젝트에서 해당 제공자를 사용할 수 있어야 합니다.
- 다른 프로젝트의 자격 증명과 구성은 자동으로 이어지지 않습니다.

## 실행

구성된 기본값을 바꾸지 않고 명령줄 실행 한 번에만 모델을 지정하려면 `--model`을 사용하세요.

```bash
opencode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

에이전트와 명령도 자체 모델을 선택할 수 있습니다. [에이전트](/agents)와 [명령](/commands)을 참고하세요.

## 기본값

새 작업의 기본 모델을 지정하려면 `opencode.json` 또는 `opencode.jsonc`에서 `model`을 설정하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-4-5",
}
```

구성된 모델이 활성화되어 있고 제공자를 사용할 수 있으면 카탈로그 기본값이 됩니다. 그렇지 않으면 OpenCode는 사용 가능한
최신 지원 모델을 대신 사용합니다.

- 세션에서 이미 선택한 모델이 구성된 기본값보다 우선합니다.
- 세션의 모델을 바꿔도 구성 파일은 다시 작성되지 않습니다.
- 현재 루트 `model`에는 기본 제공자와 모델만 유지되며 변형은 유지되지 않습니다.

구성 위치와 우선순위는 [구성](/config)을 참고하세요.

## 변형

변형(variant)은 한 모델에 대해 이름을 붙인 옵션으로, 주로 추론 강도나 토큰 예산에 사용됩니다. 실행, 세션, 에이전트,
명령에서 변형을 선택할 때는 `#variant`를 붙이세요.

```bash
opencode run --model openai/gpt-5.2#high "Review this migration plan"
```

변형 이름은 선택한 모델의 현재 카탈로그 메타데이터에서 가져옵니다. `low`, `high`, `max` 같은 이름을 모든 모델에서 사용할
수 있는 것은 아니며, 알 수 없는 변형을 지정하면 모델 해석 오류가 발생합니다.

모델의 `variants` 배열에서 새 변형을 정의하거나, 같은 ID로 카탈로그 변형을 대체할 수 있습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "openai": {
      "models": {
        "gpt-5.2": {
          "settings": {
            "reasoningEffort": "medium",
          },
          "variants": [
            {
              "id": "fast",
              "settings": {
                "reasoningEffort": "low",
              },
            },
            {
              "id": "deep",
              "settings": {
                "reasoningEffort": "high",
                "reasoningSummary": "auto",
              },
            },
          ],
        },
      },
    },
  },
}
```

각 변형에는 `settings`, `headers`, `body`를 지정할 수 있습니다. 변형의 값은 제공자와 모델 값 다음에 적용됩니다.

## 옵션

제공자 항목과 모델 항목에서 `settings`, `headers`, `body`로 요청을 사용자 지정할 수 있습니다.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "openai": {
      "settings": {
        "baseURL": "https://api.example.com/v1",
      },
      "headers": {
        "X-Team": "platform",
      },
      "models": {
        "gpt-5.2": {
          "settings": {
            "reasoningEffort": "high",
          },
          "body": {
            "store": false,
          },
        },
      },
    },
  },
}
```

| 필드       | 용도                                                               |
| ---------- | ------------------------------------------------------------------ |
| `settings` | `baseURL`이나 `reasoningEffort` 같은 제공자 패키지 옵션입니다.     |
| `headers`  | 추가 HTTP 요청 헤더입니다.                                         |
| `body`     | 제공자별 요청 본문 필드입니다.                                     |

OpenCode는 제공자 값을 먼저, 모델 값을 두 번째로, 선택한 변형을 마지막에 적용합니다.

- 중첩된 `settings`와 `body` 객체는 병합됩니다.
- 나중에 나온 배열과 스칼라 값은 이전 값을 대체합니다.
- 헤더 이름은 대소문자를 구분하지 않고 일치시킵니다.
- 옵션은 제공자마다 다르며, 다른 제공자 패키지에서는 무시되거나 거부될 수 있습니다.

## 별칭

`modelID`를 사용하면 API 모델에 더 알기 쉬운 카탈로그 ID를 붙일 수 있습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openai/coding-default",
  "providers": {
    "openai": {
      "models": {
        "coding-default": {
          "modelID": "gpt-5.2",
          "name": "Coding default",
          "capabilities": {
            "tools": true,
            "input": ["text", "image"],
            "output": ["text"],
          },
          "limit": {
            "context": 200000,
            "output": 32000,
          },
        },
      },
    },
  },
}
```

여기서 `openai/coding-default`는 선택할 수 있는 참조이고, 제공자에는 `gpt-5.2`가 전송됩니다. 카탈로그에 없는 모델이면
OpenCode는 다음과 같이 가정합니다.

- 도구 지원, 텍스트 및 이미지 입력, 텍스트 출력.
- 200,000 토큰 컨텍스트 한도와 32,000 토큰 출력 한도.
- 지정되지 않은 입력 한도.

이는 감지된 기능이 아니라 폴백 가정입니다. 정확한 값을 알고 있다면 `capabilities`와 `limit`을 설정하세요. 명시한 값이
폴백 값을 대체합니다. 사용 가능한 카탈로그에서 모델을 숨기려면 `disabled: true`를 추가하세요.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "openai": {
      "models": {
        "legacy-model": {
          "disabled": true,
        },
      },
    },
  },
}
```

## 추론

OpenAI 호환 모델이 사용자 지정 어시스턴트 메시지 필드로 추론 내용을 스트리밍한다면 `compatibility.reasoningField`를
설정하세요.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "local": {
      "models": {
        "reasoner": {
          "compatibility": {
            "reasoningField": "reasoning_content",
          },
        },
      },
    },
  },
}
```

OpenCode는 `reasoning`, `reasoning_content`, `reasoning_text`를 인식하며, 제공자별 다른 문자열도 사용할 수 있습니다.
스트리밍된 추론 내용을 해당 필드에서 읽고, 이전 어시스턴트 메시지를 모델에 다시 보낼 때 그 필드를 복원합니다.

## 프롬프트 캐싱

OpenCode는 Anthropic처럼 프롬프트 캐시 중단점이 필요한 것으로 알려진 경로에서는 중단점을 자동으로 배치합니다. 하지만
LiteLLM 같은 OpenAI 호환 프록시를 통해 Claude 모델을 제공하는 경우, OpenCode는 그 모델에 Anthropic 방식의
`cache_control` 중단점이 필요한지 알 수 없습니다. 이러한 Claude 모델에는 `compatibility.cacheFormat`을 설정하세요.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "litellm": {
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": { "baseURL": "https://litellm.example.com/v1" },
      "models": {
        "claude-sonnet-5": {
          "compatibility": { "cacheFormat": "anthropic" },
        },
        "claude-opus-5-5": {
          "compatibility": { "cacheFormat": "anthropic" },
        },
        // Other models on the same proxy cache automatically and need no setting.
        "gpt-6.1": {},
      },
    },
  },
}
```

그러면 OpenCode는 마지막 도구 정의, 시스템 프롬프트, 최신 메시지에 `cache_control: { "type": "ephemeral" }`을 표시하며,
이 경우 엔드포인트의 기본 캐시 수명인 5분이 적용됩니다. Alibaba Model Studio 모델에는 `"alibaba"`를 사용하세요. 이
모델들은 같은 표시를 허용하지만 도구 정의에 붙은 표시는 무시합니다. 제공자가 제공하는 모든 모델이 같은 형식을 허용한다면
대신 제공자에 `compatibility.cacheFormat`을 설정하세요.

## 로컬 모델

OpenCode는 Ollama, LM Studio, vLLM의 기본 로컬 주소에서 모델을 자동으로 탐색합니다. 다른 OpenAI 호환 서버도 직접 구성할
수 있습니다.

```text
ollama/gemma3:4b
lmstudio/google/gemma-4-26b-a4b
vllm/Qwen/Qwen3-Coder-30B-A3B-Instruct
```

### Ollama

Ollama가 `http://127.0.0.1:11434`에서 수신 대기 중이라면 `ollama` 제공자 ID로 탐색된 모델을 선택하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "ollama/gemma3:4b",
}
```

OpenCode는 백그라운드에서 모델 목록을 새로 고치고, Ollama에서 컨텍스트, 비전, 도구 사용 기능을 읽어 옵니다. 임베딩 전용
모델은 제외됩니다.

다른 호스트나 포트를 사용한다면 Ollama의 OpenAI 호환 URL을 설정하세요. 탐색에는 여전히 같은 경로 접두사의 네이티브
Ollama API가 사용됩니다.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "ollama": {
      "settings": {
        "baseURL": "http://127.0.0.1:5678/v1",
        "apiKey": "{env:OLLAMA_API_KEY}",
      },
    },
  },
}
```

- 엔드포인트에 bearer 인증이 필요하지 않으면 `apiKey`를 생략하세요.
- 탐색을 끄려면 `"plugins": ["-opencode.provider.ollama"]`를 사용하세요.

### LMStudio

인증이 없는 LM Studio 서버가 `http://127.0.0.1:1234`에서 실행 중이라면 `lmstudio` 제공자 ID로 탐색된 모델을
선택하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "lmstudio/google/gemma-4-26b-a4b",
}
```

OpenCode는 백그라운드에서 모델 목록을 새로 고치고, LM Studio에서 컨텍스트, 비전, 도구 사용 기능을 읽어 옵니다. 임베딩
모델은 제외됩니다.

다른 호스트나 포트를 사용한다면 OpenAI 호환 URL을 설정하세요. 모델은 여전히 자동으로 탐색됩니다.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "lmstudio": {
      "settings": {
        "baseURL": "http://127.0.0.1:5678/v1",
        "apiKey": "{env:LMSTUDIO_API_KEY}",
      },
    },
  },
}
```

- LM Studio 인증이 비활성화되어 있으면 `apiKey`를 생략하세요.
- 탐색을 끄려면 `"plugins": ["-opencode.provider.lmstudio"]`를 사용하세요.

### vLLM

vLLM이 `http://127.0.0.1:8000`에서 수신 대기 중이라면 `vllm` 제공자 ID로 탐색된 모델을 선택하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "vllm/Qwen/Qwen3-Coder-30B-A3B-Instruct",
}
```

OpenCode는 `/health`를 확인하고, 백그라운드에서 `/v1/models`를 새로 고치며, 보고된 `max_model_len`을 컨텍스트 한도로
사용하고, `vllm`이 소유한 모델 카드만 포함합니다.

탐색된 모델은 텍스트 입력과 출력만 지원하는 것으로 표시되며, 비전이나 도구는 표시되지 않습니다. vLLM은
`--enable-auto-tool-choice`, `--tool-call-parser` 같은 서버 플래그로 도구 호출을 활성화하는데, 탐색 결과에는 이 정보가
포함되지 않습니다.

다른 엔드포인트나 인증이 필요한 서버를 사용한다면 해당 OpenAI 호환 URL을 설정하세요.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "vllm": {
      "settings": {
        "baseURL": "http://127.0.0.1:9000/v1",
        "apiKey": "{env:VLLM_API_KEY}",
      },
    },
  },
}
```

- 인증이 비활성화되어 있으면 `apiKey`를 생략하세요.
- 탐색을 끄려면 `"plugins": ["-opencode.provider.vllm"]`를 사용하세요.
- 경로 접두사가 있는 프록시도 지원합니다. 예를 들어 `https://example.com/vllm/v1`은 `/vllm/health`를 확인하고
  `/vllm/v1/models`에서 모델을 탐색합니다.

### 호환 서버

다른 OpenAI 호환 서버를 사용하려면 제공자 패키지, 엔드포인트, 그리고 최소 하나의 모델을 정의하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "local/coder",
  "providers": {
    "local": {
      "name": "Local server",
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "http://127.0.0.1:1234/v1",
      },
      "models": {
        "coder": {
          "modelID": "model-name-on-server",
          "capabilities": {
            "tools": true,
            "input": ["text"],
            "output": ["text"],
          },
          "limit": {
            "context": 32768,
            "output": 8192,
          },
        },
      },
    },
  },
}
```

서버의 실제 모델 이름, 한도, 입출력 유형, 도구 지원 여부를 사용하세요. OpenCode는 사용자 지정 모델의 폴백 값이 정확한지
감지할 수 없습니다. 엔드포인트에 키가 필요하다면 `"apiKey": "{env:LOCAL_API_KEY}"`처럼 환경 변수 치환을 사용해
`settings`에 `apiKey`를 추가하세요. 비밀 값은 커밋하지 마세요.

## 모델 참조

모델 선택자는 `provider/model` 형식을 사용하며, 선택적으로 `#variant`를 붙일 수 있습니다.

```text
openai/gpt-5.2
openai/gpt-5.2#high
openrouter/anthropic/claude-sonnet-4.5#high
```

| 부분       | 규칙                                                       |
| ---------- | ---------------------------------------------------------- |
| 제공자     | 첫 번째 `/`에서 끝나며, `/`나 `#`를 포함할 수 없습니다.     |
| 모델       | `/`를 추가로 포함할 수 있지만, `#`는 포함할 수 없습니다.    |
| 변형       | 있는 경우 `#` 뒤에 옵니다.                                  |
| 대소문자   | 제공자 ID와 모델 ID는 대소문자를 구분합니다.                |

제공자의 표시 이름이 아니라 카탈로그 ID를 사용하세요. 루트, 에이전트, 명령의 `model` 필드에는 위의 문자열 형식이나 확장된
객체를 사용할 수 있습니다.

```jsonc
{
  "model": {
    "providerID": "openrouter",
    "model": "anthropic/claude-sonnet-4.5",
  },
}
```

확장 형식은 자동 생성되거나 프로그래밍 방식으로 만드는 구성에 유용합니다.

## 주의 사항

모델을 구성할 때 다음 규칙에 유의하세요.

```jsonc
{
  "model": "openai/gpt-5.2"
}
```

- 선택자 객체는 `model`을 사용하고, 제공자 카탈로그 항목은 제공자에 전송할 ID로 `modelID`를 사용합니다.
- 루트 선택 형식은 변형을 허용하지만, V2 카탈로그 기본값에는 변형이 유지되지 않습니다. 대신 세션, 실행, 에이전트, 명령에서
  변형을 선택하세요.
- 모델 옵션은 제공자마다 다릅니다. 다른 제공자 패키지에서는 무시되거나 거부될 수 있습니다.
