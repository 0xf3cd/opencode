---
title: "세션 예열"
---

세션 예열은 프롬프트 사이에 잠시 쉬는 동안 주기적으로 모델 요청을 보내, 제공자 측 프롬프트 캐시나 기타 수명이 짧은
상태를 유지합니다. 기본적으로 비활성화되어 있습니다.

[OpenCode 구성 파일](/config) 어디에서든 예열을 활성화할 수 있습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

이렇게 구성하면 OpenCode는 최근 활성 세션에서 모델 요청이 4분 동안 없을 때 세션을 예열합니다. 이후 예열이 아닌
마지막 요청으로부터 30분이 지날 때까지 4분마다 예열을 계속합니다.

## 옵션

예열 프롬프트, 유휴 간격, 활성 기간을 변경하려면 객체 형식을 사용하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| 필드 | 기본값 | 용도 |
| --- | --- | --- |
| `prompt` | 연결 유지(keep-alive) 지시 | 예열 요청마다 임시 사용자 메시지로 덧붙입니다. 기본값은 모델에게 작업을 하지 말고, 도구를 사용하지 말고, `OK`로 답하라고 요청합니다. |
| `interval` | `"4 minutes"` | 다음 예열 요청까지의 유휴 시간입니다. |
| `duration` | `"30 minutes"` | 예열이 아닌 마지막 모델 요청부터 측정하는 예열 기간입니다. |

객체에서 생략한 필드는 기본값을 유지합니다. 예를 들어 다음 구성은 간격만 변경합니다.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## 기간 형식

`interval`과 `duration`에는 기간 문자열을 지정합니다. 두 값 모두 0보다 큰 유한한 값이어야 하며, 그렇지 않으면
OpenCode는 예열을 건너뛰고 경고를 기록합니다.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## 타이밍

예열은 예열이 아닌 모델 요청 이후에 시작됩니다. 예열 요청이 끝나면 다음 유휴 간격이 시작되지만, 활성 기간은 연장되지
않습니다.

```text
00:00  normal model request
00:04  warming request
00:08  warming request
00:30  warming stops
```

예열이 아닌 새로운 모델 활동이 생기면 두 타이머가 모두 초기화됩니다. 간격이 기간과 같거나 더 길면, 예열 요청을 보내기
전에 활성 기간이 만료됩니다.

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

## 요청

예열 요청은 세션의 현재 모델, 에이전트, 지침, 대화 컨텍스트를 사용합니다. OpenCode는 구성된 프롬프트를 임시로 덧붙여
모델을 한 번 호출하고, 응답은 버립니다.

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

이 요청은 입력을 받아들이거나, 기록에 메시지를 추가하거나, 영구 세션 상태를 변경하지 않습니다. OpenCode는 로컬 도구
호출을 실행하거나 도구 루프를 이어가지 않으며, 기본 프롬프트도 모델에게 도구를 사용하지 말라고 지시합니다.

## 실패

예열에 실패하면 로그만 남기며, 세션을 실패 처리하거나 변경하지 않습니다. OpenCode는 다음 간격까지 기다렸다가 다시
시도하며, 그동안 원래의 활성 기간은 계속 줄어듭니다.

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

## 비용

예열 요청은 실제 제공자 요청입니다. 다른 모델 요청과 마찬가지로 토큰을 소비하고, 비용이 발생하고, 요청 한도에 포함되며,
실패할 수도 있습니다.

- 간격이 짧을수록 요청 수가 늘어납니다.
- 기간이 길수록 더 많은 예열 요청이 발생할 수 있습니다.
- 제공자 측 이점이 추가 사용량만큼 가치 있을 때만 예열을 활성화하세요.

예를 들어 기본값을 사용하면 중단 없는 30분 기간 동안 최대 7번 예열을 시도합니다. 시점은 4, 8, 12, 16, 20, 24, 28분입니다.

## 비활성화

예열을 명시적으로 비활성화하려면 `warming`을 `false`로 설정하세요. 필드를 생략해도 예열은 비활성화된 상태로 유지됩니다.

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
