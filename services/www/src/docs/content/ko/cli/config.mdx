CLI 설정은 터미널 클라이언트에만 적용됩니다. `opencode.json(c)`의 서버 및 프로젝트 설정과는 별개입니다.

TUI에서 자주 쓰는 설정을 변경하려면 `Ctrl+P`를 누른 다음 **Open settings**를 선택하세요.

<img src={`${import.meta.env.BASE_URL}assets/docs/cli/settings.png`} alt="OpenCode TUI 설정 대화 상자" />

## 구성 파일

OpenCode는 CLI 설정을 하나의 전역 파일에 저장합니다.

```text
~/.config/opencode/cli.json
```

`$XDG_CONFIG_HOME`이 설정되어 있으면 다음 경로를 사용합니다.

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

프로젝트별 CLI 설정 파일은 없습니다. 유효성 검사와 자동 완성을 위해 공개된 JSON Schema를 추가하세요.

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode는 이 파일을 생성하거나 마이그레이션할 때 `$schema`를 추가합니다. 알 수 없는 설정은 거부되며, 유효한 변경
사항은 TUI가 실행 중일 때 다시 로드됩니다.

## 인라인 구성

인라인 JSON으로 CLI 설정을 적용하려면 `OPENCODE_CLI_CONFIG_CONTENT`를 설정하세요.

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode는 인라인 설정을 전역 `cli.json` 위에 병합합니다. 중첩된 객체는 병합되고, 환경 변수의 배열과 스칼라 값은
전역 값을 대체합니다. 이 변수가 설정되어 있는 동안에는 인라인 설정이 우선 적용됩니다.

## 모양
테마를 선택하고, 인터페이스 모션을 제어하고, 터미널 커서를 재정의합니다.

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="모양 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `theme.name` | 문자열 | 내장 테마, 사용자 지정 테마, 터미널에서 파생된 테마 중 하나를 선택합니다. |
| `theme.mode` | `system`, `dark`, `light` | 터미널 모양을 따르거나 테마를 하나의 색상 모드로 고정합니다. |
| `animations` | 불리언 | 인터페이스 애니메이션을 활성화합니다. |
| `cursor.style` | `block`, `underline`, `line`, `default` | 커서 모양을 설정합니다. `default`는 터미널의 커서 모양을 유지합니다. |
| `cursor.blinking` | 불리언 | 커서 깜박임을 제어합니다. 스타일이 `default`이면 효과가 없습니다. |

</div>

테마 선택과 생성 방법은 [테마](/cli/theme)를 참고하세요.

## 입력

마우스 캡처, 스크롤, 편집기 컨텍스트, 붙여넣기, 프롬프트 이미지 미리 보기를 구성합니다.

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="입력 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `mouse` | 불리언 | 터미널 마우스 캡처를 활성화합니다. |
| `scroll.speed` | 숫자, `0.001` 이상 | 스크롤 입력 한 번에 이동하는 고정 거리를 설정합니다. |
| `scroll.acceleration` | 불리언 | 반복 스크롤을 가속합니다. 활성화하면 속도 설정보다 우선 적용됩니다. |
| `prompt.editor` | 불리언 | 활성 편집기의 파일이나 선택 영역을 프롬프트 컨텍스트에 포함합니다. |
| `prompt.paste` | `compact`, `full` | 긴 붙여넣기 내용을 간단한 자리 표시자로 표시하거나 전체 텍스트로 표시합니다. |
| `prompt.image_preview` | 불리언 | 프롬프트 입력란 위에 이미지 첨부 파일 미리 보기를 표시합니다. |

</div>

## 세션

전체 화면 TUI에서 세션을 표시하는 방식과 새 세션이 시작되는 위치를 구성합니다.

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="세션 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `session.sidebar` | `auto`, `hide` | 공간이 충분할 때 사이드바를 표시하거나 항상 숨깁니다. |
| `session.scrollbar` | 불리언 | 대화 기록 스크롤바를 표시합니다. |
| `session.thinking` | `show`, `hide` | 모델의 추론 과정을 기본적으로 표시하거나 숨깁니다. |
| `session.grouping` | `auto`, `none` | 관련된 대화 기록 항목을 그룹으로 묶거나 각 항목을 따로 렌더링합니다. |
| `session.image_preview` | 불리언 | 사용자 첨부 파일과 도구 결과 이미지를 대화 기록에 표시합니다. |
| `session.tps` | 불리언 | 어시스턴트 메시지 하단에 초당 출력 토큰 수를 표시합니다. |
| `session.markdown` | `source`, `rendered` | Markdown 구문 기호를 표시하거나 렌더링된 내용에서 숨깁니다. |
| `session.new_location` | `launch`, `inherit` | TUI를 실행한 디렉터리에서 시작하거나 활성 세션의 위치를 이어받습니다. |
| `session.permissions` | `prompt`, `autoaccept` | 권한 요청마다 확인을 받거나 모든 요청을 자동으로 수락합니다. |

</div>

## 탭

계속 유지되는 세션 탭 표시줄을 구성합니다.

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

기존 불리언 설정인 `tabs.enabled`도 계속 지원됩니다. `true`는 `on`, `false`는 `off`에 해당합니다. OpenCode는 이
설정을 읽기만 하고 구성 파일을 다시 쓰지 않습니다.

<div class="docs-table-scroll" role="region" aria-label="탭 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `tabs.mode` | `auto`, `on`, `off` | 탭을 자동으로, 항상, 또는 전혀 사용하지 않습니다. `auto`는 Herdr 안에서 탭을 숨깁니다. |
| `tabs.scope` | `cwd`, `global` | 작업 디렉터리마다 탭을 따로 유지하거나 전역으로 공유합니다. |
| `tabs.layout` | `horizontal`, `vertical` | 탭을 가로 표시줄이나 세로 사이드바에 배치합니다. |
| `tabs.indicators` | `status`, `numbers` | 상태 아이콘을 표시하거나 항상 탭 번호를 표시합니다. |

</div>

번호 표시기에서도 상태 색상과 배경 애니메이션은 유지됩니다. Ctrl+숫자 단축키는 두 표시기 모드 모두에서 탭을
전환합니다.

## Diff

diff의 초기 범위와 표시 방식을 구성합니다.

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Diff 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `diffs.source` | `branch`, `committed`, `working`, `turn` | 초기 검토 범위를 설정합니다. |
| `diffs.wrap` | `word`, `none` | 긴 줄을 단어 단위로 줄바꿈하거나 그대로 둡니다. |
| `diffs.tree` | 불리언 | diff 파일 트리를 표시합니다. |
| `diffs.single` | 불리언 | 선택한 파일의 패치만 표시합니다. |
| `diffs.view` | `auto`, `split`, `unified` | 레이아웃을 설정합니다. `auto`는 사용 가능한 너비에 따라 선택합니다. |

</div>

`branch`는 **All**, 즉 브랜치 변경 사항과 로컬 변경 사항을 모두 표시하고, `committed`는 브랜치 커밋만, `working`은 스테이징된
변경 사항, 스테이징되지 않은 변경 사항, 추적되지 않는 파일을 표시합니다. `turn`은 **Last turn**, 즉 세션이 가장 최근
턴에서 변경한 파일을 표시합니다. 세션이 턴을 마칠 때마다 새로 고쳐지며, 세션 밖에서 `/diff`를 열면 `branch`로
대체됩니다.

`/diff`에서 `d`를 눌러 범위를 변경하거나 **Base**에서 비교할 브랜치를 선택하세요. 이 화면에서 선택한 내용은 TUI를
종료할 때까지 유지되며 `cli.json`을 변경하지 않습니다.

## 알림

시스템 알림과 주의 알림음을 각각 활성화합니다.

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="알림 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `attention.notifications` | 불리언 | 시스템 알림을 표시합니다. 일반적으로 터미널에 포커스가 없을 때 표시됩니다. |
| `attention.sound` | 불리언 | 주의 알림음을 재생합니다. |
| `attention.volume` | `0`에서 `1` 사이의 숫자 | 알림음 볼륨을 설정합니다. |
| `attention.sound_pack` | 문자열 | 사용할 사운드 팩 ID를 선택합니다. |
| `attention.sounds` | 객체 | `default`, `question`, `permission`, `error`, `done`, `subagent_done`의 사운드 파일을 재정의합니다. |

</div>

재정의한 파일이 유효하지 않거나 읽을 수 없으면 해당 이벤트의 내장 알림음으로 대체됩니다.

업데이트 후 TUI는 홈 화면에 새 릴리스의 주요 내용을 한 번 표시합니다. 다시 보려면 `/highlights`를 실행하고, 대화
상자를 끄려면 다음과 같이 설정하세요.

```json title="cli.json"
{
  "highlights": false
}
```

## 터미널

터미널 통합을 구성합니다.

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="터미널 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `terminal.title` | 불리언 | 터미널 창 제목을 업데이트합니다. |
| `terminal.copy` | `manual`, `select` | 직접 복사하거나 선택 즉시 복사합니다. 플랫폼 기본값은 Windows에서 `manual`, 그 외에서는 `select`입니다. |

</div>

## Mini

`mini` 그룹은 최소 대화형 인터페이스인 [`opencode mini`](/cli#mini)를 제어합니다.

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Mini 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `mini.thinking` | `show`, `hide` | 모델의 추론 과정을 표시하거나 숨깁니다. |
| `mini.tools` | `show`, `hide` | 도구 호출과 그 앞의 어시스턴트 텍스트를 표시하거나 숨깁니다. |
| `mini.shell_output` | `show`, `hide` | 셸 도구의 원시 출력을 표시하거나 숨깁니다. |
| `mini.turn_summary` | `show`, `hide` | 스크롤백에 에이전트, 모델, 소요 시간 요약을 표시하거나 숨깁니다. |
| `mini.footer` | `show`, `hide` | 활동, 모델, 사용량, 컨텍스트 정보를 하단에 계속 표시하거나 숨깁니다. |
| `mini.splash` | `show`, `hide` | 시작 및 종료 시 스플래시 배너를 표시하거나 숨깁니다. |
| `mini.work_spinner` | 스피너 ID | 하단에 표시할 작업 애니메이션을 선택합니다. |
| `mini.mono` | 불리언 | 흑백 ASCII 출력을 사용합니다. |
| `mini.replay` | 불리언 | 세션을 재개하거나 터미널 크기가 바뀔 때 세션 기록을 복원합니다. |
| `mini.replay_limit` | 양의 정수 | 재생할 메시지를 최신 메시지로 제한합니다. 기본 한도는 `200`입니다. |

</div>

사용 가능한 스피너 ID는 다음과 같습니다.

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

명령줄에서 지정한 `mini` 재생 플래그는 해당 실행에 한해 이 설정을 재정의합니다.

## 단축키

명령의 키 바인딩과 리더 키 대기 시간을 재정의합니다.

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="단축키 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `keybinds.leader` | 바인딩 값 | 다른 바인딩에서 `<leader>`로 참조하는 키를 설정합니다. |
| `keybinds.<command>` | 바인딩 값 | 명령 ID 하나의 바인딩을 재정의합니다. |
| `keybinds.*.key` | 키 문자열 또는 디스크립터 | 객체 바인딩의 키를 선택합니다. |
| `keybinds.*.event` | `press`, `release` | 객체 바인딩을 특정 키 이벤트 하나로 제한합니다. |
| `keybinds.*.preventDefault` | 불리언 | 터미널의 기본 키 동작을 막을지 여부를 제어합니다. |
| `keybinds.*.fallthrough` | 불리언 | 우선순위가 낮은 핸들러도 같은 이벤트를 받을 수 있게 합니다. |
| `leader.timeout` | 양의 정수 | 리더 키를 누른 뒤 기다릴 시간을 밀리초 단위로 설정합니다. |

</div>

바인딩 값은 문자열, 대체 키 배열, 객체 중 하나입니다. 바인딩을 비활성화하려면 `"none"` 또는 `false`를 사용하세요.
사용할 수 있는 키 구문, 전체 명령 ID, 모든 기본 바인딩은 [단축키](/cli/keybinds)를 참고하세요.

## 플러그인

터미널 전용 플러그인을 순서대로 로드합니다.

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="플러그인 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `plugins` | 배열 | 순서가 있는 활성화 지시문과 외부 플러그인을 선언합니다. |
| `plugins[].package` | 문자열 | 패키지 이름, 로컬 경로, 파일 URL을 지정합니다. |
| `plugins[].options` | 객체 | 플러그인별 옵션을 해당 플러그인에 전달합니다. |

</div>

패키지 형식, 로컬 검색, 와일드카드, 비활성화 지시문은 [플러그인](/cli/plugins)을 참고하세요.

## 디버그 및 실험 기능

진단 기능을 활성화하거나 현재 제공되는 실험 기능을 사용하도록 설정합니다.

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="디버그 및 실험 기능 설정" tabIndex={0}>

| 설정 | 값 | 설명 |
| --- | --- | --- |
| `debug.devtools` | 불리언 | DevTools 디버그 바를 표시합니다. |
| `debug.timing` | 불리언 | 디버그 바에 첫 화면 렌더링까지 걸린 시간을 표시합니다. |
| `debug.turn_tokens` | 불리언 또는 `verbose` | 턴별 토큰 사용량을 표시합니다. `verbose`는 도구 호출 입력도 포함합니다. |
| `experimental` | 기능 ID를 불리언에 매핑한 객체 | 예고 없이 변경되거나 제거될 수 있는 실험 기능을 활성화하거나 비활성화합니다. |

</div>

TUI의 **Experiments** 대화 상자에 현재 표시된 기능 ID만 사용하세요. 알 수 없는 ID는 효과가 없습니다.
