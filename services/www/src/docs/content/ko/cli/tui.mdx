프로젝트에서 OpenCode를 실행하고 요청을 입력한 다음 **Enter**를 누르세요.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

줄을 바꾸려면 **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter**, **Ctrl+J** 중 하나를 누르세요. OpenCode가 작업 중일 때 **Enter**를 누르면 실행 중인 세션에 프롬프트를 바로 전달해 방향을 조정(steer)합니다. 프롬프트를 나중에 처리하도록 대기열에 넣으려면 **Ctrl+X**를 누른 다음 **Enter**를 누르세요.

## 컨텍스트

`@`를 입력해 파일을 검색하고, 파일을 선택하면 프롬프트에 첨부됩니다. `@` 뒤에 계속 입력하면 결과를 좁힐 수 있습니다.

```text
Review @src/auth.ts for error handling problems
```

경로 뒤에 줄 번호나 범위를 지정할 수도 있습니다.

```text
Explain @src/auth.ts#20-45
```

## 셸

빈 프롬프트의 맨 앞에 `!`를 입력하면 셸 모드로 들어갑니다. 명령을 입력하고 **Enter**를 누르세요. 명령을 실행하지 않고 셸 모드를 나가려면 **Esc**를 누르세요.

```text
!git status
```

셸 명령은 세션의 작업 디렉터리에서 실행되며, 출력은 세션에 남습니다.

## 명령

`/`를 입력하면 슬래시 명령 목록이 표시됩니다. 계속 입력해 목록을 필터링한 다음 **Enter**를 눌러 선택한 명령을 실행하세요.

```text
/models
```

자주 사용하는 명령으로는 `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo`, `/editor`가 있습니다. **Ctrl+P**를 누르면 현재 화면에서 사용할 수 있는 모든 작업이 담긴 명령 팔레트가 열립니다.

업데이트 후에는 홈 화면에 해당 릴리스의 새로운 기능이 한 번 표시됩니다. 다시 보려면 `/highlights`를 실행하고, 자동으로 열리지 않게 하려면 [`cli.json`](/cli/config#alerts)에서 `"highlights": false`를 설정하세요.

## 곁가지 질문

지금까지의 대화에 대해 간단히 질문하려면 `/btw <question>`을 실행하세요. 답변은 세션의 컨텍스트와 현재 모델을 사용하지만 대화에 추가되지 않으므로 이후 프롬프트에 영향을 주지 않습니다. 실행되는 동안 프롬프트 하단에 `/btw` 표시가 나타나며, 답변은 대화 상자에 열립니다. **C**를 누르면 답변을 복사합니다.

```text
/btw why did the test in step 2 fail?
```

## 모델

모델을 선택하려면 **Ctrl+X**를 누른 다음 **M**을 누르거나 `/models`를 실행하세요. **F2**를 누르면 최근 사용한 모델을 순환합니다.

에이전트를 선택하려면 **Ctrl+X**를 누른 다음 **A**를 누르거나 `/agents`를 실행하세요. **Shift+Tab**을 누르면 에이전트를 순환합니다.

## 세션

새 세션을 시작하려면 **Ctrl+X**를 누른 다음 **N**을 누르세요. 기존 세션으로 돌아가려면 **Ctrl+X**를 누른 다음 **L**을 누르거나 `/sessions`를 실행하세요. **Ctrl+O**를 누르면 최근 세션과 프로젝트가 함께 열립니다.

탭은 기본적으로 활성화되어 있습니다. 탭 사이를 이동하려면 **Ctrl+Tab**과 **Ctrl+Shift+Tab**을, 탭을 닫으려면 **Ctrl+X**를 누른 다음 **W**를, 마지막으로 닫은 탭을 다시 열려면 **Ctrl+Shift+T**를 사용하세요.

## 기록

가장 최근의 사용자 메시지와 그 이후에 수행된 작업을 되돌리려면 **Ctrl+X**를 누른 다음 **U**를 누르거나 `/undo`를 실행하세요. 되돌린 프롬프트는 입력창으로 돌아오므로 수정할 수 있습니다.

되돌린 작업을 복원하려면 **Ctrl+X**를 누른 다음 **R**을 누르거나 `/redo`를 실행하세요. 복원하지 않고 새 프롬프트를 보내면 되돌리기가 확정되고 그 지점부터 이어서 진행됩니다.

## 편집기

`VISUAL` 또는 `EDITOR`를 설정한 다음 **Ctrl+X**, **E**를 차례로 누르거나 `/editor`를 실행하면 현재 프롬프트를 해당 편집기에서 편집할 수 있습니다. 저장하고 종료하면 텍스트가 입력창으로 돌아오며, **Enter**를 눌러 보내면 됩니다.

```bash
export EDITOR="nvim"
opencode
```

리더 키는 기본적으로 **Ctrl+X**입니다. 이 단축키를 변경하려면 [단축키](/cli/keybinds)를 참고하세요.
