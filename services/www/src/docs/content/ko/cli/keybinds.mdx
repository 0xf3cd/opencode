`cli.json`에서 키 바인딩을 원하는 대로 바꿀 수 있습니다.

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

키 하나는 문자열로 지정합니다.

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

대체 키는 쉼표로 구분합니다.

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

바인딩을 비활성화하려면 `"none"` 또는 `false`를 사용합니다.

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

이벤트 동작을 지정하려면 객체를 사용합니다.

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader`의 기본값은 `ctrl+x`입니다. 다른 바인딩의 `<leader>`는 이 키를 가리킵니다.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

알 수 없는 명령 ID는 거부됩니다.

## Mini

`app.clear` 명령은 [`opencode mini`](/cli)에서만 동작합니다. `ctrl+l`을 누르면 보이는 화면을 지우고 프롬프트를 다시 그립니다. 터미널의 스크롤백은 유지됩니다.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff 뷰어

`d`(`diff.switch_source`)를 눌러 **All**, **Committed**, **Uncommitted**, **Last turn**(세션 안에서만) 중 하나를 선택하거나, **Base**를 선택해 비교 브랜치를 변경하세요. 선택한 내용은 TUI를 종료할 때까지 유지됩니다. 초기 범위는 [`cli.json`의 `diffs.source`](/cli/config#diffs)로 설정합니다.

스크롤, 페이지 이동, 처음/끝으로 이동하는 단축키는 항상 diff에 적용됩니다. 키보드 포커스 전환 기능은 없습니다. 파일을 클릭해 열고, 폴더를 클릭해 펼치거나 접고, 마우스 휠로 파일 트리를 스크롤하세요.

파일 사이를 이동하려면 `n` / `p` 또는 `alt+down` / `alt+up`(macOS에서는 Option)을 사용하세요. diff 뷰어 안에서는 Alt 단축키가 세션 탭 대신 파일 사이를 이동합니다.

`m`을 누르면 파일을 검토 완료로 표시하고 패치 본문을 접습니다. 전체 파일 보기에서 `m`을 다시 누르면 표시가 해제되고 패치가 다시 펼쳐집니다. 단일 파일 보기에서는 검토 완료로 표시하면 자동으로 다음 파일로 넘어가지만, 마지막 파일에서는 처음으로 돌아가지 않고 그대로 머뭅니다. 표시를 해제할 때는 다음 파일로 넘어가지 않습니다.

사이드바의 파일이나 해당 파일의 diff 제목을 마우스 오른쪽 버튼으로 클릭하면 **Mark complete**(또는 **Mark incomplete**)를 선택할 수 있습니다. 이 메뉴는 `m`과 같은 검토 상태를 변경합니다. 메뉴에서 다른 파일을 완료로 표시해도 그 파일이 선택되거나 현재 보고 있는 파일이 넘어가지 않습니다.

Shift가 포함된 `diff.help` 대체 키는 `?`를 누를 때 Shift 수정자를 함께 보고하는 터미널을 위한 것입니다.

| `composer.shell.down` | `down` | 다음 셸 |
| `composer.shell.select` | `return` | 셸 출력 보기 |
| `composer.shell.kill` | `ctrl+d` | 셸 명령 강제 종료 |

**Shell** 탭에서 실행 중인 명령을 선택하고 **Enter**를 누르거나 명령을 클릭하면 캡처된 stdout과 stderr를 볼 수 있습니다.
스크롤하려면 **↑/↓**, **Page Up/Down**, **Home**을, 새 출력을 따라가려면 **End**를 사용하고, 명령을 중지하지 않고 돌아가려면 **Esc**를 누르세요.
뷰어는 최근 출력을 표시하며 명령이 종료된 뒤에도 열려 있습니다. 파일로 리디렉션된 출력은 포함되지 않습니다.
