---
title: "컨텍스트 압축"
---

컨텍스트 압축은 오래된 대화를 요약으로 바꿔 긴 세션에 여유 공간을 만듭니다. 덕분에 모델의 컨텍스트 한도를 넘어서도
세션을 계속 이어갈 수 있습니다.

## 동작 방식

세션이 모델의 컨텍스트 한도에 가까워지면, OpenCode는 가장 최근 대화(기본값은 약 15,000 토큰)를 제외한 나머지를 모두
요약합니다. 요약이 준비되면 최근 대화 앞에 배치되고, 세션은 그 상태에서 계속됩니다.

```text
before   [ system prompt ][ older conversation ............ ][ recent 15k ][ pending work ]
after    [ system prompt ][ summary ][ recent 15k ][ pending work ]
```

모델은 요약을 지난 대화로 인식합니다. 이후의 압축은 처음부터 다시 요약하지 않고 같은 요약을 업데이트합니다.

## 시작

자동 압축은 기본적으로 켜져 있습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "compaction": {
    "auto": true,
    "keep": { "tokens": 15000 },
  },
}
```

압축 과정에서는 일부 정보가 손실됩니다. 최근 내용의 세부 사항이 정확히 유지되어야 한다면 `keep.tokens`를 늘리거나,
자동 압축이 실행되기 전에 직접 압축을 요청하세요.

## 수동 압축

기록이 짧더라도 언제든지 압축을 요청할 수 있습니다.

```sh
opencode api post /api/session/ses_example/compact --data '{}'
```

`api` 명령은 백그라운드 서비스를 찾아 인증합니다. 응답은 요청이 접수되었음을 확인할 뿐, 요약이 끝날 때까지 기다리지
않습니다. 압축이 끝나는 시점은 `session.compaction.*` 이벤트를 구독해 확인하세요. 전체 작업은
[API 레퍼런스](/api)를 참고하세요.

| 규칙 | 동작 |
| --- | --- |
| 실행 시점 | 다음 안전한 지점에서, 아직 대기 중인 프롬프트보다 먼저 실행됩니다. |
| 반복 요청 | 대기 중인 요청이 있는 동안 들어온 요청은 기존 요청에 병합됩니다. |
| 자동화 | `compaction.auto`가 `false`여도 동작합니다. |

`id`를 전달하면 같은 요청을 재시도해도 한 번만 처리됩니다(멱등성). 다른 요청에 같은 ID를 다시 사용하면 충돌이
반환됩니다.

```sh
opencode api post /api/session/ses_example/compact --data '{"id":"msg_compact_once"}'
```

## 설정

[OpenCode 구성 파일](/config) 어디에든 `compaction`을 추가하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "compaction": {
    "auto": false,
    "keep": { "tokens": 24000 },
    "buffer": 16000,
  },
}
```

| 필드 | 기본값 | 동작 |
| --- | ---: | --- |
| `auto` | `true` | 컨텍스트 한도에 가까워지면 자동으로 압축하고, 제공자가 요청이 너무 길다며 거부하면 한 번 복구를 시도합니다. 수동 압축은 항상 동작합니다. |
| `keep.tokens` | `15000` | 요약과 함께 유지할 최근 대화의 대략적인 크기입니다. 값이 클수록 세부 사항이 더 많이 보존되지만 새 작업에 쓸 공간은 줄어듭니다. |
| `buffer` | 한도의 10% | 모델의 한도 아래로 비워 둘 토큰 수입니다. 값이 클수록 자동 압축이 더 일찍 시작됩니다. |

`keep.tokens`와 `buffer`에는 0 이상의 정수를 지정합니다.

## 제공자

기본적으로 OpenCode는 세션의 모델을 사용해 직접 요약을 작성합니다. 일부 제공자는 대신 자체적으로 대화를 압축할 수
있습니다. `settings.compaction`으로 제공자 또는 모델별로 활성화하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "openai": {
      "settings": { "compaction": { "type": "native" } },
      "models": {
        "gpt-4.1": { "settings": { "compaction": { "type": "summary" } } },
      },
    },
  },
}
```

모델 설정은 제공자 설정을 재정의합니다. `native`는 제공자의 압축을, `summary`는 OpenCode 자체 압축을 사용합니다.

네이티브 압축을 사용하면 OpenCode는 대화를 제공자의 압축 엔드포인트로 보냅니다. 제공자는 오래된 대화를 대신하는,
내용을 알 수 없는 암호화된 항목을 반환합니다. `keep.tokens` 이내의 최근 메시지와 첨부 파일은 이 항목과 함께
유지됩니다.

```text
before   [ older conversation ........................ ][ recent user messages ]
after    [ encrypted checkpoint + recent user messages ]
```

| 항목 | 동작 |
| --- | --- |
| 지원 | OpenAI Responses 모델. 배포 환경과 모델에 따라 지원 여부가 다릅니다. |
| 임계값 | 요약 압축과 같은 `auto` 및 `buffer` 설정을 사용합니다. 수동 요청도 동작합니다. |
| 이식성 | 암호화된 체크포인트는 같은 제공자, 모델, 엔드포인트에서만 동작합니다. 모델을 바꾸면 세션은 원래 대화에서 이어집니다. |
| 길이 초과 | 제공자가 압축 요청이 너무 길다며 거부하면, OpenCode는 더 작은 요청으로 다시 시도합니다. 요약 방식으로 전환하지는 않습니다. |

## 요약

요약은 다른 에이전트가 이어받아 작업을 계속할 수 있도록 구조화되어 있습니다.

```md
## Objective
Finish the authentication migration.

## Next Move
- Update the callback handler.
- Verify the login flow.
```

요약에는 목표와 요구 사항, 결정 사항, 완료된 작업과 진행 중인 작업, 차단 요소와 다음 단계, 관련 파일이 포함됩니다.
요약과 함께 유지되는 최근 대화에서는 긴 도구 출력이 축약되고, 첨부 파일 데이터는 짧은 설명으로 대체됩니다.

압축이 끝나면 지침 파일의 현재 버전이 세션의 새 기준이 됩니다. 자세한 내용은 [지침](/instructions)을 참고하세요.

## 한계

| 한계 | 결과 |
| --- | --- |
| 모델 | 압축에는 세션의 모델을 사용합니다. 압축 전용 모델은 따로 없습니다. |
| 기록 | 압축하려면 대체할 오래된 대화가 있어야 합니다. 요청의 대부분이 고정된 지침과 도구 스키마라면 공간을 만들 수 없습니다. |
| 크기 | 압축할 대화 자체가 너무 길면, OpenCode는 축약된 텍스트 버전을 보내며 가장 오래된 대화가 빠질 수 있습니다. |
| 복구 | 너무 길어서 거부된 요청은 압축한 뒤 한 번 다시 시도합니다. 두 번째로 거부되면 오류가 반환됩니다. |
| 저장 | 더 이상 모델에 전송되지 않는 이전 메시지도 계속 저장되어 있습니다. |

예를 들어 다음과 같은 경우에는 압축이 도움이 되지 않습니다.

```text
128k context = 120k fixed instructions and tools + 8k conversation
```

## 마이그레이션

V1은 마지막 턴 유지(tail-turn)와 정리(pruning) 방식을 사용했습니다. V2는 요약과 `compaction.keep.tokens`를
사용합니다.

```jsonc
{
  "compaction": {
    "keep": { "tokens": 15000 }
  }
}
```

이 페이지의 설정과 동작은 V2에 적용됩니다.
