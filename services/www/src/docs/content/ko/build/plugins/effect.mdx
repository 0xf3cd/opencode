---
title: "Effect"
---

`@opencode/plugin/effect`는 OpenCode 플러그인 API의 Effect 네이티브 버전입니다. 컨텍스트 작업은 Effect나 Stream을 반환하고, 콜백은 Effect를 반환하며, 플러그인의 수명은 `Scope`로 표현됩니다.

OpenCode는 플러그인과 그 `node_modules` 의존성을 로드할 때 런타임에 `effect`(내보낸 `effect/*` 하위 경로 포함)와 `@opencode/plugin`을 제공합니다. 이 패키지들은 플러그인에 번들하지 말고, 로컬 타입 검사와 테스트용으로 peer 의존성이나 개발 의존성으로 설치하세요.

```sh
bun add --peer @opencode/plugin effect
```

`.opencode/plugins/`에서 Effect 플러그인을 내보내면 자동으로 로드됩니다.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

게시된 패키지와 `.opencode/plugins/` 밖의 플러그인 디렉터리는 다른 서버 플러그인과 같은 `plugins` 구성을 사용합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

활성화, 패키지 해석, 구성 우선순위는 [플러그인 구성](/plugins)을 참고하세요.

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## 수명 주기

`effect`는 플러그인이 로드될 때 실행됩니다. 스코프는 플러그인이 다시 로드되거나 언로드될 때 닫히므로, 등록, 스코프 파이버, 종료자(finalizer)가 함께 해제됩니다.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

백그라운드 작업에는 스코프 파이버를 사용하세요. 정리 과정에서 플러그인 스코프가 파이버를 인터럽트합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### 컨텍스트

컨텍스트는 연결된 OpenCode 서버용 Effect 클라이언트와 함께, 플러그인 전용 변환, 훅, 저장소, 다시 로드, 옵션을 제공합니다. OpenCode의 비공개 Core 서비스는 노출하지 않습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

플러그인 정의와 전체 컨텍스트는 다음과 같이 선언되어 있습니다.

```ts
interface Context {
  readonly app: App
  readonly location: Location.Info
  readonly options: PluginOptions
  readonly agent: AgentDomain
  readonly aisdk: AISDKDomain
  readonly command: CommandDomain
  readonly event: EventDomain
  readonly experimental: {
    readonly terminal: Pick<ExperimentalApi<unknown>["persistentPty"], "read">
  }
  readonly integration: IntegrationDomain

  readonly generate: GenerateApi<unknown>
  readonly permission: PermissionDomain
  readonly plugin: Pick<PluginApi<unknown>, "list">

  readonly worktree: WorktreeDomain
}

interface Plugin<R = Scope.Scope> {
  readonly id: string
  readonly effect: (context: Context) => Effect.Effect<void, never, R>
}
```

### 옵션

`opencode.json(c)`에서 객체 형식으로 옵션을 전달합니다.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

`ctx.options`에서 옵션을 읽습니다. 알 수 없는 값은 사용하기 전에 타입을 좁히세요.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## 변환

변환은 에디터를 통해 상태를 동기적으로 편집합니다. OpenCode는 각 도메인 안에서 등록 순서대로 변환을 적용합니다. 먼저 소스가 제공자와 변경할 수 없는 모델 정의를 제공하고, 그다음 모델 변환이 활성 제공자의 후보를 편집합니다. 등록을 yield하면 플러그인 스코프에 유지됩니다.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

모델 변환으로 활성 제공자의 전체 후보 모음에 정책을 적용할 수 있습니다.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

변환이 사용하는 외부 상태가 바뀌면 `reload`를 호출하세요. 이 예에서 `loadFromSource()`는 `{ info: Provider.Info, models: readonly Model.Info[] }` 항목을 반환합니다. 제공자를 다시 로드하면 전체 모델 결과도 무효화됩니다.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### 에이전트

모든 에이전트를 읽거나 ID로 하나를 가져옵니다. 클라이언트 응답에는 해석된 위치와 스키마 데이터가 포함됩니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

에이전트를 변환하거나 다시 로드합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

스키마: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### 제공자

사용 가능한 제공자를 읽거나 ID로 특정 제공자의 메타데이터를 확인합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

제공자 변환은 제공자 설정과 소스 정의를 편집합니다. 에디터에서 읽으면 비활성 제공자도 포함되며 변경할 수 없는 정의가 노출됩니다. `models.update`는 소스 모델의 소유 사본을 편집합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

`models.set`으로 소스 인벤토리를 교체하고, 캡처된 정의가 바뀌면 다시 로드하세요.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

계정별 검색이 필요하면 인벤토리를 로드할 때 사용한 연결을 `sourceConnection`으로 전달하세요. 다른 연결이 선택되어 있는 동안에는 플러그인이 새로 고친 인벤토리를 게시할 때까지 OpenCode가 해당 제공자를 제외합니다.

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

스키마: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### 모델

사용 가능한 모델과 기본 선택을 읽습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

모델 변환은 활성 제공자의 전체 후보 모음을 편집합니다. 비활성화된 후보도 모든 변환이 끝날 때까지 편집할 수 있습니다. `update`는 사용 가능한 제공자 아래에만 모델을 추가할 수 있습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

콜백은 원시 모델 재정의를 편집합니다. 제공자 기본값은 OpenCode가 결과를 커밋할 때 한 번 병합되며, 변경이 없으면 이후 읽기에서 그 결과를 재사용합니다. `editor.provider`는 모델 변환의 출력이 아니라 비활성 템플릿을 포함한 변경할 수 없는 소스 정의를 읽습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

스키마: [`Model.Info`](/api#schema-Model.Info).

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### 명령

현재 위치에서 사용할 수 있는 명령을 읽습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

현재 명령 변환은 추가만 지원합니다. 실행기는 세션, 프롬프트 첨부 파일, 전달 모드를 받습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

스키마: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID
  readonly prompt: PromptInput.Prompt
  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### 통합

통합을 읽고, 활성 자격 증명이 있으면 해석합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

키로 연결하거나, 연결된 API를 통해 OAuth 시도를 진행합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

통합과 인증 방법을 변환합니다. OAuth 방법 콜백은 Effect이며 스코프 리소스를 획득할 수 있습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

스키마: [`Integration.Info`](/api#schema-Integration.Info), [`Integration.Method`](/api#schema-Integration.Method),
[`Connection.Info`](/api#schema-Connection.Info), [`Form.Answer`](/api#schema-Form.Answer).

```ts
type IntegrationOAuthAuthorization = {
  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number
} & (
  | { readonly mode: "auto"; readonly callback: Effect.Effect<Credential.OAuth, unknown> }
  | { readonly mode: "code"; readonly callback: (code: string) => Effect.Effect<Credential.OAuth, unknown> }
)

type IntegrationOAuthMethodRegistration = {
  readonly integrationID: string
  readonly method: IntegrationOAuthMethod
  readonly authorize: (answer: Form.Answer) => Effect.Effect<IntegrationOAuthAuthorization, unknown, Scope.Scope>
  readonly refresh?: (credential: Credential.OAuth) => Effect.Effect<Credential.OAuth, unknown>
  readonly label?: (credential: Credential.OAuth) => string | undefined
}

interface IntegrationEditor {
  list(): readonly IntegrationRef[]
  get(id: string): IntegrationRef | undefined
  update(id: string, update: (integration: IntegrationRef) => void): void
  remove(id: string): void
  readonly method: {
    list(integrationID: string): readonly IntegrationMethod[]
    update(input: IntegrationMethodRegistration): void
    remove(integrationID: string, method: IntegrationMethod): void
  }
}

interface IntegrationDomain extends Omit<IntegrationApi<unknown>, "wellknown"> {
  readonly transform: Transform<IntegrationEditor>
  readonly reload: () => Effect.Effect<void>
  readonly connection: {
    readonly active: (integrationID: string) => Effect.Effect<ConnectionInfo | undefined>
    readonly resolve: (connection: ConnectionInfo) => Effect.Effect<Credential.Value | undefined, unknown>
  }
}
```

### MCP

MCP 서버와 현재 연결 상태를 나열합니다.


플러그인은 변환을 통해서만 MCP 서버를 관리합니다. 서버를 추가하거나 교체하려면 `editor.set`, 구성을 변경하려면 `editor.update`, 제거하려면 `editor.remove`를 사용하세요. 구성은 `editor.list`와 `editor.get`으로 확인합니다.

```ts

      const docs = editor.get("docs")
```

### 도구

Effect `Schema`로 타입이 지정된 도구를 등록합니다. 실행기는 디코딩된 입력을 받고, 타입이 지정된 출력, 표시 콘텐츠, 메타데이터를 담은 Effect를 반환합니다.

에디터는 `add`, `update`, `remove`를 지원합니다. 변환 콜백은 동기 함수이므로 Effect나 Promise를 반환하면 안 됩니다. 외부 데이터는 등록하거나 다시 로드하기 전에 로드하세요. OpenCode는 새 에디터에서 활성 변환을 등록 순서대로 다시 실행하며, 실제 도구 이름이 같으면 나중의 유효한 등록이 앞선 등록을 재정의합니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

콜백이 캡처한 소스 데이터를 변경한 후에는 `yield* ctx.tool.reload()`를 호출하세요. 다시 로드는 활성 변환을 순서를 바꾸지 않고 다시 실행하며, 플러그인 effect를 다시 실행하지는 않습니다.

도구에는 실제 이름을 담은 `id`가 있으며, 해당 ID가 없으면 `get()`은 `undefined`를 반환합니다. `update`와 `remove`에는 네임스페이스를 포함한 실제 도구 이름(위 예에서는 `acme_greeting`)을 사용하세요. 네임스페이스의 점과 도구 이름에서 지원하지 않는 문자는 `_`로 바뀝니다. 존재하지 않는 이름은 무시되며, 도구를 새로 만들려면 완전한 정의와 함께 `add`를 사용해야 합니다. 업데이트는 이름과 네임스페이스를 유지합니다. 스키마나 옵션을 바꾸려면 중첩된 값을 변경하지 말고 새 값을 할당하세요. 유효하지 않은 업데이트는 로그에 기록되고 이전 정의는 그대로 유지됩니다.

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

업데이트와 제거는 MCP 카탈로그를 새로 고친 후를 포함해 추가 작업과 함께 순서대로 다시 실행됩니다.

`transform`은 스코프 등록을 반환합니다. `yield* registration.dispose`를 실행하면 해당 변환을 제거하고 나머지 변환으로 다시 빌드하므로, 그 변환이 재정의했던 이전 정의가 다시 드러납니다. 해제는 멱등적이며, 플러그인 스코프를 닫아도 등록이 해제됩니다.

각 모델 요청은 도구 스냅샷을 캡처합니다. 다시 로드와 해제는 이후의 스냅샷에만 영향을 주며, 기존 요청이 이미 캡처한 정의나 실행기에는 영향을 주지 않습니다. 변경 가능한 플러그인 데이터를 클로저로 참조하는 실행기는 여전히 그 데이터의 변경을 보게 되므로, 값을 특정 정의에 고정해야 한다면 변환 안에서 캡처하세요.

스키마: [`Tool.Content`](/api#schema-Tool.Content), [`Tool.TextContent`](/api#schema-Tool.TextContent),
[`Tool.FileContent`](/api#schema-Tool.FileContent).

```ts

  get(id: string): (Tool.Info & { readonly id: string }) | undefined
  namespace(namespace: { name: string; description: string }): void
  add<Input extends Tool.ValueSchema<any>, Output extends Tool.ValueSchema<any> | undefined>(

  ): void
  update(id: string, update: (tool: Types.Mutable<Tool.Info>) => void): void
```

제공자 콜백은 현재 위치, 작업 사본 루트, 정규 프로젝트 루트, 선택적 저장소 스토어를 받습니다. diff 콜백은 선택된 모드, 요청된 컨텍스트, 출력 바이트 예산도 함께 받습니다. 저장소 검색에는 계속 OpenCode에 내장된 Git 및 Mercurial 감지기가 사용됩니다.

제공자는 선택적으로 `init(scope)`를 구현해 `scope.worktree`에 저장소를 만들 수 있습니다. 초기화 시에는 감지된 저장소 유형이 아니라 ID로 제공자를 선택합니다(기본값은 Git). 위치에 아직 저장소가 없더라도 `init`을 구현한 제공자를 등록하세요. OpenCode는 호출 전에 디렉터리가 존재하고 저장소가 없는지 확인한 다음, 호출 후 프로젝트를 다시 검색합니다. 새로운 저장소 형식은 이 콜백 외에 별도의 검색 지원이 필요합니다.

### 이벤트

공개 서버 이벤트 구독은 Effect `Stream`입니다. 소비자를 플러그인 스코프에서 포크하면 자동으로 인터럽트됩니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.tap((item) => Effect.logDebug("OpenCode event", { type: item.type })),
      Stream.runDrain,
      Effect.forkScoped,
    )
  }),
```

Stream 연산자로 이벤트 유형을 선택하고 처리하세요.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.filter((item) => item.type === "config.updated"),
      Stream.runForEach(() => Effect.logInfo("configuration changed")),
      Effect.forkScoped,
    )
  }),
```

## 훅

훅은 실행 중인 작업을 가로챕니다. 여러 플러그인이 같은 훅을 등록할 수 있으며, OpenCode는 플러그인 순서대로 훅을 실행하므로 나중 훅은 앞선 훅의 변경 사항을 볼 수 있습니다. 등록은 플러그인 스코프 동안 유지됩니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", () => Effect.void)
  }),
```

### 세션

모델로 보내기 직전에 조합된 시스템 지침, 메시지, 도구를 수정합니다. `context`는 에이전트 루프에서 실행되고, `compaction`, `generate`, `title`은 각각의 보조 요청에서 실행됩니다. `compaction`과 `title`은 모델 호출을 건너뛰는 `result`를 받을 수 있습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

모델 요청 설정을 수정하고, 필요하면 훅을 특정 제공자로 한정합니다. 이벤트에는 아래 HTTP 훅과 같은 `kind`가 포함됩니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

제공자의 네이티브 요청이나 응답을 수정합니다. 본문은 한 번만 읽을 수 있는 스트림이므로, 읽기 전에 본문을 복제하거나 교체하세요. 두 훅 모두 세션이 보내는 모든 요청에서 실행되며, 요청을 보낸 흐름에 따라 `event.kind`는 `"primary"`, `"compaction"`, `"title"`, `"generate"` 중 하나입니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

WebSocket으로 스트리밍하는 제공자는 세션마다 하나의 연결을 재사용하므로 HTTP 훅은 이 트래픽을 볼 수 없습니다. 실험적 훅인 `experimental.ws.handshake`는 연결이 선택되기 전에 모델 호출마다 한 번 실행되며, 연결의 `url`과 `headers`를 노출합니다. 둘 중 하나를 변경하면 소켓이 다시 열립니다. WebSocket 경로가 폴백하는 요청에서는 HTTP 훅이 그대로 실행됩니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send`와 `experimental.ws.receive`는 프레임 자체를 노출합니다. `send`는 제공자 드라이버가 아웃바운드 프레임을 만든 후 실행되고, `receive`는 드라이버가 인바운드 프레임을 확인하기 전에 프레임마다 실행됩니다. 훅이 반환될 때 `frame`에 담긴 값이 그대로 전송되거나 드라이버에 전달되며, OpenCode는 이를 검증하지 않습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

제공자 실패에 대한 재시도 결정을 재정의하거나 지연 시간(밀리초)을 바꿉니다. 이 훅은 OpenCode가 실패를 분류하고 정책을 제안한 후, 재시도가 예약되기 전에 실행됩니다. OpenCode가 내부적으로 다음 시도를 수행하는 방식은 노출하지 않습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

초기 `decision`은 OpenCode의 정책이므로, 훅은 원래 최종 실패로 처리되는 제공자 실패를 재시도 가능하게 만들거나 제안된 재시도를 거부할 수 있습니다. 여러 훅은 등록 순서대로 실행되며, 나중 훅은 현재 결정을 볼 수 있습니다. 내장된 최대 시도 횟수는 절대적인 한도로 유지됩니다. `attempt`는 제안된 실제 시도 번호입니다. 최초 요청이 시도 `1`이므로 첫 번째 재시도는 시도 `2`입니다. 유효하지 않은 지연 값(`NaN`, 무한대, 음수)은 계산된 지연 시간으로 대체됩니다. 컨텍스트 초과 복구는 같은 요청을 재시도하지 않고 대화를 압축하므로 별도로 처리됩니다.

### 도구

before 훅은 입력을 교체하거나 `Tool.Error`로 실패할 수 있습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

after 훅은 성공한 결과와 실패를 확인하거나 교체할 수 있습니다.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

공유 등록 타입을 보면 어떤 작업에 플러그인 스코프가 필요한지 알 수 있습니다.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## 게시

패키지 플러그인은 로컬 Effect 플러그인과 같은 기본 내보내기를 사용합니다. 메인 엔트리포인트에서 Effect 구현을 내보내고 `effect`를 `peerDependency`로 선언하세요.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

OpenCode는 `effect`, 내보낸 `effect/*` 하위 경로, `@opencode/plugin`의 import(플러그인의 `node_modules`에 있는 의존성의 import 포함)를 호스트의 런타임 인스턴스로 리디렉션합니다. 따라서 파이버, 로거, `Schema` 파서가 하나의 런타임 사본을 공유합니다.

- 게시하는 플러그인 아티팩트에 `effect`를 번들하지 마세요. 번들러로 빌드한다면 `effect`와 `effect/*`를 external로 지정하세요.
- 플러그인과 그 `node_modules` 의존성은 항상 호스트 OpenCode 릴리스의 `effect` 인스턴스에서 실행됩니다. 대상 OpenCode 릴리스와 호환되는 `effect` API와 모듈 경로를 사용하세요. 다른 `effect` 메이저 버전(예: Effect 3)으로 빌드된 의존성도 호스트의 `effect`를 받게 되므로 지원되지 않습니다.
- 공개 `effect` 하위 경로만 제공됩니다. Effect의 비공개 `internal` 모듈을 import하는 플러그인은 해당 경로를 명시한 오류와 함께 로드에 실패합니다.
- 컴파일된 OpenCode 바이너리에는 Effect의 HTTP API 문서 페이지에서 사용하는 Scalar 및 Swagger UI 에셋이 포함되어 있지 않습니다. 플러그인에서 이 페이지를 제공하면 대신 안내 문구가 표시됩니다.

패키지 엔트리포인트는 `effect` 함수를 포함한 `Plugin.define`을 내보냅니다.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

대상 OpenCode 릴리스와 호환되는 버전을 사용하고, 워크스페이스에 링크된 사본만이 아니라 실제로 설치한 패키지를 테스트하세요.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
