Cloudflare Durable Object 안에서는 `@opencode/sdk/workerd`를 사용하세요. 이 프로필은 객체의 SQLite 저장소를 사용하고,
제거(eviction) 후 복구를 위해 영구 이벤트를 저장하며, 사용할 수 없는 로컬 파일 시스템 및 프로세스 서비스를 대체합니다.

```sh
bun add @opencode/sdk
```

요청마다 호스트를 만들지 말고, Durable Object 인스턴스가 살아 있는 동안 하나의 호스트를 유지하세요.

```ts
import { OpenCodeWorkerd } from "@opencode/sdk/workerd"
import myPlugin from "./my-plugin"

export class OpenCodeDO {
  private readonly opencode: Promise<OpenCodeWorkerd.Interface>

  constructor(state: DurableObjectState) {
    this.opencode = state.blockConcurrencyWhile(() =>
      OpenCodeWorkerd.create({
        storage: state.storage,
        config: { default_agent: "build" },
        plugins: [myPlugin],
      }),
    )
  }

  async fetch() {
    const opencode = await this.opencode
    return Response.json(await opencode.server.info())
  }
}
```

`blockConcurrencyWhile`은 호스트가 준비될 때까지 모든 Durable Object 이벤트를 막고, 초기화에 실패하면 객체를
재설정합니다. 보관해 둔 Promise를 통해 요청 핸들러는 시작 후 같은 호스트에 바로 접근할 수 있습니다.

```ts
constructor(state: DurableObjectState) {
  this.opencode = state.blockConcurrencyWhile(() =>
    OpenCodeWorkerd.create({ storage: state.storage }),
  )
}
```

Wrangler는 `workerd` 패키지 조건을 통해 OpenCode의 Workerd 호환 구현을 선택합니다. Cloudflare는 정리 작업을 실행하지
않고 Durable Object를 제거할 수 있으므로, 정확한 동작이 `close()` 호출에 의존하지 않습니다.

```jsonc title="wrangler.jsonc"
{
  "compatibility_flags": ["nodejs_compat"]
}
```

## 사용자 지정

Worker와 함께 번들한 플러그인을 등록해 OpenCode 인스턴스를 원하는 대로 맞출 수 있습니다.
`OpenCodeWorkerd.create()`에 플러그인을 전달하면 에이전트, 모델, 도구 및 기타 동작을 사용자 지정할 수 있습니다.

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCodeWorkerd } from "@opencode/sdk/workerd"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await OpenCodeWorkerd.create({
  storage: state.storage,
  config: { default_agent: "build" },
  plugins: [plugin],
})
```

플러그인 훅, 변환, 도구, 전체 플러그인 컨텍스트는 [플러그인 전체 문서](/build/plugins)를 참고하세요.
