`@opencode/sdk`는 애플리케이션 안에서 OpenCode를 직접 호스팅합니다. [네트워크 클라이언트](/build/client)와 달리,
OpenCode 서버를 조립하고 API 호출을 메모리 안에서 HTTP 라우터로 전달합니다. HTTP 리스너를 열지 않으며, 클라이언트와
서버 사이에 네트워크 홉이 추가되지 않습니다.

Cloudflare Durable Objects에서 사용하려면 [Cloudflare 가이드](/build/sdk/cloudflare)를 참고하세요.

SDK를 설치합니다.

```sh
bun add @opencode/sdk
```

## 호스트 만들기

`OpenCode.create()`는 명시적으로 소유하는 호스트를 반환합니다. `await using`을 사용하면 라우터, Location 서비스,
파이버, 스코프 플러그인 등록이 해제됩니다.

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

명시적 리소스 관리를 사용할 수 없다면 `await opencode.close()`를 직접 호출하세요.

임베디드 호스트는 `@opencode/client`와 같은 Promise 값, 선언된 오류, 요청 옵션, `AsyncIterable` 스트림을 사용합니다.
생성된 전체 클라이언트를 노출하며, 세션 그룹과 이벤트 그룹에 대한 편의 별칭 `sessions`와 `events`를 추가로
제공합니다.

## Worktree

Worktree 작업에는 `projectID`가 필요합니다. 생성과 새로 고침은 프로젝트에 저장된 정규 체크아웃에서 구성과 플러그인을
로드합니다. 목록 조회는 저장된 인벤토리만 읽습니다. 제거는 정규 체크아웃의 플러그인을 활성화하고 기록된 전략을
사용하며, 해당 전략을 사용할 수 없으면 실패합니다.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

새로 고침은 사용 가능한 모든 전략으로 알려진 체크아웃 루트 전체에서 worktree를 검색합니다. 사용자 지정 전략은
[플러그인의 worktree 변환](/build/plugins#worktrees)으로 등록하세요.

## 이벤트 스트리밍

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

생성된 요청 옵션으로 `AbortSignal`을 전달하거나, 반복을 빠져나가면 응답 본문이 취소됩니다.

## 사용자 지정

플러그인을 등록해 OpenCode 인스턴스를 원하는 대로 맞출 수 있습니다. `OpenCode.create()`에 플러그인을 전달하면
임베디드 호스트가 시작될 때 에이전트, 모델, 도구 및 기타 동작을 사용자 지정할 수 있습니다.

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

시작 후에 다른 플러그인을 등록하려면 `await opencode.plugin(plugin)`을 호출하세요.

플러그인 훅, 변환, 도구, 전체 플러그인 컨텍스트는 [플러그인 전체 문서](/build/plugins)를 참고하세요.
