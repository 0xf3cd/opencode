OpenCode는 오픈 소스 AI 코딩 에이전트입니다. 터미널 기반 인터페이스, 데스크톱 앱, 웹 앱으로 사용할 수 있습니다.

npm 패키지는 postinstall 스크립트로 사용 중인 플랫폼에 맞는 네이티브 `opencode` 바이너리를 선택합니다. 위의 Bun 및
pnpm 명령은 필요한 스크립트 실행을 명시적으로 허용하며, Vite+는 별도의 플래그가 필요하지 않습니다. mise 명령은 mise 2026.10.9 이상이 필요하며, 이전 버전에서는 OpenCode 1이 설치됩니다.

Windows 패키지 관리자는 지원하지 않습니다.


플랫폼에 맞는 독립 실행형 CLI 바이너리를 다운로드하세요.

- **macOS:** [Apple 실리콘](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## 웹

`opencode pair` 명령을 실행해 OpenCode 웹 인터페이스에 접속하세요.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Docker 이미지는 버전 태그를 사용합니다(예: `ghcr.io/anomalyco/opencode:2.0.0`).

## 연결

OpenCode는 다양한 LLM 제공자를 기본으로 지원하며, [TUI에서](/cli/providers) `/connect` 명령으로 바로 연결할 수
있습니다.

사용자 지정 제공자를 구성하려면 [제공자](/providers) 문서를 참고하세요.

최고의 코딩 모델을 모두 손쉽게 사용하고 싶다면 [OpenCode Console](/console)을 사용해 보세요.

최고의 오픈 소스 모델을 사용할 수 있는 월 $10 구독 플랜인 [OpenCode Go](/console/go)도 있습니다.

## 사용자 지정

[OpenCode 구성](/config)을 편집하거나, [플러그인을 로드](/plugins)하거나, [MCP 서버를 연결](/mcp-servers)하거나,
[명령을 만들어](/commands) OpenCode를 원하는 대로 맞춰 보세요. 터미널 인터페이스의 테마와 단축키는 [CLI
설정](/cli/config)을 참고하세요.
