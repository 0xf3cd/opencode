---
title: "예산"
description: "워크스페이스, 멤버, 서비스 계정의 월간 지출 상한을 설정합니다."
---

예산은 워크스페이스의 월간 지출 상한을 정합니다. 소유자와 관리자는 **Members** 및 **Keys** 페이지의 **Budget limits**
패널에서 예산을 설정합니다.

## 예산 수준

| 예산                    | 적용 대상                                   | 설정 위치                                          |
| ----------------------- | ------------------------------------------- | -------------------------------------------------- |
| 워크스페이스            | 워크스페이스 전체 인원의 합산 지출          | **Members** 또는 **Keys › Monthly workspace budget** |
| 기본 사용자             | 사용자 지정 한도가 없는 각 멤버             | **Members › Monthly default user budget**          |
| 개별 사용자             | 멤버 한 명                                  | **Members** 표 또는 멤버 페이지                    |
| 기본 서비스 계정        | 사용자 지정 한도가 없는 각 서비스 계정      | **Keys › Monthly default service account budget**  |
| 개별 서비스 계정        | 서비스 계정 하나                            | 서비스 계정 페이지                                 |

요청은 워크스페이스 예산과 해당 사용자 자신의 예산을 모두 넘지 않아야 합니다. 예산이 하나도 없으면 지출에 제한이
없습니다.

## 워크스페이스 예산

워크스페이스가 예산에 도달하면 모든 사람의 요청이 차단됩니다.

1. **Members** 또는 **Keys**를 여세요.
2. **Budget limits**에서 **Monthly workspace budget**을 클릭하세요.
3. **Workspace limit**에 USD 금액을 입력하고 **Save**를 클릭하세요.

## 멤버 예산

기본 사용자 예산은 사용자 지정 한도가 없는 모든 멤버에게 적용됩니다. **Monthly default user budget**에서 설정하세요.

멤버 한 명에게 사용자 지정 한도를 지정하는 방법은 두 가지입니다.

- **Members** 행에서 **Limit** 셀을 클릭하고 금액을 입력합니다.
- 멤버를 열고 **Monthly Budget** 아래에서 **Set User Budget**을 클릭합니다.

사용자 지정 한도는 Members 표에서 강조 표시됩니다. 사용자 지정 한도를 지우면 멤버가 기본값으로 돌아가며, 멤버 페이지에
**Using Default**가 표시됩니다.

## 서비스 계정 예산

서비스 계정도 같은 방식으로 동작합니다. **Keys** 페이지에서 **Monthly default service account budget**을 설정하거나,
서비스 계정을 열고 **Set Service Account Budget**을 클릭하세요.

## 금액과 초기화

- 금액은 미국 달러로, 소수점 이하 두 자리까지 입력할 수 있습니다.
- 예산은 매월 1일 00:00 UTC에 초기화됩니다.
- `$0` 예산은 예산에 반영되는 모든 지출을 차단합니다.

## 예산에 반영되는 항목

| 지출                                                                | 예산 반영 여부               |
| ------------------------------------------------------------------- | ---------------------------- |
| 유료 Console 모델                                                   | 예                           |
| 가격이 설정된 [자체 제공자](/console/providers)의 모델              | 예, 구성한 가격 기준         |
| [웹 검색](/console/websearch)                                       | 예                           |
| 무료 모델                                                           | 아니요                       |
| 플랜 범위 내 [Go](/console/go) 사용량                               | 아니요                       |
| 크레딧으로 결제한 Go 추가 사용량                                    | 예                           |

## 예산에 도달하면

예산이 초기화되거나 관리자가 예산을 늘릴 때까지 새 요청은 HTTP `429`로 실패합니다. 응답에는 어떤 예산에 도달했는지
표시되지 않습니다.

```text
Upstream request failed: Account budget exceeded
```

예산은 요청이 시작될 때 확인합니다. 이미 진행 중인 요청은 끝까지 처리되므로 지출이 한도를 약간 넘을 수 있습니다.

## 지출 추적

각 멤버는 **Overview**에서 남은 금액, 사용한 금액, 초기화 날짜 등 자신의 예산을 확인할 수 있습니다.

멤버가 두 명 이상인 워크스페이스의 소유자와 관리자에게는 **Usage**도 표시됩니다. 여기서 일별, 모델별, 사용자별 비용을
확인할 수 있으며, **Export usage** 버튼으로 최근 7일, 30일, 90일의 일별 합계를 CSV로 다운로드할 수 있습니다.

## 예산 자동화

[Budgets API](/console/api/budgets)를 사용하면 자체 도구에서 모든 멤버의 예산을 조회하고 사용자 지정 한도를 설정할 수
있습니다.
