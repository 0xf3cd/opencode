---

워크스페이스에 연결된 모든 [제공자](/console/providers)는 Console 게이트웨이를 통해 고유한 URL로 제공됩니다. OpenCode는
`/connect` 후에 이 URL을 자동으로 사용하며, 자체 도구에서 같은 제공자를 사용하려면 직접 호출하면 됩니다. Console은 요청을
전달하기 전에 제공자 자격 증명을 추가하므로 제공자 시크릿이 워크스페이스 밖으로 나가지 않습니다.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## 제공자 URL

**Providers**에서 제공자 페이지의 **Console API URL**을 복사하세요.

```text
https://opencode.ai/inference/custom/<connection_id>
```

## 인증

`<token>`을 Console에서 만든 [서비스 계정 키](/console/api#service-accounts)로 바꾸세요. Console은 요청을 전달하기 전에
이 키를 연결의 자격 증명으로 교체합니다.

```text
Authorization: Bearer <token>
```

Console은 `x-api-key`, `api-key`, `x-goog-api-key`에서도 키를 읽으므로, 제공자 SDK를 Console API URL로 지정해도 그대로
동작합니다.

## 엔드포인트

Console API URL 뒤에 제공자의 API 경로를 붙이세요. Console은 요청을 연결의 기본 URL로 전달하고 제공자의 응답을 그대로
반환합니다.

| 형식                 | 경로                              |
| -------------------- | --------------------------------- |
| Chat Completions     | `/chat/completions`               |
| Responses API        | `/responses`                      |
| Anthropic Compatible | `/messages`                       |
| Google Generative AI | `/models/<model>:generateContent` |

모델 ID는 제공자 페이지에 표시된 그대로 보내세요. 업스트림의 API ID가 다른 모델은 Console이 ID를 다시 씁니다. 연결에서
활성화되지 않은 모델에 대한 요청은 거부됩니다.

### Chat Completions

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Responses API

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "Say hi"
  }'
```

### Anthropic Compatible

`max_tokens`는 필수입니다.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Google Generative AI

모델과 메서드는 경로에 포함됩니다. 응답을 스트리밍하려면 `:generateContent`를 `:streamGenerateContent`로 바꾸세요.

```bash
curl -X POST "https://opencode.ai/inference/custom/conn_.../models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```

## 사용량

요청은 각 모델에 설정된 가격을 기준으로 [예산](/console/budgets)에 반영됩니다. 토큰 비용은 제공자가 청구합니다.
