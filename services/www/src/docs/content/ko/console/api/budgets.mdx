통합 기능에서 모든 워크스페이스 멤버에게 실제로 적용되는 월간 예산을 조회하고, 멤버별 사용자 지정 예산을 관리할 수
있습니다.

## 빠른 시작

[Console](https://opencode.ai/console)에서 **All** 권한을 가진 [서비스 계정](/console/api#service-accounts) API 키를
만드세요. Inference only 키로는 예산 데이터에 접근하거나 한도를 변경할 수 없습니다.

```bash
export CONSOLE_URL="https://opencode.ai/console"
export SERVICE_API_KEY="oc_sk_..."
```

멤버 예산 목록을 조회합니다.

```bash
curl --fail-with-body \
  "${CONSOLE_URL}/api/v1/budgets/members" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Accept: application/json"
```

## 멤버 예산 목록 조회

```text
GET /api/v1/budgets/members
```

응답에는 현재 모든 멤버가 이메일 순으로 포함됩니다. source가 `custom`인 한도는 멤버별 재정의이고, `default`는
워크스페이스 기본값을 상속한 것입니다. 한도와 source가 null이면 해당 멤버는 한도가 없습니다.

```json
[
  {
    "user_id": "user_...",
    "email": "alice@example.com",
    "limit_micro_cents": "7525000000",
    "spent_micro_cents": "1250000000",
    "exceeded": false,
    "resets_at": "2026-10-01T00:00:00.000Z",
    "source": "custom",
    "updated_at": "2026-09-03T12:00:00.000Z"
  }
]
```

통합 기능에서 정밀도가 손실되지 않도록 금액 응답 필드는 마이크로센트 단위의 10진수 문자열로 제공됩니다. 1미국 달러는
100,000,000마이크로센트입니다. 지출과 초기화 타임스탬프는 현재 UTC 달력 월을 기준으로 합니다. 멤버별 사용자 지정
재정의가 없으면 `updated_at`은 null입니다.

## 사용자 지정 예산 설정

```text
PUT /api/v1/budgets/members/:user_id
```

멤버 한 명에게 월 $75.25 예산을 설정합니다.

```bash
curl --fail-with-body --request PUT \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"budget_dollars":75.25}'
```

`budget_dollars`에는 소수점 이하 최대 두 자리의 0 이상 미국 달러 금액을 지정합니다. PUT은 멱등적이며 HTTP 204를
반환합니다. 목록 조회에서 반환된 멤버 ID를 사용하세요.

## 워크스페이스 기본값으로 되돌리기

```text
DELETE /api/v1/budgets/members/:user_id
```

사용자 지정 재정의를 제거합니다.

```bash
curl --fail-with-body --request DELETE \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

재정의를 삭제해도 멤버는 삭제되지 않습니다. 이후 멤버는 워크스페이스 기본 예산을 상속하며, 워크스페이스에 기본값이
없으면 한도가 없어집니다. 요청을 반복해도 안전하며 HTTP 204를 반환합니다.

## 오류

| 상태   | 의미                                                     |
| ------ | -------------------------------------------------------- |
| `400`  | 멤버 ID 또는 예산 금액이 잘못되었습니다.                 |
| `401`  | 서비스 API 키가 없거나, 잘못되었거나, 만료되었거나, 취소되었습니다. |
| `403`  | API 키에 예산을 관리할 권한이 없습니다.                  |
| `404`  | API 키에 연결된 워크스페이스에 해당 멤버가 없습니다.     |
