Console API를 사용하면 통합 기능에서 워크스페이스 구성을 읽고 예산을 관리할 수 있습니다. 경로는 Console 기본 URL을
기준으로 합니다.

```bash
export CONSOLE_URL="https://opencode.ai/console"
export SERVICE_API_KEY="oc_sk_..."

curl --fail-with-body "${CONSOLE_URL}/api/v2/config" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

| API                                 | 엔드포인트                                 |
| ----------------------------------- | ------------------------------------------ |
| [추론](/console/api/inference)      | `https://opencode.ai/inference/...`        |
| [제공자](/console/api/providers)    | `https://opencode.ai/inference/custom/...` |
| [예산](/console/api/budgets)        | `/api/v1/budgets/members`                  |
| [구성](#workspace-config)           | `GET /api/v2/config`                       |

## 서비스 계정

통합 기능은 서비스 계정으로 인증합니다. 서비스 계정은 자체 API 키, 사용량, [예산](/console/budgets#service-account-budgets)을
가진 워크스페이스의 비인간 멤버입니다. 소유자와 관리자가 **Keys**에서 관리합니다.

1. **Keys**를 열고 **Add Service Account**를 클릭한 다음 이름을 지정하세요(예: `CI Pipeline`).
2. 서비스 계정을 열고 **Add API Key**를 클릭하세요.
3. **Key name**, **Permissions**, 그리고 선택 사항인 **Expiry date**를 지정한 다음 **Create key**를 클릭하세요.
4. 키를 복사하세요. 키는 한 번만 표시됩니다.

```text
oc_sk_1a2b3c4d5e6f_...
```

키를 bearer 토큰으로 보내세요. 키는 하나의 워크스페이스에 연결되어 있으므로 워크스페이스 헤더가 필요하지 않습니다.

```text
Authorization: Bearer oc_sk_...
```

### 권한

| 권한           | 허용 범위                                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| Inference only | [추론](/console/api/inference) 및 [제공자](/console/api/providers) 요청, `GET /api/v2/config`.                   |
| All            | 위의 모든 항목과 관리자 권한의 Console API. 단, 모델 관리는 제외됩니다.                                          |

멤버 초대, 역할 변경, 멤버 제거, 키 생성 및 취소 같은 일부 작업은 **All** 키가 있어도 항상 Console에 로그인한 사람이
수행해야 합니다.

### 키 취소

서비스 계정을 열고 **API Keys**에서 키를 취소하세요. 서비스 계정을 제거하면 모든 키가 취소됩니다. 취소되었거나 만료된
키를 사용하는 자동화는 즉시 HTTP `401`을 받습니다.

## 사용자 토큰

사용자 토큰은 로그인한 사람의 워크스페이스 역할로 동작합니다. 토큰과 함께 워크스페이스를 지정하는 `x-org-id` 헤더를
보내세요.

```bash
curl --fail-with-body "${CONSOLE_URL}/api/v2/config" \
  --header "Authorization: Bearer ${USER_TOKEN}" \
  --header "x-org-id: org_..."
```

[디바이스 흐름](#device-flow)으로 받은 토큰은 로그인할 때 선택한 워크스페이스에 연결되므로 이 헤더가 필요하지 않습니다.
다른 `x-org-id`를 보내면 `403`이 반환됩니다.

## 디바이스 흐름

OpenCode는 OAuth 디바이스 권한 부여 방식(RFC 8628)으로 로그인합니다. 다른 CLI도 같은 흐름을 사용할 수 있습니다.

1. 디바이스 코드를 요청하세요. 토큰을 워크스페이스에 연결하려면 `supports_org_scope=true`를 보내세요.

   ```bash
   curl --fail-with-body "${CONSOLE_URL}/auth/device/code" \
     --data "client_id=my-cli" \
     --data "supports_org_scope=true"
   ```

   응답에는 `device_code`, `user_code`, `verification_uri_complete`, `expires_in`(600초), `interval`(5초)이
   포함됩니다.

2. 브라우저에서 `verification_uri_complete`를 여세요. 이 값은 `https://opencode.ai`를 기준으로 한
   `/console/device?user_code=...` 같은 경로입니다. 사용자가 로그인하고 워크스페이스를 선택한 다음 승인합니다.

3. 같은 `client_id`로 `interval`초마다 토큰을 폴링하세요.

   ```bash
   curl --fail-with-body "${CONSOLE_URL}/auth/device/token" \
     --data "grant_type=urn:ietf:params:oauth:grant-type:device_code" \
     --data "device_code=..." \
     --data "client_id=my-cli"
   ```

   승인되기 전까지는 `authorization_pending`과 함께 `400` 응답이 반환됩니다. 성공하면 `access_token`,
   `refresh_token`, `expires_in`, `org_id`가 반환됩니다.

4. 액세스 토큰이 만료되기 전에 갱신하세요. 워크스페이스 연결은 유지됩니다.

   ```bash
   curl --fail-with-body "${CONSOLE_URL}/auth/device/token" \
     --data "grant_type=refresh_token" \
     --data "refresh_token=..." \
     --data "client_id=my-cli"
   ```

각 갱신 토큰은 한 번만 사용할 수 있습니다. 이전 갱신 토큰을 다시 사용하면 세션 전체가 취소됩니다.

## 워크스페이스 구성

`GET /api/v2/config`는 워크스페이스에서 사용할 수 있는 제공자와 모델을 OpenCode V2 [구성](/config) 형식으로
반환합니다. OpenCode는 `/connect` 후에 이 구성을 불러옵니다.

```bash
curl --fail-with-body "${CONSOLE_URL}/api/v2/config" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

```json
{
  "providers": {
    "opencode": {
      "name": "OpenCode",
      "env": ["OPENCODE_CONSOLE_TOKEN"],
      "package": "aisdk:@ai-sdk/openai-compatible",
      "settings": {
        "baseURL": "https://opencode.ai/inference/openai/v1",
        "apiKey": "{env:OPENCODE_CONSOLE_TOKEN}"
      },
      "headers": { "x-opencode-org-id": "org_..." },
      "models": {
        "kimi-k2.6": { "name": "Kimi K2.6" }
      }
    }
  }
}
```

| 필드                    | 설명                                                                             |
| ----------------------- | -------------------------------------------------------------------------------- |
| `providers`             | Console, Go, 연결된 제공자와 각각의 게이트웨이 설정 및 모델입니다.               |
| `websearch`             | 호스팅 [웹 검색](/console/websearch)입니다. 활성화된 경우 멤버에게 제공됩니다.   |
| `mcp`                   | 멤버용 Console MCP 서버입니다.                                                   |
| `experimental.policies` | 워크스페이스 [정책](/policies#console) 구문입니다.                               |

모든 키 권한 수준과 멤버 역할에서 구성을 읽을 수 있습니다.

## 오류

오류는 오류 이름을 담은 `_tag`가 포함된 JSON으로 반환됩니다.

```json
{ "_tag": "Forbidden" }
```

| 상태   | 의미                                                                                     |
| ------ | ---------------------------------------------------------------------------------------- |
| `400`  | `OrgRequired`: 사용자 토큰을 `x-org-id` 없이 보냈습니다.                                 |
| `401`  | 자격 증명이 없거나, 잘못되었거나, 만료되었거나, 취소되었습니다.                          |
| `403`  | 잘못된 워크스페이스, 권한 부족, 또는 Console 엔드포인트에 **Inference only** 키를 사용했습니다. |
| `404`  | 워크스페이스가 존재하지 않거나 삭제되었습니다.                                           |
