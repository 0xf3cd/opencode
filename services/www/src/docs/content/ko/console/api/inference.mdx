description: "인증 헤더 하나로 Console 추론을 통해 OpenAI, Anthropic, Gemini 호환 모델을 호출합니다."
---

Console 추론은 `https://opencode.ai/inference`에서 OpenAI, Anthropic, Gemini 호환 API를 제공합니다. 모델의 API 계열에
맞는 엔드포인트로 JSON `POST` 요청을 보내세요.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k2.6",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

## 인증

`<token>`을 [Console](https://opencode.ai/console)에서 만든 [서비스 계정 키](/console/api#service-accounts)로
바꾸세요. 유료 모델은 이 헤더가 필요하며, 무료 채팅 모델은 헤더 없이 호출할 수 있습니다.

```text
Authorization: Bearer <token>
```

## 엔드포인트

| API                     | 경로                                                      |
| ----------------------- | --------------------------------------------------------- |
| OpenAI Chat Completions | `/inference/openai/v1/chat/completions`                   |
| OpenAI Responses        | `/inference/openai/v1/responses`                          |
| Anthropic Messages      | `/inference/anthropic/v1/messages`                        |
| Gemini                  | `/inference/google/v1beta/models/<model>:generateContent` |

각 모델은 하나의 API 계열로 제공됩니다. [모델 엔드포인트](/console/models#endpoints) 표를 참고하거나 최신 목록을
가져오세요.

```bash
curl https://opencode.ai/inference/v1/models
```

### OpenAI Chat Completions

`kimi-k2.6`, `glm-5.1`, `minimax-m2.7` 같은 오픈 모델과 무료 모델은 Chat Completions API를 사용합니다.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/chat/completions" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.1",
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### OpenAI Responses

GPT 모델은 Responses API를 사용합니다.

```bash
curl -X POST "https://opencode.ai/inference/openai/v1/responses" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "input": "Say hi"
  }'
```

### Anthropic Messages

Claude 및 Qwen 모델은 Messages API를 사용합니다. `max_tokens`는 필수입니다.

```bash
curl -X POST "https://opencode.ai/inference/anthropic/v1/messages" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Say hi" }]
  }'
```

### Gemini

Gemini 모델은 경로에 모델과 메서드를 지정합니다. 응답을 스트리밍하려면 `:generateContent`를
`:streamGenerateContent`로 바꾸세요.

```bash
curl -X POST "https://opencode.ai/inference/google/v1beta/models/gemini-3.1-pro:generateContent" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{ "parts": [{ "text": "Say hi" }] }]
  }'
```
