워크스페이스에는 [Console](https://opencode.ai/console)의 모든 것이 담깁니다. 멤버, 크레딧, 예산, 제공자, 정책, 서비스
계정이 모두 워크스페이스에 속하며, 사용량과 결제도 워크스페이스별로 집계됩니다.

워크스페이스에는 멤버가 한 명만 있어도 됩니다. 크레딧, [자체 제공자](/console/providers), 예산, [Go](/console/go)를 혼자
사용하다가 필요할 때만 [멤버를 초대](/console/members)하면 됩니다.

## 첫 번째 워크스페이스

가입하면 Console이 **Personal**이라는 워크스페이스를 만들고, 본인을 소유자이자 유일한 멤버로 지정합니다. 초대를 받아
가입한 경우에는 초대한 워크스페이스에 바로 참여하며 Personal 워크스페이스는 생성되지 않습니다.

## 워크스페이스 만들기

1. 상단 바에서 워크스페이스 메뉴를 여세요.
2. **Create Workspace**를 클릭하세요.
3. **Workspace name**을 입력하고 **Create**를 클릭하세요.

새 워크스페이스의 소유자는 본인이 됩니다.

## 워크스페이스 전환

워크스페이스 메뉴에서 다른 워크스페이스를 선택하세요. Console은 같은 페이지를 유지하므로, `/acme/members`에서 전환하면
다른 워크스페이스의 Members 페이지가 열립니다.

대기 중인 초대는 같은 메뉴 상단에 표시됩니다. [멤버](/console/members#accept-an-invitation)를 참고하세요.

## 워크스페이스 이름 변경

소유자와 관리자는 **Settings › General**에서 워크스페이스 이름을 바꿀 수 있습니다. **Workspace name**을 수정하면 필드를
벗어날 때 변경 사항이 저장됩니다. 이름은 표시용으로만 사용됩니다.

## OpenCode 연결

OpenCode에서 `/connect`를 실행하고 브라우저에서 워크스페이스를 선택하세요. 그러면 OpenCode가 해당 워크스페이스의
모델, 정책, 예산을 사용합니다.

```text
/connect
```

OpenCode를 다른 워크스페이스로 전환하려면 `/connect`를 다시 실행하세요. 워크스페이스 [정책](/policies#console)은 새
워크스페이스의 정책으로 바뀌며, 연결을 해제하면 삭제됩니다.

## 역할

모든 멤버에게는 하나의 역할이 있습니다. 새 멤버는 항상 **Member**로 참여합니다.

| 역할   | 할 수 있는 작업                                                                                                      |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | OpenCode를 사용하고 자신의 사용량, 로그, 예산을 확인합니다.                                                          |
| Admin  | Member가 할 수 있는 모든 작업에 더해 멤버, 결제, 예산, 제공자, 정책, 서비스 계정, 설정을 관리합니다.                 |
| Owner  | Admin이 할 수 있는 모든 작업에 더해 Owner 역할을 부여하고 워크스페이스를 삭제합니다.                                 |

멤버에게는 **Overview**, **Logs**, **Settings › Account**만 표시되며, **Leaderboard**는 멤버에게 공개된 경우에만
표시됩니다.

### 역할 규칙

- 워크스페이스에는 소유자가 여러 명 있을 수 있으며, 항상 최소 한 명은 유지됩니다.
- 자신보다 높은 역할은 부여할 수 없으므로, 소유자만 다른 사람을 소유자로 지정할 수 있습니다.
- 자신의 역할은 변경할 수 없습니다.

### 소유권 이전

1. 소유자 계정으로 **Members**를 열고 새 소유자의 역할을 **Owner**로 설정하세요.
2. 새 소유자에게 본인의 역할을 **Admin**이나 **Member**로 변경해 달라고 요청하세요.

## 워크스페이스 삭제

워크스페이스는 소유자만 삭제할 수 있으며, 소유자가 다른 워크스페이스에 하나 이상 속해 있어야 합니다.

1. **Settings › General**을 열고 **Delete workspace**를 클릭하세요.
2. 모든 확인 항목에 체크하세요.
3. **Delete workspace**를 클릭해 확인하세요.

삭제는 즉시 이루어지며 되돌릴 수 없습니다.

- 멤버는 즉시 접근 권한을 잃습니다.
- 모든 서비스 계정 API 키와 대기 중인 초대가 취소됩니다.
- 자동 충전이 중지됩니다.
- 활성 Go 구독이 종료됩니다.
- 남은 크레딧 잔액은 소멸됩니다.

<Callout type="warning">결제가 처리 중일 때는 삭제할 수 없습니다. 몇 분 후에 다시 시도하세요.</Callout>

## 워크스페이스 나가기

멤버는 스스로 워크스페이스를 나갈 수 없습니다. 소유자나 관리자에게 [제거](/console/members#remove-a-member)를
요청하세요.
