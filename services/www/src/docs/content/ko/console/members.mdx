title: "멤버"
description: "OpenCode Console 워크스페이스에 사람을 초대하고, 역할을 관리하고, 제거합니다."
---

소유자와 관리자는 **Members** 페이지에서 사람을 관리합니다. 각 행에는 멤버의 역할, 참여일, 월간 사용량, 예산 한도가
표시됩니다.

## 멤버 초대

1. **Members**를 열고 **Invite Members**를 클릭하세요.
2. 이메일 주소를 하나 이상 추가하세요. 공백, 쉼표, 세미콜론으로 구분하거나 목록을 붙여 넣으면 됩니다.
3. **Send invitations**를 클릭하세요.

초대받은 사람은 **Join workspace** 버튼이 있는 **Join Acme Inc. on OpenCode**라는 제목의 이메일을 받습니다.

초대는 7일 후에 만료됩니다. 모든 사람은 **Member**로 참여하며, 참여한 후에 [역할을 변경](#change-a-role)할 수 있습니다.

<Callout>
  [OpenCode Go](/console/go) 구독이 있는 워크스페이스에는 멤버를 초대할 수 없습니다. 팀용 워크스페이스를 따로
  만드세요.
</Callout>

멤버가 자동으로 참여하게 할 수도 있습니다.

- [SSO](/console/sso#automatic-membership)는 인증된 이메일 도메인의 사용자가 처음 로그인할 때 워크스페이스에 추가합니다.
- [디렉터리 동기화](/console/scim)는 ID 공급자에서 사용자를 할당하거나 해제하는 대로 멤버를 추가하고 제거합니다.

## 초대 수락

초대받은 사람은 초대를 받은 이메일 주소로 로그인해야 합니다. 초대를 수락하는 방법은 두 가지입니다.

- 초대 이메일에서 **Join workspace**를 클릭한 다음 로그인하거나 계정을 만듭니다.
- Console에 로그인해 워크스페이스 메뉴를 열고 **Pending invitations** 아래에서 **Join**을 클릭합니다.

다른 계정으로 로그인되어 있으면 Console이 **Sign out and continue**를 눌러 초대받은 이메일로 계속하도록 안내합니다.

## 대기 중인 초대 관리

대기 중인 초대는 Members 표에 **Pending · Expires**와 날짜, 또는 **Expired**로 표시됩니다.

| 작업      | 방법                                                                                      |
| --------- | ----------------------------------------------------------------------------------------- |
| 다시 보내기 | **⋯ › Resend invitation**. 7일간 유효한 새 링크를 보내며, 이전 링크는 더 이상 작동하지 않습니다. |
| 취소      | **⋯ › Remove...**. 링크가 즉시 작동하지 않습니다.                                         |

## 역할 변경

멤버 행에서 역할 메뉴를 열고 **Member**, **Admin**, **Owner** 중 하나를 선택하세요.

자신의 역할까지만 부여할 수 있으며, 워크스페이스에는 항상 소유자가 최소 한 명 있어야 합니다.
[역할](/console/workspaces#roles)을 참고하세요.

## 멤버 제거

1. 멤버 행에서 <strong>⋯ › Remove...</strong>를 클릭하세요.
2. **Remove member**를 클릭해 확인하세요.

접근 권한은 즉시 취소되며, 나중에 다시 초대할 수 있습니다. 해당 멤버의 과거 사용량은 워크스페이스 보고서에 그대로
남습니다.

서비스 계정과 그 API 키는 워크스페이스에 속하므로, 이를 만든 멤버를 제거해도 취소되지 않습니다. 필요하면 **Keys**에서
키를 취소하세요. [서비스 계정](/console/api#service-accounts)을 참고하세요.

## 멤버 세부 정보

멤버를 클릭하면 월간 예산, 사용하는 모델과 클라이언트, 사용량 차트, 요청 로그를 볼 수 있습니다. 여기에서 멤버의
[예산](/console/budgets#member-budgets)을 설정하고 사용량을 CSV로 내보낼 수 있습니다.
