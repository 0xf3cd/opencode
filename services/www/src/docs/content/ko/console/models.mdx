OpenCode Console은 OpenCode 팀이 테스트하고 검증한 모델 목록을 제공합니다. 로그인해 크레딧을 추가하고 API 키를 발급받으면
OpenCode나 다른 코딩 에이전트에서 이 모델을 사용할 수 있습니다.

Console은 OpenCode에서 다른 제공자와 똑같이 동작합니다. **완전히 선택 사항**이며, 다른 제공자를 대신 사용해도 됩니다.
사용량이 포함된 구독을 원한다면 [OpenCode Go](/console/go)를 참고하세요.

## 작동 방식

1. [Console](https://opencode.ai/console)에 로그인해 결제 정보와 크레딧을 추가하고 API 키를 복사하세요.
2. TUI에서 `/connect`를 실행하고 OpenCode 종량제 제공자를 선택한 다음 API 키를 붙여 넣으세요.

   ```text
   /connect
   ```

3. `/models`를 실행해 사용 가능한 모델을 확인하고 하나를 선택하세요.

   ```text
   /models
   ```

요금은 요청 단위로 청구되며, 계정에 크레딧을 추가해 사용합니다.

이 AI SDK 패키지는 엔드포인트를 직접 호출하는 애플리케이션용입니다. OpenCode에서 [모델](/models)을 선택하려면
`opencode/<model-id>` 형식을 사용하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode/gpt-5.5",
}
```

### Jev

Jev는 TypeSafe AI가 만든 System One 모델로, 빠르고 구조화된 판단에 적합합니다. 텍스트를 생성하는 대신 타입이 지정된 질문에 따라 `state`를 평가하고, 코드에서 바로 사용할 수 있는 값과 확률을 반환합니다. 예/아니요(`noul`), 객관식(`choice`), 루브릭 기반(`score`) 질문을 지원합니다.

OpenCode Console API 키로 `https://opencode.ai/inference/v1/systemone` 엔드포인트를 호출하세요. 다음 예시는 지원 요청이 긴급한지 판단합니다.

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

한 번의 요청으로 여러 질문을 할 수 있습니다. Jev는 질문을 병렬로 평가하고 각 답변을 해당 질문 ID 아래에 반환합니다.

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

기간 한정 무료 모델을 사용하려면 `jev-1.13` 대신 `jev-1.13-free`를 사용하세요. 질문 유형과 응답 필드에 대한 자세한 내용은 [TypeSafe AI 문서](https://docs.typesafe.ai/)를 참고하세요.

## 배경

사용할 수 있는 모델은 많지만 코딩 에이전트로 잘 동작하는 모델은 일부에 불과합니다. 제공자마다 구성, 성능, 품질도
달라서 OpenRouter 같은 게이트웨이를 통해 접근한 모델은 성능이 다를 수 있습니다.

<Callout type="tip">OpenCode와 잘 동작하는 일부 모델과 제공자를 선별해 테스트했습니다.</Callout>

이 카탈로그를 만들기 위해 다음 작업을 했습니다.

1. 일부 모델을 선별해 테스트하고, 각 모델 팀과 최적의 실행 방법을 논의했습니다.
2. 제공자와 협력해 모델이 올바르게 서빙되는지 확인했습니다.
3. 모델과 제공자의 조합마다 벤치마크를 수행해 자신 있게 추천할 수 있는 목록을 만들었습니다.

Console은 이 모델들에 접근할 수 있게 해 주는 AI 게이트웨이입니다.

## 목표

Console을 만든 목적은 다음과 같습니다.

1. 코딩 에이전트에 가장 적합한 모델과 제공자를 **벤치마크**합니다.
2. 성능을 낮추거나 더 저렴한 제공자로 라우팅하지 않고 **최고 품질**의 옵션을 제공합니다.
3. 원가로 판매하고 결제 수수료만큼만 더 받아 **가격 인하** 혜택을 그대로 전달합니다.
4. **종속 없음**: 어떤 코딩 에이전트에서든 Console을 사용할 수 있고, OpenCode에서 다른 제공자를 사용할 수도 있습니다.
