OpenCode Go는 인기 있는 오픈 코딩 모델을 안정적으로 이용할 수 있는 서비스로, 두 가지 월간 플랜을 제공합니다.

| 플랜        | 가격          | 포함 사용량                                 |
| ----------- | ------------- | ------------------------------------------- |
| **Go**      | **월 $10**    | 아래 모델을 더 저렴하게 이용                |
| **Go Plus** | **월 $40**    | 아래 모델 전반에 더 높은 사용 한도          |

Go는 OpenCode에서 다른 제공자와 똑같이 동작합니다. OpenCode Go를 구독하고 API 키를 발급받아 사용하면 됩니다. **완전히 선택 사항**이며, OpenCode를 사용하는 데 꼭 필요하지는 않습니다.

이 서비스는 주로 해외 사용자를 위해 설계되었으며, 전 세계에서 안정적으로 접속할 수 있습니다.

## 작동 방식

1. [OpenCode Console](https://opencode.ai/console)에 로그인해 Go 또는 Go Plus를 구독하고, 결제 정보를 추가한 다음 API 키를 복사하세요.
2. TUI에서 `/connect`를 실행하고 **OpenCode Go**를 선택한 다음 API 키를 붙여 넣으세요.

   ```text
   /connect
   ```

3. `/models`를 실행해 Go에서 사용할 수 있는 모델을 선택하세요.

   ```text
   /models
   ```

<Callout>
  Go와 Go Plus는 가입할 때 생성되는 **Personal** 워크스페이스처럼 멤버가 한 명인 워크스페이스용입니다. Go 구독이 있는
  워크스페이스에는 멤버를 초대할 수 없습니다.
</Callout>

## 어디에서 사용할 수 있나요?

OpenCode Go는 [OpenCode](https://opencode.ai)와 이와 비슷한 유형의 요청을 보내는 다른 코딩 에이전트를 위해
설계되었습니다. 다른 사용자의 경험을 저하시키는 남용이 없는지 트래픽을 모니터링합니다.

클라이언트는 다음 조건을 지켜야 합니다.

1. 일반적인 코딩 에이전트 트래픽을 보냅니다.
2. 범용 SDK나 HTTP 라이브러리 이름이 아니라 `my-coding-agent/1.0`처럼 고유한 user agent로 자신을
   식별합니다.
3. 라우팅과 프롬프트 캐싱을 최적화할 수 있도록 대화마다 `x-opencode-session`에 고정된 세션 ID를 보냅니다.

### 검증된 클라이언트

OpenCode 외에도 다음 클라이언트가 OpenCode Go에서 올바르게 동작하는 것으로 검증되었습니다. 다만 앞으로도 계속
동작한다고 보장하지는 않습니다.

| 클라이언트        | 세션 지원                                                                                                                                                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hermes**        | [PR #101864](https://github.com/NousResearch/hermes-agent/pull/101864)가 포함된 빌드는 기본 및 보조 OpenCode 요청에 헤더를 보냅니다. 이 수정은 v0.21.0 이후에 병합되었으므로 해당 릴리스만으로는 포함되지 않습니다.                     |
| **Claude Code**   | Go는 이 클라이언트 고유의 세션 헤더를 인식합니다. 사용자 지정 헤더 래퍼가 필요하지 않습니다.                                                                                                                                                                |
| **Codex**         | Go는 이 클라이언트 고유의 세션 헤더를 인식합니다. 일부 버전과 프록시 구성에서는 여전히 헤더가 누락되므로, 요청을 전달할 때 세션 헤더를 유지하세요.                                                                                                          |
| **ZCode**         | Go는 이 클라이언트 고유의 세션 헤더를 인식합니다. [`x-opencode-session` 지원 요청](https://github.com/zai-org/feedback/issues/492)은 아직 열려 있지만, 더 이상 이 헤더를 따로 보낼 필요는 없습니다.                                                       |
| **Pi**            | 현재 빌드는 OpenCode에 세션 정보를 보냅니다. 이전 설치본은 업데이트하세요.                                                                                                                                                                  |
| **jcode**         | [세션 헤더 수정](https://github.com/1jehuang/jcode/issues/1167)이 포함된 **v0.81.6 이상**으로 업데이트하세요.                                                                                                                              |
| **Kilo Code CLI** | [PR #13752](https://github.com/Kilo-Org/kilocode/pull/13752)가 포함된 빌드에서 OpenCode 세션 헤더가 복구됩니다. 이 수정은 VS Code 확장이 아니라 CLI에 적용됩니다. [이슈 #13723](https://github.com/Kilo-Org/kilocode/issues/13723)을 참고하세요. |

### 문제가 알려진 클라이언트

다음 클라이언트는 확인한 버전에서 세션 지원이 없거나 불완전합니다. 링크된 보고서에서 수정 사항과 우회 방법을 추적하고
있습니다.

| 클라이언트              | 상태 및 추적                                                                                                                                                                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **DeepSeek Harness**    | 일부 모델 경로에서는 세션 정보가 전달되지만 다른 경로에서는 누락됩니다. Go는 이 클라이언트 고유의 헤더를 인식하며, 남은 작업은 모든 어댑터에서 헤더를 보내는 것입니다. [Discussion #5495](https://github.com/deepseek-ai/deepseek-harness/discussions/5495). |
| **GitHub Copilot Chat** | [VS Code 이슈 #334186](https://github.com/microsoft/vscode/issues/334186)에서 세션 헤더 자동 지원이 요청되어 있습니다.                                                                                                                                |
| **Kimi Code**           | [이슈 #3506](https://github.com/MoonshotAI/kimi-code/issues/3506)에서 세션 헤더 자동 지원이 요청되어 있습니다.                                                                                                                                        |
| **MiMo Code**           | [이슈 #2317](https://github.com/XiaomiMiMo/MiMo-Code/issues/2317)에 대한 수정이 [PR #2327](https://github.com/XiaomiMiMo/MiMo-Code/pull/2327)로 제안되었지만 아직 병합되지 않았습니다.                                                               |

### 한도 초과 사용

Console 잔액에 크레딧도 있다면 Console에서 **Use balance** 옵션을 켤 수 있습니다. 이 옵션을 켜면 사용 한도에
도달했을 때 요청을 차단하지 않고 [종량제 잔액](/console/models#pricing)을 사용합니다.

### 일부 모델의 사용량이 더 적은 이유

Go에 포함된 월간 사용량은 모델마다 다릅니다.

대부분의 모델은 대량 구매 할인과 예약된 GPU 용량으로 비용을 낮추고, 그렇게 절감한 비용을 더 많은 월간 사용량으로 돌려드립니다.

일부 모델은 출시된 지 얼마 되지 않았거나 공개 가격이 이미 할인되어 있어서, 할인을 협상하거나 더 낮은 비용으로 호스팅할 기회가 아직 없었습니다.

이런 모델도 모델 제공자에게 직접 비용을 지불할 때보다는 조금 더 많이 사용할 수 있지만, 그 때문에 포함된 월간 사용량은 더 적습니다.

## 배경

오픈 모델은 이제 정말 좋아졌습니다. 코딩 작업에서는 상용 모델에 가까운 성능을 냅니다. 또한 여러 제공자가 경쟁적으로 서빙할 수 있어 대체로 훨씬 저렴합니다.

하지만 안정적이고 지연 시간이 짧은 접근을 확보하기는 어려울 수 있습니다. 제공자마다 품질과 가용성이 다르기 때문입니다.

<Callout type="tip">OpenCode와 잘 동작하는 일부 모델과 제공자를 선별해 테스트했습니다.</Callout>

이 문제를 해결하기 위해 다음 작업을 했습니다.

1. 일부 오픈 모델을 선별해 테스트하고, 각 모델 팀과 최적의 실행 방법을 논의했습니다.
2. 몇몇 제공자와 협력해 이 모델들이 올바르게 서빙되는지 확인했습니다.
3. 모델과 제공자의 조합을 벤치마크해 자신 있게 추천할 수 있는 목록을 만들었습니다.

Go와 Go Plus 모두 이 모델들을 이용할 수 있습니다. 사용량에 맞는 플랜을 선택하세요.

## 목표

OpenCode Go를 만든 목적은 다음과 같습니다.

1. 저렴한 구독으로 더 많은 사람이 AI 코딩을 **이용할 수 있도록** 합니다.
2. 최고의 오픈 코딩 모델에 **안정적으로** 접근할 수 있도록 합니다.
3. 코딩 에이전트 용도로 **테스트하고 벤치마크한** 모델을 엄선합니다.
4. OpenCode에서 다른 제공자도 함께 사용할 수 있게 해 **종속 없이** 이용하도록 합니다.
