---
title: "웹 검색"
description: "Console을 통해 OpenCode에서 호스팅 웹 검색을 사용합니다."
---

Console은 연결된 OpenCode v2 사용자에게 호스팅 웹 검색을 제공합니다. 워크스페이스 소유자나 관리자가 워크스페이스에서 한 번만 켜면 되며, 멤버에게 별도의 검색 제공자 키를 나눠 줄 필요가 없습니다.

검색에 성공할 때마다 **$0.01**이 부과되며, 이 금액은 워크스페이스 잔액과 멤버 지출 한도에 반영됩니다.

## 활성화

1. 워크스페이스 소유자나 관리자 계정으로 [Console](https://opencode.ai/console)에 로그인하세요.
2. **Settings** > **General**을 여세요.
3. **Hosted web search**를 켜세요.

그런 다음 각 멤버가 `/connect`로 OpenCode를 워크스페이스에 연결합니다.

```text
/connect
```

OpenCode는 워크스페이스의 관리형 구성에서 **OpenCode Web Search**를 불러옵니다. 멤버는 `websearch.provider`를 설정하거나 제공자 API 키를 추가할 필요가 없습니다.

## 검색

프롬프트에서 OpenCode에 최신 정보를 요청하세요. 검색은 Console의 대화형 페이지가 아니라 OpenCode에서 실행됩니다.

```text
Find the latest Bun release and summarize the changes with source links.
```

호스팅 제공자는 공개 웹을 검색해 최대 8개의 결과를 반환합니다. OpenCode는 이 결과를 바탕으로 프롬프트에 답하고 출처를 인용합니다.

권한을 구성하거나 도구를 비활성화하려면 [웹 검색 가이드](/websearch)를 참고하세요.

## 결제

Console은 검색이 유효한 결과 집합을 반환한 후에 **$0.01**을 청구합니다. 실패한 검색과 속도 제한에 걸린 검색에는 요금이 부과되지 않습니다.

웹 검색은 **Usage**, **My Activity**, 멤버 활동, 청구서, CSV 내보내기에서 모델 사용량과 별도로 표시됩니다. 워크스페이스와 멤버의 월간 지출 한도에는 웹 검색 요금이 포함됩니다.

## 개인정보 보호

호스팅 웹 검색은 데이터를 전혀 보관하지 않습니다. Console과 호스팅 검색 제공자는 각 쿼리와 결과를 처리할 때 그 내용을 저장하지 않습니다.
