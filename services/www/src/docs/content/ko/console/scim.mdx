description: "Okta, Microsoft Entra ID 또는 SCIM 2.0 ID 공급자에서 워크스페이스 멤버를 자동으로 추가하고 제거합니다."
---

디렉터리 동기화(SCIM 2.0)는 ID 공급자에서 사용자를 할당하면 워크스페이스에 추가하고, 할당을 해제하면 접근 권한을
제거합니다. 역할은 계속 Console에서 관리합니다.

```text
https://opencode.ai/console/scim/v2
```

## 시작하기 전에

- 워크스페이스에 [SSO](/console/sso)를 설정하세요.
- 사용자가 로그인에 사용하는 모든 이메일 도메인을 [인증](/console/sso#verify-email-domains)하세요. 디렉터리 동기화는
  인증된 도메인의 사용자만 추가합니다. 그 외 사용자는 [멤버](/console/members) 페이지에서 초대하세요.

## 토큰 생성

1. **Settings › Security**를 열고 **Directory sync** 아래에서 **Set up**을 클릭하세요.
2. **SCIM base URL**과 토큰을 복사하세요. 토큰은 한 번만 표시되므로 시크릿 관리자에 보관하세요.

ID 공급자는 모든 요청에 이 토큰을 보냅니다.

```text
Authorization: Bearer <token>
```

## ID 공급자 연결

### Okta

1. **SCIM 2.0 Test App (Header Auth)** 앱을 추가하세요.
2. 기본 URL을 설정하고, **API Token**에 `Bearer ` 뒤에 토큰을 붙여 입력하세요.
3. **Create Users**, **Update User Attributes**, **Deactivate Users**를 활성화하세요. **Import Groups**와 비밀번호
   동기화는 꺼 두세요.

### Microsoft Entra ID

1. 엔터프라이즈 앱에서 **Provisioning**을 열고 모드를 **Automatic**으로 설정하세요.
2. 기본 URL을 **Tenant URL**에, 토큰을 **Secret Token**에 입력하세요.
3. 사용자와 그룹을 할당한 다음 프로비저닝을 시작하세요.

### 기타 공급자

헤더 토큰 인증을 사용하는 SCIM 2.0 앱을 기본 URL로 지정해 사용하세요. Console은 `/Users` 및 `/Groups` 엔드포인트를
지원합니다.

먼저 테스트 사용자 한 명을 할당해 보세요. 첫 요청이 들어오면 **Directory sync**에 **Connected to your identity
provider**가 표시됩니다.

## 동기화되는 항목

| ID 공급자에서             | Console에서                                                                       |
| ------------------------- | --------------------------------------------------------------------------------- |
| 사용자 할당               | **Member**로 추가됩니다. 기존 멤버는 역할이 유지됩니다.                            |
| 이름 변경                 | 프로필이 업데이트됩니다.                                                          |
| 할당 해제 또는 비활성화   | 접근이 정지되고 **Deactivated**로 표시됩니다. 해당 사용자가 만든 API 키는 취소됩니다. |
| 다시 할당                 | 접근이 복원됩니다. 취소된 키는 복원되지 않습니다.                                 |
| 삭제                      | 워크스페이스에서 제거됩니다. 계정과 다른 워크스페이스에는 영향이 없습니다.        |

- 디렉터리 동기화는 역할과 이메일 주소를 변경하지 않습니다.
- 마지막 소유자는 비활성화하거나 삭제할 수 없습니다.
- [Go](/console/go) 구독이 있는 워크스페이스에는 디렉터리 동기화로 멤버를 추가할 수 없습니다.

## 그룹

그룹을 푸시하면 그룹 멤버에게 태그가 지정됩니다(예: Okta **Push Groups** 또는 Entra 그룹 할당). 그룹을 푸시하기 전에
사용자를 먼저 할당하세요.

```text
Platform Admins  →  platform-admins
```

각 그룹은 그룹 이름을 딴 태그를 멤버에게 지정합니다. **Settings › Security › Group tags**에서 태그 이름을 바꾸거나,
여러 그룹을 하나의 태그에 연결하거나, 그룹의 태그 지정을 중지할 수 있습니다. 그룹에서 나가면 해당 태그가 제거됩니다.

## 토큰 교체

1. **New token**을 클릭하고 ID 공급자에 새 토큰을 설치하세요.
2. 새 토큰에 마지막 사용 기록이 표시될 때까지 기다리세요.
3. 이전 토큰을 취소하세요.

토큰을 취소하면 이후 업데이트는 중지되지만 기존 멤버는 변경되지 않습니다. SSO 연결을 삭제하면 모든 토큰이 취소됩니다.

## SSO와 디렉터리 동기화

워크스페이스에서 토큰을 한 번이라도 발급하면 SSO는 더 이상 [멤버를 자동으로 추가](/console/sso#automatic-membership)하지
않습니다. 나중에 토큰을 취소하더라도 멤버십은 디렉터리가 결정합니다.
