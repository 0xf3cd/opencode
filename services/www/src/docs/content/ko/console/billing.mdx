Console은 팀 규모와 관계없이 무료이며 좌석 요금이 없습니다. 워크스페이스 전체에서 사용하는 선불 크레딧으로 사용량만큼만
지불합니다. 소유자와 관리자는 **Settings › Billing**에서 결제를 관리합니다.

[자체 제공자](/console/providers)를 통한 사용량은 Console이 아니라 해당 제공자가 청구합니다.

## 결제 수단 추가

1. **Settings › Billing**을 여세요.
2. **Payment methods** 아래에서 **Add**를 클릭하세요.
3. 결제 수단을 선택하고 Stripe 설정을 완료하세요.

지원되는 결제 수단은 다음과 같습니다.

- Card
- Link
- Alipay
- UPI
- WeChat Pay

자동 결제에 사용할 수단은 **⋯ › Make default**로 선택하세요. 결제 수단을 제거하면 해당 수단을 사용하는 자동 충전과 Go
갱신이 중지될 수 있습니다.

## 크레딧 추가

1. **Credits** 아래에서 **Add credits**를 클릭하세요.
2. $10, $50, $100 중 하나를 고르거나 **Other**를 선택하고 금액을 입력하세요.
3. 결제 수단을 선택하고 **Confirm and pay**를 클릭하세요.

4.6% + $0.31의 처리 수수료가 별도로 추가됩니다. 따라서 $50를 구매하면 $52.61가 결제되고 잔액에는 $50 전액이
추가됩니다.

## 자동 충전

자동 충전은 잔액이 부족해지면 크레딧을 구매합니다.

1. **Auto-recharge** 아래에서 **Add rule**을 클릭하세요.
2. 결제를 실행할 잔액 기준과 추가할 금액을 설정하세요.
3. **Save**를 클릭하세요.

자동 충전은 처리 수수료를 포함해 기본 결제 수단으로 결제합니다. 결제에 실패하면 다시 설정할 때까지 자동 충전이
꺼집니다.

## 잔액 확인

소유자와 관리자는 **Overview**의 **Credits** 카드에서 잔액을 확인할 수 있습니다.

## 크레딧이 소진되면

잔액이 0이 되면 유료 요청이 HTTP `402`로 실패합니다. 잔액은 마이너스가 되지 않습니다.

```text
Upstream request failed: Insufficient account funds
```

## 청구서

모든 결제는 **Invoices** 아래에 상태와 함께 표시되며, **Download invoice** 또는 **View receipt** 링크가 제공됩니다.

| 항목             | 생성 시점          |
| ---------------- | ------------------ |
| Balance top-up   | 크레딧 추가        |
| Automatic top-up | 자동 충전          |
| Go subscription  | Go 구독            |
| Go renewal       | 월간 Go 갱신       |
| Monthly Usage    | 청구서 결제        |

## 청구서 결제

신용 계약을 맺은 워크스페이스는 크레딧을 구매하는 대신 매월 청구서를 받을 수 있습니다. 설정하려면 지원팀에
문의하세요.

- 사용량은 선불 잔액 대신 신용 한도에서 차감됩니다.
- 매월 청구서는 1일(UTC)에 발행되며 14일 후가 납부 기한입니다.
- 미결제 청구서에는 **Pay now** 버튼이 있습니다.
- 신용 한도에 도달하거나 청구서가 연체되면 요청이 HTTP `402`로 실패합니다.

## Go

[OpenCode Go](/console/go) 구독은 같은 결제 수단을 사용하며 같은 청구서 목록에 표시됩니다. Go 한도에 도달한 후 크레딧으로
결제하려면 **Overview** 크레딧 카드에서 **Extra usage**를 켜세요.
