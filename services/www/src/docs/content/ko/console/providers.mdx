title: "제공자"
description: "보유한 모델 제공자 계정을 OpenCode Console 워크스페이스에 연결하고 멤버가 사용할 모델을 선택합니다."
---

Anthropic, OpenAI, AWS Bedrock처럼 이미 비용을 내고 있는 제공자 계정을 연결해 워크스페이스의 모든 사람과 모델을
공유하세요. Console은 자격 증명을 저장하고 게이트웨이를 통해 각 제공자를 서빙하므로, 멤버는 제공자 키를 보지 않고도
모델을 사용할 수 있습니다. 같은 게이트웨이를 [Providers API](/console/api/providers)로 자체 도구에서도 사용할 수
있습니다.

소유자와 관리자는 **Providers** 탭에서 제공자를 관리합니다. 멤버는 `/connect`를 실행하면 OpenCode에서 활성화된 모델을
사용할 수 있습니다.

## 제공자 연결

1. **Providers**를 열고 **Connect Provider**를 클릭하세요.
2. 카탈로그에서 제공자를 고르고 API 키를 입력하세요.
3. 필요하면 **Test connection**을 클릭한 다음 **Save**를 클릭하세요.

카탈로그에는 Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter 등 많은 제공자가 있습니다. 카탈로그
제공자는 모델이 미리 구성되어 있습니다.

### 클라우드 제공자

클라우드 제공자는 몇 가지 정보를 추가로 입력해야 합니다.

| 제공자                | 필요한 정보                           |
| --------------------- | ------------------------------------- |
| Azure                 | 리소스 이름과 API 키                  |
| AWS Bedrock           | 리전과 API 키                         |
| Google Vertex AI      | 리전과 서비스 계정 JSON               |
| Cloudflare AI Gateway | 계정 ID, 게이트웨이 ID, API 토큰      |
| Databricks            | 워크스페이스 URL과 토큰               |

### 사용자 지정 제공자

**Add Custom Provider**를 클릭해 다른 엔드포인트를 연결한 다음, **Add Model**로 모델을 추가하세요.

| 필드       | 설명                                                                            |
| ---------- | ------------------------------------------------------------------------------- |
| Base URL   | Console이 요청을 전달할 주소입니다(예: `https://api.deepseek.com/v1`).          |
| Format     | Chat Completions, Responses API, Anthropic Compatible, Google Generative AI 중 하나입니다. |
| Auth mode  | Bearer, API key header, Custom header 중 하나입니다.                            |
| Credential | Console이 제공자에게 보내는 키입니다.                                           |

## 모델 선택

제공자를 열면 모델 목록을 볼 수 있습니다. 멤버는 활성화된 모델만 사용할 수 있습니다.

- **Enabled** 토글로 모델을 켜거나 끕니다.
- **New models**를 켜면 제공자가 앞으로 추가하는 모델도 활성화됩니다.

## 모델 편집

모델을 클릭해 편집하세요. 변경 사항은 패널을 닫을 때 저장됩니다.

| 섹션          | 변경할 수 있는 항목                                             |
| ------------- | --------------------------------------------------------------- |
| General       | 표시 이름, API ID, 도구 지원 여부, 입력 및 출력 유형            |
| Variants      | 자체 헤더나 본문을 가진 변형                                    |
| Configuration | 기본 변형, 요청 헤더와 본문, 토큰 한도                          |
| Cost Tiers    | 1M 토큰당 입력, 출력, 캐시 읽기, 캐시 쓰기 가격                 |

### 사용자 지정 가격

카탈로그 모델은 처음에 제공자의 정가로 설정됩니다. OpenAI 계약 할인처럼 별도로 협상한 가격이 있다면 **Cost Tiers**에서
가격을 재정의해 사용량 보고서와 [예산](/console/budgets)이 실제로 지불하는 금액과 일치하도록 하세요.

| 필드             | 정가       | 협상 가격  |
| ---------------- | ---------- | ---------- |
| 입력 가격        | $2.50      | $2.00      |
| 출력 가격        | $15.00     | $12.00     |
| 캐시 읽기 가격   | $0.25      | $0.20      |

변경한 가격은 제공자 페이지에서 강조 표시됩니다. 정가로 되돌리려면 필드에서 **Restore default value**를 사용하거나,
모델에서 <strong>⋯ › Restore...</strong>를 사용하세요.

특정 컨텍스트 크기를 넘으면 더 비싼 요금이 부과되는 모델에는 **Context** 등급을 추가하세요(예: 200K 토큰을 넘는
프롬프트).

### 사용자 지정 모델

카탈로그에 없는 모델을 추가하려면 **Add Model**을 클릭하고 **Display name**과 **Model ID**를 입력하세요. 기존 모델의
설정에서 시작하려면 해당 모델에서 <strong>⋯ › Duplicate...</strong>를 사용하세요.

## OpenCode 모델

**Models** 탭에서는 Console이 제공하는 [모델](/console/models)을 관리합니다. 이 모델의 비용은 워크스페이스 크레딧에서
차감됩니다. 제공자 페이지와 같은 방식으로 동작합니다.

- 모델을 개별적으로 켜거나 끕니다.
- **Free models**를 끄면 워크스페이스에서 무료 모델을 차단합니다.
- **New models**를 켜면 새 Console 모델이 자동으로 활성화됩니다.

자체 제공자만 사용하려면 **⋯ › Disable**로 제공자 전체를 비활성화하세요.

## OpenCode에서 사용

멤버가 `/connect`를 실행하고 워크스페이스를 선택하면, 활성화된 각 제공자가 워크스페이스 이름 뒤에 제공자 이름이 붙은
형태로 표시되고 `/models`에 해당 제공자의 활성화된 모델이 나열됩니다.

```text
Acme Inc. / Anthropic
```

**Settings › General**에서 **Managed providers only**를 켜면 모든 사람이 OpenCode에서 워크스페이스의 제공자만 사용하도록
제한할 수 있습니다.

## 비활성화 또는 제거

제공자의 **⋯** 메뉴를 여세요.

- **Disable**은 멤버에게서 제공자와 모델을 숨기지만 설정은 유지합니다.
- <strong>Remove...</strong>는 제공자와 모델을 삭제합니다. 대화 상자에 최근 사용한 사람이 표시되며, **Disable instead**(대신
  비활성화) 옵션도 제공됩니다.

키를 교체하려면 제공자 페이지에서 자격 증명을 클릭하고 새 키를 입력하세요.

## 결제

토큰 비용은 제공자가 청구하며, Console은 이에 대해 크레딧을 차감하지 않습니다. 다만 Console은 모델 가격을 기준으로 각
요청과 비용을 기록하므로 사용량 보고서와 [예산](/console/budgets)에 반영됩니다.

OpenCode 대신 자체 도구에서 제공자를 호출하려면 [Providers API](/console/api/providers)를 사용하세요.
