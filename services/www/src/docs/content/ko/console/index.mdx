[OpenCode Console](https://opencode.ai/console)은 혼자서든 팀으로든 OpenCode를 더 편리하게 사용할 수 있도록 추가 기능을
제공하는 선택형 서비스입니다.

- [팀](/console/members)과 접근 권한을 공유하는 [워크스페이스](/console/workspaces)
- 상용 모델과 오픈 소스 모델을 모두 지원하는 [추론](/console/models)
- Console 게이트웨이를 통해 자체 제공자 계정을 연결하는 [제공자](/console/providers)
- 사용량 추적 및 [예산](/console/budgets) 관리
- OpenCode 동작을 제어하는 팀 전체 정책 배포
- [웹 검색](/console/websearch)
- 오픈 소스 모델을 이용할 수 있는 월 $10, $40 구독 플랜 [OpenCode Go 및 Go Plus](/console/go)

## 시작하기

Console을 사용하는 데 팀이 필요하지는 않습니다. 모든 계정에는 본인만 멤버인 **Personal** 워크스페이스가 기본으로
생성됩니다.

1. [Console](https://opencode.ai/console)에 로그인하세요.
2. [Go](/console/go)를 구독하거나, [크레딧](/console/billing#add-credits)을 추가하거나, [제공자](/console/providers)를 연결하세요.
3. OpenCode에서 `/connect`를 실행하고 워크스페이스를 선택하세요.
4. 필요하면 팀원을 [초대](/console/members#invite-members)하세요.

```text
/connect
```

## 정책

**Policies** 페이지의 Providers 및 Tools 규칙은 워크스페이스에 연결된 모든 OpenCode V2 클라이언트에 적용됩니다. 이
규칙은 멤버 자신의 구성보다 최종적으로 우선하는 [정책](/policies#console) 구문으로 전달되며, 약 1분 안에 적용됩니다.
