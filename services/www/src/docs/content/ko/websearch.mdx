---
title: "웹 검색"
---

OpenCode에 최신 정보를 물어보면 웹을 검색하고 결과를 읽은 뒤, 출처 링크를 포함해 답변합니다.

```text
Find the latest Bun release and summarize the changes.
```

처음 검색할 때 웹 검색을 허용하고 제공자를 선택하라는 메시지가 표시됩니다. OpenCode는 이 선택을 기억해 이후 세션에서도
사용합니다.

## 제공자

OpenCode에는 다섯 가지 검색 제공자가 포함되어 있습니다.

| 제공자 | ID | 환경 변수 |
| --- | --- | --- |
| Exa | `exa` | `EXA_API_KEY` |
| Firecrawl | `firecrawl` | `FIRECRAWL_API_KEY` |
| Parallel | `parallel` | `PARALLEL_API_KEY` |
| Tavily | `tavily` | `TAVILY_API_KEY` |
| TinyFish | `tinyfish` | `TINYFISH_API_KEY` (선택 사항) |

TUI에서 `/connect`로 계정을 연결하거나, OpenCode를 시작하기 전에 제공자의 환경 변수를 설정하세요.

```bash
$ TAVILY_API_KEY=your-key opencode
```

## 선택

`opencode.jsonc`에 제공자를 지정하면 선택 메시지를 건너뜁니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "tavily",
  },
}
```

`"random"`을 사용하면 사용 가능한 제공자를 자동으로 선택합니다. 각 세션은 선택된 제공자가 요청 한도(rate limit)에
걸릴 때까지 그 제공자를 계속 사용합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "random",
  },
}
```

## 한도

제공자가 HTTP 429를 반환하면, 무작위 선택 모드에서는 사용 가능한 다른 제공자로 검색을 다시 시도합니다. 요청 한도에
걸린 제공자는 `Retry-After` 기간 동안 대기하며, 응답에 유효한 기간이 없으면 60초 동안 대기합니다.

```text
Exa returns HTTP 429
→ Exa enters cooldown
→ OpenCode retries with another provider
```

모든 제공자가 대기 중이면 검색은 즉시 실패합니다. 세션을 이동하거나 해당 서버를 다시 시작하면 세션이 기억하던 제공자가
초기화됩니다. 대기 상태는 같은 워크스페이스의 세션끼리 공유합니다.

## 권한

웹 검색은 `websearch` 권한 동작을 사용하며, 검색어를 리소스로 사용합니다. 다음 예시는 명시적으로 허용되지 않은 검색을
실행하기 전에 확인을 요청합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "permissions": [
    {
      "action": "websearch",
      "resource": "*",
      "effect": "ask",
    },
  ],
}
```

규칙 순서와 일치 방식은 [권한](/permissions)을 참고하세요.

## 비활성화

`websearch`를 `false`로 설정하면 모델 요청에서 웹 검색 도구가 제거됩니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": false,
}
```
