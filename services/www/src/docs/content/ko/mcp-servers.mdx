---
title: "MCP 서버"
---

OpenCode는 [Model Context Protocol](https://modelcontextprotocol.io/) 서버에 연결해 도구, 프롬프트, 리소스, 지침 같은 기능을 제공합니다. MCP 도구는 모델 컨텍스트를 소비하므로 필요한 서버만 추가하세요.

## 설정

원격 서버를 사용할 프로젝트에서 서버를 추가한 다음, 연결 상태를 확인하세요.

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
opencode mcp list
```

이 명령은 프로젝트 [구성](/config)에 서버를 기록합니다. 모든 프로젝트에서 사용하려면 `--global`을 추가하세요.

```sh
opencode mcp add context7 --global --url https://mcp.context7.com/mcp
```

원격 서버는 기본적으로 OAuth를 사용합니다. 목록에 `needs authentication`이 표시되면 OpenCode를 열고 `/mcps`를 실행한 뒤, 서버를 선택해 로그인하세요. 연결된 서버는 에이전트가 바로 사용할 수 있습니다.

```text
✓ context7  connected
```

## 구성

서버를 직접 구성하려면 `mcp.servers` 아래에 고유한 이름으로 추가하세요. V2에서는 서버 이름을 `mcp` 바로 아래에 두지 않습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
      },
    },
  },
}
```

서버는 자동으로 연결됩니다. 서버를 구성해 두되 연결하지 않으려면 `enabled` 필드가 아니라 `disabled`를 사용하세요.

```jsonc
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "local",
        "command": ["npx", "-y", "example-mcp-server"],
        "disabled": true,
      },
    },
  },
}
```

우선순위가 더 높은 프로젝트 구성은 같은 이름의 서버 객체 전체를 대체합니다. 연결이나 계정을 분리하려면 서로 다른 이름을 사용하고, 같은 이름으로 재정의한다면 필수 필드를 모두 다시 작성하세요.

```jsonc title="opencode.jsonc"
{
  "mcp": {
    "servers": {
      "my-server": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
      },
    },
  },
}
```

## 로컬

로컬 서버는 OpenCode가 MCP stdio 전송 방식으로 실행하는 명령입니다. `--` 뒤에 명령을 붙여 추가하세요.

```sh
opencode mcp add everything -- npx -y @modelcontextprotocol/server-everything
```

작업 디렉터리나 환경 변수 같은 프로세스 옵션은 구성에서 지정하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "everything": {
        "type": "local",
        "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
        "cwd": ".",
        "environment": {
          "LOG_LEVEL": "info",
          "MCP_API_KEY": "{env:MCP_API_KEY}",
        },
      },
    },
  },
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `type` | 예 | `"local"`이어야 합니다. |
| `command` | 예 | 실행 파일과 그 뒤에 오는 인수입니다. |
| `cwd` | 아니요 | 프로세스 디렉터리입니다. 상대 경로는 워크스페이스를 기준으로 해석되며, 기본값도 워크스페이스입니다. |
| `environment` | 아니요 | OpenCode에서 상속된 프로세스 환경에 추가할 문자열 변수입니다. |
| `disabled` | 아니요 | `true`이면 연결하지 않습니다. 기본값은 `false`입니다. |
| `codemode` | 아니요 | `false`로 설정하면 Code Mode를 거치지 않고 도구를 직접 노출합니다. 기본값은 `true`입니다. |
| `timeout` | 아니요 | 서버별 제한 시간 재정의입니다. |
| `protocol` | 아니요 | `legacy`(기본값), `auto`, `2026-07-28` 중 하나입니다. [프로토콜 버전](#protocol-version)을 참고하세요. |

환경 변수를 치환하려면 `{env:NAME}`을 사용하세요. JSON 문자열 안의 `$NAME` 같은 셸 표현식은 확장되지 않습니다.

```jsonc
{
  "environment": {
    "MCP_API_KEY": "{env:MCP_API_KEY}",
  },
}
```

## 원격

원격 서버는 MCP Streamable HTTP 전송 방식을 사용하며, 절대 URL이 필요합니다.

```sh
opencode mcp add context7 --url https://mcp.context7.com/mcp
```

서버에 헤더나 기타 옵션이 필요하면 구성을 사용하세요. 비밀 값은 파일에 직접 넣지 말고 환경 변수에 저장하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "oauth": false,
        "headers": {
          "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}",
        },
      },
    },
  },
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `type` | 예 | `"remote"`여야 합니다. |
| `url` | 예 | Streamable HTTP 엔드포인트의 절대 URL입니다. |
| `headers` | 아니요 | 엔드포인트로 보낼 문자열 HTTP 헤더입니다. |
| `oauth` | 아니요 | OAuth 설정입니다. `false`로 설정하면 OAuth를 비활성화합니다. |
| `disabled` | 아니요 | `true`이면 연결하지 않습니다. 기본값은 `false`입니다. |
| `codemode` | 아니요 | `false`로 설정하면 Code Mode를 거치지 않고 도구를 직접 노출합니다. 기본값은 `true`입니다. |
| `timeout` | 아니요 | 서버별 제한 시간 재정의입니다. |
| `protocol` | 아니요 | `legacy`(기본값), `auto`, `2026-07-28` 중 하나입니다. [프로토콜 버전](#protocol-version)을 참고하세요. |

`oauth: false`는 서버가 API 키나 다른 헤더 자격 증명만 사용하는 경우에만 지정하세요.

```jsonc
{
  "type": "remote",
  "url": "https://mcp.example.com/mcp",
  "oauth": false,
  "headers": { "Authorization": "Bearer {env:MCP_API_KEY}" },
}
```

## OAuth

`oauth`가 `false`가 아니면 원격 서버에는 OAuth가 활성화됩니다. OpenCode는 인증 서버를 찾고, PKCE를 사용하고, 토큰을 갱신하며, 지원되는 경우 동적 클라이언트 등록을 시도합니다. 자격 증명은 프로젝트 구성 밖에 보관됩니다.

동적 등록을 사용하려면 서버 URL만 구성하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
      },
    },
  },
}
```

서버에 인증이 필요하면 `/mcps`를 실행하고 서버를 선택한 뒤, 브라우저에서 인증을 완료하세요. CLI에서도 같은 흐름을 시작할 수 있습니다.

```sh
opencode mcp auth sentry
```

서비스 제공 측에서 클라이언트 자격 증명을 발급했다면 V2의 snake_case OAuth 필드를 사용하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "company-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "oauth": {
          "client_id": "{env:MCP_CLIENT_ID}",
          "client_secret": "{env:MCP_CLIENT_SECRET}",
          "scope": "tools:read tools:execute",
          "callback_port": 19876,
          "redirect_uri": "http://127.0.0.1:19876/callback",
        },
      },
    },
  },
}
```

| 필드 | 설명 |
| --- | --- |
| `client_id` | 미리 등록된 클라이언트 ID입니다. 생략하면 동적 등록을 시도합니다. |
| `client_secret` | 미리 등록된 클라이언트의 시크릿입니다. |
| `scope` | 요청할 스코프를 공백으로 구분해 지정합니다. |
| `callback_port` | `1`부터 `65535`까지의 로컬 콜백 포트입니다. 기본값은 사용 가능한 임시 포트입니다. |
| `redirect_uri` | 미리 등록된 루프백 URI로, 경로와 포트가 로컬 콜백 리스너로 연결되어야 합니다. |
| `auth_server_metadata_url` | 인증 서버의 OAuth 또는 OpenID Connect 메타데이터 문서 URL입니다. MCP 서버가 인증 서버를 명시한 보호된 리소스 메타데이터를 게시하지 않을 때 설정하세요. |

다시 로그인하거나 계정을 전환해야 할 때는 저장된 OAuth 자격 증명을 제거하세요.

```sh
opencode mcp logout sentry
```

## 제한 시간

제한 시간은 밀리초 단위의 양의 정수입니다. 기본값은 `mcp.timeout` 아래에 설정하고, 서버의 `timeout` 객체로 해당 기본값을 재정의할 수 있습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "timeout": {
      "startup": 45000,
      "catalog": 30000,
      "execution": 600000,
    },
    "servers": {
      "slow-tools": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "timeout": {
          "catalog": 60000,
        },
      },
    },
  },
}
```

| 제한 시간 | 기본값 | 적용 대상 |
| --- | --- | --- |
| `startup` | 30초 | 전송 연결 및 서버 초기화 |
| `catalog` | 30초 | 도구, 프롬프트, 리소스, 리소스 템플릿 목록 조회 |
| `execution` | 12시간 | 도구 호출, 프롬프트 조회, 리소스 읽기 |

## 프로토콜 버전

OpenCode는 기본적으로 모든 서버에 기존 MCP `initialize` 핸드셰이크로 연결합니다. 2026-07-28 리비전 기반 서버와 통신하려면 해당 서버의 `protocol`을 설정하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "modern": {
        "type": "remote",
        "url": "https://mcp.example.com/mcp",
        "protocol": "auto",
      },
    },
  },
}
```

| 값 | 동작 |
| --- | --- |
| `legacy` | 기본값입니다. `initialize`를 보내고 2025-11-25까지의 프로토콜 리비전을 사용합니다. |
| `auto` | `server/discover`로 2026-07-28 리비전 지원 여부를 확인하고, 서버가 지원하지 않으면 `legacy`로 대체합니다. |
| `2026-07-28` | 2026-07-28 리비전을 요구합니다. 이전 서버에서는 연결이 실패합니다. |

로컬 `legacy` 서버를 확인할 때는 수명이 짧은 추가 프로세스가 생기며, 서버가 알 수 없는 요청을 무시하면 시작 제한 시간까지 기다릴 수 있습니다. 따라서 `auto`는 필요한 서버에만 사용하세요.

## 이름

OpenCode는 도구 이름을 `<server>_<tool>`로 지정합니다. 영문자, 숫자, `_`, `-` 이외의 문자는 `_`로 바꿉니다.

```text
server: context 7
tool:   resolve.library/id
name:   context_7_resolve_library_id
```

MCP 프롬프트는 같은 정규화를 거쳐 `<server>:<prompt>` 이름의 명령이 됩니다. 예를 들면 다음과 같습니다.

```text
/context_7:find_docs
```

정규화 후에도 고유하게 유지되는 짧은 서버 이름을 선택하세요. 기본값인 Code Mode에서는 도구가 정규화된 서버 이름별로 묶입니다.

```text
tools.context_7.resolve_library_id(...)
```

## 권한

Code Mode가 기본값입니다. 서버의 도구를 제공자의 네이티브 도구 목록에 유지해야 한다면 `codemode`를 `false`로 설정하세요.

```jsonc
{
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp",
        "codemode": false,
      },
    },
  },
}
```

서버 연결을 끊지 않고 도구를 숨기거나 거부하려면 권한 동작을 사용하세요. 정규화된 `<server>_<tool>` 이름과 일치시키면 됩니다.

```jsonc
{
  "permissions": [
    {
      "action": "context7_*",
      "resource": "*",
      "effect": "deny",
    },
  ],
}
```

## 컨텍스트

세션을 대신해 호출할 때 OpenCode는 `CallToolRequest.params._meta["ai.opencode/sessionID"]`에 세션 ID를 담아 보냅니다. 이는 stdio와 Streamable HTTP 모두에서 직접 노출된 도구와 Code Mode에 적용됩니다.

```json
{
  "method": "tools/call",
  "params": {
    "name": "lookup",
    "arguments": { "query": "example" },
    "_meta": { "ai.opencode/sessionID": "ses_..." }
  }
}
```

이 ID는 도구 인수가 아니라 요청 메타데이터이므로, 모델에 보이는 스키마에는 나타나지 않습니다. 내용을 해석하지 않는 상관관계 식별 값으로 취급하세요.

| 규칙 | 동작 |
| --- | --- |
| 식별 대상 | MCP 전송 세션이 아니라, 호출한 OpenCode 세션을 식별합니다. |
| 존재 여부 | 세션 컨텍스트가 없는 호출에서는 없을 수 있습니다. |
| 보안 | 이 값만으로 인증이나 권한 부여를 하지 마세요. |
| 개인정보 | 원격 서버는 원본 ID를 받으며, 이를 로그에 기록하거나 보관할 수 있습니다. |

## 관리

어느 프로젝트에서든 서버 목록과 현재 연결 상태를 확인할 수 있습니다.

```sh
opencode mcp list
```

OpenCode에서 `/mcps`를 사용하면 서버를 확인하고, 연결하거나 연결을 끊고, 인증할 수 있습니다. 서버 추가와 OAuth 자격 증명 관리는 CLI로 하세요.

```sh
opencode mcp add sentry --url https://mcp.sentry.dev/mcp
opencode mcp auth sentry
opencode mcp logout sentry
```

서버를 제거하려면 서버를 추가한 프로젝트 또는 전역 구성에서 해당 항목을 삭제하세요.

```jsonc
{
  "mcp": {
    "servers": {},
  },
}
```

OAuth 클라이언트 설정, 제한 시간, 작업 디렉터리, 영구적인 활성화 여부는 구성을 직접 편집하세요.

```jsonc
{
  "mcp": {
    "servers": {
      "sentry": {
        "type": "remote",
        "url": "https://mcp.sentry.dev/mcp",
        "disabled": true,
      },
    },
  },
}
```
