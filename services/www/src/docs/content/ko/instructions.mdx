---
title: "지침"
---

`AGENTS.md` 파일을 추가하면 OpenCode에 프로젝트 지침을 지속적으로 제공할 수 있습니다. 빌드 명령, 아키텍처 메모, 코드
규칙, 검증 요구 사항 등을 담는 데 사용하세요.

```md title="AGENTS.md"
# Project instructions

- Run `bun typecheck` after changing TypeScript.
- Keep database queries in `src/database`.
- Do not edit generated files directly.
```

프로젝트 지침 파일을 커밋해 두면 저장소에서 작업하는 모든 사람이 같은 지침을 받습니다.

## 범위

`AGENTS.md`는 지침을 적용할 디렉터리에 두세요. OpenCode는 전역 파일을 먼저 로드한 다음, 현재 워크스페이스 디렉터리에서
홈 디렉터리 방향으로 올라가며 모든 `AGENTS.md`를 로드합니다. 워크스페이스가 홈 디렉터리 밖에 있으면 프로젝트 루트에서
멈춥니다.

```text
~/.config/opencode/AGENTS.md
~/code/my-project/AGENTS.md
~/code/my-project/packages/AGENTS.md
~/code/my-project/packages/web/AGENTS.md  ← current workspace
```

이 예에서는 네 파일이 모두 로드되며, 다음 순서로 합쳐집니다.

```text
~/.config/opencode/AGENTS.md
packages/web/AGENTS.md
packages/AGENTS.md
AGENTS.md
```

모든 곳에 적용되는 지침은 전역 파일에 두세요. 저장소 전체에 적용되는 지침은 프로젝트 루트에, 더 구체적인 지침은 해당
코드와 가까운 곳에 두세요. OpenCode는 파일들을 합칠 뿐, 파일 간의 충돌을 해결하지 않습니다.

워크스페이스가 프로젝트 루트 밖에 있으면 전역 파일만 로드됩니다. 전역 파일은 유지하면서 프로젝트 `AGENTS.md` 탐색만
건너뛰려면 `OPENCODE_DISABLE_PROJECT_CONFIG=1`을 설정하세요.

<Callout type="note">
  OpenCode V2는 `AGENTS.md`만 인식합니다. `CLAUDE.md`를 대체 파일로 사용하지 않습니다.
</Callout>

## 탐색

워크스페이스 아래에 있는 지침 파일은 에이전트가 프로젝트를 탐색하면서 발견됩니다. 파일을 읽거나 디렉터리 목록을 조회하면
해당 대상과 워크스페이스 사이에 있는 모든 `AGENTS.md` 파일이 로드됩니다.

```text
my-project/                         ← current workspace
├── AGENTS.md                       loaded initially
└── packages/
    └── web/
        ├── AGENTS.md               loaded when this area is read
        └── src/
            └── app.ts              read target
```

중첩된 파일은 가장 가까운 것부터 로드되며, 해당 지침 항목이 모델에 보이는 기록에 남아 있는 동안에는 중복 제거됩니다.
같은 영역을 다시 읽어도 일반적으로 다시 주입되지 않습니다. 컨텍스트 압축이나 되돌리기로 해당 항목이 제거되면, 이후에
읽을 때 파일이 다시 로드될 수 있습니다.

중첩된 파일은 로드된 후에 수정해도 변경 사항이 자동으로 감지되지 않습니다. 수정한 내용을 즉시 적용해야 한다면 새 세션을
시작하세요.

## 순서

선택한 에이전트 또는 제공자의 시스템 프롬프트가 가장 먼저 전송됩니다. 이후 OpenCode는 다음 순서로 초기 지침을
구성합니다.

```text
1. Agent or provider system prompt
2. Built-in environment and date context
3. Code Mode tool guidance, when enabled
4. Global and project AGENTS.md files
5. Available skill, reference, and MCP guidance
6. Session-specific instruction entries supplied through the API
```

이 소스들은 서로 재정의하지 않고 모두 합쳐집니다. 나중에 발견된 중첩 `AGENTS.md` 파일은 발견된 순서대로 세션 기록에
추가됩니다.

## 업데이트

세션이 실행 중일 때 전역 `AGENTS.md`나 상위 방향으로 탐색된 `AGENTS.md`를 수정하면 해당 지침이 업데이트됩니다.

```bash
$ printf '\n- Run the integration suite before committing.\n' >> AGENTS.md
```

다음 모델 요청 전에 OpenCode가 변경 사항을 감지하고, 대기 중인 입력을 전달하기 전에 지침 업데이트를 추가합니다.

```text
AGENTS.md changes
→ instruction update
→ next prompt
```

- 자동으로 로드되는(전역 및 상위 방향) `AGENTS.md`를 모두 제거하면, 이전 지침이 더 이상 적용되지 않는다는 사실이 세션에 전달됩니다.
- 일시적으로 읽기에 실패하면 지침이 삭제된 것으로 처리하지 않고 마지막으로 확인된 지침을 유지합니다.
- 세션을 이동해도 지침 상태가 유지되므로, 이동한 위치의 지침은 업데이트로 추가됩니다.
- 세션 되돌리기를 확정하면 지침 상태가 초기화되고, 다음 프롬프트 전에 지침을 다시 로드합니다.

지침 내용은 계속 특권 정보로 취급됩니다. 클라이언트는 어떤 소스가 변경되었는지는 볼 수 있지만, 그 내용은 볼 수 없습니다.

## 구성

V2 구성 스키마는 `instructions` 배열을 허용하지만, 현재 V2는 여기에 지정한 파일, glob 패턴, URL을 해석하지 않습니다.
다음 구성은 아직 모델에 지침을 추가하지 않습니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "instructions": ["CONTRIBUTING.md", "docs/guidelines/*.md", "https://example.com/instructions.md"],
}
```

V2에서 실제로 적용되는 지침에는 `AGENTS.md`를 사용하세요. 구성 파일 위치와 우선순위는 [구성](/config)을 참고하세요.
