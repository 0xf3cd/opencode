Los ajustes de la CLI solo controlan los clientes de terminal. Son independientes de los ajustes del servidor y del
proyecto en `opencode.json(c)`.

Pulsa `Ctrl+P` y selecciona **Open settings** para cambiar los ajustes más comunes desde la TUI.

<img src={`${import.meta.env.BASE_URL}assets/docs/cli/settings.png`} alt="Diálogo de ajustes de la TUI de OpenCode" />

## Archivo de configuración

OpenCode guarda los ajustes de la CLI en un único archivo global:

```text
~/.config/opencode/cli.json
```

Si `$XDG_CONFIG_HOME` está definida, OpenCode usa:

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

No existe un archivo de ajustes de la CLI por proyecto. Añade el JSON Schema publicado para obtener validación y
autocompletado:

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode añade `$schema` cuando crea o migra este archivo. Los ajustes desconocidos se rechazan, y los cambios válidos se
recargan mientras la TUI está en ejecución.

## Configuración en línea

Define `OPENCODE_CLI_CONFIG_CONTENT` para aplicar ajustes de la CLI a partir de JSON en línea:

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode combina los ajustes en línea con el `cli.json` global, y los primeros tienen prioridad. Los objetos anidados se
combinan, mientras que los arrays y los valores escalares de la variable de entorno reemplazan a los valores globales.
Los ajustes en línea prevalecen mientras la variable esté definida.

## Apariencia
Elige un tema, controla el movimiento de la interfaz y sobrescribe el cursor de la terminal:

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de apariencia" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `theme.name`      | cadena                                  | Selecciona un tema integrado, personalizado o derivado de la terminal.   |
| `theme.mode`      | `system`, `dark` o `light`              | Sigue la apariencia de la terminal o fija el tema en un modo de color.   |
| `animations`      | booleano                                | Activa las animaciones de la interfaz.                                   |
| `cursor.style`    | `block`, `underline`, `line`, `default` | Define la forma del cursor. `default` conserva la forma del cursor de la terminal. |
| `cursor.blinking` | booleano                                | Controla el parpadeo del cursor. No tiene efecto si el estilo es `default`. |

</div>

Consulta [Tema](/cli/theme) para seleccionar y crear temas.

## Entrada

Configura la captura del ratón, el desplazamiento, el contexto del editor, el pegado y las vistas previas de imágenes en
el prompt:

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de entrada" tabIndex={0}>

| Ajuste | Valores | Descripción |
| -------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| `mouse`                    | booleano                        | Activa la captura del ratón en la terminal.                                 |
| `scroll.speed`             | número, como mínimo `0.001`     | Define la distancia fija por cada paso de desplazamiento.                   |
| `scroll.acceleration`      | booleano                        | Acelera el desplazamiento repetido. Si está activado, tiene prioridad sobre la velocidad. |
| `prompt.editor`            | booleano                        | Incluye el archivo o la selección del editor activo como contexto del prompt. |
| `prompt.paste`             | `compact` o `full`              | Muestra los pegados grandes como marcadores compactos o como texto completo. |
| `prompt.image_preview`     | booleano                        | Muestra vistas previas de las imágenes adjuntas sobre el campo del prompt.  |

</div>

## Sesiones

Configura cómo se presentan las sesiones de la TUI a pantalla completa y dónde empiezan las sesiones nuevas:

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de sesión" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `session.sidebar`       | `auto` o `hide`             | Muestra la barra lateral cuando hay espacio o la oculta siempre.             |
| `session.scrollbar`     | booleano                    | Muestra la barra de desplazamiento de la transcripción.                      |
| `session.thinking`      | `show` o `hide`             | Muestra u oculta de forma predeterminada el razonamiento del modelo.         |
| `session.grouping`      | `auto` o `none`             | Agrupa los elementos relacionados de la transcripción o muestra cada uno por separado. |
| `session.image_preview` | booleano                    | Muestra en la transcripción las imágenes adjuntas por el usuario y las de los resultados de herramientas. |
| `session.tps`           | booleano                    | Muestra los tokens de salida por segundo en el pie de las respuestas del asistente. |
| `session.markdown`      | `source` o `rendered`       | Muestra los marcadores de sintaxis Markdown o los oculta en el contenido renderizado. |
| `session.new_location`  | `launch` o `inherit`        | Empieza en el directorio desde el que se inició la TUI o hereda la ubicación de la sesión activa. |
| `session.permissions`   | `prompt` o `autoaccept`     | Pregunta en cada solicitud de permiso o acepta todas las solicitudes automáticamente. |

</div>

## Pestañas

Configura la barra persistente de pestañas de sesión:

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

El antiguo ajuste booleano `tabs.enabled` sigue siendo compatible: `true` equivale a `on` y `false`, a `off`. OpenCode lo lee sin reescribir el archivo de configuración.

<div class="docs-table-scroll" role="region" aria-label="Ajustes de pestañas" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ----------------- | --------------------------- | ----------------------------------------------------------------------------- |
| `tabs.mode`       | `auto`, `on` o `off`        | Usa pestañas automáticamente, siempre o nunca. `auto` las oculta dentro de Herdr. |
| `tabs.scope`      | `cwd` o `global`            | Mantiene pestañas separadas por directorio de trabajo o las comparte globalmente. |
| `tabs.layout`     | `horizontal` o `vertical`   | Coloca las pestañas en una barra horizontal o en una barra lateral vertical.  |
| `tabs.indicators` | `status` o `numbers`        | Muestra iconos de estado o muestra siempre el número de cada pestaña.         |

</div>

Los indicadores numéricos conservan los colores de estado y las animaciones de fondo. Los atajos Ctrl+número cambian de
pestaña con cualquiera de los dos modos de indicador.

## Diffs

Configura el alcance inicial y la presentación de los diffs:

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de diffs" tabIndex={0}>

| Ajuste | Valores | Descripción |
| -------------- | ------------------------------------------- | --------------------------------------------------------- |
| `diffs.source` | `branch`, `committed`, `working` o `turn`   | Define el alcance inicial de la revisión.                 |
| `diffs.wrap`   | `word` o `none`                             | Ajusta las líneas largas por palabras o no las ajusta.    |
| `diffs.tree`   | booleano                                    | Muestra el árbol de archivos del diff.                    |
| `diffs.single` | booleano                                    | Muestra solo el parche del archivo seleccionado.          |
| `diffs.view`   | `auto`, `split` o `unified`                 | Define el diseño. `auto` lo elige según el ancho disponible. |

</div>

`branch` muestra **All**, es decir, los cambios de la rama y los locales; `committed` muestra solo los commits de la rama,
y `working` muestra los cambios preparados, sin preparar y sin seguimiento. `turn` muestra **Last turn**: los archivos
que la sesión modificó en su último turno. Se actualiza cada vez que la sesión termina un turno y recurre a `branch`
cuando `/diff` no se abre desde una sesión.

En `/diff`, pulsa `d` para cambiar el alcance o elige una rama de comparación en **Base**. Estas elecciones dentro de la
vista duran hasta que se cierra la TUI y no modifican `cli.json`.

## Alertas

Activa por separado las notificaciones del sistema y los sonidos de aviso:

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de alertas" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `attention.notifications` | booleano              | Muestra notificaciones del sistema, normalmente cuando la terminal no tiene el foco.                    |
| `attention.sound`        | booleano               | Reproduce sonidos de aviso.                                                                              |
| `attention.volume`       | número de `0` a `1`    | Define el volumen del sonido.                                                                            |
| `attention.sound_pack`   | cadena                 | Selecciona el ID del paquete de sonidos activo.                                                          |
| `attention.sounds`       | objeto                 | Sobrescribe los archivos de sonido de `default`, `question`, `permission`, `error`, `done` o `subagent_done`. |

</div>

Si una sobrescritura no es válida o no se puede leer, se usa el sonido integrado para ese evento.

Después de una actualización, la TUI muestra una vez en la pantalla de inicio las novedades de la nueva versión. Ejecuta
`/highlights` para volver a verlas o desactiva el diálogo:

```json title="cli.json"
{
  "highlights": false
}
```

## Terminal

Configura la integración con la terminal:

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de terminal" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ---------------- | -------------------- | -------------------------------------------------------------------------------------------------------- |
| `terminal.title` | booleano             | Actualiza el título de la ventana de la terminal.                                                        |
| `terminal.copy`  | `manual` o `select`  | Copia manualmente o justo después de seleccionar. El valor predeterminado es `manual` en Windows y `select` en el resto de plataformas. |

</div>

## Mini

El grupo `mini` controla [`opencode mini`](/cli#mini), la interfaz interactiva mínima:

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de mini" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| `mini.thinking`     | `show` o `hide`                | Muestra u oculta el razonamiento del modelo.                                       |
| `mini.tools`        | `show` o `hide`                | Muestra u oculta las llamadas a herramientas y el texto del asistente que las precede. |
| `mini.shell_output` | `show` o `hide`                | Muestra u oculta la salida sin procesar de la herramienta de shell.                |
| `mini.turn_summary` | `show` o `hide`                | Muestra u oculta en el historial de desplazamiento el resumen con el agente, el modelo y la duración. |
| `mini.footer`       | `show` o `hide`                | Muestra u oculta los detalles persistentes de actividad, modelo, uso y contexto.   |
| `mini.splash`       | `show` o `hide`                | Muestra u oculta los banners de entrada y salida.                                  |
| `mini.work_spinner` | ID de spinner                  | Selecciona la animación de trabajo del pie.                                        |
| `mini.mono`         | booleano                       | Usa salida ASCII monocromática.                                                    |
| `mini.replay`       | booleano                       | Restaura el historial de la sesión al reanudarla y al cambiar el tamaño de la terminal. |
| `mini.replay_limit` | entero positivo                | Limita la reproducción a los mensajes más recientes. El límite predeterminado es `200`. |

</div>

Los ID de spinner disponibles son:

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

Los flags de reproducción de `mini` en la línea de comandos sobrescriben estos ajustes para esa ejecución.

## Atajos de teclado

Sobrescribe el atajo de un comando y el tiempo de espera de la tecla líder:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de atajos de teclado" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ----------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| `keybinds.leader`       | valor de atajo                                   | Define la tecla a la que hace referencia `<leader>` en otros atajos. |
| `keybinds.<command>`    | valor de atajo                                   | Sobrescribe el atajo de un ID de comando.                            |
| `keybinds.*.key`        | cadena de tecla o descriptor                     | Selecciona la tecla de un atajo en forma de objeto.                  |
| `keybinds.*.event`      | `press` o `release`                              | Limita un atajo en forma de objeto a un evento de tecla.             |
| `keybinds.*.preventDefault` | booleano                                     | Controla si se impide el comportamiento predeterminado de la tecla en la terminal. |
| `keybinds.*.fallthrough` | booleano                                        | Permite que los handlers de menor prioridad reciban el mismo evento. |
| `leader.timeout`        | entero positivo                                  | Define cuántos milisegundos se espera después de pulsar la tecla líder. |

</div>

Un valor de atajo puede ser una cadena, un array de alternativas o un objeto. Usa `"none"` o `false` para desactivar un
atajo. Consulta [Atajos de teclado](/cli/keybinds) para ver la sintaxis de teclas admitida, todos los ID de comando y
todos los atajos predeterminados.

## Plugins

Carga en orden plugins exclusivos de la terminal:

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de plugins" tabIndex={0}>

| Ajuste | Valores | Descripción |
| -------------------- | --------------- | --------------------------------------------------------------- |
| `plugins`            | array           | Declara, en orden, directivas de activación y plugins externos. |
| `plugins[].package`  | cadena          | Define un nombre de paquete, una ruta local o una URL de archivo. |
| `plugins[].options`  | objeto          | Pasa a ese plugin sus opciones específicas.                     |

</div>

Consulta [Plugins](/cli/plugins) para ver las formas de indicar paquetes, la detección local, los comodines y las
directivas de desactivación.

## Depuración y funciones experimentales

Activa diagnósticos o habilita un experimento disponible actualmente:

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Ajustes de depuración y experimentales" tabIndex={0}>

| Ajuste | Valores | Descripción |
| ------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `debug.devtools`    | booleano                        | Muestra la barra de depuración de DevTools.                                         |
| `debug.timing`      | booleano                        | Muestra en la barra de depuración el diagnóstico del tiempo hasta el primer dibujado. |
| `debug.turn_tokens` | booleano o `verbose`            | Muestra el uso de tokens por turno; `verbose` incluye además las entradas de las llamadas a herramientas. |
| `experimental`      | objeto de ID de función a booleanos | Activa o desactiva experimentos que pueden cambiar o eliminarse sin previo aviso. |

</div>

Usa solo los ID de función que aparecen actualmente en el diálogo **Experiments** de la TUI. Los ID desconocidos no tienen
efecto.
