---
title: "TUI"
description: "Inicia una sesión y usa los flujos de trabajo habituales en la interfaz de terminal."
---

Ejecuta OpenCode desde tu proyecto, escribe una petición y pulsa **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Pulsa **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** o **Ctrl+J** para insertar una nueva línea. Mientras OpenCode trabaja, **Enter** envía el prompt a la sesión activa para reorientarla; pulsa **Ctrl+X** y después **Enter** para poner el prompt en cola para más tarde.

## Contexto

Escribe `@` para buscar un archivo y selecciónalo para adjuntarlo al prompt. Sigue escribiendo después de `@` para acotar los resultados.

```text
Review @src/auth.ts for error handling problems
```

Puedes indicar una línea o un rango después de la ruta.

```text
Explain @src/auth.ts#20-45
```

## Shell

Escribe `!` al principio de un prompt vacío para entrar en el modo shell. Escribe un comando y pulsa **Enter**; pulsa **Esc** para salir del modo shell sin ejecutar nada.

```text
!git status
```

Los comandos de shell se ejecutan en el directorio de trabajo de la sesión y su salida queda en la sesión.

## Comandos

Escribe `/` para ver los comandos de barra. Sigue escribiendo para filtrar la lista y pulsa **Enter** para ejecutar el comando seleccionado.

```text
/models
```

Entre los comandos más comunes están `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` y `/editor`. Pulsa **Ctrl+P** para abrir la paleta de comandos con todas las acciones disponibles en la vista actual.

Después de una actualización, OpenCode muestra una vez en la pantalla de inicio las novedades de la versión. Ejecuta `/highlights` para volver a verlas o define `"highlights": false` en [`cli.json`](/cli/config#alerts) para que no se abran automáticamente.

## Preguntas al margen

Ejecuta `/btw <question>` para hacer una pregunta rápida sobre la conversación hasta el momento. La respuesta usa el contexto y el modelo actual de la sesión, pero no se añade a la conversación, así que no afecta a los prompts posteriores. Mientras se ejecuta, aparece un indicador `/btw` en el pie del prompt, y la respuesta se abre en un diálogo; pulsa **C** para copiarla.

```text
/btw why did the test in step 2 fail?
```

## Modelos

Pulsa **Ctrl+X** y después **M** para elegir un modelo, o ejecuta `/models`. Pulsa **F2** para alternar entre los modelos usados recientemente.

Pulsa **Ctrl+X** y después **A** para elegir un agente, o ejecuta `/agents`. Pulsa **Shift+Tab** para alternar entre agentes.

## Sesiones

Pulsa **Ctrl+X** y después **N** para iniciar una sesión nueva. Pulsa **Ctrl+X** y después **L**, o ejecuta `/sessions`, para volver a una sesión existente; **Ctrl+O** abre a la vez las sesiones y los proyectos recientes.

Las pestañas están activadas de forma predeterminada. Usa **Ctrl+Tab** y **Ctrl+Shift+Tab** para moverte entre ellas, **Ctrl+X** y después **W** para cerrar una, y **Ctrl+Shift+T** para reabrir la última pestaña cerrada.

## Historial

Pulsa **Ctrl+X** y después **U**, o ejecuta `/undo`, para revertir el último mensaje del usuario y el trabajo posterior. El prompt revertido vuelve al editor de mensajes para que puedas modificarlo.

Pulsa **Ctrl+X** y después **R**, o ejecuta `/redo`, para restaurar el trabajo revertido. Si en su lugar envías un prompt nuevo, se acepta la reversión y se continúa desde ese punto.

## Editor

Define `VISUAL` o `EDITOR`, pulsa **Ctrl+X** y después **E**, o ejecuta `/editor`, para editar el prompt actual en ese editor. Guarda y sal para devolver el texto al editor de mensajes y pulsa **Enter** para enviarlo.

```bash
export EDITOR="nvim"
opencode
```

La tecla líder es **Ctrl+X** de forma predeterminada. Consulta [Atajos de teclado](/cli/keybinds) para cambiar estos atajos.
