title: "Atajos de teclado"
---

Personaliza los atajos en `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Usa una cadena para una sola tecla:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separa las alternativas con comas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Desactiva un atajo con `"none"` o `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Usa un objeto para controlar el comportamiento del evento:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` tiene el valor predeterminado `ctrl+x`. `<leader>` en otro atajo hace referencia a esa tecla.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Los ID de comando desconocidos se rechazan.

## Mini

El comando `app.clear` solo funciona en [`opencode mini`](/cli). Pulsa `ctrl+l` para limpiar la pantalla visible y volver a dibujar el prompt. La terminal conserva el historial de desplazamiento.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Predeterminado | Descripción        |
| ----------- | -------------- | ------------------ |
| `app.clear` | `ctrl+l`       | Limpiar la pantalla |

## Visor de diffs

Pulsa `d` (`diff.switch_source`) para elegir **All**, **Committed**, **Uncommitted** o **Last turn** (dentro de una sesión), o selecciona **Base** para cambiar la rama de comparación. Las elecciones se recuerdan hasta que se cierra la TUI. Define el alcance inicial con [`diffs.source` en `cli.json`](/cli/config#diffs).

Los atajos de desplazamiento, de avance por páginas y de inicio y fin siempre controlan el diff. No hay un cambio de foco con el teclado: haz clic en los archivos para abrirlos, haz clic en las carpetas para expandirlas o contraerlas y usa la rueda del ratón para desplazarte por el árbol de archivos.

Usa `n` / `p` o `alt+down` / `alt+up` (Option en macOS) para moverte entre archivos. Dentro del visor de diffs, los atajos con Alt navegan entre archivos y no entre pestañas de sesión.

Pulsa `m` para marcar un archivo como revisado y contraer el cuerpo de su parche. En la vista de todos los archivos, pulsa `m` de nuevo para desmarcarlo y volver a abrir el parche. En la vista de un solo archivo, al marcarlo como revisado se avanza automáticamente al siguiente, pero en el último archivo no se vuelve al principio. Al desmarcar un archivo nunca se avanza al siguiente.

Haz clic derecho en un archivo de la barra lateral o en el encabezado de su diff para ver **Mark complete** (o **Mark incomplete**). Esta opción cambia el mismo estado de revisión que `m`. Completar otro archivo desde su menú no lo selecciona ni cambia el archivo que estás leyendo.

Las alternativas de `diff.help` con Shift existen para las terminales que notifican el modificador Shift al pulsar `?`.

Selecciona un comando en ejecución en la pestaña **Shell** y pulsa **Enter**, o haz clic en él, para ver la salida capturada de stdout y stderr.
Usa **↑/↓**, **Page Up/Down** o **Home** para desplazarte, **End** para seguir la salida nueva y **Esc** para volver sin detener el comando.
El visor muestra la salida reciente y sigue abierto después de que el comando termine; no incluye la salida redirigida a un archivo.
