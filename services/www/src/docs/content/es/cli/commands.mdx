---
title: "Comandos"
description: "Referencia de la línea de comandos de opencode."
---

Todos los comandos aceptan `--help` para mostrar la lista completa de flags, por ejemplo `opencode run --help`. Algunos comandos que dependen del servidor aceptan `--standalone` para ejecutar un servidor privado o `--server <url>` para usar uno concreto; consulta la ayuda de cada comando para ver los flags que admite.

## run

Envía un mensaje y muestra la respuesta sin abrir la interfaz interactiva.

```bash
$ opencode run "Explain this repository"
```

### CI

En CI, pasa la clave de API del proveedor como secreto y usa el modo independiente para que el servidor privado la reciba. Por ejemplo, este trabajo de GitHub Actions revisa el repositorio obtenido:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Elige un modelo.

```bash
$ opencode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continúa la última sesión.

```bash
$ opencode run --continue "Now handle the expired case"
```

Genera JSON delimitado por saltos de línea para scripts.

```bash
$ opencode run --format json "List the TODO comments"
```

Adjunta archivos al mensaje.

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Ejecuta con un agente concreto.

```bash
$ opencode run --agent build "Fix the failing test"
```

Consulta todos los subcomandos y flags.

```bash
$ opencode run --help
```

## mini

Inicia la interfaz interactiva mínima en lugar de la TUI a pantalla completa.

```bash
$ opencode mini
```

Continúa la última sesión.

```bash
$ opencode mini --continue
```

Empieza con un modelo y un prompt inicial.

```bash
$ opencode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

Consulta todos los subcomandos y flags.

```bash
$ opencode mini --help
```

## session

Gestiona las sesiones.

```bash
$ opencode session list
```

Limita la lista y muéstrala en JSON.

```bash
$ opencode session list --max-count 20 --format json
```

Elimina una sesión y sus sesiones hijas.

```bash
$ opencode session delete ses_9c1b08
```

Exporta los datos de una sesión en JSON.

```bash
$ opencode session export ses_4f2a1c
```

Oculta los datos sensibles de la transcripción y de los archivos al exportar.

```bash
$ opencode session export ses_4f2a1c --sanitize
```

Importa los datos de una sesión desde un archivo JSON o una URL.

```bash
$ opencode session import session.json
```

Importa en un directorio concreto.

```bash
$ opencode session import session.json --directory ~/code/project
```

Consulta todos los subcomandos y flags.

```bash
$ opencode session --help
```

## auth

Gestiona los proveedores de IA y las credenciales.

```bash
$ opencode auth list
```

Muéstralos en JSON.

```bash
$ opencode auth list --format json
```

Inicia sesión en un proveedor.

```bash
$ opencode auth login anthropic
```

Inicia sesión con un método de autenticación concreto.

```bash
$ opencode auth login anthropic --method key
```

Cierra la sesión de una cuenta guardada.

```bash
$ opencode auth logout anthropic work
```

Cambia la cuenta activa de una integración.

```bash
$ opencode auth switch anthropic work
```

Consulta todos los subcomandos y flags.

```bash
$ opencode auth --help
```

## mcp

Gestiona los servidores MCP (Model Context Protocol).

```bash
$ opencode mcp list
```

Añade un servidor remoto.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Añade un servidor local a la configuración global.

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Añade un servidor local con una variable de entorno.

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Añade un servidor remoto con una cabecera.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Autentícate en un servidor remoto compatible con OAuth.

```bash
$ opencode mcp auth sentry
```

Elimina las credenciales de OAuth guardadas de un servidor.

```bash
$ opencode mcp logout sentry
```

Consulta todos los subcomandos y flags.

```bash
$ opencode mcp --help
```

## plugin

Gestiona los plugins.

```bash
$ opencode plugin list
```

Incluye los plugins integrados del servidor.

```bash
$ opencode plugin list --builtin
```

Instala un plugin y añádelo a la configuración global.

```bash
$ opencode plugin add @example/opencode-tui
```

Comprueba si hay actualizaciones de los plugins de paquete.

```bash
$ opencode plugin check
```

Actualiza los plugins de paquete.

```bash
$ opencode plugin update
```

Elimina un plugin de la configuración global.

```bash
$ opencode plugin remove @example/opencode-tui
```

Consulta todos los subcomandos y flags.

```bash
$ opencode plugin --help
```


Muestra JSON en lugar de un informe.



## serve

Inicia el servidor de la API y el servidor web. Consulta [Web](/cli/web).

```bash
$ opencode serve
```

Escucha en todas las interfaces en un puerto fijo.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
```

Permite un cliente de navegador desde otro origen.

```bash
$ opencode serve --cors https://app.example.com
```

Consulta todos los subcomandos y flags.

```bash
$ opencode serve --help
```

## pair

Muestra enlaces de un solo uso, junto con un código QR del primero, que inician sesión en el servidor desde un navegador
o una aplicación. Los enlaces caducan a los 5 minutos y solo funcionan una vez.

```bash
$ opencode pair
```

Usa una URL externa en los enlaces.

```bash
$ opencode pair --url https://dev.example.com
```

Empareja desde cualquier lugar a través de una dirección remota de OpenTunnel. Esto expone el servidor a internet, así que
la primera vez que activa el acceso remoto lo explica y te pide que lo aceptes. Consulta
[Acceso remoto](/cli/web#remote-access).

```bash
$ opencode pair --remote
```

Acepta sin confirmación, por ejemplo en un script sin terminal.

```bash
$ opencode pair --remote --yes
```

Consulta todos los subcomandos y flags.

```bash
$ opencode pair --help
```

## service

Gestiona el servidor en segundo plano. Consulta [Web](/cli/web).

```bash
$ opencode service start
```

Reinícialo.

```bash
$ opencode service restart
```

Muestra su estado.

```bash
$ opencode service status
```

Detenlo.

```bash
$ opencode service stop
```

Lee un ajuste.

```bash
$ opencode service get hostname
```

Define un ajuste.

```bash
$ opencode service set hostname 0.0.0.0
```

Permite un origen CORS adicional.

```bash
$ opencode service set cors https://app.example.com
```

Pasa una variable de entorno al proceso del servidor.

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Restablece un ajuste a su valor predeterminado.

```bash
$ opencode service unset hostname
```

Consulta todos los subcomandos y flags.

```bash
$ opencode service --help
```

## reload

Recarga la configuración sin reiniciar el servidor. Las sesiones en ejecución continúan con servicios renovados en el siguiente límite entre pasos.

```bash
$ opencode reload
```

## api

Hace una solicitud al servidor en ejecución.

```bash
$ opencode api GET /api/session
```

Llama a un ID de operación con un parámetro de consulta.

```bash
$ opencode api session.list --param limit=10
```

Envía un cuerpo JSON.

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

Añade una cabecera a la solicitud.

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

Consulta todos los subcomandos y flags.

```bash
$ opencode api --help
```

## upgrade

Actualiza OpenCode a la última versión o a una concreta. Alias: `update`.

```bash
$ opencode upgrade
```

Actualiza a una versión concreta con un gestor de paquetes concreto.

```bash
$ opencode upgrade 2.0.21 --method bun
```

Consulta todos los subcomandos y flags.

```bash
$ opencode upgrade --help
```

## uninstall

Elimina OpenCode y todos los archivos relacionados.

```bash
$ opencode uninstall
```

Revisa de antemano lo que se eliminaría.

```bash
$ opencode uninstall --dry-run
```

Consulta todos los subcomandos y flags.

```bash
$ opencode uninstall --help
```
