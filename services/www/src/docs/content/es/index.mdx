OpenCode es un agente de programación con IA de código abierto. Está disponible como interfaz de terminal, aplicación de
escritorio y aplicación web.

El paquete de npm usa un script postinstall para seleccionar el binario nativo de `opencode` correspondiente a tu
plataforma. Los comandos de Bun y pnpm permiten explícitamente el script necesario; Vite+ no necesita ningún flag adicional. El comando de mise requiere mise 2026.10.9 o posterior; las versiones anteriores instalan OpenCode 1.

Los gestores de paquetes de Windows no son compatibles.


Descarga un binario independiente de la CLI para tu plataforma.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)

## Web

Accede a la interfaz web de OpenCode con el comando `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Las imágenes de Docker usan etiquetas con número de versión, por ejemplo `ghcr.io/anomalyco/opencode:2.0.0`.

## Conectar

OpenCode incluye compatibilidad integrada con muchos proveedores de LLM; puedes conectarte a ellos directamente
[desde la TUI](/cli/providers) con `/connect`.

Consulta [Proveedores](/providers) para configurar proveedores personalizados.

Si quieres acceder fácilmente a los mejores modelos de programación, prueba
[OpenCode Console](/console).

También puedes probar [OpenCode Go](/console/go), un plan de suscripción de $10 al mes que te da acceso a los mejores
modelos de código abierto.

## Personalizar

Adapta OpenCode a tu manera: edita la [configuración de OpenCode](/config), [carga plugins](/plugins), [conecta servidores
MCP](/mcp-servers) o [crea comandos](/commands). Para los temas y atajos de teclado de la interfaz de terminal, consulta
los [ajustes de la CLI](/cli/config).
