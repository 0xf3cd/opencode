OpenCode Console ofrece una lista de modelos probados y verificados por el equipo de OpenCode. Inicia sesión, añade
créditos y obtén una clave de API para usarlos con OpenCode o con otro agente de programación.

Console funciona como cualquier otro proveedor en OpenCode. Es **totalmente opcional** y puedes usar cualquier otro
proveedor en su lugar. Si buscas una suscripción con uso incluido, consulta [OpenCode Go](/console/go).

## Cómo funciona

1. Inicia sesión en [Console](https://opencode.ai/console), añade tus datos de facturación y créditos, y copia tu clave
   de API.
2. Ejecuta `/connect` en la TUI, elige el proveedor de pago por uso de OpenCode y pega tu clave de API.

   ```text
   /connect
   ```

3. Ejecuta `/models` para ver los modelos disponibles y selecciona uno.

   ```text
   /models
   ```

Se te cobra por solicitud y puedes añadir créditos a tu cuenta.

### Jev

Jev es un modelo System One de TypeSafe AI para tomar decisiones rápidas y estructuradas. En lugar de generar texto, evalúa un `state` frente a preguntas tipadas y devuelve valores y probabilidades que tu código puede usar directamente. Admite preguntas de sí/no (`noul`), de opción múltiple (`choice`) y basadas en una rúbrica (`score`).

Usa tu clave de API de OpenCode Console con el endpoint `https://opencode.ai/inference/v1/systemone`. Este ejemplo comprueba si una solicitud de soporte es urgente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Puedes hacer varias preguntas en una misma solicitud. Jev las evalúa en paralelo y devuelve cada respuesta bajo el ID de la pregunta correspondiente:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Usa `jev-1.13-free` en lugar de `jev-1.13` para usar el modelo gratuito por tiempo limitado. Consulta la [documentación de TypeSafe AI](https://docs.typesafe.ai/) para obtener más información sobre los tipos de preguntas y los campos de la respuesta.

## Antecedentes

Hay muchos modelos disponibles, pero solo unos pocos funcionan bien como agentes de programación. Además, los proveedores
varían en configuración, rendimiento y calidad, así que un modelo al que accedes a través de un gateway como OpenRouter
puede comportarse de forma distinta.

<Callout type="tip">Hemos probado un grupo selecto de modelos y proveedores que funcionan bien con OpenCode.</Callout>

Para crear este catálogo:

1. Probamos un grupo selecto de modelos y hablamos con sus equipos sobre la mejor forma de ejecutarlos.
2. Trabajamos con los proveedores para asegurarnos de que los modelos se servían correctamente.
3. Evaluamos cada combinación de modelo y proveedor para elaborar una lista que podamos recomendar con confianza.

Console es un gateway de IA que te da acceso a estos modelos.

## Objetivos

Creamos Console para:

1. **Evaluar** los mejores modelos y proveedores para agentes de programación.
2. Ofrecer las opciones de **mayor calidad**, sin reducir el rendimiento ni redirigir a proveedores más baratos.
3. Trasladar las **bajadas de precio** vendiendo a precio de coste, con un margen solo para cubrir las comisiones de
   procesamiento.
4. **No atarte a nada**: usa Console con cualquier agente de programación o usa otro proveedor con OpenCode.
