---
title: "Búsqueda web"
description: "Búsqueda web alojada para OpenCode a través de Console."
---

Console ofrece búsqueda web alojada a los usuarios de OpenCode v2 conectados. Un propietario o administrador del espacio de trabajo la activa una sola vez para todo el espacio, sin tener que dar a los miembros una clave propia de un proveedor de búsqueda.

Cada búsqueda correcta cuesta **$0.01** y se descuenta del saldo del espacio de trabajo y de los límites de gasto de cada miembro.

## Activar

1. Inicia sesión en [Console](https://opencode.ai/console) como propietario o administrador del espacio de trabajo.
2. Abre **Settings** > **General**.
3. Activa **Hosted web search**.

Después, cada miembro conecta OpenCode al espacio de trabajo con `/connect`.

```text
/connect
```

OpenCode carga **OpenCode Web Search** desde la configuración gestionada del espacio de trabajo. Los miembros no necesitan definir `websearch.provider` ni añadir una clave de API de un proveedor.

## Buscar

Pide a OpenCode información actual en un prompt. Las búsquedas se ejecutan desde OpenCode, no desde una página interactiva de Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

El proveedor alojado busca en la web pública y devuelve hasta ocho resultados. OpenCode los usa para responder al prompt y citar las fuentes.

Consulta la [guía de búsqueda web](/websearch) para configurar los permisos o desactivar la herramienta.

## Facturación

Console cobra **$0.01** cuando una búsqueda devuelve un conjunto de resultados válido. No se cobran las búsquedas fallidas ni las rechazadas por límite de frecuencia.

La búsqueda web aparece separada del uso de modelos en **Usage**, **My Activity**, la actividad de los miembros, las facturas y las exportaciones CSV. Los límites de gasto mensuales del espacio de trabajo y de los miembros incluyen los cargos de búsqueda web.

## Privacidad

La búsqueda web alojada no retiene ningún dato. Console y su proveedor de búsqueda alojada procesan cada consulta y sus resultados sin almacenar su contenido.
