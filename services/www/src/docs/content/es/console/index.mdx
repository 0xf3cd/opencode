[OpenCode Console](https://opencode.ai/console) es un servicio opcional que añade ventajas al uso de OpenCode, tanto
si trabajas por tu cuenta como en equipo.

- [Espacios de trabajo](/console/workspaces) para compartir el acceso con tu [equipo](/console/members)
- [Inferencia](/console/models) con modelos propietarios y de código abierto
- [Proveedores](/console/providers) para conectar tus propias cuentas de proveedor a través del gateway de Console
- Seguimiento del uso y control del [presupuesto](/console/budgets)
- Políticas para todo el equipo que controlan el comportamiento de OpenCode
- [Búsqueda web](/console/websearch)
- [OpenCode Go y Go Plus](/console/go), suscripciones de $10 y $40 al mes para acceder a modelos de código abierto

## Primeros pasos

No necesitas un equipo para usar Console. Todas las cuentas empiezan con un espacio de trabajo **Personal** en el que
eres el único miembro.

1. Inicia sesión en [Console](https://opencode.ai/console).
2. Suscríbete a [Go](/console/go), añade [créditos](/console/billing#add-credits) o conecta un [proveedor](/console/providers).
3. Ejecuta `/connect` en OpenCode y elige el espacio de trabajo.
4. Si quieres, [invita](/console/members#invite-members) a tu equipo.

```text
/connect
```

## Políticas

Las reglas de Providers y Tools de la página Policies se aplican a todos los clientes de OpenCode V2 conectados al
espacio de trabajo. Se envían como declaraciones de [política](/policies#console) con autoridad final sobre la
configuración propia del miembro y entran en vigor en aproximadamente un minuto.
