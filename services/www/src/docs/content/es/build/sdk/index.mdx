---

`@opencode/sdk` aloja OpenCode directamente dentro de tu aplicación. A diferencia del
[cliente de red](/build/client), ensambla el servidor de OpenCode y enruta las llamadas a la API
a través de su router HTTP en memoria. No abre ningún listener HTTP ni añade ningún salto de red
entre el cliente y el servidor.

Para Durable Objects de Cloudflare, consulta la [guía de Cloudflare](/build/sdk/cloudflare).

Instala el SDK:

```sh
bun add @opencode/sdk
```

## Crear un host

`OpenCode.create()` devuelve un host con propietario explícito. Usa `await using` para
liberar su router, los servicios de Location, los fibers y los registros de plugins con ámbito:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Llama a `await opencode.close()` de forma explícita cuando no dispongas de gestión explícita de
recursos.

El host embebido usa los mismos valores Promise, errores declarados, opciones de solicitud y streams
`AsyncIterable` que `@opencode/client`. Expone el cliente generado completo y añade los alias
de conveniencia `sessions` y `events` para los grupos de sesiones y eventos.

## Worktrees

Las operaciones con worktrees requieren un `projectID`. Las operaciones de creación y actualización cargan la
configuración y los plugins desde el checkout canónico guardado del proyecto. La operación de listado solo lee el
inventario guardado; la de eliminación activa los plugins canónicos y usa la estrategia registrada, y falla si esa
estrategia no está disponible.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

La actualización descubre worktrees en todas las raíces de checkout conocidas con todas las estrategias disponibles.
Registra una estrategia personalizada mediante la [transformación de worktrees de un plugin](/build/plugins#worktrees).

## Recibir eventos en streaming

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Pasa un `AbortSignal` mediante las opciones de solicitud generadas, o sal de la iteración para
cancelar el cuerpo de su respuesta.

## Personalizar

Personaliza tu instancia de OpenCode registrando plugins. Pasa plugins a
`OpenCode.create()` para personalizar agentes, modelos, herramientas y otros comportamientos cuando
se inicia el host embebido:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Llama a `await opencode.plugin(plugin)` para registrar otro plugin después del inicio.

Consulta la [documentación completa de plugins](/build/plugins) para conocer los hooks de plugins,
las transformaciones, las herramientas y el contexto completo del plugin.
