---
title: "Effect"
---

`@opencode/sdk/effect` es el SDK embebido nativo de Effect. Las operaciones devuelven Effects y Streams tipados, y al
cerrar el Scope propietario se liberan el router, los servicios de Location, los fibers y los registros de plugins.

```sh
bun add @opencode/sdk effect
```

## Crear un host

Crea el host dentro de `Effect.scoped` y después usa sus grupos de API generados o el alias `sessions`.

```ts
import { AbsolutePath, Location, OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const opencode = yield* OpenCode.create()
    const session = yield* opencode.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* opencode.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

El host embebido usa los mismos valores de Schema, errores declarados, opciones de solicitud y Streams que
`@opencode/client/effect`.

```ts
const info = yield* opencode.server.info()
const sessions = yield* opencode.sessions.list()
```

## Recibir eventos en streaming

Los endpoints de streaming devuelven valores `Stream` de Effect. Haz fork de los consumidores en el Scope del host
cuando deban ejecutarse en segundo plano.

```ts
import { Effect, Stream } from "effect"

yield* opencode.events.subscribe().pipe(
  Stream.runForEach((event) => Effect.logInfo("OpenCode event", { type: event.type })),
  Effect.forkScoped,
)
```

## Personalizar

Personaliza tu instancia de OpenCode registrando plugins de Effect. Usa el host
embebido para personalizar agentes, modelos, herramientas y otros comportamientos:

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield* opencode.plugin(plugin)
```

Consulta la [documentación completa de plugins de Effect](/build/plugins/effect) para conocer
los hooks de plugins, las transformaciones, las herramientas y el contexto completo del plugin.

## Layer

Usa `OpenCode.layer()` cuando el host embebido deba ser un servicio de la aplicación.

```ts
import { OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const opencode = yield* OpenCode.Service
  return yield* opencode.server.info()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(OpenCode.layer())))
```
