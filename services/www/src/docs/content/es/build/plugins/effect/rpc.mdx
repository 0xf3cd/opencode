---
title: "RPC"
---

Los plugins de Effect pueden exponer métodos y eventos que devuelven Effects y Streams
tipados.

## Definir

Usa `Rpc.define` con Effect Schema para definir la RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Validación

Effect Schema valida los valores e infiere sus tipos de TypeScript.

```ts
input: Schema.Struct({ query: Schema.String })
```

También se admiten JSON Schema y Standard Schema.

### Entrada y salida

Usa `input` para el argumento del método y `output` para su valor de retorno. Omite
cualquiera de los dos cuando no haya valor.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Errores

Añade los fallos esperados a `errors`. Cada clave se convierte en el `type` del error.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Eventos

Añade los eventos al mapa `events` de nivel superior. Los datos del evento deben ser un objeto.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Implementar

Registra la implementación desde el Effect del plugin:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

El mapa de errores se convierte en el tipo de error del Effect de cada método. Usa
`context.error(...)` para crear un error declarado.

## Llamar

Una vez registrada, la RPC se puede llamar por HTTP o desde otro plugin.

### HTTP

Crea el cliente de Effect y después el subcliente de RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Plugin

Otro plugin de Effect puede crear un subcliente local a partir de su contexto:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Suscribirse

Los eventos de RPC son Streams. Suscríbete por nombre de evento y ejecuta el Stream en un fiber
con ámbito:

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

Las suscripciones son solo en vivo y se cierran cuando se deja de consumir el Stream.
