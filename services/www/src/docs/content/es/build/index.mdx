title: "Introducción"
---

Millones de personas usan OpenCode cada día. Construye sobre él tus propias aplicaciones, integraciones y experiencias
con agentes sin empezar desde cero.

También ofrecemos APIs de Effect para [plugins](/build/plugins/effect), [clientes](/build/client/effect) y
[aplicaciones integradas](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Amplía OpenCode" href="/build/plugins">
    Crea plugins que añaden herramientas, integraciones, comandos, agentes y comportamiento personalizado sin alterar el
    resto de OpenCode.
  </Card>
  <Card title="Ejecútalo como servidor" href="/build/client">
    Conéctate a OpenCode con el mismo cliente que usan la TUI y la aplicación de escritorio, y construye a su alrededor
    cualquier interfaz, flujo de trabajo o experiencia con agentes.
  </Card>
  <Card title="Intégralo" href="/build/sdk">
    Integra OpenCode directamente en tu aplicación y construye a su alrededor un agente, una interfaz o un producto para
    desarrolladores totalmente personalizado.
  </Card>
</CardGroup>
