تستخدم حزمة npm سكربت postinstall لاختيار ملف `opencode` التنفيذي الأصلي المناسب لمنصتك. تسمح أوامر Bun وpnpm أعلاه
صراحةً بتشغيل هذا السكربت، أما Vite+ فلا يحتاج إلى أي خيار إضافي. يتطلب أمر mise الإصدار 2026.10.9 أو أحدث من mise، أما الإصدارات الأقدم فتثبّت OpenCode 1.

مديرو الحزم على Windows غير مدعومين.


نزّل ملفًا تنفيذيًا مستقلًا من CLI لمنصتك.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## الويب

افتح واجهة OpenCode على الويب باستخدام الأمر `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

تستخدم صور Docker وسومًا مرقّمة بالإصدار، مثل `ghcr.io/anomalyco/opencode:2.0.0`.

## الاتصال

يتضمن OpenCode دعمًا مدمجًا للعديد من مزوّدي نماذج LLM، ويمكنك الاتصال بهم مباشرةً [من واجهة TUI](/cli/providers) باستخدام
الأمر `/connect`.

لتهيئة مزوّدين مخصصين، راجع [المزوّدون](/providers).

إذا أردت وصولًا سهلًا إلى أفضل نماذج البرمجة، فجرّب [OpenCode Console](/console).

يمكنك أيضًا تجربة [OpenCode Go](/console/go)، وهي خطة اشتراك بسعر $10 شهريًا تمنحك الوصول إلى أفضل النماذج مفتوحة
المصدر.
