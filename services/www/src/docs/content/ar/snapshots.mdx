---
title: "اللقطات"
---

تتيح لك اللقطات التراجع عن التغييرات الأخيرة في المحادثة والملفات معًا. استخدمها لمراجعة العمل الأخير، لكن احتفظ بعمليات
commit في Git أو بنسخ احتياطية لكل ما هو مهم.

## سير العمل

شغّل `/undo` بعد أي إجابة تريد مراجعتها. يُجهِّز OpenCode عملية التراجع، ويستعيد الملفات المتأثرة، ثم يعيد الموجّه المحذوف
إلى مربع الكتابة لتتمكن من تعديله.

```text
/undo

# Edit the restored prompt, then submit it again.
Add validation without changing the public API.
```

يؤدي إرسال الموجّه المعدّل إلى اعتماد التراجع المُجهَّز. وقبل الإرسال، يمكنك تشغيل `/redo` لإلغائه واستعادة المحادثة
والملفات كما كانت قبل `/undo`.

```text
/redo
```

توفر الطرفية أيضًا اختصارات افتراضية:

| الإجراء | الأمر | الاختصار |
| --- | --- | --- |
| تجهيز التراجع عن الرسالة السابقة | `/undo` | `<leader>u` |
| إلغاء التراجع المُجهَّز | `/redo` | `<leader>r` |

يمكنك أيضًا تحديد رسالة سابقة واختيار **Revert** لتجهيز تراجع إلى تلك النقطة.

## الالتقاط

في كل خطوة للنموذج، يحاول OpenCode التقاط لقطة قبل استدعاء النموذج مباشرةً، ولقطة أخرى عندما تنتهي الخطوة بنجاح أو فشل
مسجَّل. وتسجّل رسالة المساعد المسارات التي تغيّرت بين هاتين اللقطتين.

```text
before model step ── snapshot A
model edits src/api.ts
step finishes ────── snapshot B ── changed: src/api.ts
```

الالتقاط غير مضمون. إذا تعذّرت إحدى اللقطتين، تستمر المحادثة، لكن قد لا تتوفر لتلك الخطوة تغييرات في الملفات يمكن
استعادتها.

## النطاق

تغطي اللقطات الدليل النشط للجلسة داخل worktree في Git. فمثلًا، تلتقط الجلسة المفتوحة في `packages/app` الملفات المؤهلة
داخل `packages/app`، لا التغييرات في أماكن أخرى من المستودع.

| المحتوى | يُلتقط | مثال |
| --- | --- | --- |
| الملفات المتتبَّعة في الدليل النشط | نعم | `packages/app/src/app.tsx` |
| الملفات غير المتتبَّعة وغير المتجاهَلة حتى 2 MiB لكل ملف | نعم | `packages/app/notes.txt` |
| الملفات التي يتجاهلها Git | لا | `packages/app/dist/app.js` |
| الملفات غير المتتبَّعة التي يتجاوز حجم كل منها 2 MiB | لا | `packages/app/debug.log` |
| الملفات خارج الدليل النشط | لا | `packages/server/src/index.ts` |
| بيانات Git الوصفية والآثار الجانبية الأخرى | لا | عمليات commit أو الفروع أو قواعد البيانات أو العمليات |

تتطلب لقطات نظام الملفات مستودع Git. وخارج المستودع، يظل بإمكان `/undo` التراجع عن سجل المحادثة، لكنه لا يستطيع استعادة
الملفات.

## الاستعادة

لا يستعيد التراجع إلا المسارات المنسوبة إلى خطوات المساعد التي تلي حد المحادثة المحدد. ويعود كل مسار إلى حالته قبل أول خطوة
مُتراجَع عنها، ويُحذف أي ملف أنشأته تلك الخطوات إذا لم يكن موجودًا آنذاك.

| التسلسل الزمني | `src/api.ts` | `src/new.ts` |
| --- | --- | --- |
| الحد المحدد | الإصدار A | غير موجود |
| خطوات المساعد اللاحقة | الإصدار B | أُنشئ |
| بعد التراجع | الإصدار A | حُذف |

تبقى المسارات غير المنسوبة إلى تلك الخطوات كما هي. وقد تُستبدل التعديلات الحالية على أي مسار متأثر، لذا راجع ملخص الاستعادة
ومخرجات `git diff` قبل المتابعة.

```sh
git diff --stat
git diff
```

## التخزين

يخزّن OpenCode اللقطات محليًا في قاعدة بيانات كائنات Git داخلية منفصلة ضمن دليل بياناته. ولا ينشئ التقاط اللقطات عمليات
commit، ولا ينقل الفروع، ولا يغيّر فهرس مستودعك عمدًا.

```sh
# Your repository remains an ordinary dirty worktree after capture.
git status --short
```

قد تحتوي كائنات اللقطات على المحتوى الكامل للملفات المتتبَّعة والملفات غير المتتبَّعة المؤهلة. لذا تعامل مع دليل بيانات
OpenCode على أنه بيانات محلية حساسة.

## الإعدادات

اللقطات مفعّلة افتراضيًا. اضبط `snapshots` على `false` في [ملف التهيئة](/config#snapshots) لإيقاف التقاط نظام الملفات
مستقبلًا.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "snapshots": false,
}
```

لا يحذف تعطيل اللقطات اللقطاتِ المخزنة مسبقًا. ويظل التراجع عن المحادثة متاحًا، لكنه لا يستطيع استعادة تغييرات الملفات
المرتبطة بها دون حالة ملتقطة لنظام الملفات.

## الأمان

اللقطات وسيلة للراحة، وليست معاملة (transaction) ولا نسخة احتياطية:

- قد تغيّر أوامر shell الخدمات أو العمليات أو موارد الشبكة أو قواعد البيانات أو حالة Git أو المخرجات المتجاهَلة أو الملفات
  خارج الدليل النشط. ولا تعكس استعادة اللقطة هذه الآثار.
- قد يترك العمل المقاطَع أو الفاشل تغييرات عندما يفشل الالتقاط أو لا يوجد زوج لقطات صالح للاستخدام.
- تستبدل استعادة المسارات المتأثرة محتواها الحالي. وقد يستبدل إلغاء تراجع مُجهَّز أيضًا التعديلات اللاحقة.
- يرفض OpenCode عمليات التراجع أثناء عمل الجلسة، لكن المحررات والأوامر الخارجية قد تغيّر محتوى worktree بين
  الالتقاط والاستعادة.
- يؤدي اعتماد التراجع إلى إزالة الرسائل من عرض المحادثة النشطة فقط، لا من سجل الجلسة الدائم أو من مخزن اللقطات الحالي. وهو
  ليس محوًا آمنًا.

اعتمد عملك المهم في commit أو انسخه احتياطيًا قبل استخدام `/undo` على worktree يحتوي تغييرات غير معتمدة.
