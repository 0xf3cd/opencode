title: "اختصارات المفاتيح"
---

خصّص الاختصارات في `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

استخدم سلسلة نصية لمفتاح واحد:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

افصل البدائل بفواصل:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

عطّل اختصارًا باستخدام `"none"` أو `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

استخدم كائنًا للتحكم في سلوك الحدث:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

القيمة الافتراضية لـ `leader` هي `ctrl+x`. ويشير `<leader>` في أي اختصار آخر إلى ذلك المفتاح.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

تُرفض معرّفات الأوامر غير المعروفة.

## الواجهة المصغّرة

لا يعمل الأمر `app.clear` إلا في [`opencode mini`](/cli). اضغط `ctrl+l` لمسح الشاشة الظاهرة وإعادة رسم الموجّه. وتحتفظ
الطرفية بسجل التمرير.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| المعرّف | الافتراضي | الوصف |
| --- | --- | --- |
| `app.clear` | `ctrl+l` | مسح الشاشة |

## عارض الفروقات

اضغط `d` (`diff.switch_source`) لاختيار **All** أو **Committed** أو **Uncommitted** أو **Last turn** (داخل جلسة)، أو اختر
**Base** لتغيير فرع المقارنة. تُحفظ الاختيارات حتى الخروج من واجهة TUI. اضبط النطاق المبدئي باستخدام
[`diffs.source` في `cli.json`](/cli/config#diffs).

تتحكم اختصارات التمرير والتنقل بين الصفحات والانتقال إلى البداية أو النهاية في الفروقات دائمًا. لا يوجد مفتاح لتبديل تركيز
لوحة المفاتيح: انقر الملفات لفتحها، وانقر المجلدات لتوسيعها أو طيّها، واستخدم عجلة الفأرة لتمرير شجرة الملفات.

استخدم `n` / `p` أو `alt+down` / `alt+up` (المفتاح Option على macOS) للتنقل بين الملفات. وداخل عارض الفروقات، تتنقل
اختصارات Alt بين الملفات لا بين علامات تبويب الجلسات.

اضغط `m` لوسم الملف بأنه رُوجع وطيّ متن الرقعة (patch) الخاصة به. وفي عرض جميع الملفات، اضغط `m` مجددًا لإزالة الوسم
وإعادة فتح الرقعة. ينتقل عرض الملف الواحد تلقائيًا إلى الملف التالي عند وسم الملف بأنه رُوجع، لكنه يبقى على الملف الأخير
بدلًا من العودة إلى البداية. ولا تؤدي إزالة الوسم إلى الانتقال أبدًا.

انقر بزر الفأرة الأيمن على ملف في الشريط الجانبي أو على عنوان الفروقات الخاص به لاختيار **Mark complete** (أو
**Mark incomplete**). يغيّر ذلك حالة المراجعة نفسها التي يغيّرها `m`. ولا يؤدي إكمال ملف آخر من قائمته إلى تحديده أو
تجاوز الملف الذي تقرؤه حاليًا.

| `composer.shell.kill` | `ctrl+d` | إنهاء أمر shell |

حدّد أمرًا قيد التشغيل في علامة التبويب **Shell** واضغط **Enter**، أو انقر عليه، لعرض ما التُقط من stdout وstderr.
استخدم **↑/↓** أو **Page Up/Down** أو **Home** للتمرير، و**End** لمتابعة المخرجات الجديدة، و**Esc** للعودة دون إيقاف الأمر.
يعرض العارض المخرجات الأخيرة ويبقى مفتوحًا بعد انتهاء الأمر، ولا يتضمن المخرجات المعاد توجيهها إلى ملف.
