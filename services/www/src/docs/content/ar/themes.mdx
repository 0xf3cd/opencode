title: "السمات"

لاختيار سمة من واجهة الطرفية، اضغط `Ctrl+P` واختر **Open settings** ثم افتح **Theme**. ويمكنك أيضًا ضبطها مباشرةً في
تهيئة CLI العامة:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

تتبع السمات عميل الطرفية، لذا ضع اختيار السمة في `cli.json` لا في `opencode.json`. راجع [إعدادات CLI](/cli/config)
لمعرفة موقع التهيئة وسائر إعدادات الطرفية.

## الأوضاع

استخدم `system` لاتباع مظهر الطرفية، أو ثبّت السمة على وضع واحد:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| القيمة    | السلوك                                      |
| -------- | --------------------------------------------- |
| `system` | يتبع الوضع الفاتح أو الداكن للطرفية. |
| `dark`   | يستخدم السمة الداكنة دائمًا.                   |
| `light`  | يستخدم السمة الفاتحة دائمًا.                  |

إذا كانت السمة المخصصة توفّر وضعًا واحدًا فقط، فإن OpenCode يستخدم ذلك الوضع عند طلب الوضع الآخر.

## السمات المدمجة

اختر سمة مدمجة باسمها:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

من السمات المتاحة:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

تتوفر السمة `system` عندما يستطيع OpenCode قراءة لوحة ألوان الطرفية.

## الملفات

لإنشاء سمة عامة باسم `ocean`، استخدم أداة السمات لتوليد ملف كامل في دليل السمات العام. وتبدو بنيته ذات الصلة على هذا
النحو:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

ثم اختر `ocean` في الإعدادات أو اضبط `theme.name` على `ocean` في `cli.json`. اسم الملف، دون `.json`، هو اسم السمة.

| النطاق   | الدليل                                  |
| ------- | ------------------------------------------ |
| عام  | `~/.config/opencode/themes/`               |
| المشروع | `.opencode/themes/` في شجرة المشروع    |

لا يقرأ OpenCode إلا ملفات `.json`. والسمة الأقرب إلى الدليل الحالي تحل محل السمة العامة أو سمة الدليل الأب التي تحمل
الاسم نفسه.

## الصيغة

تصرّح كل سمة في V2 بشجرة tokens كاملة واحدة في `base`، وبلوحة درجات ألوان (hue) واحدة على الأقل في `light` أو `dark`.
ولا ترث الأوضاع إلا من `base` في الملف نفسه؛ فهي لا ترث من سمة OpenCode المدمجة ولا من بعضها بعضًا. استخدم أداة السمات
لتوليد `base` كامل قبل تخصيصه.

تعرض الأمثلة أدناه الأقسام المتعلقة بكل مفهوم فقط، وليست ملفات سمات كاملة.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## الألوان

استخدم لونًا سداسيًا عشريًا، أو `transparent`، أو مرجعًا إلى لون آخر في السمة:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

يمكن أن تتكون القيم السداسية العشرية من 3 أو 4 أو 6 أو 8 أرقام. تبدأ المراجع بالرمز `$`، وتستخدم مراجع درجات الألوان
الصيغة `$hue.<name>.<step>`.

## درجات الألوان

تجاوز اسمًا بديلًا لدرجة لون لتغيير عائلة من الألوان المترابطة دفعة واحدة:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| النوع    | القيم                                                               |
| ------- | -------------------------------------------------------------------- |
| أساسي    | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| اسم بديل   | `accent`, `interactive`, `neutral`                                 |
| درجة    | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`      |

تتبع الدرجات اتجاه التباين في الوضع: في السمات الفاتحة تتدرج من الداكن عند `100` إلى الفاتح عند `900`، وفي السمات
الداكنة من الفاتح عند `100` إلى الداكن عند `900`.

يضبط `categorical` درجات الألوان المرتبة المستخدمة للتمييز بين الوكلاء والعناصر المتكررة الأخرى. ويجب أن يحتوي على درجة
لون أساسية أو اسم بديل واحد على الأقل.

## الحالات

استخدم مفاتيح الحالات لتغيير الألوان التفاعلية. وتستخدم الحالات غير المحددة أقرب قيمة أساسية:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| المجموعة     | القيم                                                    |
| --------- | --------------------------------------------------------- |
| الإجراءات   | `primary`, `secondary`, `destructive`                     |
| الحالات    | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

تستخدم حقول الإدخال مفاتيح الحالات نفسها مباشرةً ضمن `text.formfield` أو `background.formfield`.

## رموز السمة (tokens)

يحتوي `base` الكامل على كل مجموعات tokens. ويمكن للوضع أن يتجاوز أي جزء منه بعد توفير لوحة درجات الألوان الكاملة الخاصة
به:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| المجموعة        | الغرض                                                       |
| ------------ | ------------------------------------------------------------- |
| `text`       | النص الأساسي والخافت ونص الإجراءات وحقول الإدخال والملاحظات         |
| `background` | الخلفية الأساسية والأسطح والإجراءات وحقول الإدخال وتعبئة الملاحظات    |
| `border`     | الحدود                                                       |
| `scrollbar`  | أشرطة التمرير                                                    |
| `diff`       | ألوان الإضافات والحذف والسياق والتمييز وأرقام الأسطر     |
| `syntax`     | تمييز صيغة الشيفرة المصدرية                                      |
| `markdown`   | عناصر Markdown                                              |

مفاتيح `syntax` هي `comment` و`keyword` و`function` و`variable` و`string` و`number` و`type` و`operator`
و`punctuation`. ومفاتيح `markdown` هي `text` و`heading` و`link` و`linkText` و`code` و`blockQuote` و`emphasis`
و`strong` و`horizontalRule` و`listItem` و`listEnumeration` و`image` و`imageText` و`codeBlock`.

## الأسطح المرتفعة

تختار اللوحات ومربعات الحوار والقوائم والإشعارات المنبثقة (toasts) عمقها من `background.raised`. وتدعم مربعات الحوار
أيضًا سطحًا سياقيًا باسم `@dialog`. تعيد واجهة TUI تحليل لوحة الألوان بعد تطبيق `@dialog`، لذا تتبع tokens التي تشير إلى
`$background.base` خلفية مربع الحوار:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

يقبل `@dialog` مجموعات tokens نفسها التي يقبلها الوضع الأساسي. كما تصبح قيمة `base` السياقية للإجراء هي البديل
الاحتياطي لحالاته غير المحددة؛ ومع ذلك يظل التجاوز الصريح للحالة هو الفائز.
