توفّر OpenCode Console قائمة بالنماذج التي اختبرها فريق OpenCode وتحقق منها. سجّل الدخول، وأضف رصيدًا، واحصل على مفتاح
API لاستخدامها مع OpenCode أو مع أي وكيل برمجة آخر.

تعمل Console مثل أي مزوّد آخر في OpenCode. وهي **اختيارية تمامًا**، ويمكنك استخدام أي مزوّد آخر بدلًا منها. وإذا أردت
اشتراكًا يتضمن حصة استخدام، فراجع [OpenCode Go](/console/go).

## آلية العمل

1. سجّل الدخول إلى [Console](https://opencode.ai/console)، وأضف بيانات الفوترة والرصيد، وانسخ مفتاح API الخاص بك.
2. شغّل `/connect` في واجهة TUI، واختر مزوّد OpenCode بالدفع حسب الاستخدام، والصق مفتاح API.

   ```text
   /connect
   ```

3. شغّل `/models` لعرض النماذج المتاحة واختيار أحدها.

   ```text
   /models
   ```

تُحاسَب على كل طلب، ويمكنك إضافة رصيد إلى حسابك.

### قائمة النماذج

اجلب القائمة الكاملة للنماذج المتاحة وبياناتها الوصفية من نقطة نهاية النماذج:

```bash
curl https://opencode.ai/inference/v1/models
```

### Jev

يُعد Jev نموذجًا من نوع System One من TypeSafe AI مخصصًا للقرارات السريعة والمنظّمة. فبدلًا من توليد نص، يقيّم حالةً
(`state`) وفق أسئلة محددة الأنواع، ويعيد قيمًا واحتمالات يمكن لشيفرتك استخدامها مباشرةً. ويدعم أسئلة نعم/لا (`noul`)،
والاختيار من متعدد (`choice`)، والتقييم وفق معايير (`score`).

استخدم مفتاح API الخاص بك في OpenCode Console مع نقطة النهاية `https://opencode.ai/inference/v1/systemone`. يتحقق هذا
المثال مما إذا كان طلب الدعم عاجلًا:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

يمكنك طرح عدة أسئلة في طلب واحد. يقيّمها Jev بالتوازي ويعيد كل إجابة تحت ID السؤال المطابق:

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

استخدم `jev-1.13-free` بدلًا من `jev-1.13` لاستخدام النموذج المجاني لفترة محدودة. راجع [توثيق TypeSafe AI](https://docs.typesafe.ai/) للاطلاع على تفاصيل أنواع الأسئلة وحقول الاستجابة.

## الخلفية

تتوفر نماذج كثيرة، لكن قلة منها فقط تعمل جيدًا كوكلاء برمجة. كما يختلف المزوّدون في التهيئة والأداء والجودة، لذا قد
يختلف أداء النموذج عند الوصول إليه عبر بوابة مثل OpenRouter.

<Callout type="tip">اختبرنا مجموعة منتقاة من النماذج والمزوّدين الذين يعملون جيدًا مع OpenCode.</Callout>

لبناء هذا الكتالوج، قمنا بما يلي:

1. اختبرنا مجموعة منتقاة من النماذج وتحدثنا مع فرقها حول أفضل طريقة لتشغيلها.
2. عملنا مع المزوّدين للتأكد من تقديم النماذج بشكل صحيح.
3. قسنا أداء كل تركيبة من نموذج ومزوّد لإعداد قائمة نوصي بها بثقة.

تُعد Console بوابة ذكاء اصطناعي تمنحك الوصول إلى هذه النماذج.

## الأهداف

أنشأنا Console من أجل:

1. **قياس أداء** أفضل النماذج والمزوّدين لوكلاء البرمجة.
2. تقديم خيارات **بأعلى جودة** دون خفض الأداء أو توجيه الطلبات إلى مزوّدين أرخص.
3. تمرير **انخفاض الأسعار** إليك عبر البيع بسعر التكلفة، مع هامش يقتصر على تغطية رسوم المعالجة.
4. **عدم التقييد بمزوّد واحد**: استخدم Console مع أي وكيل برمجة، أو استخدم مزوّدًا آخر مع OpenCode.
