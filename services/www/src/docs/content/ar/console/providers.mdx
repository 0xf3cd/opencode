اربط حسابات المزوّدين التي تدفع مقابلها بالفعل، مثل Anthropic أو OpenAI أو AWS Bedrock، وشارك نماذجها مع كل من في مساحة
العمل. تخزّن Console بيانات الاعتماد وتقدّم كل مزوّد عبر بوابتها، فيستخدم الأعضاء النماذج دون أن يروا مفتاح المزوّد أبدًا.
والبوابة نفسها متاحة لأدواتك الخاصة عبر [واجهة API للمزوّدين](/console/api/providers).

يدير المالكون والمسؤولون المزوّدين من علامة التبويب **Providers**. ويحصل الأعضاء على النماذج المفعّلة في OpenCode بعد
تشغيل `/connect`.

## ربط مزوّد

1. افتح **Providers** وانقر **Connect Provider**.
2. اختر مزوّدًا من الكتالوج وأدخل مفتاح API الخاص به.
3. يمكنك اختياريًا نقر **Test connection**، ثم انقر **Save**.

يضم الكتالوج Anthropic وOpenAI وGoogle وxAI وDeepSeek وMistral وGroq وOpenRouter وغيرها الكثير. وتأتي نماذج مزوّدي الكتالوج
مهيّأة مسبقًا.

### المزوّدون السحابيون

يحتاج المزوّدون السحابيون إلى بعض التفاصيل الإضافية.

| المزوّد | التفاصيل |
| --------------------- | ------------------------------------- |
| Azure | اسم المورد ومفتاح API |
| AWS Bedrock | المنطقة ومفتاح API |
| Google Vertex AI | المنطقة وملف JSON لحساب الخدمة |
| Cloudflare AI Gateway | Account ID وGateway ID وAPI token |
| Databricks | عنوان URL لمساحة العمل وtoken |

### المزوّدون المخصصون

انقر **Add Custom Provider** لربط أي نقطة نهاية أخرى، ثم أضف نماذجها باستخدام **Add Model**.

| الحقل | الوصف |
| ---------- | ------------------------------------------------------------------------------- |
| Base URL | الوجهة التي تعيد Console توجيه الطلبات إليها، مثل `https://api.deepseek.com/v1`. |
| Format | Chat Completions أو Responses API أو Anthropic Compatible أو Google Generative AI. |
| Auth mode | Bearer أو API key header أو Custom header. |
| Credential | المفتاح الذي ترسله Console إلى المزوّد. |

## اختيار النماذج

افتح مزوّدًا لعرض نماذجه. لا تتاح للأعضاء إلا النماذج المفعّلة.

- استخدم مفتاح التبديل **Enabled** لتشغيل نموذج أو إيقافه.
- فعّل **New models** لتفعيل النماذج التي يضيفها المزوّد مستقبلًا.

## تعديل النماذج

انقر نموذجًا لتعديله. تُحفظ التغييرات عند إغلاق اللوحة.

| القسم | ما يمكنك تغييره |
| ------------- | --------------------------------------------------------------- |
| General | اسم العرض، وAPI ID، ودعم الأدوات، وأنواع الإدخال والإخراج |
| Variants | صيغ (variants) لكل منها ترويساتها أو متن طلبها الخاص |
| Configuration | الصيغة الافتراضية، وترويسات الطلب ومتنه، وحدود tokens |
| Cost Tiers | أسعار الإدخال والإخراج والقراءة من ذاكرة التخزين المؤقت والكتابة فيها لكل مليون token |

### التسعير المخصص

تبدأ نماذج الكتالوج بسعر القائمة لدى المزوّد. وإذا كان لديك تسعير تفاوضي، كخصم في عقدك مع OpenAI مثلًا، فتجاوز الأسعار تحت
**Cost Tiers** حتى تطابق تقارير الاستخدام و[الميزانيات](/console/budgets) ما تدفعه فعليًا.

| الحقل | سعر القائمة | سعرك |
| ---------------- | ---------- | ---------- |
| Input price | $2.50 | $2.00 |
| Output price | $15.00 | $12.00 |
| Cache read price | $0.25 | $0.20 |

تُميَّز الأسعار التي غيّرتها في صفحة المزوّد. استخدم **Restore default value** على حقل ما، أو **⋯ › Restore...** على
النموذج، للعودة إلى سعر القائمة.

أضف شريحة **Context** عندما يفرض النموذج سعرًا أعلى فوق حجم سياق معيّن، مثل الموجّهات التي تتجاوز 200K token.

### النماذج المخصصة

انقر **Add Model** لإضافة نموذج غير موجود في الكتالوج، مع **Display name** و**Model ID** الخاصين به. واستخدم
**⋯ › Duplicate...** على نموذج موجود للبدء من إعداداته.

## نماذج OpenCode

تدير علامة التبويب **Models** [النماذج](/console/models) التي توفّرها Console، والتي تُدفع تكلفتها من رصيد مساحة العمل.
وتعمل مثل صفحة المزوّد:

- شغّل نماذج بعينها أو أوقفها.
- أوقف **Free models** لحظر النماذج المجانية في مساحة العمل.
- فعّل **New models** لتفعيل نماذج Console الجديدة تلقائيًا.

عطّل المزوّد بأكمله من **⋯ › Disable** لاستخدام مزوّديك الخاصين فقط.

## الاستخدام في OpenCode

يشغّل الأعضاء `/connect` ويختارون مساحة العمل. يظهر كل مزوّد مفعّل باسم مساحة العمل متبوعًا باسم المزوّد، ويسرد الأمر
`/models` نماذجه المفعّلة.

```text
Acme Inc. / Anthropic
```

فعّل **Managed providers only** في **Settings › General** لقصر OpenCode على مزوّدي مساحة العمل لدى الجميع.

## التعطيل أو الإزالة

افتح قائمة **⋯** الخاصة بالمزوّد:

- يُخفي **Disable** المزوّد ونماذجه عن الأعضاء لكنه يحتفظ بإعداداته.
- يحذف **Remove...** المزوّد ونماذجه. ويعرض مربع الحوار من استخدمه مؤخرًا، ويقدّم خيار
  **Disable instead**.

لتدوير مفتاح، انقر بيانات الاعتماد في صفحة المزوّد وأدخل المفتاح الجديد.

## الفوترة

يفوترك المزوّد مقابل tokens، ولا تخصم Console أي رصيد مقابلها. ومع ذلك تسجّل Console كل طلب وتكلفته وفق تسعير النموذج، لذا
تتضمنه تقارير الاستخدام و[الميزانيات](/console/budgets).

لاستدعاء مزوّد من أدواتك الخاصة بدلًا من OpenCode، استخدم [واجهة API للمزوّدين](/console/api/providers).
