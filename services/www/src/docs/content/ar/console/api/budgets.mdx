اقرأ الميزانيات الشهرية الفعلية لكل أعضاء مساحة العمل، وأدِر الميزانية المخصصة لكل عضو من خلال عملية تكامل.

## البدء السريع

أنشئ مفتاح API [لحساب خدمة](/console/api#service-accounts) بأذونات **All** في [Console](https://opencode.ai/console).
لا تستطيع المفاتيح المقتصرة على الاستدلال الوصول إلى بيانات الميزانية أو تغيير الحدود.

```bash
export CONSOLE_URL="https://opencode.ai/console"
export SERVICE_API_KEY="oc_sk_..."
```

اعرض قائمة ميزانيات الأعضاء:

```bash
curl --fail-with-body \
  "${CONSOLE_URL}/api/v1/budgets/members" \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Accept: application/json"
```

## عرض ميزانيات الأعضاء

```text
GET /api/v1/budgets/members
```

تتضمن الاستجابة كل الأعضاء الحاليين، مرتبين حسب البريد الإلكتروني. الحد ذو المصدر `custom` هو تجاوز خاص بالعضو، أما
المصدر `default` فيعني أن الحد موروث من القيمة الافتراضية لمساحة العمل. وإذا كان الحد والمصدر كلاهما null، فالعضو غير
مقيّد بحد.

```json
[
  {
    "user_id": "user_...",
    "email": "alice@example.com",
    "limit_micro_cents": "7525000000",
    "spent_micro_cents": "1250000000",
    "exceeded": false,
    "resets_at": "2026-10-01T00:00:00.000Z",
    "source": "custom",
    "updated_at": "2026-09-03T12:00:00.000Z"
  }
]
```

الحقول المالية في الاستجابة سلاسل نصية عشرية مقوّمة بالميكروسنت، حتى لا تفقد عمليات التكامل الدقة. يساوي الدولار
الأمريكي الواحد 100,000,000 ميكروسنت. ويغطي الإنفاق وطوابع إعادة التعيين الزمنية الشهر التقويمي الحالي بتوقيت UTC.
وتكون قيمة `updated_at` هي null عند عدم وجود تجاوز مخصص للعضو.

## ضبط ميزانية مخصصة

```text
PUT /api/v1/budgets/members/:user_id
```

اضبط ميزانية شهرية قدرها $75.25 لعضو واحد:

```bash
curl --fail-with-body --request PUT \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"budget_dollars":75.25}'
```

يقبل الحقل `budget_dollars` مبلغًا غير سالب بالدولار الأمريكي، بحد أقصى منزلتين عشريتين. والطلب PUT متساوي القوة
(idempotent) ويعيد HTTP 204. استخدم ID العضو الذي تعيده عملية عرض القائمة.

## العودة إلى القيمة الافتراضية لمساحة العمل

```text
DELETE /api/v1/budgets/members/:user_id
```

أزِل التجاوز المخصص:

```bash
curl --fail-with-body --request DELETE \
  "${CONSOLE_URL}/api/v1/budgets/members/user_..." \
  --header "Authorization: Bearer ${SERVICE_API_KEY}"
```

لا يؤدي حذف التجاوز إلى حذف العضو. بعد ذلك يرث العضو ميزانية مساحة العمل الافتراضية، أو يصبح غير مقيّد بحد إذا لم تكن
لمساحة العمل قيمة افتراضية. وتكرار الطلب آمن ويعيد HTTP 204.

## الأخطاء

| الحالة | المعنى |
| ------ | -------------------------------------------------------- |
| `400` | قيمة ID العضو أو مبلغ الميزانية غير صالحة. |
| `401` | مفتاح API للخدمة مفقود أو غير صالح أو منتهي الصلاحية أو ملغى. |
| `403` | لا يملك مفتاح API إذنًا بإدارة الميزانيات. |
| `404` | العضو ليس ضمن مساحة العمل المرتبطة بمفتاح API. |
