## الإرفاق

أرفق ملفًا محليًا، ثم اطلب من OpenCode استخدامه في موجّهك. في تطبيق سطح المكتب أو الويب، اختر **Attach file**، أو الصق
ملفًا، أو اسحبه إلى مربع الموجّه.

```text
Summarize the attached README.md and list the required setup steps.
```

يمكن أن يصل إجمالي الملفات المحددة عبر منتقي الملفات في تطبيق سطح المكتب إلى 20 MiB. وقد تفرض الواجهات الأخرى حدودًا أدنى
من جهة العميل.

<Callout type="warning">
  اختر نموذجًا يقبل إدخال الصور قبل إرفاق صورة. يستطيع OpenCode تمرير الصور المدعومة إلى المزوّد، لكن المزوّد والنموذج
  يفرضان مع ذلك قيودهما الخاصة على الصيغ والأبعاد وعدد الملفات وأحجامها. وقد يرفض النموذج الذي لا يدعم إلا النص الطلبَ.
</Callout>

## الصيغة

تصف مدخلات الموجّهات والأوامر في V2 المرفق بالحقل `uri`، مع الحقلين الاختياريين `name` و`description`:

```json
{
  "uri": "file:///home/me/project/src/server.ts",
  "name": "server.ts",
  "description": "HTTP server entrypoint"
}
```

استخدم عنوان URL مطلقًا بالمخطط `file:` لملف أو دليل متاح للخادم. وفي الملفات النصية، يحدد المعاملان الموجبان `start`
و`end` الأسطر مع بدء الترقيم من 1.

```text
file:///home/me/project/src/server.ts?start=20&end=60
```

استخدم عنوان URL بالمخطط `data:` لإرسال المحتوى مضمّنًا:

```json
{
  "uri": "data:text/plain;base64,SGVsbG8sIE9wZW5Db2RlIQ==",
  "name": "greeting.txt"
}
```

عناوين URL للمرفقات بالمخططين HTTP وHTTPS غير مدعومة. وراجع [مرجع API](/api) المُولَّد لإرسال الموجّهات برمجيًا.

## الصيغ المدعومة

تجعل جلسات V2 الحالية أنواع المرفقات التالية مرئية للنموذج:

| المُدخل                         | ما يتلقاه النموذج                                        | مثال               |
| ------------------------------- | -------------------------------------------------------- | ------------------ |
| ملف نصي بترميز UTF-8            | اسم الملف والنص بعد فك ترميزه                            | `README.md`        |
| دليل                            | قائمة غير تعاودية بالملفات والأدلة المباشرة              | `file:///home/me/` |
| PNG أو JPEG أو GIF أو WebP      | وسائط صورة                                               | `diagram.png`      |

يُعامَل SVG على أنه نص. أما PDF وAVIF وBMP والصوت والفيديو وغيرها من المرفقات الثنائية فلا تُضمَّن في طلب النموذج. حوّل
الملف الثنائي غير المدعوم إلى نص أو إلى صورة مدعومة أولًا؛ مثلًا، صدّر صفحة PDF بصيغة `page-1.png` قبل إرفاقها.

يقرأ OpenCode كل مرفق قبل قبول الموجّه. ويرفض عناوين URL غير الصالحة، والمسارات غير القابلة للقراءة، والمسارات التي ليست
ملفات أو أدلة، والمرفقات التي يتجاوز حجمها بعد فك الترميز 20 MiB. ويُكتشف نوع الوسائط من البايتات نفسها، لذا لا يؤدي تغيير
اسم الملف أو نوع الوسائط في عنوان `data:` إلى جعل ملف ثنائي غير مدعوم مرئيًا.

## الصور

هيّئ معالجة الصور وتوحيد مقاساتها في `opencode.json` أو `opencode.jsonc`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "media": {
    "image": {
      "auto_resize": true,
      "max_width": 2000,
      "max_height": 2000,
      "max_base64_bytes": 5242880,
    },
  },
}
```

جميع الحقول اختيارية:

| الحقل              | القيمة الافتراضية | السلوك                                                                    |
| ------------------ | ----------------- | ------------------------------------------------------------------------- |
| `auto_resize`      | `true`            | يغيّر حجم الصورة التي تتجاوز حدًا مهيّأً؛ وعند `false` تُرفض الصورة.      |
| `max_width`        | `2000`            | أقصى عرض بالبكسل؛ ويجب أن يكون عددًا صحيحًا موجبًا.                       |
| `max_height`       | `2000`            | أقصى ارتفاع بالبكسل؛ ويجب أن يكون عددًا صحيحًا موجبًا.                    |
| `max_base64_bytes` | `5242880`         | أقصى عدد من البايتات في الصورة المرمّزة بـ Base64؛ ويجب أن يكون عددًا صحيحًا موجبًا. |

مثلًا، يرفض هذا الإعداد أي صورة يزيد عرضها على 1200 بكسل بدلًا من تغيير حجمها:

```jsonc title="opencode.jsonc"
{
  "media": {
    "image": {
      "auto_resize": false,
      "max_width": 1200,
    },
  },
}
```

تنطبق هذه الإعدادات على الصور المدعومة المرفقة بالموجّهات وعلى الصور التي تُرجعها الأداة المدمجة `read` على حد سواء.

## المعالجة

تتعرّف الأداة `read` على صيغ PNG وJPEG وGIF وWebP من محتواها، وتقرأ ما يصل إلى 20 MiB من بيانات الصورة المصدر. ثم تتحقق من
العرض والارتفاع وطول Base64 مقارنةً بحدود الصور المهيّأة.

عند ضبط `auto_resize: true`، يحافظ OpenCode على نسبة العرض إلى الارتفاع ويصغّر الصورة حتى حدود الأبعاد. ثم يجرّب ترميزات PNG
وJPEG أصغر تدريجيًا حتى يُستوفى حد Base64، لذا قد يتغير نوع وسائط المخرجات.

```text
Input:  4000 × 2000 WebP
Limits: 2000 × 2000
Output: 2000 × 1000 PNG or JPEG
```

إذا لم يتسع أي ترميز ضمن الحد، تفشل المعالجة. ومع `auto_resize: false`، تفشل الصورة التي تتجاوز أي حد دون تعديلها، كما تفشل
الصورة التي يتعذر فك ترميزها.

```text
Input:  2400 × 1600 JPEG
Limit:  max_width = 2000, auto_resize = false
Result: Image processing fails
```

إذا لم تكن أداة تغيير حجم الصور متاحة، يمرّر OpenCode الصورة الأصلية دون تغيير. لذا فإعدادات الصور حدود للمعالجة، وليست
حدًا للرفع أو حاجزًا أمنيًا.

## الحدود

| الحد                                 | القيمة أو السلوك                                                | مثال                                                |
| ------------------------------------ | --------------------------------------------------------------- | --------------------------------------------------- |
| المرفق المباشر                       | 20 MiB بعد فك الترميز لكل عنصر؛ وقد يفرض العملاء حدودًا أدنى    | يجتاز ملفان بحجم 12 MiB حد العنصر الواحد            |
| التحديد عبر منتقي سطح المكتب         | 20 MiB إجمالًا                                                  | يتجاوز ملفان بحجم 12 MiB حد التحديد                 |
| `max_base64_bytes`                   | بيانات Base64 المرمّزة فقط، دون عنوان `data:` الكامل            | تُحتسب `SGVsbG8=` على أنها 8 بايتات                 |
| حدود الصور لدى المزوّد               | تُطبَّق بعد معالجة OpenCode                                     | قد يرفض المزوّد صورة قبلها OpenCode                 |
| دعم النموذج للمرفقات النصية          | لا يتطلب نموذجًا متعدد الوسائط                                  | يُدرج `notes.txt` نصًا في الموجّه                   |
| حدود النص في `read`                  | يستخدم حدودًا منفصلة للتقسيم إلى صفحات والاقتطاع                | اقرأ سجلًا كبيرًا على صفحات                         |

قبول العميل لملف لا يضمن وصول محتواه إلى النموذج. إذ يجب أن يكون المرفق بصيغة يراها النموذج، وأن يستوفي حدود OpenCode وحدود
المزوّد معًا.
