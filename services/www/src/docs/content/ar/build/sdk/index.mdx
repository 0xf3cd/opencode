تتيح لك الحزمة `@opencode/sdk` استضافة OpenCode مباشرةً داخل تطبيقك. وعلى خلاف [عميل الشبكة](/build/client)، فهي تجمّع خادم
OpenCode وتمرّر استدعاءات API داخل الذاكرة عبر مكوّن توجيه HTTP (router) الخاص به، فلا تفتح أي منفذ HTTP للاستماع ولا تضيف أي قفزة شبكية
بين العميل والخادم.

أما Durable Objects على Cloudflare، فراجع [دليل Cloudflare](/build/sdk/cloudflare).

ثبّت SDK:

```sh
bun add @opencode/sdk
```

## إنشاء مضيف

تُعيد الدالة `OpenCode.create()` مضيفًا تملكه صراحةً. استخدم `await using` لتحرير مكوّن التوجيه الخاص به وخدمات Location
وكائنات Fiber وتسجيلات الإضافات المرتبطة بالنطاق:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

إذا لم تكن الإدارة الصريحة للموارد (explicit resource management) متاحة، فاستدعِ `await opencode.close()` بنفسك.

يستخدم المضيف المضمَّن قيم Promise والأخطاء المُعلنة وخيارات الطلب وتدفقات `AsyncIterable` نفسها التي تستخدمها
`@opencode/client`. ويتيح العميل المُولَّد كاملًا، ويضيف الاسمين المختصرين `sessions` و`events` لمجموعتي الجلسات والأحداث.

## عمليات worktree

تتطلب عمليات worktree معرّف `projectID`. تحمّل عمليتا الإنشاء والتحديث التهيئة والإضافات من النسخة الأساسية (canonical
checkout) المحفوظة للمشروع. أما عملية السرد فتقرأ المخزون المحفوظ فقط، بينما تفعّل عملية الإزالة الإضافات الأساسية وتستخدم
الاستراتيجية المسجّلة، وتفشل إذا لم تكن تلك الاستراتيجية متاحة.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

تكتشف عملية التحديث مجلدات worktree في جميع جذور النسخ المعروفة باستخدام كل الاستراتيجيات المتاحة. ولتسجيل استراتيجية مخصصة،
استخدم [تحويل worktree في إضافة](/build/plugins#worktrees).

## بث الأحداث

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

مرّر `AbortSignal` عبر خيارات الطلب المُولَّدة، أو اخرج من حلقة التكرار لإلغاء جسم الاستجابة.

## التخصيص

خصّص نسخة OpenCode الخاصة بك بتسجيل الإضافات. مرّر الإضافات إلى `OpenCode.create()` لتخصيص الوكلاء والنماذج والأدوات
وغيرها من السلوكيات عند بدء المضيف المضمَّن:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

لتسجيل إضافة أخرى بعد البدء، استدعِ `await opencode.plugin(plugin)`.

راجع [التوثيق الكامل للإضافات](/build/plugins) للتعرّف على خطّافات (hooks) الإضافات والتحويلات والأدوات وسياق الإضافة
الكامل.
