title: "Effect"

الحزمة `@opencode/client/effect` هي العميل المبني أصلًا على Effect لواجهة HTTP API في OpenCode. تُعيد قيم Effect وStream
ذات أنواع محددة، وتفك ترميز الاستجابات إلى قيم Schema الخاصة بـ OpenCode.

```sh
bun add @opencode/client effect
```

## إنشاء عميل

أنشئ عميلًا بعنوان URL للخادم، ثم استدعِ الطرق المجمّعة حسب مورد API.

```ts
import { AbsolutePath, Location, OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const session = yield* client.session.create({
    location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
  })
  yield* client.session.prompt({
    sessionID: session.id,
    text: "Review the current changes",
  })
  return session
})

const session = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

## الترويسات والطلبات

اضبط الترويسات الافتراضية على `HttpClient` الذي توفّره. تعتمد العمليات الأصلية على المقاطعة (interruption) المعتادة في
Effect للإلغاء، بينما تقبل طرق RPC أيضًا خيارات الموقع والترويسات والإشارة لكل استدعاء على حدة.

```ts
import { HttpClient, HttpClientRequest } from "effect/http"

const httpClient = yield * HttpClient.HttpClient
const client =
  yield *
  OpenCode.make({ baseUrl: "https://opencode.example.com" }).pipe(
    Effect.provideService(
      HttpClient.HttpClient,
      HttpClient.mapRequest(httpClient, (request) =>
        HttpClientRequest.setHeaders(request, { authorization: `Bearer ${process.env.OPENCODE_TOKEN}` }),
      ),
    ),
  )

const sessions = yield * client.session.list()
```

## بث الأحداث

تُعيد العمليات المتدفقة، مثل `event.subscribe()` و`session.log()`، قيمًا من نوع Stream في Effect.

```ts
import { Effect, Stream } from "effect"

yield *
  client.event.subscribe().pipe(Stream.runForEach((event) => Effect.logInfo("OpenCode event", { type: event.type })))
```

تتشارك قيم Stream للأحداث الأصلية وأحداث RPC اتصالًا كسولًا (lazy) واحدًا لكل عميل. لا يؤدي إنشاء Stream إلى الاتصال، بل
يحدث الاتصال عند استهلاكه. وإيقاف أحد المستهلكين يُبقي الآخرين قيد التشغيل، ويُغلق المصدر عند مغادرة آخر مستهلك. يُنهي
وصول المصدر إلى نهايته (EOF) أو فشله الاشتراكات الحالية دون إعادة محاولة أو إعادة تشغيل تلقائية للأحداث. ويتلقى المستهلكون
الأصليون المتأخرون علامة الاتصال الحالية قبل الأحداث الحية.

## استدعاء RPC في الإضافات

استخدم العقد المشترك نفسه الذي تستخدمه عملاء Promise وإضافات الخادم:

```ts
import { Acme } from "opencode-acme-plugin/rpc"

const acme = client.rpc(Acme)
const result = yield * acme.search({ query: "hello" }, { location: { directory: "/workspace" } })

yield *
  acme.events
    .subscribe("updated")
    .pipe(
      Stream.runForEach((event) =>
        Effect.logInfo("Plugin event", { type: event.type, location: event.location, text: event.data.text }),
      ),
    )
```

تُستنتج وسائط الطرق ونتائجها من العقد. يحمل الوسيط الاختياري الثاني الخيارات `location` و`signal` و`headers`، وإذا حُذف
الموقع فتُستخدم القيم الافتراضية المعتادة للطلبات. تُقاطَع الاستدعاءات مع قيمة Effect التي تستهلكها. وتُستنتج خرائط أخطاء
الطرق في قناة الأخطاء الخاصة بـ Effect، ويُفك ترميز الأخطاء المُعلنة عبر مخططات بياناتها. يزيل العميل الفرعي ذو الأنواع
المحددة غلاف أخطاء HTTP RPC العام، بينما تحدد الأنواع المحجوزة `rpc.*` إخفاقات إطار العمل.

أحداث RPC هي قيم Stream ذات أنواع محددة، وليست مستمعات `on` بأسلوب استدعاءات الرجوع. تتلقى أحداث واجهة RPC من جميع
المواقع، ويحمل كلٌّ منها الحقل الإلزامي `location` ونوعًا عاديًا ذا بادئة مثل `rpc.acme.updated`. ويختلف ذلك عن مقابض
إضافات الخادم المقيّدة بموقعها الخاص. راجع [RPC في إضافات Effect](/build/plugins/effect/rpc) للتعرّف على التعريفات
والمخططات والتسجيل ودلالات الاشتراكات الحية.

## الخدمة الخلفية المحلية

تكتشف نقطة الدخول `@opencode/client/effect/service`، المخصصة لـ Node فقط، الخدمةَ الخلفية المحلية وتشغّلها وتصادق عليها
وتوقفها في صورة قيم Effect.

```sh
bun add @effect/platform-node
```

أنشئ عميلًا مصادَقًا للخدمة التي ضمنت تشغيلها.

```ts
import { NodeFileSystem } from "@effect/platform-node"
import { OpenCode } from "@opencode/client/effect"
import { Service } from "@opencode/client/effect/service"
import { Effect } from "effect"
import { FetchHttpClient, HttpClient, HttpClientRequest } from "effect/http"

const program = Effect.gen(function* () {
  const endpoint = yield* Service.ensure()
  const httpClient = yield* HttpClient.HttpClient
  const client = yield* OpenCode.make({ baseUrl: endpoint.url }).pipe(
    Effect.provideService(
      HttpClient.HttpClient,
      HttpClient.mapRequest(httpClient, (request) => HttpClientRequest.setHeaders(request, Service.headers(endpoint))),
    ),
  )
  return yield* client.server.info()
})

const health = await Effect.runPromise(
  program.pipe(Effect.provide(FetchHttpClient.layer), Effect.provide(NodeFileSystem.layer)),
)
```

يمكنك اكتشاف الخدمة دون تشغيلها، أو إيقاف الخدمة المسجّلة بعينها.

```ts
const endpoint = yield * Service.discover()
yield * Service.stop()
```
