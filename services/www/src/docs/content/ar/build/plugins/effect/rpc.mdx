title: "RPC"
---

يمكن لإضافات Effect أن تتيح طرقًا وأحداثًا تُعيد قيم Effect وStream ذات أنواع محددة.

## التعريف

استخدم `Rpc.define` مع Effect Schema لتعريف واجهة RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### التحقق من الصحة

يتحقق Effect Schema من القيم ويستنتج أنواع TypeScript الخاصة بها.

```ts
input: Schema.Struct({ query: Schema.String })
```

ويُدعم أيضًا كلٌّ من JSON Schema وStandard Schema.

### المدخلات والمخرجات

استخدم `input` لوسيط الطريقة و`output` لقيمتها المُعادة. واحذف أيًّا منهما عند عدم وجود قيمة.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### الأخطاء

أضف الإخفاقات المتوقعة إلى `errors`. يصبح كل مفتاح قيمة `type` للخطأ.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### الأحداث

أضف الأحداث إلى الخريطة `events` في المستوى الأعلى. يجب أن تكون بيانات الحدث كائنًا.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## التنفيذ

سجّل التنفيذ من داخل قيمة Effect الخاصة بالإضافة:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

تصبح خريطة الأخطاء نوعَ الخطأ في قيمة Effect لكل طريقة. استخدم `context.error(...)` لإنشاء خطأ مُعلن.

## الاستدعاء

بعد تسجيل واجهة RPC، يمكن استدعاؤها عبر HTTP أو من إضافة أخرى.

### عبر HTTP

أنشئ عميل Effect، ثم أنشئ عميل RPC الفرعي:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### من إضافة

يمكن لإضافة Effect أخرى إنشاء عميل فرعي محلي من سياقها:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### الاشتراك

أحداث RPC هي قيم Stream. اشترك باسم الحدث، وشغّل Stream في fiber مرتبط بالنطاق (scoped):

```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield *
  acme.events.subscribe("updated").pipe(
    Stream.runForEach((event) => Effect.logInfo(event.data.text)),
    Effect.forkScoped,
  )
```

الاشتراكات حيّة فقط، وتُغلق عند توقف استهلاك Stream.
