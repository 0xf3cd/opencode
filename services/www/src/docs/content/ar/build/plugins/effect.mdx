title: "Effect"
---

الحزمة `@opencode/plugin/effect` هي النسخة المبنية أصلًا على Effect من واجهة الإضافات البرمجية في OpenCode. تُعيد عمليات
السياق فيها قيم Effect أو Stream، وتُعيد استدعاءات الرجوع قيم Effect، ويُمثَّل عمر الإضافة بواسطة `Scope`.

يوفّر OpenCode الحزمتين `effect` (بما في ذلك المسارات الفرعية المُصدَّرة `effect/*`) و`@opencode/plugin` في بيئة التشغيل عند
تحميل الإضافات واعتمادياتها في `node_modules`. لذا ثبّتهما كاعتماديات peer/dev لأغراض التحقق من الأنواع والاختبار محليًا،
بدلًا من تضمينهما في حزمة إضافتك.

```sh
bun add --peer @opencode/plugin effect
```

صدّر إضافة Effect من `.opencode/plugins/` ليُحمّلها OpenCode تلقائيًا.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

تستخدم الحزم المنشورة ومجلدات الإضافات الموجودة خارج `.opencode/plugins/` تهيئة `plugins` نفسها التي تستخدمها إضافات الخادم
الأخرى.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

راجع [تهيئة الإضافات](/plugins) للتعرّف على التفعيل وحلّ الحزم (package resolution) وترتيب أولوية التهيئة.

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## دورة الحياة

تعمل الدالة `effect` عند تحميل الإضافة. ويُغلق نطاقها (scope) عند إعادة تحميل الإضافة أو إلغاء تحميلها، فتُحرَّر التسجيلات
وكائنات Fiber المرتبطة بالنطاق والمُنهِيات (finalizers) معًا.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

استخدم كائنات Fiber مرتبطة بالنطاق للأعمال الخلفية، إذ يقاطع نطاق الإضافة كائن Fiber أثناء التنظيف.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### السياق

يتيح السياق عميل Effect لخادم OpenCode المتصل، إضافةً إلى ما يخص الإضافات وحدها: التحويلات والخطّافات (hooks) والتخزين
وإعادة التحميل والخيارات. ولا يتيح خدمات Core الخاصة في OpenCode.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

يُعلَن تعريف الإضافة والسياق الكامل على النحو التالي.

### الخيارات

مرّر الخيارات باستخدام الصيغة الكائنية في `opencode.json(c)`.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

اقرأ الخيارات من `ctx.options`، وضيّق أنواع القيم المجهولة قبل استخدامها.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## التحويلات

تعدّل التحويلات الحالة بشكل متزامن عبر محرِّر (editor). يطبّق OpenCode التحويلات بترتيب تسجيلها داخل كل مجال. تساهم
المصادر أولًا بالمزوّدين وتعريفات النماذج غير القابلة للتعديل، ثم تعدّل تحويلات النماذج المرشّحين لدى المزوّدين النشطين.
ويؤدي تنفيذ `yield*` على التسجيل إلى إبقائه ضمن نطاق الإضافة.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

يمكن لتحويل النماذج فرض سياسة على المجموعة الكاملة من المرشّحين لدى المزوّدين النشطين.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

استدعِ `reload` عندما تتغير حالة خارجية يعتمد عليها تحويل ما. في هذا المثال، تُعيد `loadFromSource()` إدخالات بالشكل
`{ info: Provider.Info, models: readonly Model.Info[] }`؛ كما تؤدي إعادة تحميل المزوّدين إلى إبطال نتيجة النماذج بأكملها.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### الوكيل

اقرأ جميع الوكلاء أو اجلب وكيلًا واحدًا بمعرّفه. تتضمن استجابات العميل الموقع بعد حلّه وبيانات Schema.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

حوّل الوكلاء أو أعد تحميلهم.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

المخطط: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### المزوّدون

اقرأ المزوّدين المتاحين أو افحص البيانات الوصفية لمزوّد واحد بمعرّفه.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

تعدّل تحويلات المزوّدين إعدادات المزوّدين وتعريفات المصادر. تشمل قراءات المحرِّر المزوّدين غير النشطين وتعرض التعريفات غير
القابلة للتعديل، بينما تعدّل `models.update` نسخة مملوكة من نموذج المصدر.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-4-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

استبدل مخزون أحد المصادر باستخدام `models.set`، ثم أعد التحميل بعد تغيّر التعريفات التي التقطها.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

للاكتشاف الخاص بحساب معيّن، مرّر الاتصال المستخدَم لتحميل المخزون بوصفه `sourceConnection`. يستبعد OpenCode ذلك المزوّد ما
دام اتصال آخر محددًا، إلى أن تنشر إضافتك مخزونها المحدَّث.

```ts
const connection = yield * ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield * loadInventory(connection)
yield *
  ctx.provider.transform((editor) => {
    editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
  })
```

المخططات: [`Provider.Info`](/api#schema-Provider.Info)، [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### النماذج

اقرأ النماذج المتاحة والاختيار الافتراضي.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

تعدّل تحويلات النماذج المجموعة الكاملة من المرشّحين لدى المزوّدين النشطين. ويبقى المرشّحون المعطَّلون قابلين للتعديل حتى
تنتهي جميع التحويلات؛ ولا تستطيع `update` إضافة نموذج إلا تحت مزوّد متاح.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-4-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

تعدّل استدعاءات الرجوع تجاوزات النماذج الخام. تُدمج القيم الافتراضية للمزوّد مرة واحدة عندما يعتمد OpenCode النتيجة، وتعيد
القراءات اللاحقة دون تغيير استخدامَ تلك النتيجة. وتقرأ `editor.provider` تعريفات المصادر غير القابلة للتعديل، بما فيها
القوالب غير النشطة، لا مخرجات تحويلات النماذج.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-4-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

المخطط: [`Model.Info`](/api#schema-Model.Info).

```ts

```

### الأوامر

اقرأ الأوامر المتاحة في الموقع الحالي.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

يقتصر تحويل الأوامر حاليًا على إضافة أوامر جديدة. ويتلقى المنفِّذ الجلسة ومرفقات الموجّه ووضع التسليم.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

المخططات: [`Command.Info`](/api#schema-Command.Info)،
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

### التكاملات

اقرأ التكاملات، واحصل على بيانات الاعتماد النشطة إن وُجدت.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

اتصل باستخدام مفتاح، أو أدِر محاولة OAuth عبر API المتصلة.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

حوّل التكاملات وطرق المصادقة. استدعاءات الرجوع في طرق OAuth هي قيم Effect، ويمكنها حجز موارد مرتبطة بالنطاق.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

المخططات: [`Integration.Info`](/api#schema-Integration.Info)، [`Integration.Method`](/api#schema-Integration.Method)،
[`Connection.Info`](/api#schema-Connection.Info)، [`Form.Answer`](/api#schema-Form.Answer).

```ts

  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number

)

  readonly integrationID: string

}

  readonly transform: Transform<IntegrationEditor>

  }
}
```

### MCP

اسرد خوادم MCP وحالة اتصالها الحالية.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

لا تدير الإضافات خوادم MCP إلا عبر التحويلات. استخدم `editor.set` لإضافة خادم أو استبداله، و`editor.update` لتغيير تهيئته،
و`editor.remove` لإزالته. وافحص التهيئة باستخدام `editor.list` و`editor.get`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
```

### الأدوات

سجّل أدوات ذات أنواع محددة باستخدام `Schema` في Effect. يتلقى المنفِّذ المدخلات بعد فك ترميزها، ويُعيد قيمة Effect تحتوي على
مخرجات ذات أنواع محددة أو محتوى للعرض أو بيانات وصفية.

يدعم المحرِّر العمليات `add` و`update` و`remove`. استدعاء الرجوع الخاص بالتحويل متزامن: يجب ألا يُعيد Effect أو Promise.
لذا حمّل البيانات الخارجية قبل التسجيل أو إعادة التحميل. يعيد OpenCode تشغيل التحويلات النشطة بترتيب تسجيلها على محرِّر
جديد؛ وعند تطابق الاسم الفعلي للأداة، يتجاوز التسجيلُ الصالح اللاحق التسجيلَ السابق.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

استدعِ `yield* ctx.tool.reload()` بعد تغيير بيانات المصدر التي التقطها استدعاء الرجوع. تعيد عملية إعادة التحميل تشغيل
التحويلات النشطة دون تغيير ترتيبها، ولا تعيد تشغيل دالة `effect` الخاصة بالإضافة.

لكل أداة `id` يحتوي على اسمها الفعلي، وتُعيد `get()` القيمة `undefined` إذا لم يكن ذلك المعرّف موجودًا. استخدم `update`
و`remove` مع الاسم الفعلي للأداة متضمنًا مساحة أسمائها (`acme_greeting` في المثال أعلاه). تتحول النقاط في مساحات الأسماء
والمحارف غير المدعومة في أسماء الأدوات إلى `_`. تُتجاهل الأسماء غير الموجودة؛ إذ يتطلب إنشاء أداة استخدام `add` مع تعريف
كامل. تحافظ التحديثات على الاسم ومساحة الأسماء. ولاستبدال المخططات أو الخيارات، أسند قيمًا جديدة بدلًا من تعديل القيم
المتداخلة. وتُسجَّل التحديثات غير الصالحة في السجل ويبقى التعريف السابق كما هو.

```ts
yield *
  ctx.tool.transform((editor) => {
    editor.update("acme_greeting", (tool) => {
      tool.description = "Greet the user by name"
    })
    editor.remove("acme_obsolete")
  })
```

يُعاد تشغيل التحديثات والإزالات بالترتيب مع عمليات `add`، بما في ذلك بعد تحديث كتالوج MCP.

تُعيد `transform` تسجيلًا مرتبطًا بالنطاق. شغّل `yield* registration.dispose` لإزالة تحويله وإعادة البناء من التحويلات
المتبقية، فيظهر أي تعريف سابق كان قد تجاوزه. التخلص من التسجيل متساوي الأثر (idempotent)، كما يؤدي إغلاق نطاق الإضافة إلى
التخلص من تسجيلاتها.

يلتقط كل طلب نموذج لقطة من الأدوات. تؤثر إعادة التحميل والتخلص على اللقطات المستقبلية، لا على التعريفات أو المنفِّذات التي
التقطها طلب قائم بالفعل. أما المنفِّذات التي تحتفظ (عبر closure) ببيانات قابلة للتغيير في الإضافة فتظل ترى تلك البيانات؛ لذا التقط
القيمة داخل التحويل إذا كان يجب أن تبقى مرتبطة بذلك التعريف.

المخططات: [`Tool.Content`](/api#schema-Tool.Content)، [`Tool.TextContent`](/api#schema-Tool.TextContent)،
[`Tool.FileContent`](/api#schema-Tool.FileContent).


### نظام التحكم في الإصدارات (VCS)

اقرأ معلومات المستودع، أو حالة نسخة العمل، أو الفروقات (diff) في الملفات.

```ts

    const info = yield* vcs.get().pipe(Effect.orDie)
    const branches = yield* vcs.branches({ search: "feature", limit: 10 }).pipe(Effect.orDie)
    const changes = yield* vcs.status().pipe(Effect.orDie)
    const diff = yield* vcs.diff({ mode: "working", context: 3 }).pipe(Effect.orDie)
    yield* Effect.logInfo("vcs", { branch: info.data.branch.current, files: changes.data.length })
  }),
```

سجّل مزوّدًا مرتبطًا بالموقع عبر تحويل مرتبط بالنطاق. يُختار تلقائيًا المزوّد المطابق لنوع المستودع المكتشَف؛ استخدم
`editor.default.set` لاختيار مزوّد مختلف.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",
        info: () => Effect.succeed({ branch: { current: "feature", default: "main" } }),
        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

تتلقى استدعاءات الرجوع الخاصة بالمزوّد الموقع الحالي، وجذر نسخة العمل، والجذر الأساسي للمشروع، ومخزن المستودع الاختياري.
وتتلقى استدعاءات الفروقات أيضًا الوضع المحدد والسياق المطلوب وميزانية المخرجات بالبايت. ويظل اكتشاف المستودعات معتمدًا
على كاشفات Git وMercurial المدمجة في OpenCode.

يمكن للمزوّدين اختياريًا تنفيذ `init(scope)` لإنشاء مستودع في `scope.worktree`. تختار التهيئة الأولية المزوّد بمعرّفه
(Git افتراضيًا)، لا بنوع المستودع المكتشَف. سجّل مزوّدًا يدعم `init` حتى لو لم يكن في الموقع مستودع بعد؛ إذ يتحقق OpenCode
من وجود المجلد وخلوّه من أي مستودع قبل استدعائها، ثم يعيد اكتشاف المشروع. وما زالت صيغ المستودعات الجديدة تحتاج إلى دعم
للاكتشاف يتجاوز استدعاء الرجوع هذا.

### الأحداث

الاشتراك العام في أحداث الخادم هو قيمة `Stream` في Effect. شغّل مستهلكه في fiber منفصل (fork) ضمن نطاق الإضافة لتحصل على
مقاطعة تلقائية.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.tap((item) => Effect.logDebug("OpenCode event", { type: item.type })),
      Stream.runDrain,
      Effect.forkScoped,
    )
  }),
```

استخدم عوامل Stream لاختيار أنواع الأحداث ومعالجتها.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.filter((item) => item.type === "config.updated"),
      Stream.runForEach(() => Effect.logInfo("configuration changed")),
      Effect.forkScoped,
    )
  }),
```

```ts
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", () => Effect.void)
  }),
```

### الجلسات

عدّل تعليمات النظام المجمّعة أو الرسائل أو الأدوات مباشرةً قبل إرسالها إلى النموذج. يعمل `context` لحلقة الوكيل، بينما تعمل
`compaction` و`generate` و`title` للطلبات المساعدة المقابلة. ويقبل كلٌّ من `compaction` و`title` قيمة `result` تتخطى
استدعاء النموذج.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

عدّل إعدادات طلب النموذج، ويمكنك اختياريًا قصر الخطّاف على مزوّد واحد. يحمل الحدث قيمة `kind` نفسها التي تحملها خطّافات HTTP
أدناه.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

عدّل الطلبات أو الاستجابات الأصلية للمزوّد. أجسامها تدفقات تُقرأ مرة واحدة فقط؛ لذا انسخ الجسم أو استبدله قبل قراءته. يعمل
كلا الخطّافين لكل طلب تُصدره الجلسة، وتكون قيمة `event.kind` إحدى القيم `"primary"` أو `"compaction"` أو `"title"` أو
`"generate"` حسب المسار الذي أصدر الطلب.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

يعيد المزوّدون الذين يبثون عبر WebSocket استخدام اتصال واحد لكل جلسة، لذا لا ترى خطّافات HTTP تلك الحركة إطلاقًا. يعمل
الخطّاف التجريبي `experimental.ws.handshake` مرة واحدة لكل استدعاء نموذج قبل اختيار الاتصال، ويتيح قيمتي `url` و`headers`
للاتصال؛ ويؤدي تغيير أيٍّ منهما إلى إعادة فتح المقبس. وتظل خطّافات HTTP تعمل لأي طلب يلجأ إليه مسار WebSocket كبديل احتياطي.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

يتيح الخطّافان `experimental.ws.send` و`experimental.ws.receive` الإطارات نفسها: يعمل `send` بعد أن يبني مشغّل المزوّد إطارًا
صادرًا، ويعمل `receive` على كل إطار وارد قبل أن يراه المشغّل. وأيًّا كان ما يحمله `frame` عند عودة الخطّاف، فهو ما يُرسل عبر
الاتصال أو يصل إلى المشغّل؛ ولا يتحقق OpenCode من صحته.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

تجاوز قرار إعادة المحاولة عند فشل المزوّد، أو استبدل مدة التأخير بالمللي ثانية. يعمل الخطّاف بعد أن يصنّف OpenCode الفشل
ويقترح سياسته، ولكن قبل جدولة أي إعادة محاولة. ولا يكشف كيف ينفّذ OpenCode المحاولة التالية داخليًا.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

قيمة `decision` الأولية هي سياسة OpenCode، لذا يمكن للخطّافات جعل فشل المزوّد الذي يُعدّ نهائيًا عادةً قابلًا لإعادة
المحاولة، أو رفض إعادة محاولة مقترحة. تعمل الخطّافات المتعددة بترتيب تسجيلها، وترى الخطّافات اللاحقة القرار الحالي. ويظل
الحد الأقصى المدمج لعدد المحاولات حدًا صارمًا. تمثّل `attempt` المحاولة الفعلية المقترحة؛ والطلب الأولي هو المحاولة `1`،
لذا تكون أول إعادة محاولة هي المحاولة `2`. وتُستبدل مُدد التأخير غير الصالحة (`NaN` أو اللانهاية أو القيم السالبة) بمدة
التأخير المحسوبة. أما التعافي من تجاوز السياق فيبقى منفصلًا، لأنه يضغط المحادثة بدلًا من إعادة محاولة الطلب نفسه.

#### المرجع

```ts
interface SessionHooks {
  readonly context: SessionContext
  readonly compaction: SessionCompaction
  readonly generate: SessionGenerate
  readonly title: SessionTitle
  readonly "model.request": SessionModelRequest
  readonly "http.request": SessionHttpRequest

  readonly "experimental.ws.send": SessionWebSocketSend

interface SessionRetry {

```

### أوامر shell

عدّل أوامر shell أو مجلدات العمل أو مُدد المهلة أو الملفات التنفيذية أو متغيرات البيئة قبل التنفيذ.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const shell = ctx.shell
    yield* shell.hook("create.before", (event) =>
      Effect.sync(() => {
        if (event.command === "npm") event.command = "bun"
        event.timeout = Math.min(event.timeout, 60_000)
        event.env.COMPANY_ENV = "development"
      }),
    )
  }),
```

### الأدوات

يمكن للخطّافات السابقة للتنفيذ (before) استبدال المدخلات أو الفشل بالخطأ `Tool.Error`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

ويمكن للخطّافات اللاحقة للتنفيذ (after) فحص النتائج الناجحة والإخفاقات أو استبدالها.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

#### المرجع

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
}

interface ToolFailures extends Record<keyof ToolHooks, unknown> {
  readonly "execute.before": Tool.Error
  readonly "execute.after": never
}

interface ToolHookDomain {
  readonly hook: Hooks<ToolHooks, ToolFailures>
}
```

توضح أنواع التسجيل المشتركة العمليات التي تتطلب نطاق الإضافة.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## النشر

تستخدم الإضافة المنشورة كحزمة التصدير الافتراضي نفسه الذي تستخدمه إضافة Effect المحلية. صدّر تنفيذ Effect من نقطة الدخول
الرئيسية، وأعلن `effect` بوصفها `peerDependency`.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.0"
  }
}
```

يعيد OpenCode توجيه عمليات استيراد `effect` والمسارات الفرعية المُصدَّرة `effect/*` و`@opencode/plugin` (بما في ذلك عمليات
الاستيراد من الاعتماديات في `node_modules` الخاصة بالإضافة) إلى نسخ بيئة التشغيل في المضيف، حتى تتشارك كائنات Fiber
والمسجِّلات ومحللات `Schema` نسخة واحدة من بيئة التشغيل.

- لا تضمّن `effect` في حزمة الإضافة المنشورة. وإذا كنت تبني باستخدام أداة تجميع (bundler)، فاجعل `effect` و`effect/*`
  خارجيتين (external).
- تعمل الإضافات واعتمادياتها في `node_modules` دائمًا مع نسخة `effect` الخاصة بإصدار OpenCode المضيف. لذا استخدم واجهات
  `effect` ومسارات الوحدات المتوافقة مع إصدار OpenCode الذي تستهدفه؛ أما الاعتماديات المبنية على إصدار رئيسي آخر من `effect`
  (مثل Effect 3) فتتلقى هي أيضًا نسخة `effect` الخاصة بالمضيف، وهي غير مدعومة.
- لا تتوفر إلا المسارات الفرعية العامة من `effect`. والإضافة التي تستورد إحدى وحدات `internal` الخاصة في Effect تفشل في
  التحميل بخطأ يذكر المسار.
- لا يتضمن ملف OpenCode التنفيذي المُجمَّع أصول Scalar وSwagger UI التي تستخدمها صفحات توثيق HTTP API في Effect؛ لذا يؤدي
  تقديم تلك الصفحات من إضافة إلى عرض إشعار بدلًا منها.

تُصدِّر نقطة دخول الحزمة `Plugin.define` مع دالة `effect`.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

استخدم إصدارات متوافقة مع إصدار OpenCode الذي تستهدفه، واختبر الحزمة المثبّتة بدلًا من الاكتفاء بنسخة مرتبطة عبر مساحة
العمل.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
