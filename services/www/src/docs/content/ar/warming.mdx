---
title: "التسخين المسبق"
---

يرسل تسخين الجلسة طلبات دورية إلى النموذج للحفاظ على ذاكرة التخزين المؤقت للموجّهات لدى المزوّد، أو على أي حالة أخرى قصيرة
العمر، أثناء توقفك بين الموجّهات. وهو معطّل افتراضيًا.

فعّل التسخين المسبق في أي [ملف من ملفات تهيئة OpenCode](/config):

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

بهذه التهيئة، يسخّن OpenCode الجلسة النشطة مؤخرًا بعد أربع دقائق دون أي طلب إلى النموذج. ويستمر في ذلك كل أربع دقائق إلى
أن تمر 30 دقيقة على آخر طلب لا يخص التسخين.

## الخيارات

استخدم صيغة الكائن لتغيير موجّه التسخين أو فاصل الخمول أو النافذة النشطة:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| الحقل | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `prompt` | تعليمات إبقاء الجلسة نشطة | يُلحَق بوصفه رسالة مستخدم مؤقتة في كل طلب تسخين. وتطلب القيمة الافتراضية من النموذج ألا ينفّذ أي عمل وألا يستخدم أي أداة وأن يرد بـ `OK`. |
| `interval` | `"4 minutes"` | مدة الخمول قبل طلب التسخين التالي. |
| `duration` | `"30 minutes"` | نافذة التسخين، وتُحتسب من آخر طلب إلى النموذج لا يخص التسخين. |

تحتفظ حقول الكائن المحذوفة بقيمها الافتراضية. مثلًا، لا يغيّر هذا الإعداد إلا الفاصل الزمني:

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## المدد الزمنية

يقبل `interval` و`duration` سلاسل نصية تمثل مددًا زمنية. ويجب أن يؤول كلاهما إلى قيمة محدودة أكبر من الصفر؛ وإلا يتخطى
OpenCode التسخين ويسجّل تحذيرًا.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## التوقيت

يبدأ التسخين بعد أي طلب إلى النموذج لا يخص التسخين. وبعد انتهاء طلب تسخين، يبدأ فاصل الخمول التالي، لكن النافذة النشطة لا
تُمدَّد.

```text
00:00  normal model request
00:04  warming request
00:08  warming request
00:30  warming stops
```

يعيد أي نشاط جديد للنموذج لا يخص التسخين ضبط المؤقتين كليهما. وإذا كان الفاصل مساويًا للمدة أو أطول منها، تنتهي النافذة
النشطة قبل إرسال أي طلب تسخين.

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

## الطلبات

يستخدم طلب التسخين النموذج والوكيل والتعليمات وسياق المحادثة الحالية للجلسة. ويُلحق OpenCode الموجّه المهيّأ مؤقتًا، ويجري
استدعاءً واحدًا للنموذج، ثم يتجاهل الاستجابة.

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

لا يقبل الطلب أي مدخلات، ولا يضيف رسائل إلى السجل، ولا يغيّر حالة الجلسة الدائمة. ولا ينفّذ OpenCode استدعاءات الأدوات
المحلية ولا يواصل حلقة أدوات؛ كما يطلب الموجّه الافتراضي من النموذج عدم استخدام الأدوات.

## الإخفاقات

تُسجَّل إخفاقات التسخين دون أن تُفشل الجلسة أو تغيّرها. وينتظر OpenCode حتى الفاصل التالي قبل المحاولة مجددًا، بينما يستمر
العد التنازلي للنافذة النشطة الأصلية.

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

## التكاليف

طلبات التسخين طلبات حقيقية إلى المزوّد. فقد تستهلك tokens، وتترتب عليها تكاليف، وتُحتسب ضمن حدود المعدل، وقد تفشل كغيرها
من طلبات النموذج.

- تزيد الفواصل الأقصر عدد الطلبات.
- تسمح المدد الأطول بمزيد من طلبات التسخين.
- لا تفعّل التسخين إلا إذا كانت فائدته لدى المزوّد تستحق الاستخدام الإضافي.

مثلًا، تسمح القيم الافتراضية بما يصل إلى سبع محاولات تسخين خلال نافذة واحدة متصلة مدتها 30 دقيقة: عند الدقائق 4 و8 و12
و16 و20 و24 و28.

## التعطيل

اضبط `warming` على `false` لتعطيله صراحةً. ويبقى التسخين معطّلًا أيضًا إذا حذفت الحقل.

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
