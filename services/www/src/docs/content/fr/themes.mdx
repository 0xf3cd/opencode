title: "Thèmes"
---

Choisissez un thème dans l'interface en terminal : appuyez sur `Ctrl+P`, sélectionnez **Open settings**, puis ouvrez
**Theme**. Vous pouvez aussi le définir directement dans votre configuration globale du CLI :

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Les thèmes relèvent du client en terminal. Définissez le thème dans `cli.json`, et non dans `opencode.json`. Consultez
[Paramètres du CLI](/cli/config) pour l'emplacement de ce fichier et les autres paramètres du terminal.

## Modes

Utilisez `system` pour suivre l'apparence de votre terminal, ou fixez le thème sur un seul mode :

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Valeur   | Comportement                                     |
| -------- | ------------------------------------------------ |
| `system` | Suit le mode clair ou sombre du terminal.        |
| `dark`   | Utilise toujours le thème sombre.                |
| `light`  | Utilise toujours le thème clair.                 |

Si un thème personnalisé ne fournit qu'un seul mode, OpenCode utilise ce mode lorsque l'autre est demandé.

## Thèmes intégrés

Sélectionnez un thème intégré par son nom :

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Les thèmes disponibles comprennent notamment :

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

Le thème `system` est disponible lorsqu'OpenCode peut lire la palette de votre terminal.

## Fichiers

Pour créer un thème global nommé `ocean`, utilisez l'outil de thème afin de générer un fichier complet dans le
répertoire global des thèmes. Sa structure se présente ainsi (extrait des parties pertinentes) :

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Sélectionnez ensuite `ocean` dans les paramètres ou définissez `theme.name` sur `ocean` dans `cli.json`. Le nom du
fichier, sans `.json`, est le nom du thème.

| Portée  | Répertoire                                       |
| ------- | ------------------------------------------------ |
| Globale | `~/.config/opencode/themes/`                     |
| Projet  | `.opencode/themes/` dans l'arborescence du projet |

OpenCode ne lit que les fichiers `.json`. Un thème plus proche du répertoire courant remplace un thème global ou parent
portant le même nom.

## Format

Chaque thème V2 déclare un arbre de tokens `base` complet et au moins une palette de teintes `light` ou `dark`. Les modes
n'héritent que de la base de ce fichier ; ils n'héritent ni du thème OpenCode intégré ni l'un de l'autre. Utilisez
l'outil de thème pour générer une base complète avant de la personnaliser.

Les exemples ci-dessous ne montrent que les sections utiles à chaque notion ; ce ne sont pas des fichiers de thème
complets.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Couleurs

Utilisez une couleur hexadécimale, `transparent` ou une référence à une autre couleur du thème :

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Les valeurs hexadécimales peuvent comporter 3, 4, 6 ou 8 chiffres. Les références commencent par `$` ; les références de
teinte prennent la forme `$hue.<name>.<step>`.

## Teintes

Remplacez un alias de teinte pour modifier d'un coup toute une famille de couleurs associées :

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Type   | Valeurs                                                              |
| ------ | -------------------------------------------------------------------- |
| Base   | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Alias  | `accent`, `interactive`, `neutral`                                   |
| Palier | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Les paliers de teinte suivent le sens de contraste du mode : dans les thèmes clairs, ils vont du foncé (`100`) au clair
(`900`), tandis que dans les thèmes sombres, ils vont du clair (`100`) au foncé (`900`).

`categorical` définit la liste ordonnée des teintes utilisées pour distinguer les agents et les autres éléments répétés.
Elle doit contenir au moins une teinte de base ou un alias.

## États

Utilisez les clés d'état pour modifier les couleurs interactives. Les états non spécifiés utilisent la valeur de base la
plus proche :

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Groupe  | Valeurs                                                      |
| ------- | ------------------------------------------------------------ |
| Actions | `primary`, `secondary`, `destructive`                        |
| États   | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Les champs de formulaire utilisent les mêmes clés d'état, directement sous `text.formfield` ou `background.formfield`.

## Tokens

La `base` complète contient tous les groupes de tokens. Un mode peut en remplacer n'importe quelle partie après avoir
fourni sa palette de teintes complète :

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Groupe       | Rôle                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| `text`       | Texte de base, atténué, d'action, de champ de formulaire et de feedback     |
| `background` | Fond de base, surfaces, actions, champs de formulaire et fonds de feedback  |
| `border`     | Bordures                                                                    |
| `scrollbar`  | Barres de défilement                                                        |
| `diff`       | Couleurs des ajouts, suppressions, contexte, surlignage et numéros de ligne |
| `syntax`     | Coloration syntaxique du code source                                        |
| `markdown`   | Éléments Markdown                                                           |

Les clés de syntaxe sont `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` et
`punctuation`. Les clés Markdown sont `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`,
`horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` et `codeBlock`.

## Surfaces surélevées

Les panneaux, boîtes de dialogue, menus et notifications (toasts) choisissent leur niveau de profondeur dans
`background.raised`. Les boîtes de dialogue prennent en plus en charge une surface contextuelle `@dialog`. Le TUI résout
à nouveau la palette après avoir appliqué `@dialog` : les tokens qui référencent `$background.base` suivent donc le fond
de la boîte de dialogue :

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` accepte les mêmes groupes de tokens que le mode de base. La valeur contextuelle `base` d'une action sert aussi
de repli pour ses états non spécifiés ; un remplacement d'état explicite garde la priorité.
