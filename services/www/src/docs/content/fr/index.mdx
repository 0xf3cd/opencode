OpenCode est un agent de code IA open source. Il est disponible sous forme d'interface en terminal, d'application de bureau
et d'application web.

Le paquet npm utilise un script postinstall pour sélectionner le binaire natif `opencode` adapté à votre plateforme. Les
commandes Bun et pnpm autorisent explicitement ce script ; Vite+ ne nécessite aucune option supplémentaire. La commande mise nécessite mise 2026.10.9 ou une version ultérieure ; les versions antérieures installent OpenCode 1.

Les gestionnaires de paquets Windows ne sont pas pris en charge.


Téléchargez un binaire CLI autonome pour votre plateforme.

- **macOS :** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows :** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc) :** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## Web

Accédez à l'interface web d'OpenCode avec la commande `opencode pair`.

```bash
$ opencode pair

  URLs      http://127.0.0.1:49374
  Username  opencode
  Password  ********
```

## Docker

Les images Docker utilisent des tags versionnés, par exemple `ghcr.io/anomalyco/opencode:2.0.0`.

## Connexion

OpenCode prend en charge nativement de nombreux fournisseurs de LLM : vous pouvez vous y connecter directement
[depuis le TUI](/cli/providers) avec `/connect`.

Pour configurer des fournisseurs personnalisés, consultez [Fournisseurs](/providers).

Pour accéder facilement aux meilleurs modèles de code, essayez [OpenCode Console](/console).

Vous pouvez aussi essayer [OpenCode Go](/console/go), un abonnement à 10 $/mois qui vous donne accès aux meilleurs
modèles open source.

## Personnalisation

Adaptez OpenCode à vos besoins en modifiant la [configuration d'OpenCode](/config), en [chargeant des plugins](/plugins),
en [connectant des serveurs MCP](/mcp-servers) ou en [créant des commandes](/commands). Pour les thèmes et les raccourcis
clavier de l'interface en terminal, consultez [Paramètres du CLI](/cli/config).
