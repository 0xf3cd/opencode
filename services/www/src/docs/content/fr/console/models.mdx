OpenCode Console propose une liste de modèles testés et validés par l'équipe OpenCode. Connectez-vous, ajoutez des
crédits et obtenez une clé API pour les utiliser avec OpenCode ou un autre agent de code.

La Console fonctionne comme n'importe quel autre fournisseur dans OpenCode. Elle est **entièrement facultative** : vous
pouvez utiliser n'importe quel autre fournisseur à la place. Pour un abonnement avec une utilisation incluse, consultez
[OpenCode Go](/console/go).

## Fonctionnement

1. Connectez-vous à la [Console](https://opencode.ai/console), ajoutez vos informations de facturation et des crédits,
   puis copiez votre clé API.
2. Exécutez `/connect` dans le TUI, choisissez le fournisseur OpenCode à l'usage (pay-as-you-go) et collez votre clé API.

   ```text
   /connect
   ```

3. Exécutez `/models` pour afficher les modèles disponibles et en sélectionner un.

   ```text
   /models
   ```

Vous êtes facturé à la requête et pouvez ajouter des crédits à votre compte.

### Jev

Jev est un modèle System One de TypeSafe AI conçu pour des décisions rapides et structurées. Au lieu de générer du
texte, il évalue un `state` au regard de questions typées et renvoie des valeurs et des probabilités directement
exploitables par votre code. Il prend en charge les questions fermées oui/non (`noul`), à choix multiples (`choice`) et
notées selon une grille d'évaluation (`score`).

Utilisez votre clé API OpenCode Console avec le point de terminaison `https://opencode.ai/inference/v1/systemone`. Cet
exemple vérifie si une demande d'assistance est urgente :

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Vous pouvez poser plusieurs questions dans une même requête. Jev les évalue en parallèle et renvoie chaque réponse sous
l'ID de la question correspondante :

```bash
curl https://opencode.ai/inference/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.13",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Utilisez `jev-1.13-free` au lieu de `jev-1.13` pour profiter du modèle gratuit pendant une durée limitée. Consultez la
[documentation de TypeSafe AI](https://docs.typesafe.ai/) pour en savoir plus sur les types de questions et les champs de
la réponse.

## Contexte

Les modèles disponibles sont nombreux, mais seuls quelques-uns fonctionnent bien comme agents de code. Les fournisseurs
diffèrent aussi en configuration, en performances et en qualité : un modèle utilisé via une passerelle comme OpenRouter
peut donc se comporter différemment.

<Callout type="tip">Nous avons testé une sélection de modèles et de fournisseurs qui fonctionnent bien avec OpenCode.</Callout>

Pour constituer ce catalogue, nous avons :

1. Testé une sélection de modèles et échangé avec leurs équipes sur la meilleure façon de les exécuter.
2. Travaillé avec les fournisseurs pour nous assurer que les modèles étaient servis correctement.
3. Évalué chaque combinaison modèle/fournisseur pour établir une liste que nous recommandons en toute confiance.

La Console est une passerelle d'IA qui vous donne accès à ces modèles.

## Objectifs

Nous avons créé la Console pour :

1. **Évaluer** les meilleurs modèles et fournisseurs pour les agents de code.
2. Proposer les options de **meilleure qualité**, sans dégrader les performances ni rediriger vers des fournisseurs moins
   chers.
3. Répercuter les **baisses de prix** en vendant à prix coûtant, avec une marge destinée uniquement à couvrir les frais de
   traitement.
4. N'imposer **aucun verrouillage** : utilisez la Console avec n'importe quel agent de code, ou un autre fournisseur avec
   OpenCode.
