---
title: "Raccourcis clavier"
---

Personnalisez les raccourcis dans `cli.json` :

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Utilisez une chaîne pour une seule touche :

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Séparez les alternatives par des virgules :

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Désactivez un raccourci avec `"none"` ou `false` :

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Utilisez un objet pour contrôler le comportement des événements :

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` vaut `ctrl+x` par défaut. Dans un autre raccourci, `<leader>` désigne cette touche.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Les ID de commande inconnus sont rejetés.

## Mini

La commande `app.clear` ne fonctionne que dans [`opencode mini`](/cli). Appuyez sur `ctrl+l` pour effacer l'écran visible et réafficher le prompt. Le terminal conserve l'historique de défilement.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Par défaut | Description      |
| ----------- | ---------- | ---------------- |
| `app.clear` | `ctrl+l`   | Effacer l'écran  |

## Visionneuse de diffs

Appuyez sur `d` (`diff.switch_source`) pour choisir **All**, **Committed**, **Uncommitted** ou **Last turn** (dans une session), ou sélectionnez **Base** pour changer la branche de comparaison. Ces choix sont conservés jusqu'à la fermeture du TUI. Définissez la portée initiale avec [`diffs.source` dans `cli.json`](/cli/config#diffs).

Les raccourcis de défilement, de pagination et de début/fin agissent toujours sur le diff. Il n'y a pas de bascule du focus clavier : cliquez sur un fichier pour l'ouvrir, sur un dossier pour le développer ou le réduire, et utilisez la molette de la souris pour faire défiler l'arborescence des fichiers.

Utilisez `n` / `p` ou `alt+down` / `alt+up` (Option sur macOS) pour passer d'un fichier à l'autre. Dans la visionneuse de diffs, les raccourcis Alt parcourent les fichiers et non les onglets de session.

Appuyez sur `m` pour marquer un fichier comme relu et réduire le contenu de son patch. Dans la vue de tous les fichiers, appuyez de nouveau sur `m` pour retirer la marque et rouvrir le patch. En vue fichier unique, marquer un fichier comme relu passe automatiquement au fichier suivant, mais reste sur le dernier fichier au lieu de revenir au premier. Retirer la marque ne fait jamais avancer.

Faites un clic droit sur un fichier dans la barre latérale ou sur l'en-tête de son diff pour choisir **Mark complete** (ou **Mark incomplete**). Cela modifie le même état de relecture que `m`. Marquer comme terminé un autre fichier depuis son menu ne le sélectionne pas et ne fait pas avancer le fichier en cours de lecture.

Les variantes de `diff.help` avec Shift prennent en charge les terminaux qui signalent le modificateur Shift lorsque vous appuyez sur `?`.

Sélectionnez une commande en cours d'exécution dans l'onglet **Shell** et appuyez sur **Enter**, ou cliquez dessus, pour afficher le stdout et le stderr capturés.
Utilisez **↑/↓**, **Page Up/Down** ou **Home** pour faire défiler, **End** pour suivre la nouvelle sortie et **Esc** pour revenir sans arrêter la commande.
La visionneuse affiche la sortie récente et reste ouverte une fois la commande terminée ; la sortie redirigée vers un fichier n'est pas incluse.
