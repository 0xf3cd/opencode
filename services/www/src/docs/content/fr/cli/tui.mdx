title: "TUI"
description: "Démarrez une session et découvrez les workflows courants de l'interface en terminal."
---

Lancez OpenCode depuis votre projet, saisissez une demande et appuyez sur **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Appuyez sur **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** ou **Ctrl+J** pour insérer un saut de ligne. Pendant qu'OpenCode travaille, **Enter** envoie le prompt pour réorienter la session active ; appuyez sur **Ctrl+X**, puis sur **Enter** pour mettre le prompt en file d'attente.

## Contexte

Saisissez `@` pour rechercher un fichier, puis sélectionnez-le pour le joindre au prompt. Continuez à taper après `@` pour affiner les résultats.

```text
Review @src/auth.ts for error handling problems
```

Vous pouvez ajouter une ligne ou une plage de lignes après le chemin.

```text
Explain @src/auth.ts#20-45
```

## Shell

Saisissez `!` au début d'un prompt vide pour passer en mode shell. Tapez une commande et appuyez sur **Enter** ; appuyez sur **Esc** pour quitter le mode shell sans rien exécuter.

```text
!git status
```

Les commandes shell s'exécutent dans le répertoire de travail de la session, et leur sortie reste dans la session.

## Commandes

Saisissez `/` pour afficher la liste des commandes slash. Continuez à taper pour filtrer la liste, puis appuyez sur **Enter** pour exécuter la commande sélectionnée.

```text
/models
```

Parmi les commandes courantes figurent `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` et `/editor`. Appuyez sur **Ctrl+P** pour ouvrir la palette de commandes, qui regroupe toutes les actions disponibles dans la vue actuelle.

Après une mise à jour, OpenCode affiche une fois sur l'écran d'accueil les nouveautés de la version. Exécutez `/highlights` pour les revoir, ou définissez `"highlights": false` dans [`cli.json`](/cli/config#alerts) pour qu'elles ne s'ouvrent plus automatiquement.

## Questions annexes

Exécutez `/btw <question>` pour poser une question rapide sur la conversation en cours. La réponse s'appuie sur le contexte de la session et sur le modèle actuel, mais n'est pas ajoutée à la conversation : elle n'influence donc pas les prompts suivants. Un indicateur `/btw` s'affiche dans le pied du prompt pendant l'exécution, puis la réponse s'ouvre dans une boîte de dialogue ; appuyez sur **C** pour la copier.

```text
/btw why did the test in step 2 fail?
```

## Modèles

Appuyez sur **Ctrl+X**, puis sur **M** pour choisir un modèle, ou exécutez `/models`. Appuyez sur **F2** pour parcourir les modèles récemment utilisés.

Appuyez sur **Ctrl+X**, puis sur **A** pour choisir un agent, ou exécutez `/agents`. Appuyez sur **Shift+Tab** pour passer d'un agent à l'autre.

## Sessions

Appuyez sur **Ctrl+X**, puis sur **N** pour démarrer une nouvelle session. Appuyez sur **Ctrl+X**, puis sur **L**, ou exécutez `/sessions` pour revenir à une session existante ; **Ctrl+O** ouvre à la fois les sessions et les projets récents.

Les onglets sont activés par défaut. Utilisez **Ctrl+Tab** et **Ctrl+Shift+Tab** pour passer de l'un à l'autre, **Ctrl+X** puis **W** pour en fermer un, et **Ctrl+Shift+T** pour rouvrir le dernier onglet fermé.

## Historique

Appuyez sur **Ctrl+X**, puis sur **U**, ou exécutez `/undo`, pour annuler le dernier message utilisateur et le travail qui a suivi. Le prompt annulé revient dans la zone de saisie pour que vous puissiez le modifier.

Appuyez sur **Ctrl+X**, puis sur **R**, ou exécutez `/redo`, pour restaurer le travail annulé. Si vous envoyez plutôt un nouveau prompt, l'annulation est validée et la session reprend à partir de ce point.

## Éditeur

Définissez `VISUAL` ou `EDITOR`, puis appuyez sur **Ctrl+X**, puis sur **E**, ou exécutez `/editor`, pour modifier le prompt actuel dans cet éditeur. Enregistrez et quittez pour renvoyer le texte dans la zone de saisie, puis appuyez sur **Enter** pour l'envoyer.

```bash
export EDITOR="nvim"
opencode
```

La touche leader est **Ctrl+X** par défaut. Consultez [Raccourcis clavier](/cli/keybinds) pour modifier ces raccourcis.
