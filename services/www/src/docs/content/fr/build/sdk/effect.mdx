---
title: "Effect"
---

`@opencode/sdk/effect` est le SDK embarqué natif Effect. Les opérations renvoient des Effects et des Streams typés, et la
fermeture du Scope propriétaire libère le routeur, les services Location, les fibers et les enregistrements de plugins.

```sh
bun add @opencode/sdk effect
```

## Créer un hôte

Créez l'hôte dans `Effect.scoped`, puis utilisez ses groupes d'API générés ou l'alias `sessions`.

```ts
import { AbsolutePath, Location, OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const opencode = yield* OpenCode.create()
    const session = yield* opencode.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* opencode.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

L'hôte embarqué utilise les mêmes valeurs de schéma, erreurs déclarées, options de requête et Streams que
`@opencode/client/effect`.

```ts
const info = yield* opencode.server.info()
const sessions = yield* opencode.sessions.list()
```

## Flux d'événements

Les points de terminaison de streaming renvoient des valeurs `Stream` Effect. Lancez les consommateurs avec un fork dans
le Scope de l'hôte lorsqu'ils doivent s'exécuter en arrière-plan.

```ts
import { Effect, Stream } from "effect"

yield* opencode.events.subscribe().pipe(
  Stream.runForEach((event) => Effect.logInfo("OpenCode event", { type: event.type })),
  Effect.forkScoped,
)
```

## Personnalisation

Personnalisez votre instance OpenCode en enregistrant des plugins Effect. Utilisez l'hôte embarqué pour personnaliser
les agents, les modèles, les outils et d'autres comportements :

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield* opencode.plugin(plugin)
```

Consultez la [documentation complète des plugins Effect](/build/plugins/effect) pour les hooks, les transformations, les
outils et le contexte complet des plugins.

## Layer

Utilisez `OpenCode.layer()` lorsque l'hôte embarqué doit être un service de l'application.

```ts
import { OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const opencode = yield* OpenCode.Service
  return yield* opencode.server.info()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(OpenCode.layer())))
```
