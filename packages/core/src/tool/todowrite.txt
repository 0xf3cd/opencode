Create and update a todo list for the current session. The user sees it as your working plan.

- Use it for multi-step work or when the user gives several tasks. Skip it for single, simple, or conversational requests.
- Send the full list on every call; it replaces the previous one.
- Keep one item `in_progress` at a time. Mark it `completed` only once the work is actually done.
- Only call it when the list changes.
