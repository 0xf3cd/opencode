Create and update a todo list for the current session. The user sees it as your working plan, so keep it accurate.

Use it for work with several distinct steps, or when the user gives multiple tasks or asks for a todo list. Skip it for a single simple change or a purely conversational request.

- Send the full list on every call; it replaces the previous one.
- Statuses: `pending` (not started), `in_progress` (working on it now), `completed` (done), `cancelled` (no longer needed).
- Keep exactly one item `in_progress` while work remains. Mark it before you start and update it as soon as you finish; don't batch updates.
- Mark an item `completed` only after the work, including any required verification, is actually done. If you're blocked, keep it `in_progress` and add an item for the blocker.
- Keep items specific and actionable, and add follow-ups you discover along the way.
- Only call it when the list changes.
